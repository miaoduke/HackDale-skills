# 财务报表可靠性评估

## 适用场景
需要评估财务报表可靠性以支持分析结论时，执行危险信号识别程序和局限性评估。

## 基本原则
只有依据规范的、可靠的财务报表，才能得出正确的分析结论。"规范的、可靠的"定义：除报表本身的局限性外，不存在虚假陈述。

## 危险信号识别程序

### 第一类：财务报告失范
- 重大遗漏（可能因不想讲真话引起）
- 不能及时提供报告（暗示企业当局可能与注册会计师存在分歧）
- 不规范的财务报告，其可靠性应受到怀疑

### 第二类：数据出现异常
| 异常类型 | 具体情形 | 可能原因 |
|---------|---------|---------|
| 原因不明的会计调整 | - | 利用会计政策灵活性"粉饰"报表 |
| 应收账款异常增加 | 与销售相比 | 可能存在提前确认收入问题 |
| 净利润与经营现金流缺口加大 | - | 可能存在盈余管理 |
| 利润总额与应纳税所得额缺口加大 | - | 可能存在盈余管理 |
| 第四季度大额资产冲销和调整 | - | 中期报告存在问题，年度报告根据注册会计师意见调整 |

**处理原则**：异常数据如无合理解释，应考虑该数据的真实性和一贯性是否存在问题。

### 第三类：关联方交易异常
- 关联方交易的定价不公允
- 存在转移利润的可能

### 第四类：资本利得金额大
- 在经营业绩不佳时，公司可能通过出售长期资产、债务重组等交易实现资本利得

### 第五类：审计报告异常
- 无正当理由更换注册会计师
- 出具非标准审计报告

## 财务报表信息披露的局限性

### 局限性根源
1. **会计环境**：包括会计规范、会计管理、税务与会计关系、外部审计、法律系统、资本市场结构、公司治理结构等
2. **企业会计策略**：企业根据环境和经营目标作出的主观选择，包括会计政策、会计估计、补充披露及具体报告格式的选择

### 会计环境导致的局限性
- 历史成本报告：财务数据不代表现行成本或变现价值
- 币值不变假设：财务数据不按通货膨胀率或物价水平调整
- 谨慎原则：可能少计收益和资产
- 分期报告：只报告短期信息，不能提供反映长期潜力的信息

### 企业会计策略导致的局限性
- 不同企业会有不同的会计策略，导致财务报告差异
- 对同一会计事项，会计准则允许公司选择不同的会计政策
- 影响信息可比性

### 具体局限性表现
- **信息不完整**：财务报表没有披露企业的全部信息
- **存在估计误差**：已经披露的财务信息存在会计估计误差
- **可比性降低**：管理层的各项会计政策选择，有可能导致降低信息可比性

## 发现危险信号后的处理程序
1. 对于存有"危险信号"的报表，分析人员要通过更细致的考察或获取其他有关信息
2. 最终目标：对财务报表信息的可靠性作出自己的判断

## 评估结果输出

### 风险等级
- **低风险**：未发现明显危险信号——可适度信赖报表
- **中风险**：发现危险信号——需进一步细致考察或获取其他信息后再作判断
- **高风险**：危险信号严重——高度警惕报表可靠性，谨慎使用分析结论
