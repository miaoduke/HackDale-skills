# 直线回归法计算示例

## 已知数据（维修成本）

n = 12
ΣXᵢ = 1,260（千小时）
ΣYᵢ = 1,009（千元）
ΣXᵢ² = 137,762
ΣXᵢYᵢ = 107,751

## 计算回归系数

### 计算固定成本（a）
```
a = [137,762 × 1,009 − 1,260 × 107,751] / [12 × 137,762 − 1,260²]
a = 49.37（千元）
```

### 计算单位变动成本（b）
```
b = [12 × 107,751 − 1,260 × 1,009] / [12 × 137,762 − 1,260²]
b = 0.3306（千元/千小时）
```

## 建立成本方程式
```
Y（全月）= 49.37 + 0.3306X
```

## 模型验证

用全年总产量验证：
```
Y（全年）= 49.37 × 12 + 0.3306 × 1,260 = 1,008.996（千元）
```

与实际ΣYᵢ = 1,009对比，差异仅为四舍五入所致，验证通过。

R² = 0.84
