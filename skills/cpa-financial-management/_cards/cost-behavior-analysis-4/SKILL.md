# 成本性态分析

## 混合成本识别

### 识别标准
1. 成本总额随业务量变动而变动
2. 变动幅度与业务量变动不成正比例关系
3. 不属于纯粹的固定成本或变动成本

### 混合成本分类

混合成本一般可分为四种主要类别：
1. **半变动成本**（Semi-variable Cost）
2. **阶梯式成本**（Step Cost）
3. **延期变动成本**
4. **曲线成本**

## 混合成本分解原理

### 核心目的
为构建线性总成本模型 y = a + bx，其中：
- y = 总成本
- a = 固定成本（一定期间发生额稳定）
- b = 单位变动成本（随业务量变化的比率）
- x = 业务量（产量或业务量）

### 数学描述选择

#### 精确描述选择
- 对混合成本的实际性态进行真实的数学描述
- 结果：方程式种类繁多，可能相当复杂
- 缺点：建立和使用花费大量时间和精力

#### 简化描述选择（推荐）
- 将所有混合成本近似看成半变动成本，用 y = a + bx 表达
- 优点：数学描述问题大大简化
- 代价：所得结果与实际成本性态有一定差别
- 弥补措施：用"限定相关范围"来限制差别

### 分解方法
1. 账户分析法
2. 工业工程法
3. 直线回归法
4. 高低点法

## 直线回归法成本估计

### 建立回归方程模型
```
Y = a + bX
```
- Y：因变量（总成本）
- X：自变量（业务量）
- a：回归线截距（代表固定成本）
- b：回归线斜率（代表单位变动成本）

### 计算所需汇总统计量
- n：数据点个数（样本量）
- ΣXᵢ：业务量合计
- ΣYᵢ：成本合计
- ΣXᵢ²：业务量平方和
- ΣXᵢYᵢ：业务量与成本乘积和

### 计算回归系数

#### 固定成本（a）
```
a = [ΣXᵢ² × ΣYᵢ − ΣXᵢ × ΣXᵢYᵢ] / [n × ΣXᵢ² − (ΣXᵢ)²]
```

#### 单位变动成本（b）
```
b = [n × ΣXᵢYᵢ − ΣXᵢ × ΣYᵢ] / [n × ΣXᵢ² − (ΣXᵢ)²]
```

### 模型验证

#### 全年总产量验证法
```
Y（全年）= a × n + b × ΣXᵢ
```
与实际ΣYᵢ对比，差异应仅为四舍五入所致

#### 决定系数（R²）解读
- R²越接近1，回归线拟合程度越高
- R² = 0.84 表示业务量变化可解释84%的成本变化，模型解释力较强

### 统计软件辅助分析

可用工具：SPSS、R、EXCEL等

EXCEL输出结果解读：
- 常量系数 = a（固定成本）
- X变量系数 = b（单位变动成本）
- P值：0.000表示回归有意义，显著性高
- R²：决定系数，表示自变量解释因变量变化的程度

## 使用流程

1. **识别混合成本**：判断成本是否随业务量变动但不成正比例
2. **收集历史数据**：获取一系列历史成本资料和业务量数据
3. **选择分解方法**：根据数据质量和精度要求选择合适的方法
4. **执行分解计算**：应用直线回归法或其他方法计算a和b
5. **建立成本模型**：得到 y = a + bx 方程
6. **验证模型**：使用验证方法检验模型拟合度
7. **应用模型**：在相关范围内预测任何产量x下的总成本y
