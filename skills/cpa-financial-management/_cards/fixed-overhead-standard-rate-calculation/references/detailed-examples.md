# 固定制造费用标准分配率计算示例

## 多车间计算实例

### 第一车间
**预算构成：**
- 折旧费：200元
- 管理人员工资：700元
- 间接人工：500元
- 保险费：300元
- 其他固定费用：300元
- **预算总额：2,000元**

**工时数据：**
- 直接人工标准总工时：4,000工时

**计算：**
```
固定制造费用标准分配率 = 2,000元 ÷ 4,000工时 = 0.5元/工时
```

### 第二车间
**预算构成：**
- 折旧费：2,350元
- 管理人员工资：1,800元
- 间接人工：1,200元
- 保险费：400元
- 其他固定费用：250元
- **预算总额：6,000元**

**工时数据：**
- 直接人工标准总工时：10,000工时

**计算：**
```
固定制造费用标准分配率 = 6,000元 ÷ 10,000工时 = 0.6元/工时
```

## 在标准成本卡中的应用

计算出标准分配率后，用于计算单位产品标准成本中的固定制造费用部分：

```
单位产品固定制造费用标准成本 = 单位产品标准工时 × 标准分配率
```

**第一车间示例：**
- 单位产品标准工时：4小时/件
- 标准分配率：0.5元/工时
- 单位产品固定制造费用：4 × 0.5 = 2元/件
