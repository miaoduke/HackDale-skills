# 固定制造费用标准分配率计算

计算固定制造费用的标准分配率（即价格标准），确定每标准工时应分摊的固定制造费用金额。

## 何时使用

- 建立或更新标准成本制度时
- 制定固定制造费用价格标准
- 编制标准成本卡需要确定制造费用分配率
- 进行固定制造费用差异分析前确定基准
- 基于预算产能重新评估费用分摊标准

## 前提条件

- [ ] 已完成固定制造费用预算编制（包含折旧、管理人员工资、间接人工、保险费等）
- [ ] 已确定直接人工标准总工时（预算产量 × 单位产品标准工时）
- [ ] 明确预算期内的正常产能水平

## 计算步骤

### 1. 确认分子：固定制造费用预算总额
提取预算期内固定制造费用预算总额：
- 基于**预算总额**，而非实际发生额
- 包含：折旧费、管理人员工资、间接人工、保险费、其他固定费用

### 2. 确认分母：直接人工标准总工时
计算标准总工时（生产量标准）：
```
直接人工标准总工时 = 预算产量 × 单位产品直接人工标准工时
```

### 3. 计算标准分配率
```
固定制造费用标准分配率 = 固定制造费用预算总额 ÷ 直接人工标准总工时
```

**单位**：元/工时（或元/机器工时，取决于用量标准类型）

## 关键约束

⚠️ **重要区分**：
- **分子必须使用预算总额**：基于预算编制数据，而非实际发生金额
- **分母必须使用标准总工时**：使用预算产量下的标准工时总数，而非实际工时或单纯预算产量

## 快速示例

某车间数据：
- 固定制造费用预算总额：2,000元
- 预算产量：1,000件
- 单位产品标准工时：4小时/件
- 直接人工标准总工时：4,000工时

计算：
```
标准分配率 = 2,000元 ÷ 4,000工时 = 0.5元/工时
```
