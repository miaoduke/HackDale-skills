# 变动制造费用标准成本计算方法

## 适用场景
- 需要计算单位产品变动制造费用标准成本
- 采用变动成本法
- 各生产车间需要制定制造费用标准

## 基本概念与编制原则

### 按部门编制
制造费用标准成本按部门分别编制，然后将同一产品涉及的各部门单位制造费用标准加以汇总，得出整个产品制造费用标准成本。

### 成本分类
按照变动成本法原理，制造费用分为变动制造费用和固定制造费用，因此各部门制造费用标准成本分为两部分。

## 用量标准的确定

### 标准选择
变动制造费用的用量标准通常采用单位产品直接人工工时标准。

### 替代标准
也可采用机器工时或其他用量标准。

### 关键要求
作为用量标准的计量单位，应尽可能与变动制造费用保持较好的线性相关关系。

## 价格标准的确定

### 标准定义
变动制造费用的价格标准是单位工时变动制造费用的标准分配率。

### 计算公式
```
变动制造费用标准分配率 = 变动制造费用预算总数 / 直接人工标准总工时
```

### 预算内容
变动制造费用预算包括：运输、电力、消耗材料、间接人工、燃料、其他等项目。

## 单位产品变动制造费用标准成本计算

### 核心公式
```
单位产品变动制造费用标准成本 = 单位产品直接人工标准工时 × 变动制造费用标准分配率
```

### 计算步骤

**步骤1：计算各车间变动制造费用标准分配率**
```
该车间的变动制造费用标准分配率 = 该车间的变动制造费用预算合计 / 该车间的生产量标准（人工工时）
```

**步骤2：计算各车间单位产品变动制造费用标准成本**
```
该车间的单位产品变动制造费用标准成本 = 该车间的直接人工用量标准（人工工时） × 该车间的变动制造费用标准分配率
```

**步骤3：汇总各车间结果**
得出单位产品变动制造费用标准成本合计。

## 变量说明
- 变动制造费用预算总数：各车间变动制造费用各项目预算之和
- 直接人工标准总工时：该车间的生产量标准，以人工工时计量
- 变动制造费用标准分配率：单位工时变动制造费用的标准价格
- 单位产品直接人工标准工时：生产单位产品所需的标准人工工时
- 车间变动制造费用标准成本：某车间生产单位产品的变动制造费用标准成本

## 决策输出
单位产品变动制造费用标准成本（元/产品），由各车间变动制造费用标准成本汇总得出。
