# 年金终值系数表查询

## 适用场景
- 计算一系列等额收付款项在期末的终值
- 利率在12%-36%之间
- 期数在1-60期之间
- 普通年金（期末等额收付款项）

## 执行步骤
1. **确定计息期数(n)**：在表格第一列"期数"中找到对应的行（1至60期）
2. **确定年利率(i)**：在表格第一行"利率"中找到对应的列
3. **执行交叉查询**：定位到第n行和第i列的交叉单元格
4. **读取系数值**：该单元格的数值即为(F/A, i, n)年金终值系数
5. **应用公式计算**：FV = A × (F/A, i, n)

## 支持的利率点
12%、14%、15%、16%、18%、20%、24%、28%、32%、36%

## 特殊值处理
- 表格中标记为`*`的单元格表示数值大于99,999
- 期数为1时，所有利率对应的系数均为1.0000

## 核心公式
```
FV = A × (F/A, i, n)
```

其中：
- FV：年金终值
- A：每期等额收付款项
- (F/A, i, n)：年金终值系数
- i：年利率
- n：计息期数

## 约束条件
- 不适用于期初年金(预付年金)直接查表（需调整）
- 利率或期数超出表格范围无法直接查询

## 数据示例验证
- 期数=2, 利率=12% → 系数 = 2.1200
- 期数=10, 利率=20% → 系数 = 25.959
- 期数=30, 利率=36% → 系数 = 28172.3
- 期数=60, 利率=32% → 系数 = * (表示 > 99,999)
