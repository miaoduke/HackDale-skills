# 非公开增发方案设计详解

## 完整案例分析：H公司2023年非公开增发

### 公司背景与困境

H公司2020-2022年关键财务指标：

| 年度 | 加权平均ROE | 扣非后ROE | 现金分红 |
|-----|-----------|-----------|---------|
| 2020 | 1.82% | 1.58% | 无 |
| 2021 | 5.04% | 3.93% | 无 |
| 2022 | 11.97% | 6.64% | 无 |

**关键不满足点分析**：

1. 三年平均ROE = (1.82% + 5.04% + 11.97%) ÷ 3 = **6.28%**
   - 表面接近6%门槛，但波动剧烈且前两年极低
   - 扣非后ROE更低，盈利质量存疑

2. **致命缺陷**：连续三年现金分红为"无"
   - 完全不符合公开增发"最近三年现金累计分配利润≥年均可分配利润30%"的要求
   - 此为硬性门槛，无协商空间

### 方案设计：双重目标实现

#### 交易结构

```
非公开增发总募集资金：XX亿元
    │
    ├── 资产认购部分（约60%）
    │       ├── 向原控股股东：收购核心经营性资产
    │       └── 向3家非关联公司：收购产业链相关资产
    │
    └── 现金认购部分（约40%）
            └── 向5家机构投资者：募集资金用于项目建设
```

#### 投资者安排与锁定期

| 认购方 | 认购方式 | 金额/资产 | 锁定期 | 战略意图 |
|-------|---------|----------|--------|---------|
| 原控股股东 | 资产认购 | 核心资产 | 未披露（通常较长） | 资产注入+控制权巩固 |
| 非关联公司A/B/C | 资产认购 | 产业链资产 | 18个月 | 产业整合 |
| 基金公司D/E/F/G/H | 现金认购 | 合计XX亿 | 6个月 | 财务投资、流动性支持 |

#### 控制权变化测算

| 指标 | 发行前 | 发行后 | 变化 |
|-----|--------|--------|------|
| 控股股东持股比例 | 19.86% | 26.33% | **+6.47pct** |
| 机构投资者合计 | - | 约15% | 新引入 |
| 其他股东稀释 | 80.14% | 约58% | 被动稀释 |

**核心效果**：原控股股东通过参与资产认购，在融资同时实现控制权提升，化解了股权分散风险。

### 非公开增发的监管要点

#### 发行条件（与公开增发对比）

| 条件 | 公开增发 | 非公开增发 |
|-----|---------|-----------|
| 盈利要求 | 三年平均ROE≥6% | 无硬性要求 |
| 分红要求 | 三年现金分红≥年均可分配利润30% | 无要求 |
| 发行对象 | 社会公众 | 不超过35名特定对象 |
| 定价方式 | 市场化询价 | 不低于定价基准日前20日均价80% |
| 锁定期 | 无 | 6个月/18个月/36个月 |

#### 定价基准日选择

可选方案：
- **董事会决议公告日**：提前锁定价格，适用于股价低迷期
- **股东大会决议公告日**：兼顾确定性与时效性
- **发行期首日**：贴近市场价，投资者接受度高

**H公司选择**：董事会决议公告日，以较低价格吸引控股股东和战略投资者参与。

### 方案设计的决策树扩展

```
确定采用非公开增发后：
    │
    ├── 是否需要注入资产？
    │       ├── 是 → 设计资产认购部分
    │       │           ├── 资产权属清晰？
    │       │           ├── 评估作价公允？
    │       │           └── 是否构成重大资产重组？
    │       └── 否 → 纯现金募集
    │
    ├── 是否需要巩固控制权？
    │       ├── 是 → 安排控股股东/关联方认购
    │       └── 否 → 全部向外部投资者发行
    │
    ├── 是否需要产业协同？
    │       ├── 是 → 引入战略投资者（18个月锁定期）
    │       └── 否 → 引入财务投资者（6个月锁定期）
    │
    └── 资金用途规划
                ├── 补充流动资金（≤30%）
                ├── 偿还债务
                ├── 项目建设
                └── 收购资产
```

### 关键计算公式

#### 发行价格下限

```
发行价格 ≥ max(定价基准日前20个交易日均价 × 80%, 每股净资产)
```

#### 发行数量上限

```
发行数量 ≤ 发行前总股本 × 30%  （监管通常以此为准入门槛）
```

#### 控股股东持股比例变化

```
发行后持股比例 = (原持股数 + 认购股数) ÷ (原总股本 + 新增股本)
```

### 风险提示与缓释

| 风险类型 | 具体表现 | 缓释措施 |
|---------|---------|---------|
| 定价风险 | 股价下跌导致发行失败 | 设置价格调整机制；选择股价相对低位启动 |
| 投资者认购不足 | 现金部分募集失败 | 提前与投资者签署认购意向；控股股东兜底 |
| 资产估值争议 | 注入资产作价不公允 | 聘请两家评估机构；采用多种评估方法 |
| 监管审核风险 | 方案被否或反馈周期长 | 充分预沟通；聘请经验丰富的保荐机构 |
| 股价摊薄压力 | 发行后EPS下降 | 合理控制发行规模；选择业绩释放时点 |

### 实务操作时间表

| 阶段 | 主要工作 | 耗时 |
|-----|---------|------|
| 内部决策 | 董事会/股东大会决议 | 1-2个月 |
| 监管预沟通 | 与交易所/证监会沟通 | 2-4周 |
| 投资者锁定 | 路演、签署认购协议 | 1-2个月 |
| 申报审核 | 保荐机构申报、反馈回复 | 3-6个月 |
| 发行缴款 | 定价、认购、验资 | 2-4周 |
| 股份登记 | 登记公司办理、上市流通 | 2-4周 |

**总周期**：通常6-12个月，复杂项目可能更长。
