# 配股除权参考价计算

## 适用场景
- 股票已完成配股股权登记
- 需要对股票进行除权处理
- 需要计算除权日股价涨跌幅度的基准价格

## 前置条件
- 已知配股前每股价格
- 已知配股价格
- 已知配股数量或配股比例

## 计算步骤

### 1. 选择计算公式
根据已知数据，选择以下两种等价公式之一进行计算：

**公式一：基于绝对数量**
```
配股除权参考价 = (配股前股票市值 + 配股价格 × 配股数量) / (配股前股数 + 配股数量)
```

**公式二：基于每股价格和变动比例**
```
配股除权参考价 = (配股前每股价格 + 配股价格 × 股份变动比例) / (1 + 股份变动比例)
```
其中：股份变动比例 = 配股数量 / 配股前股数

### 2. 执行计算
代入已知数值进行计算。

### 3. 结果解读
- **填权**：若除权后实际市价高于除权参考价，参与配股的股东财富增加。
- **贴权**：若除权后实际市价低于除权参考价，参与配股的股东财富减少。

## 注意事项
- 除权参考价仅作为计算除权日股价涨跌幅度的基准，并非实际交易价格。
- 实际交易价格可能偏离该参考价。
- 若所有股东都参与配股，股份变动比例等于拟配售比例。
