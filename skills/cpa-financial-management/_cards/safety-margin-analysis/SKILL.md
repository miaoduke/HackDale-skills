# 安全边际分析

## 核心概念

安全边际是一个安全区间，表明销售额（量）下降多少企业仍不至亏损。安全区间越大，风险越小。安全边际和安全边际额的数值越大，企业发生亏损的可能性就越小，企业也就越安全。

## 计算公式

### 安全边际额
```
安全边际额 = 实际或预计销售额 - 盈亏临界点销售额
```

### 安全边际量
```
安全边际量 = 实际或预计销售量 - 盈亏临界点销售量
```

### 替代计算方式

用于考察当年生产经营安全情况：
```
可用本年实际订货额（量）代替实际或预计销售额（量）来计算安全边际
```

## 经济含义

1. **安全区间**：表明销售额（量）下降多少企业仍不至亏损
2. **风险指示**：安全区间越大，风险越小
3. **安全程度**：数值越大表示企业承受销售下降的能力越强，经营越安全

## 计算示例

### 已知数据
- 实际销售额：5,000元
- 盈亏临界点销售额：4,000元
- 单价：2元

### 计算过程

**安全边际额**：
```
安全边际额 = 5,000 - 4,000 = 1,000元
```

**安全边际量**：
```
实际销售量 = 5,000 ÷ 2 = 2,500件
盈亏临界点销售量 = 4,000 ÷ 2 = 2,000件
安全边际量 = 2,500 - 2,000 = 500件
```

## 适用对象

- 单一产品企业
- 多产品企业
- 需要进行经营安全评估的组织

## 前提条件

- 实际或预计销售额（量）数据
- 盈亏临界点销售额（量）数据
- 或实际订货额（量）数据

## 使用流程

1. **获取基础数据**：收集实际或预计销售额（量）、盈亏临界点销售额（量）
2. **计算安全边际额**：应用安全边际额公式
3. **计算安全边际量**：应用安全边际量公式（需先计算销售量）
4. **评估经营安全**：根据安全边际数值评估企业承受销售下降的能力
5. **制定应对策略**：根据安全边际大小制定相应的经营策略
