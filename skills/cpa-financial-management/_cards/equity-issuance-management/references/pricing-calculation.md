# 股票发行价格计算详解

## 前20个交易日均价计算

```
前20个交易日均价 = 前20个交易日股票交易总额 / 前20个交易日股票交易总量
```

或：
```
前20个交易日均价 = Σ(每日收盘价 × 每日成交量) / 总成交量
```

## 增发发行底价计算

### 公开增发
```
发行底价 = max(前20个交易日均价, 前1个交易日均价)
```

### 向特定对象发行
```
发行底价 = 定价基准日前20个交易日均价 × 80%
```

## 关键时间节点
- **公告招股意向书日**：公开增发的计算基准日
- **发行期首日**：向特定对象发行的定价基准日
- **交易日**：不含停牌日
