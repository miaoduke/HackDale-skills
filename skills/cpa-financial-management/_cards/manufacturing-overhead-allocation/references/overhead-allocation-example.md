# 制造费用分配示例

## 实际分配率分配法示例

已知数据：
- 本月发生制造费用：36,080元
- 甲产品实用人工工时：56,000小时
- 乙产品实用人工工时：32,000小时

计算步骤：

1. 计算总工时
```
总工时 = 56,000 + 32,000 = 88,000小时
```

2. 计算分配率
```
分配率 = 36,080 ÷ 88,000 = 0.41元/小时
```

3. 计算各产品制造费用
```
甲产品制造费用 = 56,000 × 0.41 = 22,960元
乙产品制造费用 = 32,000 × 0.41 = 13,120元
```

4. 验证平衡
```
22,960 + 13,120 = 36,080元（与待分配总额一致）
```

5. 编制会计分录
```
借：生产成本——基本生产成本——甲产品 22,960
    生产成本——基本生产成本——乙产品 13,120
贷：制造费用 36,080
```
