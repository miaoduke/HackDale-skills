# 制造费用分配

## 费用归集

### 归集范围
包括工资和福利费、折旧费、修理费、办公费、水电费、机物料消耗、劳动保护费、租赁费、保险费、排污费等。

### 归集方法
- 通过"制造费用"科目进行归集
- 按生产车间开设明细账，账内按照费用项目开设专栏
- 费用发生时根据支出凭证借记"制造费用"
- 材料、工资、折旧等费用可在月末根据汇总编制的各种费用分配表记入

## 实际分配率分配法

### 计算公式
```
月实际分配率 = 当月实际制造费用总额 ÷ 各种产品生产实用（或定额）工时之和
某产品应负担的制造费用 = 该种产品实用（或定额）工时数 × 月实际分配率
```

### 分配步骤

1. **计算月实际分配率**
   - 需要当月实际发生的制造费用总额
   - 需要各种产品生产实用人工工时或机器加工工时（或定额工时）数据

2. **计算各产品应负担的制造费用**
   - 根据各产品实用（或定额）工时数乘以分配率

3. **编制会计分录**
   ```
   借：生产成本——基本生产成本（按各产品明细）
   贷：制造费用
   ```

### 分配方法选择

| 条件 | 分配方法 |
|------|---------|
| 具备实用人工工时统计资料 | 按实用人工工时的比例分配 |
| 缺乏实用人工工时，有准确的人工工时定额 | 按产品定额人工工时的比例分配 |
| 机械化程度较高的车间 | 按机器工时比例分配 |
| 其他情况 | 按直接人工费用等比例分配 |

### 管理控制逻辑

- 制造费用的大部分属于产品生产的间接费用
- 不能按照产品制定定额，只能按照车间、部门和费用项目编制制造费用计划加以控制
- 通过制造费用的归集和分配，反映和监督各项制造费用计划的执行情况

## 责任归属五步骤方法

### 步骤1：直接计入责任中心
- **适用对象**：可以直接判别责任归属的费用项目
- **操作方法**：直接列入应负责的成本中心，不需要采用其他标准进行分配
- **典型示例**：机物料消耗、低值易耗品的领用

### 步骤2：按责任基础分配
- **适用对象**：不能直接归属于个别责任中心但数额受成本中心控制的费用
- **核心标准**：能找到合理依据来分配，即成本中心能自己控制使用量
- **典型示例**：动力费（按实际使用量分配）、维修费（按实际使用维修服务量分配）
- **关键控制点**：分配时要使用固定的内部结算价格，防止供应部门的责任向使用部门转嫁

### 步骤3：按受益基础分配
- **适用对象**：不是专门属于某个责任中心且不宜用责任基础分配，但与各中心的受益多少有关的费用
- **核心标准**：与受益程度相关，而非可控程度
- **典型示例**：按装机功率分配电费
- **注意**：此方法不完全反映可控性，仅作为次优选择

### 步骤4：归入某一个特定的责任中心
- **适用对象**：既不能用责任基础分配，也不能用受益基础分配的费用
- **操作方法**：考虑有无可能将其归属于一个特定的责任中心，不向各班组分配
- **典型示例**：车间运输费用（建立专门的运输成本中心）、试验检验费用（建立专门的质检成本中心）

### 步骤5：不能归属于任何责任中心的固定成本，不进行分摊
- **适用对象**：不能归属于任何责任中心的固定成本
- **典型示例**：车间厂房的折旧（是以前决策的结果，短期内无法改变）
- **处理方式**：暂时不加控制，作为不可控费用

### 执行要点

必须严格按1→2→3→4→5的顺序判断，前一步适用则不再考虑后一步。每一步的判断核心是"能否找到合理的责任归属依据"。
