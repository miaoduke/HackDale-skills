# 沉没成本识别与排除

## 何时使用

- 固定资产是否继续使用或处置的决策
- 亏损项目是否终止的评估
- 旧设备更新或继续使用的分析
- 投资项目的后评价与复盘
- 任何需要区分历史成本与相关成本的决策场景

## 核心原则

沉没成本是**已经发生且当前及未来决策均无法改变**的成本，必须在决策分析中完全排除。

## 判定流程

### 步骤1：确认成本的历史性
验证该成本是否为过去已经发生的支出，而非未来可能发生的成本。

### 步骤2：验证不可改变性
确认该成本数额**无法通过任何当前或未来的决策改变**。

### 步骤3：计算沉没成本金额

对于固定资产：
```
沉没成本 = 资产原价 - 累计折旧 = 账面净值
```

### 步骤4：决策排除
在决策分析中**完全剔除**该沉没成本，仅以未来相关现金流作为决策依据。

## 快速判定清单

| 检查项 | 是 = 沉没成本 | 否 = 相关成本 |
|--------|-------------|-------------|
| 成本是否已实际支付/发生？ | ✓ | 未来成本 |
| 当前决策能否改变其数额？ | ✓ | 可避免成本 |
| 未来决策能否回收或补偿？ | ✓ | 可收回成本 |

## 常见应用场景

### 场景A：设备更新决策
- **沉没成本**：旧设备账面净值
- **相关成本**：旧设备变现价值、新设备购置成本、运营成本差异

### 场景B：项目终止评估
- **沉没成本**：已投入且无法收回的研发费用、已计提折旧
- **相关成本**：终止所需额外支出、继续运营的追加投入

### 场景C：存货处置决策
- **沉没成本**：存货历史采购成本
- **相关成本**：处置收入、仓储成本、机会成本

## 关键警示

> **沉没成本谬误**：因舍不得已投入成本而继续错误决策。
> 
> 正确做法：无论过去投入多少，仅比较各方案的未来净收益。

## 输出模板

```
沉没成本识别结果：
- 成本性质：[历史成本/已计提折旧/已发生费用]
- 沉没成本金额：[金额]元
- 判定依据：该成本已发生且当前决策无法改变
- 决策处理：予以排除，不作为决策依据
```
