# 定价计算示例

## 案例：H公司非公开发行

**背景：** H公司计划非公开发行股票募集资金

**数据：**
- 定价基准日前20个交易日股票交易总额：8.5亿元
- 定价基准日前20个交易日股票交易总量：1.19亿股

**计算过程：**

```
20日均价 = 850,000,000 ÷ 119,000,000 = 7.1429元/股

发行底价 = 7.1429 × 80% = 5.7143元/股

实际发行价格：7.14元/股（高于底价，等于均价的100%）
```

**结果分析：** 实际发行价7.14元/股符合"不低于80%"的要求，定价合理。

## 对比：加权平均 vs 算术平均

假设某股票近5日交易数据（简化示例）：

| 日期 | 收盘价 | 成交量（万股） | 成交额（万元） |
|-----|--------|------------|-----------|
| T-4 | 10元 | 100 | 1,000 |
| T-3 | 12元 | 50 | 600 |
| T-2 | 11元 | 200 | 2,200 |
| T-1 | 13元 | 80 | 1,040 |
| T日 | 12元 | 150 | 1,800 |

**错误算法（算术平均）：**
```
(10+12+11+13+12) ÷ 5 = 11.6元
```

**正确算法（加权平均）：**
```
(1000+600+2200+1040+1800) ÷ (100+50+200+80+150) = 6640 ÷ 580 = 11.45元
```

**差异：** 在高成交量低价日（T-4）或低成交量高价日（T-3）时，两种方法结果差异显著。监管要求必须使用加权平均。
