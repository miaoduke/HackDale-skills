# 成本管理基础详细参考

## 成本分类详解

### 按经济用途分类
- 制造成本：直接材料、直接人工、制造费用
- 非制造成本：销售费用、管理费用、财务费用

### 按成本性态分类

**固定成本**：
- 定义：成本总额不随业务量变动而变动
- 特点：单位固定成本随业务量增加而降低
- 示例：折旧费、管理人员工资

**变动成本**：
- 定义：成本总额随业务量变动而成正比例变动
- 特点：单位变动成本保持不变
- 示例：直接材料、计件工资

**混合成本**：
- 定义：成本总额随业务量变动但不成正比例
- 分解方法：高低点法、散布图法、回归分析法

### 按决策相关性分类

**相关成本**：
- 与决策有关，影响决策选择的成本
- 包括：差量成本、边际成本、机会成本、重置成本

**不相关成本**：
- 与决策无关，不影响决策选择的成本
- 包括：沉没成本、历史成本

## 存货管理方法

### ABC分类管理
- A类：品种少、价值高，重点管理
- B类：品种适中、价值适中，一般管理
- C类：品种多、价值低，简化管理

### 经济订货批量（EOQ）
```
Q* = √(2KD / Kc)
```
- Q*：经济订货批量
- K：每次订货成本
- D：年需要量
- Kc：单位存储成本

### 适时制（JIT）
- 零库存管理
- 按需生产
- 供应链协同

## 定价方法

### 成本加成定价
```
价格 = 单位成本 × (1 + 成本加成率)
```

### 变动成本加成定价
```
价格 = 单位变动成本 × (1 + 变动成本加成率)
```

### 目标成本定价
```
目标成本 = 目标价格 - 目标利润
```

### 市场导向定价
- 竞争导向定价
- 需求导向定价
- 价值导向定价
