# WACC计算与最优资本结构

## 何时使用

- 使用实体现金流量计算项目净现值
- 项目采用债务融资，需要确定整体资本成本
- 比较不同资本结构下的企业价值
- 确定使企业价值最大化/资本成本最小化的最优债务水平

## 第一部分：WACC计算公式

### 核心公式

```
WACC = [税前债务资本成本 × (1 - 税率) × 债务权重] + [股权资本成本 × 权益权重]

或：WACC = (税后债务成本 × Wd) + (权益成本 × We)
```

### 分步计算

**步骤1：计算税后债务成本**
```
税后债务成本 = 税前债务资本成本 × (1 - 所得税税率)
```
*原理：债务利息具有税盾效应（税前扣除），实际成本低于名义利率*

**步骤2：确定资本结构权重（基于目标资本结构）**
```
债务权重(Wd) = 净负债 / (净负债 + 股东权益) = (D/E) / [1 + (D/E)]
权益权重(We) = 股东权益 / (净负债 + 股东权益) = 1 / [1 + (D/E)]
```
*关键：权重必须按市场价值计算，使用项目的目标资本结构*

**步骤3：计算加权成本并求和**
```
WACC = (税后债务成本 × Wd) + (股权资本成本 × We)
```

## 第二部分：与权益成本的关键区别

| 对比项 | WACC | 权益成本Re |
|-------|------|-----------|
| 反映对象 | 全部资本提供者（债权人+股东） | 仅股东 |
| 适用现金流量 | **实体现金流量（FCFF）** | 股权现金流量（FCFE） |
| 风险覆盖 | 企业整体风险 | 仅股权风险 |
| 税盾效应 | 已体现在税后债务成本中 | 不涉及 |

**核心原则**：现金流量类型与折现率必须匹配

## 第三部分：最优资本结构判定

### 双重验证标准

| 标准 | 计算方法 | 目标 |
|-----|---------|------|
| **首要标准** | 企业价值V = S + B | **最大化** |
| **辅助验证** | 加权平均资本成本WACC | **最小化** |

**逻辑关系**：当EBIT恒定时，V = EBIT(1-T)/WACC，因此WACC最小则V最大，两者等价。

### 决策流程

1. 设定不同债务水平（B）方案
2. 对每个方案：
   - 计算股权价值S（股利折现或FCFE折现）
   - 计算企业价值V = S + B
   - 计算WACC
3. 比较各方案的V和WACC
4. 选择**V最大且WACC最小**的债务水平作为最优资本结构

### 权衡机制

| 阶段 | 增加债务的影响 | 结果 |
|-----|-----------|------|
| 初期 | 税盾效应降低WACC，债务成本较低 | V上升 |
| 过度 | 财务风险急剧上升，rs和rd大幅上升 | WACC上升，V下降 |
| 最优点 | 边际税盾收益 = 边际财务风险成本 | V_max，WACC_min |

## 完整示例

**已知条件**：
- 税前债务成本(Rd) = 6%
- 所得税税率(T) = 30%
- 股权资本成本(Re) = 14.45%
- 目标资本结构：净负债/股东权益 = 2/3

**计算过程**：
```
总资本份数 = 2（负债）+ 3（权益）= 5份
债务权重(Wd) = 2/5 = 40%
权益权重(We) = 3/5 = 60%

税后债务成本 = 6% × (1-30%) = 4.2%
债务贡献 = 4.2% × 40% = 1.68%
权益贡献 = 14.45% × 60% = 8.67%

WACC = 1.68% + 8.67% = 10.35%
```

**结果解释**：项目整体资本成本10.35%，低于权益成本14.45%，体现债务融资的低成本优势。

## 注意事项

- 必须确保现金流量类型与折现率匹配
- 资本结构权重应使用目标结构（项目维持的D/E比）
- 若项目寿命期内资本结构变化，需分阶段计算WACC
- 不存在优先股时，Wd + We = 1
