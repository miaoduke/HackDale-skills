# 利润中心业绩评价示例

## 基础数据

| 项目 | 金额（万元） |
|------|-------------|
| 部门销售收入 | 1,000 |
| 部门变动成本总额 | 600 |
| 部门可控固定成本 | 200 |
| 部门不可控固定成本 | 100 |
| 公司总部管理费用（不分配） | 50 |

## 指标计算

### 1. 部门边际贡献
```
部门边际贡献 = 1,000 - 600 = 400万元
```

### 2. 部门可控边际贡献
```
部门可控边际贡献 = 400 - 200 = 200万元
```

### 3. 部门税前经营利润
```
部门税前经营利润 = 200 - 100 = 100万元
```

## 评价应用

### 评价部门经理业绩
**使用指标：** 部门可控边际贡献 = 200万元

**评价理由：** 该指标反映了部门经理在其权限和控制范围内有效使用资源的能力

### 评价部门对公司贡献
**使用指标：** 部门税前经营利润 = 100万元

**评价理由：** 该指标反映了部门扣除所有成本后对公司整体利润的贡献

### 决定部门取舍
**使用指标：** 部门税前经营利润 = 100万元

**决策：** 若部门税前经营利润持续为负，应考虑关闭该部门

## 可控与不可控成本区分示例

| 成本项目 | 可控性 | 判断依据 |
|----------|--------|----------|
| 部门人员工资 | 可控 | 部门经理有权决定招聘人数和工资水平 |
| 部门设备折旧 | 不可控 | 设备由公司总部统一购置，部门无处置权 |
| 部门办公租金 | 不可控 | 租赁合同由公司总部签订 |
| 部门差旅费 | 可控 | 部门经理可控制差旅安排 |
| 部门广告费 | 可控 | 部门经理可决定广告投放策略 |
