# 利润中心业绩评价

## 使用场景
- 需要对利润中心进行业绩考核时
- 需要计量利润中心利润时
- 评价部门经理业绩时
- 评价部门对公司整体贡献时
- 决定部门取舍时

## 计算三种利润指标

### 1. 部门边际贡献
```
部门边际贡献 = 部门销售收入 - 部门变动成本总额
```

### 2. 部门可控边际贡献
```
部门可控边际贡献 = 部门边际贡献 - 部门可控固定成本
```

### 3. 部门税前经营利润
```
部门税前经营利润 = 部门可控边际贡献 - 部门不可控固定成本
```

## 指标适用性分析与选择

### 部门边际贡献
**适用性：** 作为业绩评价依据不够全面

**原因：**
- 部门经理至少可以控制某些固定成本
- 在固定成本和变动成本划分上有选择余地
- 仅以此评价可能导致经理尽可能多支出固定成本以减少变动成本

### 部门可控边际贡献
**适用性：** 评价部门经理业绩的最佳选择

**原因：**
- 体现了可控原则
- 反映了部门经理在其权限和控制范围内有效使用资源的能力

**难点：** 可控固定成本和不可控固定成本的区分比较困难

**区分示例：**
- **折旧、保险费：** 若有资产处置权则为可控
- **工资：** 若有权决定人数则为可控；若既不能决定水平也不能决定人数则为不可控

### 部门税前经营利润
**适用性：** 适合评价该部门对公司利润的贡献，决定部门取舍；不适合评价部门经理

**原因：**
- 包含一部分过去最高管理层投资决策结果的固定成本
- 现在的部门经理已很难改变
- 超出了经理人员的控制范围

## 总部管理费用的处理原则

### 原则
不应将公司总部的管理费用分配给各部门进行业绩评价

### 原因
1. 部门经理无法控制该成本
2. 分配方法常常是任意的（如销售百分比、资产百分比）
3. 部门活动与分配费用无因果关系
4. 其他部门基数变化会影响本部门分配数额

### 替代方案
通过给每个部门建立期望能达到的可控边际贡献标准，提醒部门经理注意抵补总部费用，使其集中精力增加收入并降低可控成本

## 关键变量

- **部门销售收入：** 部门实现的销售收入总额
- **部门变动成本总额：** 随业务量变动的销货成本及变动费用之和
- **部门可控固定成本：** 部门经理在其权限范围内可以控制的固定成本
- **部门不可控固定成本：** 部门经理无法控制的固定成本

## 约束条件
- 不适用于内部转移定价（需单独讨论）
- 需结合非货币指标（如生产率、市场地位等）作为补充

## 输出结果
- 三种利润指标的具体数值
- 评价目标对应的指标选择建议
- 业绩评价结论
