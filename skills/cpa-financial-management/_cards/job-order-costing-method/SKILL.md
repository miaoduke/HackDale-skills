# 产品成本计算的分批法

## 使用场景
- 单件小批生产的企业（如造船业、重型机器制造业）
- 新产品试制
- 在建工程
- 设备修理作业
- 按订单组织生产

## 前提条件
- 生产任务通知单（工作号）
- 确定的购货订单或产品批次

## 成本计算对象
以产品的"批别"（或订单）作为成本计算对象。

通常依据销货订单签发工作号来组织生产。

## 成本计算流程

### 第一步：确定成本计算对象
- 以产品批别（订单）为计算对象
- 每个批别设置成本计算单
- 按工作号归集费用

### 第二步：归集生产费用
按产品批别归集：
- 直接材料费
- 直接人工费
- 制造费用

### 第三步：确定成本计算期

**成本计算期特点**：
- 成本计算是不定期的
- 成本计算期与产品生产周期基本一致
- 与核算报告期（如月度）不一致

### 第四步：完工产品与在产品成本分配

#### 一般情况
由于成本计算期与生产周期一致，月末计算成本时，通常不存在完工产品与在产品之间分配费用的问题。

#### 特殊情况（跨月陆续完工）
若同一批次产品跨月陆续完工，需将归集的生产费用在完工产品和期末在产品之间进行分配。

**原材料费用分配**（假设生产开始时一次投入）：
```
分配率 = 本月该批材料费用总额 / (完工产品数量 + 在产品数量)
产成品应分配的材料费用 = 分配率 × 完工产品数量
```

**其他费用分配**（直接人工、制造费用）：
采用约当产量法进行分配。

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| Batch_ID | 字符串 | 产品批号或工作令号 |
| Total_Material_Cost | 货币 | 该批次归集的原材料费用总额 |
| Finished_Qty | 数值 | 本月实际完工的产品数量 |
| WIP_Qty | 数值 | 月末尚未完工的在产品数量 |
| Equivalent_Unit_Ratio | 百分比 | 在产品的约当产量比例 |

## 约束条件
- 不适用于大量大批连续式生产
- 若非跨月完工，通常不需要进行完工产品与在产品的费用分配

## 输出结果
```
输出该批次产品的完工产品总成本、单位成本及期末在产品成本
```

## 触发条件
```
IF (生产组织方式为单件小批) AND (按订单或批次组织生产) 
THEN 应用分批法计算成本
```
