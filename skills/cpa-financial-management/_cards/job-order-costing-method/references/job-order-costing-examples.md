# 分批法完整计算示例

## 示例背景
某企业采用分批法计算产品成本，本月生产批号501的产品。

### 基础数据
- 批号：501
- 批量：60件
- 本月投产：60件
- 本月完工：40件
- 月末在产：20件

## 成本归集

### 直接材料
- 材料在生产开始时一次投入
- 本月该批材料费用总额：18,000元

### 直接人工
- 本月该批直接人工费用：12,000元
- 在产品完工程度：50%

### 制造费用
- 本月该批制造费用：6,000元
- 在产品完工程度：50%

## 成本分配计算

### 1. 直接材料费用分配

由于材料在生产开始时一次投入，完工产品和在产品按数量比例分配。

```
分配率 = 18,000 / (40 + 20) = 300元/件
完工产品材料费 = 300 × 40 = 12,000元
在产品材料费 = 300 × 20 = 6,000元
```

### 2. 直接人工费用分配

采用约当产量法分配。

```
在产品约当产量 = 20 × 50% = 10件
总约当产量 = 40 + 10 = 50件
分配率 = 12,000 / 50 = 240元/件
完工产品人工费 = 240 × 40 = 9,600元
在产品人工费 = 240 × 10 = 2,400元
```

### 3. 制造费用分配

采用约当产量法分配。

```
在产品约当产量 = 20 × 50% = 10件
总约当产量 = 40 + 10 = 50件
分配率 = 6,000 / 50 = 120元/件
完工产品制造费用 = 120 × 40 = 4,800元
在产品制造费用 = 120 × 10 = 1,200元
```

## 成本汇总

### 完工产品成本
```
完工产品总成本 = 12,000 + 9,600 + 4,800 = 26,400元
完工产品单位成本 = 26,400 / 40 = 660元/件
```

### 在产品成本
```
在产品总成本 = 6,000 + 2,400 + 1,200 = 9,600元
```

## 成本计算单（批号501）

| 成本项目 | 生产费用 | 完工产品成本 | 在产品成本 |
|----------|----------|--------------|------------|
| 直接材料 | 18,000 | 12,000 | 6,000 |
| 直接人工 | 12,000 | 9,600 | 2,400 |
| 制造费用 | 6,000 | 4,800 | 1,200 |
| **合计** | **36,000** | **26,400** | **9,600** |

## 约当产量法详细说明

### 约当产量概念
约当产量是指在产品按其完工程度折算成相当于完工产品的数量。

### 计算公式
```
在产品约当产量 = 在产品数量 × 完工程度
总约当产量 = 完工产品数量 + 在产品约当产量
分配率 = 待分配费用 / 总约当产量
```

### 完工程度确定

**材料费用**：
- 一次投料：完工程度100%
- 分次投料：按实际投料比例确定

**加工费用**（人工、制造费用）：
- 按实际加工进度确定
- 通常按50%估算（简化处理）

### 特殊情况处理

**情况1：全部完工**
- 无需分配，全部费用为完工产品成本

**情况2：全部未完工**
- 无需分配，全部费用为在产品成本

**情况3：陆续完工**
- 采用约当产量法分配
- 区分材料和加工费用分别计算
