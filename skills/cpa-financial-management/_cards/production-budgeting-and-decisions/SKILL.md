# 生产预算与决策

## 生产预算编制

### 适用场景
- 需要制定下一年度或季度的生产计划
- 已完成销售预算
- 需要平衡生产与销售

### 执行步骤

**步骤1：基础数据获取**
直接引用销售预算中的"预计销售量"数据

**步骤2：计算存货数量**

**预计期末产成品存货**：
```
预计期末产成品存货 = 下季度销售量 × 预留比例
```
通常按下期销售量的一定百分比确定（如10%）

**预计期初产成品存货**：
通常等于上季度期末产成品存货

**步骤3：计算预计生产量**
```
预计生产量 = (预计销售量 + 预计期末产成品存货) - 预计期初产成品存货
```

### 编制目的与背景
由于生产和销售往往不能做到"同步同量"，设置产成品存货是为了：
- 保证在发生意外需求时按时供货
- 均衡生产以节省赶工的额外支出

### 实际编制的复杂性与优化

**物理限制**：
- 产量受生产能力限制
- 产成品存货数量受仓库容量限制

**成本权衡决策**：
- 销量很大时，采用赶工方法增产，需多付加班费
- 提前在淡季生产，会增加产成品存货，需多付资金利息

**最终目标**：权衡两者得失，选择成本最低的决策方案

## 约束资源最优利用决策

### 适用场景
- 企业实际拥有的资源能力 < 生产需要的资源能力
- 存在资源瓶颈
- 需要进行短期生产经营决策

### 执行步骤

**步骤1：识别约束资源**
确定企业中实际能力小于需求能力的瓶颈资源，如：
- 流动资金
- 原材料
- 劳动力
- 生产设备
- 技术或时间安排

**步骤2：确定决策目标**
核心目标是最大化企业**总的边际贡献**（固定成本对短期决策无影响）

**步骤3：计算核心指标**
计算每种产品的**单位约束资源边际贡献**：
```
单位约束资源边际贡献 = 单位产品边际贡献 ÷ 该单位产品耗用的约束资源量
```

**步骤4：比较与排序**
对比不同产品的单位约束资源边际贡献，数值越大的产品，利用紧缺资源的效益越高，应**优先安排生产**

**步骤5：执行生产安排（资源分配）**
1. 将约束资源优先分配给单位约束资源边际贡献最高的产品，直至满足该产品的最大市场销量或资源耗尽
2. 计算剩余的约束资源能力：
```
剩余能力 = 总能力 - 已使用能力
```
3. 将剩余资源分配给次优产品，依此类推，直至资源耗尽

**步骤6：验证与计算总效益**
计算该方案下的最大总边际贡献金额

### 计算示例

**设定条件**：
- 设备总能力：12,000分钟
- A产品：单位边际贡献15元，耗时2分钟/件
- B产品：单位边际贡献12元，耗时1分钟/件

**计算指标**：
- A产品单位约束资源边际贡献 = 15 ÷ 2 = 7.5 元/分钟
- B产品单位约束资源边际贡献 = 12 ÷ 1 = 12 元/分钟

**决策**：因 12 > 7.5，优先生产B产品

**安排**：
- 生产B产品7,000件（耗时7,000分钟）
- 剩余时间：12,000 - 7,000 = 5,000分钟
- 生产A产品：5,000 ÷ 2 = 2,500件

**结果**：
```
总边际贡献 = (7,000 × 12) + (2,500 × 15) = 84,000 + 37,500 = 121,500 元
```

## 关键控制点

1. **资源识别**：准确识别真正的约束资源
2. **指标计算**：正确计算单位约束资源边际贡献
3. **优先排序**：严格按照单位约束资源边际贡献从高到低排序
4. **能力平衡**：确保总需求不超过总能力
5. **市场限制**：考虑各产品的最大市场销量限制
