# 成本分配方法

## 工资费用分配

### 适用场景
- 月末进行工资费用分配
- 已获取工资结算单和生产工时记录

### 执行步骤

**步骤1：数据收集**
- 获取"工资结算单"
- 获取"生产工时记录"

**步骤2：编制部门分配表**
分别为各生产部门编制"工资费用分配表"

**步骤3：计算直接生产人员工资**
```
分配率 = 待分配工资总额 ÷ 总生产工时
直接生产人员工资 = 该产品生产工时 × 分配率
```

**步骤4：归集管理人员工资**
直接记录管理人员的工资金额

**步骤5：计算其他职工薪酬**
```
其他职工薪酬 = 工资合计 × 计提比例
```

**步骤6：编制汇总表**
汇总各部门数据，编制"工资及其他职工薪酬分配汇总表"

**步骤7：编制会计分录**
```
借：生产成本——基本生产成本
    生产成本——辅助生产成本
    制造费用——基本车间
    制造费用——辅助车间
    管理费用
  贷：应付职工薪酬
```

## 制造费用按年预计分配率分配法

### 适用场景
- 各月产量波动较大的企业
- 需要避免单位产品制造费用波动

### 执行步骤

**步骤1：计算年预计分配率**
```
年预计分配率 = 年制造费用预计总额 ÷ 各种产品生产计划（或定额）工时之和
```

**步骤2：月度制造费用分配**
```
某产品某月应负担的制造费用 = 该种产品实际工时数 × 年预计分配率
```

**步骤3：识别账户差异**
- 借方 > 贷方：有借方余额，实际发生额大于分配额
- 借方 < 贷方：有贷方余额，实际发生额小于分配额

**步骤4：年末累计差异调整**
- **差异较小**：一次转入销货成本账户
- **差异较大**：按期末在产品、产成品、销货成本账户金额比例分配结转

## 辅助生产费用分配

### 适用场景
- 辅助生产产品完工或提供劳务
- 需要将辅助生产成本转出至受益对象

### 执行步骤

**前置步骤**：将各辅助车间的制造费用分配转入各辅助生产明细账

**场景A：生产工具、模具、备件等实物产品**
```
借：原材料
  贷：生产成本——辅助生产成本
```

**场景B：提供水、电、气、运输、修理等劳务**
```
借：制造费用
    管理费用
  贷：生产成本——辅助生产成本
```

**特殊情况（交互分配）**：
- 采用直接分配法或交互分配法
- 按受益单位耗用的劳务数量分配

## 联产品联合成本分配（分离点售价法）

### 适用场景
- 存在联产品联合成本需要分配
- 分离点各产品总售价可可靠计量

### 执行步骤

**步骤1：计算联合成本分配率**
```
联合成本分配率 = 待分配联合成本 ÷ 各联产品分离点总售价之和
```

**步骤2：计算各产品应分配的联合成本**
```
A产品应分配联合成本 = 联合成本分配率 × A产品分离点的总售价
B产品应分配联合成本 = 联合成本分配率 × B产品分离点的总售价
```

**关键要点**：
- 分配基础：分离点时的总售价（不是单位售价）
- 假设售价越高的产品，应承担的成本比例越高
- 验证：各产品分配成本之和应等于待分配联合成本

## 传统制造费用分配（统一分配率法）

### 适用场景
- 采用传统完全成本法进行成本计算
- 需要将制造费用分配至各产品

### 执行步骤

**步骤1：计算制造费用统一分配率**
```
制造费用分配率 = 制造费用总额 ÷ 直接人工成本总额
```

**步骤2：各产品制造费用分配**
```
某产品制造费用 = 该产品直接人工成本 × 制造费用分配率
```

**步骤3：计算各产品总成本**
```
某产品总成本 = 直接材料 + 直接人工 + 制造费用
```

**步骤4：计算单位成本**
```
每件成本 = 总成本 ÷ 总件数
```

**方法特征**：
- "一刀切"分配，所有产品使用同一分配率
- 分配基础：单一成本动因——直接人工成本
- 隐含假设：制造费用消耗与直接人工消耗成正比
