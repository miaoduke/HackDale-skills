# 项目经营期现金流量计算

## 何时使用此技能

- 计算项目经营期间的年度营业现金流量
- 进行投资项目财务评价（NPV、IRR、回收期分析）
- 需要区分经营现金流与筹资现金流
- 处理折旧抵税效应的税务影响
- 编制项目增量现金流量表

## 核心原则

> **关键排除原则**：经营期现金流量必须排除所有筹资活动现金流，包括利息支付、债务本金偿还、现金股利支付。原因是折现率（必要报酬率/资本成本）已包含筹资成本，现金流量中再扣除会导致重复计算。

## 执行步骤

### 步骤1：识别税后增量现金流入

计算项目实施带来的营业收入增加额：

```
税后增量收入 = 增量营业收入 × (1 - 所得税税率)
```

### 步骤2：识别税后增量现金流出（付现成本）

1. 确定与项目直接相关的付现成本增加额
2. **行政费用处理规则**：
   - 若费用不受新项目实施影响 → **不计入**项目现金流出
   - 若费用受新项目实施影响/有关 → **必须计入**项目经营期现金流出
3. 计算税后付现成本：

```
税后增量付现成本 = 增量付现成本 × (1 - 所得税税率)
```

### 步骤3：计算折旧抵税收益

折旧本身是非付现成本，但产生抵税效应（视为现金流入或流出减少）：

```
折旧抵税 = 折旧额 × 所得税税率
```

### 步骤4：明确排除筹资相关现金流

| 排除项目 | 排除原因 |
|---------|---------|
| 债务利息支付 | 折现率已反映债务成本 |
| 债务本金偿还 | 属于筹资活动，非经营活动 |
| 现金股利支付 | 股权成本已体现在折现率中 |

### 步骤5：计算经营期现金流量

**公式一（推荐）**：
```
经营期现金流量 = 税后增量收入 - 税后增量付现成本 + 折旧抵税
```

**公式二**：
```
经营期现金流量 = (增量收入 - 增量付现成本 - 折旧) × (1 - 税率) + 折旧
```

**公式三**：
```
经营期现金流量 = 增量营业利润 × (1 - 税率) + 折旧
```

## 输入变量清单

| 变量名 | 类型 | 说明 |
|-------|------|------|
| 增量营业收入 | 金额 | 项目带来的收入增加额 |
| 增量付现成本 | 金额 | 项目带来的现金成本增加额 |
| 折旧额 | 金额 | 项目资产的年度折旧 |
| 所得税税率 | 百分比 | 适用企业所得税税率 |

## 输出结果

计算得出各经营年度的**税后增量营业现金流量**：
- 正值：现金净流入
- 负值：现金净流出

## 常见错误警示

⚠️ **重复计算筹资成本**：在现金流中扣除利息同时，使用包含债务成本的WACC作为折现率

⚠️ **混淆付现成本与非付现成本**：折旧不计入现金流出，但需计算抵税收益

⚠️ **遗漏增量原则**：只计入因项目而产生的增量现金流，排除无关的沉没成本和行政费用
