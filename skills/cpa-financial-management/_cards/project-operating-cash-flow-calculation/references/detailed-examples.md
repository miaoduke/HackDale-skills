# 详细计算示例

## 案例一：基础计算

**项目背景**：
- 新增生产线，年增量营业收入：1,000万元
- 年增量付现成本：600万元
- 年折旧额：100万元（直线法，资产原值500万，5年）
- 所得税税率：25%
- 项目融资：银行贷款300万，年利率6%

**错误计算（包含筹资成本）**：
```
错误现金流 = (1000-600-100-18) × (1-25%) + 100 = 211.5万
（错误：扣除了利息18万）
```

**正确计算**：
```
税后增量收入 = 1000 × (1-25%) = 750万
税后增量付现成本 = 600 × (1-25%) = 450万
折旧抵税 = 100 × 25% = 25万

经营期现金流量 = 750 - 450 + 25 = 325万

验证（公式二）：
= (1000 - 600 - 100) × (1-25%) + 100
= 300 × 0.75 + 100
= 225 + 100 = 325万 ✓
```

> 利息18万明确排除，折现率使用WACC（已含债务成本6%）进行贴现

## 案例二：行政费用分摊处理

**情景**：新项目使用现有行政管理人员，不新增人员

| 费用类型 | 处理方式 | 理由 |
|---------|---------|------|
| 现有行政人员工资 | 不计入 | 不受项目影响，非增量成本 |
| 新增专属管理人员 | 计入 | 项目直接相关增量成本 |
| 辅助生产车间变动费用 | 计入 | 随产量增加而增加 |
| 总部固定管理费用分摊 | 不计入 | 沉没成本，与项目决策无关 |
