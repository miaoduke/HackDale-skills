# 特殊场景处理指南

## 场景一：亏损项目抵税处理

当项目初期亏损时：

```
若 (R - C - D) < 0（经营亏损）

则：亏损抵税 = |经营亏损| × T（视为现金流入）
或：当年少缴税款 = 企业其他利润 × T（需结合企业整体）
```

**处理方式**：
- 若企业有其他盈利项目：亏损抵税立即实现
- 若企业整体亏损：确认递延所得税资产，未来抵扣

## 场景二：折旧方法变更

| 折旧方法 | 对现金流的影响 | 适用场景 |
|---------|------------|---------|
| 直线法 | 各年折旧抵税均衡 | 收益稳定项目 |
| 双倍余额递减法 | 前期折旧抵税大，后期小 | 加速回收投资 |
| 年数总和法 | 同上，递减幅度较缓 | 技术更新快项目 |

**注意**：折旧方法选择影响现金流时间分布，但不改变总折旧额和总抵税额。

## 场景三：营运资金变动

经营期现金流量还需考虑**营运资金增量**：

```
完整经营期现金流 = 营业现金流量 - 营运资金增加额
```

- 营业收入增加 → 应收账款、存货增加 → 营运资金占用增加（现金流出）
- 应付账款增加 → 营运资金占用减少（现金流入）

**处理原则**：
- 项目开始时：营运资金增加 → 现金流出
- 项目结束时：营运资金收回 → 现金流入

## 场景四：通货膨胀处理

| 处理方法 | 名义现金流 + 名义折现率 | 实际现金流 + 实际折现率 |
|---------|----------------------|----------------------|
| 现金流调整 | 按通胀率调整收入和成本 | 保持不变 |
| 折现率调整 | 名义利率 = (1+实际利率)(1+通胀率)-1 | 实际利率 |
| 一致性 | 必须匹配 | 必须匹配 |

**建议**：通常采用名义值计算，更直观且数据易获取。

---

## 场景五：项目期末处理

最后一期经营现金流特殊组成：

```
最后年度现金流 = 正常经营现金流 + 资产残值变现 + 营运资金收回
```

**残值处理**：
- 账面残值 vs 实际变现价值 → 可能产生纳税影响
- 若变现价值 > 账面价值：差额补税（现金流出）
- 若变现价值 < 账面价值：差额抵税（现金流入）
