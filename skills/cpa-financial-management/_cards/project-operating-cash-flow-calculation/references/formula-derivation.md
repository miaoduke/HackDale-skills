# 公式推导与等价性证明

## 三个公式的等价性证明

### 基础定义

设：
- R = 增量营业收入
- C = 增量付现成本
- D = 折旧额
- T = 所得税税率

### 公式一推导

**起点**：净利润 + 非付现成本

税后经营利润 = (R - C - D) × (1 - T)

加回折旧（非付现成本）：
```
NCF = (R - C - D) × (1 - T) + D
    = (R - C) × (1 - T) - D × (1 - T) + D
    = (R - C) × (1 - T) + D × T
```

即：**税后收入 - 税后付现成本 + 折旧抵税**

### 公式二结构

```
NCF = (R - C - D) × (1 - T) + D
```

直接体现：税后经营利润 + 折旧

### 公式三结构

```
NCF = 增量营业利润 × (1 - T) + D
```

其中：增量营业利润 = R - C - D

### 等价性验证

| 公式 | 展开形式 | 简化结果 |
|-----|---------|---------|
| 一 | R(1-T) - C(1-T) + DT | (R-C)(1-T) + DT |
| 二 | (R-C-D)(1-T) + D | (R-C)(1-T) - D(1-T) + D = (R-C)(1-T) + DT |
| 三 | (R-C-D)(1-T) + D | 同上 |

**结论**：三公式完全等价，根据已知条件选择最便捷的计算方式

## 为什么必须排除利息

### 双重计算问题

假设项目全债务融资，利率8%，所得税率25%：

| 处理方式 | 现金流计算 | 折现率 | 结果 |
|---------|----------|--------|------|
| 错误：现金流扣利息，用WACC折现 | 已扣税后利息6% | WACC=8%×(1-25%)=6% | 利息成本被计算两次 |
| 正确：现金流不扣利息，用WACC折现 | 不扣利息 | WACC包含税后债务成本6% | 利息成本计算一次 |

### 一致性原则

现金流量与折现率必须保持**风险匹配**：
- 股权现金流 → 用股权成本折现
- 债权现金流 → 用债务成本折现  
- **实体现金流（不含筹资）→ 用WACC折现**

本项目计算的是**实体现金流**，故必须用WACC，且不得扣除筹资现金流。
