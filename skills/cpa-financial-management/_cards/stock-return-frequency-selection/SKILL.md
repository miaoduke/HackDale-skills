# 股票收益计量时间间隔选择

## 适用场景

- 构建CAPM模型计算β系数
- 进行股票报酬率与市场指数的回归分析
- 选择投资组合绩效评估的数据频率
- 处理存在停牌或流动性问题的股票数据

## 核心决策

### 默认选择：月度报酬率

**适用条件**：股票上市时间≥2年，具备基本流动性

**执行步骤**：
1. 收集股票月度收盘价（月末最后交易日）
2. 计算对数收益率或简单收益率
3. 同步获取市场指数（如沪深300、中证500）月度数据
4. 进行回归分析

### 备选选择：周度报酬率

**适用条件**：上市时间较短（6个月-2年），月度样本不足

**执行步骤**：
1. 采用周收盘价（通常周五，遇节假日取前一交易日）
2. 计算周收益率
3. 匹配市场指数周度数据
4. 回归分析并标注数据频率

## 避免使用的频率

| 频率 | 问题 | 例外情况 |
|------|------|---------|
| **日度** | 停牌日记为0收益，低估β值 | 仅用于高频交易策略回测，非β估计 |
| **年度** | 样本量需求过大（20-30年），早期数据失效 | 超长期结构研究，需配合滚动窗口 |

## 快速检查清单

- [ ] 确认股票非长期停牌或流动性枯竭状态
- [ ] 上市时间>2年 → 优先月度
- [ ] 上市时间6个月-2年 → 使用周度
- [ ] 记录所选频率及样本量
- [ ] 在分析报告中说明频率选择理由

## 常见错误

**错误**：使用日度数据提高样本量
**后果**：停牌期间的零收益人为降低股票与市场的相关性，β估计偏向0

**错误**：混合使用不同频率数据
**后果**：收益率尺度不可比，回归结果失真

## 输出规范

最终输出需明确标注：
- 所选时间间隔（月度/周度）
- 样本期间起止日期
- 有效观测值数量
- 排除的停牌期间说明（如有）
