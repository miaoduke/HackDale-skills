# 成本差异分析详细公式

## 变动成本差异分析

### 直接材料差异
- 价格差异 = 实际用量 × (实际价格 - 标准价格)
- 数量差异 = (实际用量 - 标准用量) × 标准价格

### 直接人工差异
- 工资率差异 = 实际工时 × (实际工资率 - 标准工资率)
- 效率差异 = (实际工时 - 标准工时) × 标准工资率

### 变动制造费用差异
- 耗费差异 = 实际工时 × (实际分配率 - 标准分配率)
- 效率差异 = (实际工时 - 标准工时) × 标准分配率

## 固定制造费用三因素分析

### 计算示例（例14-4）
- 生产能力：1000小时
- 实际工时：890小时
- 实际产量：400件
- 单位标准工时：2小时/件
- 标准分配率：1.5元/小时

**计算结果**：
- 闲置能力差异 = (1000 - 890) × 1.5 = 165元（U）
- 效率差异 = (890 - 400×2) × 1.5 = 135元（U）
- 验证：165 + 135 = 300元（等于二因素分析法能力差异）

## 多品种保本分析示例

**产品数据**：
- A产品：销售额40000元，边际贡献率37.5%
- B产品：销售额15000元，边际贡献率18.75%
- C产品：销售额25000元，边际贡献率43.75%
- 固定成本总额：50000元

**计算过程**：
1. 总销售额 = 40000 + 15000 + 25000 = 80000元
2. 销售比重：A=50%，B=18.75%，C=31.25%
3. 加权平均边际贡献率 = 37.5%×50% + 18.75%×18.75% + 43.75%×31.25% = 51.875%
4. 综合保本销售额 = 50000 / 51.875% ≈ 96386元
5. B产品保本销售额 = 96386 × 18.75% ≈ 18072元
6. B产品保本销售量 = 18072 / 15 ≈ 1205件
