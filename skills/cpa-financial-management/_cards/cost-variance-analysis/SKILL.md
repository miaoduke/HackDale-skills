# 成本差异分析与边际贡献分析

## 使用场景
当需要执行以下任一任务时使用本技能：
- 计算直接材料、直接人工、变动制造费用的成本差异
- 进行固定制造费用的三因素差异分析
- 计算边际贡献并评估产品盈利能力
- 进行多品种企业的保本点分析
- 编制材料费用分配表

## 核心分析流程

### 1. 变动成本差异分析（通用模型）

**适用对象**：直接材料、直接人工、变动制造费用

**基础公式**：
```
成本差异 = 实际成本 - 标准成本
```

**差异分解**：
```
价格差异 = 实际数量 × (实际价格 - 标准价格)
数量差异 = (实际数量 - 标准数量) × 标准价格
```

### 2. 固定制造费用三因素分析法

**适用场景**：需要将能力差异分解为闲置能力和效率两个维度

**三个差异组成**：

1. **耗费差异**：反映实际发生额与预算额的差异
   ```
   耗费差异 = 固定制造费用预算 - 实际工时 × 标准分配率
   ```

2. **闲置能力差异**：因实际工时未达到生产能力形成的差异
   ```
   闲置能力差异 = (生产能力 - 实际工时) × 标准分配率
   ```

3. **效率差异**：因实际工时脱离标准工时形成的差异
   ```
   效率差异 = (实际工时 - 实际产量标准工时) × 标准分配率
   ```

**验证关系**：闲置能力差异 + 效率差异 = 二因素分析法的能力差异

### 3. 边际贡献计算

**基本定义**：销售收入减去变动成本后的差额

**计算公式**：
```
边际贡献总额 = 销售收入 - 变动成本
单位边际贡献 = 单价 - 单位变动成本
```

**经济含义**：
- 首先用于补偿固定成本
- 补偿后剩余形成利润
- 不足则产生亏损

### 4. 多品种保本点分析（边际贡献法）

**适用条件**：企业销售多种产品，销售结构保持不变

**计算步骤**：

1. 计算各产品销售额和边际贡献
2. 确定销售结构（销售百分比）
3. 计算加权平均边际贡献率
   - 方法一：总额法 = Σ各产品边际贡献 / Σ各产品销售收入
   - 方法二：加权平均法 = Σ(各产品边际贡献率 × 销售比重)
4. 计算综合保本销售总额 = 固定成本总额 / 加权平均边际贡献率
5. 分解各产品保本销售额 = 综合保本总额 × 该产品销售百分比
6. 计算各产品保本销售量 = 该产品保本销售额 / 销售单价

### 5. 材料费用分配表编制

**分配方法**：定额消耗量法

**计算步骤**：
1. 计算各产品定额消耗用量 = 产量 × 单位消耗定额
2. 计算材料费用分配率 = 共同耗用材料费总额 / 定额消耗用量合计
3. 计算各产品应分配材料费 = 该产品定额消耗用量 × 分配率
4. 计算耗用原材料总额 = 应分配材料费 + 直接领用的原材料

**会计分录**：
```
借：生产成本——基本生产成本
    生产成本——辅助生产成本
    制造费用——基本车间
    管理费用
贷：原材料
```

## 决策要点

- 变动成本差异分析时，价格差异和数量差异应分别归因管理责任
- 三因素分析法的闲置能力差异反映生产能力利用程度，效率差异反映生产效率
- 边际贡献 > 0 时，销售产品可回收部分固定成本
- 多品种保本分析的关键假设是销售结构保持不变
- 材料费用分配需区分直接领用和共同耗用两种情况

## 输出结果
- 变动成本的价格差异和数量差异金额
- 固定制造费用的耗费差异、闲置能力差异、效率差异
- 边际贡献总额和单位边际贡献
- 多品种企业的综合保本销售额及各产品保本点
- 材料费用分配表及对应会计分录
