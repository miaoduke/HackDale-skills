# 平衡计分卡详细框架

## 四个维度的战略目标

### 财务维度
- 增加收入
- 降低成本
- 提高资产利用率

### 客户维度
- 市场份额
- 客户满意度
- 客户保持率
- 客户获利率

### 内部业务流程维度
- 创新流程：新产品开发
- 营运流程：提高效率、降低成本
- 售后服务流程：提高客户满意度

### 学习与成长维度
- 员工能力
- 信息系统能力
- 激励、授权和协作

## 战略地图构建

平衡计分卡通过战略地图将四个维度联系起来：

```
学习与成长 → 内部业务流程 → 客户 → 财务
```

- 学习与成长：提升无形资产
- 内部业务流程：改善关键流程
- 客户：满足客户价值主张
- 财务：实现股东价值

## 绩效棱柱模型五面

1. **利益相关者满意度**：谁是关键利益相关者？他们想要什么？
2. **利益相关者贡献**：组织从利益相关者那里获得什么？
3. **战略**：组织需要什么战略来满足利益相关者？
4. **流程**：组织需要什么流程来执行战略？
5. **能力**：组织需要什么能力来支持流程？
