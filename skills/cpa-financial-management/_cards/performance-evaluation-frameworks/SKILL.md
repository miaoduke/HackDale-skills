# 绩效评价框架体系

## 适用场景
- 企业战略目标分解与绩效指标体系设计
- 绩效棱柱模型、KPI体系或平衡计分卡的构建
- 区分平衡计分卡与传统业绩评价系统
- 跨部门绩效管理与团队协作促进

## 框架选择指南

### 绩效棱柱模型
**适用条件：** 需要以利益相关者为中心的绩效评价框架

**核心特征：**
- 开发者：英国克兰菲尔德学院、安达信咨询公司
- 核心焦点：利益相关者
- 政策依据：《管理会计应用指引第604号——绩效棱柱模型》（财会〔2018〕22号）

### 关键绩效指标（KPI）体系
**适用条件：** 企业应用关键绩效指标法，处于制定绩效计划阶段

**前置要求：**
- 明确的战略目标
- 清晰的价值创造模式
- 关键业务流程定义
- 员工岗位职责说明

### 平衡计分卡
**适用条件：** 需要构建企业战略地图或区分平衡计分卡与传统业绩考核

**核心维度：**
1. 财务维度
2. 客户维度
3. 内部业务流程维度
4. 学习与成长维度

## KPI体系构建流程

### 第一步：构建三层指标体系

**第一层（企业级）：**
- 根据战略目标设定
- 结合价值创造模式
- 综合考虑企业内外部经营环境

**第二层（所属单位/部门级）：**
- 根据企业级KPI设定
- 结合所属单位关键业务流程
- 按照"上下结合、分级编制、逐级分解"程序
- 在沟通反馈基础上设定

**第三层（岗位/员工级）：**
- 根据所属单位级KPI设定
- 结合员工岗位职责
- 结合关键工作价值贡献

### 第二步：确定指标类别

**结果类指标（反映企业绩效的价值指标）：**
- 投资报酬率
- 权益净利率
- 经济增加值
- 息税前利润
- 自由现金流量

**动因类指标（反映企业价值关键驱动因素）：**
- 资本性支出
- 单位生产成本
- 产量、销量
- 客户满意度
- 员工满意度

### 第三步：验证指标特征
- 指标含义明确
- 指标可度量
- 指标与战略目标高度相关

## 平衡计分卡框架构成

### 内部业务流程维度
**战略功能：**
- 针对顾客的价值主张进行生产与交货
- 为财务层面的生产力要件进行流程改善与成本降低

**流程组成：**
1. 营运管理流程
2. 顾客管理流程
3. 创新管理流程
4. 法规与社会流程

### 学习与成长维度
**核心说明：** 企业的无形资产及它们在战略中扮演的角色

**资产分类：**
1. 人力资本
2. 信息资本
3. 组织资本

## 平衡计分卡与传统系统的区别

| 区别点 | 传统业绩评价系统 | 平衡计分卡 |
|--------|-----------------|-----------|
| 目标管理视角 | 注重对员工执行过程的控制 | 强调目标制定环节，使员工理解战略使命 |
| 战略关联性 | 业绩评价与战略执行脱节 | 把企业战略和业绩管理系统联系起来 |
| 目标建立维度 | 单一财务目标 | 四个方面建立战略目标 |
| 考评与调整 | 周期性调整 | 及时考评，适时调整战略、目标和指标 |
| 团队协作 | 部门独立 | 有效建立跨部门团队合作 |

## 执行步骤

1. **选择评价框架**：根据企业战略和管理需求选择绩效棱柱、KPI或平衡计分卡
2. **明确战略目标**：确定企业整体战略和价值创造模式
3. **构建指标体系**：按企业级、部门级、岗位级三层构建
4. **确定指标类别**：选择结果类和动因类指标
5. **验证指标质量**：确保明确、可度量、相关
6. **实施与调整**：定期考评战略执行情况，适时调整

## 注意事项
- 平衡计分卡不适用于非战略导向的简单事务性评价
- KPI指标必须与战略目标高度相关
- 绩效棱柱模型具体实施需参考应用指引604号
