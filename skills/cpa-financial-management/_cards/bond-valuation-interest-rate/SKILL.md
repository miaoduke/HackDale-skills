# 债券估值与利率分析

## 适用场景
- 估计无风险利率（股权资本成本计算）
- 比较不同付息频率债券的投资回报
- 计算债券实际融资成本
- 可转换债券估值与套利分析
- 债券付息方式选择

## 政府债券期限选择规则

### 基本原则
选择长期政府债券利率（通常指10年期或更长期限）作为无风险利率基准。

### 选择理由
1. **期限匹配**：普通股是长期有价证券，现金流理论上是永续的。长期政府债券的现金流模式更接近普通股的永续现金流特征。
2. **资本预算匹配**：长期政府债券的期限和投资项目现金流持续时间能较好地配合。
3. **波动性控制**：长期政府债券的利率波动较小，短期债券波动性过大。

### 排除选项
不应选择短期政府债券利率（如3个月、1年期国债）。

## 票面利率与有效年利率

### 核心差异
- **票面利率**：债券契约中明确标明的名义利率
- **有效年利率（EAR）**：考虑复利效应后资金的实际年度增长率

### 有效年利率计算公式
```
EAR = (1 + 名义利率/m)^m - 1
```
其中m为每年复利期数。

### 付息频率影响
- **半年付息一次**：EAR = (1 + 票面利率/2)^2 - 1，结果大于票面利率
  - 示例：票面利率10%，EAR = (1 + 5%)^2 - 1 = 10.25%
- **一年付息一次**：EAR = 票面利率
- **到期一次总付**：EAR通常低于票面利率

### 实际应用决策
- 比较不同债券时，必须将收益率转换为有效年利率进行标准化比较
- 绝不能仅比较票面利率
- 付息频率越高，有效年利率越高，实际收益越好

## 可转换债券估值

### 底线价值确定
```
底线价值 = Max(纯债券价值, 转换价值)
```

- **纯债券价值**：基于未来现金流按适当折现率计算的现值
- **转换价值**：转换比率 × 当前股票市价

### 套利机制
1. **纯债券价值套利**：如果市价低于纯债券价值，投资者购入债券，需求增加推动价格上升
2. **转换价值套利**：如果市价低于转换价值，投资者购入债券并立即转换股票出售，获取无风险收益

### 可转换债券赎回条款

**结构要素：**
1. **不可赎回期**：从发行日起不能赎回的期间（如前2年）
2. **赎回期**：不可赎回期结束后可赎回的期间
3. **赎回价格**：事前规定的赎回出价，一般高于面值
4. **赎回溢价**：赎回价格与面值的差额，随到期日临近而减少

**赎回条件：**
- 无条件赎回：赎回期内随时可赎回
- 有条件赎回：需满足特定条件（如股价持续高于转股价）

## 债券付息方式选择

### 匹配规则

| 债券类型 | 付息频率 | 付息方式 |
|---------|---------|---------|
| 记名债券 | 分次付息 | 支票或汇款 |
| 不记名债券 | 分次付息 | 息票方式 |
| 任意类型 | 一次性付息 | 现金或支票 |
| 贴现发行 | - | 无实际付息（利息体现在折价中） |

### 特殊情况
- **贴现发行**：发行人以现金折扣形式出售债券，到期按面值偿还，不发生实际付息行为
- **利随本清债券**：使用现金或支票一次性支付全部利息
