## 现金流量定义与计算

### 股利现金流量
企业分配给股权投资者的现金流量。

### 股权现金流量（股权自由现金流量）
一定期间企业可以提供给股权投资者的现金流量。

**计算公式**：
```
股权现金流量 = 实体现金流量 - 债务现金流量
```

或：
```
股权现金流量 = 净利润 + 折旧摊销 - 资本支出 - 营运资本增加 - 债务本金偿还 + 新借债务
```

### 实体现金流量（实体自由现金流量）
企业全部现金流入扣除成本费用和必要的投资后的剩余部分，可以提供给所有投资者（股权和债权）的税后现金流量。

**计算公式**：
```
实体现金流量 = 税后经营净利润 + 折旧摊销 - 资本支出 - 营运资本增加
```

或：
```
实体现金流量 = 股权现金流量 + 债务现金流量
```

### 债务现金流量
流向债权人的现金流量。

**计算公式**：
```
债务现金流量 = 税后利息费用 - 净负债增加
```

## 两阶段DCF模型公式

### 股权现金流量两阶段模型

```
股权价值 = 预测期股权现金流量现值 + 后续期股权现金流量现值

= Σ(t=1 to n)[股权现金流量t / (1+rs)^t] + [股权现金流量n+1 / (rs - g)] / (1+rs)^n
```

其中：rs = 股权资本成本，g = 永续增长率

### 实体现金流量两阶段模型

```
实体价值 = 预测期实体现金流量现值 + 后续期实体现金流量现值

= Σ(t=1 to n)[实体现金流量t / (1+WACC)^t] + [实体现金流量n+1 / (WACC - g)] / (1+WACC)^n
```

## 折现率确定

### 股权资本成本（CAPM）
```
rs = rf + β × (rm - rf)
```

### 加权平均资本成本（WACC）
```
WACC = (E/V) × rs + (D/V) × rd × (1-T)
```
其中：E = 股权价值，D = 债务价值，V = E+D，T = 所得税税率
