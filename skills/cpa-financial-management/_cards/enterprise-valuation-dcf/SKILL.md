# 企业估值：现金流量折现模型

## 何时使用

- 进行企业整体价值评估、股权价值评估或实体价值评估
- 企业并购、投资决策、价值管理
- 需要区分持续经营价值与清算价值
- 估计DCF模型中的永续增长率

## 持续经营价值与清算价值

### 价值定义

| 价值类型 | 定义 |
|---------|------|
| 持续经营价值 | 由营业所产生的未来现金流量的现值 |
| 清算价值 | 停止经营，出售资产产生的现金流量 |

### 公平市场价值确定规则

```
企业的公平市场价值 = MAX(持续经营价值, 清算价值)
```

### 持续经营基本条件

**自利原则应用**：
- 持续经营价值 > 清算价值 → 投资者选择持续经营
- 未来现金流量现值 < 清算价值 → 投资者选择清算

### 例外情况

控制企业的人拒绝清算 → 企业被迫持续经营 → 持续削减股东本来可以通过清算得到的价值

## 现金流量折现模型分类

### 模型选择决策

| 现金流种类 | 折现率 | 模型名称 | 适用场景 |
|-----------|--------|---------|---------|
| 股利现金流量 | 股权资本成本 | 股利现金流量模型 | 股利政策稳定、可预测 |
| 股权现金流量 | 股权资本成本 | 股权现金流量模型 | 大多数企业估值场景 |
| 实体现金流量 | 加权平均资本成本 | 实体现金流量模型 | 资本结构复杂或频繁变动 |

### 核心公式

**股利现金流量模型**：
```
股权价值 = Σ[股利现金流量t / (1 + 股权资本成本)^t]
```

**股权现金流量模型**：
```
股权价值 = Σ[股权现金流量t / (1 + 股权资本成本)^t]
```
股权现金流量 = 实体现金流量 - 债务现金流量

**实体现金流量模型**：
```
实体价值 = Σ[实体自由现金流量t / (1 + WACC)^t]
净负债价值 = Σ[债务现金流量t / (1 + 等风险债务资本成本)^t]
股权价值 = 实体价值 - 净负债价值
```

### 模型选择建议

- **股利模型局限性**：股利分配政策有较大变动，股利现金流量很难预计，实务中很少使用
- **主流选择**：大多数企业估值使用股权现金流量模型或实体现金流量模型
- **替代方案**：假设股权现金流量全部作为股利发放，则股权现金流量模型可取代股利现金流量模型

## 后续期销售增长率估计

### 基准估计原则（竞争均衡理论）

```
后续期销售增长率 ≈ 宏观经济的名义增长率
```

理论基础：长期来看，企业无法持续跑赢宏观经济，竞争将使得超额利润趋于零。

### 具体数值范围

| 企业类型 | 增长率范围 | 说明 |
|---------|-----------|------|
| 一般企业 | 2% ~ 6% | 宏观经济增长率（不考虑通货膨胀） |
| 特殊优势企业 | 宏观增长率 + (0~2%) | 最高不超过宏观增长率+2% |

### 特殊优势企业判定

- 必须掌握具有说服力的证据
- 并且被长期的历史所验证
- 超额增长率上限：即使具有特殊优势，超过宏观经济增长率的幅度也不会超过2%

## 执行流程

1. **选择模型**：根据现金流可预测性和资本结构稳定性选择适当模型
2. **预测现金流**：分详细预测期和后续期（稳定期）
3. **确定折现率**：匹配现金流风险特征
4. **估计永续增长率**：一般企业2%-6%，特殊优势企业最高+2%
5. **计算价值**：详细期现值 + 后续期现值
6. **价值检验**：持续经营价值 vs 清算价值，取较高者
