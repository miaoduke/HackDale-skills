# 估值方法详细说明

## 市场法

### 市盈率法
```
企业价值 = 可比公司市盈率 × 目标公司净利润
```

### 市净率法
```
企业价值 = 可比公司市净率 × 目标公司净资产
```

### 交易案例法
参考类似企业的并购交易价格，进行适当调整。

## 收益法

### 现金流折现法（DCF）
```
企业价值 = Σ [FCFt / (1 + WACC)^t] + 终值
```

其中：
- FCFt：第t年自由现金流
- WACC：加权平均资本成本
- 终值：预测期后的持续价值

## 成本法

### 资产基础法
```
企业价值 = 有形资产价值 + 无形资产价值 - 负债
```

### 重置成本法
```
企业价值 = 资产重置成本 × (1 - 贬值率)
```

## 调整因素

### 控制权溢价
- 控制股权通常比少数股权有溢价
- 溢率通常在20%-40%之间

### 流动性折扣
- 非上市股权缺乏流动性
- 折扣率通常在20%-30%之间

### 信息不对称调整
- 信息不充分时需要风险溢价
- 调整幅度取决于信息质量
