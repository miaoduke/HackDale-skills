# 财务管理基础概念详解

## 货币的时间价值

### 基本原理

**为什么货币具有时间价值？**

1. **投资机会**：货币可以投资获得收益
2. **通货膨胀**：货币购买力随时间下降
3. **风险偏好**：人们偏好当前消费
4. **机会成本**：当前消费的放弃需要补偿

### 核心公式

#### 单利终值
```
FV = PV × (1 + n × i)
```

#### 复利终值
```
FV = PV × (1 + i)^n
```

#### 现值
```
PV = FV / (1 + i)^n
```

#### 年金终值
```
FVA = PMT × [(1 + i)^n - 1] / i
```

#### 年金现值
```
PVA = PMT × [1 - (1 + i)^(-n)] / i
```

### 计算示例

**问题**：现在存入10000元，年利率5%，5年后能获得多少？（复利）

**解答**：
```
FV = 10000 × (1 + 5%)^5
   = 10000 × 1.2763
   = 12763元
```

**问题**：5年后需要10000元，年利率5%，现在需要存入多少？

**解答**：
```
PV = 10000 / (1 + 5%)^5
   = 10000 / 1.2763
   = 7835元
```

## 风险与报酬

### 风险的度量

#### 期望报酬率
```
E(R) = Σ [Pi × Ri]
```

其中：
- Pi：第i种结果发生的概率
- Ri：第i种结果的报酬率

#### 标准差（衡量风险）
```
σ = √{Σ [Pi × (Ri - E(R))^2]}
```

#### 变异系数（单位风险报酬）
```
CV = σ / E(R)
```

### 风险与报酬关系

**资本资产定价模型（CAPM）**：
```
E(Ri) = Rf + βi × [E(Rm) - Rf]
```

其中：
- E(Ri)：资产i的期望报酬率
- Rf：无风险利率
- βi：资产i的贝塔系数（系统风险）
- E(Rm)：市场组合的期望报酬率
- [E(Rm) - Rf]：市场风险溢价

### 计算示例

**问题**：某投资项目有三种可能结果：

| 结果 | 概率 | 报酬率 |
|------|------|--------|
| 好 | 30% | 20% |
| 中 | 50% | 10% |
| 差 | 20% | -5% |

计算期望报酬率和标准差。

**解答**：

**期望报酬率**：
```
E(R) = 30% × 20% + 50% × 10% + 20% × (-5%)
     = 6% + 5% - 1%
     = 10%
```

**标准差**：
```
σ = √[30% × (20% - 10%)^2 + 50% × (10% - 10%)^2 + 20% × (-5% - 10%)^2]
   = √[30% × 100%^2 + 50% × 0%^2 + 20% × (-15%)^2]
   = √[30% × 0.01 + 0 + 20% × 0.0225]
   = √[0.003 + 0.0045]
   = √0.0075
   = 8.66%
```

## 两大概念的综合应用

### 投资决策

1. **计算未来现金流量的现值**（考虑时间价值）
2. **根据风险调整折现率**（考虑风险与报酬）
3. **比较现值与投资成本**，做出决策

### 资本成本确定

1. **无风险利率**：时间价值的基础
2. **风险溢价**：根据风险水平确定
3. **资本成本 = 无风险利率 + 风险溢价**

### 资产定价

1. **确定资产未来现金流量**
2. **评估资产风险水平**
3. **使用CAPM确定必要报酬率**
4. **计算资产现值**
