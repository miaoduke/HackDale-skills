## 内部转移价格选择决策树

```
开始
  │
  ├─ 是否有外部活跃市场？
  │   ├─ 是 → 市场型（使用市场价）
  │   └─ 否 → 继续判断
  │
  ├─ 是否为利润中心？
  │   ├─ 是 → 市场型（模拟市场价）
  │   └─ 否 → 继续判断
  │
  ├─ 是否为成本中心？
  │   ├─ 是 → 成本型（完全成本或变动成本）
  │   └─ 否 → 继续判断
  │
  └─ 分权程度是否较高？
      ├─ 是 → 协商型
      └─ 否 → 成本型
```

## 责任归属判别示例

### 示例1：材料成本
- **生产部门**通过优化工艺可降低材料消耗 → 生产部门负责
- **采购部门**采购价格高于标准 → 采购部门负责

### 示例2：维修成本
- **设备管理部门**有权决定维修服务的外包或自营 → 设备管理部门负责
- **生产部门**使用不当导致设备损坏 → 生产部门负责

### 示例3：设备折旧
- **技术部门**参与设备选型，对设备折旧成本有重要影响 → 技术部门负责
- **采购部门**采购设备价格过高 → 采购部门负责

## 费用中心预算编制对比

| 方法 | 优点 | 缺点 |
|------|------|------|
| 同行业比较法 | 便于横向比较 | 行业数据可能难以获取 |
| 零基预算法 | 科学合理，避免浪费 | 编制工作量大 |
| 历史经验法 | 简单易行 | 可能导致预算虚高 |
