# 投资中心投资报酬率(ROI)计算

## 适用场景
- 计算投资中心业绩指标
- 拥有资产控制权的部门绩效评估
- 比较不同投资中心运用资产创造利润的效率
- 投资评估和资源配置决策

## 计算公式

### 基本公式
```
部门投资报酬率(ROI) = 部门税前经营利润 ÷ 部门平均净经营资产 × 100%
```

### 分母计算（关键步骤）
```
部门平均净经营资产 = 部门平均经营资产 - 部门平均经营负债
```
（也称为：部门平均净投资资本）

## 数据要求

### 利润数据
- 必须是**税前经营利润**（包含部门可控的所有经营收入和成本）
- 反映部门经营活动产生的利润，未扣除所得税

### 资产数据
- 使用**平均值**：（期初余额 + 期末余额）÷ 2
- 以匹配利润数据的期间性（利润是期间概念，资产是时点概念）

### 负债扣除
- 必须扣除**经营负债**，反映部门实际占用的净投资资本
- 不是使用总资产，而是使用净经营资产

## 计算示例

### A 部门计算
- 部门税前经营利润：108,000 元
- 部门平均经营资产：900,000 元
- 部门平均经营负债：50,000 元
- 部门平均净经营资产：900,000 - 50,000 = **850,000 元**
- 投资报酬率：108,000 ÷ 850,000 × 100% = **12.71%**

### B 部门计算
- 部门税前经营利润：90,000 元
- 部门平均经营资产：600,000 元
- 部门平均经营负债：40,000 元
- 部门平均净经营资产：600,000 - 40,000 = **560,000 元**
- 投资报酬率：90,000 ÷ 560,000 × 100% = **16.07%**

## 执行步骤

1. **收集利润数据**：获取部门税前经营利润（期间数据）
2. **确定经营资产**：统计部门控制的全部经营性资产的期初和期末余额，计算平均值
3. **确定经营负债**：统计部门经营性负债的期初和期末余额，计算平均值
4. **计算净经营资产**：用平均经营资产减去平均经营负债
5. **计算 ROI**：将税前经营利润除以净经营资产，乘以 100% 得到百分比
6. **业绩比较**：将计算结果与部门历史数据、其他部门或公司最低报酬率要求进行比较

## 结果应用

- **效率衡量**：ROI 越高，说明部门运用资产创造利润的效率越高（如示例中 B 部门 16.07% 优于 A 部门 12.71%）
- **投资决策**：作为评价投资项目可行性的参考指标
- **资源配置**：根据 ROI 高低决定资源在不同部门间的分配
