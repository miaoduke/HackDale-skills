# 留存收益预测与销售百分比法

## 何时使用

- 预测企业内部融资来源
- 计算留存收益增加额以减少外部融资需求
- 进行融资需求测算和财务规划
- 评估销售百分比法的适用性和局限性

## 核心公式

### 留存收益增加额

```
留存收益增加 = 预计营业收入 × 预计营业净利率 × (1 - 预计股利支付率)
```

**关键假设**：当年利润当年分配股利

### 外部融资额计算

```
外部融资额 = 资金需求总量 - 增加留存收益
```

## 循环逻辑处理

### 数据循环关系

```
股利支付率 → 留存收益 → 净利润 → 利息费用 → 借款数额 → 留存收益增加额
```

### 解决方法

| 方法 | 说明 |
|------|------|
| 多次迭代法 | 逐步逼近可以使数据平衡的留存收益和借款增加额（精确但复杂） |
| 净利率覆盖假设 | 假设预计营业净利率可以涵盖增加的利息，先确定留存收益，再确定借款增加额（简化方法） |

## 销售百分比法的两大局限性

### 局限性一：稳定百分比假设的不现实性

- **核心假设**：各项经营资产和经营负债与营业收入保持稳定的百分比关系
- **问题**：该假设"可能与事实不符"
- **具体表现**：
  - 规模经济效应：资产使用效率可能随规模扩大而提升
  - 批量采购效应：大规模采购可能改变负债比例
  - 资产不可分割性：某些资产需要一次性大额投入
  - 行业周期性：不同经济周期中资产周转效率变化

### 局限性二：营业净利率覆盖假设的不合理性

- **核心假设**：假设预计营业净利率可以涵盖借款利息的增加
- **问题**：该假设"也未必合理"
- **实际情况**：增加借款 → 利息费用增加 → 净利润下降 → 留存收益减少 → 可能进一步增加融资需求

## 方法定位

- **性质**：一种比较简单、粗略的预测方法
- **适用场景**：初步快速估算、数据有限、短期预测
- **不适用场景**：精确预测、长期规划、资本结构大幅变动时

## 计算示例

假设ABC公司20×2年：
- 预计营业收入 = 4000万元
- 预计营业净利率 = 4.5%
- 股利支付率 = 0（不支付股利）

计算：
- 增加留存收益 = 4000 × 4.5% = 180万元
- 若资金需求总量 = 574万元
- 外部融资额 = 574 - 180 = 394万元
