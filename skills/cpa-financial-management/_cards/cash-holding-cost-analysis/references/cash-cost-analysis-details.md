# 现金持有成本详细分析

## 机会成本详解

**定义：** 现金作为资金占用的代价，即因持有现金而失去将其投入生产经营获得的收益。

**计算逻辑：**
- 企业在循环期之初持有现金C
- 随着现金的逐步使用，现金余额逐渐减少到0
- 平均现金持有量为C/2
- 机会成本 = 平均现金持有量 × 机会成本率 = (C/2) × K

**经济含义：** 持有现金意味着放弃了将这些资金用于投资或生产经营所能获得的收益。

## 交易成本详解

**定义：** 企业持有现金很少时，通过出售有价证券换回现金所付出的代价（如支付经纪费用）。

**计算逻辑：**
- 一定期间内现金总需求量为T
- 每次转换补充现金C
- 转换次数 = T/C
- 交易成本 = 转换次数 × 每次固定交易成本 = (T/C) × F

**经济含义：** 现金持有量越少，需要越频繁地出售有价证券，交易成本越高。

## 成本权衡原理

**成本曲线特征：**
1. 机会成本曲线：从原点出发，随C增加而上升（线性关系）
2. 交易成本曲线：随C增加而下降（反比关系）
3. 总成本曲线：U型曲线，存在最低点

**最佳现金持有量：** 总成本最低时的现金持有量，即机会成本等于交易成本时的持有量。

**数学推导：**
```
总成本 = (C/2) × K + (T/C) × F
对C求导并令导数为0：
K/2 - T×F/C² = 0
C² = 2×T×F/K
C = √(2×T×F/K)
```

此即最佳现金持有量公式（存货模式）。
