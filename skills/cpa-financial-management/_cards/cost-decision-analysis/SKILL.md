# 成本决策分析

## 使用场景
当企业需要：
- 在多个备选方案中选择最优方案
- 进行短期经营决策（如停产、自制与外购）
- 评估方案的经济效益
- 避免收集无关紧要的成本信息

## 决策评价标准

### 二元经济评价标准体系
1. **成本**：方案实施所需的资源耗费
2. **经济效益**：方案带来的经济收益或利润

### 成本-效益关系
- 成本是影响经济效益高低的重要制约因素
- 决策需寻求成本与效益的最优平衡

## 成本分类框架

### 相关成本（Relevant Cost）
- **定义**：与特定决策相关，会影响决策结果的成本
- **特征**：随决策选择不同而变化
- **示例**：差量成本、机会成本、不可延缓成本（在特定约束下）
- **决策处理**：必须纳入方案比较

### 不相关成本（Irrelevant Cost）
- **定义**：与特定决策无关，不影响决策结果的成本
- **特征**：不随决策选择变化
- **示例**：沉没成本、不可避免成本、无差别成本、共同成本（通常情况）
- **决策处理**：应从差异分析中剔除

## 无差别成本识别

### 定义
无差别成本是指两个或两个以上方案之间没有差别的成本，无论选择哪个方案，该成本的金额都保持不变。

### 识别流程
1. 列出所有备选方案（方案A、方案B...）
2. 识别各方案涉及的共同成本项目
3. 比较该成本项目在各方案中的具体金额
4. 若金额完全相同（无差别），则判定为无差别成本
5. 将该成本归类为不相关成本，在决策差异分析中予以排除

### 典型实例
**决策场景**：企业到某高校招聘大学生，面临两位候选人选择
- 候选人条件：甲和乙都是该校同班同学
- 成本分析：岗前培训费用在甲和乙之间花费相同
- 结论：该岗前培训费属于无差别成本

## 差量分析法

### 适用条件
- 需要在两个互斥方案中选择最优方案
- 能够准确识别并量化各方案的相关收入与相关成本

### 计算步骤

**步骤1：明确比较对象**
确定需要比较的两个备选方案（方案一与方案二）

**步骤2：计算差额收入**
```
差额收入 = 方案一的相关收入 - 方案二的相关收入
```

**步骤3：计算差额成本**
```
差额成本 = 方案一的相关成本 - 方案二的相关成本
```

**步骤4：计算差额利润**
```
差额利润 = 差额收入 - 差额成本
```

**步骤5：决策规则**
- 若差额利润 > 0：方案一优于方案二，应选择方案一
- 若差额利润 < 0：方案二优于方案一，应选择方案二

### 分析原则
- 只考虑相关收入和相关成本
- 对不相关因素（如沉没成本、不可避免成本、共同成本等）不予考虑
- 可通过编制差量分析表系统计算和列示

### 局限性
- 仅适用于两个方案之间的直接比较
- 三个及以上备选方案时需两两逐次比较，过程繁琐
- 多方案时可考虑采用边际贡献分析法等其他决策方法

## 成本分类决策应用原则

### 实施步骤
1. 识别决策类型（短期经营决策）
2. 列出所有潜在成本项目
3. 逐一判定各成本的相关性
   - 判断标准：该成本在不同方案间是否存在差异？是否受决策影响？
4. 筛选出相关成本进行深入分析
5. 排除不相关成本，避免资源浪费

### 重要限制条件

**原则1：根据具体情况作细致的分析**
- 同一成本在不同决策场景下可能分类不同
- 例如：共同成本在产能决策中可能变为相关成本

**原则2：切不可根据一般的原则进行机械的分类**
- 避免教条主义应用
- 考虑决策的具体情境和时间跨度

**原则3：区分短期与长期**
- 该分类方法特别适用于短期经营决策
- 长期决策中，更多成本可能变为相关成本

### 常见错误防范
- **错误1**：将共同成本一律视为不相关成本（在涉及产能调整或长期决策时可能相关）
- **错误2**：忽视不可延缓成本的约束条件
- **错误3**：过度简化分类，未考虑决策的具体情境

### 应用价值
- 使企业在决策中避免把精力耗费在收集无关紧要的信息上
- 减少得不偿失的劳动（信息收集成本超过信息价值）
- 将注意力集中在差别成本、机会成本等真正影响决策的因素上
