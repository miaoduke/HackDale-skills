# 成本决策分析示例

## 差量分析法示例

### 场景：自制与外购决策

**方案A：自制**
- 相关成本：直接材料 10,000元 + 直接人工 8,000元 + 变动制造费用 5,000元 = 23,000元
- 相关收入：0元

**方案B：外购**
- 相关成本：采购价格 25,000元
- 相关收入：0元

**计算过程**
```
差额收入 = 0 - 0 = 0元
差额成本 = 23,000 - 25,000 = -2,000元
差额利润 = 0 - (-2,000) = 2,000元
```

**决策结论**
差额利润 > 0，方案A（自制）优于方案B（外购），应选择自制，可节约2,000元。

## 无差别成本识别示例

### 场景：招聘决策

**备选方案**
- 方案A：招聘候选人甲
- 方案B：招聘候选人乙

**成本分析**
| 成本项目 | 方案A | 方案B | 差异 |
|---------|-------|-------|------|
| 岗前培训费 | 5,000元 | 5,000元 | 0（无差别） |
| 薪酬（年） | 80,000元 | 85,000元 | 5,000元（相关） |
| 福利费用 | 12,000元 | 12,750元 | 750元（相关） |

**决策处理**
- 岗前培训费为无差别成本，从差异分析中剔除
- 只比较薪酬和福利费用：方案A比方案B节约5,750元
- 决策：选择候选人甲

## 相关成本与不相关成本对比示例

### 场景：停产决策

**产品X的年度成本数据**
| 成本项目 | 金额 | 分类 |
|---------|------|------|
| 直接材料 | 50,000元 | 相关（可避免） |
| 直接人工 | 30,000元 | 相关（可避免） |
| 变动制造费用 | 20,000元 | 相关（可避免） |
| 固定制造费用（分摊） | 40,000元 | 不相关（不可避免） |
| 合计 | 140,000元 | - |

**决策分析**
- 若停产产品X，可避免成本 = 50,000 + 30,000 + 20,000 = 100,000元
- 固定制造费用40,000元无论是否停产都会发生，属于不相关成本
- 若产品X年收入为120,000元，则贡献毛益 = 120,000 - 100,000 = 20,000元
- 决策：不应停产（因为停产将损失20,000元贡献毛益）
