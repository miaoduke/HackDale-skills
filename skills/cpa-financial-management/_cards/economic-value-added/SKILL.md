# 经济增加值计算

## 选择计算方法

### 披露的经济增加值

**适用对象**：利用公开数据进行的外部业绩评价、市场价值分析

**数据来源**：公开财务报表及其附注

**特点**：根据公布的财务报表及其附注中的数据进行调整，据说可以解释公司市场价值变动的50%。

### 简化经济增加值

**适用对象**：
- 中央企业
- 纳入国资委考核的企业
- 银行保险证券业务企业（特殊调整）
- 境外经营企业

**特点**：国资委考核专用，有明确的会计调整规则。

## 披露的经济增加值调整规则

### 典型调整项目

1. **研究与开发费用**：作为投资并在合理期限内摊销
2. **战略性投资**：在专门账户中资本化并在开始生产时逐步摊销
3. **建立品牌/新市场/扩大市场份额费用**：资本化并在适当期限内摊销
4. **折旧费用**：对大量使用长期设备的公司，使用"沉淀资金折旧法"

## 简化经济增加值计算公式

### 核心公式

经济增加值 = 税后净营业利润 - 调整后资本 × 平均资本成本率

### 税后净营业利润计算

税后净营业利润 = 净利润 + (利息支出 + 研究开发费用调整项) × (1 - 25%)

### 调整后资本计算

调整后资本 = 平均所有者权益 + 平均带息负债 - 平均在建工程

### 平均资本成本率计算（WACC）

平均资本成本率 = 债权资本成本率 × [平均带息负债 / (平均带息负债 + 平均所有者权益)] × (1 - 25%) + 股权资本成本率 × [平均所有者权益 / (平均带息负债 + 平均所有者权益)]

## 关键会计调整项目

### 研究开发费用调整项
- 财务报表"期间费用"项下的"研发费用"
- 当期确认为无形资产的开发支出
- 特殊政策：承担关键核心技术攻关任务的研发投入，可按100%比例加回

### 在建工程扣除
- 符合业主规定的"在建工程"从调整后资本中扣除

### 利息支出与带息负债口径
- 利息支出：财务报表"财务费用"项下的"利息支出"
- 带息负债：企业带息负债情况表中的"带息负债合计"

### 境外经营企业所得税税率调整
- 企业经营业务主要在国（境）外时，25%的企业所得税税率可按实际适用税率调整

## 前提条件

- 企业财务报表数据
- 研发费用明细
- 利息支出数据
- 带息负债情况表
- 在建工程明细
- 所有者权益数据

## 输出结果

经济增加值（EVA）为绝对数指标：
- 正值：企业创造价值超过资本成本
- 负值：未能弥补资本成本
