# 固定资产更新决策的年成本比较法

## 适用场景
- 企业面临固定资产更新决策
- 新旧设备使用年限不同
- 设备更换不改变企业生产能力
- 不增加企业现金流入
- 无法使用净现值法和内含报酬率法

## 核心特征
- 设备更换并不改变企业的生产能力
- 更新决策的现金流量主要是现金流出
- 即使有少量残值变现收入，也属于支出抵减

## 排除不适用的分析方法

### 不适用净现值法(NPV)和内含报酬率法(IRR)
原因：没有适当的现金流入，无法计算净现值和内含报酬率

### 不适用总成本比较法
原因：新旧设备使用年限不同，取得的"产出"不相同，不能直接比较总成本

### 不适用差额分析法
原因：使用年限不同，差额现金流无法对应

## 年成本比较法（年均成本法）

### 核心原理
比较获得1年的生产能力所付出的代价

### 计算公式

#### 考虑货币时间价值的年均成本
```
年均成本 = [初始投资现值 + 运行成本现值 - 残值现值] / 年金现值系数
```

#### 不考虑货币时间价值的简化计算
```
平均年成本 = (初始投资成本 + 年运行成本 × 使用年限 - 残值) / 使用年限
```

### 变量说明
- 初始投资：旧设备为当前变现价值（机会成本），新设备为购置价格
- 运行成本：每年为维持设备运转发生的现金流出
- 最终残值：设备使用期满时的变现价值
- 使用年限：旧设备为剩余使用年限，新设备为全新使用年限
- 必要报酬率：企业要求的最低回报率，用于折现计算

## 决策流程

### 步骤1：采用互斥方案视角
- 方案A（旧设备）：现在用当前变现价值购置这台旧设备
- 方案B（新设备）：现在用购置价格购置新设备
- 关键：从局外人角度考虑，而非"已有旧设备"角度

### 步骤2：计算各方案年均成本
- 分别计算旧设备继续使用的年均成本
- 分别计算新设备的年均成本

### 步骤3：比较决策
- 以年成本较低者作为好方案
- 不可直接比较总成本现值，因为年限不同

## 决策规则
选择年均成本较低的方案作为最优更新决策方案
