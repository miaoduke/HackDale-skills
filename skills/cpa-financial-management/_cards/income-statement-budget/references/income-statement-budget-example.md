# 利润表预算示例

## 预算表示例

| 项目 | 金额 |
|------|------|
| 销售收入 | 126,000 |
| 销货成本 | 56,700 |
| 毛利 | 69,300 |
| 销售费用 | 20,000 |
| 管理费用 | 10,000 |
| 借款利息 | 2,500 |
| 利润总额 | 36,800 |
| 所得税费用 | 9,200（估计值） |
| 净利润 | 27,600 |

## 循环逻辑说明

### 错误做法

```
利润总额 = 36,800
↓
所得税 = 36,800 × 25% = 9,200
↓
修改现金预算中的所得税
↓
借款计划变化
↓
借款利息变化
↓
利润总额变化
↓
需要重新计算所得税
（循环往复）
```

### 正确做法

```
利润预测时估计所得税 = 9,200
↓
列入现金预算
↓
确定借款计划和利息
↓
计算利润总额
↓
直接使用估计的所得税
↓
计算净利润
（避免循环）
```

## 适用范围

- 适用于：内部管理预算、全面预算编制
- 不适用于：对外报送的法定财务报表编制、无纳税调整事项的简单税务计算
