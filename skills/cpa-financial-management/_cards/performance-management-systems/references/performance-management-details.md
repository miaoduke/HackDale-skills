# 绩效管理系统详细参考

## 经济增加值（EVA）计算

### EVA公式
```
EVA = NOPAT - (WACC × 投资资本)
```
- NOPAT：税后净营业利润
- WACC：加权平均资本成本
- 投资资本：债务资本 + 权益资本

### EVA与传统指标对比

| 指标 | 是否考虑权益资本成本 | 是否反映价值创造 |
|------|-------------------|----------------|
| 净利润 | 否 | 否 |
| ROE | 否 | 部分 |
| EVA | 是 | 是 |

## 绩效柱模型指标配置

### 利益相关者满意构面
- 投资者：总资产报酬率、净资产收益率、派息率、资产负债率、流动比率
- 员工：员工满意度、工资收入增长率、人均工资
- 客户：客户满意度、客户投诉率
- 供应商：逾期付款次数
- 监管机构：社会贡献率、资本保值增值率

### 企业战略构面
- 投资者：可持续增长率、资本结构、研发投入比率
- 员工：员工职业规划、员工福利计划
- 客户：品牌意识、客户增长率
- 监管机构：政策法规认知度、企业的环保意识

### 业务流程构面
- 投资者：标准化流程比率、内部控制有效性
- 员工：员工培训有效性、培训费用支出率
- 客户：产品合格率、准时交货率
- 供应商：环保投入率、供应商的稳定性

### 组织能力构面
- 投资者：总资产周转率、管理水平评分
- 员工：员工专业技术水平、人力资源管理水平
- 客户：售后服务水平、市场管理水平
- 供应商：采购折扣率水平、供应链管理水平

### 利益相关者贡献构面
- 投资者：融资成本率
- 员工：员工生产率、员工保持率
- 客户：客户忠诚度、客户毛利水平
- 供应商：供应商产品质量水平、按时交货率

## 平衡计分卡实施步骤

1. **阐明战略**：明确企业愿景和战略目标
2. **沟通与连接**：将战略传达给全体员工
3. **业务规划**：将战略目标与业务计划整合
4. **反馈与学习**：定期评估战略执行情况并调整

## 战略地图四个层面

1. **财务层面**：股东如何看待我们？
2. **客户层面**：客户如何看待我们？
3. **内部流程层面**：我们擅长什么？
4. **学习与成长层面**：我们能否持续创造价值？
