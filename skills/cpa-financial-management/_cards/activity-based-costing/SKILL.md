# 作业成本法（ABC）实施

## 适用场景
- 制造费用包含多种不同性质的间接费用
- 多数费用不随产量变动
- 传统单一分配基础导致成本扭曲
- 需要更精确的产品成本信息

## 核心原理

### 基本指导思想
"作业消耗资源、产品（或服务）消耗作业"

### 分配路径对比
- **作业成本法**：资源 → 作业 → 产品
- **传统方法**：资源 → 部门 → 产品

## 两阶段分配流程

### 第一阶段：资源到作业

**目标**：将作业执行中耗费的资源进行分配

**分配方式**：
- **追溯**：对于可直接归属的资源消耗直接计入
- **间接分配**：对于间接资源消耗按动因分配

**输出**：得出各作业的成本

### 第二阶段：作业到产品

**目标**：将作业成本分配到各成本对象

**分配方式**：
- **追溯**：对于可直接追溯的作业成本
- **动因分配**：按作业成本动因分配

**输出**：各产品或服务的精确成本

## 资源成本动因分配

### 定义
资源成本动因是作业成本增加的驱动因素，用来衡量一项作业的资源消耗量

### 直接归属处理
对于可以直接归属于特定作业的资源成本，直接计入该作业成本
- 示例：检验人员工资、专用设备折旧费

### 间接资源分配（以能源成本为例）

**步骤1：确定动因**
"设备的额定功率 × 开动时间"是能源成本的动因

**步骤2：获取数据**
- 设备额定功率
- 设备开动时间

**步骤3：计算动因数量**
```
动因数量 = 设备额定功率 × 设备开动时间
```

**步骤4：分配成本**
按动因数量比例将能源成本分配到检验作业

## 作业成本动因分配

### 定义
作业成本动因是衡量一个成本对象需要的作业量，是产品成本增加的驱动因素

### 执行步骤

**步骤1：确定动因**
识别导致作业消耗的因素
- 示例：检验的"次数"是检验作业的成本动因

**步骤2：计算单位作业成本**
```
每次检验成本 = 检验作业总成本 ÷ 检验总次数
```

**步骤3：分配成本至成本对象**
```
某种产品应承担的检验作业成本 = 该种产品的批次 × 每次检验成本
```

## 作业成本分配至成本对象

### 核心步骤

**步骤1：计算单位作业成本（作业分配率）**
```
单位作业成本 = 本期作业成本库归集的总成本 ÷ 作业量
```

**步骤2：计算成本对象应负担的作业成本**
```
某产品应分配的作业成本 = 单位作业成本 × 该产品耗用的作业量
```

## 作业动因类型选择

### 业务动因（以执行次数计量）

**适用条件**：
- 每次作业执行成本相等
- 不同产品所需作业时间差异不大

**计算公式**：
```
分配率 = 归集期内作业成本总成本 ÷ 归集期内总作业次数
某产品应分配的作业成本 = 分配率 × 该产品耗用的作业次数
```

### 持续动因（以执行时间计量）

**适用条件**：
- 不同产品所需作业量差异较大
- 检验不同产品所耗用的时间长短差别较大

**计算公式**：
```
分配率 = 归集期内作业总成本 ÷ 归集期内总作业时间
某产品应分配的作业成本 = 分配率 × 该产品耗用的作业时间
```

**决策逻辑**：
- 时间差异小 → 使用业务动因（计算简便）
- 时间差异大 → 必须使用持续动因（保证准确性）

## 多维成本动因优势

### 传统方法局限性
- 将产量视为解释产品成本变动的唯一动因
- 用单一量作为分配制造费用的基础
- 制造费用由多种不同性质的间接费用组成
- 多数费用并不随产量变动

### 作业成本法改进
- **第一步**：资源消耗追溯/分配到作业
- **第二步**：使用不同层面和数量众多的作业动因将作业成本分配到产品
- **"不同层面"**：单位级、批次级、产品级、设施级等
- **"数量众多"**：针对不同类型的作业采用相应的动因

### 优势
- 更加合理
- 更能保证产品成本计算的准确性
- 避免传统方法下产量高产品成本虚高、产量低产品成本虚低的问题
