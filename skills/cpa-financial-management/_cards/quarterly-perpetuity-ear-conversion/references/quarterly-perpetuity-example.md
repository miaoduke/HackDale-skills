# 季度支付永续年金计算示例

## 问题背景
某优先股每季度支付股息 2 元，有效年利率（EAR）为 6%，求该优先股的理论价值。

## 详细计算过程

### 步骤 1：问题识别
- **现金流特征**：每季度支付 2 元（非年度支付）
- **利率特征**：给定的 6% 是年利率（有效年利率 EAR）
- **关键矛盾**：支付频率（季度）与利率周期（年度）不匹配，不能直接套用年度公式

### 步骤 2：周期利率转换（核心步骤）

使用有效年利率（EAR）公式倒推周期利率 r：

```
EAR = (1 + r)^m - 1
```

**已知条件**：
- EAR = 6% = 0.06
- m = 4（每年季度数）

**建立方程**：
```
(1 + r)^4 - 1 = 6%
(1 + r)^4 = 1.06
```

**求解**：
```
1 + r = 1.06^(1/4) = 1.014673...
r = 1.467% ≈ 1.47%
```

因此，季度利率 r ≈ 1.47%

### 步骤 3：永续年金现值计算

现在支付频率与利率周期匹配（均为季度）：

```
P = 季度支付额 ÷ 季度利率
P = 2 ÷ 1.47%
P = 2 ÷ 0.0147
P = 136.054...
```

**结果**：136.05 元

## 结果分析与对比

### 与年度支付的比较
- 季度支付情况的现值：**136.05 元**
- 年度支付情况的现值：**133.33 元**（假设年支付 8 元，年利率 6%）

### 为什么季度支付现值更高？

虽然每年总股息相同（都是 8 元），但季度支付意味着：
1. 投资者可以更早收到部分现金（时间价值原理）
2. 从复利角度看，季度利率 1.47% 换算的有效年利率正好是 6%，但季度支付的现金流结构使得现值略高

### 精确验证

如果按精确季度利率 1.4667% 计算：
```
2 ÷ 0.014667 = 136.36
```

教材使用 1.47% 近似值得到 136.05，两者差异源于四舍五入。

## 公式总结

### 有效年利率转周期利率
```
r = (1 + EAR)^(1/m) - 1
```

### 永续年金现值
```
P = PMT / r
```

其中：
- PMT = 每期支付金额
- r = 与支付频率匹配的周期利率

## 适用场景扩展

此方法同样适用于：
- 月度支付永续年金（m=12）
- 半年度支付永续年金（m=2）
- 其他支付频率与利率周期不匹配的情况
