# 季度现金流永续年金与有效年利率转换

## 使用场景
当遇到以下情况时使用此技能：
- 永续年金或优先股按季度支付
- 给定的是有效年利率（EAR），而非季度利率
- 支付频率（季度）与利率周期（年度）不匹配

## 核心步骤

### 1. 识别问题
确认以下信息：
- 每期支付金额（季度支付额）
- 有效年利率（EAR）
- 每年支付期数（m=4，表示季度）

### 2. 转换周期利率
使用有效年利率公式倒推季度利率 r：

```
EAR = (1 + r)^m - 1
```

求解步骤：
1. (1 + r)^m = 1 + EAR
2. 1 + r = (1 + EAR)^(1/m)
3. r = (1 + EAR)^(1/m) - 1

### 3. 计算永续年金现值
使用匹配的周期利率计算：

```
现值 = 季度支付额 ÷ 季度利率
```

## 关键约束
- 必须先将年利率转换为季度利率，不能直接使用年利率
- 假设利率为复利计算
- 支付频率必须与计算出的周期利率严格匹配

## 常见错误
- 直接使用年利率计算季度支付年金
- 使用简单除法（EAR/4）而非复利公式转换利率
