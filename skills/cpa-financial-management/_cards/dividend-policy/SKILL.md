# 股利政策

## 适用场景
- 制定或调整股利分配政策
- 评估股利支付的法律限制
- 分析股东因素对股利政策的影响
- 理解股利政策与企业价值的关系

## 核心内容

### 1. 一鸟在手理论

**理论基础：**
- 股东投资收益来自当期股利和资本利得
- 核心问题：在当期股利收益与未来预期资本利得之间权衡

**核心比喻：**
- "林中之鸟"：资本利得好像林中之鸟，看上去很多但不一定抓得到（未来价值不确定）
- "在手之鸟"：现金股利好像在手之鸟，是股东有把握按时、按量得到的现实收益
- 理论名称："一鸟在手，强于二鸟在林"

**股东偏好结论：**
- 由于经营存在不确定性，股东认为现金股利比未来资本利得更可靠
- 股东更偏好现金股利而非资本利得
- 倾向于选择股利支付率高的股票

**风险与资本成本关系：**
```
高股利支付率 → 股东承担风险小 → 权益资本成本低 → 企业权益价值上升
低股利支付率 → 股东承担风险大 → 权益资本成本高 → 企业权益价值下降
```

**企业权益价值公式：**
```
企业权益价值 = 分红总额 / 权益资本成本
```

**政策启示：** 为实现股东价值最大化，企业应实行高股利分配率的股利政策

### 2. 股利支付的限制与影响因素

**法律限制检查（无力偿付限制）：**
```
IF (公司已经无力偿付负债) OR (股利支付会导致公司失去偿债能力)
THEN 禁止支付股利
```
核心依据：对债权人利益保护

**股东因素分析：**

1. **稳定的收入和避税需求：**
   - 依赖股利型股东：要求支付稳定股利，反对留存较多利润
   - 高边际税率股东：出于避税考虑，反对发放较多股利

2. **控制权的稀释：**
   - 逻辑链条：支付较高股利 → 留存盈余减少 → 发行新股可能性加大 → 控制权稀释
   - 决策倾向：拥有控制权的股东若不愿稀释控制权，倾向于不分配股利

**公司因素分析：**

1. **盈余的稳定性：**
   - 盈余相对稳定的公司具有较高的股利支付能力
   - 盈余稳定的公司对保持较高股利支付率更有信心
   - 收益稳定的公司面临的经营风险和财务风险较小，筹资能力较强

## 决策要点
- 一鸟在手理论基于股东风险厌恶假设
- 高股利支付率可降低权益资本成本、提升企业权益价值
- 法律限制优先于股利支付决策
- 股东的税收状况和控制权考虑影响股利政策偏好
- 盈余稳定性是股利决策的重要基础
