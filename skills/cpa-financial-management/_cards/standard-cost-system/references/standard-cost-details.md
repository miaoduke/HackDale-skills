# 标准成本系统详细说明

## 直接材料标准成本计算示例

### 已知条件（A产品）

**甲材料**：
- 图纸用量：3千克
- 允许损耗量：0.3千克
- 发票单价：1.00元/千克
- 装卸检验费：0.07元/千克

**乙材料**：
- 图纸用量：2千克
- 允许损耗量：0千克
- 发票单价：4.00元/千克
- 装卸检验费：0.28元/千克

### 计算过程

**甲材料**：
- 单产标准用量：3 + 0.3 = 3.3千克
- 每千克标准价格：1.00 + 0.07 = 1.07元
- 成本标准：3.3 × 1.07 = 3.53元

**乙材料**：
- 单产标准用量：2 + 0 = 2千克
- 每千克标准价格：4.00 + 0.28 = 4.28元
- 成本标准：2 × 4.28 = 8.56元

**单位产品直接材料标准成本**：3.53 + 8.56 = 12.09元

## 直接人工标准成本计算示例

### 已知条件
- 单位产品标准工时：10小时
- 月工资总额：20,000元
- 每人每月工时：25.5天 × 8小时 = 204小时
- 出勤率：95%
- 人数：5人

### 计算过程

**可用工时总量**：204 × 95% × 5 = 969小时

**标准工资率**：20,000 ÷ 969 = 20.64元/小时

**单位产品直接人工标准成本**：10 × 20.64 = 206.4元

## 直接人工差异分析示例

### 已知条件
- 实际产量：1,000件
- 单位产品标准工时：10小时
- 标准工资率：20元/小时
- 实际工时：9,500小时
- 实际工资率：21元/小时

### 计算过程

**标准直接人工成本**：1,000 × 10 × 20 = 200,000元

**实际直接人工成本**：9,500 × 21 = 199,500元

**总差异**：199,500 - 200,000 = -500元 (F)

**工资率差异**：9,500 × (21 - 20) = 9,500元 (U)

**效率差异**：(9,500 - 10,000) × 20 = -10,000元 (F)

**验证**：9,500 + (-10,000) = -500元 ✓

## 标准成本账务处理

### 材料成本差异
```
借：生产成本（标准成本）
    材料成本差异（超支）
  贷：原材料（实际成本）
      材料成本差异（节约）
```

### 人工成本差异
```
借：生产成本（标准成本）
    直接人工工资率差异（超支）
    直接人工效率差异（超支）
  贷：应付职工薪酬（实际成本）
      直接人工工资率差异（节约）
      直接人工效率差异（节约）
```
