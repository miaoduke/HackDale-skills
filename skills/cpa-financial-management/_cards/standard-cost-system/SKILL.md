# 标准成本系统实施

## 适用场景
- 企业决定实施标准成本法
- 需要进行成本控制
- 需要进行差异分析和绩效评价
- 具备制定标准成本的技术能力

## 标准成本制定总体流程

### 制定顺序
按以下顺序确定：
1. 直接材料的标准成本
2. 直接人工的标准成本
3. 制造费用的标准成本
4. 汇总确定单位产品的标准成本

### 核心公式
```
单位产品标准成本 = 直接材料标准成本 + 直接人工标准成本 + 制造费用标准成本
```

## 成本项目标准成本制定

### 核心公式
```
成本项目的单位产品标准成本 = 用量标准 × 价格标准
```

### 直接材料标准成本

**用量标准确定**：
- 采用统计方法、工业工程法或其他技术分析方法
- 在"现有技术条件"下生产单位产品所需的材料数量
- 必须包括：
  - 必不可少的消耗（图纸理论用量）
  - 各种"难以避免的损失"（工艺性损耗、正常废品等）

**价格标准确定**：
- 预计"下一年度"需要支付的进料单位成本
- 必须是"取得材料的完全成本"，包括：
  - 发票价格
  - 运费（或装卸费）
  - 检验费
  - 正常损耗成本

### 直接人工标准成本

**用量标准（单位产品标准工时）确定**：
- 在现有生产技术条件下，生产单位产品所需要的时间
- 必须包含：
  - 直接加工操作必不可少的时间
  - 必要的间歇和停工（工间休息、设备调整准备时间）
  - 不可避免的废品耗用工时

**价格标准（标准工资率）确定**：
- **计件工资制**：预定的每件产品支付的工资 ÷ 标准工时，或直接使用预定的小时工资
- **月工资制**：月工资总额 ÷ 可用工时总量

### 价格标准制定主体

**主导部门**：会计部门和有关其他部门共同研究确定

**具体责任分工**：
- 材料价格：采购部门
- 小时工资率：人力资源部门
- 小时制造费用分配率：各生产车间

## 标准成本法实施六步骤流程

### 步骤1：制定单位产品标准成本
通过精确的调查、分析与技术测定，确定单位产品的材料、人工、制造费用标准消耗量和标准单价

### 步骤2：计算产品的标准成本
```
标准成本（总额） = 实际产量 × 单位产品标准成本
```

### 步骤3：汇总计算实际成本
收集生产过程中的实际耗费数据，按实际产量计算实际发生的总成本

### 步骤4：计算标准成本与实际成本的差异
将标准成本总额与实际成本总额进行对比，计算总差异，并按成本项目分解差异

### 步骤5：分析成本差异发生的原因
- 对每项差异进行定量与定性分析
- 区分价格差异与数量差异（或效率差异）
- 追溯差异产生的责任部门与原因
- 若将标准成本纳入账簿体系，进行账务处理

### 步骤6：向成本负责人提供成本控制报告
编制包含差异分析、原因诊断、改进建议的正式报告

## 直接人工成本差异分析

### 第一层：总差异公式
```
直接人工成本差异 = 实际直接人工成本 - 标准直接人工成本
```
- 结果为正数表示不利差异(U)
- 结果为负数表示有利差异(F)

### 第二层：差异分解公式

**直接人工工资率差异（价差）**：
```
工资率差异 = 实际工时 × (实际工资率 - 标准工资率)
```

**直接人工效率差异（量差）**：
```
效率差异 = (实际工时 - 标准工时) × 标准工资率
```

### 第三层：平衡验算公式
```
直接人工成本差异 = 工资率差异 + 效率差异
```

## 直接人工差异责任归属

### 工资率差异（Price Variance）

**主责部门**：人力资源部门

**具体成因**：
1. 人员等级变动（升级或降级使用）
2. 奖励制度未产生实效
3. 工资率调整（法定最低工资上调、集体谈判结果）
4. 加班或使用临时工
5. 出勤率变化

### 效率差异（Efficiency Variance）

**主责部门**：生产部门

**具体成因**：
1. 工作环境不良
2. 工人经验不足或劳动情绪不佳
3. 机器或工具选用不当、设备故障较多
4. 生产计划安排不当
5. 产量规模太小无法发挥经济批量优势

**重要例外**：材料质量不高也会影响生产效率，此情况应追溯至采购部门

## 分析流程建议

1. 确认差异类型（工资率差异或效率差异）
2. 根据成因清单逐项排查
3. 区分可控因素与不可控因素
4. 对跨部门因素进行联合调查
5. 制定改进措施时明确主责部门与配合部门
