# 项目财务杠杆调整与贝塔系数转换

## 适用场景
- 新项目投资评估中需要估算权益资本成本
- 跨行业多元化项目的风险调整
- 可比公司法估值中资本结构差异调整

## 核心流程

### 第一步：卸载可比公司财务杠杆（去杠杆化）
剔除可比公司现有资本结构中的财务风险，得到仅反映行业经营风险的资产贝塔。

**公式：**
```
β_资产 = β_权益(可比公司) ÷ [1 + (1 - T) × (D/E)_可比]
```

### 第二步：加载目标项目财务杠杆（加杠杆）
根据项目自身的目标资本结构重新添加财务风险。

**公式：**
```
β_权益(项目) = β_资产 × [1 + (1 - T) × (D/E)_项目]
```

## 关键假设
- 可比公司与目标项目具有相同的经营风险（业务类型、资产风险相同）
- 债务无风险或风险可忽略
- 所得税税率在卸载和加载过程中保持一致

## 输出结果
经财务杠杆调整后的项目权益贝塔系数 β_权益(项目)，用于后续计算股东权益资本成本。

## 决策规则
- 若 β_权益(项目) > β_资产：表明财务杠杆增加了系统风险
- 负债比例越高，权益贝塔越大
