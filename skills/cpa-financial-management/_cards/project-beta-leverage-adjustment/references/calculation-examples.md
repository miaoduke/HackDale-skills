# 贝塔系数调整计算示例

## 完整示例：A公司进入飞机制造业

### 已知条件
- **可比公司B**：β_权益 = 1.2，净负债/权益 = 7/10，所得税税率 = 30%
- **目标公司A**：目标净负债/权益 = 2/3，所得税税率 = 30%

### 步骤一：卸载B公司杠杆
```
β_资产 = 1.2 ÷ [1 + (1-30%) × (7/10)]
       = 1.2 ÷ [1 + 0.7 × 0.7]
       = 1.2 ÷ 1.49
       = 0.8054
```

### 步骤二：加载A公司杠杆
```
β_权益 = 0.8054 × [1 + (1-30%) × (2/3)]
       = 0.8054 × [1 + 0.7 × 0.6667]
       = 0.8054 × 1.4667
       = 1.1813
```

### 结果解读
A公司飞机制造项目的权益贝塔为 **1.1813**，既包含行业经营风险（0.8054），也包含A公司目标资本结构的财务风险溢价（约0.3759）。

## 变量定义表

| 变量 | 符号 | 说明 |
|------|------|------|
| 可比公司权益贝塔 | β_权益(可比) | 含可比公司自身财务杠杆 |
| 资产贝塔 | β_资产 | 无杠杆贝塔，仅反映资产经营风险 |
| 项目权益贝塔 | β_权益(项目) | 含项目目标财务杠杆 |
| 企业所得税税率 | T | 百分比形式，如30% |
| 可比公司负债权益比 | (D/E)_可比 | 净负债与股东权益比率 |
| 项目目标负债权益比 | (D/E)_项目 | 目标资本结构下的比率 |

## 理论基础

本调整过程基于 **MM理论 with taxes**，即哈马达方程（Hamada Equation）：

```
β_权益 = β_资产 × [1 + (1-T) × D/E]
```

该公式揭示了财务杠杆与系统风险之间的定量关系：负债通过税盾效应和固定偿付义务放大权益持有人的风险暴露。
