|---------|---------|-----------|

| 新西兰 | NZD | 1 NZD = 0.60 USD |

## 特殊情况：美国的混合标价

美国对部分货币采用直接标价法：
- 对英镑：1 GBP = X USD（直接标价，历史惯例）
- 对欧元：1 EUR = X USD（直接标价）
- 对其他货币：1 USD = X 外币（间接标价）

## 标价法的历史渊源

- **直接标价法**：源于金本位时期"应付"黄金的实物交割思维，即买入外币需"支付"多少本币
- **间接标价法**：源于英国作为国际金融中心的历史地位，强调"应收"多少外币

## 实务中的交叉汇率计算

当两种货币均采用直接标价法时，交叉汇率计算：

```
已知：1 USD = 7.20 CNY，1 USD = 145 JPY
求：1 CNY = ? JPY

解：1 CNY = 145 / 7.20 = 20.14 JPY
```

当涉及间接标价法时，注意倒数转换：

```
已知：1 GBP = 1.25 USD，1 USD = 7.20 CNY
求：1 GBP = ? CNY

解：1 GBP = 1.25 × 7.20 = 9.00 CNY
```
