# 杜邦分析示例

## 基础数据（ABC公司）
- 上年权益净利率 = 5.614% × 1.6964 × 1.9091 = 18.18%
- 本年权益净利率 = 4.533% × 1.5 × 2.0833 = 14.17%
- 总变动额 = 14.17% - 18.18% = -4.01%

## 连环替代法计算

### 营业净利率变动影响
按本年营业净利率计算的上年权益净利率 = 4.533% × 1.6964 × 1.9091 = 14.68%
影响值 = 14.68% - 18.18% = -3.5%

### 总资产周转次数变动影响
按本年营业净利率和本年周转次数计算的上年权益净利率 = 4.533% × 1.5 × 1.9091 = 12.98%
影响值 = 12.98% - 14.68% = -1.7%

### 权益乘数变动影响
本年权益净利率 = 4.533% × 1.5 × 2.0833 = 14.17%
影响值 = 14.17% - 12.98% = +1.19%

## 分析结论
- 营业净利率下降导致权益净利率下降3.5%（主要不利因素）
- 总资产周转次数下降导致权益净利率下降1.7%
- 权益乘数上升导致权益净利率上升1.19%（有利因素）
- 综合影响：-3.5% - 1.7% + 1.19% = -4.01%
