# 营运资本管理详细示例

## ABC公司营运资本配置分析实例

### 数据对比

| 项目 | 上年末 | 本年末 | 变动金额 | 变动幅度 |
|:---|:---|:---|:---|:---|
| 流动资产 | 610万元 | 700万元 | +90万元 | +15% |
| 流动负债 | 220万元 | 300万元 | +80万元 | +36% |
| 营运资本 | 390万元 | 400万元 | +10万元 | +2.6% |
| 营运资本配置比率 | 64% | 57% | - | -7个百分点 |

### 分析结论
1. 绝对数视角：营运资本从390万元增至400万元，"缓冲垫"绝对增厚10万元
2. 相对数视角：营运资本配置比率从64%降至57%，偿债能力实际下降
3. 核心原因：流动负债增长速度（36%）超过流动资产增长速度（15%）
4. 本质洞察：债务的"穿透力"增加，偿债能力降低

## 现金随机模式完整示例

### 已知条件
- 有价证券年利率 = 9%，日利率i = 9% ÷ 360 = 0.025%
- 每次固定转换成本b = 50元
- 现金余额下限L = 1000元
- 现金余额波动标准差δ = 800元

### 计算过程
```
R = ∛[(3×50×800²)/(4×0.025%)] + 1000
  = ∛[(3×50×640000)/(0.001)] + 1000
  = ∛[96000000/0.001] + 1000
  = ∛[96000000000] + 1000
  = 4579 + 1000 = 5579元

H = 3×5579 - 2×1000 = 16737 - 2000 = 14737元
```

### 操作执行
- 当现金余额达到14737元时：以9158元现金投资于有价证券
- 当现金余额降至1000元时：转让4579元有价证券换回现金
