# 营运资本管理

## 适用场景
- 评估营运资本政策变化对短期偿债能力的影响
- 确定营运资本的最佳投资量
- 现金需求波动大且难以预知时的现金持有量控制
- 利用信息技术优化应收账款、存货和应付账款管理

## 核心流程

### 1. 营运资本配置比率分析

**计算公式：**
```
营运资本配置比率 = 营运资本 ÷ 流动资产
```

**分析步骤：**
1. 计算本期和上期的营运资本配置比率
2. 计算流动资产、流动负债、营运资本的增长率
3. 对比绝对数变动和相对比率变动
4. 判断短期偿债能力变化趋势

**关键洞察：**
- 比率越高，流动资产中由长期资本提供的部分越多，短期偿债压力越小
- 即使营运资本绝对数增加，若流动负债增长率超过流动资产增长率，偿债能力仍可能下降

### 2. 适中型营运资本投资策略

**决策原则：**
- 最佳投资量使"短缺成本"和"持有成本"之和最小化
- 适中型策略要求短缺成本和持有成本大体相等

**权衡分析：**
- 投资较少：节约成本但增加短缺风险
- 投资较多：降低风险但增加持有成本

### 3. 现金持有量随机模式控制

**适用条件：**
- 现金需求量波动大且难以预知
- 无法准确预测未来现金收支总量

**计算步骤：**

1. **确定基础参数：**
   - 下限L：根据最低现金需要和风险承受倾向确定
   - 固定转换成本b：每次有价证券交易的固定成本
   - 日利息率i：年利率 ÷ 360
   - 标准差δ：历史现金余额波动的标准差

2. **计算现金返回线R：**
```
R = ∛(3bδ²/4i) + L
```

3. **计算控制上限H：**
```
H = 3R - 2L
```

4. **执行动态控制：**
   - 现金余额达到H时：用现金购入有价证券，金额 = 当前余额 - R
   - 现金余额降至L时：抛售有价证券换回现金，金额 = R - 当前余额
   - 现金余额在L和H之间：不进行转换操作

### 4. 信息技术驱动的动态优化

**应收账款管理：**
- 集成CRM和ERP系统
- 实时跟踪客户信用状况和付款行为
- 自动触发差异化催收策略

**存货管理：**
- 利用物联网实现库存实时可视
- 结合需求预测算法
- 实施"按需生产、精准补货"

**应付账款管理：**
- 分析现金流预测、合同条款和投资机会
- 动态优化付款时机
- 存在现金折扣时优先提前付款

## 决策要点
- 营运资本分析必须同时关注绝对数和相对比率
- 随机模式计算结果较为保守，可能导致现金持有量偏高
- 适中型策略适用于风险中性企业
- 信息技术应用需要CRM、ERP、物联网等数字化基础
