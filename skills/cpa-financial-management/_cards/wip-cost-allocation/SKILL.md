# 完工产品与在产品成本分配

## 适用场景
- 需要计算本月产成品成本
- 月末存在在产品
- 需要在完工产品和在产品之间分配生产费用

## 基本平衡公式

### 费用构成
本月产成品成本由"月初在产品成本"和"本月发生生产费用"两部分组成。

### 平衡公式
```
月初在产品成本 + 本月发生生产费用 = 本月完工产品成本 + 月末在产品成本
```

### 完工产品成本计算
```
本月完工产品成本 = 月初在产品成本 + 本月发生生产费用 - 月末在产品成本
```

## 分配方法选择

### 方法一：比例分配法
将前两项之和（月初在产品成本 + 本月发生生产费用）按一定比例在后两项（本月完工产品成本、月末在产品成本）之间进行分配。

### 方法二：扣除分配法
先确定月末在产品成本，再利用公式倒挤计算求得完工产品的成本。

## 具体分配方法

### 场景A：定额成本法

**适用条件**：如果在产品数量稳定或者数量较少，并且制定了比较准确的定额成本。

**计算步骤**：
1. 确定各加工阶段在产品的定额单位成本
2. 计算月末在产品成本 = 月末在产品数量 × 在产品定额单位成本
3. 计算产成品总成本 = (月初在产品成本 + 本月发生费用) - 月末在产品成本
4. 计算产成品单位成本 = 产成品总成本 / 产成品产量

**合规调整**：根据财政部《企业产品成本核算制度（试行）》，期末应当将定额成本调整为实际成本。

### 场景B：定额比例法

**适用条件**：如果各月末在产品数量变动较大，但制定了比较准确的消耗定额。

**材料费用分配**（通常按定额消耗量比例）：
```
材料费用分配率 = (月初在产品实际成本 + 本月投入的实际材料成本) / (完工产品定额材料成本 + 月末在产品定额材料成本)
完工产品应分配的材料成本 = 完工产品定额材料成本 × 材料费用分配率
月末在产品应分配的材料成本 = 月末在产品定额材料成本 × 材料费用分配率
```

**工资及制造费用分配**（通常按定额工时比例）：
```
工资费用（或制造费用）分配率 = (月初在产品实际工资/费用 + 本月投入实际工资/费用) / (完工产品定额工时 + 月末在产品定额工时)
完工产品应分配的工资费用（或制造费用） = 完工产品定额工时 × 工资费用（或制造费用）分配率
月末在产品应分配的工资费用（或制造费用） = 月末在产品定额工时 × 工资费用（或制造费用）分配率
```

### 场景C：约当产量法（加权平均法）

**适用条件**：采用加权平均法核算成本。

**计算步骤**：
1. 计算在产品约当产量 = 在产品数量 × 完工程度
2. 计算单位成本（分配率）= (月初在产品成本 + 本月发生生产费用) / (完工产品产量 + 月末在产品约当产量)
3. 分配完工产品成本 = 单位成本 × 完工产品产量
4. 分配月末在产品成本 = 单位成本 × 月末在产品约当产量

**完工程度确定**：
- 一般情况：根据月末在产品数量，用技术测定等方法计算
- 具备工时定额时：(前面各工序工时定额之和 + 本工序工时定额 × 50%) / 产品工时总定额 × 100%
- 简化核算：各工序内部在产品加工程度不同时，按平均完工程度50%计算

**原材料费用特殊处理**：
- 一次投入：直接按数量比例，不计算约当产量
- 陆续投入：按各工序投入的累计材料费用比例计算投料程度约当产量

## 会计处理

### 产成品入库
将完工入库产成品的成本从"生产成本"科目贷方转入"产成品"科目借方。

### 自制材料/工具
将完工自制材料、工具、模具等的成本转入"原材料"等科目借方。

### 在建工程劳务
将在建工程提供的劳务费用（不论是否完工）转入"在建工程"科目借方。

### 期末余额确认
"生产成本——基本生产成本"科目月末余额即为基本生产车间在产品的成本。

## 决策输出
获得月末在产品成本、产成品总成本及单位成本数值，并完成相应的会计账务处理。
