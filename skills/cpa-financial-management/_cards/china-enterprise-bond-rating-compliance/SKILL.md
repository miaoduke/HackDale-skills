# 中国企业债券信用评级合规指南

## 适用场景与触发条件

当中国企业计划**向社会公开发行企业债券**（非私募）时，根据中国人民银行规定，必须经由中国人民银行认可的资信评级机构进行信用评级并评定信用级别。本技能指导完成从机构选择到评级报告获取的全流程合规操作。

**立即使用本技能当用户询问：**
- "公开发行企业债券需要什么评级要求？"
- "中国人民银行认可的评级机构有哪些资质要求？"
- "如何准备债券评级的五大维度材料？"
- "企业债券评级流程是什么？"

## 监管前提与约束检查

**必须满足以下条件：**
- [ ] 债券类型：向社会公开发行的企业债券（非私募发行）
- [ ] 发行地点：中国境内市场
- [ ] 评级机构：必须获得中国人民银行认可资质

**不适用场景（停止并提示用户）：**
- 非公开发行（私募）企业债券（可能不适用强制评级要求）
- 境外发行的债券（适用发行地监管规则）
- 国债、金融债等非企业债券（适用不同监管规定）

## 评级执行流程

### 步骤一：委托合规评级机构
- 核实评级机构具备中国人民银行认可的资信评级资质（评信机构资格）
- 未经中国人民银行认可的机构出具的评级结果不符合监管要求
- 签署委托评级协议，明确评级范围、时间安排及双方权责

### 步骤二：组建项目组开展尽职调查
- 评级机构组建专项项目组，配备具备行业经验的分析师
- 开展现场尽职调查：实地考察生产经营场所、访谈管理层
- 开展非现场调查：收集审计报告、财务数据、项目批文、合同文件
- 验证资料真实性，识别重大风险事项

### 步骤三：五大维度综合评分
依据监管要求，从以下五个维度进行系统评估：

1. **企业素质**：公司治理、管理水平、内部控制、行业地位
2. **财务质量**：报表质量、资产负债结构、盈利能力、偿债指标
3. **项目状况**：募投项目进度、资金使用计划、合规手续完备性
4. **项目前景**：市场需求预测、收益产生能力、现金流覆盖
5. **偿债能力**：整体债务负担、现金流覆盖倍数、外部支持

*详细评分标准与计算公式详见 references/rating-dimensions-details.md*

### 步骤四：评审委员会确定信用等级
- 召开内部评审委员会会议，由资深分析师和行业专家参与
- 综合五大维度评分进行加权计算
- 确定最终信用等级（通常采用三等九级：AAA/AA/A/BBB/BB/B/CCC/CC/C）
- 形成评级报告初稿，内部复核合规性

### 步骤五：出具报告并向监管部门报备
- 出具正式信用评级报告，包含评级观点、等级符号、风险提示
- 向中国人民银行及相关债券市场监管部门报备评级结果
- 获取信用级别评定报告，作为债券公开发行申请的必要文件

## 评级结果应用与影响

**发行必要条件**：
- 信用评级报告是债券获得公开发行批准的**必备前置文件**
- 无有效评级报告，监管部门不予受理公开发行申请

**定价基准功能**：
- 信用等级直接决定发行利率区间：AAA级通常较基准利率上浮较少，低等级债券需提高利率补偿风险
- 等级越低，投资者要求的信用利差越大

**持续监管要求**：
- 评级机构需在债券存续期内进行**跟踪评级**（通常每年一次）
- 发生重大事项时需进行不定期跟踪评级
- 等级调整将触发债券价格波动和投资者保护条款

## 关键变量核查清单

在提交评级申请前，确认以下核心评估要素已准备充分：

**企业素质维度**：
- [ ] 公司章程、股东会/董事会/监事会议事规则
- [ ] 近三年高管变动情况及简历
- [ ] 内部控制制度文件及执行记录
- [ ] 行业排名、市场份额数据

**财务质量维度**：
- [ ] 近三年经审计财务报表及附注
- [ ] 主要偿债能力指标计算：流动比率、速动比率、利息保障倍数
- [ ] 银行授信额度及使用情况
- [ ] 或有负债、对外担保明细

**项目状况维度**：
- [ ] 募投项目可行性研究报告
- [ ] 立项批复、环评批复、土地证等合规文件
- [ ] 项目当前建设进度证明
- [ ] 资金使用计划与监管账户安排

**项目前景维度**：
- [ ] 行业市场分析报告
- [ ] 项目收益测算模型（产量×价格-成本）
- [ ] 敏感性分析（价格变动±10%对收益的影响）
- [ ] 项目现金流预测表

**偿债能力维度**：
- [ ] 债务结构表（按期限、利率、债权人分类）
- [ ] 未来三年现金流预测
- [ ] 应急资金安排说明
- [ ] 政府支持函或股东支持承诺（如有）
