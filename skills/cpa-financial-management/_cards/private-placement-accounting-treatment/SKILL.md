# 非公开增发会计处理

## 使用场景
当上市公司完成非公开增发（定向增发）后，需要进行以下会计处理时使用本技能：
- 计算股本增加额
- 计算资本公积增加额
- 处理发行费用
- 计算增发后股权结构变化

## 前置条件
在执行计算前，需确认以下信息：
- 发行价格（元/股）
- 各类认购方式的股份数量（资产认购、现金认购）
- 发行费用金额
- 每股面额（中国A股标准为1元）

## 计算步骤

### 1. 计算股本增加额
```
股本增加额 = 每股面额 × 认购股份数量
```

### 2. 计算资本公积增加额
```
资本公积增加额 = (发行价格 - 每股面额) × 认购股份数量
```

### 3. 处理发行费用
```
资本公积净增加额 = 资本公积增加总额 - 发行费用
```

### 4. 计算股权结构变动
- 增发后总股数 = 增发前总股数 + 增发股数
- 各股东持股比例 = 该股东持股数 ÷ 增发后总股数

## 输出结果
- 股本增加总额
- 资本公积增加净额
- 增发后总股本
- 主要股东持股比例变化

## 注意事项
- 本技能仅适用于非公开发行股票完成后的会计处理
- 假设每股面额为1元（中国A股标准）
- 发行费用直接从资本公积中扣除
