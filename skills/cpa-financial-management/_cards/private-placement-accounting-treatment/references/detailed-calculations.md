# 非公开增发会计处理详细参考

## 基本公式

### 股本计算
```
股本增加额 = 每股面额 × 认购股份数量
```
- 每股面额：中国A股标准为1元
- 认购股份数量：包括资产认购和现金认购

### 资本公积计算
```
资本公积增加额 = (发行价格 - 每股面额) × 认购股份数量
```

### 发行费用处理
```
资本公积净增加额 = 资产认购资本公积 + 现金认购资本公积 - 发行费用
```

## 资产认购方式处理

### 计算公式
- 股本增加额 = 1 × 资产认购股份数量
- 资本公积增加额 = (发行价格 - 1) × 资产认购股份数量

### 示例
H公司资产认购80,401,951股，发行价格7.14元/股：
- 股本增加 = 1 × 80,401,951 = 80,401,951元
- 资本公积增加 = (7.14 - 1) × 80,401,951 = 6.14 × 80,401,951 = 493,667,979.14元

## 现金认购方式处理

### 计算公式
- 股本增加额 = 1 × 现金认购股份数量
- 资本公积增加额 = (发行价格 - 1) × 现金认购股份数量

### 示例
H公司现金认购44,598,049股，发行价格7.14元/股：
- 股本增加 = 1 × 44,598,049 = 44,598,049元
- 资本公积增加 = (7.14 - 1) × 44,598,049 = 6.14 × 44,598,049 = 273,832,020.86元

## 发行费用处理

### 处理原则
发行费用从资本公积中扣除，不计入当期损益。

### 示例
H公司发行费用17,565,000元（1756.5万元）：
- 直接从资本公积总额中扣除

## 完整案例：H公司

### 基础数据
- 资产认购股数：80,401,951股
- 现金认购股数：44,598,049股
- 发行价格：7.14元/股
- 发行费用：17,565,000元
- 每股面额：1元

### 合计计算

#### 1. 股本增加总额
```
股本增加总额 = 资产认购股本增加 + 现金认购股本增加
             = 80,401,951 + 44,598,049
             = 125,000,000元（即12,500万股）
```

#### 2. 资本公积增加总额
```
资本公积增加总额 = 资产认购资本公积 + 现金认购资本公积 - 发行费用
                 = 493,667,979.14 + 273,832,020.86 - 17,565,000
                 = 749,935,000元
```

## 股权结构变动计算

### 增发前总股数计算（倒推法）
```
增发前总股数 = 控股股东持股数 ÷ 控股股东持股比例
```

示例：
- 增发前控股股东持股63,407,989股，占比19.86%
- 增发前总股数 = 63,407,989 ÷ 19.86% = 319,274,869股

### 增发后股权结构
```
增发后总股数 = 增发前总股数 + 增发股数
```

示例：
- 增发后总股数 = 319,274,869 + 125,000,000 = 444,274,869股

### 股东持股比例变化
```
增发后持股比例 = (原持股数 + 新认购股数) ÷ 增发后总股数
```

示例：
- 控股股东原持股：63,407,989股
- 控股股东新认购：53,531,600股
- 增发后持股比例 = (63,407,989 + 53,531,600) ÷ 444,274,869
                  = 116,939,589 ÷ 444,274,869
                  = 26.33%

### 控制权变化分析
- 增发前持股比例：19.86%
- 增发后持股比例：26.33%
- 变化：持股比例提升6.47个百分点，控制权进一步加强

## 锁定期规定
- 非关联公司：18个月
- 机构投资者：6个月

## 变量说明

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 资产认购股份数量 | 股份数量 | 以非现金资产认购的股份数量 |
| 现金认购股份数量 | 股份数量 | 以现金认购的股份数量 |
| 发行价格 | 货币金额/股 | 每股发行价格 |
| 每股面额 | 货币金额/股 | 股票面值，通常为1元 |
| 发行费用 | 货币金额 | 本次非公开增发的相关发行费用 |
