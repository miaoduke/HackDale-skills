# 定价决策方法

## 完全成本加成定价法

### 适用条件

- 采用完全成本计算法
- 需要确定产品目标销售价格

### 计算步骤

#### 步骤1：确定成本基数
```
单位产品制造成本 = 直接材料 + 直接人工 + 制造费用（变动制造费用 + 固定制造费用）
```

#### 步骤2：确定加成率

根据企业要求确定，需确保加成部分能同时覆盖：
- 非制造成本（变动销售及管理费用 + 固定销售及管理费用）
- 企业期望的合理利润

#### 步骤3：计算成本加成金额
```
成本加成 = 单位产品制造成本 × 加成率
```

#### 步骤4：计算目标销售价格
```
目标销售价格 = 单位产品制造成本 × (1 + 加成率)
```

### 关键理解要点

- "加成"的内容必须包括两部分：非制造成本 + 合理利润
- 不能简单理解为"利润率"，因为加成基数是制造成本而非全部成本
- 若加成率过低，可能导致非制造成本无法弥补，企业实际亏损

## 重置成本定价决策原则

### 核心决策规则

当备选方案需要动用企业现有资产时，分析评价中不能以账面成本估价，必须以重置成本作为估价依据。

### 概念界定

- **重置成本**：目前从市场上购置一项原有资产所需支付的成本，也称现时成本或现行成本
- **账面成本**：一项资产在账簿中所记录的历史成本

### 定价决策中的具体应用

#### 步骤1：获取商品账面单位成本（历史成本）
#### 步骤2：获取商品当前重置成本（现时市场购置价格）
#### 步骤3：比较售价与重置成本，而非售价与账面成本
#### 步骤4：判断标准
- 售价 > 重置成本 = 真正盈利
- 售价 < 重置成本 = 实质亏损

### 关键洞察

历史成本可能导致虚假盈利判断，重置成本反映真实经济后果。

## 市场导向定价策略

### 场景一：一般市场定价法

#### 适用条件
产品拥有活跃的市场。

#### 定价依据
直接根据市场价格进行定价，或者根据市场上同类或相似产品的价格进行定价。

#### 应用示例
- 广州羊城通卡首发时，参考香港八达通卡和上海通卡价格定价
- 邯钢经验中的"模拟市场核算"，核心要义是对内部各种消耗和内部转让价格，基本都根据同类产品的市场价格定价

#### 目的
有利于时刻保持对市场的敏感性、对同行的敏锐性。

### 场景二：新产品销售定价

#### 特征识别
新产品定价具有"不确定性"特点，因未被消费者了解，需求量难以确定。

#### 试销流程（标准步骤）
1. 选择几个地区分别作为试点
2. 在不同地区采用不同价格进行试销
3. 收集有关新产品的市场反应信息
4. 根据收集到的信息确定产品的最终销售价格

#### 策略选择

在撇脂性定价和渗透性定价两种策略中选择。

### 策略实施：撇脂性定价

#### 执行步骤
在新产品试销初期先定出较高的价格；以后随着市场的逐步扩大，再逐步把价格降低。

#### 预期效果
使产品销售初期获得较高的利润。

#### 风险与约束
- 销售初期的暴利往往会引来大量的竞争者
- 致使后期的竞争异常激烈，高价格很难维持
- 因此这是一种短期性的策略

#### 适用条件
往往适用于生命周期较短的产品（例如："大哥大"、苹果智能手机刚进入市场时）。
