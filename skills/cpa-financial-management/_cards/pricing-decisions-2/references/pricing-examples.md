# 定价决策计算示例

## 完全成本加成定价法示例

**已知数据**：
- 直接材料：6元
- 直接人工：4元
- 变动制造费用：3元
- 固定制造费用：7元
- 加成率：50%
- 变动销售及管理费用：2元
- 固定销售及管理费用：1元

**计算过程**：

1. 确定成本基数：
```
单位产品制造成本 = 6 + 4 + 3 + 7 = 20元
```

2. 计算成本加成金额：
```
成本加成 = 20 × 50% = 10元
```

3. 计算目标销售价格：
```
目标销售价格 = 20 × (1 + 50%) = 30元
```

4. 验证加成内容的充分性：
```
单位非制造成本 = 2 + 1 = 3元
剩余利润 = 10 - 3 = 7元/件
总利润 = 7 × 10,000 = 70,000元
```

## 重置成本定价决策示例

**已知数据**：
- 库存商品A账面单位成本：200元
- 库存商品A重置成本：250元
- 售价：230元

**决策分析**：

错误决策（按历史成本考虑）：
```
获利 = 230 - 200 = 30元
```

正确分析（按重置成本考虑）：
```
售出后按重置成本补进需250元
实际亏损 = 230 - 250 = -20元
```

**结论**：按230元出售实际上是亏损的，不应接受此价格。

## 市场导向定价示例

**场景**：某企业推出新产品

**试销数据**：
- 地区A（试销价100元）：销量1,000件
- 地区B（试销价120元）：销量800件
- 地区C（试销价80元）：销量1,500件

**分析**：
- 价格80元时销量最高，但利润可能不足
- 价格120元时销量较低，但单位利润较高
- 价格100元时销量和利润平衡较好

**决策**：选择100元作为最终销售价格，采用渗透性定价策略，快速占领市场。
