# ABC公司财务比率完整计算手册

基于20×1年度假设数据，详细展示各类财务比率的计算过程。

## 一、短期偿债能力比率

### 1. 流动比率
```
流动比率 = 流动资产 ÷ 流动负债
         = 700 ÷ 300
         = 2.33
```

### 2. 速动比率
```
速动比率 = （流动资产 - 存货 - 预付款项）÷ 流动负债
```
> 注：本数据集未提供存货明细，假设存货为200万元：
```
速动比率 = (700 - 200) ÷ 300 = 1.67
```

### 3. 现金比率
```
现金比率 = 货币资金 ÷ 流动负债
```
> 需假设货币资金金额，或使用经营活动现金流量替代：
```
现金流量比率 = 经营活动现金流量净额 ÷ 流动负债
             = 246 ÷ 300
             = 0.82
```

## 二、长期偿债能力比率

### 4. 资产负债率
```
资产负债率 = 负债合计 ÷ 资产总计 × 100%
           = 1040 ÷ 2000 × 100%
           = 52%
```

### 5. 产权比率
```
产权比率 = 负债合计 ÷ 股东权益合计
         = 1040 ÷ 960
         = 1.08
```

### 6. 权益乘数
```
权益乘数 = 资产总计 ÷ 股东权益合计
         = 2000 ÷ 960
         = 2.08
```

### 7. 利息保障倍数
**关键假设**：财务费用110万元全部为利息支出

假设所得税费用为64万元（推算：利润总额200万，税率25%）：
```
息税前利润(EBIT) = 净利润 + 所得税费用 + 利息费用
                = 136 + 64 + 110
                = 310

利息保障倍数 = EBIT ÷ 利息费用
            = 310 ÷ 110
            = 2.82
```

### 8. 现金流量利息保障倍数
```
现金流量利息保障倍数 = 经营活动现金流量净额 ÷ 利息费用
                    = 246 ÷ 110
                    = 2.24
```

## 三、营运能力比率

### 9. 应收账款周转率
假设应收账款年末250万元，年初200万元：
```
应收账款周转率 = 营业收入 ÷ 平均应收账款余额
              = 3000 ÷ [(250+200)/2]
              = 3000 ÷ 225
              = 13.33（次）

应收账款周转天数 = 365 ÷ 13.33 = 27.4（天）
```

### 10. 存货周转率
假设存货年末200万元，年初180万元：
```
存货周转率 = 营业成本 ÷ 平均存货余额
          = 2644 ÷ [(200+180)/2]
          = 2644 ÷ 190
          = 13.92（次）

存货周转天数 = 365 ÷ 13.92 = 26.2（天）
```

### 11. 流动资产周转率
```
流动资产周转率 = 营业收入 ÷ 平均流动资产余额
              = 3000 ÷ [(700+610)/2]
              = 3000 ÷ 655
              = 4.58（次）
```

### 12. 总资产周转率
```
总资产周转率 = 营业收入 ÷ 平均资产总计
            = 3000 ÷ [(2000+1680)/2]
            = 3000 ÷ 1840
            = 1.63（次）
```

---

## 四、盈利能力比率

### 13. 营业净利率
```
营业净利率 = 净利润 ÷ 营业收入 × 100%
          = 136 ÷ 3000 × 100%
          = 4.53%
```

### 14. 总资产净利率
```
总资产净利率 = 净利润 ÷ 平均资产总计 × 100%
            = 136 ÷ 1840 × 100%
            = 7.39%
```

### 15. 权益净利率（ROE）
```
权益净利率 = 净利润 ÷ 平均股东权益 × 100%
          = 136 ÷ [(960+880)/2] × 100%
          = 136 ÷ 920 × 100%
          = 14.78%
```

---

## 五、市价比率（需补充假设）

若假设：
- 普通股股数：100万股
- 每股市价：20元

### 16. 每股收益（EPS）
```
每股收益 = 净利润 ÷ 流通在外普通股加权平均股数
        = 136 ÷ 100
        = 1.36（元/股）
```

### 17. 市盈率
```
市盈率 = 每股市价 ÷ 每股收益
      = 20 ÷ 1.36
      = 14.71（倍）
```

### 18. 市净率
```
每股净资产 = 股东权益合计 ÷ 流通在外普通股股数
          = 960 ÷ 100
          = 9.6（元/股）

市净率 = 每股市价 ÷ 每股净资产
      = 20 ÷ 9.6
      = 2.08（倍）
```

---

## 六、杜邦分析体系

```
权益净利率 = 营业净利率 × 总资产周转次数 × 权益乘数
          = 4.53% × 1.63 × 2.08
          = 15.36%
```

> 与直接计算结果14.78%存在差异，系平均数计算口径不同所致。
