# 经济增加值考核重大调整事项

## 何时使用

- 接受国资委经济增加值考核的中央企业
- 发生特定情形且对EVA考核产生重大影响
- 需要向国资委申请考核调整

## 适用条件（必须同时满足）

1. 发生下列四种情形之一
2. 该情形对企业经济增加值考核产生**"重大影响"**
3. 由国资委**"酌情"**决定是否调整（非企业自主调整）

## 四类可申请调整的情形

### (1) 重大政策变化

- 国家层面出台的、对企业经营产生重大影响的法律法规、产业政策、监管要求等变化
- **例如**：行业准入政策重大调整、环保标准突然提高、价格管制政策变化等

### (2) 严重自然灾害等不可抗力因素

- 地震、洪水、台风等严重自然灾害
- 其他不可抗力事件（如重大疫情等）
- **关键判定**：不可预见、不可避免、不可克服

### (3) 企业重组、上市及会计准则调整等不可比因素

- **企业重组**：合并、分立、重大资产置换等
- **上市**：IPO或重大资产重组上市
- **会计准则调整**：会计政策变更导致数据不可比
- **核心特征**：导致前后期间数据缺乏可比性

### (4) 国资委认可的企业结构调整等其他事项

- 兜底条款
- 需国资委个案认可
- **例如**：战略性结构调整、政策性搬迁、重大技术转型等

## 申请与审批流程

```
企业提出申请 → 说明具体情形、影响程度、调整建议 → 国资委审核 → "酌情"决定
```

**调整方式**：未明确具体方法，由国资委根据个案确定

## 关键要点

| 要点 | 说明 |
|------|------|
| 审批性质 | 国资委自由裁量，非自动调整 |
| 影响程度 | 必须达到"重大影响"标准 |
| 证据要求 | 需提供充分证明材料 |
| 调整幅度 | 由国资委个案确定 |
