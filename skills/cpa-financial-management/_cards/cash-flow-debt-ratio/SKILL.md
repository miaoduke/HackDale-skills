# 现金流量与负债比率计算

## 适用场景
需要评估企业用经营活动现金流量偿付全部债务的能力时，计算现金流量与负债比率。

## 指标定义
现金流量与负债比率是指经营活动现金流量净额与负债总额的比率。

## 计算公式
```
现金流量与负债比率 = (经营活动现金流量净额 ÷ 负债总额) × 100%
```

## 关键计算规则

### 负债总额的取值
- **采用**：期末数而非平均数
- **原因**：实际需要偿还的是期末金额，而非平均金额

## 计算示例

**ABC公司**：
```
本年现金流量与负债比率 = (246 ÷ 1,040) × 100% = 24%
```

## 指标解读
该比率表明企业用经营活动现金流量净额偿付全部债务的能力。

## 结果判断
比率越高，偿还负债总额的能力越强。

## 注意事项
- 该指标反映全部债务偿付能力，非仅利息
- 必须使用期末负债总额，而非平均数
