# 资本预算与固定资产更新决策

## 适用场景
- 固定资产更新决策（比较新旧设备）
- 不同寿命期互斥项目比较
- 确定固定资产经济寿命
- 设备最优更新时机评估

## 核心决策流程

### 步骤1：判断项目类型

**情况A：尚可使用年限相同**
- 方法：比较现金流出的总现值
- 决策规则：选择现金流出总现值较小的方案

**情况B：尚可使用年限不同**
- 方法：使用等额年金法（EAA）或平均年成本（AAC）
- 决策规则：选择等额年金或平均年成本较低的方案

### 步骤2：计算平均年成本（考虑时间价值）

**公式：**
```
平均年成本 = [C + A×(P/A,i,n) - S×(P/F,i,n)] / (P/A,i,n)
```

其中：\- C = 初始投资成本
- A = 年运行成本
- S = 残值
- i = 贴现率
- n = 使用年限
- (P/A,i,n) = 年金现值系数
- (P/F,i,n) = 复利现值系数

### 步骤3：确定经济寿命（如需）

对第1年、第2年...第n年分别计算UAC，找出最小值对应的年份。

**经济寿命UAC公式：**
```
UAC = [C - S_n/(1+i)^n + Σ(i=1 to n)(C_i/(1+i)^i)] / (P/A, i, n)
```

### 步骤4：等额年金法（不同寿命项目）

**计算步骤：**
1. 计算各项目的净现值(NPV)
2. 计算等额年金额：EAA = NPV ÷ (P/A, i, n)
3. （可选）计算永续净现值：永续NPV = EAA ÷ i
4. 决策：选择EAA较大（或永续NPV较大）的项目

## 实务应用准则

### 重置概率筛选
- 只有重置概率很高的项目才适宜采用重置分析方法
- 重置概率低时，直接按各自年限计算NPV比较

### 年限差异判断
- 年限差别不大（如8年vs10年，差异仅2年）：直接比较NPV
- 不需要做复杂的重置现金流分析

### 数据截断原则（10年规则）
- 舍去10年以后的数据，只进行10年内的分析
- 即使理论需要24年（如6年和8年的最小公倍数），实务中可能只分析前10年

## 关键注意事项

1. **生产能力假设**：假设新旧设备生产能力相同，因此只需比较成本
2. **收入差异**：若收入不同，则应比较净现值或净现值差额
3. **折现率**：使用统一的折现率（如加权平均资本成本）
4. **成本形态**：运行成本递增，持有成本递减，总成本呈U型曲线
