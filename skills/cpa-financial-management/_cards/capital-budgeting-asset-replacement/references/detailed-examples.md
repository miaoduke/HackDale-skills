# 详细计算示例

## 示例1：新旧设备比较（年限相同）

**数据：**
- 旧设备：初始成本600元，年运行成本700元，残值200元，使用6年
- 新设备：初始成本2400元，年运行成本400元，残值300元，使用10年
- 贴现率：15%

**计算：**

旧设备平均年成本：
- 分子：600 + 700×3.784 - 200×0.432 = 600 + 2648.8 - 86.4 = 3162.4
- 分母：(P/A,15%,6) = 3.784
- 结果：3162.4 / 3.784 = 836元

新设备平均年成本：
- 分子：2400 + 400×5.019 - 300×0.247 = 2400 + 2007.6 - 74.1 = 4333.5
- 分母：(P/A,15%,10) = 5.019
- 结果：4333.5 / 5.019 = 863元

**决策：** 旧设备836元 < 新设备863元，保留旧设备

## 示例3：等额年金法

**数据：** 资本成本10%
- A项目：NPV=12,441万元，n=6年，(P/A,10%,6)=4.3553
- B项目：NPV=8,324万元，n=3年，(P/A,10%,3)=2.4869

**计算：**
- A项目EAA = 12,441 ÷ 4.3553 = 2,857万元
- B项目EAA = 8,324 ÷ 2.4869 = 3,347万元

**永续NPV：**
- A项目永续NPV = 2,857 ÷ 10% = 28,570万元
- B项目永续NPV = 3,347 ÷ 10% = 33,470万元

**决策：** B项目优于A项目
