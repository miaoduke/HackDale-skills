# 本量利分析详细公式与推导

## 边际贡献方程式详解

### 基本推导
基于基本损益方程式：
```
息税前利润 = 销售收入 - 变动成本 - 固定成本
           = 边际贡献 - 固定成本
```

### 两种表达形式的关系
- **销量形式**：适用于单一产品或产品组合结构稳定的情形
- **收入形式**：适用于多品种企业，因为销售收入可直接相加

### 多品种企业的加权平均边际贡献率
```
加权平均边际贡献率 = Σ(各产品边际贡献) / Σ(各产品销售收入)
                   = Σ(各产品销售收入占比 × 该产品边际贡献率)
```

## 保利分析完整推导

### 无税情形
目标：求解实现目标利润所需的业务量

由：目标利润 = 销量 × 单位边际贡献 - 固定成本
得：销量 = (固定成本 + 目标利润) / 单位边际贡献

保利额 = 保利量 × 单价 = [(固定成本 + 目标利润) / 单位边际贡献] × 单价
       = (固定成本 + 目标利润) / (单位边际贡献/单价)
       = (固定成本 + 目标利润) / 边际贡献率

### 有税情形
设税后目标利润为 P_after，所得税税率为 T

由：P_after = 税前利润 × (1-T)
得：税前目标利润 = P_after / (1-T)

代入无税公式即可。

## 敏感系数计算示例

### 基准数据
- 销量 Q = 100,000件
- 单价 SP = 2元
- 单位变动成本 VC = 1.2元
- 固定成本 FC = 40,000元
- 原利润 P₀ = 100,000 × (2-1.2) - 40,000 = 40,000元

### 单价敏感系数（变动+20%）
- 新单价 = 2 × 1.2 = 2.4元
- 新利润 = 100,000 × (2.4-1.2) - 40,000 = 80,000元
- 利润变动率 = (80,000-40,000)/40,000 = 100%
- **敏感系数 = 100%/20% = 5**

### 单位变动成本敏感系数（变动+20%）
- 新单位变动成本 = 1.2 × 1.2 = 1.44元
- 新利润 = 100,000 × (2-1.44) - 40,000 = 16,000元
- 利润变动率 = (16,000-40,000)/40,000 = -60%
- **敏感系数 = -60%/20% = -3**

### 销量敏感系数（变动+20%）
- 新销量 = 100,000 × 1.2 = 120,000件
- 新利润 = 120,000 × 0.8 - 40,000 = 56,000元
- 利润变动率 = (56,000-40,000)/40,000 = 40%
- **敏感系数 = 40%/20% = 2**

### 固定成本敏感系数（变动+20%）
- 新固定成本 = 40,000 × 1.2 = 48,000元
- 新利润 = 80,000 - 48,000 = 32,000元
- 利润变动率 = (32,000-40,000)/40,000 = -20%
- **敏感系数 = -20%/20% = -1**

### 敏感程度排序
| 参数 | 敏感系数 | 排名 |
|------|---------|------|
| 单价 | 5 | 1（最敏感） |
| 单位变动成本 | -3 | 2 |
| 销量 | 2 | 3 |
| 固定成本 | -1 | 4（最不敏感） |

## 保利额计算数值示例

### 无企业所得税（例16-6数据）
- 固定成本 = 1,600元
- 目标利润 = 1,500元
- 单价 = 2元/件
- 单位变动成本 = 1.2元/件

**保利量** = (1,600 + 1,500) / (2 - 1.2) = 3,100 / 0.8 = **3,875件**

**保利额** = 3,875 × 2 = **7,750元**

验证（边际贡献率法）：
- 边际贡献率 = (2-1.2)/2 = 40%
- 保利额 = (1,600 + 1,500) / 0.4 = 3,100 / 0.4 = **7,750元** ✓

## 安全边际与盈亏临界点关系

### 基本恒等式推导
```
实际销售额 = 盈亏临界点销售额 + 安全边际额
```

两端同除以实际销售额：
```
1 = 盈亏临界点作业率 + 安全边际率
```

### 示例（例16-6数据）
- 盈亏临界点销售额 = 4,000元
- 实际销售额 = 5,000元
- 安全边际额 = 1,000元

盈亏临界点作业率 = 4,000/5,000 = **80%**
安全边际率 = 1,000/5,000 = **20%**
验证：80% + 20% = **100%** ✓
