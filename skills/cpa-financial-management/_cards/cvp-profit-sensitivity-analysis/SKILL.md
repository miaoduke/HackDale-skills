# 本量利分析与利润敏感分析

## 适用场景
- 盈亏平衡计算与目标利润规划
- 评估单价、成本、销量变动对利润的影响
- 多品种产品盈利分析
- 不同企业/行业间的经营安全性比较

## 核心工具一：边际贡献方程式

### 基于销量的方程
```
息税前利润 = 销量 × 单位边际贡献 - 固定成本
```

### 基于收入的方程（多品种适用）
```
息税前利润 = 销售收入 × 边际贡献率 - 固定成本
```

其中：边际贡献率 = (单价 - 单位变动成本) / 单价

## 核心工具二：保利分析

### 无企业所得税情形
```
保利额 = (固定成本 + 目标利润) / 边际贡献率
保利量 = (固定成本 + 目标利润) / 单位边际贡献
```

### 存在企业所得税情形
```
保利额 = [固定成本 + 税后目标利润/(1-所得税税率)] / 边际贡献率
```

**关键调整**：税后目标利润需转换为税前目标利润，即除以(1-税率)。

## 核心工具三：利润敏感系数

### 计算四步法
1. 设定参数变动百分比（通常±20%）
2. 计算变动后的参数值并求新利润
3. 计算利润变动百分比 = (P₁ - P₀) / P₀ × 100%
4. **敏感系数 = 利润变动百分比 / 参数变动百分比**

### 解读规则
| 敏感系数绝对值 | 敏感程度 |
|--------------|---------|
| > 1 | 敏感因素，微小变化引起利润更大变化 |
| = 1 | 等比例变动 |
| < 1 | 不敏感因素 |

- 正值：参数与利润同向变动
- 负值：参数与利润反向变动

## 核心工具四：安全边际分析

### 安全边际率
```
安全边际率 = 安全边际额 / 实际或预计销售额 × 100%
```

### 关键恒等式
```
安全边际率 + 盈亏临界点作业率 = 1
```

**风险判断**：安全边际率数值越大，企业发生亏损的可能性越小，经营越安全。

## 快速决策流程

1. **需要计算目标利润下的销售额？** → 使用保利额公式
2. **存在所得税？** → 税后利润先转税前
3. **多品种企业？** → 使用边际贡献率方程式，计算加权平均边际贡献率
4. **评估哪个参数对利润影响最大？** → 计算各参数敏感系数并排序
5. **比较不同企业抗风险能力？** → 计算安全边际率（相对指标，可跨企业比较）
