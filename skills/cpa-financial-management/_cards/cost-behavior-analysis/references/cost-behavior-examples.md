# 成本性态分析详细示例

## 工业工程法完整计算示例

### 场景：铸造车间燃料成本分析

### 已知条件

**固定投入（每次点火）**
- 劈柴：0.1吨/次
- 焦炭：1.5吨/次

**变动投入（熔化铁水）**
- 焦炭：0.15吨/吨铁水

**作业安排**
- 每个工作日点火一次
- 全月工作26天

**材料单价**
- 劈柴：500元/吨
- 焦炭：1,800元/吨

### 计算过程

**1. 计算每次点火的固定成本**
```
劈柴成本 = 0.1吨 × 500元/吨 = 50元
焦炭成本 = 1.5吨 × 1,800元/吨 = 2,700元
每次点火固定成本 = 50 + 2,700 = 2,750元
```

**2. 计算每月固定成本**
```
每月固定成本 = 2,750元/次 × 26次 = 71,500元
```

**3. 计算单位变动成本**
```
每吨铸件变动成本 = 0.15吨 × 1,800元/吨 = 270元
```

**4. 建立成本公式**
```
y = 71,500 + 270x
```

**5. 应用示例**

若预计下月产量为500吨，则燃料总成本为：
```
y = 71,500 + 270 × 500
y = 71,500 + 135,000
y = 206,500元
```

## 账户分析法示例

### 场景：制造费用分解

### 账户分析

| 费用项目 | 月度金额 | 成本性态 | 分类 |
|---------|---------|---------|------|
| 设备折旧 | 10,000元 | 不随产量变动 | 固定成本 |
| 车间管理人员工资 | 15,000元 | 不随产量变动 | 固定成本 |
| 间接材料 | 8,000元 | 随产量变动 | 变动成本 |
| 电力费用 | 12,000元 | 部分固定、部分变动 | 混合成本 |
| 修理费用 | 5,000元 | 随产量变动 | 变动成本 |
| 合计 | 50,000元 | - | - |

### 进一步分解混合成本

**电力费用分析**：
- 基础电费（固定）：3,000元/月
- 用电电费（变动）：0.09元/度
- 预计月度用电量：100,000度

```
固定部分 = 3,000元
变动部分 = 100,000度 × 0.09元/度 = 9,000元
```

### 最终成本公式

```
固定成本总额 = 10,000 + 15,000 + 3,000 = 28,000元
变动成本总额 = 8,000 + 9,000 + 5,000 = 22,000元
单位变动成本 = 22,000元 ÷ 1,000件（假设产量）= 22元/件

y = 28,000 + 22x
```

## 两种方法对比

| 维度 | 账户分析法 | 工业工程法 |
|------|-----------|-----------|
| 数据要求 | 会计核算账户数据 | 现场观察和技术测定 |
| 精度 | 较低（定性分析） | 较高（科学分析） |
| 操作难度 | 简单 | 复杂 |
| 适用场景 | 有历史数据、快速分析 | 无历史数据、建立标准 |
| 成本 | 低 | 高 |
| 时间 | 短 | 长 |
