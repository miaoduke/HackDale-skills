# 成本性态分析

## 使用场景
当企业需要：
- 将混合成本分解为固定成本和变动成本
- 建立成本估计公式 y = a + bx
- 制定标准成本或预算
- 无历史成本数据或历史数据不可靠
- 需验证历史成本分析结论

## 方法选择决策

### 账户分析法
**适用条件**：
- 具备详细的会计核算账户数据
- 优先考虑操作简便性而非精度

**特点**：简单、粗糙，但方便操作

### 工业工程法
**适用条件**：
- 能够进行现场观察和技术测定
- 有明确的投入产出关系
- 无历史成本数据或数据不可靠
- 需建立标准成本或制定预算

**特点**：比历史成本分析更科学

## 账户分析法

### 执行步骤
1. 分析会计核算账户中各个成本项目的特点
2. 识别比较接近变动成本特征的账户或项目，将其归为变动成本
3. 识别比较接近固定成本特征的账户或项目，将其归为固定成本

### 注意事项
- 该方法属于定性分析
- 依赖分析人员的经验和判断
- 精度相对较低

## 工业工程法

### 执行步骤

**步骤1：选择需要研究的成本项目**

**步骤2：观察现行方法并记录全部事实**
- 主要是投入的成本和产出的数量

**步骤3：进行全面的科学分析**
- 研究出"最实用、最有效、最经济"的新的工作方法

**步骤4：把新的方法确定为标准的方法**
- 测定新方法的每项投入成本
- 将与产量有关的部分归集为单位变动成本
- 将与产量无关的部分归集为固定成本

### 计算逻辑示例（基于燃料成本）

**确定投入**
- 固定投入：每次点火耗用劈柴0.1吨、焦炭1.5吨
- 变动投入：熔化1吨铁水耗用焦炭0.15吨

**确定作业量**
- 每个工作日点火一次，全月工作26天

**确定单价**
- 劈柴：500元/吨
- 焦炭：1,800元/吨

**计算**
```
每日固定成本 = (0.1 × 500) + (1.5 × 1,800) = 2,750元
每月固定成本 = 2,750 × 26 = 71,500元
每吨铸件变动成本 = 0.15 × 1,800 = 270元
```

**建立总成本公式**
```
y = 71,500 + 270x
```
其中：
- y = 每月燃料总成本（或总成本）
- a = 固定成本总额（71,500元）
- b = 单位变动成本（270元）
- x = 产量（吨铸件）

## 成本估计公式

### 通用公式
```
y = a + bx
```

### 变量说明
- **y**：总成本
- **a**：固定成本总额
- **b**：单位变动成本
- **x**：业务量（产量、销量、工时等）

### 应用
- 预测不同业务量下的总成本
- 编制弹性预算
- 进行本量利分析
- 评估成本控制业绩
