# 易变现率计算与营业周期分析

评估企业适中型筹资策略下的流动性保障程度，区分营业高峰期与低谷期分别计算。

## 何时使用

- 评估适中型筹资策略的流动性状况
- 比较营业高峰期与低谷期的资金保障程度
- 监测企业流动性风险
- 分析长期资金对流动资产的覆盖比例

## 前提条件

- 已确定长期资金来源总额（股东权益 + 长期债务 + 经营性流动负债）
- 已确定长期资产金额
- 已确定当前流动资产总额
- 明确当前处于营业高峰期或低谷期

## 计算步骤

### 步骤1：确定计算时期

判断当前分析场景：
- **营业低谷期**：仅存在稳定性流动资产，无波动性流动资产
- **营业高峰期**：同时存在稳定性流动资产和波动性流动资产

### 步骤2：计算易变现率

使用公式：

```
易变现率 = (长期资金来源 - 长期资产) / 流动资产 × 100%
```

其中：
- **长期资金来源** = 股东权益 + 长期债务 + 经营性流动负债
- **分子** = 长期性资产总额 - 长期资产 = 稳定性流动资产
- **分母** = 当前时点流动资产总额

### 步骤3：解读结果

| 时期 | 预期比率 | 含义 |
|:---|:---|:---|
| 营业低谷期 | 100% | 全部流动资产由长期资金支持，无短期借款 |
| 营业高峰期 | < 100% | 部分流动资产依赖短期借款，比率越低短期融资占比越高 |

## 关键判断标准

- **100%**：流动资产完全由长期资金保障
- **< 100%**：存在短期借款缺口，差额比例即为短期资金占比
- 适中型策略下，高峰期比率下降是正常的，但需关注短期偿债能力

## 注意事项

- 本方法仅适用于适中型筹资策略评估
- 必须区分高峰期和低谷期分别计算，不可混用
- 高峰期比率下降幅度反映波动性流动资产占比

## 示例速查

某企业：淡季需300万流动资产+500万长期资产；高峰期额外增加200万季节性存货；长期资金800万，高峰期借入200万短期借款。

- **高峰期**：(800-500)/(300+200) = 60%
- **低谷期**：300/300 = 100%
