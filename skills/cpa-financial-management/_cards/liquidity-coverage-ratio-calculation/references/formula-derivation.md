# 易变现率公式推导与原理

## 核心概念定义

### 长期性资产
长期性资产 = 长期资产 + 稳定性流动资产

代表企业长期占用的资金需求，应当由长期资金来源满足。

### 长期资金来源
长期资金来源 = 股东权益 + 长期债务 + 经营性流动负债

代表企业可长期使用的资金，包括自发性的经营性流动负债。

## 公式推导

### 基本平衡关系

在适中型筹资策略下：

```
长期资金来源 = 长期资产 + 稳定性流动资产
```

### 易变现率的经济含义

易变现率衡量：**当前流动资产中，有多少比例可以由长期资金来源保障**。

```
易变现率 = (长期资金来源 - 长期资产) / 流动资产
         = 可用于支持流动资产的长期资金 / 流动资产总额
         = 稳定性流动资产 / 流动资产
```

### 分时期推导

#### 营业低谷期
```
流动资产 = 稳定性流动资产（无波动性资产）

易变现率 = (长期资金来源 - 长期资产) / 稳定性流动资产
         = 稳定性流动资产 / 稳定性流动资产
         = 100%
```

#### 营业高峰期
```
流动资产 = 稳定性流动资产 + 波动性流动资产

易变现率 = 稳定性流动资产 / (稳定性流动资产 + 波动性流动资产)
         < 100%
```

## 数学性质

### 取值范围
- 理论上：0% ≤ 易变现率 ≤ 100%（适中型策略）
- 保守型策略：可能 > 100%（长期资金还支持部分波动性资产）
- 激进型策略：低谷期可能 < 100%

### 与波动性资产占比的关系

设：波动性流动资产占比 = α

则：易变现率 = (1 - α) / 1 = 1 - α（高峰期，且严格适中型策略）

即：**高峰期易变现率 = 1 - 波动性流动资产占比**
