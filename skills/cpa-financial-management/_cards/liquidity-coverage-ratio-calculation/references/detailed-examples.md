# 易变现率计算详细案例

## 案例一：制造业企业营业周期分析

### 企业背景
- 行业：季节性消费品制造
- 营业周期：明显季节性，Q4为高峰期

### 基础数据
| 项目 | 金额（万元） |
|:---|---:|
| 股东权益 | 400 |
| 长期债务 | 300 |
| 经营性流动负债 | 100 |
| **长期资金来源合计** | **800** |
| 固定资产（长期资产） | 500 |
| 稳定性流动资产（淡季） | 300 |
| 波动性流动资产（旺季增量） | 200 |

### 筹资策略安排
- 长期资金800万元：覆盖全部长期资产500万 + 稳定性流动资产300万
- 短期借款200万元：仅在高峰期借入，覆盖波动性流动资产

### 分期计算

#### 营业低谷期（Q1-Q3）
```
分子 = 800 - 500 = 300（万元）
分母 = 300（万元）【仅稳定性流动资产】
易变现率 = 300 / 300 × 100% = 100%
```

**解读**：
- 全部流动资产由长期资金支持
- 无短期借款，财务风险低
- 资金成本较高但稳定性强

#### 营业高峰期（Q4）
```
分子 = 800 - 500 = 300（万元）【长期资金用于稳定性流动资产的部分】
分母 = 300 + 200 = 500（万元）【稳定性+波动性流动资产】
易变现率 = 300 / 500 × 100% = 60%
```

**解读**：
- 60%流动资产由长期资金支持
- 40%流动资产（200万/500万）依赖短期借款
- 符合适中型策略特征：长期资产+稳定性流动资产用长期资金，波动性流动资产用短期资金

## 案例二：三种筹资策略对比

| 策略类型 | 低谷期易变现率 | 高峰期易变现率 | 特征 |
|:---|:---|:---|:---|
| 适中型策略 | 100% | 约60% | 波动性资产用短期资金 |
| 保守型策略 | 100% | > 60% | 部分波动性资产也用长期资金 |
| 激进型策略 | < 100% | < 60% | 部分稳定性资产也用短期资金 |

---

## 公式等价变形

### 变形一：直接法
```
易变现率 = 稳定性流动资产 / 流动资产 × 100%
```

### 变形二：资金来源法
```
易变现率 = (股东权益 + 长期债务 + 经营性流动负债 - 长期资产) / 流动资产 × 100%
```

### 变形三：短期资金缺口法
```
易变现率 = 1 - (短期借款 / 流动资产) × 100%
```

## 常见错误

### 错误1：混淆分子计算
❌ 错误：分子 = 长期资金来源  
✅ 正确：分子 = 长期资金来源 - 长期资产

### 错误2：忽略时期区分
❌ 错误：全年使用同一比率  
✅ 正确：高峰期和低谷期分别计算

### 错误3：错误识别波动性资产
❌ 错误：将稳定性流动资产误判为波动性  
✅ 正确：波动性资产是随营业周期临时增减的部分

## 与其他指标的关系

| 指标 | 关联说明 |
|:---|:---|
| 流动比率 | 易变现率侧重资金来源结构，流动比率侧重偿债能力 |
| 营运资本 | 易变现率 = 营运资本 / 流动资产（低谷期时） |
| 现金周期 | 营业周期分析需结合现金周期判断资金需求时点 |
