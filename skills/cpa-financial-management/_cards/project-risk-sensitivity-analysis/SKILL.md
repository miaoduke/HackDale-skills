# 项目风险敏感性分析

## 何时使用

- 评估投资项目特有风险
- 确定各变量使NPV由正转零的临界值
- 识别对项目价值影响最大的关键参数
- 判断项目风险是否可控

## 方法一：最大最小法

**目标：** 计算使净现值由正值变为0的各变量临界值

### 操作步骤

**第一步：计算基准净现值**
```
NPV = ∑(各年税后营业现金净流量 × 折现系数) - 初始投资
```

**第二步：计算变量临界值**
- 选择一个关键变量
- 假设其他所有变量保持不变
- 令 NPV = 0，求解该变量的临界值

**第三步：结果解释**
- 现金流入类变量：计算**最小值**（低于则项目不可行）
- 现金流出类变量：计算**最大值**（高于则项目不可行）

### 决策规则

若决策者确信实际值不会突破临界值，则项目特有风险可控，可以投资；反之，则项目风险很大，应慎重考虑。

## 方法二：敏感程度法

**目标：** 量化各变量变动对NPV的影响程度

### 操作步骤

**第一步：计算基准净现值**

**第二步：单变量变动测试**
- 选定一个关键变量
- 假设该变量发生特定幅度变化（通常±5%、±10%）
- **关键约束：** 其他所有因素保持不变
- 重新计算各变动幅度下的NPV

**第三步：计算敏感系数**
```
敏感系数 = 目标值变动百分比 ÷ 选定变量变动百分比
         = [(新NPV - 基准NPV) ÷ 基准NPV] ÷ 变量变动百分比
```

**经济含义：** 选定变量每变化1%时，导致NPV变动的百分数。

### 敏感性判断

| 敏感系数绝对值 | 敏感程度 |
|-------------|---------|
| 较大 | 净现值对该变量高度敏感，为主要敏感因素 |
| 较小 | 净现值对该变量相对不敏感 |

## 关键提示

- 两种方法均基于**单变量敏感性分析**假设
- 实际中变量可能同时变化，需结合情景分析
- 敏感系数绝对值越大，表明该变量风险敞口越大
- 识别主要敏感因素后，应重点监控和管控这些变量
