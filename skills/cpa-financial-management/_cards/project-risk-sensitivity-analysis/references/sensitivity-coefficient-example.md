# 敏感程度法计算示例

## 基础数据（同上例）

基准NPV = 22.53万元

## 税后营业现金流入敏感系数

**测试：流入下降10%至90万元**

```
新年税后营业现金净流量 = 90 - 69 + 4.5 = 25.5万元
新NPV = 25.5 × 3.1699 - 90 = 80.83 - 90 = -9.17万元

目标值变动百分比 = (-9.17 - 22.53) ÷ 22.53 = -140.7%

敏感系数 = -140.7% ÷ (-10%) = +14.07
```

**含义：** 税后营业现金流入每变动1%，NPV同向变动14.07%。

## 税后营业现金流出敏感系数

**测试：流出增加10%至75.9万元**

```
新年税后营业现金净流量 = 100 - 75.9 + 4.5 = 28.6万元
新NPV = 28.6 × 3.1699 - 90 = 90.66 - 90 = 0.66万元

目标值变动百分比 = (0.66 - 22.53) ÷ 22.53 = -97.07%

敏感系数 = -97.07% ÷ 10% = -9.71
```

**含义：** 税后营业现金流出每增加1%，NPV下降9.71%。

## 初始投资敏感系数

**测试：投资增加10%至99万元**

```
新年折旧额 = 99 ÷ 4 = 24.75万元
新年折旧抵税 = 24.75 × 20% = 4.95万元
新年税后营业现金净流量 = 100 - 69 + 4.95 = 35.95万元
新NPV = 35.95 × 3.1699 - 99 = 113.96 - 99 = 14.96万元

目标值变动百分比 = (14.96 - 22.53) ÷ 22.53 = -33.6%

敏感系数 = -33.6% ÷ 10% = -3.36
```

## 敏感性排序

| 变量 | 敏感系数绝对值 | 敏感程度 |
|-----|------------|---------|
| 税后营业现金流入 | 14.07 | **最高** |
| 税后营业现金流出 | 9.71 | 高 |
| 初始投资 | 3.36 | 相对较低 |

**结论：** 税后营业现金流入是最敏感因素，应重点监控。
