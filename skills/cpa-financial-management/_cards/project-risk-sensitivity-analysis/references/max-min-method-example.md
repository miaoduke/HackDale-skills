# 最大最小法计算示例

## 基础数据

- 初始投资：90万元
- 项目寿命：4年
- 折旧方法：直线法，无残值
- 年折旧额 = 90 ÷ 4 = 22.5万元
- 预期每年税后营业现金流入：100万元
- 预期每年税后营业现金流出：69万元
- 所得税税率：20%
- 折现率：10%

## 基准NPV计算

```
年折旧抵税 = 22.5 × 20% = 4.5万元

基准年税后营业现金净流量 = 100 - 69 + 4.5 = 35.5万元

年金现值系数(10%,4年) = 3.1699

每年税后营业现金净流量总现值 = 35.5 × 3.1699 = 112.53万元

基准净现值 = 112.53 - 90 = 22.53万元
```

## 临界值计算

**令NPV=0，则每年税后营业现金净流量总现值必须等于90万元**

```
临界年税后营业现金净流量 = 90 ÷ 3.1699 = 28.39万元
```

### 每年税后营业现金流入最小值

```
X - 69 + 4.5 = 28.39
X = 92.89万元
```

**结论：** 若每年税后营业现金流入下降到92.89万元，NPV将变为0。

安全空间 = 100 - 92.89 = **7.11万元**（下降7.11%）

### 每年税后营业现金流出最大值

```
100 - Y + 4.5 = 28.39
Y = 76.11万元
```

**结论：** 若每年税后营业现金流出上升至76.11万元，NPV将变为0。

安全空间 = 76.11 - 69 = **7.11万元**（上升10.3%）
