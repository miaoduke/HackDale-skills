# 营运资本管理

## 适用场景
- 制定营运资本投资策略和筹资策略
- 评估客户信用标准
- 计算应收账款资金占用成本
- 判断企业营运资本管理策略类型
- 评估营运资本管理的风险收益特征

## 信用标准评估（5C系统）

### 信用标准定义
信用标准是指顾客获得企业的交易信用所应具备的条件。如果顾客达不到信用标准，便不能享受企业的信用优惠或只能享受较低的信用优惠。

### 5C系统评估框架

1. **品质**
   - 定义：顾客的信誉，即履行偿债义务的可能性
   - 操作：了解顾客过去的付款记录，看其是否有按期如数付款的一贯做法
   - 重要性：经常被视为评价顾客信用的首要因素

2. **能力**
   - 定义：顾客的偿债能力，即其流动资产的数量和质量以及与流动负债的比例
   - 判断：流动资产越多，转换为现金支付款项的能力越强
   - 注意：需注意流动资产质量，避免存货过多、过时或质量下降

3. **资本**
   - 定义：顾客的财务实力和财务状况

4. **抵押**
   - 定义：顾客拒付款项或无力支付款项时能被用作抵押的资产
   - 适用场景：对不知底细或信用状况有争议的顾客尤为重要
   - 决策：如果提供足够抵押，可以考虑提供相应信用

5. **条件**
   - 定义：可能影响顾客付款能力的经济环境
   - 分析：了解顾客在过去困难时期的付款历史

### 评估目标
设定某一顾客的信用标准时，评估其赖账的可能性

## 应收账款占用资金计算

### 核心原则
需要增加的营运资金数额仅仅是变动成本，既不是全部销售额，也不是全部制造成本。

### 计算公式
```
应收账款占用资金 = 应收账款平均余额 × 变动成本率
```

其中：
- 应收账款平均余额 = 日销售额 × 平均收现期
- 变动成本率 = 变动成本 / 销售额 = 单位变动成本 / 单价

### 推导逻辑
1. 企业为赊销业务实际投入的资金仅限于变动成本部分
2. 固定成本属于沉没成本，不随赊销规模变化而新增投入
3. 销售额中的边际贡献部分是赊销带来的增值，并非企业垫付资金
4. 计算资金占用成本时，只需考虑变动成本所占用的资金

### 错误做法警示
- ❌ 按全部销售额计算：高估资金占用，导致错误的信用政策决策
- ❌ 按全部制造成本计算：可能包含固定成本分摊，同样不准确

## 激进型流动资产投资策略

### 资产配置策略
- 持有尽可能少的现金和小额的有价证券投资
- 在存货上作少量投资
- 采用严格的销售信用政策或者禁止赊销

### 财务表现
表现为安排较低的流动资产与收入比

### 成本效益分析
- **收益**：节约流动资产的持有成本，例如节约资金的机会成本
- **风险**：承担较大的风险，例如经营中断和丢失销售收入等短缺成本

## 营运资本筹资策略

### 策略定义
营运资本筹资策略是指在总体上如何为流动资产筹资，采用短期资金来源还是长期资金来源，或者兼而有之。核心是确定流动资产所需资金中短期资金和长期资金的比例。

### 衡量指标：易变现率
```
易变现率 = [(股东权益 + 长期债务 + 经营性流动负债) - 长期资产] / 经营性流动资产
```
该比率衡量经营性流动资产中长期筹资来源的比重。

### 策略类型判断

1. **保守型筹资策略**
   - 条件：易变现率高
   - 特征：资金来源的持续性强，偿债压力小，管理起来比较容易

2. **激进型筹资策略**
   - 条件：易变现率低
   - 特征：资金来源的持续性较弱，偿债压力大

3. **适中型筹资策略**
   - 介于保守型和激进型之间

### 风险分布
从最保守型筹资策略到最激进型筹资策略之间，分布着一系列风险程度不同的筹资策略。

## 输出结果
- 5C信用评估结果及信用政策建议
- 应收账款占用资金数额
- 流动资产投资策略类型及风险收益分析
- 营运资本筹资策略类型及偿债压力评估
