# 公式与风险分析

## 核心计算公式

### 空头套期保值（Short Hedge）
**净损益公式**：
```
净损益 = [期货卖出价 - 期货买入价] × 数量 + [未来现货卖出价 - 现货购买价] × 数量
       = 期货盈亏 + 现货盈亏
```

**锁定价格效果**：
```
实际等价出售价格 = 原现货购买价格 + (期货卖出价 - 期货买入价) + (未来现货卖出价 - 原现货购买价)
                 ≈ 期货开仓价 ± 基差变化
```

### 多头套期保值（Long Hedge）
**净成本公式**：
```
净成本变化 = [未来现货购买价 - 现货当前参考价] × 数量 - [期货平仓价 - 期货开仓价] × 数量
           = 现货额外成本 - 期货盈利
```

**锁定价格效果**：
```
实际等价购买价格 = 当前现货参考价格 + 净成本变化/数量
                 ≈ 期货开仓价 ± 基差变化
```

### 基差（Basis）分析
```
基差 = 现货价格 - 期货价格

基差变化对对冲结果的影响：
- 基差走强（现货相对期货涨幅更大或跌幅更小）：
  * 空头套保：有利（期货亏损减少或盈利增加）
  * 多头套保：不利（期货盈利减少或亏损增加）
  
- 基差走弱（现货相对期货跌幅更大或涨幅更小）：
  * 空头套保：不利
  * 多头套保：有利
```

## 主要风险详解

### 1. 基差风险（Basis Risk）
**定义**：期货与现货价格变动幅度不完全一致，导致无法100%对冲价格风险。

**产生原因**：
- **品质差异**：期货合约规定标准品质，实际现货可能存在品质升贴水
- **地点差异**：期货交割地点与现货交易地点不同，存在运输成本差异
- **时间差异**：期货到期日与现货交易日期不完全匹配

**量化**：
```
基差风险 = σ_基差 × 对冲数量
其中 σ_基差 是基差变化的标准差
```

### 2. 保证金风险（Margin Risk）
**机制**：期货采用每日无负债结算制度（Mark-to-Market），亏损当日从保证金账户扣除。

**风险表现**：
- 价格向不利方向变动时，需追加保证金（Margin Call）
- 资金不足时会被强制平仓，导致对冲失败
- 即使最终价格回归，中途追加资金压力可能导致流动性危机

**管理方法**：
- 预留充足流动资金（通常为期货合约价值的10-20%）
- 设置止损线，避免过度亏损
- 考虑使用期权组合替代部分期货头寸，降低保证金压力

### 3. 数量不匹配风险（Quantity Mismatch）
**问题**：期货合约有固定交易单位（如铜期货5吨/手，外汇期货125,000单位/手），现货数量可能不是整数倍。

**影响**：
- **过度对冲（Over-hedge）**：期货数量 > 现货数量，暴露额外期货投机风险
- **对冲不足（Under-hedge）**：期货数量 < 现货数量，部分现货敞口未受保护

**案例二中的数量不匹配**：
- 现货：300,000 CHF
- 期货：250,000 CHF（2份合约）
- 未对冲敞口：50,000 CHF（16.7%风险暴露）

### 4. 交叉对冲风险（Cross Hedging）
**定义**：当期货标的资产与现货资产不完全相同时（如用铝期货对冲铜现货风险）。

**风险**：
- 两种资产价格相关性不完美（ρ < 1）
- 可能出现现货涨、期货跌的背离情况

**最优对冲比率**：
```
h = ρ × (σ_S / σ_F)

其中：
- h：最优对冲比率
- ρ：现货与期货价格变化的相关系数
- σ_S：现货价格变化的标准差
- σ_F：期货价格变化的标准差

期货合约数量 = h × (现货总价值 / 单份期货合约价值)
```

## 决策检查清单

**执行套期保值前必须确认**：
- [ ] 未来交易时间和数量是否已确定？（不确定性高时不适合套保）
- [ ] 价格风险敞口方向是否明确？（担心涨→多头，担心跌→空头）
- [ ] 期货市场是否存在对应标的合约？
- [ ] 合约到期月份是否覆盖现货交易时间？
- [ ] 是否有足够资金支付初始保证金和潜在追加？
- [ ] 基差历史波动是否在可接受范围？（基差风险 < 价格风险）
- [ ] 对冲数量是否能与合约单位匹配？（能否接受部分对冲？）

**对冲期间监控要点**：
- 每日检查保证金余额
- 跟踪基差变化趋势
- 评估是否提前平仓或展期（Roll Over）
