# 期货套期保值策略

通过建立与现货市场相反的期货头寸，对冲未来价格波动风险，锁定交易成本或销售收入。

## 套保类型选择

**执行空头套期保值（Short Hedge）如果：**
- 当前持有现货资产或确定未来将获得资产
- 未来某时点需要出售该资产（如商品交付、外汇收款）
- 担心未来价格下跌导致出售收入减少

**执行多头套期保值（Long Hedge）如果：**
- 未来某时点需要买入标的资产（如原材料采购、外汇支付）
- 目前未持有该资产但确定未来需要（现货空头）
- 担心未来价格上涨导致购买成本增加

## 空头套期保值操作流程

1. **风险识别**：确认未来出售资产的时间、数量和当前持仓成本，评估价格下跌风险敞口
2. **建立空头**：在期货市场卖出相应数量的期货合约，建立与现货多头相反的头寸
3. **持仓监控**：每日跟踪期货与现货价格变化（基差），准备追加保证金
4. **平仓对冲**：在未来出售现货资产的同时，在期货市场买入相同数量期货合约平仓
5. **效果核算**：计算净损益 = 期货盈亏（卖出价-买入价）+ 现货盈亏（未来卖出价-原购买价）

**盈亏机制**：
- 价格下跌：现货亏损被期货盈利弥补，锁定原预期出售价格
- 价格上涨：现货额外收益被期货亏损抵消，产生机会成本但锁定价格确定性

## 多头套期保值操作流程

1. **风险识别**：确认未来购买资产的时间和数量，评估价格上涨风险敞口
2. **建立多头**：在期货市场买入相应数量的期货合约，建立与现货空头相反的头寸
3. **持仓监控**：监控保证金要求和基差变化，确保资金充足
4. **平仓对冲**：在未来购买现货资产的同时，在期货市场卖出相同数量期货合约平仓
5. **效果核算**：计算净成本 = 现货成本变化（未来购买价-当前参考价）- 期货盈利（平仓价-开仓价）

**盈亏机制**：
- 价格上涨：现货额外成本被期货盈利弥补，锁定原预期购买价格
- 价格下跌：现货节省成本被期货亏损抵消，产生机会成本但获得价格确定性

## 关键风险控制

- **基差风险**：期货与现货价格变动幅度可能不同（基差变化），导致不完全对冲或额外损益
- **保证金管理**：期货采用每日无负债结算，价格不利变动时需追加保证金（Margin Call），资金规划不足可能被迫提前平仓
- **数量匹配**：期货合约有固定规格（如每份125,000瑞士法郎），现货数量可能无法完全匹配，导致过度对冲或对冲不足
- **交叉对冲风险**：当期货标的与现货资产不完全相同时（如用铜期货对冲铝现货），价格相关性风险增加
