# 股权结构决策

## 适用场景
- 股东需要决定是否参与配股
- 公司考虑进行股票分割
- 公司计划回购本公司股份
- 分析股权结构变化对股东财富的影响

## 配股参与决策分析

### 分析前提
不考虑新募集资金投资产生净现值引起的企业价值变化，即配股后股票的价格等于配股除权参考价。

### 情景一：所有股东均参与配股

#### 计算步骤
1. 配股前股票价值 = 持股数量 × 配股前股价
2. 可认购新股 = 持股数量 × 配股比例
3. 认购支出 = 可认购新股 × 配股价格
4. 配股后持股 = 原持股数量 + 可认购新股
5. 配股后股票总价值 = 配股后持股 × 配股除权参考价
6. 财富变化分析：
   - 股票价值增加 = 配股后股票总价值 - 配股前股票价值
   - 净财富变化 = 股票价值增加 - 认购支出

#### 结论
股东财富没有变化

### 情景二：该股东不参与配股，但其他股东参与

#### 计算步骤
1. 配股后股数 = 原总股数 + 其他股东认购股数（该股东放弃认购部分）
2. 配股后股票价格 = (原总市值 + 认购资金) / 配股后总股数
3. 该股东配股后持股 = 原持股数量（不变）
4. 该股东股票价值 = 配股后持股 × 配股后股票价格
5. 财富损失 = 配股前股票价值 - 配股后股票价值

#### 结论
股东财富损失

### 核心决策规则
- 若所有股东都参与：参与配股→财富不变；不参与→财富受损
- **理性选择**：必须参与配股以避免财富被稀释
- 关键机制：不参与配股的股东将承担股权稀释损失，其持股比例下降且无法享受低价认购的收益

## 股票分割影响分析

### 每股收益(EPS)计算逻辑

#### 计算公式
```
每股收益 = 净利润 ÷ 流通在外普通股股数
```

#### 数学关系
```
新EPS = 原EPS ÷ 分割倍数
```

### 每股市价影响分析

#### 核心假设
市盈率(P/E ratio)保持不变

#### 价格传导机制
股价 = EPS × 市盈率，因此EPS下降，理论股价也按相同比例下降

### 公司价值守恒原理
```
公司总价值 = 每股市价 × 总股数
```
股票分割不改变公司总价值，仅改变股份数量和单股价格。

### 重要提示
上述计算基于"市盈率不变"假设，实践中股票分割常被视为"公司正处于发展之中"的积极信号，可能推动市盈率上升，从而使实际股价降幅小于理论值。

## 股票回购法定情形

### 法定允许回购的六种情形（exhaustive list）
1. **减少公司注册资本**
2. **与持有本公司股份的其他公司合并**
3. **将股份奖励给本公司职工**（Employee Stock Awards/ESOP）
4. **股东因对股东会作出的合并、分立决议持异议，要求公司收购其股份**（Appraisal Rights/Dissenter's Rights）
5. **将股份用于转换公司发行的可转换为股票的公司债券**（Convertible Bond Conversion）
6. **上市公司为维护公司价值及股东权益所必需**（Market Value Protection - 仅限上市公司）

### 交易方式强制性要求

#### 适用范围
情形三、五、六（员工奖励、可转债转换、维护市值）

#### 强制方法
必须通过公开的集中交易方式进行

#### 禁止
协议转让等非公开方式（针对上述三种情形）

### 绝对禁止事项
公司不得接受本公司的股份作为质权的标的（即禁止以本公司股票作为质押物提供融资）。

## 执行步骤

### 配股决策分析
1. 获取配股方案（配股比例、配股价格、配股前股价）
2. 计算配股除权参考价
3. 分析参与配股的财富影响
4. 分析不参与配股的财富影响
5. 比较两种情景，做出决策

### 股票分割评估
1. 确定分割比例（如1:2表示1股变2股）
2. 计算分割后EPS
3. 基于市盈率不变假设估算新股价
4. 验证公司总价值守恒
5. 评估信号效应可能带来的溢价

### 股票回购合规检查
1. 确认回购目的
2. 对照六种法定情形，确认属于其中之一
3. 如属于情形三、五、六，确认通过公开集中交易方式进行
4. 确保不违反禁止事项（不接受本公司股份作为质押标的）
