# 非财务指标详细说明

## 顾客维度指标计算方法

### 市场份额
```
市场份额 = （企业销售额 / 目标市场总销售额）× 100%
```

### 顾客满意度
- 采用Likert量表（1-5分或1-7分）
- 需定期进行客户调查
- 样本需具有代表性

### 顾客忠诚度
```
复购率 = （重复购买客户数 / 总客户数）× 100%
留存率 = （期末客户数 - 期内新增客户数） / 期初客户数 × 100%
```

## 内部营运维度指标计算方法

### 准时交付率
```
准时交付率 = （按时交付订单数 / 总订单数）× 100%
```

### 存货周转率
```
存货周转率 = 营业成本 / 平均存货余额
存货周转天数 = 365 / 存货周转率
```

### 产品合格率
```
合格率 = （合格产品数 / 总产品数）× 100%
缺陷率 = （缺陷产品数 / 总产品数）× 100%
```

## 学习成长维度指标计算方法

### 员工流动率
```
员工流动率 = （期内离职员工数 / 期内平均员工总数）× 100%
```

### 员工满意度
- 采用匿名调查方式
- 涵盖工作环境、薪酬福利、发展机会等维度
- 建议每半年或每年进行一次

## 数据收集建议

### 定量指标
- 建立自动化数据采集系统
- 确保数据来源唯一性
- 定期进行数据校验

### 定性指标
- 设计标准化问卷
- 培训调查人员
- 建立数据审核机制
