# 预算编制方法

## 适用场景
- 编制弹性预算
- 编制销售费用预算
- 现金多余时的还款安排
- 利息计算
- 短期投资管理

## 列表法编制弹性预算

### 何时使用
需要编制弹性预算或需要评价不同业务量水平下的实际成本时。

### 执行步骤
1. **确定业务量范围**：在确定的业务量范围内，划分出若干个不同水平
2. **计算各项预算值**：分别计算变动成本、混合成本和固定成本
3. **汇总编制表格**：将各项预算值列入一个预算表格
4. **评价实际成本**：当实际业务量与表中数据不完全一致时，使用内插法计算

### 实际成本评价计算

#### 变动成本计算
```
变动总成本 = 实际业务量 × (运输费率 + 电力费率 + 材料费率)
```

#### 固定成本计算
不随业务量变动，直接使用表中固定值

#### 混合成本计算（内插法）
```
(实际业务量 - 低点业务量) / (高点业务量 - 低点业务量) = (实际预算成本 - 低点成本) / (高点成本 - 低点成本)
```

#### 总预算成本汇总
```
总预算成本 = 变动总成本 + 固定总成本 + 混合总成本
```

### 优缺点
- **优点**：不管实际业务量多少，不必经过计算即可找到与业务量相近的预算成本；混合成本中的阶梯成本和曲线成本可按总成本性态模型计算
- **缺点**：在评价和考核实际成本时，往往需要使用内插法，比较麻烦

## 销售费用预算编制

### 何时使用
需要编制销售费用预算，且销售预算已确定时。

### 执行步骤
1. **定义与目标确立**：明确销售费用预算是为实现销售预算所需安排的费用预算
2. **基础数据确立**：以销售预算为基础
3. **关系分析**：系统分析销售收入、销售利润和销售费用三者的内在关系
4. **本量利分析应用**：利用本量利分析方法，评估不同费用水平对利润的影响
5. **历史数据审查**：考察过去销售费用支出的必要性和效果
6. **预算细化**：按品种、地区、用途三个维度细化
7. **有效性验证**：确保每项费用支出都能通过本量利检验

### 预算细化维度
- **按品种**：不同产品线的销售费用分配
- **按地区**：不同销售区域的费用配置
- **按用途**：广告费、运输费、保管费等具体用途分类

### 核心原则
"费用的支出应能获取更多的收益"——边际收益大于边际费用

## 现金多余时的还款安排

### 何时使用
现金预算显示资金多余，且现金多余或不足 > 最低现金余额 + 预计利息支出时。

### 执行步骤
1. **判定现金多余**：确认现金多余或不足 > 最低现金余额 + 预计利息支出
2. **安排运用顺序**：首先偿还借款本金，其次支付利息，剩余部分投资有价证券
3. **计算短期借款利息**：借款利息 = 本金 × 年利率 × (借款月数/12)
4. **处理长期借款利息**：将长期借款利息纳入现金支出部分
5. **验证最低余额**：确保期末现金余额 ≥ 最低现金余额
6. **安排剩余资金投资**：超出最低现金余额的部分投资于有价证券

### 借款偿还原则
"期初借入，期末归还，利随本清"

### 短期借款利息计算
```
借款利息 = 本金 × 年利率 × (借款月数/12)
```

### 部分还款规则
```
最大可还款额 = 现金多余额 - 最低现金余额 - 预计利息
```

### 最低现金余额验证
```
期末余额 = 还款前现金 - 实际还款额 - 利息 ≥ 最低现金余额
```

### 剩余资金投资
```
投资金额 = 现金多余额 - 还款本金 - 利息支出 - 最低现金余额
```
