# EVA调整后资本与资本成本率调整

## 何时使用

- 采用经济增加值(EVA)进行业绩评价
- 计算调整后资本作为EVA的投入资本基数
- 根据资产负债率变化调整平均资本成本率
- 评估企业财务风险对资本成本的影响

## 第一部分：调整后资本计算

### 核心公式

```
调整后资本 = 平均所有者权益 + 平均带息负债 - 平均在建工程
```

### 公式解析

EVA计算需要确定"投入资本"，即企业**实际占用且创造当期收益**的资本总额。

| 组成部分 | 计算方法 | 含义 |
|---------|---------|------|
| **平均所有者权益** | (年初+年末)÷2 | 股东投入的资本 |
| **平均带息负债** | (年初+年末)÷2 | 需要支付利息的债务资本 |
| **平均在建工程**（扣除项） | (年初+年末)÷2 | 尚未形成生产能力的资本占用 |

### 关键约束条件

**在建工程扣除前提**：必须符合**主业规定**
- 即在建工程应与企业主营业务相关
- 非主业在建工程**不得扣除**

### 计算示例

| 项目 | 年初 | 年末 | 平均 |
|-----|------|------|------|
| 所有者权益 | 700亿元 | 900亿元 | 800亿元 |
| 带息负债 | 600亿元 | 800亿元 | 700亿元 |
| 在建工程（符合主业） | 220亿元 | 180亿元 | 200亿元 |

```
调整后资本 = 800 + 700 - 200 = 1300亿元
```

**资本构成理解**：调整后资本 = 真正创造当期收益的资本占用 = 权益资本 + 债务资本 - 未形成产能的资本

## 第二部分：资产负债率触发的资本成本率上浮

### 触发条件（必须同时满足）

1. **资产负债率高于上年**：本年资产负债率 > 上年资产负债率
2. **达到特定阈值区间**：资产负债率落入对应行业的规定区间

### 行业分类与调整标准

#### 第一档调整（上浮0.2个百分点）

| 企业类型 | 资产负债率区间 |
|---------|--------------|
| 科研技术企业 | 65%（含）至 70% |
| 工业企业 | 70%（含）至 75% |
| 非工业企业 | 75%（含）至 80% |

#### 第二档调整（上浮0.5个百分点）

| 企业类型 | 资产负债率区间 |
|---------|--------------|
| 科研技术企业 | 70%（含）以上 |
| 工业企业 | 75%（含）以上 |
| 非工业企业 | 80%（含）以上 |

### 判断流程

```
步骤1：计算本年资产负债率和上年资产负债率
        资产负债率 = 负债总额 ÷ 资产总额

步骤2：判断是否满足"本年 > 上年"
        若不满足 → 无需调整
        若满足 → 进入步骤3

步骤3：判定企业行业类型
        科研技术企业 / 工业企业 / 非工业企业

步骤4：根据行业类型查表确定适用区间

步骤5：确定调整幅度
        第一档区间 → 上浮0.2个百分点
        第二档区间 → 上浮0.5个百分点
        未达区间 → 不调整
```

### 计算示例

**甲公司（电力企业，属工业企业）**：
- 年末资产负债率 = (200+800)÷(200+800+900) = 1000÷1900 = **52.63%**
- 年初资产负债率 = (150+600)÷(150+600+700) = 750÷1450 = **51.72%**

**判断**：
1. 52.63% > 51.72% ✓（高于上年）
2. 52.63% < 65%（工业企业第一档下限）✗（未达区间）

**结论**：无需上浮调整

## 关键要点总结

| 项目 | 核心规则 |
|-----|---------|
| 调整后资本 | 权益+带息负债-在建工程（须符合主业） |
| 资本成本调整 | 双条件触发：同比升高 + 达阈值区间 |
| 行业差异 | 科研技术/工业/非工业适用不同阈值 |
| 政策意图 | 对财务风险上升的企业增加资本成本惩罚 |
