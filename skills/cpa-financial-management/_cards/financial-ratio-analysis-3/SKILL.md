# 财务比率分析

## 适用场景
- 评估企业用经营活动现金流量支付利息的能力
- 评价企业整体资产运营效率
- 进行资产综合利用能力分析
- 与同行业比较判断财务水平

## 现金流量利息保障倍数

### 何时使用
需要评估企业用经营活动现金流量支付利息的能力，且希望获得比利润基础更可靠的指标时。

### 执行步骤
1. **获取数据**：经营活动现金流量净额、利息支出
2. **计算倍数**：现金流量利息保障倍数 = 经营活动现金流量净额 ÷ 利息支出
3. **解读结果**：倍数越高，利息支付保障能力越强

### 核心公式
```
现金流量利息保障倍数 = 经营活动现金流量净额 ÷ 利息支出
```

### 指标优势
比利润基础的利息保障倍数更为可靠，因为实际支付利息的是现金而非利润。

## 总资产周转率

### 何时使用
需要评估企业整体资产运营效率或进行资产综合利用能力分析时。

### 三种计算方法

#### 方法一：总资产周转次数（频率角度）
```
总资产周转次数 = 营业收入 ÷ 总资产
```
经济含义：1年中总资产周转的次数，数值越高效率越高

#### 方法二：总资产周转天数（时间角度）
```
总资产周转天数 = 365 ÷ 总资产周转次数
```
经济含义：总资产周转一次需要的时间，数值越低效率越高

#### 方法三：总资产与收入比（投资强度角度）
```
总资产与收入比 = 总资产 ÷ 营业收入
```
经济含义：每1元营业收入需要的总资产投资，数值越低效率越高

### 执行步骤
1. **获取数据**：营业收入、总资产（流动资产+非流动资产）
2. **选择计算方法**：根据分析目的选择次数、天数或收入比
3. **计算指标**：应用相应公式
4. **分析评价**：与历史数据、同行业数据比较

### 指标关系
- 周转次数与周转天数互为倒数（以365天为基准）
- 周转次数与收入比互为倒数
- 三种指标结论方向一致
