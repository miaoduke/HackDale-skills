## 现金流量利息保障倍数计算示例

### ABC公司数据
- 经营活动现金流量净额：246万元
- 利息支出：110万元

计算：
```
现金流量利息保障倍数 = 246 ÷ 110 = 2.24
```

解读：每1元利息支出有2.24元经营现金净额保障

## 总资产周转率计算示例

### ABC公司数据
- 营业收入：3000万元
- 总资产：2000万元

计算：
```
总资产周转次数 = 3000 ÷ 2000 = 1.5（次/年）
总资产周转天数 = 365 ÷ 1.5 = 243.3（天/次）
总资产与收入比 = 2000 ÷ 3000 = 66.7%
```

### 指标分解
```
总资产周转率 = 营业收入 ÷ (流动资产 + 非流动资产)
```
受流动资产周转率和非流动资产周转率的共同影响

### 评价标准
- 周转次数 > 1 通常被视为较好水平
- 需结合行业特性判断
- 与同行业比较判断资产运营水平
