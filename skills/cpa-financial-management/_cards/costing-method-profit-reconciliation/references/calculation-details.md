# 利润差异计算详细说明

## 公式推导逻辑

### 完全成本法
产品成本 = 直接材料 + 直接人工 + 变动制造费用 + **固定制造费用**

### 变动成本法
产品成本 = 直接材料 + 直接人工 + 变动制造费用
固定制造费用 = 期间费用（全部当期扣除）

### 利润差异来源
当存货水平变动时，完全成本法下存货会吸收或释放固定制造费用，而变动成本法下固定制造费用始终全部计入当期损益。

## 计算步骤详解

1. **确定存货数量**
   - 期初存货数量（件）
   - 期末存货数量（件）

2. **确定单位固定制造费用**
   - 根据存货计价方法（先进先出法、加权平均法等）确定
   - 期初存货单位固定制造费用
   - 期末存货单位固定制造费用

3. **代入公式计算**
   ```
   ΔP = 期末存货固定制造费用 - 期初存货固定制造费用
      = (期末数量 × 期末单位费用) - (期初数量 × 期初单位费用)
   ```

## 典型情形分析

### 情形一：产量 > 销量（存货增加）
- 部分固定制造费用被期末存货吸收
- 完全成本法下当期扣除的固定制造费用较少
- **结果：完全成本法利润 > 变动成本法利润（ΔP > 0）**

### 情形二：产量 < 销量（存货减少）
- 期初存货释放的固定制造费用加入当期成本
- 完全成本法下当期扣除的固定制造费用较多
- **结果：完全成本法利润 < 变动成本法利润（ΔP < 0）**

### 情形三：产量 = 销量（存货不变）
- 两法下计入当期的固定制造费用相同
- **结果：两法利润相等（ΔP = 0）**

## 注意事项
- 需明确存货计价方法以确定单位固定制造费用
- 假设发行人不违约，持有到期
- 该方法仅反映当期利润差异，不涉及现金流差异
