# 变动成本法与完全成本法利润差异计算

## 适用场景
- 对比两种成本核算方法下的当期利润
- 从变动成本法利润推算完全成本法利润（或反向）
- 分析存货变动对利润的影响

## 核心公式

### 利润差异计算
```
ΔP = (期末存货数量 × 期末单位固定制造费用) - (期初存货数量 × 期初单位固定制造费用)
```

其中：
- **P1** = 完全成本法下的当期利润
- **P2** = 变动成本法下的当期利润
- **ΔP** = P1 - P2（两种方法的利润差额）

## 利润转换关系
```
P1 = P2 + ΔP
P2 = P1 - ΔP
```

## 结果解读

| ΔP 情况 | 含义 | 原因 |
|--------|------|------|
| ΔP > 0 | 完全成本法利润 > 变动成本法利润 | 期末存货吸收的固定制造费用 > 期初存货释放的固定制造费用 |
| ΔP < 0 | 完全成本法利润 < 变动成本法利润 | 期末存货吸收的固定制造费用 < 期初存货释放的固定制造费用 |
| ΔP = 0 | 两法利润相等 | 存货数量无变化，或单位固定制造费用相同 |

## 实际应用

若日常采用变动成本法核算，可利用此关系调整存货成本、营业成本，使对外报告符合完全成本法要求。

## 关键驱动因素
利润差异的唯一来源：**存货中固定制造费用的变动**
- 产量 > 销量 → 存货增加 → 固定制造费用递延 → 完全成本法利润较高
- 产量 < 销量 → 存货减少 → 固定制造费用释放 → 完全成本法利润较低
