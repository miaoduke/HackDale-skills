# 利润敏感分析中的最大最小法

## 何时使用
- 需要确定各参数变化导致企业由盈利转为盈亏平衡的临界界限
- 进行利润敏感性分析
- 评估经营风险
- 制定参数变化应对策略
- 预先掌握参数变化的影响程度

## 基本原理

最大最小法通过设定利润为零（盈亏平衡点），求解各参数的临界值，确定参数允许变动的最大或最小范围。

## 计算步骤

### 步骤1：计算当前预计利润
```
P = 产销量 × (销售单价 - 单位变动成本) - 固定成本
```

### 步骤2：设定临界条件
设定利润 P = 0，即企业由盈利转为盈亏平衡的临界点

### 步骤3：计算各参数临界值

#### (1) 销售单价最小值
```
产销量 × (SP - 单位变动成本) - 固定成本 = 0
```
求解 SP，得到单价下降的最低临界值

#### (2) 单位变动成本最大值
```
产销量 × (销售单价 - VC) - 固定成本 = 0
```
求解 VC，得到单位变动成本上升的最高临界值

#### (3) 固定成本最大值
```
产销量 × (销售单价 - 单位变动成本) - FC = 0
```
求解 FC，得到固定成本上升的最高临界值

#### (4) 销售量最小值（盈亏临界点销售量）
```
销售量最小值 = 固定成本 / (销售单价 - 单位变动成本)
```

### 步骤4：计算允许变动幅度
```
允许变动百分比 = (临界值 - 原值) / 原值 × 100%
```

## 决策应用

经营者利用这些界限值（最大值或最小值）预先掌握参数变化的影响程度，以便在变化发生时及时采取对策，调整企业计划。

## 风险评估

- 允许变动幅度越小：参数越敏感，风险越大
- 允许变动幅度越大：参数越不敏感，风险越小
- 重点关注敏感参数：加强监控和管理

## 注意事项

- 假设除待求变量外的其他参数都是确定不变的
- 基于无利息支出和所得税的假设（如需考虑需调整公式）
- 适用于单一产品分析
- 临界值分析为决策提供参考，实际决策需综合考虑其他因素
