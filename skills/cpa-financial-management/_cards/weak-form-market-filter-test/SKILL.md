# 弱式有效市场过滤检验

## 使用场景
当需要以下情况时使用此技能：
- 通过交易策略绩效比较检验市场弱式有效性
- 评估基于历史价格变动的交易规则是否有效
- 验证证券价格是否存在系统性变动趋势
- 比较主动交易策略与被动持有策略的收益

## 检验原理

通过制定基于历史价格变动的交易规则（过滤规则）买卖股票，测定其收益率并与"简单购买/持有"策略比较：
- 如果过滤规则无法获得超额收益 → 市场达到弱式有效
- 如果过滤规则获得超额收益 → 市场未达到弱式有效

## 执行步骤

### 1. 设定过滤参数
- 确定过滤阈值 x%（如 5%）
- 准备历史价格数据
- 准备简单购买/持有策略的收益数据作为基准

### 2. 执行过滤交易规则
- **买入规则**：当股价上涨 x% 时立即买入持有
- **卖出规则**：待股价相较于购入成本下跌 x% 时卖出
- **再买入规则**：待股价相较于前次卖出价上升 x% 时再买入
- **卖空规则**：当证券价格从前一次下降中上涨 x% 时，卖出并做卖空
- **循环操作**：按特定规则不断重复进行

### 3. 计算收益率
- 计算过滤策略的总收益率（包含所有买卖交易的盈亏）
- 计算同期"简单购买/持有"策略的收益率

### 4. 比较与判定
- 计算超额收益 = 过滤策略收益率 - 简单购买/持有收益率
- 根据超额收益判定市场有效性

## 判定标准

| 条件 | 结论 |
|------|------|
| 过滤策略收益率 > 简单购买/持有收益率 | 市场未达到弱式有效，存在系统性趋势 |
| 过滤策略收益率 ≤ 简单购买/持有收益率 | 市场达到弱式有效，无系统性趋势 |

## 约束条件
- 假设可以无成本地执行买卖操作
- 适用于存在系统性价格趋势的市场检验
- 需要长期交易数据以计算平均收益

## 输出结果
```
过滤策略收益率为[X%]，简单购买/持有策略收益率为[Y%]，超额收益为[Z%]，判定市场[达到/未达到]弱式有效
```
