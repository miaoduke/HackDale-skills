# 杠杆与盈亏平衡分析

## 适用场景
- 企业长期资本筹资决策
- 比较不同筹资方案的每股收益
- 确定企业不亏不盈时的销售量
- 评估营业收入变化对每股收益的综合影响
- 平衡经营风险与财务风险
- 进行本量利分析

## 每股收益无差别点分析法

### 基本原理
每股收益无差别点法是指计算不同筹资方案下企业的每股收益（EPS）相等时所对应的息税前利润（EBIT）。判断原则是比较不同筹资方式能否给股东带来更大的每股收益。

### 核心计算公式
```
EPS = [(EBIT - I)(1 - T) - PD] ÷ N
```

其中：
- EBIT：每股收益无差别时的息税前利润
- I：年利息支出
- T：企业所得税税率
- PD：支付的优先股股利
- N：筹资后流通在外的普通股股数

### 求解无差别点
令两个方案的EPS相等，建立方程：
```
[(EBIT - I₁)(1 - T) - PD₁] ÷ N₁ = [(EBIT - I₂)(1 - T) - PD₂] ÷ N₂
```
解方程求出EBIT值，即为每股收益无差别点。

### EBIT-EPS分析图绘制逻辑

**长期债务筹资**：起点为横轴（EBIT）上等于利息支出的点（EBIT = I）。必须有足够的息税前利润支付利息。

**优先股筹资**：起点为横轴上足以支付优先股股利的息税前利润点（EBIT = PD ÷ (1 - T)）。因为优先股股利在税后支付，需还原为税前利润。

**普通股筹资**：以0为起点，因为没有固定性财务费用。

### 决策判断规则

**比较预期EBIT与无差别点EBIT**
- 若预期EBIT > 无差别点EBIT：选择具有固定筹资成本的方案（如债务或优先股），因其能提供更高的每股收益
- 若预期EBIT < 无差别点EBIT：选择普通股筹资方案，因其能提供更高的每股收益

**稳定性分析**
预期盈利水平与每股收益无差别点对应的盈利水平距离越远，优势越明显，状态稳定性越高。

**特殊情况（债务 vs 优先股）**
若长期债务线与优先股线平行（斜率相同），则不会产生无差别点。此时债务筹资在任何同一预期收益条件下均比发行优先股能提供更高的每股收益。

## 盈亏平衡点分析

### 基础公式定义
息税前利润（EBIT）的计算公式为：
```
EBIT = Q(P - V) - F
```

其中：
- EBIT：息税前利润
- Q：产品销售数量
- P：单位销售价格
- V：单位变动成本
- F：固定经营成本总额

### 盈亏平衡点定义
当企业的营业收入总额与成本总额相等时，即当息税前利润等于0时，达到盈亏平衡点。

### 盈亏平衡点销售数量（Q_BE）计算公式
设 EBIT = 0，即 Q_BE(P - V) - F = 0
```
Q_BE = F ÷ (P - V)
```

### 结果分析与判断逻辑

**盈利状态**
当实际销售量（Q）超过盈亏平衡点（Q > Q_BE）时，企业处于盈利状态。此时距离盈亏平衡点越远，利润越大。

**亏损状态**
当实际销售量（Q）跌到盈亏平衡点以下（Q < Q_BE）时，企业处于亏损状态。此时距离盈亏平衡点越远，亏损越大。

## 联合杠杆系数（DTL）

### 概念定义
联合杠杆（又称总杠杆）是指由于固定经营成本和固定融资成本的存在而导致的每股收益变动率大于营业收入变动率的杠杆效应。它直接考察营业收入的变化对每股收益的影响程度。

### 定义表达式
```
DTL = 每股收益变化的百分比 ÷ 营业收入变化的百分比 = (ΔEPS/EPS) ÷ (ΔS/S)
```

### 关系表达式
```
DTL = DOL · DFL
```

### 具体计算公式

**基于销量**
```
DTL = Q(P-V) ÷ [Q(P-V) - F - I - PD/(1-T)]
```

**基于EBIT**
```
DTL = (EBIT + F) ÷ [EBIT - I - PD/(1-T)]
```

### 管理意义与应用

**影响估计**
使管理层在一定的成本结构与资本结构下，当营业收入变化时，能够对每股收益的影响程度作出判断。例如，如果一家企业的联合杠杆系数是3，则说明当营业收入每增长（减少）1倍，就会造成每股收益增长（减少）3倍。

**风险管理**
通过经营杠杆与财务杠杆之间的相互关系，有利于管理层对经营风险与财务风险进行管理。为了控制某一联合杠杆系数，经营杠杆和财务杠杆可以有很多不同的组合：
- 组合策略A：经营杠杆系数较高的企业可以在较低的程度上使用财务杠杆
- 组合策略B：经营杠杆系数较低的企业可以在较高的程度上使用财务杠杆

企业需在考虑各相关具体因素之后作出选择。
