# 杠杆与盈亏平衡分析示例

## 盈亏平衡点计算示例
假设某企业生产产品A：
- 销售单价（P）= 50元
- 单位变动成本（V）= 25元
- 固定经营成本总额（F）= 100,000元

Q_BE = 100,000 ÷ (50 - 25) = 4,000件

## 联合杠杆系数计算示例
甲公司：
- 经营杠杆系数（DOL）= 2
- 财务杠杆系数（DFL）= 1.5

联合杠杆系数（DTL）= 2 × 1.5 = 3

含义：当营业收入每增长（减少）1倍，就会造成每股收益增长（减少）3倍。

## 每股收益无差别点示例
方案A（普通股）：I₁ = 0, N₁ = 100万股
方案B（债务）：I₂ = 50万元, N₂ = 80万股
所得税税率 T = 25%

建立方程：
[(EBIT - 0)(1 - 25%) - 0] ÷ 100 = [(EBIT - 50)(1 - 25%) - 0] ÷ 80

解得：EBIT = 250万元

决策：
- 若预期EBIT > 250万元，选择债务方案
- 若预期EBIT < 250万元，选择普通股方案
