# 利率公式与风险特征

## 利率计算公式

### 固定利率
```
票面利率 = 常数
```

### 浮动利率
```
票面利率 = 基准利率 + 利差
```

其中：
- 基准利率：SHIBOR、LPR、国债收益率等市场参考利率
- 利差：以基点（bp）表示，1基点 = 0.01%

## 风险特征

### 固定利率风险分配
- **利率下降时**：发行人承担风险（支付高于市场利率的利息）
- **利率上升时**：投资者承担风险（获得低于市场利率的收益）

### 浮动利率风险分配
- 利率风险由发行人和投资者共同分担
- 利率上升时，投资者获得更高收益
- 利率下降时，发行人降低融资成本

## 常见基准利率

### 中国市场
- **LPR**（贷款市场报价利率）：1年期、5年期以上
- **SHIBOR**（上海银行间同业拆放利率）：隔夜至1年期
- **国债收益率**：各期限国债到期收益率

### 国际市场
- **LIBOR**（已逐步退出）
- **SOFR**（担保隔夜融资利率）
- **EURIBOR**（欧元银行间同业拆放利率）
