# 永续债相较普通债券的筹资优势判定

## 适用场景
- 比较永续债与普通债券的筹资方案
- 企业希望避免未来大额现金流出、降低流动性风险
- 需要优化财务报表、降低资产负债率
- 现金流波动大或投资回收期长的项目融资

## 核心对比维度

### 维度一：本金偿还压力

| 特征 | 永续债 | 普通债券 |
|------|--------|---------|
| 本金偿还 | 不用偿还本金 | 到期必须还本 |
| 财务困境风险 | 无还本压力 | 存在刚性兑付压力 |
| 再融资风险 | 无 | 到期再融资失败可能导致违约 |
| 适用项目 | 现金流波动大、回收期长 | 现金流稳定、短期项目 |

**决策要点**：当企业希望避免未来大额现金流出时，永续债优于普通债券。

### 维度二：会计处理与财务指标

| 影响 | 永续债（权益认定） | 普通债券 |
|------|------------------|---------|
| 会计科目 | 其他权益工具 | 应付债券（负债） |
| 资产负债率 | **降低** | 提高 |
| 资本金补充 | 实质补充资本金 | 增加负债 |
| 信用评级 | 改善 | 可能恶化 |
| 债务契约风险 | 降低 | 可能触发比率限制 |

## 综合决策流程

```
步骤1：评估当前资产负债率是否接近监管红线或契约限制
    ↓
步骤2：预测未来现金流是否足以覆盖普通债券到期本金
    ↓
步骤3：判断永续债条款是否符合会计准则权益工具认定条件
    （利息递延权、无强制付息义务等）
    ↓
步骤4：决策
    ├── 若步骤1-3答案为"是" → 优先选择永续债
    └── 若现金流充裕且希望低成本 → 选择普通债券
```

## 权益认定关键条件
永续债需符合以下条件才能计入权益：
- 发行人拥有利息递延支付权
- 无强制付息义务
- 无强制赎回条款或赎回条款不构成交付现金的合同义务
- 清偿顺序劣后于普通债务

## 输出结果
筹资方式建议及财务影响预测：
- 选择永续债：资产负债率变化[具体数值]，未来现金流压力[低]
- 选择普通债券：资本成本[较低]，但需规划到期偿付资金
