# 在产品成本分配示例

## 方法一示例

某企业月末在产品数量很少，价值很低，各月数量稳定。
- 本月生产费用：100,000元

分配结果：
- 完工产品成本：100,000元
- 在产品成本：0元

## 方法二示例

某企业年初在产品成本为50,000元，各月在产品数量变动不大。
- 1-11月每月生产费用：80,000元
- 12月实际盘点在产品数量，计算年末在产品成本为55,000元

分配结果：
- 1-11月每月：完工产品成本=80,000元，在产品成本=50,000元
- 12月：完工产品成本=80,000元+差额调整，在产品成本=55,000元

## 方法三示例

某企业原材料费用占比70%，生产开始时一次投入。
- 原材料费用总额：70,000元
- 完工产品数量：900件
- 在产品数量：100件
- 直接人工：20,000元
- 制造费用：10,000元

计算：
```
原材料费用分配率 = 70,000 ÷ (900 + 100) = 70元/件
完工产品原材料费用 = 900 × 70 = 63,000元
在产品原材料费用 = 100 × 70 = 7,000元
完工产品成本 = 63,000 + 20,000 + 10,000 = 93,000元
在产品成本 = 7,000元
```
