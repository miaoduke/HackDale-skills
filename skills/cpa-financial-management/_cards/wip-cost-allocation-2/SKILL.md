# 在产品成本分配方法

## 方法一：不计算在产品成本法

### 适用条件（需同时满足）
1. 月末有结存在产品
2. 月末在产品数量很少
3. 月末在产品价值很低
4. 各月在产品数量比较稳定

### 成本分配处理
```
月末在产品成本 = 0
完工产品成本 = 本月发生的全部生产费用
```

### 理论依据
- 重要性原则：在产品成本对总成本影响微小
- 成本效益原则：精确计算的成本高于收益

---

## 方法二：在产品成本按年初数固定计算法

### 适用条件（满足任一情形即可）
1. 月末在产品数量很少
2. 在产品数量虽多，但各月之间在产品数量变动不大
3. 月初、月末在产品成本的差额对完工产品成本影响不大

### 日常核算处理（1-11月）
```
本月完工产品成本 = 本月发生的生产费用
各月在产品成本 = 年初固定数
```

### 年终调整处理（12月必须执行）
1. 根据实地盘点的在产品数量，重新调整计算在产品成本
2. 按实际盘点数量×定额或实际成本计算年末在产品成本
3. 将全年累计的偏差在本年最后一次成本计算中调整

### 风险控制
- 年终实地盘点是关键控制点，必须严格执行
- 若年度内生产条件发生重大变化，应提前调整

---

## 方法三：在产品成本按所耗原材料费用计算法

### 适用条件（必须同时满足）
1. 原材料费用在产品成本中所占比重较大（通常超过50%-60%）
2. 原材料是在生产开始时一次全部投入

### 成本项目分配规则

| 成本项目 | 在产品负担 | 完工产品负担 |
|---------|-----------|------------|
| 原材料费用 | ✓ 按实际耗用计算 | ✓ 剩余部分 |
| 直接人工 | ✗ 不负担 | ✓ 全部 |
| 制造费用 | ✗ 不负担 | ✓ 全部 |
| 其他费用 | ✗ 不负担 | ✓ 全部 |

### 原材料费用分配计算
```
原材料费用分配率 = 原材料费用总额 ÷ (完工产品数量 + 在产品数量)
完工产品原材料费用 = 完工产品数量 × 分配率
在产品原材料费用 = 在产品数量 × 分配率
```

### 完工产品成本构成
```
完工产品成本 = 完工产品原材料费用 + 全部直接人工 + 全部制造费用 + 全部其他费用
```

### 方法局限性
- 若人工费用和制造费用占比实际上升，会导致成本分配失真
- 仅适用于生产周期较短、在产品加工程度不高的场景

## 方法选择决策树

```
开始
  ↓
在产品数量很少且价值很低？
  ├─ 是 → 方法一：不计算在产品成本法
  └─ 否 ↓
        在产品数量变动不大？
          ├─ 是 → 方法二：按年初数固定计算法
          └─ 否 ↓
                原材料费用占比大且一次投入？
                  ├─ 是 → 方法三：按所耗原材料费用计算法
                  └─ 否 → 需采用其他方法（如约当产量法）
```
