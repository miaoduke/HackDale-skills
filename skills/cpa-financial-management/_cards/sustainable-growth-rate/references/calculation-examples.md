## 可持续增长率计算示例

### 示例1：基于期初股东权益（20×1年数据）

**已知数据**：
- 营业净利率 = 5%
- 期末总资产周转次数 = 2.5641
- 期末总资产/期初股东权益 = 1.3（即390/300）
- 利润留存率 = 60%

**计算**：
```
可持续增长率 = 5% × 2.5641 × 1.3 × 60% = 10%
```

**实际增长率验证**：
```
实际增长率 = (1000 - 909.09) / 909.09 = 10%
```

### 示例2：因素变动影响分析

**基期数据**：
- 营业收入：1000万元
- 净利润：50万元
- 总资产：500万元
- 股东权益：300万元
- 股利支付：20万元

**计算基础指标**：
- 营业净利率 = 50/1000 = 5%
- 总资产周转率 = 1000/500 = 2次
- 权益乘数 = 500/300 = 1.67
- 利润留存率 = (50-20)/50 = 60%

**可持续增长率（期末权益法）**：
```
g = (5% × 2 × 1.67 × 60%) / (1 - 5% × 2 × 1.67 × 60%) = 10% / (1-10%) = 11.11%
```

### 示例3：增长过快的情景分析

**情景**：企业实际销售增长20%，但可持续增长率仅10%

**问题诊断**：
- 增长过快，财务资源紧张
- 可能后果：资金周转困难、过度负债、流动性危机

**解决方案**：
1. 提高经营效率（提高营业净利率或资产周转率）
2. 改变财务政策（提高权益乘数或利润留存率）
3. 增发新股筹集权益资本
4. 降低实际增长率目标
