## 两种计算方法的比较

| 对比维度 | 期初权益法 | 期末权益法 |
|---------|-----------|-----------|
| 公式复杂度 | 较简单，直接相乘 | 较复杂，含分母调整 |
| 权益计算 | 期初股东权益 | 期末股东权益 |
| 适用场景 | 有明确期初权益数据 | 只有期末报表数据 |
| 结果一致性 | 在精确计算下一致 | 在精确计算下一致 |
| 推荐使用 | 有期初数据时优先 | 只有期末数据时使用 |

### 公式等价性证明

在平衡增长假设下，两种方法计算结果相同：

**期初权益法**：
```
g = (净利润/期初权益) × 利润留存率
```

**期末权益法推导**：
```
期末权益 = 期初权益 + 净利润 × 利润留存率 = 期初权益 × (1 + g)

因此：g = 净利润×利润留存率/期初权益 = 净利润×利润留存率/(期末权益/(1+g))

整理得：g × 期末权益 = 净利润×利润留存率 × (1+g)

g = 净利润×利润留存率 / (期末权益 - 净利润×利润留存率)
  = (净利润/期末权益)×利润留存率 / (1 - (净利润/期末权益)×利润留存率)
  = 期末权益净利率×利润留存率 / (1 - 期末权益净利率×利润留存率)
```
