# 可持续增长率计算与分析

## 何时使用

- 企业不增发新股且不回购股票
- 维持基期经营效率（营业净利率和资产周转率不变）
- 维持基期财务政策（权益乘数和利润留存率不变）
- 测算下期销售所能达到的最大增长率
- 对比实际增长率与可持续增长率，评估财务资源紧张或闲置

## 核心概念

**可持续增长率**：在不增发新股或回购股票，不改变经营效率和财务政策的前提下，企业下期销售所能达到的增长率。

## 五项关键假设条件

| 假设 | 内容 |
|------|------|
| 假设1 | 公司营业净利率将维持基期水平，且该比率已经涵盖新增债务增加的利息 |
| 假设2 | 公司总资产周转率将维持基期水平 |
| 假设3 | 公司基期的资本结构是目标资本结构，并且打算继续维持下去（权益乘数不变） |
| 假设4 | 公司基期的利润留存率是目标利润留存率，并且打算继续维持下去 |
| 假设5 | 不愿意或者不打算增发新股（包括股份回购） |

## 计算方法

### 方法一：基于期初股东权益（推荐）

```
可持续增长率 = 期初权益本期净利率 × 本期利润留存率

或展开为：
可持续增长率 = 营业净利率 × 期末总资产周转次数 × (期末总资产/期初股东权益) × 本期利润留存率
```

**关键规则**：权益乘数使用"期初股东权益"而非期末数，其他比率采用本期发生额或期末数。

### 方法二：基于期末股东权益

```
可持续增长率 = (营业净利率 × 总资产周转率 × 权益乘数 × 利润留存率) / (1 - 营业净利率 × 总资产周转率 × 权益乘数 × 利润留存率)
```

## 四因素分解

| 因素 | 公式 | 含义 |
|------|------|------|
| 营业净利率 | 本期净利润/本期营业收入 | 经营获利能力 |
| 总资产周转率 | 本期营业收入/期末总资产 | 资产运营效率 |
| 权益乘数 | 期末总资产/股东权益 | 资本结构杠杆 |
| 利润留存率 | 利润留存/本期净利润 | 收益再投资比例 |

## 平衡增长状态

当五项假设全部成立时：
```
资产增长率 = 负债增长率 = 股东权益增长率 = 可持续增长率
```

**示例**：年初资产100万元 = 负债40万元 + 股东权益60万元
- 新增资产10万元（增长10%）
- 必须同时新增负债4万元（增长10%）和新增股东权益6万元（增长10%）

## 实际增长率对比分析

| 情形 | 含义 | 管理含义 |
|------|------|---------|
| 实际增长率 > 可持续增长率 | 增长过快 | 财务资源可能紧张，需调整政策或增发股票 |
| 实际增长率 < 可持续增长率 | 增长不足 | 财务资源闲置，需提高增长目标或调整股利政策 |
| 实际增长率 = 可持续增长率 | 平衡增长 | 当前政策可持续，维持现状 |

## 边界条件说明

不增发股票只是维持"当前"可持续增长状态的条件。如果公司增发股票或改变其他假设条件，仍然可以实现可持续增长，但可持续增长率的数值将会发生变化，需要重新计算。
