# 财务杠杆配置决策

## 何时使用

- 制定企业财务政策和资本结构目标
- 配置财务杠杆以平衡收益与风险
- 评估权益乘数水平的合理性
- 协调总资产净利率与财务杠杆的关系

## 核心机制（前提：总资产净利率不变）

```
权益净利率 = 总资产净利率 × 权益乘数
```

**杠杆效应：**
- 提高财务杠杆（权益乘数↑）→ 权益净利率↑
- 但同时 → 财务风险↑

## 核心决策困境

如何配置财务杠杆是公司**最重要的财务政策**，需要在收益提升与风险控制之间取得平衡。

## 行业经验规律（反向配置原则）

| 企业类型 | 总资产净利率 | 财务杠杆 | 配置逻辑 |
|---------|-----------|---------|---------|
| 高盈利企业 | 较高 | **较低** | 自身盈利能力强，不需依赖杠杆放大收益，保持低杠杆降低风险 |
| 低盈利企业 | 较低 | **较高** | 盈利能力有限，适度提高杠杆放大权益净利率，但需警惕风险 |

## 决策建议框架

1. **评估**当前总资产净利率水平
2. **参照**行业典型杠杆水平
3. **评估**企业自身风险承受能力
4. **确定**权益乘数目标区间
5. **建立**财务风险监控机制

## 风险警示

- 杠杆提升具有**双刃剑效应**：放大收益的同时也放大风险
- 财务风险增加表现：偿债压力上升、融资成本增加、财务灵活性下降
- 极端情况下，高杠杆可能导致财务困境甚至破产
