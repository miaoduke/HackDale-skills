# 现金流量折现法的局限性及实物期权修正

## 适用场景
- 传统净现值为负但具有战略灵活性的项目
- 未来存在重大不确定性的长期项目
- 管理者有权根据事态发展修改投资方案的项目
- 需要评估管理灵活性价值的资本预算决策

## 传统DCF的隐含缺陷

### 关键假设问题
- 假设公司会按既定方案执行，不会进行重要修改
- 假设管理者被动接受既定方案
- **忽视管理者主动管理价值**

### 现实冲突
管理者实际行为：
- 随时关注市场、技术、政策等变化
- 前景更好时 → **执行扩张期权**，加大投资
- 前景变差时 → **执行收缩/放弃期权**，减少损失

## 忽视实物期权的后果
- 折现现金流量不能提供项目价值的全部信息
- 仅反映"被动执行价值"
- **可能导致错误的资本预算决策**（过早拒绝有价值项目）

## 投资决策修正规则

### 传统标准
```
NPV > 0 → 接受
NPV < 0 → 拒绝
```

### 修正标准
```
项目总价值 = NPV（传统）+ 实物期权价值
```

### 新决策规则
```
若 NPV + 实物期权价值 > 0 → 接受项目

即使传统NPV为负，若实物期权价值足够大，也应接受
```

## 典型实物期权类型

| 期权类型 | 触发条件 | 价值来源 |
|---------|---------|---------|
| 扩张期权 | 市场需求超预期 | 追加投资获取更大收益 |
| 收缩期权 | 市场不及预期 | 减少投资降低损失 |
| 放弃期权 | 项目持续亏损 | 终止项目回收残值 |
| 延迟期权 | 信息尚不充分 | 等待更优时机 |

## 关键结论
只要未来是不确定的，管理者就会利用拥有的实物期权增加价值，而不是被动地接受既定方案。完全忽视项目本身的实物期权，是传统现金流量折现法的重大局限性。
