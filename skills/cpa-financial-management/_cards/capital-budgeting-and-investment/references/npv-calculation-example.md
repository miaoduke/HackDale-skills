# 新建投资项目NPV计算完整示例

## 项目背景
- 新建生产线投资
- 项目期限：5年
- 资本成本：12%
- 所得税税率：25%

## 初始投资（2023年末，第0年）
- 厂房成本：5,000万元
- 设备购置成本：2,000万元
- 营运资本投入：200万元
- **初始投资合计：7,200万元**

## 营业现金流量计算

### 折旧计算
- 厂房折旧 = 5,000 ÷ 20 = 250万元/年（直线法，20年）
- 设备折旧 = 2,000 ÷ 5 = 400万元/年（直线法，5年）
- 总折旧 = 250 + 400 = 650万元/年

### 第1年
- 增加的销售收入 = 5,000 - 500 = 4,500万元
- 增加的变动付现成本 = 1,000 - 200 = 800万元
- 增加的固定付现成本 = 1,000万元
- 税后经营净利润 = (4,500 - 800 - 1,000 - 650) × 0.75 = 1,537.5万元
- 营业现金净流量 = 1,537.5 + 650 = 2,187.5万元

### 第2-5年
- 增加的销售收入 = 6,000 - 500 = 5,500万元
- 增加的变动付现成本 = 1,200 - 200 = 1,000万元
- 增加的固定付现成本 = 1,000万元
- 税后经营净利润 = (5,500 - 1,000 - 1,000 - 650) × 0.75 = 2,137.5万元
- 营业现金净流量 = 2,137.5 + 650 = 2,787.5万元

## 终结点现金流量（第5年末）

### 营运资本回收
- 金额：200万元

### 厂房变现
- 账面价值 = 5,000 - (250×5) = 3,750万元
- 变现价值 = 4,000万元
- 变现利得 = 4,000 - 3,750 = 250万元
- 变现利得纳税 = 250 × 25% = 62.5万元
- 厂房变现净流量 = 4,000 - 62.5 = 3,937.5万元

### 设备变现
- 账面价值 = 2,000 - (400×5) = 0万元
- 变现价值 = 0万元
- 设备变现净流量 = 0万元

### 第5年总现金流量
- 营业现金流量：2,787.5万元
- 营运资本回收：200万元
- 厂房变现净流量：3,937.5万元
- **合计：6,925万元**

NPV = 4,660.27万元 > 0，项目可行，可增加企业价值4,660.27万元
