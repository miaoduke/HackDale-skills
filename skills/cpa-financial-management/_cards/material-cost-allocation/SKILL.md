# 材料费用归集与分配

## 适用场景
- 企业在生产活动中发生材料消耗
- 需要明确材料用途（生产、维护、管理或建造）
- 几种产品共同耗用某种材料
- 消耗定额比较准确

## 费用性质界定

### 生产费用
产品生产过程中发生的材料、人工、燃料动力和制造费用等。
- 基本生产费用：基本生产车间发生的生产费用
- 辅助生产费用：辅助生产车间发生的生产费用

### 非生产费用（期间费用）
包括管理费用、销售费用和财务费用。

## 材料费用归集与分配

### 根据用途分类处理

#### 1. 计入"直接材料成本"项目
适用于构成产品实体的原料、主要材料和有助于产品形成的辅助材料。

#### 2. 列入"制造费用"项目
适用于用于维护生产设备和管理生产的各种材料。

#### 3. 列入期间费用
适用于不应计入产品成本而属于期间费用的材料费用，具体列入"管理费用"或"销售费用"。

#### 4. 构成固定资产价值
适用于用于购置和建造固定资产等的材料费用（此类费用不得列入产品成本，也不得列入期间费用）。

## 共同耗用材料的分配

### 适用条件
- 某种材料被几种产品共同耗用
- 消耗定额比较准确

### 分配方法
采用材料定额消耗量比例或材料定额成本比例进行分配。

### 计算公式

**步骤1：计算分配率**
```
分配率 = 材料总消耗量(或实际成本) ÷ 各种产品材料定额消耗量(或定额成本)之和
```

**步骤2：计算某种产品应分配的材料数量(费用)**
```
某种产品应分配的材料数量(费用) = 该种产品的材料定额消耗量(或定额成本) × 分配率
```

### 具体计算步骤

1. 确定材料总消耗量或实际成本
2. 计算各产品的材料定额消耗量(或定额成本)
3. 汇总各种产品的定额消耗量(或定额成本)之和
4. 计算分配率
5. 计算各产品应分配的材料费用
6. 验算：各产品分配费用之和应等于材料总成本

## 会计处理
- 基本生产产品材料费用记入"生产成本"科目借方及"直接材料成本"项目
- 辅助生产材料费用记入"生产成本——辅助生产成本"
- 车间及管理部门材料费用记入"制造费用""管理费用"

## 决策输出
将费用归集至：直接材料成本 / 制造费用 / 管理费用 / 销售费用 / 固定资产价值
