# 材料费用分配计算示例

## 已知条件
- 甲产品投产400件，消耗定额1.2千克/件
- 乙产品投产300件，消耗定额1.1千克/件  
- 共同耗用原材料842.4千克，单价50元/千克，总成本42,120元

## 计算过程

### 步骤1：计算各产品定额消耗量
```
甲产品定额消耗量 = 400 × 1.2 = 480千克
乙产品定额消耗量 = 300 × 1.1 = 330千克
```

### 步骤2：汇总定额消耗量
```
定额消耗量之和 = 480 + 330 = 810千克
```

### 步骤3：计算分配率
```
分配率 = 42,120 ÷ 810 = 52元/千克
```

### 步骤4：计算各产品应分配费用
```
甲产品分配费用 = 480 × 52 = 24,960元
乙产品分配费用 = 330 × 52 = 17,160元
```

### 步骤5：验算
```
24,960 + 17,160 = 42,120元 ✓
```
