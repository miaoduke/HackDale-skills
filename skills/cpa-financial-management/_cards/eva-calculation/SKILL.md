# 基本经济增加值计算

## 适用场景
- 基于未经调整的会计数据快速计算经济增加值
- 评估企业是否创造价值
- 企业业绩评价
- 财务分析

## 定义
基本的经济增加值是根据未经调整的经营利润和总资产计算的经济增加值。

## 执行步骤
1. **获取税后净营业利润**：使用未经调整的税后净营业利润
2. **获取报表平均总资产**：使用未经调整的报表平均总资产
3. **确定加权平均资本成本**：计算或获取企业的加权平均资本成本
4. **计算资本成本**：资本成本 = 报表平均总资产 × 加权平均资本成本
5. **计算经济增加值**：经济增加值 = 税后净营业利润 - 资本成本
6. **解读结果**：正值表示创造价值，负值表示毁灭价值

## 核心公式
```
基本的经济增加值 = 税后净营业利润 - 报表平均总资产 × 加权平均资本成本
```

## 变量说明
- **税后净营业利润**：未经调整的税后净营业利润
- **报表平均总资产**：未经调整的报表平均总资产
- **加权平均资本成本**：企业的加权平均资本成本

## 特点分析

### 优点
- 计算很容易
- 对于会计利润来说是个进步，因为它承认了股权资金的资本成本

### 缺点
- 由于"经营利润"和"总资产"是按照会计准则计算的，它们歪曲了公司的真实业绩
- 不适用于需要精确反映真实业绩的场景

## 结果解读
- **正值**：表示企业创造价值
- **负值**：表示企业毁灭价值
- **数值大小**：反映价值创造或毁灭的程度
