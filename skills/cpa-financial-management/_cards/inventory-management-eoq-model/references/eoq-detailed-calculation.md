# 经济订货量详细计算示例

## 示例数据（例11-6）
- D = 3600千克（年需求量）
- U = 10元（单价）
- Kc = 2元（单位储存变动成本）
- K = 25元（每次订货变动成本）

## 计算过程

### 1. 经济订货量
```
Q* = √(2 × 25 × 3600 / 2) = √(90000) = 300千克
```

### 2. 每年最佳订货次数
```
N* = 3600 / 300 = 12次
```

### 3. 与经济批量有关的存货总成本
```
TC(Q*) = √(2 × 25 × 3600 × 2) = √(360000) = 600元
```

### 4. 最佳订货周期
```
t* = 1/12年 = 1个月
```

### 5. 经济订货量占用资金
```
I* = (300/2) × 10 = 1500元
```

## 再订货点计算示例

### 已知条件
- 订货日至到货日期的时间 L = 10天
- 每日存货需求量 d = 10千克

### 计算
```
R = 10 × 10 = 100千克
```

### 操作说明
- 当库存降至100千克时，立即发出订货单
- 订货批量仍为300千克
- 经过10天交货期后，新批次货物到达
- 此时原有库存剩余量 = 100 - (10 × 10) = 0，刚好用完
