# 存货管理与经济订货量模型

## 适用场景
- 需要确定最优订货批量以最小化总成本
- 存在订货提前期，需要设置再订货点
- 需要计算存货的取得成本和储存成本
- 企业能够及时补充存货，需求量稳定可预测

## 经济订货量(EOQ)基本模型

### 前提条件（必须全部满足）
1. 企业能够及时补充存货
2. 货物能集中到货
3. 不允许缺货
4. 货物年需求量稳定且可预测
5. 存货单价不变
6. 企业现金充足
7. 所需存货市场供应充足

### 计算步骤

**步骤1：确定变量参数**
- K：一次订货变动成本
- D：存货年需求量
- Kc：单位储存变动成本
- U：存货单价

**步骤2：计算经济订货量**
```
Q* = √(2KD / Kc)
```

**步骤3：计算衍生指标**
- 每年最佳订货次数：N* = D / Q* = √(DKc / 2K)
- 与经济批量有关的存货总成本：TC(Q*) = √(2KDKc)
- 最佳订货周期：t* = 1 / N*
- 经济订货量占用资金：I* = (Q* / 2) · U

## 订货提前期下的再订货点

### 适用条件
- 存货不能随用随补充
- 存在交货延迟
- 无保险储备（安全库存为零）
- 需求率和交货时间稳定

### 计算公式
```
再订货点 R = L × d
```
其中：
- L = 平均交货时间（天）
- d = 每日平均需求量

### 操作流程
1. 监控库存水平
2. 当库存降至再订货点R时，立即发出订货单
3. 订货批量保持经济订货量Q*不变
4. 新批次货物将在库存刚好耗尽时到达

## 存货成本计算

### 取得成本 (TCa)
```
TCa = F1 + (D/Q)K + DU
```
其中：
- F1：订货固定成本
- D：年需求量
- Q：每次进货量
- K：每次订货变动成本
- U：存货单价

### 储存成本 (TCC)
```
TCC = F2 + Kc × (Q/2)
```
其中：
- F2：储存固定成本
- Kc：单位变动储存成本
- Q：每次进货量

## 决策规则
- 选择使总成本最小的订货批量
- 当库存降至再订货点时立即订货
- 订货提前期不影响经济订货量本身，只影响订货时机
