# 债权人利益保护的三层防御机制

## 适用场景

在以下情境下启动本技能：
- 设计新的债务合约或审查现有合约条款
- 监控债务人经营状况和财务决策
- 发现潜在违约风险或股东侵占债权人利益的迹象
- 处于债务合约签订前谈判阶段或存续期管理阶段

## 前提条件

- 已识别到股东可能侵占债权人利益的风险
- 处于债务合约签订前或存续期
- 受限于法律法规框架和市场谈判地位

## 三层防御体系概览

债权人利益保护采用"预防-监控-救济"的三层递进式防御架构：

1. **第一层（立法保护）**：法定权利，破产时生效
2. **第二层（契约限制）**：事前防范，通过合同条款约束
3. **第三层（合作终止）**：事后救济，主动退出止损

## 执行流程

### 第一层：立法保护（基础层）

**作用时机**：公司破产清算时自动生效

**核心权利**：
- **先行接管权**：在公司破产时，债权人可先行接管公司资产
- **优先分配权**：在破产清算时，债权人先于股东分配剩余财产

**关键认知**：
- 尽管有法定优先权，但多数情况下破产财产不足以全额偿债
- 此层为最后保障，不能依赖此层实现全额回收
- 注意：债权人优先权劣后于担保物权人、职工债权、税款等

### 第二层：契约限制（核心层）

**作用时机**：债务合约签订前（设计阶段）和存续期（监督阶段）

**核心工具**：限制性条款（Restrictive Covenants）

**设计要点**：

1. **资金用途限制**
   - 明确规定借款的具体用途
   - 禁止将资金投向高风险项目（防范资产替代风险）
   - 示例："借款应用于补充流动资金，不得用于证券投资或房地产开发"

2. **债务限额条款**
   - 规定不得发行新债或限制发行新债的额度
   - 防范债务稀释风险
   - 可设置资产负债率上限或绝对债务规模上限

3. **财务维持条款**（可选）
   - 维持一定的流动比率、资产负债率
   - 限制股利支付比例
   - 限制重大资产出售

> **详细参考**：详见 `references/restrictive-covenants-catalog.md` 获取完整条款模板和表述范例

### 第三层：合作终止与退出（行动层）

**作用时机**：发现公司有损害债权利益意图或行为时

**执行步骤**：

1. **持续监控**
   - 密切关注公司经营状况和财务决策
   - 识别风险信号：投资高风险项目迹象、过度举债、资产异常处置等
   - 定期审查财务报表和资金流水

2. **拒绝进一步合作**
   - 不再提供新的贷款
   - 切断后续融资渠道
   - 冻结未提用授信额度

3. **提前收回贷款**
   - 在合同允许的情况下，宣布贷款提前到期
   - 立即收回已发放的贷款，及时止损
   - 必要时启动担保物处置程序

**适用条件**：特别适用于发现股东有投资高风险项目或过度举债的迹象时

## 实施检查清单

- [ ] 已评估第一层保护的局限性（破产财产不足风险）
- [ ] 已在合约中设置资金用途限制条款
- [ ] 已设置债务限额或新债发行限制条款
- [ ] 已建立定期监控机制（财务报告审查、现场检查）
- [ ] 已明确约定提前收贷的触发条件和程序
- [ ] 已准备风险信号识别清单（参见 `references/risk-signals-monitoring.md`）

## 关键变量定义

- `restrictive_covenants`: 限制性条款清单（用途限制、债务限额、财务比率等）
- `debtor_risk_signals`: 债务人风险信号（投资高风险项目、发行新债、资产转移等）
- `legal_priority`: 法定优先顺位（通常债权人优先于股东，但劣后于担保物权人、职工债权等）

## 注意事项

1. **谈判地位影响**：契约条款的实际约束力取决于债权人的市场谈判地位
2. **成本权衡**：过度严格的限制条款可能增加交易成本或导致借款人拒绝签约
3. **动态调整**：根据债务人信用状况变化，适时调整监控频率和限制条件
4. **法律合规**：确保所有条款符合《民法典》《破产法》等相关法律法规
