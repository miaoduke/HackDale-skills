# 分批法与作业成本法结合计算示例

## 已知数据

### 直接材料
- 101批直接领用X材料：160,000元
- 102批直接领用X材料：100,000元
- 共同耗用Y材料：20,000千克 × 5元/千克 = 100,000元

### 产量
- 101批：2,000件
- 102批：8,000件

### 作业成本库
- 材料切割：240,000元，总次数24,000次
- 机器加工：900,000元，总工时3,000小时
- 产品组装：435,000元，总工时2,900小时

### 101批作业量
- 材料切割：12,000次
- 机器加工：2,000小时
- 产品组装：1,700小时

### 102批作业量
- 材料切割：12,000次
- 机器加工：1,000小时
- 产品组装：1,200小时

### 102批完工情况
- 完工：4,000件
- 在产品：4,000件（机器加工完工程度50%，尚未组装）

## 计算过程

### 1. 直接材料费用分配

**共同耗用Y材料分配率**：
```
分配率 = 100,000 ÷ 10,000 = 10元/件
```

**101批直接材料总额**：
```
160,000 + 2,000 × 10 = 180,000元
```

**102批直接材料总额**：
```
100,000 + 8,000 × 10 = 180,000元
```

### 2. 制造费用分配（作业成本法）

**作业成本分配率**：
```
材料切割 = 240,000 ÷ 24,000 = 10元/次
机器加工 = 900,000 ÷ 3,000 = 300元/小时
产品组装 = 435,000 ÷ 2,900 = 150元/小时
```

**101批制造费用**：
```
材料切割 = 12,000 × 10 = 120,000元
机器加工 = 2,000 × 300 = 600,000元
产品组装 = 1,700 × 150 = 255,000元
合计 = 975,000元
```

**102批制造费用**：
```
材料切割 = 12,000 × 10 = 120,000元
机器加工 = 1,000 × 300 = 300,000元
产品组装 = 1,200 × 150 = 180,000元
合计 = 600,000元
```

### 3. 完工产品与在产品成本分配

**101批（全部完工）**：
```
完工产品成本 = 180,000 + 975,000 = 1,155,000元
在产品成本 = 0元
```

**102批（部分完工）**：

直接材料（按产量比例）：
```
完工产品 = 180,000 × [4,000 ÷ (4,000 + 4,000)] = 90,000元
在产品 = 180,000 - 90,000 = 90,000元
```

材料切割作业（按产量比例）：
```
完工产品 = 120,000 × [4,000 ÷ (4,000 + 4,000)] = 60,000元
在产品 = 120,000 - 60,000 = 60,000元
```

机器加工作业（按约当产量，在产品完工程度50%）：
```
在产品约当产量 = 4,000 × 50% = 2,000件
完工产品 = 300,000 × [4,000 ÷ (4,000 + 2,000)] = 200,000元
在产品 = 300,000 - 200,000 = 100,000元
```

产品组装作业（在产品尚未组装）：
```
完工产品 = 180,000元
在产品 = 0元
```

**102批汇总**：
```
完工产品成本 = 90,000 + 60,000 + 200,000 + 180,000 = 530,000元
在产品成本 = 90,000 + 60,000 + 100,000 + 0 = 250,000元
```

### 4. 计算单位成本

```
101批单位成本 = 1,155,000 ÷ 2,000 = 577.5元/件
102批单位成本 = 530,000 ÷ 4,000 = 132.5元/件
```
