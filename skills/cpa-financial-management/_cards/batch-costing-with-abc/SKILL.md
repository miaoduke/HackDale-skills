# 分批法与作业成本法结合的成本计算

## 适用场景

- 批次生产产品（如101批M产品、102批N产品）
- 涉及共同材料耗用
- 多步骤制造费用分配
- 月末存在在产品需要分配成本

## 计算流程

### 步骤1：直接材料费用分配

#### 直接领用材料
将成本直接计入对应批次。

#### 共同耗用材料
按产品产量进行分配（前提是单耗相同）：
```
共同耗用材料总成本 = 总数量 × 单价
分配率 = 共同耗用材料总成本 ÷ 总产量
某批次分配金额 = 该批次产量 × 分配率
```

### 步骤2：制造费用分配（作业成本法）

#### 计算作业成本分配率
```
作业成本分配率 = 作业成本库总成本 ÷ 各批次作业量之和
```

#### 分配作业成本至各批次
```
某批次作业成本 = 该批次作业量 × 作业成本分配率
```

### 步骤3：完工产品与在产品成本分配

#### 直接材料分配（按产量比例）
```
完工产品成本 = 直接材料总额 × [完工产品数量 ÷ (完工产品数量 + 在产品数量)]
在产品成本 = 直接材料总额 - 完工产品成本
```

#### 材料切割作业分配（按产量比例）
```
完工产品成本 = 材料切割成本 × [完工产品数量 ÷ (完工产品数量 + 在产品数量)]
在产品成本 = 材料切割成本 - 完工产品成本
```

#### 机器加工作业分配（按约当产量）
```
在产品约当产量 = 在产品数量 × 完工程度
完工产品成本 = 机器加工成本 × [完工产品数量 ÷ (完工产品数量 + 在产品约当产量)]
在产品成本 = 机器加工成本 - 完工产品成本
```

#### 产品组装作业分配
若在产品尚未组装，则全部由完工产品负担。

### 步骤4：计算单位成本
```
单位成本 = 完工产品总成本 ÷ 完工产品数量
```

## 其他费用按约当产量法分配

### 适用对象
- 直接人工费用
- 制造费用
- 其他加工费用

### 计算步骤

#### 步骤1：分工序计算在产品约当产量
```
某工序在产品约当产量 = 该工序完工程度(%) × 该工序在产品实际数量
在产品约当产量合计 = 各工序在产品约当产量之和
```

#### 步骤2：确定费用分配的总产量基数
```
产量合计（分配基数）= 产成品数量 + 在产品约当产量合计
```

#### 步骤3：费用分配
```
费用分配率 = 待分配费用总额 ÷ 产量合计
产成品应分配费用 = 费用分配率 × 产成品数量
在产品应分配费用 = 费用分配率 × 在产品约当产量合计
```

### 平衡校验
```
产成品应分配费用 + 在产品应分配费用 = 待分配费用总额
```
