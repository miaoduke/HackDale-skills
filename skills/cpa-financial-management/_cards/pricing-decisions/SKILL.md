# 定价决策

## 使用场景
- 确定产品正常销售价格时
- 面临特殊订单需要定价时
- 参与投标项目需要确定报价时
- 企业存在闲置生产能力时
- 需要评估不同定价策略时

## 方法一：变动成本加成法

### 适用条件
- 企业选择变动成本加成法作为定价方法
- 已确定单位变动成本、全部固定成本、预期利润目标

### 执行步骤

1. **确定成本基数：**
   ```
   单位变动成本 = 直接材料 + 直接人工 + 变动制造费用 + 变动销售和管理费用
   ```

2. **确定加成率：**
   - 加成部分必须涵盖全部固定成本和预期利润
   - 加成率不是随意设定的

3. **计算成本加成金额：**
   ```
   成本加成 = 单位变动成本 × 加成率
   ```

4. **计算目标销售价格：**
   ```
   目标销售价格 = 单位变动成本 + 成本加成
   目标销售价格 = 单位变动成本 × (1 + 加成率)
   ```

### 与完全成本加成法的对比

| 项目 | 变动成本加成法 | 完全成本加成法 |
|------|----------------|----------------|
| 成本基数 | 单位变动成本 | 单位完全成本 |
| 加成率 | 较高 | 较低 |
| 最终价格 | 相同 | 相同 |

**核心原则：** 定价必须弥补全部成本（变动成本+固定成本）并提供预期利润

## 方法二：增量成本定价法（闲置能力条件下）

### 适用条件
- 企业具有闲置生产能力
- 面临激烈竞争（如投标、特殊订单）
- 需要短期内维持运营和员工稳定

### 执行步骤

1. **检查适用条件：**
   - 存在剩余生产能力
   - 面临市场需求变化，竞争激烈

2. **计算增量成本：**
   ```
   增量成本 = 直接材料 + 直接人工 + 变动制造费用 + 变动销售和行政管理费用
   ```

3. **确定价格区间：**
   - **下限：** 变动成本（增量成本）
   - **上限：** 目标价格（变动成本 + 成本加成）

4. **决策规则：**
   - 只要价格 > 变动成本，就可以接受
   - 投标时，为确保中标，价格可定在接近下限位置

### 经济效益分析

即使价格低于总成本（含固定成本），只要高于变动成本：
- 可以弥补一部分固定成本
- 提供边际贡献
- 短期内维持企业正常运营和员工稳定

### 决策约束
- 价格不能低于变动成本
- 不能妨碍正常业务承接

## 关键变量

- **单位变动成本：** 包含直接材料、直接人工、变动制造费用、变动销售和管理费用
- **加成率：** 基于单位变动成本的加成比例
- **全部固定成本：** 包括固定制造费用和固定销售管理费用
- **预期利润：** 企业希望获得的满意利润水平
- **目标销售价格：** 最终确定的对外销售价格

## 输出结果
- 目标销售价格
- 价格接受区间
- 定价决策建议（接受/拒绝）
