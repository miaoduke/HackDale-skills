# 期权估值基础概念

## 影响期权价值的因素

### 看涨期权
1. **标的资产价格**：价格越高，期权价值越大
2. **执行价格**：执行价格越低，期权价值越大
3. **到期期限**：期限越长，期权价值越大
4. **标的资产波动率**：波动率越高，期权价值越大
5. **无风险利率**：利率越高，看涨期权价值越大

### 看跌期权
1. **标的资产价格**：价格越低，期权价值越大
2. **执行价格**：执行价格越高，期权价值越大
3. **到期期限**：期限越长，期权价值越大
4. **标的资产波动率**：波动率越高，期权价值越大
5. **无风险利率**：利率越高，看跌期权价值越小

## 实物期权与金融期权的对应关系

| 金融期权 | 实物期权 |
|---------|---------|
| 标的股票价格 | 项目预期现金流现值 |
| 执行价格 | 项目投资成本 |
| 到期时间 | 项目投资机会持续时间 |
| 波动率 | 项目现金流的不确定性 |
| 无风险利率 | 无风险利率 |

## 实物期权估值方法

### 1. 二叉树模型
适用于离散时间、有限决策点的项目。

### 2. Black-Scholes模型
适用于连续时间、欧式期权。

### 3. 蒙特卡洛模拟
适用于复杂路径依赖的期权。

## 实物期权应用案例

### 扩张期权案例
- 公司投资建设第一阶段工厂
- 获得在市场需求旺盛时建设第二阶段工厂的权利
- 第一阶段投资包含扩张期权价值

### 延迟期权案例
- 公司拥有某矿藏开采权
- 可选择立即开采或等待价格上升
- 等待的权利具有价值

### 放弃期权案例
- 公司投资建设可变卖的生产线
- 若项目失败，可出售设备回收部分投资
- 退出权利降低了下行风险
