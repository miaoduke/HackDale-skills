# 每股收益最大化目标分析

## 何时使用

- 需要克服利润最大化目标的局限性
- 关注单位资本收益水平
- 评价公司业绩的关键指标分析
- 比较不同规模企业的盈利效率

## 核心定义

将公司的利润和股东投入的资本联系起来考察，用**每股收益最大化**来概括公司的财务管理目标。

## 计算公式

```
每股收益 = 归属于普通股股东净利润 ÷ 流通在外普通股股数
```

## 目的

旨在克服"利润最大化"目标的局限性，引入资本投入规模的考量。

## 三大局限性

| 局限性 | 说明 |
|--------|------|
| 未考虑时间价值 | 仍然没有考虑每股收益取得的时间 |
| 未考虑风险因素 | 仍然没有考虑每股收益的风险 |
| 投入资本差异 | 现实中每股股票投入资本差别很大，导致不同公司的每股收益不可比 |

## 适用条件

如果每股收益的**取得时间**、**承担风险**、**投入资本**相同，则每股收益最大化也是一个可以接受的目标。

## 实际应用

许多投资者都把每股收益作为评价公司业绩的关键指标。

## 方法定位

**过渡性目标**：比利润最大化更完善，但仍未完全解决财务管理的核心问题（股东财富最大化）。
