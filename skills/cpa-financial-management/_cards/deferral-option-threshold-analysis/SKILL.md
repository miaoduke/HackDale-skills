# 延迟期权投资成本临界值判定

## 何时使用
- 需要确定立即投资与延迟投资的无差异临界点
- 投资成本发生变化需要重新评估决策
- 进行投资决策的敏感性分析
- 评估延迟期权的价值

## 基本原理

通过计算投资成本临界值（使延迟期权价值降为零的点），确定立即投资与延迟投资的无差异点。

## 计算步骤

### 步骤1：理解投资成本对期权价值的影响机制

- 当投资成本降低时，不含期权的项目净现值（立即投资净现值）会增加
- 含有期权的项目净现值也会增加，但前者增加速度更快
- 两者的增量之比为：上行概率 ÷ (1 + 无风险报酬率)

### 步骤2：建立投资成本临界值方程

**不含期权的项目净现值**：
```
不含期权的项目净现值 = 项目价值 - 投资成本
```

**含有期权的项目净现值**（当投资成本 ≥ 下行项目价值时，下行状态放弃投资，价值为0）：
```
含有期权的项目净现值 = [上行概率 × (上行项目价值 - 投资成本) + 下行概率 × 0] ÷ (1 + 无风险报酬率)
```

**令两者相等（期权价值为零）**：
```
项目价值 - 投资成本临界值 = [上行概率 × (上行项目价值 - 投资成本临界值)] ÷ (1 + 无风险报酬率)
```

### 步骤3：求解临界投资成本

通过代数运算求解上述方程中的投资成本临界值。

### 步骤4：验证与决策应用

**验证**：
- 当投资成本 = 临界值时，不含期权的净现值 = 含有期权的净现值
- 期权价值 = 0，立即投资与延迟投资无差异

**决策规则**：
- 若实际投资成本 < 临界值：立即执行项目更有利
- 若实际投资成本 > 临界值：应当等待，保留延迟期权具有正价值
- 若实际投资成本 = 临界值：两种策略等价

## 关键变量

- **投资成本临界值**：使延迟期权价值降为零的投资成本阈值
- **项目价值**：基于当前期望现金流量计算的项目现值
- **上行项目价值**：延迟一年后上行状态下的项目价值
- **增量比率**：含期权NPV与不含期权NPV对投资成本变化的敏感度比率

## 注意事项

- 仅适用于投资成本单一变量变化分析
- 假设下行状态下当投资成本大于等于下行项目价值时放弃项目
- 假设其他所有参数（现金流量、折现率）保持不变
- 需要已完成基础延迟期权估值（已知上行概率、项目价值二叉树）
