# 企业价值评估模型选择与应用

## 适用场景
需要评估企业价值且现金流量折现模型应用困难或需基于市场比较时，应用相对价值评估模型；需要根据企业现金流量分布特征选择永续增长模型或两阶段增长模型时，应用模型选择决策。

## 相对价值评估模型

### 核心假设
- 存在一个支配企业市场价值的主要变量（如净利）
- 市场价值与该变量的比值，各企业是类似的、可以比较的

### 基本操作步骤
1. 寻找一个影响企业价值的关键变量（如净利）
2. 确定一组可以比较的类似企业（可比企业）
3. 计算可比企业的"市价/关键变量"的平均值（如平均市盈率）
4. 计算目标企业评估价值 = 目标企业的关键变量 × 得到的平均值

### 结果性质
- 所得结论是相对于可比企业而言的，以可比企业价值为基准
- 这是一种"相对价值"，而非目标企业的"内在价值"

### 模型缺陷与局限性
- **理论缺陷（循环论证）**：隐含假设资本市场对其他公司的估值正确，而对目标公司的估值出现偏差
- **实践缺陷（可比性问题）**：依据行业、资产规模、营业收入规模、企业发展阶段、战略定位等指标定义的可比性，会因指标选择不同而不同

### 主要应用场景
主要用于非上市企业的价值评估。

## 股权现金流量模型类型选择

### 模型选择决策树

```
开始
  │
  ▼
分析企业现金流量分布特征
  │
  ├──► 企业是否处于长期稳定、可持续增长状态？
  │    │
  │    ├──► 是 → 选择【永续增长模型】
  │    │         - 特征：单一增长阶段，增长率g恒定且g < r
  │    │         - 典型企业：成熟行业龙头企业、公用事业公司
  │    │
  │    └──► 否 → 继续判断
  │              │
  │              ▼
  │         增长是否呈现两个阶段？
  │         （详细预测期高速增长/不稳定增长 + 后续期稳定增长）
  │              │
  │              ├──► 是 → 选择【两阶段增长模型】
  │              │         - 特征：第一阶段详细预测各年现金流，第二阶段永续增长
  │              │         - 典型企业：高新技术企业、成长期企业、具有领先同业优势的企业
  │              │
  │              └──► 否 → 考虑其他模型（如三阶段模型或情景分析）
```

### 关键判断标准

#### 永续增长模型适用标志
- 企业有永续的增长率（通常为GDP增长率或略高，3%-5%）
- 有永续的净投资资本报酬率（ROIC稳定）
- 行业成熟，竞争格局稳定
- 无重大技术变革或市场结构变化预期

#### 两阶段增长模型适用标志
- 企业具有明显的竞争优势期（如案例中的"领先同业的优势"）
- 预测期内增长率显著高于永续增长率
- 能够合理预测未来5-7年的具体现金流
- 详细预测期后有明确的稳定状态预期

### 模型选择常见错误

#### 错误1：对高增长企业直接使用永续增长模型
- **后果**：低估企业价值（忽略高增长期的超额收益）

#### 错误2：对成熟企业使用两阶段模型但预测期过长
- **后果**：预测误差累积，估值不确定性增加
- **建议**：成熟企业详细预测期通常3-5年即可

#### 错误3：混淆分界点（m的确定）
- **关键**：m应为企业达到稳定状态的时点，而非主观设定
- **判断依据**：增长率是否降至可持续的永续水平、资本支出是否normalized

## 现金流量折现模型参数的整体性原则

### 三大核心参数
1. 资本成本（折现率）
2. 未来现金流量
3. 预测期（包括详细预测期和后续期/永续期）

### 参数间的相互影响关系
- 资本成本的变化会影响现金流量的现值计算
- 预测期的长短会影响增长假设的设定
- 增长率的假设又会影响未来现金流量的金额

### 禁止的做法
- 孤立地估计资本成本而不考虑现金流特征
- 单独预测现金流量而不匹配相应的折现率
- 随意设定预测期长度而不考虑企业生命周期

### 正确的处理流程
1. 先理解企业的商业模式和增长阶段
2. 在此基础上，同步考虑三大参数的协调一致性
3. 反复检验参数组合的合理性

## 价值评估模型在投资决策中的应用

### 证券投资决策流程（证券投资者适用）
1. 运用价值评估模型计算特定证券的现值（即内在价值）
2. 将计算得到的现值与该证券当前的市场价格进行直接比较
3. 根据比较结果作出投资决策：
   - 若现值 > 市场价格：证券被低估，考虑买入
   - 若现值 < 市场价格：证券被高估，考虑卖出或回避
   - 若现值 ≈ 市场价格：证券定价合理，持有或观望

### 项目投资决策流程（项目投资者适用）
1. 运用价值评估模型计算特定项目的净现值（NPV）
2. 根据净现值结果作出决策：
   - 若NPV > 0：项目创造价值，接受投资
   - 若NPV < 0：项目损毁价值，拒绝投资
   - 若NPV = 0：项目刚好补偿资本成本，可接受但无超额收益

### 模型应用的关键一致性要求
无论证券还是项目评估，必须统一基于现金流量进行折现估计，确保评估逻辑的内在一致性。
