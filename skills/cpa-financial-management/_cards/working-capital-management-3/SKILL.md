# 营运资本管理

## 适用场景
- 短期资产管理决策
- 短期筹资决策
- 平衡现金流缺口与资本成本
- 制定营运资本投资与筹资政策

## 定义与计算

### 营运资本公式
```
营运资本 = 流动资产（短期资产） - 流动负债（短期负债）
```

## 管理范畴划分

### 营运资本投资管理（短期投资管理）
- 制定营运资本投资政策
- 决定资金分配：分配多少资金用于应收账款和存货
- 决定现金持有量：决定保留多少现金以备支付
- 日常管理：对这些资产进行日常管理

### 营运资本筹资管理（短期筹资管理）
- 制定营运资本筹资政策
- 决定借款规模：决定向谁借入多少短期资金
- 决定筹资方式：是否采用赊购筹资等

## 管理目标

### 目标1：有效运用流动资产
力求其边际收益大于边际成本

### 目标2：选择合理流动负债
最大限度地降低营运资本的资本成本

### 目标3：加速营运资本周转
以尽可能少的营运资本支持尽可能大的经营规模并保持公司支付债务的能力

## 风险与报酬权衡

### 背景
营业现金流的时间和数量具有不确定性，现金流入和流出在时间上不匹配，公司经常出现现金流缺口。

### 高营运资本配置
- **优点**：有利于减少现金流的缺口
- **缺点**：会增加资本成本

### 低营运资本配置
- **优点**：有利于节约资本成本
- **缺点**：会增大不能及时偿债的风险

### 决策原则
公司需要根据具体情况权衡风险和报酬，制定适当的营运资本政策。

## 执行步骤
1. **计算营运资本**：流动资产 - 流动负债
2. **分析现金流缺口**：评估营业现金流的不确定性
3. **制定投资政策**：确定应收账款、存货、现金的配置水平
4. **制定筹资政策**：确定短期借款规模和方式
5. **权衡风险报酬**：平衡现金流缺口与资本成本
6. **监控与调整**：定期评估并调整营运资本政策
