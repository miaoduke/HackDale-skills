# 动态回收期计算示例

## A项目示例（折现率10%）

### 已知条件
- 原始投资：20,000万元
- 第1年现金流量：11,800万元
- 第2年现金流量：13,240万元
- 折现率：10%

### 计算过程

**步骤1：确定原始投资额现值**
```
原始投资：20,000万元
折现系数（第0年）：1.0000
现值：20,000 × 1.0000 = 20,000万元
累计净值：(20,000)万元
```

**步骤2：计算第1年现金流入的现值**
```
第1年现金流量：11,800万元
折现系数（10%，1年）：0.9091
现值：11,800 × 0.9091 = 10,727万元
累计净值：(20,000) + 10,727 = (9,273)万元
```

**步骤3：计算第2年现金流入的现值**
```
第2年现金流量：13,240万元
折现系数（10%，2年）：0.8264
现值：13,240 × 0.8264 = 10,942万元
累计净值：(9,273) + 10,942 = 1,669万元
```

**步骤4：确定动态回收期**
```
第1年末尚未回收：9,273万元
第2年可收回现值：10,942万元
需要第2年的回收比例：9,273 ÷ 10,942 = 0.85年
动态回收期 = 1 + 0.85 = 1.85年
```

### 结果解读
项目需要1.85年才能收回考虑货币时间价值后的全部投资。

## B项目示例（折现率8%）

### 已知条件
- 原始投资：50,000万元
- 第1年现金流量：20,000万元
- 第2年现金流量：25,000万元
- 第3年现金流量：30,000万元
- 折现率：8%

### 计算过程

**折现系数表（8%）**
| 年份 | 折现系数 |
|------|---------|
| 0 | 1.0000 |
| 1 | 0.9259 |
| 2 | 0.8573 |
| 3 | 0.7938 |

**现值计算**
| 年份 | 现金流量 | 折现系数 | 现值 | 累计净值 |
|------|---------|---------|------|---------|
| 0 | (50,000) | 1.0000 | (50,000) | (50,000) |
| 1 | 20,000 | 0.9259 | 18,518 | (31,482) |
| 2 | 25,000 | 0.8573 | 21,433 | (10,049) |
| 3 | 30,000 | 0.7938 | 23,814 | 13,765 |

**动态回收期计算**
```
第2年末尚未回收：10,049万元
第3年可收回现值：23,814万元
需要第3年的回收比例：10,049 ÷ 23,814 = 0.42年
动态回收期 = 2 + 0.42 = 2.42年
```

## 静态vs动态回收期对比

### A项目对比
- 静态回收期：(20,000 - 11,800) ÷ 13,240 + 1 = 1.62年
- 动态回收期：1.85年
- 差异：0.23年

### B项目对比
- 静态回收期：(50,000 - 20,000 - 25,000) ÷ 30,000 + 2 = 2.17年
- 动态回收期：2.42年
- 差异：0.25年

## 决策规则

- **独立项目：** 动态回收期 ≤ 要求回收期，接受
- **互斥项目：** 选择动态回收期较短的项目
- **注意：** 动态回收期未考虑回收期后的现金流量
