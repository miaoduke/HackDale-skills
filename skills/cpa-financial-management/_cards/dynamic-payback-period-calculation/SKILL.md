# 动态回收期计算

## 使用场景
当需要评估投资项目回收期且必须考虑货币时间价值时使用此技能。

## 核心定义
动态回收期（折现回收期）是指在考虑货币时间价值的情况下，投资引起的未来现金流量累计到与原始投资额相等所需要的时间。

## 数学判定条件
```
当 ∑(t=0到m) 未来现金流量现值 = 原始投资额现值 时，m = 动态回收期
```

## 计算步骤

### 第一步：确定原始投资额现值
```
现值 = 原始投资 × 折现系数（第0年）
折现系数（第0年）= 1.0000
```

### 第二步：计算各期现金流入的现值
```
第t年现值 = 第t年现金流量 × 折现系数（r, t年）
折现系数 = (1 + r)^(-t)
```

### 第三步：计算累计净值
```
累计净值_m = 前m年现值之和 - 原始投资额现值
```

### 第四步：确定动态回收期（插值法）
```
动态回收期 = (n-1) + |累计净值_(n-1)| ÷ 第n年现值
```
其中：n为累计净值首次转正的年份

## 关键要点

1. **克服静态缺点：** 动态回收期法考虑了货币时间价值
2. **必须折现：** 所有现金流量必须先折现后再累计
3. **插值假设：** 假设现金流量在年内均匀发生
4. **通常更长：** 动态回收期通常长于静态回收期（因折现效应）

## 与静态回收期对比

| 特征 | 静态回收期 | 动态回收期 |
|------|-----------|-----------|
| 货币时间价值 | 不考虑 | 考虑 |
| 计算复杂度 | 简单 | 复杂 |
| 回收期长度 | 较短 | 较长 |
| 决策准确性 | 较低 | 较高 |
