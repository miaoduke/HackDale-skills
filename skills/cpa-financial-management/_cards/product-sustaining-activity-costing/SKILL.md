# 品种级（产品级）作业成本核算

## 适用判断

确认同时满足以下条件：
- 作业服务于**特定型号或样式**的产品（非具体批次或单位）
- 成本依赖于**产品品种数/规格型号数**，而非产量或批次数
- 成本呈现**阶梯式特性**：只要该品种存在就发生成本，无论生产多少数量（即使产量为零）

典型作业：产品设计、生产工艺规程制定、工艺改造、产品更新、产品工程师维护。

## 前置准备

执行前确认已获取：
- [ ] 已识别的品种级作业清单及总成本
- [ ] 产品品种数/规格型号数统计
- [ ] 产品复杂度数据（零件数量、设计工时、工艺文件页数）
- [ ] 明确"产品"与"品种"的划分标准（按型号、规格、样式）

## 执行步骤

### 第一步：确认成本性态

验证品种级成本的核心特征：
- **成本动因**：产品品种数或规格型号数
- **变动规律**：随品种数变化，不随产量、批次数变化  
- **发生逻辑**：仅仅因为某个特定产品品种存在而发生
- **成本特性**：只要该品种存在（即使产量为零），就产生维持成本

### 第二步：确定分配基础

选择能反映产品复杂度的量化指标：

| 作业类型 | 推荐分配基础 | 逻辑依据 |
|---------|------------|---------|
| 工程师维护 | 零件数量 | 产品复杂度是零件数量的函数 |
| 产品设计 | 设计工时 | 直接反映设计资源投入 |
| 工艺规程制定 | 工艺文件页数 | 反映工艺复杂程度 |
| 通用情况 | 产品种类数 | 按品种平均分配 |

**决策原则**：分配基础应能合理解释"为何某产品消耗更多品种级资源"。

### 第三步：执行三级分配

#### 第一级：分配至每一种产品

将品种级作业总成本分配到各产品：

```
分配率 = 品种级作业总成本 / 总分配基础量（如总零件数）
某产品分配额 = 分配率 × 该产品分配基础量
```

**关键控制**：此步骤将成本与"品种"绑定，与产量脱钩。即使某产品当期无产量，仍应保留其品种级成本份额。

#### 第二级：分配给生产批次

将已分配到特定产品的成本，进一步分配到该产品的各个生产批次：

```
某批次分配额 = 该产品总品种级成本 × (该批次产量 / 该产品当期总计划产量)
```

若批次规模相同，可按订单数量平均分配。

#### 第三级：分配至单位产品

```
单位产品品种级成本 = 该批次分配额 / 该批次产量
```

该金额计入单位产品成本的"品种级作业成本"项目。

## 关键控制点

1. **阶梯成本识别**：确保成本确实不随产量/批次变动。若成本随产量变化，应归类为单位级或批次级作业。

2. **分配顺序不可跳级**：必须先按品种归集（第一级），再逐步向下分配，**不可直接按产量分配**到单位产品。

3. **品种界定一致性**：明确"品种"划分标准（型号、规格、样式），避免与"产品系列"混淆。

4. **零产量处理**：即使某品种当期产量为零，其品种级成本仍应保留在该产品层面，由实际生产的批次承担（若永久停产则重新评估成本库）。

## 概念辨析

- **产品 vs 品种**：产品比品种更综合，一种产品可能包括多种规格型号的品种
- **品种级 vs 产品级**：两者具有相似特征，均服务于特定产品线而非具体批次或单位，可合并处理
- **成本性态**：只要特定品种存在就发生成本，无论生产多少数量、分多少批次

## 输出结果

通过三级分配，最终得到：
- **产品层面**：各产品应承担的总品种级成本
- **批次层面**：各批次应承担的品种级成本份额  
- **单位层面**：单位产品应承担的品种级作业成本

该结果反映产品维持成本在产品间的合理分摊，支持产品盈利能力分析和定价决策。
