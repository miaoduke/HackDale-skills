# 品种级作业成本核算示例

## 场景设定

某制造企业生产A、B两种产品，其中：
- A产品：2个规格型号（A1、A2），各型号零件数分别为50个、80个
- B产品：1个规格型号（B1），零件数为120个
- 当期品种级作业总成本（工程师维护）：300,000元
- 当期生产情况：
  - A1型号：生产2批，共1,000件
  - A2型号：生产1批，共500件  
  - B1型号：生产3批，共2,000件

## 第一级分配：按零件数分配到产品品种

总零件数基数 = 50 + 80 + 120 = 250

分配率 = 300,000 / 250 = 1,200元/零件

- A1品种成本 = 1,200 × 50 = 60,000元
- A2品种成本 = 1,200 × 80 = 96,000元
- B1品种成本 = 1,200 × 120 = 144,000元

**验证**：60,000 + 96,000 + 144,000 = 300,000元

## 第二级分配：分配到批次

### A1型号（总成本60,000元，共1,000件）
- 第一批（600件）：60,000 × (600/1,000) = 36,000元
- 第二批（400件）：60,000 × (400/1,000) = 24,000元

### A2型号（总成本96,000元，共500件）
- 第一批（500件）：96,000元（全部）

### B1型号（总成本144,000元，共2,000件）
- 第一批（800件）：144,000 × (800/2,000) = 57,600元
- 第二批（700件）：144,000 × (700/2,000) = 50,400元
- 第三批（500件）：144,000 × (500/2,000) = 36,000元

## 第三级分配：计算单位成本

- A1单位成本 = 36,000/600 = 60元/件（第一批）或 24,000/400 = 60元/件（第二批）
- A2单位成本 = 96,000/500 = 192元/件
- B1单位成本 = 57,600/800 = 72元/件（第一批）

## 关键观察

1. **与产量无关**：即使A2只生产500件，其单位品种级成本（192元）远高于A1（60元），这是因为A2产品复杂度（80零件）高于A1（50零件），而非产量差异。

2. **零产量情况**：若A1当期未生产，其60,000元品种级成本仍保留在A1产品层面，可由下期生产批次承担，或重新评估是否保留该品种。

3. **批次规模影响**：同一品种的不同批次，单位产品承担的品种级成本相同（假设按产量比例分配）。
