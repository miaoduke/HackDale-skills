# 五类项目分析方法详解

## 类型1：扩张项目 - 标准DCF法

### 现金流估算要点
- **初始现金流**：新设备购置成本 + 营运资本增加 - 旧设备变现(如有)
- **营业现金流**：Δ收入×(1-T) - Δ付现成本×(1-T) + Δ折旧×T
- **终结现金流**：残值收入 + 营运资本回收

### 特殊考量
- 产能利用率爬坡期：初期可能未达满产，需分年预测
- 对现有产品 cannibalization( cannibalization)：需扣除对现有业务的侵蚀

## 类型2：更新项目 - 平均年成本法(AAC)

### 方法原理
当收入不变时，比较新旧设备的平均年成本，选择成本较低者。

### 计算公式
```
平均年成本 = 现金流出总现值 / 年金现值系数(P/A, i, n)

或 = 投资额/年金现值系数 + 年运营成本 - 残值/(F/A, i, n)
```

### 关键决策规则
- 若旧设备AAC < 新设备AAC：继续使用旧设备
- 若旧设备AAC > 新设备AAC：更新设备

### 注意事项
- 旧设备投资以"变现价值"计量(机会成本)
- 需考虑旧设备剩余使用年限与新设备寿命差异
- 若年限不同，必须使用AAC法而非简单比较NPV

## 类型3：研发项目 - 实物期权法

### 为什么不能用标准DCF
研发项目价值 = 传统NPV + 期权价值
标准DCF往往低估项目价值，因为忽略了放弃、延迟、扩张的灵活性。

### 常见实物期权类型
1. **延迟期权**：等待市场信息明确后再投资
2. **扩张期权**：研发成功后扩大生产规模的权利
3. **放弃期权**：研发失败时终止项目的权利
4. **转换期权**：技术路线转换的灵活性

### Black-Scholes模型应用(简化)
```
C = S×N(d1) - X×e^(-rt)×N(d2)

其中：
S = 项目未来现金流现值(标的资产现价)
X = 投资成本(执行价格)
T = 研发周期(到期时间)
σ = 现金流波动率
```

### 决策树分析步骤
1. 识别关键决策节点(如：是否进入二期临床试验)
2. 识别不确定性节点(如：试验成功概率)
3. 从后向前计算各节点期望值
4. 在决策节点选择最优分支

## 类型4：勘探项目 - 信息价值分析

### 完美信息价值(EVPI)
```
EVPI = 完美信息下期望收益 - 当前信息下期望收益
```
若EVPI > 勘探成本，则值得进行勘探。

### 样本信息价值(EVSI)
勘探信息通常不完美，存在误差：
```
EVSI = 样本信息下期望收益 - 当前信息下期望收益
```
决策规则：若EVSI > 勘探成本，则进行勘探。

### 序贯决策
勘探通常分阶段进行(如：地质普查→详查→精查)：
- 每阶段结束后评估是否进入下一阶段
- 使用贝叶斯更新修正成功概率
- 若某阶段结果不佳，及时终止避免沉没成本

## 类型5：其他项目 - 多标准决策分析

### 强制合规项目
- 若法规强制要求：直接执行，无需财务评价
- 若有多方案可选：选择成本现值最低的方案

### 成本效益分析(CBA)
当项目产生社会效益但无直接收入时：
```
社会NPV = 社会收益现值 - 社会成本现值
```
需将无形收益(如环境改善、员工安全)货币化。

### 多标准评分法
当无法货币化时，使用加权评分：
1. 确定标准：合规性、安全性、环保性、成本、可维护性
2. 赋予权重
3. 各方案打分
4. 计算加权总分

## 跨类型比较的特殊处理

当需要在不同类型项目间分配资本限额时：
- 类型1、2：可直接比较NPV或AAC
- 类型3、4：需将期权价值纳入总收益
- 类型5：通常作为约束条件(必须满足最低安全/环保投资)，剩余资金再分配给其他类型

## 常见错误警示

1. **对更新项目使用简单NPV**：忽略旧设备变现价值的机会成本
2. **对研发项目使用标准DCF**：忽略管理灵活性价值，导致好的研发项目被错误拒绝
3. **混淆勘探与研发**：勘探产出是信息(减少不确定性)，研发产出是技术(增加产能)
4. **忽视社会责任项目的间接收益**：仅看直接成本而忽略避免罚款、提升品牌价值等间接收益
