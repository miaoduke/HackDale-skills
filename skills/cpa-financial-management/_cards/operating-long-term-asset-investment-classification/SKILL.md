# 经营性长期资产投资项目五类分类

识别经营性长期资产投资项目的类型，匹配对应的现金流特征与分析方法。

## 适用场景

- 资本预算决策前的项目类型识别
- 选择适当的项目评价方法(DCF、平均年成本法、实物期权等)
- 预测项目现金流分布模式
- 确定项目风险特征与折现率

## 前置检查

确认项目满足：
- [ ] 投资对象为长期资产(固定资产、无形资产等)
- [ ] 属于经营性投资(非金融性投资)
- [ ] 投资期限超过一年

## 五类分类决策树

```
投资对象是否为经营性长期资产?
├── 是 → 按投资目的分类：
│   ├── 添置新资产且增加收入? → 类型1：扩张项目
│   ├── 更换旧资产且收入不变? → 类型2：更新项目
│   ├── 形成技术/知识资产? → 类型3：研发项目
│   ├── 获取资源/市场信息? → 类型4：勘探项目
│   └── 履行社会责任/合规? → 类型5：其他项目
└── 否 → 不适用本分类体系
```

## 分类执行步骤

### 步骤1：识别资产变动方式

判断项目对资产的影响：
- **新增产能**：添置新的固定资产，扩大生产规模
- **维持产能**：更换或改造现有固定资产，不扩大规模
- **形成知识资产**：投入研发，产出技术或知识产权
- **获取信息**：投入勘探，产出资源储量或市场数据
- **合规设施**：投入环保/安全设施，满足监管要求

### 步骤2：判断现金流影响模式

根据收入与成本变化判断：

| 现金流模式 | 收入变化 | 成本变化 | 对应类型 |
|-----------|---------|---------|---------|
| 流入增加 | 显著增加 | 可能增加 | 类型1：扩张 |
| 维持不变 | 基本不变 | 降低或维持 | 类型2：更新 |
| 无直接流入 | 无 | 持续投入 | 类型3：研发 |
| 信息价值 | 不确定 | 投入换取信息 | 类型4：勘探 |
| 间接流出减少 | 无直接变化 | 避免未来支出 | 类型5：其他 |

### 步骤3：确定项目类型与分析方法

**类型（1）：新产品开发或现有产品的规模扩张项目**
- **识别特征**：添置新的固定资产，新增产能
- **现金流特征**：增加企业的营业现金流入(营业收入增长)
- **分析方法**：标准DCF法(净现值NPV、内含报酬率IRR、回收期)
- **关键参数**：增量收入、增量成本、产能利用率

**类型（2）：设备或厂房的更新项目**
- **识别特征**：更换固定资产，替换旧资产
- **现金流特征**：不改变营业现金收入，通过降低成本或维持运营能力产生价值
- **分析方法**：平均年成本法(AAC)、总成本比较法
- **关键参数**：旧设备变现价值、新旧设备运营成本差异、剩余使用年限

**类型（3）：研究与开发项目(R&D)**
- **识别特征**：投入研发资源，形成知识资产或技术储备
- **现金流特征**：通常不直接产生现实的收入，短期内无现金流入
- **分析方法**：实物期权法(Real Options)、决策树分析，或调整DCF(更高折现率)
- **关键参数**：成功概率、后续商业化价值、期权时间价值

**类型（4）：勘探项目**
- **识别特征**：投入勘探资源(矿产资源、市场勘探)
- **现金流特征**：不直接产生营业现金流入，获得有价值的信息
- **分析方法**：信息价值分析、序贯决策分析、实物期权
- **关键参数**：信息精度、后续投资决策灵活性、资源储量概率分布

**类型（5）：其他项目(社会责任类)**
- **识别特征**：劳动保护设施、污染控制装置等
- **现金流特征**：不直接产生营业现金流入，可能减少未来现金流出(避免罚款)
- **分析方法**：强制合规性检查(必须做)、成本效益分析(可选优化方案)
- **关键参数**：合规成本、潜在罚款/诉讼成本、企业形象价值

## 分析方法匹配速查

| 项目类型 | 首选方法 | 辅助方法 | 禁忌方法 |
|---------|---------|---------|---------|
| 扩张(1) | NPV/IRR | 获利指数 | 平均年成本法 |
| 更新(2) | 平均年成本法 | 总成本现值 | 简单NPV(忽略旧设备机会成本) |
| 研发(3) | 实物期权 | 决策树 | 标准DCF(低估灵活性价值) |
| 勘探(4) | 信息价值分析 | 序贯决策 | 静态NPV |
| 其他(5) | 合规检查+成本最小化 | 多标准决策 | 纯财务NPV(忽略社会效益) |

## 输出格式

为每个项目生成分类标签：

```yaml
项目类型: [1/2/3/4/5]
类型名称: [扩张/更新/研发/勘探/其他]
现金流模式: [流入增加/维持不变/无直接流入/信息价值/间接流出减少]
资产变动: [添置新资产/更换旧资产/形成知识资产/获取信息/合规设施]
推荐分析方法: [具体方法名称]
特殊考虑: [如实期权价值、信息价值等]
```

## 常见混淆点辨析

**扩张 vs 更新**：
- 扩张：有增量收入，资产数量增加
- 更新：无增量收入，资产替换(一对一或一对多但产能不变)

**研发 vs 勘探**：
- 研发：产出是技术/产品，目的是形成生产能力
- 勘探：产出是信息(储量、市场数据)，目的是减少不确定性

**更新 vs 其他(安全改造)**：
- 更新：维持或恢复生产能力
- 其他：满足合规要求，不一定提升生产能力

## 验证检查

分类完成后确认：
- [ ] 项目确实属于经营性长期资产(非金融资产、非流动资产投资)
- [ ] 现金流特征描述与项目实际情况匹配
- [ ] 分析方法选择符合该类型的决策逻辑
- [ ] 对于类型3、4，已考虑期权价值或信息价值，而非仅使用静态DCF
