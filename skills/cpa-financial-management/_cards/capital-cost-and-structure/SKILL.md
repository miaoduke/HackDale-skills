# 资本成本与结构

## 适用场景
- 估计普通股资本成本
- 选择资本成本估计方法
- 评估企业所得税和个人所得税对企业价值的影响
- 分析负债节税效应

## 核心内容

### 1. 普通股资本成本估计方法选择

**三种估计方法：**
1. **资本资产定价模型（CAPM）：** 最广泛使用
2. **股利增长模型：** 适用于股利政策稳定的公司
3. **债券收益率风险调整模型：** 适用于同时发行债券的公司

**选择决策标准：**
- **首要标准：** 数据可靠性
- **选择策略：** 选用最有把握的一种数据基础
- **实务建议：** 通常三种方法都会计算，然后比较判断或取平均值

**方法适用性：**
- **CAPM：** 适用于上市公司，有可靠的β值和市场数据
- **股利增长模型：** 适用于股利政策稳定、可预测的公司
- **债券收益率风险调整：** 基于债务成本加风险溢价

### 2. 米勒模型（双重税收）

**基本公式：**
```
V_L^T = V_U^T + D^T × [1 - ((1-T_C)(1-T_E))/(1-T_D)]
```

**变量含义：**
- V_L^T：有双重税收有负债企业的价值
- V_U^T：有双重税收无负债企业的价值
- D^T：债务价值
- T_C：企业所得税税率
- T_E：股东个人所得税税率
- T_D：债权人个人所得税税率

**节税价值：**
```
节税价值 = D^T × [1 - ((1-T_C)(1-T_E))/(1-T_D)]
```

**特殊情况分析：**

| 情况 | 条件 | 结果 |
|:---|:---|:---|
| 无税MM理论 | T_C = T_E = T_D = 0 | V_L = V_U |
| 有税MM理论 | T_E = T_D = 0 | V_L^T = V_U^T + D^T × T_C |
| 节税效应不变 | T_E = T_D | 与仅考虑企业所得税的MM理论相同 |
| 节税效应为零 | (1-T_C)(1-T_E) = 1-T_D | 负债节税价值为0，财务杠杆无效 |
| 节税效应减少 | T_E < T_D | 来自债务的节税收益减少 |
| 节税效应增加 | T_E > T_D | 来自债务的节税收益增加 |

## 决策要点
- 三种资本成本估计方法各有优缺点，数据可靠性决定方法选择
- 理论上三种方法应得出相近结果，实务中可能存在差异
- 米勒模型是对有税MM理论的进一步修正
- 股东和债权人的个人所得税税率关系影响负债节税效应
- 当T_E = T_D时，双重税收环境退化为仅考虑企业所得税的情况
