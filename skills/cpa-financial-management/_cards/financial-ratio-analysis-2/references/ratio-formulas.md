# 财务比率详细公式与示例

## 现金流量比率

**公式**：现金流量比率 = 经营活动现金流量净额 ÷ 流动负债

**示例（ABC公司）**：
- 经营活动现金流量净额 = 246万元
- 流动负债 = 300万元
- 现金流量比率 = 246 ÷ 300 = 0.82

**说明**：
- 分子使用现金流量表中的"经营活动产生的现金流量净额"
- 分母使用资产负债表流动负债期末数
- 该比率表明每1元流动负债的经营活动现金流量保障程度

## 资产负债率

**公式**：资产负债率 = 总负债 ÷ 总资产 × 100%

**示例（ABC公司）**：
- 本年末：1,040 ÷ 2,000 × 100% = 52%
- 上年末：800 ÷ 1,680 × 100% = 48%

**风险阈值**：
- 通常资产在破产拍卖时的售价不到账面价值的50%
- 如果资产负债率高于50%，债权人利益缺乏保障

**资产类别影响**：
- 房地产变现价值损失小
- 专用设备难以变现
- 不同企业的资产负债率差异可能与其持有的资产类别相关

## 流动资产周转率

**示例（ABC公司）**：
- 营业收入 = 3000万元
- 流动资产 = 700万元

计算结果：
- 周转次数 = 3000 ÷ 700 = 4.3（次/年）
- 周转天数 = 365 ÷ (3000 ÷ 700) = 85.2（天/次）
- 与收入比 = 700 ÷ 3000 = 23.3%

## 营运资本周转率

**示例（ABC公司）**：
- 营业收入 = 3000万元
- 营运资本 = 400万元（已剔除非经营性项目）

计算结果：
- 周转次数 = 3000 ÷ 400 = 7.5（次/年）
- 周转天数 = 365 ÷ (3000 ÷ 400) = 48.7（天/次）
- 与收入比 = 400 ÷ 3000 = 13.3%

## 存货周转率

**示例（ABC公司）**：
- 营业收入 = 3000万元
- 营业成本 = 2644万元
- 存货 = 119万元

计算结果：
- 存货（收入）周转次数 = 3000 ÷ 119 = 25.2（次/年）
- 存货（收入）周转天数 = 365 ÷ (3000 ÷ 119) = 14.5（天/次）
- 存货与收入比 = 119 ÷ 3000 = 4%

**成本率转换**：
- 成本率 = 2644 ÷ 3000 = 88.13%
- 存货（成本）周转次数 = 25.2 × 88.13% = 22.2（次）

## 营运资本等价公式

**从长期资本角度**：
营运资本 = 长期资本 - 长期资产

其中：
- 长期资本 = 股东权益 + 非流动负债
- 长期资产 = 非流动资产

**验证（ABC公司）**：
- 本年末营运资本 = 960 + 740 - 1300 = 400（万元）
- 与流动资产-流动负债计算结果一致
