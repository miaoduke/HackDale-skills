# 租赁决策分析

## 使用场景
当企业需要购置固定资产且考虑通过租赁方式筹资时，使用此技能进行租赁与购买的决策分析。

## 租赁决策五步法

### 第一步：分析是否应该取得一项资产
- 通过常规的资本预算程序完成
- 确信投资于该资产有正的净现值之后才会考虑如何筹资问题
- 若资本预算结果为负净现值，则直接放弃该资产

### 第二步：分析公司是否有足够的现金
- 评估企业现金状况
- 通常运行良好的公司没有足够的多余现金用于固定资产投资
- 确定需要通过外部筹资解决资金缺口

### 第三步：分析可供选择的筹资途径
- 筹资途径包括：借款、发行新股、租赁等
- 关键判断：租赁和借款对于资本结构的影响类似，1元的租赁等于1元的借款

### 第四步：利用租赁分析模型计算租赁净现值

**基本模型公式**：
租赁净现值 = 租赁的现金流量总现值 - 借款购买的现金流量总现值

**预计现金流量包括**：
1. 预计借款筹资购置资产的现金流量
2. 与可供选择的出租人讨论租赁方案
3. 判断租赁的税务性质
4. 预计租赁方案的现金流量

**折现率估计**：
- 标准做法：采用有担保债券的税后利率作为折现率

### 第五步：根据租赁净现值及其他非计量因素决策
- 定量因素：租赁净现值的正负和大小
- 非计量因素：合同条款灵活性、资产所有权偏好、未来技术发展不确定性、管理层风险偏好等

## 租赁存在的经济动因分析

### 降低交易成本
- **购置环节**：租赁公司大批量购置资产可获得价格优惠
- **维修环节**：租赁公司通常比承租人更内行或效率更高
- **处置环节**：租赁公司对旧资产处置更有经验
- **融资环节**：租赁公司融资成本通常低于承租人（特别是中小企业）

### 减少不确定性（风险）
- **风险归属**：租赁风险主要与租赁期满时资产余值有关。承租人不拥有所有权，不承担此风险
- **风险偏好匹配**：
  - 规模较小或新成立的公司（总风险大）：倾向于租赁以降低风险
  - 蓝筹公司（有能力承担风险）：倾向于自行购置

## 调整净现值法应用

### 适用条件
IF (项目按常规筹资有负的净现值) AND (租赁净现值 > 常规净现值的绝对值) THEN 应用调整净现值法

### 计算公式
项目的调整净现值 = 项目的常规净现值 + 租赁净现值

### 决策规则
- 若调整净现值 > 0：尽管常规净现值为负，但考虑租赁筹资后项目具有投资价值，应接受项目
- 若调整净现值 ≤ 0：即使考虑租赁筹资，项目仍不具有投资价值，应拒绝项目

## 输出结果
- 租赁净现值 > 0：选择租赁筹资更有利，可增加股东财富
- 租赁净现值 < 0：选择借款购买更有利
- 需结合非计量因素综合决策
