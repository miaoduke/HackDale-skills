# 辅助生产费用归集与分配

## 适用场景
- 辅助生产车间发生费用
- 需要分配辅助生产费用
- 辅助生产车间之间存在内部交互服务

## 辅助生产费用归集

### 科目设置
使用"生产成本——辅助生产成本"科目，并按车间和产品品种设置明细账。

### 直接费用归集
- **直接材料费用**：根据"材料费用分配表"记入该科目借方
- **直接人工费用**：根据"工资及其他职工薪酬分配汇总表"及有关凭证记入该科目借方

### 间接费用归集
- 辅助生产发生的间接费用，先记入"制造费用"科目借方
- 期末再从"制造费用"科目贷方，直接转入或分配转入"生产成本——辅助生产成本"科目及其明细账的借方

### 完工转出
辅助生产车间完工的产品或劳务成本，从"生产成本——辅助生产成本"科目贷方转出。

### 余额含义
"生产成本——辅助生产成本"科目的借方余额表示辅助生产的产品成本（即在产品成本）。

## 一次交互分配法

### 适用条件
- 需要分配辅助生产费用
- 辅助生产车间之间存在内部交互服务

### 分配流程

#### 第一阶段：交互分配（第一次分配）

**步骤1：计算交互分配前的单位成本**
```
交互分配前的单位成本 = 待分配费用总额 ÷ 该辅助生产车间提供的劳务总量
```

**步骤2：在各辅助生产车间之间进行分配**
根据各辅助生产车间相互提供的产品或劳务数量和交互分配前的单位成本，计算交互分配的金额。

#### 第二阶段：对外分配（第二次分配）

**步骤3：计算交互分配后的实际费用**
```
交互分配后的实际费用 = 交互分配前的成本费用 + 交互分配转入的成本费用 - 交互分配转出的成本费用
```

**步骤4：计算交互分配后的单位成本**
```
交互分配后的单位成本 = 交互分配后的实际费用 ÷ 对外提供产品或劳务的数量
```

**步骤5：在辅助生产车间以外的各受益单位进行分配**
根据对外提供的产品或劳务数量和交互分配后的单位成本，计算各受益单位应承担的费用。

### 账务处理

**交互分配分录**：
```
借：生产成本——辅助生产成本——[受益车间]
贷：生产成本——辅助生产成本——[提供劳务车间]
```

**对外分配分录**：
```
借：生产成本——基本生产成本——[产品]
    制造费用
    管理费用
贷：生产成本——辅助生产成本——[辅助生产车间]
```

### 方法评价

**优点**：辅助生产内部相互提供的产品或劳务全都进行了交互分配，从而提高了分配结果的准确性。

**缺点**：各辅助生产费用要计算两个单位成本（费用分配率），进行两次分配，增加了计算工作量。
