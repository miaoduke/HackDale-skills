# 折价债券价值周期性变动规律

## 使用条件

在以下情况下使用本技能：
- 债券为折价发行（票面利率 < 市场利率）
- 债券在二级市场流通
- 发行后市场利率保持不变

## 核心规律

流通债券的价值在两个付息日之间呈周期性变动，总体呈现"锯齿状上升"的形态。

## 付息周期内的四个阶段

### 阶段一：付息日后 → 逐渐升高
- 发行后价值逐渐升高
- 原因：随着下一次利息支付的临近，利息的现值逐渐增大

### 阶段二：临近付息日 → 可能超过面值
- 越临近付息日，利息的现值越大
- 债券的价值有可能超过面值

### 阶段三：付息日 → 割息导致价值下降
- 在付息日由于"割息"（利息支付）而价值下降
- 付息日后债券的价值下降，会低于面值

### 阶段四：新的周期开始 → 重复上升
- 然后又逐渐上升

## 关键概念

### 割息
指债券支付利息的行为，付息后债券剥离了该期利息权利，价值相应下降。

### 折价债券价值能暂时超过面值的原因
临近付息日时，即将收到的利息现值很大，加上本金现值，总和可能超过面值。

## 图形化理解

- **横轴**：时间（付息周期）
- **纵轴**：债券价值
- **曲线形态**：锯齿状上升曲线，每个付息周期内先上升后骤降，总体向上倾斜

## 应用意义

- **投资者可利用此规律选择买卖时机**
- 临近付息日前卖出可能获得较高价格
- 付息日后买入可能获得较低价格

## 执行步骤

1. 确认债券是否符合使用条件（折价发行、市场利率不变）
2. 识别当前处于付息周期的哪个阶段
3. 根据所处阶段判断债券价值的变动趋势
4. 结合投资目标选择合适的买卖时机

## 约束条件

- 仅适用于折价发行债券
- 假设发行后市场利率保持不变
- 不适用于溢价发行债券的变动规律
