# 杜邦分析完整示例

## 基础数据

| 指标 | 上年 | 本年 |
|------|------|------|
| 营业净利率 | 5.61% | 4.533% |
| 总资产周转次数 | 1.37 | 1.5 |
| 权益乘数 | 1.9091 | 1.9091 |
| 权益净利率 | 14.68% | 12.98% |

## 连环替代法计算

### 基数（上年）
```
权益净利率 = 5.61% × 1.37 × 1.9091 = 14.68%
```

### 第一次替代：营业净利率
```
权益净利率 = 4.533% × 1.37 × 1.9091 = 11.86%
营业净利率变动影响 = 11.86% - 14.68% = -2.82%
```

### 第二次替代：总资产周转次数
```
权益净利率 = 4.533% × 1.5 × 1.9091 = 12.98%
总资产周转次数变动影响 = 12.98% - 11.86% = 1.12%
```

### 第三次替代：权益乘数
```
权益净利率 = 4.533% × 1.5 × 1.9091 = 12.98%
权益乘数变动影响 = 12.98% - 12.98% = 0%
```

## 影响因素汇总

| 因素 | 影响金额 | 影响性质 |
|------|---------|---------|
| 营业净利率 | -2.82% | 不利 |
| 总资产周转次数 | 1.12% | 有利 |
| 权益乘数 | 0% | 无影响 |
| **合计** | **-1.70%** | **不利** |

## 分析结论

1. **营业净利率降低**是导致权益净利率下降的主要原因（-2.82%）
2. **总资产周转次数提高**部分抵消了不利影响（+1.12%）
3. **权益乘数不变**，财务杠杆未发生变化
4. **总体影响**：权益净利率下降1.70个百分点

## 改进建议

1. **提高营业净利率：**
   - 控制成本费用
   - 提高产品附加值
   - 优化产品结构

2. **保持总资产周转效率：**
   - 继续提高资产利用效率
   - 优化资产结构
   - 加速存货和应收账款周转

3. **考虑适度财务杠杆：**
   - 在风险可控前提下，可适当提高权益乘数
