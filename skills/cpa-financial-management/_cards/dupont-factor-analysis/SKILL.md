# 杜邦分析因素分析

## 使用场景
当需要计算总资产周转次数变动对权益净利率的影响时使用此技能。

## 替代顺序（连环替代法）

### 杜邦分析公式
```
权益净利率 = 营业净利率 × 总资产周转次数 × 权益乘数
```

### 替代步骤

**第一次替代：营业净利率**
```
营业净利率变动后的权益净利率 = 本年营业净利率 × 上年总资产周转次数 × 上年权益乘数
```

**第二次替代：总资产周转次数**
```
总资产周转次数变动后的权益净利率 = 本年营业净利率 × 本年总资产周转次数 × 上年权益乘数
```

**第三次替代：权益乘数**
```
权益乘数变动后的权益净利率 = 本年营业净利率 × 本年总资产周转次数 × 本年权益乘数
```

## 总资产周转次数变动影响计算

### 计算公式
```
总资产周转次数变动影响 = 总资产周转次数变动后的权益净利率 - 营业净利率变动后的权益净利率
```

### 结果解读
- **正值：** 表明总资产周转次数提高，对权益净利率产生有利影响
- **负值：** 表明总资产周转次数降低，对权益净利率产生不利影响

## 计算示例

### 已知条件
- 本年营业净利率：4.533%
- 本年总资产周转次数：1.5
- 上年权益乘数：1.9091
- 营业净利率变动后的权益净利率：14.68%

### 计算过程

**步骤1：计算总资产周转次数变动后的权益净利率**
```
= 4.533% × 1.5 × 1.9091
= 12.98%
```

**步骤2：计算总资产周转次数变动的影响**
```
= 12.98% - 14.68%
= -1.7%
```

### 结果解读
-1.7%表示由于总资产周转次数降低，导致权益净利率下降了1.7个百分点。

## 关键要点

1. **替代顺序：** 必须按照营业净利率→总资产周转次数→权益乘数的顺序
2. **基准选择：** 计算某因素影响时，该因素用本年数据，其他因素用上年数据
3. **综合分析：** 与营业净利率变动影响、权益乘数变动影响共同构成权益净利率总变动分析
