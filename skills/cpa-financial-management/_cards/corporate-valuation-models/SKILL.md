# 企业估值模型

## 适用场景
- 企业价值评估
- 投资项目评价
- 计算内含增长率
- 财务规划与增长预测

## 现金流量折现模型

### 何时使用
需要进行企业价值评估，且基于未来收益视角时。

### 核心原则
任何资产的价值是其产生的未来现金流量按照含有风险的折现率计算的现值。

### 执行步骤
1. **确定评估基准日**：明确价值评估的时点
2. **预测未来现金流量**：预测企业或资产未来产生的经济利益流入
3. **确定折现率**：选择含有风险的折现率
4. **计算现值**：将未来现金流量折现到当前时点
5. **处理企业特殊性**：解决无限期、增长特征、分配计量等问题

### 企业作为资产的特殊性
- 企业是由若干投资项目组成的复合项目
- 可以使用现金流量折现法进行评估

### 与投资项目评价的相似性
- 都能带来现金流量
- 现金流量均具有不确定性
- 现金流量均为陆续产生
- 净现值（NPV）是项目产生的企业价值增量

### 与投资项目评价的区别
- **寿命期限**：项目寿命有限，企业寿命无限
- **现金流量特征**：项目现金流量稳定或下降，企业通常增长
- **可计量性**：项目现金流量可直接计量，企业现金流量需决策层决定分配

## 内含增长率测算

### 何时使用
需要计算仅依靠内部留存收益支持的销售增长率时。

### 执行步骤
1. **确认基础假设**：
   - 可动用的金融资产为0
   - 经营资产销售百分比保持不变
   - 经营负债销售百分比保持不变
   - 不进行外部融资
2. **获取必要数据**：
   - 经营资产销售百分比
   - 经营负债销售百分比
   - 预计营业净利率
   - 预计股利支付率（或利润留存率）
3. **应用计算公式**：使用内含增长率公式
4. **变量替换**：如营业净利率不变，可用上年数据替代

### 核心公式
```
内含增长率 = [(预计净利润 / 预计净经营资产) × 预计利润留存率] / [1 - (预计净利润 / 预计净经营资产) × 预计利润留存率]
```

### 变量说明
- **经营资产销售百分比**：经营资产与营业收入的比率
- **经营负债销售百分比**：经营负债与营业收入的比率
- **预计营业净利率**：预计净利润与预计营业收入的比率
- **预计股利支付率**：预计支付股利占净利润的比例
- **预计利润留存率**：1 - 预计股利支付率

### 约束条件
- 可动用的金融资产为0
- 经营资产销售百分比保持不变
- 经营负债销售百分比保持不变
- 不进行外部融资（借款和股权融资）
