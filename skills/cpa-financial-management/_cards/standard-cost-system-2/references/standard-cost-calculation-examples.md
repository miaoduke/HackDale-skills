# 标准成本计算示例

## 计算示例

假设某月实际生产100件产品：
- 单位产品标准消耗量：2公斤材料
- 标准单价：10元/公斤

### 第一步：计算单位产品标准成本
```
单位产品标准成本 = 2公斤 × 10元/公斤 = 20元/件
```

### 第二步：计算标准成本总额
```
标准成本总额 = 100件 × 20元/件 = 2000元
```

## 差异分析应用

在成本差异分析中：
1. 先计算标准成本总额与实际总成本的总差异
2. 再分解为价格差异和数量差异
3. 此时需回溯使用单位产品标准消耗量和标准单价进行差异分解

## 关键要点

- 第一种含义（成本标准）适用于单位产品层面
- 第二种含义（总额）适用于批次或期间层面
- 成本差异分析通常从含义二开始，再回溯到含义一的构成要素
