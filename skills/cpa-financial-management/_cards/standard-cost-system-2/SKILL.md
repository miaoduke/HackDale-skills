# 标准成本系统

## 核心功能

标准成本系统具有四大核心功能：
1. **目标体现功能**：体现企业成本管理目标和要求，作为导向性指标
2. **效率衡量功能**：衡量产品制造过程的工作效率，通过实际成本与标准成本对比评估生产效率
3. **成本控制功能**：作为控制成本的核心工具，通过设定标准监控和约束实际成本支出
4. **计价功能**：用于存货计价和销货成本计价，为财务报表提供成本计量基础

## 系统定位

标准成本法是为克服实际成本计算系统缺陷（无法提供有助于成本控制的确切信息）而研究出来的会计信息系统和成本控制系统。

## 标准成本的双重含义

### 含义一：单位产品标准成本（成本标准）

**定义**：单位产品应当耗费的成本标准

**计算公式**：
```
成本标准 = 单位产品标准消耗量 × 标准单价
```

**构成要素**：
- 单位产品标准消耗量：在现有技术条件下，生产单位产品所需的材料数量、人工工时或机器工时
- 标准单价：预定的材料标准价格、人工标准工资率或制造费用标准分配率

### 含义二：实际产量的标准成本总额

**定义**：根据实际生产的产品总量计算得出的标准成本总金额

**计算公式**：
```
标准成本（总额）= 实际产量 × 单位产品标准成本
```
或展开为：
```
标准成本（总额）= 实际产量 × 单位产品标准消耗量 × 标准单价
```

## 应用场景优先级

- **首要应用**：制造过程效率评估与成本控制
- **次要应用**：存货和销货成本的会计计价

## 使用流程

1. 确定单位产品标准消耗量（通过技术测定）
2. 确定标准单价（材料价格、工资率、费用分配率）
3. 计算单位产品标准成本（含义一）
4. 根据实际产量计算标准成本总额（含义二）
5. 将标准成本总额与实际成本对比，进行差异分析
