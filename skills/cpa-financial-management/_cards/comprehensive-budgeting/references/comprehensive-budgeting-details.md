## 预算编制方法

### 固定预算
- 按照某一固定业务量编制
- 适用于业务量稳定的单位

### 弹性预算
- 按照不同业务量水平编制
- 适用于业务量波动较大的单位

### 增量预算
- 以基期成本费用水平为基础
- 结合预算期业务量水平及有关降低成本措施

### 零基预算
- 不以基期为基础
- 一切从零开始
- 适用于费用控制要求高的单位

### 定期预算
- 预算期固定与会计年度一致

### 滚动预算
- 预算期与会计年度脱节
- 随着预算执行不断延伸补充

## 差异分析方法

### 价格差异
```
价格差异 = (实际价格 - 标准价格) × 实际数量
```

### 数量差异
```
数量差异 = (实际数量 - 标准数量) × 标准价格
```

### 总差异
```
总差异 = 价格差异 + 数量差异
```

## 预算控制要点

### 事前控制
- 预算编制的合理性
- 预算目标的可行性

### 事中控制
- 预算执行的监控
- 偏差的及时纠正

### 事后控制
- 预算执行结果的分析
- 经验教训的总结

## 预算考核原则

### 公平性原则
- 考核标准统一
- 考核过程透明

### 激励性原则
- 考核结果与奖惩挂钩
- 激发员工积极性

### 可控性原则
- 只考核可控因素
- 排除不可控因素影响
