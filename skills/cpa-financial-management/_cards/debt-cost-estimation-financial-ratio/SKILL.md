# 财务比率法估计债务资本成本

## 何时使用

目标公司同时满足以下三个条件：
- 无上市长期债券（无法使用到期收益率法）
- 无可比公司（无法使用可比公司法）
- 无信用评级资料（无法直接使用风险调整法）

## 操作流程

### 第一步：收集6个关键财务比率

| 序号 | 财务比率 | 性质 |
|-----|---------|------|
| 1 | 利息保障倍数 | 正向指标（越高越好） |
| 2 | 净现金流/总负债 | 正向指标（越高越好） |
| 3 | 资本回报率 | 正向指标（越高越好） |
| 4 | 经营利润/销售收入 | 正向指标（越高越好） |
| 5 | 长期负债/总资产 | 负向指标（越低越好） |
| 6 | 总负债/总资产 | 负向指标（越低越好） |

### 第二步：对照行业信用级别基准

将目标公司6个比率与行业信用级别对照表逐项对比，综合判断最匹配的信用级别。

### 第三步：应用风险调整法

```
债务资本成本 = 同期限政府债券到期收益率 + 该信用级别对应的风险溢价
```

## 关键提示

- 实际判断时需考虑各比率的权重和行业特性
- 某些比率偏离较大时需结合业务实质分析
- 最终信用级别估计需综合6个比率的分布情况
