# 内含报酬率计算详细示例

## A项目逐步测试

### 已知条件
- 原始投资：20,000万元
- 第1年现金净流量：11,800万元
- 第2年现金净流量：13,240万元

### 第1次测试（18%）
- 第0年现值：(20,000) × 1 = (20,000)
- 第1年现值：11,800 × 0.847 = 9,995
- 第2年现值：13,240 × 0.718 = 9,506
- NPV = (20,000) + 9,995 + 9,506 = (499)万元

### 第2次测试（16%）
- 第0年现值：(20,000) × 1 = (20,000)
- 第1年现值：11,800 × 0.862 = 10,172
- 第2年现值：13,240 × 0.743 = 9,837
- NPV = (20,000) + 10,172 + 9,837 = 9万元

### 内插计算
IRR = 16% + 2% × (9 / 508) = 16.04%

## B项目测试

### 已知条件
- 原始投资：(9,000)万元
- 第1年：1,200万元
- 第2年：6,000万元
- 第3年：6,000万元

### 18%测试
- 第1年现值：1,200 × 0.847 = 1,016
- 第2年现值：6,000 × 0.718 = 4,308
- 第3年现值：6,000 × 0.609 = 3,654
- NPV = (9,000) + 1,016 + 4,308 + 3,654 = (22)万元

### 内插计算
从表5-5可知：18%时NPV = -22万元；16%时NPV = 338万元

IRR = 16% + 2% × (338 / 360) = 17.88%

## 年金现值系数表内插

### C项目
已知：(P/A, i, 3) = 2.609

查表：n=3时，7%对应2.624，8%对应2.577

i = 7% + 1% × [(2.624 - 2.609) / (2.624 - 2.577)]
i = 7% + 0.32% = 7.32%

## 共同年限法示例

### 重置现金流量计算
重置B项目第3年年末的现金净流量：
= 重置初始投资(-17,800万元) + 第一期项目第3年年末现金流入(12,000万元)
= -5,800万元
