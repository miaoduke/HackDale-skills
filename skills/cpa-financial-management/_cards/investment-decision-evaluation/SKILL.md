# 投资决策评估方法

## 适用场景
- 评估独立投资项目的可行性
- 比较互斥投资项目的优劣
- 项目寿命期不同时的决策
- 需要计算内含报酬率但现金流量不等

## 净现值法（NPV）

### 计算公式
**净现值 = 未来现金净流量现值 - 原始投资额现值**

### 决策标准
- **净现值 > 0**：投资报酬率 > 资本成本，增加股东财富，采纳
- **净现值 = 0**：投资报酬率 = 资本成本，不改变股东财富，可选
- **净现值 < 0**：投资报酬率 < 资本成本，减损股东财富，放弃

### 优缺点
- 优点：适用性广，理论上完善
- 缺点：绝对数指标，比较期限/投资额不同的项目有局限

## 现值指数法

### 计算公式
**现值指数 = 未来现金净流量现值 ÷ 原始投资额现值**

### 指标含义
表示1元初始投资现值取得的毛收益现值

### 决策标准
- **现值指数 > 1**：盈利，增加财富
- **现值指数 < 1**：亏损，财富减少

### 与净现值对比
- 现值指数：相对数，反映投资效率
- 净现值：绝对数，反映投资效益
- 现值指数消除了投资规模差异，但未消除期限差异

## 内含报酬率法（IRR）

### 适用条件
- 各期现金净流量不相等
- 无法直接使用年金现值系数表

### 逐步测试法

#### 步骤
1. **初始估计**：根据经验估计初始折现率i
2. **测试与判断**：
   - NPV > 0：提高折现率
   - NPV < 0：降低折现率
3. **多次迭代**：找到一正一负两个NPV值，且折现率差距较小

#### 示例
- 第1次测试（18%）：NPV = -499万元（负数）→ 降低折现率
- 第2次测试（16%）：NPV = 9万元（接近0的正数）→ IRR ≈ 16%

### 内插法精确计算

#### 公式
**IRR = i1 + (i2 - i1) × [NPV1 / (NPV1 + |NPV2|)]**

其中：
- i1：较低折现率（对应正NPV）
- i2：较高折现率（对应负NPV）
- NPV1：i1对应的净现值（正数）
- NPV2：i2对应的净现值（负数）

#### 计算示例
已知：i1=16%，NPV1=9万元；i2=18%，NPV2=-499万元

IRR = 16% + 2% × (9 / 508) = 16.04%

### 内含报酬率法的优缺点

#### 优点
- 揭示项目本身可以达到的实际报酬率
- 计算时不必事先估计资本成本

#### 缺点
1. **多解或无解问题**：非常规现金流（符号多次变化）导致
2. **不合理的再投资假设**：假设再投资报酬率 = 项目IRR（实际应为资本成本）

### 修订的内含报酬率法（MIRR）

#### 改进思路
- 以项目资本成本为折现率计算现金流出现值
- 以项目资本成本为复利利率计算现金流入终值
- 再投资报酬率 = 资本成本（更合理）

#### 决策规则
修订的内含报酬率 > 项目资本成本 → 项目可行

## 互斥项目比较方法

### 共同年限法（重置价值链法）

#### 适用场景
- 互斥项目
- 项目期限不同
- NPV与IRR评价结论有矛盾

#### 步骤
1. 确定项目年限
2. 确定共同比较期（最小公倍数或匹配较长年限）
3. 构建重置现金流量：
   - 重置年现金净流量 = 重置初始投资（负值）+ 第一期该年现金流入（正值）
4. 计算重置后净现值
5. 选择净现值较大的项目

#### 局限性
- 共同比较期可能很长（如7年和9年项目，共同期63年）
- 难以可靠估计几十年后的现金流量

### 等额年金法

#### 特征
- 将项目净现值平均分摊到每一年
- 计算等额年金

#### 优缺点
- 优点：应用简单，计算工作量小
- 缺点：不便于理解，概念抽象

### 方法选择
- 追求直观理解：选共同年限法
- 追求计算简便：选等额年金法
- 两种方法结论通常相同

## 决策流程

### 独立项目
1. 计算NPV
2. NPV > 0 → 采纳；NPV ≤ 0 → 放弃

### 互斥项目
1. 若期限相同：直接比较NPV
2. 若期限不同：使用共同年限法或等额年金法
3. 若NPV与IRR矛盾：以NPV为准（或使用共同年限法）
