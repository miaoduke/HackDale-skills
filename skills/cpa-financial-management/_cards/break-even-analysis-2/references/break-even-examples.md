# 保本分析示例

## 基础数据

假设：
- 单价（p）= 2元
- 单位变动成本（b）= 1.2元
- 固定成本（a）= 1,600元

## 保本点计算

### 保本量

保本量 = 固定成本 / (单价 - 单位变动成本)
       = 1,600 / (2 - 1.2)
       = 1,600 / 0.8
       = 2,000件

### 保本额

保本额 = 保本量 × 单价
       = 2,000 × 2
       = 4,000元

## 边际贡献图绘制说明

### 坐标轴

- 横轴（x）：业务量（销售量）
- 纵轴（y）：金额（收入、成本）

### 线条绘制

1. **变动成本线V**：从原点出发，斜率为单位变动成本1.2
   - 方程：y = 1.2x

2. **总成本线T**：从(0, 1,600)出发，与V平行
   - 方程：y = 1,600 + 1.2x

3. **销售收入线S**：从原点出发，斜率为单价2
   - 方程：y = 2x

### 保本点P

求解：2x = 1,600 + 1.2x
     0.8x = 1,600
     x = 2,000
     y = 4,000

保本点坐标：(2,000, 4,000)

### 图形解读

- 当x < 2,000时：销售收入线S在总成本线T下方，亏损区
- 当x = 2,000时：S与T相交，保本点
- 当x > 2,000时：S在T上方，盈利区
- S与V之间的垂直距离：边际贡献
- T与V之间的垂直距离：固定成本（始终为1,600）
