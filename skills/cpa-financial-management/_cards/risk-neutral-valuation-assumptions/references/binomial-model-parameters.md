# 二项式模型参数设定详解

## 波动率与价格变动参数

### 标准 CRR 模型（Cox-Ross-Rubinstein）

```
u = e^(σ√Δt)
d = e^(-σ√Δt) = 1/u
```

**特性**：中心对称，确保风险中性概率 `q ≈ 0.5`

### Jarrow-Rudd 模型（等概率设定）

```
u = e^((r-σ²/2)Δt + σ√Δt)
d = e^((r-σ²/2)Δt - σ√Δt)
q = 0.5
```

**适用场景**：需要简化风险中性概率计算时

### 风险中性概率公式

```
q = (e^(rΔt) - d) / (u - d)
```

约束条件：`d < e^(rΔt) < u`（无套利条件）

## 多期模型收敛性

### 收敛到 Black-Scholes

当 `n → ∞`（期数增加），二项式模型价格收敛：

```
C_binomial(n) → C_BS = S_0N(d1) - Ke^(-rT)N(d2)
```

**实用建议**：
- 欧式期权：n = 50-100 通常足够
- 美式期权：n = 100-500 取决于提前执行特征

### 期数选择权衡

| 期数 | 精度 | 计算成本 | 适用场景 |
|-----|------|---------|---------|
| n=10 | 低 | 极低 | 教学演示 |
| n=50 | 中 | 低 | 快速估算 |
| n=100 | 高 | 中 | 标准实务 |
| n=500+ | 很高 | 高 | 精确定价/敏感性分析 |

## 股息处理

### 已知现金股息

调整除息日前的股票价格：

```
S_adj = S - PV(Dividends)
```

### 连续股息收益率 q

调整风险中性概率：

```
q = (e^((r-q)Δt) - d) / (u - d)
```

## 利率期限结构

### 时变无风险利率

每期使用对应期限的即期利率：

```
q_i = (e^(r_iΔt) - d) / (u - d)
```

折现时使用相应期限的利率。

### 双利率模型（借贷利差）

当 `r_borrow ≠ r_lend`：

```
q_up = (e^(r_lendΔt) - d) / (u - d)    [多头头寸]
q_down = (e^(r_borrowΔt) - d) / (u - d)  [空头头寸]
```

产生无套利价格区间而非单一定价。
