# 市场摩擦调整方法

## 交易成本：买卖价差模型

### 包含比例交易成本

设交易成本率为 `k`（买卖各付）：

**调整后的无套利区间**：

```
C_ask ≤ C_model ≤ C_bid

其中：
C_ask = 复制组合成本（含买入成本）
C_bid = 复制组合收益（扣除卖出成本）
```

### Leland 模型（连续时间）

调整波动率以反映交易成本：

```
σ_adj = σ√(1 + √(2/π) × k/(σ√Δt))
```

## 卖空限制调整

### 保证金要求影响

设卖空保证金比例为 `m`（如 50%）：

**有效卖空收益**：

```
可用资金 = 卖空所得 × (1 - m)
```

**复制组合调整**：
- 减少股票空头头寸规模
- 或增加期权多头作为替代对冲

### 禁止卖空的市场

替代策略：
1. 使用已有持仓进行对冲
2. 寻找可替代的可卖空工具（期货、ETF）
3. 接受不完全对冲，计算跟踪误差

## 离散交易与不可分割性

### 最小交易单位约束

股票通常有最小交易单位（如 100 股）：

```
Δ = (C_up - C_down) / (S_up - S_down)  [理论对冲比率]
Δ_adj = round(Δ / lot_size) × lot_size  [实际可执行]
```

**离散误差**：`ε = |Δ - Δ_adj| × S`

## 税收影响

### 不同税率处理

设：
- `τ_c` = 资本利得税率
- `τ_d` = 股息税率
- `τ_i` = 利息收入税率

**税后无风险利率**：

```
r_after-tax = r × (1 - τ_i)
```

**含股息的标的资产收益**：

```
μ_after-tax = (r - q) + q × (1 - τ_d) = r - q × τ_d
```

## 流动性风险调整

### 流动性溢价

非流动性工具的估值调整：

```
V_liquid = V_model - L

L = 流动性溢价（通常基于买卖价差、Amihud 指标等估计）
```

### 市场冲击成本

大额交易的预期价格影响：

```
S_executed = S_quoted × (1 + λ × order_size / avg_daily_volume)

λ = 市场冲击系数（通常 0.1-1.0）
```
