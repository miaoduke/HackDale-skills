# 风险中性估值假设验证

## 何时使用

- 应用二项式期权定价模型前
- 构建风险中性复制组合时
- 检验无套利定价条件是否成立
- 模型结果与市场实际价格出现显著偏离时
- 评估模型在特定市场环境下的适用性

## 核心验证流程

### 第一步：验证市场参与者假设

检查以下行为假设是否成立：

| 假设 | 验证问题 | 常见偏离 |
|------|---------|---------|
| 价格接受者 | 交易规模是否影响市场价格？ | 大额交易冲击成本 |
| 理性决策 | 投资者是否追求期望收益最大化？ | 行为金融偏差 |

**若违反**：考虑使用包含流动性溢价或市场冲击的修正模型。

### 第二步：验证卖空机制假设

**必须同时满足**：
1. 允许无限制卖空标的资产
2. 可立即获得全部卖空所得现金
3. 卖空所得可按无风险利率投资

**快速检查清单**：
- [ ] 市场是否存在卖空禁令或限制？
- [ ] 卖空保证金要求比例是否为零？
- [ ] 卖空所得资金是否可即时动用？

**若违反**：
- 无法构建完整复制组合
- 风险中性估值可能高估或低估期权价值
- 建议改用受限卖空调整模型或市场价格校准

### 第三步：验证资金借贷假设

**理想条件**：
```
借款利率 = 贷款利率 = 无风险利率 r
且对所有参与者相同，无金额限制
```

**实际处理**：
- 若 `r_borrow > r_lend`：使用利率区间或平均利率近似
- 若存在信用额度限制：调整复制组合规模

### 第四步：验证价格过程假设（二项式模型特定）

**核心假设**：单期内价格仅有两种状态

```
S_0 → S_up = S_0 × u  （概率 q）
    → S_down = S_0 × d （概率 1-q）
```

**参数确定**：
- `u` 和 `d` 通常由标的资产波动率 σ 和时期长度 Δt 确定
- 常见设定：`u = e^(σ√Δt)`, `d = 1/u`

**若价格连续变动**：
- 增加二项式模型期数（多期逼近）
- 或改用 Black-Scholes 连续时间模型

### 第五步：验证市场摩擦假设

| 摩擦类型 | 理想假设 | 现实调整 |
|---------|---------|---------|
| 交易成本 | 零成本 | 加入买卖价差和佣金 |
| 税收 | 无税收或税率中性 | 使用税后收益率 |
| 可分割性 | 无限分割 | 最小交易单位限制 |

### 第六步：验证信息假设

- 所有参与者对 `S_up`、`S_down`、`r` 有同质预期
- 无私有信息或信息不对称

**若违反**：考虑引入信念异质性或信息溢价。

## 假设偏离的系统性影响

| 违反的假设 | 估值偏差方向 | 调整方法 |
|-----------|------------|---------|
| 卖空限制 | 通常低估看跌期权 | 使用受限卖空模型 |
| 借贷利差 | 取决于期权类型 | 双利率二项式模型 |
| 交易成本 | 扩大无套利区间 | 包含成本的边界分析 |
| 连续价格 | 单期误差 | 增加期数或换连续模型 |

## 快速决策流程

```
开始应用风险中性估值
    ↓
检查卖空和借贷限制是否严重？
    → 是 → 评估是否可用市场校准替代理论定价
    → 否 → 继续
    ↓
检查交易成本是否显著？
    → 是 → 使用无套利区间而非单一点估计
    → 否 → 继续
    ↓
单期二项式是否足够？
    → 是 → 应用标准风险中性定价
    → 否 → 增加期数或改用 Black-Scholes
```
