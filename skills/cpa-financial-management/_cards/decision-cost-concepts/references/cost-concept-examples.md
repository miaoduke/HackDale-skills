# 决策成本概念示例

## 可避免成本识别示例

**决策情境：** 决定是否增加销售人员

**方案A：** 增加销售人员
- 新增工资：50,000元/年
- 新增培训费：5,000元/年

**方案B：** 改进销售流程，不增加人员
- 流程优化成本：10,000元/年

**可避免成本分析：**
- 方案A的工资和培训费：若选择方案B则可避免，属于可避免成本
- 方案B的流程优化成本：若选择方案A则可避免，属于可避免成本

## 专属成本识别示例

**产品线分析：**

| 成本项目 | 产品A | 产品B | 共同成本 |
|----------|-------|-------|----------|
| 专用设备折旧 | 10,000元 | 8,000元 | - |
| 专用厂房租金 | 5,000元 | - | - |
| 管理人员工资 | - | - | 20,000元 |
| 公用设施费 | - | - | 3,000元 |

**专属成本：**
- 产品A：10,000 + 5,000 = 15,000元
- 产品B：8,000元

**共同成本：** 20,000 + 3,000 = 23,000元（决策时不考虑）

## 差量分析完整示例

**决策：** 自制还是外购零件

| 项目 | 自制方案 | 外购方案 |
|------|----------|----------|
| 单位变动成本 | 48元 | - |
| 单位购价 | - | 52元 |
| 专属固定成本 | 10,000元 | - |
| 年需求量 | 5,000件 | 5,000件 |

**计算：**
- 自制总成本 = 48 × 5,000 + 10,000 = 250,000元
- 外购总成本 = 52 × 5,000 = 260,000元
- 差量成本 = 260,000 - 250,000 = 10,000元

**决策：** 选择自制（节省10,000元）
