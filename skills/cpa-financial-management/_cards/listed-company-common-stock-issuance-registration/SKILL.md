# 上市公司普通股发行注册程序

## 适用场景

当中国境内上市公司（主板、科创板、创业板、北交所）计划发行普通股进行再融资时，使用本技能指导完整的注册发行流程。

**触发条件：**
- 拟进行定向增发（向特定对象发行）
- 拟进行公开发行（向不特定对象发行）
- 拟使用年度股东会授权额度进行小额快速融资
- 需要了解发行注册各阶段时限及合规要求

## 前置条件

启动注册程序前必须满足：
1. **董事会依法作出决议**（距首次公开发行上市日不少于6个月）
2. **股东会批准**（须经出席会议股东所持表决权2/3以上通过）
3. **保荐人保荐**（由保荐人向交易所申报）

## 核心工作流程

### 阶段一：内部决策（董事会→股东会）

**1. 董事会决议**
- 编制论证分析报告（含发行必要性、定价合理性等6项内容）
- 独立董事发表专项意见
- 如引入战略投资者，需逐名审议并作为单独议案
- **关键时限**：董事会决议日与首次公开发行股票上市日间隔≥6个月

**2. 股东会审议**
- 决议内容：发行种类数量、方式对象、定价方式、募集资金用途、有效期、授权事项
- **表决要求**：
  - 须经出席会议股东所持表决权2/3以上通过
  - 中小投资者表决单独计票
  - 关联股东回避表决
  - 战略投资者作为单独议案表决
- 必须提供网络投票方式

**特殊授权机制**：年度股东会可授权董事会决定向特定对象发行融资总额≤3亿元且≤最近1年末净资产20%的股票，授权在下一年度股东会召开日失效。

### 阶段二：申报与受理

- 制作注册申请文件，由保荐人向交易所申报
- 交易所5个工作日内决定是否受理
- **法律责任起点**：自申报之日起，相关方承担法律责任
- 受理后文件不得随意改动，重大事项需及时报告更新

### 阶段三：交易所审核

- 审核部门审核，上市委员会对公开发行申请提出审议意见
- 通过问询与回答方式开展审核
- **审核时限**：自受理之日起2个月内形成审核意见（补充、修改、现场检查时间除外）
- 发现重大敏感事项、无先例情况、重大舆情、违法线索需及时向证监会请示报告

### 阶段四：证监会注册

- 证监会收到交易所审核意见后，15个工作日内作出予以注册或不予注册的决定（补充、修改、核查时间除外）
- 发现新增事项可要求交易所进一步问询
- 认为审核意见依据不充分，可退回交易所补充审核（期限重新计算）
- **注册有效期**：予以注册的决定自作出之日起1年内有效

### 阶段五：发行上市前管理

- 持续更新信息披露文件，保荐人持续尽职调查
- 发生重大事项需及时报告
- **风险防控**：若发现不符合发行条件，证监会可要求暂缓发行或撤销注册
- **撤销后果**：尚未发行的停止发行；已发行未上市的，按发行价加算银行同期存款利息返还持有人

### 阶段六：特殊情形处理

- **再次申请**：终止审核或不予注册的，6个月后可再次提出申请
- **中止程序**：存在重大资产重组、实际控制人变更等事项，应及时申请中止（因本次发行导致实际控制人变更的除外）
- **现场检查**：证监会和交易所可进行现场检查或要求专项核查

## 关键参数速查

| 参数 | 要求 |
|------|------|
| 董事会决议间隔期 | ≥6个月（距首次公开发行上市日） |
| 股东会表决比例 | ≥2/3出席会议表决权 |
| 小额快速融资上限 | ≤3亿元且≤最近1年末净资产20% |
| 交易所审核时限 | 2个月（受理之日起） |
| 证监会注册时限 | 15个工作日 |
| 注册有效期 | 1年 |
| 再次申请间隔 | 6个月（被终止/不予注册后） |

## 合规约束清单

- 必须符合发行条件
- 必须符合信息披露要求
- 必须符合国家产业政策和板块定位
- 关联股东必须回避表决
- 必须提供网络投票

## 使用说明

1. **确定发行类型**：首先明确是向特定对象发行（定向增发）还是向不特定对象发行（公开发行/配股）
2. **检查时间窗口**：确认董事会决议日距公司上市日是否已满6个月
3. **准备论证报告**：确保论证分析报告包含6项法定内容并获得独立董事意见
4. **关注审核进度**：跟踪交易所审核问询，确保在2个月审核期内及时回复
5. **把握发行窗口**：注册决定作出后1年内自主选择发行时点
