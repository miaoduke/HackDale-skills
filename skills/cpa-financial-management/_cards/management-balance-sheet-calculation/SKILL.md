# 管理用资产负债表计算

## 使用场景
当以下情况时触发此技能：
- 已完成资产和负债的经营/金融分类
- 需要计算管理用资产负债表关键指标
- 需要验证管理用报表的会计恒等式

## 前置条件
在应用此技能前，必须确保：
- 资产和负债已正确进行经营/金融分类
- 无项目遗漏或错分

## 计算流程

### 第一层：基础分解
1. **资产分解**
   - 资产 = 经营资产 + 金融资产
   - 经营资产 = 经营性流动资产 + 经营性长期资产
   - 金融资产 = 短期金融资产 + 长期金融资产

2. **负债分解**
   - 负债 = 经营负债 + 金融负债
   - 经营负债 = 经营性流动负债 + 经营性长期负债
   - 金融负债 = 短期金融负债 + 长期金融负债

### 第二层：净额计算
3. **净经营资产**
   - 净经营资产 = 经营资产 - 经营负债
   - = (经营性流动资产 - 经营性流动负债) + (经营性长期资产 - 经营性长期负债)
   - = 经营营运资本 + 净经营性长期资产

4. **净负债**
   - 净负债 = 金融负债 - 金融资产
   - = 净金融负债

### 第三层：平衡关系
5. **会计恒等式**
   - 净经营资产 = 净负债 + 股东权益
   - = 净投资资本

## 关键指标

| 指标名称 | 计算公式 | 说明 |
|---------|---------|------|
| 经营营运资本 | 经营性流动资产 - 经营性流动负债 | 反映经营性流动资金占用 |
| 净经营性长期资产 | 经营性长期资产 - 经营性长期负债 | 反映长期经营净投资 |
| 净经营资产 | 经营资产 - 经营负债 | 企业经营活动的净投资 |
| 净负债 | 金融负债 - 金融资产 | 企业金融活动的净融资 |
| 净投资资本 | 净经营资产 | 等价表述，等于净负债加股东权益 |

## 验证步骤
1. 计算净经营资产（通过经营资产减经营负债）
2. 计算净负债（通过金融负债减金融资产）
3. 验证平衡关系：净经营资产 = 净负债 + 股东权益
4. 如果等式不成立，检查分类是否正确或计算是否有误

## 注意事项
- 确保所有项目都已正确分类为经营性或金融性
- 经营营运资本和净经营性长期资产之和应等于净经营资产
- 净经营资产、净负债和股东权益三者必须满足平衡关系
