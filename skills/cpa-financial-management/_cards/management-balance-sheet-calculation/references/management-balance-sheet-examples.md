# 管理用资产负债表计算示例

## ABC公司年末数据验证

### 基础数据
- 经营性流动资产 = 700万元
- 经营性流动负债 = 228万元
- 经营性长期资产 = 1,300万元
- 经营性长期负债 = 50万元
- 金融负债合计 = 762万元
- 金融资产合计 = 0万元
- 股东权益合计 = 960万元

### 计算过程

#### 第一步：计算经营营运资本
```
经营营运资本 = 经营性流动资产 - 经营性流动负债
            = 700 - 228
            = 472万元 ✓
```

#### 第二步：计算净经营性长期资产
```
净经营性长期资产 = 经营性长期资产 - 经营性长期负债
                 = 1,300 - 50
                 = 1,250万元 ✓
```

#### 第三步：计算净经营资产
```
净经营资产 = 经营营运资本 + 净经营性长期资产
           = 472 + 1,250
           = 1,722万元 ✓
```

#### 第四步：计算净负债
```
净负债 = 金融负债 - 金融资产
       = 762 - 0
       = 762万元 ✓
```

#### 第五步：验证平衡关系
```
净负债 + 股东权益 = 762 + 960 = 1,722万元
净经营资产 = 1,722万元

验证结果：1,722 = 1,722 ✓
```

## 公式层次结构

### 第一层：基础分解公式
- 资产 = 经营资产 + 金融资产
- 负债 = 经营负债 + 金融负债

### 第二层：净额计算
- 净经营资产 = 经营资产 - 经营负债
- 净金融负债 = 金融负债 - 金融资产

### 第三层：平衡关系
- 净经营资产 = 净负债 + 股东权益 = 净投资资本

## 常见错误

1. **分类错误**：将经营性项目误分为金融性，或反之
2. **遗漏项目**：某些资产负债表项目未纳入计算
3. **符号错误**：净负债计算时顺序颠倒
4. **平衡验证缺失**：未验证会计恒等式是否成立
