# 作业成本法计算示例

## 已知数据
- 批次级作业成本总额：84,000元
- 生产批次数：30批
- 夹克产品线成本：54,000元，24批
- 西服产品线成本：66,000元，6批
- 生产维持成本：10,800元
- 直接人工成本：107,400元

## 第一步：计算作业成本分配率

```
批次级分配率 = 84,000 / 30 = 2,800元/批
夹克产品线分配率 = 54,000 / 24 = 2,250元/批
西服产品线分配率 = 66,000 / 6 = 11,000元/批
生产维持分配率 = 10,800 / 107,400 ≈ 0.1006
```

## 第二步：分配作业成本到产品

假设某产品本月生产10批，其中夹克8批、西服2批，直接人工成本50,000元：

```
批次相关成本 = 10 × 2,800 = 28,000元
夹克产品相关成本 = 8 × 2,250 = 18,000元
西服产品相关成本 = 2 × 11,000 = 22,000元
生产维持成本 = 50,000 × 0.1006 = 5,030元

制造费用合计 = 28,000 + 18,000 + 22,000 + 5,030 = 73,030元
```

## 汇总计算总成本

假设该产品直接材料30,000元，直接人工50,000元，产量1,000件：

```
总成本 = 30,000 + 50,000 + 73,030 = 153,030元
单件成本 = 153,030 / 1,000 = 153.03元/件
```
