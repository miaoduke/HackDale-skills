# 成本会计与决策

## 适用场景
- 选择分步成本计算方法
- 采用作业成本法核算产品成本
- 短期生产决策和多方案优选
- 特殊订单决策和约束资源利用决策

## 核心内容

### 1. 分步法分类与选择

**分类决策依据：**
- 首要考虑因素：成本管理是否要求计算半成品成本
- 次要考虑因素：简化核算的要求

**两种方法类型：**

| 方法 | 适用条件 | 特征 |
|:---|:---|:---|
| 逐步结转分步法 | 需要计算半成品成本 | 按加工顺序逐步计算并结转半成品成本 |
| 平行结转分步法 | 不需要计算半成品成本或需要简化核算 | 各步骤成本平行汇总计算产成品成本 |

**选择逻辑：**
```
IF (管理要求提供各步骤半成品成本资料)
THEN 采用逐步结转分步法
ELSE IF (管理不要求半成品成本资料 AND 要求简化核算)
THEN 采用平行结转分步法
```

### 2. 作业成本法分配计算

**两步分配法：**

**第一步：计算作业成本分配率**
```
分配率 = 作业成本总额 / 成本动因总量
```

**成本库类型：**
- **批次级作业成本库：** 包含生产准备、抽样检验、供应材料，通常按生产批次数分配
- **产品级作业成本库：** 按产品线分配，分配基础可选择生产批次、产品产量或相关成本
- **生产维持成本库：** 分配基础通常选择直接人工成本

**第二步：分配作业成本到产品**
- 批次相关成本 = 本月批次 × 批次级分配率
- 产品相关成本 = 本月批次 × 对应产品线分配率
- 生产维持成本 = 直接人工成本 × 维持级分配率

**汇总计算总成本：**
```
制造费用合计 = 批次相关总成本 + 产品相关总成本 + 生产维持成本
总成本 = 直接材料 + 直接人工 + 制造费用合计
单件成本 = 总成本 / 产量
```

### 3. 边际贡献分析法

**基本公式：**
```
边际贡献 = 销售收入 - 变动成本
```

**标准决策流程（无专属成本时）：**
1. 计算各备选方案的边际贡献额
2. 直接比较各方案边际贡献额的大小
3. 选择边际贡献额最大的方案作为最优方案

**原理依据：** 在短期生产决策过程中，固定成本往往稳定不变，因此固定成本为无关成本，无需考虑

**特殊处理流程（涉及追加专属成本时）：**
```
相关损益（剩余边际贡献） = 边际贡献额 - 专属成本
```

**决策规则：**
- 无专属成本时：选择边际贡献额最大的方案
- 存在专属成本时：选择相关损益（剩余边际贡献）最大的方案

**适用边界检查：**
- 确认决策属于短期经营决策范围
- 确认固定成本在相关范围内确实保持不变
- 若固定成本发生变化，需重新评估方法适用性

## 决策要点
- 分步法选择取决于是否需要计算半成品成本
- 作业成本法采用两步分配：计算分配率、分配成本
- 若不同产品品种的批次级成本差异大，需分品种建立成本库
- 边际贡献分析法适用于固定成本稳定不变的短期决策
- 涉及追加专属成本时，必须转为使用相关损益指标
