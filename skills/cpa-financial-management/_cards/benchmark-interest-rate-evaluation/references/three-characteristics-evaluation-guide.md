# 三大特征详细评估指南

本指南提供基准利率三大特征的详细评估方法论和量化标准。

## 一、市场化（Marketization）深度评估

### 1.1 市场供求弹性测算

**定义**：利率变动百分比与市场资金供求变动百分比的比率。

**计算公式**：
```
弹性系数 = (Δr/r) / (ΔM/M)
```
其中：
- Δr：利率变动值
- r：基准利率水平
- ΔM：市场资金供求变动量（可用货币市场成交量、银行间质押式回购成交量等代理）
- M：市场资金供求基期水平

**判断标准**：
- 高弹性（|弹性| > 0.5）：市场化程度高
- 中弹性（0.2 < |弹性| < 0.5）：市场化程度中等
- 低弹性（|弹性| < 0.2）：市场化程度低，可能存在管制

### 1.2 信息含量检验（事件研究法）

**步骤**：
1. 选取宏观经济数据发布事件（如CPI、GDP、PMI发布）
2. 定义事件窗口（如发布前后各5个交易日）
3. 计算异常收益率（利率变动）
4. 统计显著性检验

**判断标准**：
- 在1%水平显著响应宏观经济数据：信息含量高，市场化程度好
- 不显著或延迟响应：可能存在行政干预或市场分割

### 1.3 与政策利率利差分析

观察基准利率与央行政策利率（如MLF、逆回购利率）的利差变化：
- 利差稳定收窄：市场化程度提升
- 利差异常扩大或长期固定：可能存在非市场因素

## 二、基础性（Fundamentality）深度评估

### 2.1 相关性矩阵构建

**步骤**：
1. 选取代表性利率品种：
   - 货币市场：DR007、SHIBOR、同业存单利率
   - 债券市场：国债收益率（1年、5年、10年）
   - 信贷市场：LPR、一般贷款利率
   - 存款市场：大额存单利率

2. 计算皮尔逊相关系数：
```
ρ(X,Y) = Cov(X,Y) / (σ_X * σ_Y)
```

3. 构建相关性热力图

**判断标准**：
- 与主要市场利率相关系数 > 0.8：基础性强
- 相关系数 0.5-0.8：基础性中等
- 相关系数 < 0.5：基础性弱，不适合作为基准利率

### 2.2 网络中心性分析

使用网络分析方法识别利率体系的中心节点：
- **度中心性**：与该利率直接相关的其他利率数量
- **中介中心性**：该利率在其他利率对之间的中介作用
- **特征向量中心性**：考虑邻居节点重要性的综合中心性指标

**工具**：可使用Gephi、Python NetworkX库进行分析

### 2.3 定价模式验证

**检验方法**：
1. 收集浮动利率债券、贷款利率的定价公式
2. 验证是否采用"基准利率+利差"模式
3. 统计使用该基准利率定价的金融产品规模占比

**判断标准**：
- 定价参照占比 > 50%：具有基础性地位
- 定价参照占比 < 20%：基础性不足

## 三、传递性（Transmission）深度评估

### 3.1 传导时滞测算（向量自回归模型）

**模型设定**：
```
Δr_t = α + Σβ_i * Δr_{t-i} + Σγ_j * Δpolicy_{t-j} + ε_t
```

**步骤**：
1. 建立VAR模型或SVAR模型
2. 进行脉冲响应分析（Impulse Response Function）
3. 观察基准利率冲击对其他利率的峰值响应时间

**判断标准**：
- 最优传导时滞：1-2个月（货币市场），2-3个月（信贷市场）
- 时滞 > 6个月：传递性存在严重问题

### 3.2 传导幅度比率计算

**计算公式**：
```
传导幅度比率 = (目标利率变动幅度 / 基准利率变动幅度) × 100%
```

**分市场测算**：
- 货币市场传导：通常接近100%
- 债券市场传导：通常80-100%
- 信贷市场传导：通常60-80%（受银行定价行为影响）
- 存款利率传导：通常50-70%（受银行负债成本约束）

**判断标准**：
- 比率 > 80%：传递性优秀
- 比率 50-80%：传递性良好
- 比率 < 50%：传递性不足，存在堵塞

### 3.3 传导渠道诊断

**渠道一：金融机构资产负债渠道**
- 观察银行存贷款重定价频率
- 分析银行FTP（内部资金转移定价）机制是否参考基准利率

**渠道二：市场套利渠道**
- 观察基差交易活跃度
- 分析利率互换市场与现货市场的联动性

**渠道三：预期渠道**
- 通过问卷调查或市场隐含利率分析预期形成机制
- 观察基准利率变动对远期利率的影响
