# 短期偿债能力分析

## 使用场景
当需要评估企业短期债务支付能力、进行信用分析或风险预警时使用此技能。

## 分析流程

### 第一步：计算核心比率指标

**1. 流动比率**
```
流动比率 = 流动资产 ÷ 流动负债
```
- 传统参考标准：2左右
- 现代趋势：许多成功企业低于2
- 行业规律：营业周期越短，合理比率越低

**2. 速动比率**
```
速动比率 = 速动资产 ÷ 流动负债
速动资产 = 货币资金 + 交易性金融资产 + 各种应收款项
```
- 大量现销企业：低于1属正常
- 应收款项较多企业：可能大于1

**3. 现金比率**
```
现金比率 = 货币资金 ÷ 流动负债
```
- 反映即时支付能力
- 最保守的偿债能力指标

### 第二步：识别表外影响因素

**增强因素：**
- 可动用的银行授信额度（查阅董事会决议公告）
- 可快速变现的非流动资产（储备土地、采矿权、出租房产等）
- 良好的偿债声誉

**降低因素：**
- 与担保有关的或有负债（金额较大且很可能发生时需扣减）

### 第三步：检查应收账款预警信号

**正常逻辑链条：**
赊销增加 → 应收账款增加 → 现金增加

**异常预警信号：**
应收账款日益增加 + 现金日益减少

**潜在问题诊断：**
- 大为放宽信用政策（激进销售）
- 随意发货（缺乏管控）
- 未能收回现金（回款困难）

## 注意事项

1. **比率局限性：**
   - 流动比率假设全部流动资产可变现
   - 速动比率依赖应收款项质量
   - 需结合行业特征和历史趋势分析

2. **综合分析要求：**
   - 不同行业比率标准差异显著
   - 需对流动资产和流动负债各项目逐一分析
   - 检查流动资产周转率考察变现能力

3. **表外信息获取：**
   - 授信额度通常不在财务报表中反映
   - 需查阅董事会决议公告等披露信息
