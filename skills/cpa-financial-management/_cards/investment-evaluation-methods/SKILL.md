# 投资项目评估方法

## 使用场景
当需要使用会计报表数据评估项目盈利性，或进行业绩评价时，使用此技能计算会计报酬率。

## 会计报酬率法

### 基本公式

会计报酬率 = (年平均税后经营净利润 / 资本占用) × 100%

### 分母确定（资本占用）

#### 方式一：原始投资额
```
会计报酬率 = (年平均税后经营净利润 / 原始投资额) × 100%
```

#### 方式二：平均资本占用
```
会计报酬率 = (年平均税后经营净利润 / 平均资本占用) × 100%
其中：平均资本占用 = (原始投资额 + 投资净残值) ÷ 2
```

### 计算示例

假设某项目数据：
- 第1年税后经营净利润 = 1800万元
- 第2年税后经营净利润 = 3240万元
- 原始投资额 = 20000万元
- 投资净残值 = 0万元

#### 计算分子
```
年平均税后经营净利润 = (1800 + 3240) ÷ 2 = 2520万元
```

#### 按方式一计算
```
会计报酬率 = (2520 / 20000) × 100% = 12.6%
```

#### 按方式二计算
```
平均资本占用 = (20000 + 0) ÷ 2 = 10000万元
会计报酬率 = (2520 / 10000) × 100% = 25.2%
```

### 方法特性

#### 优点
- 概念简单易懂
- 数据易从财务报告取得
- 考虑了整个寿命期利润
- 揭示财务报表变化，便于业绩预期和后续评价

#### 缺点
- 使用账面利润而非现金流量，忽视折旧影响
- 忽视利润时间分布对经济价值的影响
- 不适用于需要精确评估现金流量的场景
- 不适用于对货币时间价值敏感的项目评估

## 适用场景

- 使用会计报表数据评估项目盈利性
- 业绩评价和考核
- 初步项目筛选
- 与其他评估方法结合使用

## 不适用场景

- 需要精确评估现金流量的场景
- 对货币时间价值敏感的项目评估
- 长期、大型投资项目的最终决策

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| 年平均税后经营净利润 | 货币金额 | 项目整个寿命期内的年平均税后经营净利润 |
| 原始投资额 | 货币金额 | 项目初始投入的资本总额 |
| 投资净残值 | 货币金额 | 项目结束时的估计残值 |
| 平均资本占用 | 货币金额 | (原始投资额 + 投资净残值) ÷ 2 |

## 决策参考

- 会计报酬率越高，项目盈利性越好
- 可与行业平均或企业要求的最低报酬率比较
- 应与其他评估方法（如NPV、IRR）结合使用
