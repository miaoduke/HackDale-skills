# 投资评估方法详细比较

## 会计报酬率法 vs 净现值法

| 维度 | 会计报酬率法 | 净现值法 |
|------|-------------|---------|
| 数据基础 | 会计利润 | 现金流量 |
| 时间价值 | 不考虑 | 考虑 |
| 计算复杂度 | 简单 | 较复杂 |
| 决策准确性 | 较低 | 较高 |
| 适用场景 | 业绩评价 | 投资决策 |

## 会计报酬率法 vs 内部收益率法

| 维度 | 会计报酬率法 | 内部收益率法 |
|------|-------------|-------------|
| 数据基础 | 会计利润 | 现金流量 |
| 时间价值 | 不考虑 | 考虑 |
| 多解问题 | 无 | 可能存在 |
| 再投资假设 | 无 | 假设按IRR再投资 |

## 会计报酬率法详细示例

### 项目数据

| 年份 | 税后经营净利润（万元） |
|------|------------------------|
| 1 | 1800 |
| 2 | 3240 |
| 3 | 2800 |
| 4 | 2200 |
| 5 | 1600 |

原始投资额 = 20000万元
投资净残值 = 2000万元

### 计算过程

#### 步骤1：计算年平均税后经营净利润
```
年平均税后经营净利润 = (1800 + 3240 + 2800 + 2200 + 1600) ÷ 5
                         = 11640 ÷ 5
                         = 2328万元
```

#### 步骤2：按方式一计算（原始投资额）
```
会计报酬率 = (2328 / 20000) × 100% = 11.64%
```

#### 步骤3：按方式二计算（平均资本占用）
```
平均资本占用 = (20000 + 2000) ÷ 2 = 11000万元
会计报酬率 = (2328 / 11000) × 100% = 21.16%
```

### 结果分析

- 方式一结果：11.64%
- 方式二结果：21.16%
- 差异原因：方式二考虑了净残值，分母更小，结果更高

## 方法选择建议

### 何时使用方式一（原始投资额）
- 项目净残值很小或为零
- 强调初始投资效率
- 与其他使用原始投资额的方法比较

### 何时使用方式二（平均资本占用）
- 项目净残值较大
- 强调平均资本使用效率
- 更符合经济实质

## 与其他指标结合使用

### 推荐组合

1. **初步筛选**：会计报酬率法
2. **精确评估**：净现值法
3. **风险分析**：敏感性分析
4. **业绩评价**：会计报酬率法

### 决策流程

1. 计算会计报酬率，初步判断项目可行性
2. 计算净现值，精确评估项目价值
3. 进行敏感性分析，评估项目风险
4. 综合判断，做出投资决策
5. 项目实施后，使用会计报酬率进行业绩评价
