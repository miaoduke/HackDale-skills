# 资本市场理论

## 适用场景
- 判断资本市场效率层级
- 分析信息反映程度
- 处理通货膨胀对利率的影响
- 选择名义或实际无风险利率

## 核心内容

### 1. 资本市场效率程度三级分类

**信息类型分类：**
- **历史信息：** 证券价格、交易量等历史交易信息
- **公开信息：** 财务报表、附表、政府公布信息等
- **内部信息：** 未发布的内幕信息

**效率程度判定：**

| 效率层级 | 反映信息范围 | 特征 |
|:---|:---|:---|
| 弱式有效 | 仅历史信息 | 最低程度的有效市场 |
| 半强式有效 | 历史信息 + 公开信息 | 股价反映所有公开信息 |
| 强式有效 | 历史信息 + 公开信息 + 内部信息 | 最高程度的有效市场 |

**层级关系：**
- 强式有效包含半强式有效
- 半强式有效包含弱式有效
- 信息类别决定市场效率层级

### 2. 名义利率与实际利率换算

**基本换算公式：**
```
1 + r_RF = (1 + r*) × (1 + 通货膨胀率)
```
其中：
- r_RF：名义无风险利率
- r*：真实无风险利率（实际利率）

**现金流量定义：**
- **实际现金流量：** 基于预算年度价格水平，消除通货膨胀影响
- **名义现金流量：** 包含通货膨胀影响

**现金流量换算公式：**
```
名义现金流量 = 实际现金流量 × (1 + 通货膨胀率)^n
```
其中n为相对于基期的期数

**核心匹配原则（必须遵守）：**
- 含有通货膨胀的现金流量 → 使用名义利率折现
- 实际的现金流量 → 使用实际利率折现

**政府债券特性：**
- 政府债券未来现金流按含有通货膨胀的货币支付
- 据此计算的到期收益率是名义利率

## 决策要点
- 市场效率分类基于信息反映程度，不涉及市场摩擦或交易成本
- 不同有效程度的市场吸纳的信息类别不同
- 必须保持现金流类型与折现率类型的一致性
- 名义现金流配名义利率，实际现金流配实际利率
- 不适用于恶性通货膨胀环境
