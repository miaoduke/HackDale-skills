# 责任会计详细参考

## 责任中心类型

### 成本中心
- 只对成本负责的责任中心
- 不形成或不考核收入
- 适用于生产车间、职能部门

### 利润中心
- 既对成本负责，又对收入和利润负责的责任中心
- 适用于分公司、事业部

### 投资中心
- 既对成本、收入、利润负责，又对投资效果负责的责任中心
- 适用于子公司、事业部

## 责任报告

### 成本中心责任报告
- 可控成本实际数
- 可控成本预算数
- 差异及分析

### 利润中心责任报告
- 收入实际数与预算数
- 成本实际数与预算数
- 利润实际数与预算数
- 差异及分析

### 投资中心责任报告
- 投资报酬率
- 剩余收益
- 差异及分析

## 投资报酬率计算

```
投资报酬率 = 营业利润 / 营业资产
```

### 分解公式
```
投资报酬率 = 销售利润率 × 资产周转率
```

## 剩余收益计算

```
剩余收益 = 营业利润 - (营业资产 × 最低报酬率)
```

### 优点
- 可以使业绩评价与企业目标协调一致
- 避免投资中心为追求局部利益而损害整体利益

## 内部转移价格

### 市场价格
- 以产品或劳务的市场价格作为内部转移价格
- 适用于存在外部市场的中间产品

### 协商价格
- 责任中心双方协商确定
- 适用于不存在外部市场的中间产品

### 双重价格
- 买卖双方分别采用不同的内部转移价格
- 适用于需要同时激励双方的情况

### 成本加成价格
- 以成本为基础加上一定利润
- 适用于需要补偿成本并获取利润的情况
