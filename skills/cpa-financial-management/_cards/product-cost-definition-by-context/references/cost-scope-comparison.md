# 产品成本口径对比分析

| 成本要素 | 对外财务报告 | 政府合同 | 定价/组合决策 |

## 详细说明

### 1. 对外财务报告成本口径

**目的**：存货计价与损益计算

**包含内容**：
```
产品成本 = 直接材料 + 直接人工 + 制造费用
```

**会计准则要求**：
- 符合GAAP/IFRS要求
- 成本与收入配比原则
- 存货可变现净值考虑

**示例**：
- 某产品生产成本：直接材料100元 + 直接人工50元 + 制造费用30元 = 180元
- 存货计价：180元/件

### 2. 政府合同成本口径

**目的**：合同报价与成本补偿

**包含内容**：
```
产品成本 = 部分研发成本 + 全部设计成本 + 全部生产成本
```

**合同类型**：
- 成本加成合同
- 成本分担合同

**示例**：
- 研发成本（可计入）：200,000元
- 设计成本：150,000元
- 生产成本（10,000件）：1,800,000元
- 合同总成本：2,150,000元
- 报价（加成10%）：2,365,000元

### 3. 定价/组合决策成本口径

**目的**：战略定价与产品组合优化

**包含内容**：
```
产品成本 = 研发 + 设计 + 生产 + 营销 + 配送 + 客服
```

**全生命周期成本视角**：
- 考虑产品从概念到退出的全部成本
- 支持长期盈利能力分析

**示例**：
- 研发成本（分摊）：20元/件
- 设计成本（分摊）：15元/件
- 生产成本：180元/件
- 营销成本：30元/件
- 配送成本：10元/件
- 客服成本：5元/件
- 全价值链成本：260元/件

## 决策应用

### 定价决策
- 使用全价值链成本确定最低价格
- 考虑目标利润率
- 分析竞争对手定价

### 产品组合决策
- 比较各产品的全价值链成本
- 识别高利润产品
- 优化资源配置

### 政府合同投标
- 按合同要求确定成本口径
- 确保成本可追溯
- 符合合规要求

### 财务报告
- 使用制造成本口径
- 符合会计准则
- 确保财务报表准确性
