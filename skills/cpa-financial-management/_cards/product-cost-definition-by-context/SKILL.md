# 基于决策背景的产品成本定义

## 使用场景
- 进行涉及成本的管理决策
- 需要明确产品成本核算范围
- 不同决策目的对应不同成本口径
- 价值链成本分析

## 价值链构成

### 价值链环节
价值链包括以下六个环节：
1. 研究与开发（R&D）
2. 设计
3. 生产
4. 营销
5. 配送
6. 客户服务

### 战略选择
管理者应结合自己的资源禀赋优势，选择某一个或某几个价值链环节来获得竞争优势。

## 根据决策背景确定成本口径

### 场景A：对外财务报告目的

**产品成本定义**：产品制造成本（即价值链中的生产成本）

**包含环节**：
- 直接材料
- 直接人工
- 制造费用

**用途**：按其进行存货计价与损益计算

**排除项**：研发、设计、营销、配送、客服成本

### 场景B：涉及政府合同

**产品成本定义**：部分研发成本 + 全部设计与生产成本

**包含环节**：
- 部分研发成本
- 全部设计成本
- 全部生产成本

**排除项**：
- 营销成本
- 配送成本
- 客户服务成本

**计价方式**：通常按照产品成本加成计价

### 场景C：涉及产品定价或者产品组合调整决策

**产品成本定义**：整个价值链的成本

**包含环节**：
- 研究与开发
- 设计
- 生产
- 营销
- 配送
- 客户服务

**用途**：
- 产品定价决策
- 产品组合优化
- 盈利能力分析

## 执行决策步骤

1. **明确决策问题类型**：识别当前决策属于哪种场景
2. **确定成本口径**：根据决策类型选择相应的成本定义
3. **收集成本信息**：按确定的口径收集相关成本数据
4. **预测未来方案**：预测不同行动方案的成本和收益
5. **选择最优方案**：选择成本效益最优的方案执行

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 决策背景 | 字符串 | 对外报告、政府合同或定价/组合决策 |
| 价值链环节 | 列表 | 研发、设计、生产、营销、配送、客服 |
| 成本口径 | 公式 | 根据背景包含不同环节的成本总和 |

## 约束条件
- 不同决策目的对应不同的成本范围，不可混用
- 必须明确决策问题类型
- 必须识别价值链环节

## 输出结果
```
输出特定口径下的产品成本数据，用于定价、存货计价或合同报价
```
