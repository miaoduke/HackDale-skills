# 应收账款账龄分析详细参考

## 完整分析表示例

以应收账款总额20万元为例：

| 应收账款账龄 | 账户数量（个） | 金额（万元） | 百分率（%） |
|------------|------------|-----------|-----------|
| 信用期内 | - | 8 | 40 |
| 超过信用期1~20天 | - | 4 | 20 |
| 超过信用期21~40天 | - | 2 | 10 |
| 超过信用期41~60天 | - | 2 | 10 |
| 超过信用期61~80天 | - | 2 | 10 |
| 超过信用期81~100天 | - | 1 | 5 |
| 超过信用期100天以上 | - | 1 | 5 |
| **合计** | - | **20** | **100** |

## 风险结构解读

**逾期结构分析**：
- 逾期总额：12万元（60%）
- 其中：短期逾期4万元（20%）、中期逾期7万元（35%）、长期逾期1万元（5%）

**关键风险指标**：
- 逾期率 = 逾期金额 / 应收账款总额 × 100%
- 长期逾期率 = 100天以上逾期金额 / 应收账款总额 × 100%
- 坏账风险敞口 = 长期逾期金额 + 中期逾期金额 × 风险系数

## 账龄与回收可能性对应关系

| 账龄 | 预计回收可能性 | 建议计提比例参考 |
|-----|-----------|------------|
| 信用期内 | 95%~100% | 0%~1% |
| 1~30天逾期 | 85%~95% | 5%~10% |
| 31~60天逾期 | 70%~85% | 10%~20% |
| 61~90天逾期 | 50%~70% | 20%~50% |
| 91~180天逾期 | 30%~50% | 50%~80% |
| 180天以上 | 0%~30% | 80%~100% |

> 注：具体计提比例应根据企业历史回收数据、客户信用评级、行业特点等因素确定。

## 与预期信用损失模型的结合

根据《企业会计准则第22号》，应收账款减值应采用预期信用损失模型：

1. **简化方法**：始终按照整个存续期内预期信用损失的金额计量损失准备
2. **账龄组合法**：以账龄为基础评估预期信用损失
3. **前瞻性调整**：考虑宏观经济因素对未来回收率的影响

## 监控频率建议

| 客户类型 | 建议监控频率 |
|---------|---------|
| 战略大客户 | 每周 |
| 一般赊销客户 | 每月 |
| 小额零散客户 | 每季度 |
| 已逾期客户 | 实时跟踪 |

## 系统实现要点

- 确保应收账款明细数据包含：客户编码、发票日期、到期日、金额、信用额度
- 设置自动预警：到期前3天提醒、逾期当日预警、逾期30天升级预警
- 账龄分析表应支持按客户、按区域、按业务线等多维度汇总
