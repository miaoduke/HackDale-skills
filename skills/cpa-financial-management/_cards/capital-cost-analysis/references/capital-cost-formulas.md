# 资本成本计算公式

## 加权平均资本成本（WACC）
```
WACC = Wd × Kd × (1 - T) + We × Ke
```

其中：
- Wd：债务资本权重
- Kd：债务资本成本（税前）
- T：企业所得税税率
- We：权益资本权重
- Ke：权益资本成本

## 债务资本成本
```
Kd = 年利息 × (1 - T) / 筹资净额
```

## 权益资本成本（CAPM模型）
```
Ke = Rf + β × (Rm - Rf)
```

其中：
- Rf：无风险利率
- β：系统性风险系数
- Rm：市场预期收益率
- (Rm - Rf)：市场风险溢价

## 股利增长模型
```
Ke = D1 / P0 + g
```

其中：
- D1：预期下一年股利
- P0：当前股价
- g：股利增长率
