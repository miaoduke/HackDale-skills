# 资本成本分析

## 适用场景
- 评估公司融资成本
- 进行投资决策分析
- 理解投资者与筹资者关系
- 分析股价波动原因
- 评估项目可行性

## 基本定义

### 核心概念
资本成本是指运用资金投资特定项目的机会成本。

### 性质特征
- **不是实际支付的成本**，而是一种"失去的收益"
- 将资本用于本项目投资所放弃的其他所有等风险投资机会的最高收益
- 别名：投资项目的取舍率、最低可接受的报酬率

## 资本成本的两个维度

### 筹资活动相关
- 公司募集和使用资金的成本
- 即筹资的成本

### 投资活动相关
- 投资的必要报酬率
- 项目必须达到的最低回报率

## 资本成本分类

### 公司资本成本
- 投资者针对整个公司要求的报酬率
- 投资者对于企业全部资产要求的报酬率

### 项目资本成本
- 公司投资于资本支出项目所要求的报酬率
- 基于项目特定风险的必要报酬率

## 资本成本的性质

### 性质一：公司取得资本使用权的代价

**视角转换：**
- 从投资者角度（评价证券报酬和风险）
- 转换为筹资者（公司）角度

**基本假设：**
- 不考虑所得税影响
- 不考虑交易费用影响

**对应关系：**
```
投资者从证券上取得的报酬 = 证券发行公司的成本
债权投资者的收益 = 筹资公司的债务资本成本
权益投资者的收益 = 筹资公司的股权资本成本
```

**核心逻辑：**
- 一方的所得就是另一方所失
- 一方的收益就是另一方的成本
- **投资者的税前必要报酬率 = 筹资者的税前资本成本**

### 性质二：公司投资者的必要报酬率

**定义：**
- 公司资本成本是公司投资者的必要报酬率
- 是维持公司股价不变的报酬率

**股价影响机制：**
```
IF 公司投资报酬率 > 投资者要求 THEN
  吸引新投资者购买股票 → 股价上升 → 现有股东财富增加

IF 公司投资报酬率 < 投资者要求 THEN
  股东出售股票 → 股价下跌 → 股东财富减少
```

## 决定因素：机会成本

### 基本逻辑
- 资本成本取决于投资者的必要报酬率
- 必要报酬率由其他投资机会的报酬率（机会成本）决定

### 案例说明

**银行贷款案例：**
```
银行收取的利率 = 银行投资的要求报酬率 = 银行贷款的机会成本
```
因为资金贷给别人也能得到此回报。

**股东投资案例：**
```
股票的必要报酬率 = 股东不撤资的机会成本
```
预期回报率必须足够高，防止资金转移到其他投资机会。

### 市场联动性
- 如果市场上其他投资机会的报酬率升高
- 公司的资本成本也会上升

## 资本成本的重要性

### 筹资决策基础
- 公司要达到股东财富最大化，必须使所有投入成本（包括资本成本）最小化
- 正确估计和合理降低资本成本是筹资决策的基础

### 投资决策基础
- 为了增加股东财富，公司只能投资于投资报酬率高于资本成本率的项目
- 正确估计项目的资本成本是投资决策的基础

## 分析流程

1. **确定分析目的**
   - 筹资决策：计算公司整体资本成本
   - 投资决策：计算项目特定资本成本

2. **识别资本来源**
   - 债务资本
   - 权益资本

3. **计算各要素成本**
   - 债务资本成本
   - 权益资本成本

4. **加权平均**
   - 按资本结构权重计算加权平均资本成本（WACC）

5. **应用决策**
   - 筹资：选择成本最低的融资方案
   - 投资：选择回报率高于资本成本的项目
