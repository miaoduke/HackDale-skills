# 市净率估值模型应用

## 适用场景
需要评估市场对公司净资产质量的评价，或需要计算股票估值指标时，应用市净率计算规则。

## 基本定义与公式

### 市净率（P/B Ratio）
- **定义**：普通股每股市价与每股净资产的比率
- **经济含义**：反映普通股股东愿意为每1元净资产支付的价格，说明市场对公司净资产质量的评价
- **公式**：市净率 = 每股市价 ÷ 每股净资产

### 每股净资产（每股账面价值）
- **定义**：普通股股东权益与发行在外普通股股数的比率
- **经济含义**：表示每股普通股享有的净资产
- **公式**：每股净资产 = 普通股股东权益 ÷ 发行在外普通股股数

## 存在优先股时的特殊处理

对于既有优先股又有普通股的公司，通常只为普通股计算每股净资产：

### 第一步：计算普通股权益
```
普通股权益 = 股东权益总额 − 优先股权益
优先股权益 = 优先股的清算价值 + 全部拖欠的股息
```

**关键说明**：优先股权益必须完全扣除，包括：
- 优先股的清算价值（每股清算价值 × 优先股股数）
- 全部累积拖欠的股息（每股拖欠股息 × 优先股股数）

### 第二步：计算普通股每股净资产
```
普通股每股净资产 = 普通股权益 ÷ 发行在外普通股股数
```

## 股数选择的关键规则

**重要约束**：在计算市净率和每股净资产时：
- **必须使用**：资产负债表日发行在外普通股股数（时点数）
- **禁止使用**：当期发行在外普通股加权平均股数

**原因**：每股净资产的分子（普通股股东权益）为时点数，根据配比原则，分母也应选取同一时点数，确保分子分母口径一致。

## 市净率估值模型的适用性判断

### 模型优点
1. **适用范围广**：净收益为负值的企业不能用市盈率进行估值，而市净率极少为负值
2. **数据易获取**：净资产账面价值的数据容易取得，并且容易理解
3. **数据稳定性高**：净资产账面价值比净收益稳定，也不像净收益那样经常被人为操纵
4. **价值反映能力**：如果会计准则合理并且各企业会计政策一致，净资产的变化可以反映企业价值的变化

### 模型局限性
1. **会计政策差异风险**：净资产账面价值受会计政策选择的影响，如果各企业执行不同的会计准则或采用不同的会计政策，市净率将会失去可比性
2. **轻资产企业不适用**：固定资产很少的服务性企业和高科技企业，净资产与企业价值的关系不大，市净率比较也就没有什么实际意义
3. **极端值失效**：少数企业的净资产是0或负值，则市净率没有意义，无法用于比较

### 适用性判断决策流程

**步骤1**：检查目标企业净资产是否为正值
- 若为0或负值 → 市净率无意义，无法使用，终止
- 若为正值 → 进入步骤2

**步骤2**：评估企业资产结构特征
- 若为固定资产很少的服务性企业或高科技企业 → 净资产与企业价值关系不大，市净率无实际意义，不建议使用
- 若为拥有大量资产的企业（如汽车制造业） → 进入步骤3

**步骤3**：检查会计政策可比性
- 若各企业执行不同会计准则或会计政策 → 市净率失去可比性，需谨慎使用或调整
- 若会计准则合理且各企业会计政策一致 → 适合使用市净率估值模型

## 估值计算公式
```
目标企业每股价值 = 目标企业每股净资产 × 可比公司平均市净率
```

## 结果解读

| 市净率 | 含义 |
|--------|------|
| > 1 | 市场愿意溢价购买公司净资产，反映市场对公司净资产质量或未来盈利能力的乐观评价 |
| = 1 | 市场按净资产平价交易 |
| < 1 | 市场折价交易，可能反映公司资产质量差、盈利能力低或存在破产风险 |
