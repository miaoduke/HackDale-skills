# 零增长股票估值

## 使用场景
当股票未来股利保持不变，形成永续年金时使用此技能。

## 核心公式
```
V₀ = D ÷ rₛ
```

- V₀：股票当前内在价值（零时点价值）
- D：每年固定不变的现金股利（永续年金金额）
- rₛ：等风险投资的必要报酬率（折现率）

## 公式原理
由于未来股利不变，其支付过程是一个永续年金，因此股票价值等于永续年金的现值。

```
永续年金现值公式：PV = A ÷ i
此处：A = D，i = rₛ
```

## 计算步骤

### 第一步：确定参数
- D：每年固定股利
- rₛ：等风险投资的必要报酬率

### 第二步：计算内在价值
```
V₀ = D ÷ rₛ
```

### 第三步：与市价比较
- 若市价 < V₀：股票被低估，可考虑买入
- 若市价 > V₀：股票被高估，可考虑卖出

### 第四步：反算期望报酬率（可选）
```
期望报酬率 = D ÷ 市价 × 100%
```
- 若期望报酬率 > 必要报酬率：投资价值高
- 若期望报酬率 < 必要报酬率：投资价值低

## 关键要点

1. **适用条件：** 仅适用于股利零增长的情况
2. **永续假设：** 假设公司持续经营、股利永续支付
3. **市价波动：** 市场上股价可能高于或低于内在价值
4. **报酬率关系：** 市价低于股票价值时，期望报酬率高于必要报酬率
