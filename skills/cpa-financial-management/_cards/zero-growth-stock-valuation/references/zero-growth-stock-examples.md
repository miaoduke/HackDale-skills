# 零增长股票估值示例

## 例3-23：基础计算

### 已知条件
- 上年股利：每股2元
- 预计未来保持该水平不变（每年现金股利D=2元）
- 等风险投资必要报酬率rₛ=16%

### 计算过程
```
V₀ = D ÷ rₛ
V₀ = 2 ÷ 16%
V₀ = 12.5元
```

### 经济含义
该股票每年给投资者带来2元的收益，在必要报酬率为16%的条件下，它相当于12.5元资本的收益，所以其价值是12.5元。

## 市价与价值关系分析

### 情景一：市价低于内在价值

**已知条件：**
- 股票内在价值：12.5元
- 市场价格：12元
- 每年固定股利：2元

**投资决策：**
```
市价12元 < 内在价值12.5元 → 股票被低估 → 考虑买入
```

**期望报酬率计算：**
```
期望报酬率 = D ÷ 市价 × 100%
期望报酬率 = 2 ÷ 12 × 100% = 16.67%
```

**结论：**
- 期望报酬率16.67% > 必要报酬率16%
- 投资价值高

### 情景二：市价高于内在价值

**已知条件：**
- 股票内在价值：12.5元
- 市场价格：15元
- 每年固定股利：2元

**投资决策：**
```
市价15元 > 内在价值12.5元 → 股票被高估 → 考虑卖出
```

**期望报酬率计算：**
```
期望报酬率 = 2 ÷ 15 × 100% = 13.33%
```

**结论：**
- 期望报酬率13.33% < 必要报酬率16%
- 投资价值低

## 敏感性分析

### 必要报酬率变动对价值的影响

| 必要报酬率 | 内在价值 | 变动 |
|-----------|---------|------|
| 12% | 16.67元 | +33.36% |
| 14% | 14.29元 | +14.32% |
| 16% | 12.50元 | 基准 |
| 18% | 11.11元 | -11.12% |
| 20% | 10.00元 | -20.00% |

**结论：** 必要报酬率越高，股票内在价值越低。

### 股利变动对价值的影响

| 每年股利 | 内在价值 | 变动 |
|---------|---------|------|
| 1.6元 | 10.00元 | -20.00% |
| 1.8元 | 11.25元 | -10.00% |
| 2.0元 | 12.50元 | 基准 |
| 2.2元 | 13.75元 | +10.00% |
| 2.4元 | 15.00元 | +20.00% |

**结论：** 股利越高，股票内在价值越高。

## 与其他估值模型对比

| 模型类型 | 适用条件 | 公式 |
|---------|---------|------|
| 零增长模型 | 股利不变 | V₀ = D ÷ rₛ |
| 固定增长模型 | 股利固定增长 | V₀ = D₁ ÷ (rₛ - g) |
| 非固定增长模型 | 股利不规则增长 | 分段计算现值 |
