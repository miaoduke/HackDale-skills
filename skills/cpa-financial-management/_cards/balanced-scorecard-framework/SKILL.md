# 平衡计分卡框架

## 何时使用

- 需要全面了解企业经营状况
- 将业绩评价与企业发展战略联系起来
- 构建整合财务与非财务指标的绩效体系
- 企业高管需要迅速掌握经营全貌

## 核心定义

平衡计分卡是一套指标体系，通过将**"财务指标"**与**"非财务指标"**相结合，将企业的**"业绩评价"**同**"企业发展战略"**联系起来。

## 设计目的

- 使企业高管能迅速且全面了解企业经营状况
- 表达企业发展战略所必须达到的目标
- 把任务和决策转化成目标和指标

## 来源基础

平衡计分卡的目标和指标必须来源于企业的**"愿景"**和**"战略"**。

## 四维度框架

### 维度一：财务维度

| 项目 | 内容 |
|------|------|
| 核心问题 | 股东如何看待我们？ |
| 目的 | 表明企业的努力是否最终对企业的经济收益产生了积极的作用 |
| 逻辑依据 | 现代企业财务管理目标是企业价值最大化，离不开相关财务指标 |
| 常用指标 | 投资报酬率、权益净利率、经济增加值、息税前利润、自由现金流量、资产负债率、总资产周转率 |

### 维度二：顾客维度

| 项目 | 内容 |
|------|------|
| 核心问题 | 顾客如何看待我们？ |
| 逻辑依据 | 顾客是企业之本，是现代企业的利润来源，顾客感受理应成为企业关注的焦点 |
| 关注点 | 从"时间"、"质量"、"服务效率"以及"成本"等方面了解市场份额、顾客需求和顾客满意程度 |
| 常用指标 | 市场份额、客户满意度、客户获得率、客户保持率、客户获利率、战略客户数量 |

### 维度三：内部业务流程

框架组成部分，关注企业运营效率和流程优化。

### 维度四：学习与成长

框架组成部分，关注员工能力、信息系统和企业文化等长期发展基础。

## 实施要点

- 四个维度相互关联，形成因果链条
- 指标选择需体现战略重点，避免面面俱到
- 财务维度是最终目标，其他维度是驱动因素
- 需定期回顾和调整指标体系
