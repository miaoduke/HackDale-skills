# 责任成本会计示例

| 成本项目 | 直接/间接 | 变动/固定 | 可控性 | 责任归属 |

| 直接材料 | 直接 | 变动 | 可控 | 生产车间 |
| 直接人工 | 直接 | 变动 | 可控 | 生产车间 |
| 工长工资 | 直接 | 固定 | 不可控 | 上级管理部门 |
| 机物料消耗 | 间接 | 变动 | 可控 | 生产车间 |
| 设备折旧 | 间接 | 固定 | 不可控 | 上级管理部门 |

## 三种成本计算方法对比示例

### 场景：某产品成本数据

**已知条件**
- 直接材料：100元/件
- 直接人工：50元/件
- 变动制造费用：30元/件
- 固定制造费用：20元/件（按产量分摊）
- 产量：1,000件

### 三种方法计算结果

**1. 产品制造成本法**
```
单位成本 = 100 + 50 + 30 + 20 = 200元/件
总成本 = 200 × 1,000 = 200,000元
```

**2. 产品变动成本法**
```
单位成本 = 100 + 50 + 30 = 180元/件
总成本 = 180 × 1,000 = 180,000元
```

**3. 责任成本法**
假设生产车间可控成本为直接材料、直接人工和部分变动制造费用（25元/件）：
```
生产车间单位责任成本 = 100 + 50 + 25 = 175元/件
生产车间总责任成本 = 175 × 1,000 = 175,000元
```

### 应用场景对比

| 方法 | 适用场景 | 决策用途 |
|------|---------|---------|
| 制造成本法 | 外部财务报告、存货计价 | 产品定价、盈利能力分析 |
| 变动成本法 | 内部经营决策、本量利分析 | 短期决策、特殊订单定价 |
| 责任成本法 | 绩效评价、成本控制 | 责任中心考核、激励机制 |
