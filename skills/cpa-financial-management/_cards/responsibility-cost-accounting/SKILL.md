# 责任成本会计

## 使用场景
当企业需要：
- 建立责任会计体系
- 评价成本控制业绩
- 区分可控成本与不可控成本
- 对比不同成本计算方法

## 责任成本定义

**责任成本**：以责任中心为对象，归集各责任中心的"可控成本"。

## 责任成本与其他成本的关系

### 责任成本与直接成本的关系（基于可追溯性）

**直接成本**：可直接追溯到个别产品或部门的成本
**间接成本**：由几个产品或部门共同引起的成本

**可控性判断规则**：
- 对生产基层单位，大多数直接材料和直接人工是可控的
- 但也有部分不可控（例如：工长的工资是直接成本，但工长无法改变，故不可控）
- 最基层单位无法控制大多数间接成本，但有一部分是可控的（例如：机物料消耗虽间接计入产品，但操作工可控制）

### 责任成本与变动成本、制造成本的关系（基于成本性态）

**变动成本**：随产量正比例变动的成本
**固定成本**：一定范围内不随产量变动而基本保持不变的成本

**可控性判断规则**：
- 大多数变动成本是可控的，但也有例外
  - 例如：按产量和实际成本分摊的工艺装备费是变动成本，但车间无法控制
  - 原因：产量是上级指令，实际成本由辅助车间控制
- 固定成本不等同于不可控成本
  - 与产量无关的广告费、科研开发费、教育培训费等"酌量性固定成本"都是可控的

## 三种成本计算方法的区别

### 区别一：成本计算目的

| 方法 | 目的 |
|------|------|
| 制造成本 | 确定产品存货成本和销货成本 |
| 变动成本 | 为了经营决策 |
| 责任成本 | 为了评价成本控制业绩 |

### 区别二：成本对象

| 方法 | 成本对象 |
|------|---------|
| 变动成本 | 产品 |
| 制造成本 | 产品 |
| 责任成本 | 责任中心 |

### 区别三：成本范围

| 方法 | 成本范围 |
|------|---------|
| 产品制造成本 | 全部制造成本（直接材料、直接人工、全部制造费用） |
| 产品变动成本 | 直接材料、直接人工、变动制造费用 |
| 责任成本 | 各责任中心的"可控成本" |

### 区别四：共同费用分摊原则

| 方法 | 分摊原则 |
|------|---------|
| 制造成本 | 按"受益原则"，谁受益谁承担，分摊全部制造费用 |
| 变动成本 | 只分摊变动制造费用，不分摊固定制造费用 |
| 责任成本 | 按"可控原则"，谁能控制谁负责。不仅分配可控的变动间接费用，还要分配可控的固定间接费用 |

## 责任成本法的定位

- 介于完全成本法和变动成本法之间
- 别称："局部吸收成本法"或"变动成本和吸收成本法结合的成本方法"

## 可控性判断关键点

### 基本原则
- 成本是否可控取决于责任中心的管理权限
- 同一成本对不同责任中心可能具有不同的可控性

### 判断流程
1. 确定责任中心的管理权限范围
2. 分析成本项目是否在该权限范围内
3. 判断责任中心能否影响成本的发生金额
4. 综合考虑成本性态和可追溯性

### 典型示例

**工长工资**：
- 直接成本：是（可追溯到工长所在部门）
- 可控成本：否（工长无法改变自己的工资水平）

**机物料消耗**：
- 间接成本：是（需分配计入产品）
- 可控成本：是（操作工可控制消耗量）

**工艺装备费**：
- 变动成本：是（随产量变动）
- 可控成本：否（产量由上级决定，成本由辅助车间控制）

**广告费**：
- 固定成本：是（不随产量变动）
- 可控成本：是（管理层可控制广告投入）
