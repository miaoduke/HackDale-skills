# 经济增加值计算示例

## 税后净营业利润计算示例（例20-1）

**已知条件：**
- 净利润 = 40亿元
- 研发费用 = 20亿元
- 当期无确认为无形资产的开支支出
- 费用化利息支出 = 12亿元
- 企业所得税税率 = 25%

**计算步骤：**
```
第一步：确定净利润 = 40亿元

第二步：计算研究开发费用调整项
= 研发费用 + 当期确认为无形资产的开支支出
= 20 + 0 = 20亿元

第三步：确定利息支出 = 12亿元

第四步：计算调整项的税后金额
= (利息支出 + 研究开发费用调整项) × (1 - 25%)
= (12 + 20) × 75%
= 32 × 0.75
= 24亿元

第五步：计算税后净营业利润
= 40 + 24 = 64亿元
```

## 经济增加值最终计算示例（例20-1）

**已知条件：**
- 税后净营业利润 = 64亿元
- 调整后资本 = 1300亿元
- 平均资本成本率 = 4.07%

**计算步骤：**
```
第一步：确认各项数据
- 税后净营业利润 = 64亿元
- 调整后资本 = 1300亿元
- 平均资本成本率 = 4.07%

第二步：计算资本成本
= 调整后资本 × 平均资本成本率
= 1300 × 4.07%
= 1300 × 0.0407
= 52.91亿元

第三步：计算经济增加值
= 64 - 52.91 = 11.09亿元
```

**结果解读：**
- EVA = 11.09亿元 > 0 → 甲公司20×0年为股东创造了11.09亿元的经济价值

**与会计利润的对比：**
- 会计净利润 = 40亿元
- 经济增加值 = 11.09亿元
- 差额 = 28.91亿元 → 这部分是会计利润但未覆盖的资本成本

## 剩余收益决策示例

**B部门示例：**
- 要求报酬率12%
- 原剩余收益 = 22,800元

**采纳投资方案：**
- 投资额100,000元，获利13,000元（报酬率13%）
- 新剩余收益 = 22,800 + (13,000 - 100,000×12%) = 22,800 + 1,000 = 23,800元
- 结论：采纳该方案增加剩余收益

**放弃减资方案：**
- 减少资产50,000元，获利6,500元（报酬率13%）
- 新剩余收益 = 22,800 - (6,500 - 50,000×12%) = 22,800 - 500 = 22,300元
- 结论：减少该资产降低剩余收益，应放弃减资

## EVA作为业绩考核指标的优势

1. 考虑了全部资本成本，防止盲目扩张
2. 与股东价值创造直接挂钩
3. 跨部门、跨期间可比
4. 鼓励管理层提高资本使用效率

## 剩余收益的局限性

1. **规模效应：** 作为绝对数指标，不便于不同规模的公司和部门比较。较大规模的公司或部门即使运行效率较低，也能获得较大的剩余收益。
2. **数据质量：** 计算依赖会计数据（净利润、投资账面价值），若会计信息质量低劣，会导致评价结果失真。
