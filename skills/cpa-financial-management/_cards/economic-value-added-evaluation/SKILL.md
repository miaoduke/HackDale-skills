# 经济增加值(EVA)业绩评价

## 适用场景
- 评价投资中心部门业绩
- 进行部门投资/减资决策
- 计算企业经济增加值
- 评估企业价值创造能力
- 央企及上市公司业绩考核

## 核心概念

**税后净营业利润(NOPAT)：** 将会计净利润调整为税后净营业利润，还原企业真实的经营盈利能力
**调整后资本：** 投入资本，用于计算资本成本
**平均资本成本率：** 加权平均资本成本(WACC)
**经济增加值(EVA)：** 衡量企业创造的"经济利润"，扣除了全部资本成本
**剩余收益：** 部门税前经营利润减去部门占用的资本成本

## 计算方法

### 1. 税后净营业利润(NOPAT)计算

**公式：**
```
税后净营业利润 = 净利润 + (利息支出 + 研究开发费用调整项) × (1 - 25%)
```

**分步计算：**
1. 确定净利润（直接取自利润表）
2. 计算研究开发费用调整项 = 研发费用 + 当期确认为无形资产的开支支出
3. 确定利息支出（通常使用费用化利息支出）
4. 计算调整项的税后金额 = (利息支出 + 研究开发费用调整项) × (1 - 25%)
5. 计算税后净营业利润 = 净利润 + 调整项的税后金额

**调整目的：** 还原企业真实的经营盈利能力，消除会计政策和资本结构的影响。

### 2. 剩余收益计算

**公式：**
```
部门剩余收益 = 部门税前经营利润 - (部门平均净经营资产 × 要求的税前投资报酬率)
```

**决策判断逻辑：**
- 如果新项目的税前投资报酬率 > 部门要求的税前投资报酬率，采纳该方案将增加部门剩余收益
- 如果现有资产的税前投资报酬率 > 部门要求的税前投资报酬率，减少该资产将降低部门剩余收益

### 3. 经济增加值(EVA)最终计算

**公式：**
```
经济增加值 = 税后净营业利润 - 资本成本
经济增加值 = 税后净营业利润 - 调整后资本 × 平均资本成本率
```

**计算步骤：**
1. 确认税后净营业利润
2. 确认调整后资本
3. 确认平均资本成本率
4. 计算资本成本 = 调整后资本 × 平均资本成本率
5. 计算经济增加值 = 税后净营业利润 - 资本成本

**结果解读：**
- EVA > 0：企业为股东创造了价值
- EVA < 0：即使会计利润为正，企业实际上在损毁股东价值
- EVA = 0：企业刚好达到资本成本要求的回报水平

## 执行流程

### 场景一：计算部门剩余收益
1. 确定部门税前经营利润
2. 确定部门平均净经营资产
3. 确定部门要求的税前投资报酬率
4. 计算部门剩余收益
5. 根据剩余收益变化判断投资/减资决策

### 场景二：计算企业经济增加值
1. 计算税后净营业利润
2. 计算调整后资本
3. 计算平均资本成本率
4. 计算资本成本
5. 计算经济增加值
6. 解读结果，评估价值创造能力

## 关键变量
- **净利润：** 会计净利润
- **利息支出：** 费用化利息支出
- **研发费用：** 当期研发费用
- **当期确认为无形资产的开支支出：** 资本化研发支出
- **研究开发费用调整项：** 研发费用与资本化支出之和
- **所得税税率：** 固定为25%
- **部门税前经营利润：** 部门在扣除利息和所得税之前的经营利润
- **部门平均净经营资产：** 部门占用的平均净经营资产额
- **要求的税前投资报酬率：** 根据部门或资产风险调整的最低报酬率
- **调整后资本：** 投入资本
- **平均资本成本率：** WACC

## 输出结果
- 税后净营业利润金额
- 部门剩余收益金额
- 经济增加值金额
- 价值创造判断（创造价值/损毁价值）

## 约束条件
- 剩余收益不适用于不同规模部门间的直接横向比较
- 依赖高质量的会计数据（净利润、账面价值等）
- 研究开发费用调整项需按特定规则计算
- 利息支出通常指费用化利息
