# 资本结构详细分析

## 清算顺序示例

### 公司清算资产分配

假设公司清算资产价值1000万元，负债600万元，股东权益400万元。

**分配顺序：**
1. 债权人：600万元（优先受偿）
2. 股东：400万元（剩余索取）

### 资产不足清偿债务

假设公司清算资产价值500万元，负债600万元，股东权益-100万元。

**分配顺序：**
1. 债权人：500万元（优先受偿，但损失100万元）
2. 股东：0元（剩余索取权为负，一无所获）

## 收益分配示例

### 债权人收益

**债券信息：**
- 面值：1000元
- 票面利率：5%
- 每年利息：50元

**收益：**
- 无论公司盈利多少，每年固定获得50元利息
- 到期收回1000元本金

### 股东收益

**股票信息：**
- 每股面值：1元
- 公司盈利：每股0.5元
- 股利政策：股利支付率50%

**收益：**
- 每股股利：0.5 × 50% = 0.25元
- 若公司亏损：可能无股利
- 若公司盈利增长：股利可能增加

## 风险对比

| 风险类型 | 债权人 | 股东 |
|---------|-------|------|
| 收益风险 | 低（固定利息） | 高（股利不保证） |
| 本金风险 | 低（到期偿还） | 高（无到期日） |
| 清算风险 | 低（优先受偿） | 高（最后受偿） |
| 通货膨胀风险 | 高（固定收益贬值） | 低（收益可增长） |

## 资本结构理论

### MM理论（无税）
```
公司价值 = 资产价值（与资本结构无关）
WACC = 资产必要报酬率（与资本结构无关）
```

### MM理论（有税）
```
公司价值 = 无杠杆公司价值 + 税盾价值
税盾价值 = 负债 × 企业所得税税率
```

### 权衡理论
```
公司价值 = 无杠杆公司价值 + 税盾价值 - 财务困境成本
```

## 实务应用

### 债权人保护措施

1. **担保：** 抵押、质押、保证
2. **契约条款：** 限制性条款、保护性条款
3. **信用评级：** 评估违约风险

### 股东保护措施

1. **投票权：** 参与公司决策
2. **剩余索取权：** 享受公司成长
3. **有限责任：** 仅以出资额为限承担责任
