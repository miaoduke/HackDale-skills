# 成本性态分析

## 使用场景
- 需要理解成本如何随业务量变化时
- 进行本量利分析前需要分解成本时
- 预测不同业务量水平下的成本时
- 建立成本预算模型时

## 识别成本类型

### 固定成本
**判定标准：** 在相关范围内，成本总额不随业务量变动而变化

**典型示例：**
- 固定月工资
- 固定资产折旧费
- 取暖费、财产保险费
- 职工培训费、科研开发费、广告费

**关键特征：**
- 总额在相关范围内保持稳定
- 单位固定成本与业务量成反比
- 相关范围是前提条件

### 变动成本
**判定标准：** 在相关范围内，成本总额随业务量成正比例变动

**典型示例：**
- 直接材料成本
- 直接人工成本
- 外部加工费
- 销售佣金

**分类：**
1. **技术性变动成本（约束性）：** 由技术或设计关系决定，如汽车装配的发动机配件
2. **酌量性变动成本：** 由管理层决策决定，如按销售额百分比的销售佣金

### 非线性成本
**判定标准：** 成本随业务量增加但不成正比例

**类型：**
- 变化率递减：如自备水源成本
- 变化率递增：如违约金、罚金、累进计件工资

**处理方法：** 在相关范围内使用线性近似 y = a + bx

## 高低点法分解混合成本

### 执行步骤
1. **选取数据点：** 从历史资料中找出业务量最高点和最低点及其对应成本
2. **计算单位变动成本：**
   ```
   单位变动成本 = (最高点成本 - 最低点成本) / (最高点产量 - 最低点产量)
   ```
3. **计算固定成本：**
   ```
   固定成本 = 高点总成本 - 单位变动成本 × 高点产量
   或
   固定成本 = 低点总成本 - 单位变动成本 × 低点产量
   ```
4. **建立成本模型：** Y = a + bX

### 注意事项
- 确保高低点数据不是异常值
- 仅适用于成本与业务量呈线性关系的情况
- 该方法简单但忽略了其他数据点信息

## 相关范围概念

**定义：** 能够使成本性态保持稳定的特定业务量范围

**重要性：**
- 固定成本和变动成本的线性关系仅在相关范围内成立
- 超出相关范围，成本性态可能发生根本变化
- 非线性成本可在相关范围内进行线性近似
