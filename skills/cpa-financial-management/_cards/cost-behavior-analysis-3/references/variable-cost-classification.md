# 变动成本分类详解

## 技术性变动成本（约束性变动成本）

**定义：** 由技术或设计关系决定，与产量有明确的生产技术或产品结构设计关系

**特点：**
- 一旦产品设计确定，这类成本就难以改变
- 与产量存在严格的正比例关系

**示例：** 一部汽车必须装配：
- 一套发动机配件
- 一套传动系配件
- 一套制动系配件
- 一套转向系配件
- 一套行驶系配件

## 酌量性变动成本

**定义：** 单位成本发生额由经理人员决定，可通过管理决策行动改变

**特点：**
- 最佳合理支出难以精确计算
- 通常依靠经理人员综合判断
- 决策一经作出，支出额随业务量成正比例变动

**示例：**
- 按销售额一定百分比开支的销售佣金
- 技术转让费

**目的：** 提高竞争能力或改善企业形象
