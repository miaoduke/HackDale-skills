# 固定成本详细说明

## 相关范围的含义

相关范围是指能够使固定成本保持稳定的特定业务量范围。例如：
- 照明用电在业务量特定范围内不受影响，属于固定成本
- 如果业务量超出范围需要调增生产班次，照明用电也会变动

## 总额与单位成本的反向关系

**数学关系：** 单位固定成本 = 固定成本总额 / 业务量

**示例：**
- 固定成本总额：10,000元/月
- 产量1,000件时：单位固定成本 = 10元
- 产量2,000件时：单位固定成本 = 5元

## 稳定性的相对性

固定成本总额的稳定性是相对的：
- 对于变动的业务量来说该项成本是稳定的
- 但每月实际发生额可能仍有波动（如照明用电每月实际度数不同）
