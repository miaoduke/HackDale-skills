# 生产决策分析示例

## 出售或深加工决策示例

**已知数据**：
- 半成品直接出售单价：50元
- 深加工后出售单价：80元
- 加工数量：1,000件
- 单位追加变动成本：20元
- 专属固定成本：50,000元
- 机会成本（生产能力可转移）：75,000元

**计算过程**：

1. 计算相关收入（差量收入）：
```
相关收入 = (80 - 50) × 1,000 = 30,000元
```

2. 确定相关成本（差量成本）：
```
追加变动成本 = 20 × 1,000 = 20,000元
专属固定成本 = 50,000元
机会成本 = 75,000元
相关成本合计 = 20,000 + 50,000 + 75,000 = 145,000元
```

3. 计算差量利润：
```
差量利润 = 30,000 - 145,000 = -115,000元
```

4. 决策判定：
```
差量利润 < 0，选择"直接出售"方案
```

## 自制与外购存货决策示例

**已知数据**：
- 全年需求量D：3,600件
- 每日平均需求量d：10件
- 储存变动成本率：20%

**外购方案**：
- 单价：4元
- 一次订货成本：10元

**自制方案**：
- 单位成本：3元
- 每次生产准备成本：600元
- 每日产量P：50件

**计算过程**：

### 外购方案计算

1. 单位储存成本：
```
Kc = 4 × 20% = 0.8元
```

2. 经济订货量相关总成本：
```
TC(Q*) = √(2 × 10 × 3,600 × 0.8) = √57,600 = 240元
```

3. 外购总成本：
```
TC_purchase = 3,600 × 4 + 240 = 14,400 + 240 = 14,640元
```

### 自制方案计算

1. 单位储存成本：
```
Kc = 3 × 20% = 0.6元
```

2. 修正因子：
```
(1 - d/P) = (1 - 10/50) = 0.8
```

3. 经济生产批量相关总成本：
```
TC(Q*) = √[2 × 600 × 3,600 × 0.6 × 0.8] = √2,073,600 = 1,440元
```

4. 自制总成本：
```
TC_make = 3,600 × 3 + 1,440 = 10,800 + 1,440 = 12,240元
```

### 决策结论

```
12,240元 < 14,640元
自制总成本低于外购总成本，差额为2,400元
因此应选择自制方案
```
