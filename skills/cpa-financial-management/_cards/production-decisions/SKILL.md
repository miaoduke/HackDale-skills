# 生产决策分析

## 出售或深加工决策

### 适用条件

企业拥有半成品，需要在直接出售与进一步加工之间做出选择。

### 决策方法

应用差量分析法进行决策。

### 决策步骤

#### 步骤1：确定无关成本（沉没成本）

进一步深加工前的半成品所发生的所有成本（包括半成品的变动成本和分摊的固定成本）均为沉没成本。无论是否深加工，这些成本都已经发生且无法改变，因此在决策时不予考虑。

#### 步骤2：计算相关收入（差量收入）
```
相关收入 = (加工后出售单价 - 直接出售单价) × 加工数量
```
即加工后出售和直接出售的收入之差。

#### 步骤3：确定相关成本（差量成本）

仅包括进一步深加工所需的追加成本，具体包括：

**a. 追加变动成本**：
```
追加变动成本 = 单位追加变动成本 × 加工数量
```

**b. 专属固定成本**：
如果深加工需要追加专属设备或费用，应全额计入。

**c. 机会成本**：
如果用于深加工的生产能力可以转移（如用于对外承揽加工），则应将放弃的潜在收益作为机会成本计入。

#### 步骤4：计算差量利润
```
差量利润 = 相关收入 - 相关成本
```

#### 步骤5：决策判定

- **IF (差量利润 > 0)**：选择"进一步深加工"方案（因为能提高收益）
- **IF (差量利润 < 0)**：选择"直接出售"方案（因为深加工会减少利润）

### 特殊情况处理

- **生产能力无法转移**：相关成本中不包含机会成本，仅需考虑追加变动成本和专属固定成本
- **生产能力有限且可转移**：需按实际可加工数量计算，并将放弃的替代用途收益计入机会成本

## 自制与外购存货决策分析框架

### 适用条件

需要决定零件或产品应该自制还是外购，且两种方案的成本结构数据可获得。

### 决策逻辑

自制零件属于边送边用（陆续供应）情况，单位成本通常较低但每批投产的生产准备成本较高；外购零件属于瞬时补充（一次全部入库），单位成本可能较高但一次订货成本较低。决策标准是全面衡量各自的总成本（购置成本+订货/准备成本+储存成本），选择总成本较低的方案。

### 决策步骤

#### 步骤1：计算外购方案总成本（使用瞬时补充模型）

**确定单位储存变动成本**：
```
Kc_purchase = 外购单价 × 储存变动成本率
```

**计算经济订货量相关总成本**：
```
TC(Q*)_purchase = √(2 × K_purchase × D × Kc_purchase)
```
其中K_purchase为一次订货成本，D为全年需求量

**计算外购总成本**：
```
TC_purchase = D × 外购单价 + TC(Q*)_purchase
```

#### 步骤2：计算自制方案总成本（使用陆续供应和使用模型）

**确定单位储存变动成本**：
```
Kc_make = 自制单位成本 × 储存变动成本率
```

**计算经济生产批量相关总成本**：
```
TC(Q*)_make = √[2 × K_make × D × Kc_make × (1 - d/P)]
```
其中K_make为每次生产准备成本，P为每日产量，d为每日平均需求量

**计算自制总成本**：
```
TC_make = D × 自制单位成本 + TC(Q*)_make
```

#### 步骤3：决策规则

比较TC_make和TC_purchase：
- **IF (TC_make < TC_purchase)**：选择自制
- **IF (TC_make > TC_purchase)**：选择外购

### 关键假设

- 外购为瞬时补充（基本EOQ模型）
- 自制为陆续供应（边产边用）
- 不考虑质量差异、供应风险等定性因素，仅基于成本定量分析
