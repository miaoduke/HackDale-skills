# 销售百分比法预测外部融资需求

## 何时使用

- 需要预测企业未来资金需求量，特别是外部融资需求
- 经营资产和经营负债与营业收入存在稳定百分比关系
- 编制财务预算或融资计划
- 评估销售增长对资金需求的影响
- 进行融资可行性分析

## 核心假设

- 相关资产、负债与营业收入存在稳定的百分比关系
- 各项费用是营业收入的函数
- 销售百分比在预测期可以持续

## 工作流程

### 第一步：估计各项费用和利润留存额

1. 假设各项费用是营业收入的函数，据此估计费用和损失
2. 在费用估计基础上确定净利润
3. 计算利润留存额：
   ```
   利润留存额 = 净利润 × 利润留存率
   ```

### 第二步：确定经营资产和经营负债项目的销售百分比

**计算公式**：
```
各项目销售百分比 = 基期经营资产（或负债）÷ 基期营业收入
```

**数据来源选择**：
- 传统财务报表数据
- 经过调整的管理用财务报表数据（推荐，更方便合理）

**百分比确定方法**：
- 根据基期的数据确定
- 根据以前若干年度的平均数确定
- 根据预测数据确定

### 第三步：预测预计经营资产和经营负债

```
预测期某项目金额 = 预计营业收入 × 该项目销售百分比
```

计算：
1. 经营资产合计
2. 经营负债合计
3. 净经营资产 = 经营资产合计 - 经营负债合计

### 第四步：估计所需外部融资需求

**核心公式**：
```
外部融资需求 = 预计经营资产总量 
               - 已有的经营资产 
               - 自发增长的经营负债 
               - 可动用的金融资产 
               - 内部提供的利润留存额
```

或简化为：
```
外部融资需求 = 预计净经营资产 - 基期净经营资产 
               - 可动用的金融资产 
               - 利润留存额
```

## 快速计算法

若使用净经营资产销售百分比：
```
外部融资需求 = 营业收入增加额 × 净经营资产销售百分比
               - 可动用的金融资产
               - 利润留存额
```

其中：
```
净经营资产销售百分比 = 经营资产销售百分比 - 经营负债销售百分比
```

## 关键输出

- 外部融资需求金额（正值表示需要外部融资，负值或零表示无外部融资需求或资金盈余）
- 预计经营资产明细和合计
- 预计经营负债明细和合计
- 净经营资产预测数据

## 注意事项

- 区分经营项目与金融项目（建议使用管理用财务报表）
- 检查销售百分比的稳定性，异常变动需调整
- 考虑可动用金融资产的实际流动性
- 利润留存率需结合股利政策确定
