# 企业价值比较法

## 适用场景
- 企业需要优化资本结构
- 评估通过发行债券回购股票的融资方案
- 比较不同债务水平下的企业价值和资本成本
- 确定使企业价值最大化的最优债务水平

## 前置条件
- 企业当前EBIT（息税前利润）
- 当前股权账面价值
- 不同债务水平对应的债务税前资本成本rd和股票β系数
- 无风险利率rRF和市场平均收益率rm
- 企业所得税税率T

## 核心假设
- EBIT在各方案下保持不变
- 债务资金用于回购股票（调整资本结构）
- 债务价值等于账面价值

## 执行步骤

### 步骤一：确定基础数据
1. 确定当前资本结构（股权账面价值、长期债务、优先股）
2. 确定EBIT（假设永续不变）
3. 确定所得税税率T
4. 确定无风险利率rRF和市场平均收益率rm

### 步骤二：设定备选债务方案
1. 设定不同的长期债务规模B（如0、300、600、900、1200、1500万元）
2. 为每个债务水平确定对应的债务税前资本成本rd和股票β值

### 步骤三：计算各方案的权益资本成本rs
使用CAPM模型计算：
```
rs = rRF + β × (rm - rRF)
```

### 步骤四：计算各方案的股权价值S和企业价值V
1. 计算年利息：I = B × rd
2. 计算归属于普通股的净收益：(EBIT - I) × (1 - T)
3. 计算股权价值：S = [(EBIT - I) × (1 - T)] / rs
4. 计算企业价值：V = S + B

### 步骤五：计算各方案的加权平均资本成本WACC
```
rWACC = rd × (1 - T) × (B/V) + rs × (S/V)
```

### 步骤六：比较决策
1. 比较各方案的企业价值V，找出最大值
2. 验证该方案是否同时使WACC最小
3. 确定最优债务水平B*

### 步骤七：验证股东财富最大化
计算股东财富 = 股权价值S + 股票回购价值（债务金额B）
- 在最优资本结构下，股东财富 = S + B = V，达到最大化
- 确认此时股东财富大于初始状态

### 步骤八：最终决策
选择使企业价值最大、WACC最小的债务水平作为最佳资本结构。

## 决策标准
- **最优方案**：企业价值V最大，且WACC最小
- **验证标准**：股东财富在最优结构下达到最大化

## 输出结果
确定最佳债务水平B*，执行发行债券回购股票的方案，使资本结构调整为B*/V*的负债率，实现企业价值最大化和股东财富最大化。
