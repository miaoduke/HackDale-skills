# 企业价值比较法详细示例

## 示例背景
某企业当前为全权益结构：
- 股票账面价值：3000万元
- 无长期债务和优先股
- EBIT：每年600万元（假设永续不变）
- 所得税税率T：25%
- 无风险利率rRF：8%
- 市场平均收益率rm：12%

## 备选债务方案数据

| 债务B（万元） | 债务成本rd | 股票β |
|-------------|-----------|-------|
| 0           | -         | 1.20  |
| 300         | 8%        | 1.25  |
| 600         | 10%       | 1.40  |
| 900         | 12%       | 1.60  |
| 1200        | 15%       | 1.90  |
| 1500        | 18%       | 2.30  |

## 详细计算过程

### 方案B=600万元计算示例

**1. 计算权益资本成本rs**
```
β = 1.4
rs = 8% + 1.4 × (12% - 8%)
rs = 8% + 5.6% = 13.6%
```

**2. 计算年利息I**
```
I = 600 × 10% = 60万元
```

**3. 计算净收益**
```
净收益 = (600 - 60) × (1 - 25%)
净收益 = 540 × 0.75 = 405万元
```

**4. 计算股权价值S**
```
S = 405 / 13.6% = 2977.94万元
```

**5. 计算企业价值V**
```
V = 2977.94 + 600 = 3577.94万元
```

**6. 计算WACC**
```
债务权重 = 600 / 3577.94 = 16.77%
权益权重 = 2977.94 / 3577.94 = 83.23%

rWACC = 10% × (1 - 25%) × 16.77% + 13.6% × 83.23%
rWACC = 1.258% + 11.319% = 12.58%
```

## 各方案计算结果汇总

|-------|----|---|----|---|--------|-----|-----|------|

| 900 | 12% | 1.60 | 14.4% | 108 | 369 | 2562.50 | 3462.50 | 13.00% |
| 1200 | 15% | 1.90 | 15.6% | 180 | 315 | 2019.23 | 3219.23 | 13.98% |
| 1500 | 18% | 2.30 | 17.2% | 270 | 247.5 | 1438.95 | 2938.95 | 15.31% |

## 决策分析

### 企业价值V比较
- B=0时：V=3515.63万元
- B=300时：V=3623.08万元
- B=600时：V=3577.94万元
- B=900时：V=3462.50万元（开始下降）
- B=1200时：V=3219.23万元
- B=1500时：V=2938.95万元

**最大企业价值**：B=300万元时，V=3623.08万元

### WACC比较
- B=0时：WACC=12.80%
- B=300时：WACC=12.41%（最小）
- B=600时：WACC=12.58%
- B=900时：WACC=13.00%
- B=1200时：WACC=13.98%
- B=1500时：WACC=15.31%

**最小WACC**：B=300万元时，WACC=12.41%

### 股东财富验证

**初始状态（B=0）**：
- 股东财富 = S + B = 3515.63 + 0 = 3515.63万元

**最优状态（B=300）**：
- 股东财富 = S + B = 3323.08 + 300 = 3623.08万元
- 股东财富增加 = 3623.08 - 3515.63 = 107.45万元

## 最终决策

选择长期债务为**300万元**的资本结构作为最佳资本结构：
- 企业价值最大：3623.08万元
- 加权平均资本成本最低：12.41%
- 股东财富最大化：3623.08万元
- 资本结构调整创造价值：107.45万元

## 关键洞察

1. **债务的税盾效应**：适度债务可以降低WACC，提高企业价值
2. **财务风险权衡**：债务增加会提高β值和rs，超过最优点后企业价值下降
3. **最优债务水平**：在税盾收益与财务风险之间取得平衡
4. **股东财富最大化**：最优资本结构下，股东财富等于企业价值
