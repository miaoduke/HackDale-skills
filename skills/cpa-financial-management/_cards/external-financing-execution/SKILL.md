# 外部融资执行与优先顺序

## 何时使用

- 已确定融资总需求金额
- 需要选择债务融资或股权融资
- 评估目标资本结构状态并制定融资方案

## 融资优先顺序

筹集资金的优先顺序：

1. **动用现存的金融资产**
2. **增加留存收益**（内部融资）
3. **增加金融负债**（债务融资）
4. **增发股票**（股权融资）

## 融资方式选择决策

**决策条件：** 目标资本结构是否允许增加借款

| 情形 | 融资方式 | 原因 |
|-----|---------|------|
| 目标资本结构允许增加借款 | **优先使用借款融资** | 债务成本通常低于股权，具有税盾效应 |
| 目标资本结构不允许再增加借款 | **增发股票** | 债务比例已达上限，不宜继续增加负债 |

## 融资方案示例

**ABC公司案例：**
- 融资总需求 = 574万元
- 分解：动用金融资产0 + 增加留存收益180 + 增加借款394 = 574万元
- 选择借款394万元，说明目标资本结构允许该借款额度

## 关键提示

- 融资优序理论（Pecking Order Theory）指导：内部融资优先于外部融资，债务融资优先于股权融资
- 最终融资方案需结合目标资本结构、融资成本、财务风险综合确定
