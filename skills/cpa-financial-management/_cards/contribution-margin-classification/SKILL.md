# 边际贡献分类

## 使用场景
当变动成本包含生产制造过程变动成本和销售管理变动成本，需要分别评估生产环节和最终产品的贡献能力时使用此技能。

## 分类前提
由于变动成本既包括生产制造过程的变动成本（产品变动成本），还包括销售、管理费用中的变动成本（变动期间成本），因此边际贡献分为两个层次。

## 制造边际贡献

### 定义
销售收入减去变动生产成本后的差额。

### 计算公式
```
制造边际贡献 = 销售收入 - 变动生产成本
```

### 经济含义
反映生产环节本身对固定制造费用和利润的贡献能力，衡量生产效率和产品制造环节的盈利性。

### 应用场景
- 评估生产部门绩效
- 分析生产环节创造价值的能力

## 产品边际贡献

### 定义
制造边际贡献减去变动销售和管理费用后的差额，或销售收入减去全部变动成本后的差额。

### 计算公式

**方法A：**
```
产品边际贡献 = 制造边际贡献 - 变动销售和管理费用
```

**方法B：**
```
产品边际贡献 = 销售收入 - 变动生产成本 - 变动销售和管理费用
```

### 经济含义
反映最终产品对企业固定成本（包括固定制造费用和固定期间费用）和最终利润的总贡献能力。

### 应用场景
- 产品盈利能力分析
- 是否继续销售某产品的决策
- 盈亏平衡点计算

## 术语默认规则
通常，如果在"边际贡献"前未加任何定语，则是指"产品边际贡献"。

```
边际贡献（默认）= 产品边际贡献 = 销售收入 - 全部变动成本
```

## 层级关系

```
销售收入
- 变动生产成本
= 制造边际贡献
- 变动销售和管理费用
= 产品边际贡献（即默认的"边际贡献"）
- 固定成本（制造+期间）
= 利润
```

## 关键要点

1. **两个层次：** 制造边际贡献（生产环节）和产品边际贡献（最终产品）
2. **默认术语：** 未标注时默认为产品边际贡献
3. **应用区分：** 生产绩效用制造边际贡献，产品决策用产品边际贡献
4. **成本分类：** 需明确区分变动生产成本和变动期间成本
