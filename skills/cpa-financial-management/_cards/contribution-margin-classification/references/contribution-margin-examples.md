# 边际贡献计算示例

## 基础数据

| 项目 | 金额 |
|------|------|
| 销售收入 | 1000万元 |
| 销售数量 | 10000件 |
| 单价 | 1000元/件 |

### 变动成本明细

| 成本项目 | 金额 |
|---------|------|
| 直接材料 | 300万元 |
| 直接人工 | 200万元 |
| 变动制造费用 | 100万元 |
| **变动生产成本合计** | **600万元** |
| 变动销售费用 | 50万元 |
| 变动管理费用 | 30万元 |
| **变动期间成本合计** | **80万元** |
| **变动成本总计** | **680万元** |

### 固定成本明细

| 成本项目 | 金额 |
|---------|------|
| 固定制造费用 | 150万元 |
| 固定销售费用 | 40万元 |
| 固定管理费用 | 30万元 |
| **固定成本总计** | **220万元** |

## 边际贡献计算

### 制造边际贡献
```
制造边际贡献 = 销售收入 - 变动生产成本
制造边际贡献 = 1000 - 600 = 400万元
```

### 产品边际贡献
```
产品边际贡献 = 制造边际贡献 - 变动销售和管理费用
产品边际贡献 = 400 - 80 = 320万元
```

或
```
产品边际贡献 = 销售收入 - 全部变动成本
产品边际贡献 = 1000 - 680 = 320万元
```

### 利润
```
利润 = 产品边际贡献 - 固定成本
利润 = 320 - 220 = 100万元
```

## 贡献毛益式利润表

```
销售收入                    1000万元
减：变动生产成本            (600万元)
--------------------------------
制造边际贡献                400万元
减：变动销售和管理费用      (80万元)
--------------------------------
产品边际贡献（边际贡献）    320万元
减：固定成本                (220万元)
--------------------------------
利润                        100万元
```

## 单位指标计算

### 单位制造边际贡献
```
单位制造边际贡献 = 单价 - 单位变动生产成本
单位制造边际贡献 = 1000 - 600 = 400元/件
```

### 单位产品边际贡献
```
单位产品边际贡献 = 单价 - 单位变动成本总计
单位产品边际贡献 = 1000 - 680 = 320元/件
```

## 应用示例

### 生产部门绩效评估

**指标：** 制造边际贡献
**数值：** 400万元
**分析：** 生产环节创造了400万元的贡献，可用于覆盖固定制造费用和创造利润。

### 产品盈利能力分析

**指标：** 产品边际贡献
**数值：** 320万元
**分析：** 最终产品创造了320万元的贡献，可用于覆盖全部固定成本和创造利润。

### 盈亏平衡点计算

```
盈亏平衡点销售量 = 固定成本 ÷ 单位产品边际贡献
盈亏平衡点销售量 = 2200000 ÷ 320 = 6875件
```

### 安全边际计算

```
安全边际 = 实际销售量 - 盈亏平衡点销售量
安全边际 = 10000 - 6875 = 3125件

安全边际率 = 安全边际 ÷ 实际销售量
安全边际率 = 3125 ÷ 10000 = 31.25%
```

## 术语使用注意事项

### 情景一：未加定语
```
"边际贡献为320万元"
→ 默认指产品边际贡献
```

### 情景二：明确标注
```
"制造边际贡献为400万元"
→ 明确指生产环节边际贡献

"产品边际贡献为320万元"
→ 明确指最终产品边际贡献
```

### 情景三：容易混淆
```
"该产品边际贡献很高"
→ 需确认是指制造边际贡献还是产品边际贡献
→ 建议明确标注
```
