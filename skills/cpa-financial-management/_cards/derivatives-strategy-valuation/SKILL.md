# 衍生工具策略与定价

## 适用场景
- 交易者需要明确交易目的为风险对冲或风险承担以获利
- 需要计算期权或衍生品当前理论价值
- 已知未来可能状态及payoff
- 制定衍生品交易策略

## 衍生工具交易目的区分

### 定义辨析
- **套期保值（Hedging）**：为冲抵风险而买卖相应的衍生工具的行为
- **投机（Speculation）**：与套期保值相反的行为，主动承担风险以获取利润

### 目的对比
- **套期保值目的**：降低风险（Risk Reduction）
- **投机目的**：承担额外的风险以盈利（Risk Taking for Profit）

### 结果对比
- **套期保值结果**：降低了风险敞口，锁定成本或收益
- **投机结果**：增加了风险敞口，面临更大盈亏波动

### 决策逻辑

#### 步骤1：识别现有或未来的现货资产敞口
检查是否存在需要管理的现货头寸风险。

#### 步骤2：判断风险态度
- 若希望消除价格波动风险 → 选择套期保值策略
- 若希望利用价格波动获利 → 选择投机策略

#### 步骤3：确认风险承担能力
- **套期保值者**：通常有实体业务背景，需保护现货头寸
- **投机者**：无实体对冲需求，通过预测价格走势获取价差收益

## 风险中性估值流程

### 基本假设
- 市场无摩擦
- 可以无限制以无风险利率借贷

### 执行步骤

#### 步骤1：构建标的资产价格二叉树
- 确定当前标的资产价格 S_0
- 确定一个时期后可能的两种价格：上涨状态价格 S_up 和下跌状态价格 S_down
- 计算价格变动：
  - 上涨百分比 u = S_up/S_0
  - 下跌百分比 d = S_down/S_0

#### 步骤2：确定期权在各状态的payoff
- **看涨期权**：
  - C_up = max(S_up - K, 0)
  - C_down = max(S_down - K, 0)
  - 其中 K 为执行价格
- **看跌期权**：
  - P_up = max(K - S_up, 0)
  - P_down = max(K - S_down, 0)
- 对于复杂衍生品，根据合约条款计算各状态下的具体现金流

#### 步骤3：计算风险中性概率
利用无风险利率与期望报酬率的关系：
```
r_f = p × R_up + (1-p) × R_down
```
其中：
- R_up = (S_up - S_0)/S_0 = u - 1
- R_down = (S_down - S_0)/S_0 = d - 1

解出风险中性上行概率：
```
p = (r_f - R_down) / (R_up - R_down) = (1 + r_f - d) / (u - d)
```
下行概率为：1 - p

#### 步骤4：计算期望payoff
```
期望值 = p × (上行时payoff) + (1-p) × (下行时payoff)
```
例如对于看涨期权：
```
E[C] = p × C_up + (1-p) × C_down
```

#### 步骤5：折现计算现值
```
期权当前价值 = 期望payoff / (1 + r_f)^T
```
其中 T 为到期期限（离散时间）

或使用连续折现：
```
期权价值 = E[C] × e^(-r_f × T)
```

#### 步骤6：结果验证
确保计算出的期权价值满足无套利条件，即不存在通过买卖期权和标的资产获得无风险收益的机会。

## 执行步骤

### 交易策略制定
1. 识别现货资产敞口
2. 明确风险态度（规避或承担）
3. 确定交易目的（套期保值或投机）
4. 选择相应的衍生工具和策略

### 期权定价
1. 构建标的资产价格二叉树
2. 计算各状态下的期权payoff
3. 计算风险中性概率
4. 计算期望payoff
5. 折现计算期权当前价值
6. 验证无套利条件
