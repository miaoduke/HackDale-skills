# 可转换债券计算完整示例

## 资本成本计算示例

### 已知条件
- 债券面值：1000元
- 票面利率：10%（年利息100元）
- 转换比率：20股/张
- 当前股价：35元
- 股价年增长率：6%
- 持有期限：10年
- 普通债券市场利率：12%
- 股权资本成本（税后）：14%
- 所得税税率：25%

### 步骤一：确定现金流量
| 时点 | 现金流 | 说明 |
|------|--------|------|
| 第0年 | -1000元 | 购买债券支出 |
| 第1-10年 | +100元/年 | 年利息收入 |
| 第10年末 | +1253.56元 | 转换价值 |

### 步骤二：计算第10年末转换价值
```
转换价值 = 35 × (1+6%)^10 × 20
         = 35 × 1.7908 × 20
         = 1253.56元
```

### 步骤三：求解IRR
方程：
```
1000 = Σ(t=1 to 10)[100/(1+i)^t] + 1253.56/(1+i)^10
```

使用财务计算器或Excel IRR函数求解：
**i = 11.48%**

### 步骤四：可行性评估

**上限检验**：
```
税前股权成本 = 14% / (1-25%) = 18.67%
11.48% < 18.67% ✓（未超过上限）
```

**下限检验**：
```
普通债券利率 = 12%
11.48% < 12% ✗（低于下限）
```

**结论**：当前方案不可行，对投资者缺乏吸引力，需修改条款（提高票面利率或降低转换价格）。

## 纯债券价值计算示例

### 已知条件
- 面值：1000元
- 票面利率：10%（年利息100元）
- 期限：20年
- 等风险普通债券市场利率：12%

### 计算
```
纯债券价值 = 年金现值(100, 12%, 20) + 复利现值(1000, 12%, 20)
           = 100 × 7.4694 + 1000 × 0.1037
           = 746.94 + 103.67
           = 850.61元
```

### 价值变动规律
| 时间 | 纯债券价值 | 说明 |
|------|-----------|------|
| 发行日 | 850.61元 | 低于面值（因票面利率<市场利率） |
| 第10年 | 887.00元 | 逐年递增 |
| 到期日 | 1000元 | 收敛于面值 |

## 关键公式汇总

| 计算项目 | 公式 |
|---------|------|
| 转换价值 | 股价×(1+g)^n×转换比率 |
| 纯债券价值 | Σ(利息/(1+r)^t) + 面值/(1+r)^n |
| 筹资资本成本 | 使NPV=0的折现率（IRR） |
| 税前股权成本 | 税后股权成本/(1-T) |
