# 可转换债券筹资资本成本计算与可行性评估

## 适用场景
- 评估可转换债券筹资方案的资本成本合理性
- 计算可转换债券的纯债券价值（债底价值）
- 设计可转换债券条款（票面利率、转换比率等）
- 比较可转换债券与纯债券、普通股的筹资成本

## 核心计算一：筹资资本成本（IRR法）

### 现金流量分布
- **零时点**：购买可转换债券支出（现金流出）
- **第1年至第n年**：每年年末取得利息（现金流入）
- **第n年年底**：转换价值（现金流入，含本金回收与转换增值）

### 转换价值计算
```
转换价值 = 当前股价 × (1 + 年增长率)^年数 × 转换比率
```

### 求解内含报酬率（IRR）
建立方程并求解使NPV=0的折现率：
```
发行价 = Σ(年利息/(1+i)^t) + 转换价值/(1+i)^n
```

该IRR即为投资者的预期报酬率，也是筹资人的**税前资本成本**。

## 核心计算二：纯债券价值

### 现金流折现模型
```
纯债券价值 = Σ(每年利息/(1+折现率)^t) + 到期值/(1+折现率)^n
```

其中折现率 = 等风险普通债券的市场利率

### 价值特征
- 发行初期：纯债券价值通常高于转换价值，形成价值底线
- 时间趋势：逐年递增，到期收敛于面值
- 投资者保护：当纯债券价值 > 转换价值时，投资者不会选择转换

## 可行性评估：双重阈值检验

### 上限检验（与股权成本比较）
```
税前股权资本成本 = 税后股权资本成本 / (1 - 所得税税率)
```

**规则**：若可转换债券税后资本成本 > 税后股权资本成本，则不如直接增发普通股，方案不可行。

### 下限检验（与债务成本比较）
**规则**：若税前资本成本 < 普通债券市场利率，则对投资者缺乏吸引力（不如买普通债券），方案不可行。

### 可行区间
```
普通债券利率 < 筹资资本成本 < 税前股权资本成本
```

## 付息频率设计
从五种标准频率中选择，权衡投资者吸引力与企业成本：
- 按月/季付息 > 按半年付息 > 按年付息 > 一次性付息（吸引力角度）
- 高频付息增加企业资金调度难度和付息操作成本

## 输出结果
- 税前筹资资本成本（X.XX%）
- 判定结果：[可行/不可行]
- 若低于下限：提示"对投资者缺乏吸引力"
- 若高于上限：提示"不如直接增发普通股"
