# 权益分派实施

本技能用于指导执行上市公司权益分派的具体操作流程，包括确定分派对象、执行送转股、处理零碎股以及派发现金红利。

## 适用场景

当需要执行以下任务时使用此技能：

- 实施上市公司权益分派方案（送股、转增股、派息）
- 计算并处理零碎股分配
- 确定权益分派对象及执行时间节点
- 计算权益分派后的股本结构变动

## 执行步骤

### 1. 确定权益分派对象

根据权益登记日确定分派范围：

- **基准时间**：权益登记日下午收市后。
- **登记机构**：中国证券登记结算有限责任公司（如深圳分公司）。
- **对象范围**：在登记机构登记在册的本公司全体股东。

### 2. 执行送（转）股

- **记入时间**：除权除息日（通常为权益登记日次日）直接记入股东证券账户。
- **操作方式**：将资本公积转增或送股股份直接划转至股东账户。

### 3. 应用零碎股处理算法

针对送转股过程中不足1股的零碎股份，按以下算法处理：

1. **排序**：按股东应得股份的小数点后尾数由大到小排序。
2. **派发**：依次向排序在前的股东派发1股。
3. **平局处理**：若尾数相同，则在尾数相同者中由系统随机排序派发。
4. **终止条件**：重复上述步骤，直至实际送（转）股总数与本次计划送（转）股总数完全一致。

### 4. 派发现金红利

- **委托方式**：上市公司委托中国结算分公司代派。
- **派发对象**：A股股东。
- **执行时间**：除权除息日。
- **划转路径**：通过股东托管证券公司或其他托管机构，直接划入其资金账户。

### 5. 计算股份变动结果

根据分派方案计算变动前后的股本结构：

- 统计有限售条件流通股的变动数量及比例。
- 统计无限售条件流通股的变动数量及比例。
- 汇总股份总数变动。

## 关键变量

- **权益登记日**：确定股东资格的截止日期。
- **除权除息日**：股份及现金红利实际派发到账日期。
