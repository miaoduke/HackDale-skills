# 投资组合风险与分散化效应

## 适用场景
- 计算两种证券组合的风险水平
- 评估分散化投资效果
- 分析相关系数对组合风险的影响
- 资产配置决策

## 核心计算公式

### 组合期望报酬率
```
r_p = w_A × r_A + w_B × r_B
```

其中：
- r_p = 组合期望报酬率
- w_A, w_B = 证券A和B的投资权重（w_A + w_B = 1）
- r_A, r_B = 各证券期望报酬率

### 组合标准差（考虑协方差）
```
σ_p = √(w_A²σ_A² + w_B²σ_B² + 2w_Aw_Bρ_{AB}σ_Aσ_B)
```

其中：
- σ_p = 组合标准差（风险水平）
- σ_A, σ_B = 证券A和B各自的标准差
- ρ_{AB} = 相关系数（范围[-1, 1]）

## 分散化效应判定

### 判定规则
只要两种证券预期报酬率的相关系数小于1（ρ<1），证券组合报酬率的标准差就小于各证券报酬率标准差的加权平均数。

### 比较基准
```
加权平均标准差 = w_A × σ_A + w_B × σ_B
```

### 效应解释
- **ρ = 1**（完全正相关）：无分散化效应，组合标准差等于加权平均标准差
- **ρ < 1**：存在分散化效应，组合风险降低
- **ρ越小**（越接近-1）：风险降低效果越明显

## 计算步骤

### 步骤1：计算组合期望报酬率
使用简单加权平均公式计算。

### 步骤2：计算组合标准差
代入协方差调整的标准差公式。

### 步骤3：比较与判定
- 计算加权平均标准差
- 比较组合标准差与加权平均标准差
- 若组合标准差 < 加权平均标准差，则分散化有效

## 极端情况分析

### 完全正相关（ρ=1）
- 无任何抵消作用
- 协方差项达到最大值
- 等比例投资时，组合标准差等于两种证券标准差的算术平均数

### 完全负相关（ρ=-1）
- 最大程度抵消作用
- 可以通过适当权重完全消除风险

### 不相关（ρ=0）
- 存在分散化效应
- 风险降低效果中等

## 关键洞察

1. **分散化原理**：通过不完全正相关的资产组合降低整体风险
2. **相关系数作用**：相关系数是决定分散化效果的关键因素
3. **风险降低幅度**：风险降低幅度 = (加权平均标准差 - 组合标准差) / 加权平均标准差
4. **实际应用**：投资者应选择相关系数较低的资产进行组合
