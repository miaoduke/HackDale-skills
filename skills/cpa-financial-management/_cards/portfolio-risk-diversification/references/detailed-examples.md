# 详细计算示例

## 示例：两种证券组合风险计算

**基础数据：**
- A证券：期望报酬率10%，标准差12%
- B证券：期望报酬率18%，标准差20%
- 相关系数：ρ=0.2
- 投资比例：等比例投资（w_A=w_B=0.5）

### 步骤1：计算组合期望报酬率
```
r_p = 10% × 0.5 + 18% × 0.5 = 5% + 9% = 14%
```

### 步骤2：计算组合标准差

**代入公式：**
```
σ_p = √(0.5²×0.12² + 0.5²×0.2² + 2×0.5×0.5×0.2×0.12×0.2)
```

**逐步计算：**
- 第一项（A的方差贡献）：0.5×0.5×1×0.12² = 0.25×0.0144 = 0.0036
- 第二项（协方差贡献）：2×0.5×0.5×0.2×0.12×0.2 = 0.5×0.2×0.024 = 0.0024
- 第三项（B的方差贡献）：0.5×0.5×1×0.2² = 0.25×0.04 = 0.01

**求和与开方：**
```
求和：0.0036 + 0.0024 + 0.01 = 0.016
σ_p = √0.016 ≈ 0.1265 = 12.65%
```

### 步骤3：分散化效应判定

**比较基准：**
```
加权平均标准差 = 0.5×12% + 0.5×20% = 6% + 10% = 16%
```

**判定：**
- 组合标准差（12.65%）< 加权平均标准差（16%）
- 分散化有效

**风险降低幅度：**
```
风险降低幅度 = (16% - 12.65%) / 16% = 3.35% / 16% = 20.9%
```

## 极端情况对比

### 情况1：完全正相关（ρ=1）
```
σ_p = √(0.5²×0.12² + 0.5²×0.2² + 2×0.5×0.5×1×0.12×0.2)
    = √(0.0036 + 0.01 + 0.0024)
    = √0.016
    = 0.16 = 16%
```

**结论：** 组合标准差（16%）= 加权平均标准差（16%），无分散化效应

### 情况2：不相关（ρ=0）
```
σ_p = √(0.0036 + 0 + 0.01) = √0.0136 ≈ 11.66%
```

**风险降低幅度：** (16% - 11.66%) / 16% = 27.1%

### 情况3：完全负相关（ρ=-1）
```
σ_p = √(0.0036 - 0.0024 + 0.01) = √0.0112 ≈ 10.58%
```

**风险降低幅度：** (16% - 10.58%) / 16% = 33.9%

## 总结

| 相关系数 | 组合标准差 | 风险降低幅度 | 分散化效果 |
|---------|-----------|-------------|-----------|
| ρ=1 | 16.00% | 0% | 无效果 |
| ρ=0.2 | 12.65% | 20.9% | 中等 |
| ρ=0 | 11.66% | 27.1% | 较好 |
| ρ=-1 | 10.58% | 33.9% | 最佳 |
