# 销售预算示例

## 基础数据

假设M公司收款政策：
- 当季收款：60%
- 下季收款：40%

## 预算表示例

| 季度 | 第一季度 | 第二季度 | 第三季度 | 第四季度 | 全年 |
|------|---------|---------|---------|---------|------|
| 预计销售量（件） | 100 | 150 | 200 | 180 | 630 |
| 预计单价（元） | 200 | 200 | 200 | 200 | 200 |
| 销售收入（元） | 20,000 | 30,000 | 40,000 | 36,000 | 126,000 |

## 预计现金收入计算

| 项目 | 第一季度 | 第二季度 | 第三季度 | 第四季度 | 全年 |
|------|---------|---------|---------|---------|------|
| 上年应收账款 | 6,200 | | | | 6,200 |
| 第一季度销售（20,000） | 12,000 | 8,000 | | | 20,000 |
| 第二季度销售（30,000） | | 18,000 | 12,000 | | 30,000 |
| 第三季度销售（40,000） | | | 24,000 | 16,000 | 40,000 |
| 第四季度销售（36,000） | | | | 21,600 | 21,600 |
| 现金收入合计 | 18,200 | 26,000 | 36,000 | 37,600 | 117,800 |

## 关键说明

- 销售预算是整个预算的编制起点，其他预算的基础
- 预计现金收入用于现金预算编制
- 年末应收账款 = 第四季度销售收入 × 40% = 36,000 × 40% = 14,400元
