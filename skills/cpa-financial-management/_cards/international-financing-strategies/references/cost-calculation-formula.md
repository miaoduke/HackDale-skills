# 资金成本计算公式

## 税后实际资金成本计算

```
税后实际成本 = (名义利率 × (1 - 税率) + 汇率预期变动率 + 政治风险溢价 + 交易成本率)
```

## 变量说明
- K_d：债务资本成本
- K_e：股权资本成本
- 汇率预期变动率：资金使用过程中预计的汇率升贬值幅度
- τ：有效税率（包括东道国税率和预提税影响）
- 政治风险溢价：因资金汇回风险而增加的额外成本

## WACC计算

```
WACC = (E/V) × K_e + (D/V) × K_d × (1 - τ)
```

其中：
- E = 股权价值
- D = 债务价值
- V = 企业总价值 (E + D)
