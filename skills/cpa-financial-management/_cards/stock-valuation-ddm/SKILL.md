# 股票估值基本模型（股利折现模型）

## 适用场景
- 需要评估普通股的内在价值
- 能够预测未来股利现金流
- 能够确定适当的折现率
- 股票有股利分配特征

## 基本原理
股票带给持有者的现金流入包括两部分：股利收入和出售时的售价。股票的内在价值由一系列的股利和将来出售股票时售价的现值所构成。

## 核心公式

### 永久持有情形
```
V₀ = D₁/(1+r_s)¹ + D₂/(1+r_s)² + ... + D∞/(1+r_s)^∞ = Σ(t=1→∞) D_t/(1+r_s)^t
```

### 有限期持有后出售情形
```
V₀ = Σ(t=1→n) D_t/(1+r_s)^t + V_n/(1+r_s)^n
```

### 变量说明
- V₀：普通股当前价值（内在价值）
- D_t：第t年的预期股利
- r_s：年折现率（资本成本率或必要报酬率）
- V_n：第n年末出售时的预期股价
- n：投资者计划持有的年数

## 核心结论
不管投资者是永久持有股票，还是持有一段时间后卖掉，并不影响股票的内在价值。股票价值只取决于未来所有股利的现值，与投资者的持有期限决策无关。

## 实际应用的关键问题

### 股利预测
- 股利取决于：每股盈利 × 股利支付率
- 估计方法：历史资料的统计分析（回归分析、时间序列趋势分析）
- 简化处理（因无限期预测不可行）：
  - 假设每年股利相同（零增长模型）
  - 假设股利固定比率增长（固定增长模型）

### 折现率确定
- 折现率作用：把所有未来不同时间点的现金流入折算为现在的价值
- 折现率选择：应当是投资的必要报酬率

## 投资决策规则
- 当市场价格 < V₀时，股票被低估，建议买入
- 当市场价格 > V₀时，股票被高估，建议卖出或不买入
- 当市场价格 = V₀时，股票定价合理
