# 股利折现模型变体

## 1. 零增长模型
假设股利每年保持不变，即 D₁ = D₂ = ... = D∞ = D

```
V₀ = D / r_s
```

## 2. 固定增长模型（戈登模型）
假设股利以固定增长率g增长

```
V₀ = D₁ / (r_s - g)
```

其中：
- D₁：下一期预期股利
- r_s：必要报酬率
- g：股利固定增长率

**适用条件：** r_s > g

## 3. 非固定增长模型
适用于股利增长模式不固定的股票，通常分为两个或多个阶段：
- 第一阶段：高速增长期
- 第二阶段：稳定增长期

计算步骤：
1. 计算高速增长期各期股利的现值
2. 计算稳定增长期开始时的股票价值
3. 将稳定期价值折现到当前时点
4. 汇总各部分现值
