# 公司资本成本计算

## 适用场景
- 计算公司整体资本成本
- 比较不同公司资本成本
- 分析公司资本成本变动原因
- 计算普通股资本成本（股利增长模型）

## 资本成本三因素分解模型

### 何时使用
需要理解公司资本成本的构成，或分析不同公司资本成本差异的原因时。

### 执行步骤
1. **确定无风险利率**：使用政府债券收益率作为基准
2. **评估经营风险溢价**：根据公司业务类型和经营前景不确定性确定
3. **评估财务风险溢价**：根据公司负债率和财务杠杆确定
4. **计算资本成本**：三因素相加

### 核心公式
```
公司资本成本 = 无风险利率 + 经营风险溢价 + 财务风险溢价
```

### 三因素说明

#### 无风险利率（基础层）
- 定义：无风险投资所要求的报酬率
- 典型示例：政府债券投资的收益率
- 作用：构成资本成本的基准底线

#### 经营风险溢价（业务层）
- 定义：由于公司未来经营前景的不确定性导致的要求报酬率增加部分
- 逻辑：经营风险越高 → 要求报酬率增加越多
- 差异：不同公司业务不同，经营风险不同

#### 财务风险溢价（资本结构层）
- 定义：高财务杠杆产生的风险补偿
- 传导：负债率越高 → 股东收益波动性越大 → 要求报酬率越高
- 本质：财务杠杆放大了股东收益的波动风险

## 股利增长模型

### 何时使用
需要计算普通股资本成本，且公司支付股利并假设股利以固定增长率增长时。

### 执行步骤
1. **确定当前股价P0**：普通股当前市场价格
2. **估计增长率g**：使用历史增长率法、可持续增长率法等
3. **确定股利数据**：当前股利D0或预期下年股利D1
4. **代入公式计算**：应用股利增长模型

### 核心公式
```
rs = (D1 / P0) + g
```

或：
```
rs = [D0 × (1 + g) / P0] + g
```

其中：
- rs：普通股资本成本
- D1：预期下年现金股利额
- P0：普通股当前市价
- g：股利长期平均增长率
- D0：当前已支付的最近一期股利

### 约束条件
- 假设股利以固定年增长率永续增长
- 不适用于不支付股利或股利不稳定的公司
- g必须小于rs以保证模型有意义
