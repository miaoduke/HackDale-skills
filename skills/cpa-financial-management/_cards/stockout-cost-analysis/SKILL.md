# 缺货成本分析

## 触发条件

发生存货供应中断或库存不足

## 缺货类型及对应损失

### 材料供应中断
计算造成的停工损失

### 产成品库存缺货
计算拖欠发货损失和丧失销售机会的损失

### 无形损失
估算商誉损失（需主观估计）

## 紧急采购场景处理

### 判断条件
IF (生产企业以紧急采购代用材料解决库存材料中断)

### 计算方法
```
缺货成本 = 紧急额外购入成本
```

### 注意事项
紧急额外购入的开支会大于正常采购的开支

## 符号表示

缺货成本用 TCs 表示

## 适用对象

- 存货
- 原材料
- 产成品

## 不适用情况

不适用于存货供应充足的情况

## 使用流程

1. **识别缺货类型**：判断是材料供应中断、产成品库存缺货还是其他类型
2. **计算对应损失**：根据缺货类型计算相应的损失金额
3. **处理紧急采购**：如适用，计算紧急额外购入成本
4. **汇总缺货成本**：将各项损失汇总得到缺货成本总额
5. **制定改进措施**：根据缺货成本分析结果，制定相应的库存管理改进措施

## 经济意义

缺货成本是存货总成本的重要组成部分，反映了库存不足对企业经营造成的负面影响。通过计算缺货成本，可以帮助企业：

1. 评估库存管理的有效性
2. 确定合理的库存水平
3. 平衡库存持有成本与缺货成本
4. 优化供应链管理
