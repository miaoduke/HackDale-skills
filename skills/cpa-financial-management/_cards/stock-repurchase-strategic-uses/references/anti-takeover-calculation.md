# 反收购成本计算方法

## 基本概念

股票回购通过减少流通股数量，提高每股价格，从而增加收购方的收购成本。

## 计算公式

### 1. 收购成本增加比例
```
收购成本增加比例 = (回购后股价 - 回购前股价) / 回购前股价 × 100%
```

### 2. 流通股减少比例
```
流通股减少比例 = 回购股数 / 回购前总流通股数 × 100%
```

### 3. 理论股价提升（简化模型）
```
理论股价提升 = (回购金额 × 回购前市盈率) / 回购后流通股数
```

## 实际案例分析

### 案例参数
- 回购前总流通股数：1亿股
- 回购前股价：10元/股
- 回购前市值：10亿元
- 回购金额：1亿元
- 回购股数：1000万股

### 计算过程
1. **流通股减少比例**：
   - 1000万股 / 1亿股 = 10%

2. **回购后流通股数**：
   - 1亿股 - 1000万股 = 9000万股

3. **理论股价提升**（假设市盈率不变）：
   - 回购后市值仍为10亿元（假设回购资金来自现金，不影响企业价值）
   - 回购后股价 = 10亿元 / 9000万股 ≈ 11.11元/股
   - 股价提升 = (11.11 - 10) / 10 = 11.1%

4. **收购成本增加**：
   - 收购方需要支付的总金额增加约11.1%

## 影响因素

### 正向因素
- 回购比例越大，股价提升效果越明显
- 市场对公司回购的正面反应
- 流动性减少带来的溢价效应

### 限制因素
- 回购资金来源限制
- 法规对回购比例的限制
- 市场对回购动机的解读
- 回购后的股份处置要求
