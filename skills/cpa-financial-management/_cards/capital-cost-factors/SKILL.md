# 资本成本影响因素分析

## 适用场景
需要分析或预测企业资本成本变化，或制定筹资决策/资本结构决策时，应用本知识框架识别影响因素。

## 总体框架

在市场经济环境中，决定企业资本成本高低的五大核心因素：
1. 无风险利率
2. 市场风险溢价
3. 税率
4. 资本结构
5. 投资政策

**关键原则**：这些因素发生变化时，资本成本也会发生改变。

## 外部因素（个别公司无法控制）

### 因素1：无风险利率
- **作用机制**：
  - 无风险利率上升 → 投资者机会成本增加 → 公司必须付给债权人更多报酬 → 债务资本成本上升
  - 根据资本资产定价模型(CAPM)：无风险利率上升 → 普通股成本上升
- **公司可控性**：个别公司无法改变，只能被动接受

### 因素2：市场风险溢价
- **定义**：由资本市场上的供求双方决定
- **作用机制**：根据资本资产定价模型，市场风险溢价会影响股权资本成本
- **公司可控性**：个别公司无法控制

### 因素3：税率
- **性质**：政府政策，个别公司无法控制
- **多重影响路径**：
  - **直接影响**：税率变化 → 税后债务资本成本变化 → 加权平均资本成本变化
  - **间接影响**：资本性收益的税务政策变化 → 影响人们对于权益投资和债务投资的选择 → 影响公司的最佳资本结构 → 影响加权平均资本成本

## 内部因素（公司可以主动调整）

### 因素4：资本结构
- **基本前提**：计算加权平均资本成本时，假定公司的目标资本结构已经确定
- **动态关系**：企业改变资本结构时，资本成本会随之改变
- **债务比重调整的双向效应**：
  - 增加债务比重 → 有可能使平均资本成本趋于降低（债务成本通常低于股权成本，且利息抵税）
  - 但同时会加大公司的财务风险
  - 财务风险提高 → 引起债务资本成本和股权资本成本上升
- **决策原则**：公司应适度负债，寻求资本成本最小化的资本结构
