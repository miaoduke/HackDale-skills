# 分步法

## 适用范围

### 适用条件（需同时满足）
1. **生产组织特点**：大量大批生产（非单件小批）
2. **生产工艺特点**：多步骤生产（产品生产可分为若干个生产步骤）
3. **管理需求特点**：既要求按照产品品种计算成本，又要求按照生产步骤计算成本

### 典型适用行业
纺织、冶金、汽车制造等大量大批的制造企业

### 管理目的
为考核和分析各种产品及各生产步骤成本计划的执行情况提供资料，满足分步骤成本控制与考核的需求

## 成本计算对象

产品生产步骤（区别于品种法的产品品种、分批法的产品批别）

## 逐步结转分步法

### 方法定义
按照产品加工的顺序，逐步计算并结转半成品成本，直到最后加工步骤才能计算出产成品成本的方法。

### 别名
计算半成品成本分步法

### 核心目的
为了分步计算半成品成本

## 逐步结转分步法计算程序

### 步骤1（第一加工步骤）
- 计算第一个加工步骤的半成品成本
- 成本构成：本步骤耗用的直接材料 + 本步骤加工费用（直接人工+制造费用）
- 输出：步骤1半成品成本

### 步骤2（第二加工步骤）
- 接收第一步骤转来的半成品成本（作为本步骤的"上步骤转入成本"或"自制半成品成本"）
- 归集本步骤新发生的成本：本步骤耗用的材料（如有）+ 本步骤加工费用
- 计算逻辑：第二步骤半成品成本 = 第一步骤转来的半成品成本 + 本步骤耗用的材料 + 本步骤加工费用
- 输出：步骤2半成品成本（已累积步骤1和步骤2的全部成本）

### 步骤n（第n加工步骤，中间步骤）
- 接收第(n-1)步骤转来的半成品成本（包含前n-1个步骤的累积成本）
- 加上本步骤耗用的材料和加工费用
- 计算本步骤半成品成本（累积成本继续增加）
- 如此顺序逐步转移累计

### 最终步骤（最后加工步骤）
- 接收前一步骤转来的半成品成本（包含前面所有步骤的累积成本）
- 加上最后步骤耗用的材料和加工费用
- 计算结果：产成品成本（包含所有生产步骤的完整成本）

## 成本流转特征

1. **成本随实物转移**：半成品成本随半成品实物的转移而结转
2. **累积性**：后续步骤的半成品成本包含前面所有步骤的成本累积
3. **顺序性**：必须严格按照产品加工顺序进行，不能跳步或倒序

## 关键公式

### 某步骤半成品成本
```
某步骤半成品成本 = 上步骤转来的半成品成本 + 本步骤直接材料 + 本步骤直接人工 + 本步骤制造费用
```

### 最终步骤产成品成本
```
产成品成本 = 前一步骤转来的半成品成本 + 最后步骤直接材料 + 最后步骤直接人工 + 最后步骤制造费用
```

## 使用流程

1. **确定适用性**：确认企业为大量大批多步骤生产，且管理要求按步骤计算成本
2. **明确加工顺序**：确定产品加工的步骤顺序（步骤1→步骤2→...→步骤n）
3. **逐步计算**：按照加工顺序，逐步计算各步骤的半成品成本
4. **逐步结转**：将上一步骤的半成品成本转入下一步骤
5. **最终计算**：在最后步骤计算出产成品成本
6. **成本分析**：利用分步骤成本资料进行成本控制与考核
