# 逐步结转分步法计算示例

## 已知数据

### 步骤1（第一加工步骤）
- 直接材料：10,000元
- 直接人工：5,000元
- 制造费用：3,000元

### 步骤2（第二加工步骤）
- 从步骤1转入的半成品成本：18,000元
- 本步骤耗用材料：2,000元
- 直接人工：4,000元
- 制造费用：2,000元

### 步骤3（最后加工步骤）
- 从步骤2转入的半成品成本：26,000元
- 本步骤耗用材料：1,000元
- 直接人工：3,000元
- 制造费用：2,000元

## 计算过程

### 步骤1半成品成本
```
步骤1半成品成本 = 10,000 + 5,000 + 3,000 = 18,000元
```

### 步骤2半成品成本
```
步骤2半成品成本 = 18,000（步骤1转入） + 2,000 + 4,000 + 2,000 = 26,000元
```

### 步骤3产成品成本
```
产成品成本 = 26,000（步骤2转入） + 1,000 + 3,000 + 2,000 = 32,000元
```

## 成本累积过程

| 步骤 | 上步骤转入 | 本步骤材料 | 本步骤人工 | 本步骤制造费用 | 半成品/产成品成本 |
|------|-----------|-----------|-----------|--------------|------------------|
| 步骤1 | 0 | 10,000 | 5,000 | 3,000 | 18,000 |
| 步骤2 | 18,000 | 2,000 | 4,000 | 2,000 | 26,000 |
| 步骤3 | 26,000 | 1,000 | 3,000 | 2,000 | 32,000 |

## 成本分析

- 步骤1成本：18,000元
- 步骤2新增成本：8,000元（2,000+4,000+2,000）
- 步骤3新增成本：6,000元（1,000+3,000+2,000）
- 产成品总成本：32,000元

通过分步骤成本资料，可以分析各步骤的成本控制情况，为成本管理提供依据。
