# 分步法成本计算

## 适用场景
- 多步骤生产的企业
- 需要计算最终产成品成本
- 不需要提供各步骤半成品成本资料（平行结转法）
- 需要按原始成本项目考核分析产品成本（综合结转法）

## 平行结转分步法

### 核心原则
在计算各步骤成本时：
- 不计算各步骤所产半成品成本
- 不计算各步骤所耗用上一步骤的半成品成本

### 计算内容
- 只计算本步骤发生的各项其他费用
- 计算这些费用中应计入产成品成本的"份额"

### 成本结转程序
1. 尽管半成品的实物转入下一生产步骤继续加工，但其成本并不结转到下一生产步骤的成本计算单中去
2. 各步骤的产品生产费用并不伴随着半成品实物的转移而结转
3. 只有当产品最终完工入库时，才将各步骤费用中应由完工产成品负担的份额，从各步骤成本计算单中转出
4. 将相同产品的各步骤成本明细账中的这些份额平行结转、汇总，计算出该种产品的产成品成本

### 广义在产品定义
包括本步骤在产品和本步骤已完工但未最终完工的所有后续仍需继续加工的在产品、半成品。

### 优缺点

**优点**：
1. 各步骤可以同时计算产品成本，平行汇总计入产成品成本
2. 能够直接提供按原始成本项目反映的产成品成本资料，不必进行成本还原

**缺点**：
1. 不能提供各个步骤的半成品成本资料
2. 不能全面地反映各步骤产品的生产耗费水平（第一步骤除外）

## 综合结转成本还原

### 还原原因
综合结转法下，产成品成本中"半成品"项目占比大，掩盖了直接人工、制造费用等原始成本项目构成，无法满足全企业角度的成本分析。

### 还原定义
从最后一个步骤起，将产成品所耗上一步骤半成品的综合成本，分解还原为直接材料、直接人工、制造费用等原始成本项目。

### 计算公式

**标准公式（仅适用于两个步骤）**：
```
成本还原分配率 = 产成品所耗用的上一生产步骤半成品成本合计 / 上一生产步骤所产该种半成品成本合计
```

**通用公式（适用于三个及以上步骤）**：
```
成本还原分配率 = 产成品所耗以前生产步骤半成品成本合计 / 以前生产步骤所产该种半成品成本合计
```

### 还原计算步骤
1. 计算成本还原分配率
2. 用分配率分别乘以上一步骤本月所产半成品各成本项目金额
3. 将计算出的还原金额与产成品成本中对应的原始成本项目相加
4. 得出按原始成本项目反映的产成品成本

### 注意事项
还原后的总成本应与还原前产成品总成本相等。

## 决策输出

### 平行结转法
产成品成本 = Σ (各步骤成本明细账中应计入产成品成本的份额)

### 综合结转法
产出产成品成本还原计算表，展示按原始成本项目（直接材料、直接人工、制造费用）反映的成本构成。
