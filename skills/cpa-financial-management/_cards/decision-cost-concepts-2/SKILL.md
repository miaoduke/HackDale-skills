# 决策成本概念

## 相关成本

### 核心判定标准

相关成本必须同时满足以下条件：
1. **与决策方案相关**：成本必须与正在考虑的特定决策直接关联
2. **有差别**：不同方案之间的成本必须存在差异
3. **未来成本**：必须是决策将要影响的未来期间成本，而非历史成本
4. **随决策改变而改变**：如果决策变化导致该成本不变，则不属于相关成本

### 相关成本与无关成本的区分原则

- 企业必须使用相关成本并剔除无关成本进行决策
- 无关成本：已经发生的历史成本、各方案共同发生的相同成本等

### 主要表现形式

- 边际成本（marginal cost）
- 机会成本（opportunity cost）
- 重置成本
- 付现成本
- 可避免成本
- 可延缓成本
- 专属成本
- 差量成本
- 变动成本

## 边际成本

### 经济学定义

业务量变动一个单位时，成本的变动部分。

### 数学表达
```
MC = ΔTC / ΔQ
```
其中ΔQ趋近于0（理论定义）

### 实际计量中的处理

- **现实约束**：产量的无限小的变化只能小到一个单位
- **实际定义**：产量增加或减少一个单位所引起的成本变动
- **计算公式**：边际成本 = 产量变化一个单位时的总成本变化额

### 决策应用要点

- 边际成本用于判断增加一单位产量是否经济
- 当边际收入 > 边际成本时，增加产量有利
- 最优产量点：边际收入 = 边际成本

## 机会成本

### 定义

实行本方案的一种代价，等于所放弃方案的最大潜在收益。

### 本质特征（辩证理解）

- 不是通常意义上的成本
- 实际上不是一种支出和费用（无实际现金流出）
- 是失去的潜在收益，是辩证的概念
- 需要主观估计，非客观记账数据

### 计量方法

```
机会成本 = 被放弃方案中的最大潜在收益
```

### 方案针对性的关键原则

- 机会成本总是针对具体方案的
- "离开了被放弃的方案就无从确定"
- 不同决策场景下，同一资源的机会成本可能不同

### 决策应用要求

1. 全面考虑可能采取的各种方案（穷尽备选方案）
2. 准确估计各方案的潜在收益
3. 选择被放弃方案中的最大收益作为机会成本
4. 为既定资源寻求最为有利的使用途径
5. 最终目标：优化资源配置

### 常见应用场景

- 自有资金用于项目投资（机会成本 = 放弃的利息/投资收益）
- 自有房产用于企业经营（机会成本 = 放弃的租金收入）
- 机器设备用于生产A产品而非B产品（机会成本 = 生产B产品的最大贡献毛益）

## 不同目的不同成本原则

### 核心原则

同一项成本，在不同目的下，处理也可能不同。

### 成本计算目的分类

#### 对外财务报告目的
- **适用方法**：品种法、分步法、分批法和作业成本法
- **计算对象**：产品制造成本
- **处理规则**：严格遵循会计准则

#### 内部管理决策目的
- **生产决策**：计算与生产方案相关的特定成本口径
- **定价决策**：计算与定价策略匹配的成本
- **部门业绩考核**：计算责任成本，强调可控性与责任归属
- **处理灵活性**：可根据管理需求调整成本归集和分摊方法

### 典型案例分析

**成本项目**：推广生命周期较长产品的广告成本

**对外财务报告处理**：按照会计准则全部费用化，计入当期损益

**内部业绩考核处理**：可以先资本化再摊销，以更公允地衡量管理层业绩

**差异原因**：对外报告强调谨慎性和统一性，内部考核强调公允性和激励性

### 成本口径选择决策树

1. 确定使用场景（对外报告 vs 生产决策 vs 定价决策 vs 业绩考核）
2. 选择对应的成本计算方法
3. 确定特定成本项目的处理方式（费用化时点、分摊基础、资本化条件）
4. 计算特定目的下的产品成本或责任成本

### 质量检查

确保计算出的成本口径与决策目的严格匹配，避免混用对外报告成本进行内部决策。
