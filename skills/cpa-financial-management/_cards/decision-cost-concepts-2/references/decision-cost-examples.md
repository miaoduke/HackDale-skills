# 决策成本计算示例

## 边际成本计算示例

**已知数据**：
- 产量从100件增加到101件
- 总成本从5,000元变为5,040元

**计算**：
```
边际成本 = 5,040 - 5,000 = 40元/件
```

**决策应用**：
- 若增加1件产品的边际收入为50元，则50 > 40，增加产量有利
- 若增加1件产品的边际收入为35元，则35 < 40，不应增加产量

## 机会成本计算示例

**场景**：A和B两种方案可供选择，选择了B方案

**已知数据**：选择A方案可获利10,000元

**计算**：
```
机会成本 = 10,000元（即被放弃方案A的最大潜在收益）
```

**决策分析**：
- 选择B方案的总代价 = B方案的实际成本 + 10,000元机会成本
- 需要确保B方案的收益超过其总代价

## 不同目的不同成本示例

**场景**：某企业为推广生命周期较长的产品发生广告成本100,000元

**对外财务报告目的**：
```
借：销售费用 100,000
贷：银行存款 100,000
```
（全部费用化，计入当期损益）

**内部业绩考核目的**：
```
1. 先资本化：
借：长期待摊费用 100,000
贷：银行存款 100,000

2. 按受益期摊销（假设受益期10个月）：
借：销售费用 10,000
贷：长期待摊费用 10,000
```
（资本化后摊销，更公允地衡量管理层业绩）
