# 可转换债券估值与决策

## 适用场景
- 可转换债券持有人决定是否行使转换权
- 分析可转换债券的转换价值和投资收益
- 评估回售条款和赎回条款的影响
- 发行人设计可转换债券条款

## 转换价值计算

### 基础计算公式
```
转换价值 = 当前股票市场价格 × 转换比率
```

### 未来价值预测
```
转换价值(t) = 当前股价 × (1 + 年增长率)^t × 转换比率
```

### 计算示例
已知条件：
- 当前股票市场价格：35元/股
- 转换比率：20（每张债券可换20股股票）
- 年增长率：6%
- 转换价格：50元（=面值1000/转换比率20）

**零时点（发行日）计算：**
转换价值 = 35 × 20 = 700元

**未来时点计算（复利增长）：**
- 第5年：转换价值 = 700 × (1.06)^5 = 936.76元
- 第10年：转换价值 = 700 × (1.06)^10 = 1,253.56元
- 第20年：转换价值 = 700 × (1.06)^20 = 2,244.99元

### 投资者行为逻辑
- **即时转换决策**：在零时点，转换价值（700元）< 纯债券价值（850.61元），投资者不会为取得700元转换价值而放弃债券部分价值
- **等待策略**：投资者会继续持有债券，寄希望于股价增长，使未来转换价值超过纯债券价值
- **转换时机**：当转换价值 > 纯债券价值时，理性投资者会选择转换

### 底线价值确定
```
可转换债券的底线价值 = max(纯债券价值, 转换价值)
```

## 转换偿还机制

### 触发条件
- 债券持有人主动行使转换权，或
- 达到债券契约中约定的强制转换条件（如股价持续高于转股价一定比例）

### 执行转换
1. 按约定的转换价格和转换比率计算应发行的普通股股数
2. 公式：可转换股数 = 债券面值 / 转换价格（或按约定比率）
3. 注销债券持有人持有的债券
4. 向其发行相应数量的本公司普通股股票

### 完成偿还
债券持有人身份转变为公司股东，债券债务关系终止，视为已通过普通股偿还债券。

## 回售条款分析

### 触发条件
- 发行公司股票价格达到条款约定程度
- 处于回售时间窗口

### 权利行使
当条件满足时，债券持有人有权（但非必须）按照约定的回售价格将可转换债券卖回给发行公司。

### 条款要素
- **回售时间**：规定可以行使回售权的具体时间段
- **回售价格**：约定买回债券的具体价格水平

### 保护机制目的
- 核心目标：保护债券投资者的利益
- 风险缓释：使投资者能够避免遭受过大的投资损失
- 降低投资者面临的下行风险
- 使投资者具有安全感
- 有利于吸引投资者参与认购

## 赎回条款与投资者决策

### 赎回保护期
债券设有赎回保护期（如10年），在此期间发行者不可以赎回债券，投资者享有转换权的独占期。

### 赎回条件触发
保护期结束后，发行人获得赎回权，有权以约定价格（如1050元）赎回债券。

### 投资者决策比较

#### 决策时点价值评估
- **纯债券价值**：基于预期现金流折现
- **转换价值**：基于当前股价 × 转换比率
- **底线价值**：Max(纯债券价值, 转换价值)

#### 决策比较
- **发行人赎回报价**：约定价格现金
- **投资者可选方案**：
  - 方案A（接受赎回）：获得现金，投资结束
  - 方案B（转换为股）：获得价值等于转换价值的普通股

#### 最优决策判定
```
若 转换价值 > 赎回价格：立即转换
若 转换价值 < 赎回价格：接受赎回
```

### 一般化决策规则
- 若转换价值 > 赎回价格：立即转换
- 若转换价值 < 赎回价格：接受赎回

**注意**：发行人通常仅在转换价值持续高于赎回价格一段时间后才行使赎回权，以强制投资者转换，减少利息支出。

## 执行步骤

### 转换价值分析
1. 确定当前股票市场价格和转换比率
2. 计算当前转换价值
3. 预测未来转换价值（基于预期增长率）
4. 比较转换价值与纯债券价值

### 投资决策
1. 检查是否处于赎回保护期
2. 如发行人行使赎回权，比较转换价值与赎回价格
3. 根据比较结果选择转换或接受赎回
4. 评估回售条款是否触发

### 条款设计（发行人视角）
1. 设定合理的转换价格和转换比率
2. 设计赎回保护期和赎回价格
3. 设计回售条款的时间和价格
4. 平衡发行成本与投资者吸引力
