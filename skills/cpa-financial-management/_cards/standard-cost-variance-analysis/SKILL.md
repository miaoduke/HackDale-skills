# 标准成本差异分析

## 使用场景
当企业需要：
- 分析实际成本与标准成本的差异
- 评估各部门的成本控制业绩
- 识别成本超支或节约的原因
- 进行成本控制和绩效评价

## 差异计算通用规则

### 结果判读
- **正数**：表示超支，属于不利差异，标记为 "U" (Unfavorable)
- **负数**：表示节约，属于有利差异，标记为 "F" (Favorable)

### 验算原则
各分项差异之和必须等于总差异，用于验证计算正确性。

## 直接材料成本差异分析

### 计算步骤

**1. 计算直接材料成本总差异**
```
直接材料成本差异 = 实际成本 - 标准成本
实际成本 = 实际数量 × 实际价格
标准成本 = 标准数量 × 标准价格
```

**2. 分解为价格差异（价差）**
```
直接材料价格差异 = 实际数量 × (实际价格 - 标准价格)
```

**3. 分解为数量差异（量差）**
```
直接材料数量差异 = (实际数量 - 标准数量) × 标准价格
```

**4. 验算**
```
直接材料成本差异 = 直接材料价格差异 + 直接材料数量差异
```

### 责任归属

**价格差异**：
- **责任部门**：采购部门
- **形成环节**：材料采购过程中
- **常见原因**：
  - 供应厂家调整售价
  - 未批量进货（丧失数量折扣）
  - 未能及时订货造成的紧急订货
  - 采购时舍近求远使运费和途耗增加
  - 使用不必要的快速运输方式
  - 违反合同被罚款
  - 承接紧急订货造成额外采购

**数量差异**：
- **默认责任部门**：生产部门
- **形成环节**：材料耗用过程中
- **生产部门可控原因**：
  - 工人操作疏忽造成废品或废料增加
  - 操作技术改进而节省材料（有利差异）
  - 新工人上岗造成用料增多
  - 机器或工具不适造成用料增加
- **例外情况**（非生产部门责任）：
  - 购入材料质量低劣或规格不符 → 采购部门或供应商
  - 工艺变更导致用量变化 → 技术部门或工艺设计部门
  - 检验过严使数量差异加大 → 质量检验部门

## 直接人工成本差异分析

### 计算步骤

**1. 数据整理**
- 计算实际工资率 = 实际工资总额 ÷ 实际工时
- 计算标准总工时 = 实际产量 × 单位标准工时

**2. 计算工资率差异**
```
直接人工工资率差异 = 实际工时 × (实际工资率 - 标准工资率)
```

**3. 计算效率差异**
```
直接人工效率差异 = (实际工时 - 标准工时) × 标准工资率
```

**4. 计算总差异**
```
直接人工成本差异 = 实际直接人工成本 - 标准直接人工成本
```

**5. 验算**
```
直接人工成本差异 = 工资率差异 + 效率差异
```

### 责任归属
- **工资率差异**：人事部门或生产部门（取决于工资率控制权）
- **效率差异**：生产部门（与工人熟练程度、设备状况、生产组织安排相关）

## 变动制造费用差异分析

### 计算步骤

**1. 耗费差异**
```
变动制造费用耗费差异 = 实际工时 × (实际分配率 - 标准分配率)
```

**2. 效率差异**
```
变动制造费用效率差异 = (实际工时 - 标准工时) × 标准分配率
```

### 责任归属

**耗费差异**：
- **责任部门**：部门经理
- **管理要求**：将变动制造费用控制在弹性预算限额之内
- **控制重点**：每小时费用率是否超标

**效率差异**：
- **责任部门**：生产部门
- **形成原因**：与人工效率差异相似
- **管理启示**：改善工时效率可同时降低直接人工成本和变动制造费用成本

## 固定制造费用差异分析（二因素分析法）

### 差异分解
将固定制造费用差异分解为"耗费差异"和"生产能力利用差异"（简称能力差异）。

### 计算步骤

**1. 耗费差异**
```
固定制造费用耗费差异 = 固定制造费用实际数 - 固定制造费用预算数
```
- **分析逻辑**：固定费用不因业务量而变，考核时不考虑业务量的变动，以原来的预算数作为标准

**2. 能力差异**
```
固定制造费用能力差异 = (生产能力 - 实际产量标准工时) × 固定制造费用标准分配率
```
- **定义**：反映实际产量标准工时未能达到生产能力而造成的损失

**3. 总差异**
```
固定制造费用成本差异 = 实际固定制造费用 - 标准固定制造费用
```

**4. 验算**
```
固定制造费用成本差异 = 耗费差异 + 能力差异
```

## 差异分析决策树

```
IF 差异类型 = 价格/工资率/耗费差异 THEN
    检查重点 = 费率控制情况
    责任中心 = 采购/人事/部门经理
    控制工具 = 标准价格/费率制度
ELSE IF 差异类型 = 数量/效率差异 THEN
    检查重点 = 用量/工时利用效率
    责任中心 = 生产部门
    控制工具 = 标准用量/工时制度
```

## 调查要求
无论哪种差异，都需要进行具体的调查研究才能明确最终原因和责任归属，不能仅凭差异发生环节简单判定。
