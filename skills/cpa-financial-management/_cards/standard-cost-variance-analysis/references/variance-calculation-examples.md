# 标准成本差异计算示例

## 直接材料差异计算示例（例14-1）

### 已知条件
- 本月生产产品：400件
- 实际使用材料：2,500千克
- 材料实际单价：0.55元/千克
- 单位产品标准成本：3元（每件耗用6千克，每千克标准价格0.5元）
- 标准总用量 = 400 × 6 = 2,400千克

### 计算过程

**(1) 直接材料价格差异**
```
= 2,500 × (0.55 - 0.5)
= 2,500 × 0.05
= 125元 (U)
```

**(2) 直接材料数量差异**
```
= (2,500 - 2,400) × 0.5
= 100 × 0.5
= 50元 (U)
```

**(3) 直接材料成本差异**
```
= (2,500 × 0.55) - (400 × 6 × 0.5)
= 1,375 - 1,200
= 175元 (U)
```

**(4) 验算**
```
125 (U) + 50 (U) = 175 (U) ✓
```

## 直接人工差异计算示例

### 已知条件
- 实际产量：400件
- 实际工时：890小时
- 实际工资总额：4,539元
- 单位标准成本：10元/件
- 单位标准工时：2小时/件
- 标准工资率：5元/小时

### 计算过程

**步骤1：数据整理与中间计算**
- 实际工资率 = 4,539 ÷ 890 = 5.10元/小时
- 标准总工时 = 400件 × 2小时/件 = 800小时
- 标准总成本 = 400件 × 10元/件 = 4,000元

**步骤2：计算直接人工工资率差异**
```
= 890 × (5.10 - 5.00)
= 890 × 0.10
= 89元 (U)
```

**步骤3：计算直接人工效率差异**
```
= (890 - 800) × 5
= 90 × 5
= 450元 (U)
```

**步骤4：计算直接人工成本总差异（直接计算法）**
```
= 4,539 - 4,000
= 539元 (U)
```

**步骤5：验算（加总法）**
```
= 89元(U) + 450元(U)
= 539元(U) ✓
```

## 固定制造费用差异计算示例（例14-4）

### 已知条件
- 实际产量：400件
- 实际固定制造成本：1,424元
- 实际工时：890小时
- 企业生产能力：500件（即1,000小时）
- 标准成本：3元/件（标准工时2小时/件，标准分配率1.5元/小时）

### 计算过程

**(1) 耗费差异**
```
= 1,424 - (1,000 × 1.5)
= 1,424 - 1,500
= -76元 (F)
```

**(2) 能力差异**
```
= (1,000 × 1.5) - (400 × 2 × 1.5)
= 1,500 - 1,200
= 300元 (U)
```

**(3) 总差异**
```
= 1,424 - (400 × 3)
= 1,424 - 1,200
= 224元 (U)
```

**(4) 验算**
```
= -76 + 300
= 224元 (U) ✓
```
