# 差异化股权资本成本率确定

## 适用场景
- 计算经济增加值（EVA）
- 进行企业业绩考核
- 确定股权资本成本率
- 评估企业资本成本水平

## 确定流程

### 第一步：判断企业大类
- **商业类企业** → 进入第二步细分
- **公益类企业** → 股权资本成本率 = 4.5%

### 第二步：商业类企业进一步细分
- **充分竞争行业和领域的商业类企业** → 股权资本成本率 = 6.5%
- **关系国家安全、国民经济命脉的重要行业和关键领域、主要承担重大专项任务的商业类企业** → 股权资本成本率 = 5.5%

### 第三步：资产通用性调整
- 判断企业是否属于"军工、电力、农业等资产通用性较差的企业"
- 如果是 → 在上述确定的成本率基础上"下浮0.5个百分点"
  - 例：电力企业原定为5.5%，下浮后为5.5% - 0.5% = 5%

## 关键术语说明
- **"原则上"**：表示存在例外情况和调整空间
- **"下浮"**：指在原有百分比基础上减去相应数值
- **"资产通用性较差"**：指资产专用程度高，难以在不同行业间转移使用的资产特性

## 计算公式
```
股权资本成本率 = [基础利率] - [下浮调整]
```
其中：
- 基础利率根据企业类型取6.5%、5.5%或4.5%
- 下浮调整为0%或0.5%

## 输出结果
确定最终的股权资本成本率。
