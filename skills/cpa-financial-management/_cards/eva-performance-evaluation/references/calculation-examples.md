# 经济增加值计算示例

## 基础案例（例19-2）

### 已知条件
- 加权平均税前资本成本：11%
- 所得税税率：25%
- 假设无调整项目

### A部门计算
| 项目 | 数值 |
|------|------|
| 税后净营业利润 | 81,000元 |
| 平均资本占用 | 850,000元 |
| 税后资本成本 | 850,000 × 11% × (1-25%) = 70,125元 |
| **经济增加值** | **81,000 - 70,125 = 10,875元** |

### B部门计算
| 项目 | 数值 |
|------|------|
| 税后净营业利润 | 67,500元 |
| 平均资本占用 | 560,000元 |
| 税后资本成本 | 560,000 × 11% × (1-25%) = 46,200元 |
| **经济增加值** | **67,500 - 46,200 = 21,300元** |

## 投资决策应用

### 场景：B部门考虑采纳新投资项目
**项目条件**：
- 投资额：100,000元
- 每年税前获利：13,000元
- 税前投资报酬率：13%

**传统决策陷阱**：
- B部门当前税前投资报酬率 = 90,000/560,000 = 16.07%
- 新项目报酬率13% < 16.07%，部门经理可能拒绝
- 但13% > 资本成本11%，从公司角度应接受

**EVA决策验证**：
| 项目 | 计算 | 数值 |
|------|------|------|
| 新税后净营业利润 | (90,000+13,000)×75% | 77,250元 |
| 新平均资本占用 | 560,000+100,000 | 660,000元 |
| 新资本成本 | 660,000×11%×75% | 54,450元 |
| **新经济增加值** | **77,250-54,450** | **22,800元** |

**决策**：EVA从21,300元提高到22,800元，**B部门经理会接受该项目** ✓

## 减资决策应用

### 场景：B部门考虑减少现有资产
**条件**：
- 减少投资额：50,000元
- 每年减少税前获利：6,500元
- 原税前投资报酬率：13%

**EVA计算**：
| 项目 | 计算 | 数值 |
|------|------|------|
| 新税后净营业利润 | (90,000-6,500)×75% | 62,625元 |
| 新平均资本占用 | 560,000-50,000 | 510,000元 |
| 新资本成本 | 510,000×11%×75% | 42,075元 |
| **新经济增加值** | **62,625-42,075** | **20,550元** |

**决策**：EVA从21,300元降低到20,550元，**B部门经理会放弃减资方案** ✓

## 平均资本成本率计算（例20-1）

### 已知条件
- 债权资本成本率：4%（28÷700）
- 股权资本成本率：5%（电力企业5.5%下浮0.5%）
- 平均带息负债：700亿元
- 平均所有者权益：800亿元
- 本年资产负债率：52.63%
- 上年资产负债率：51.72%

### 分步计算
**第一步：计算权重**
- 总资本 = 700 + 800 = 1,500亿元
- 债务权重 = 700/1500 = 46.67%
- 权益权重 = 800/1500 = 53.33%

**第二步：计算债务成本（税后）**
```
= 4% × 46.67% × (1-25%)
= 4% × 0.4667 × 0.75
= 1.4%
```

**第三步：计算权益成本**
```
= 5% × 53.33%
= 2.67%
```

**第四步：计算WACC**
```
= 1.4% + 2.67% = 4.07%
```

**第五步：检查资产负债率调整**
- 52.63% > 51.72%（高于上年）
- 但52.63% < 65%（未达上浮阈值）
- **结论：无需调整，最终WACC = 4.07%**

### 若需调整的情形
| 情形 | 调整幅度 | 调整后WACC |
|------|---------|-----------|
| 第一档触发 | +0.2个百分点 | 4.27% |
| 第二档触发 | +0.5个百分点 | 4.57% |
