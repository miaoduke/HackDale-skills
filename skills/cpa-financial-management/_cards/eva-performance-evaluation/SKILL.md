# 经济增加值（EVA）核心计算与应用

## 适用场景
- 企业部门业绩评价
- 中央企业负责人经营业绩考核
- 国有企业价值评价
- 投资决策评估（是否接受新项目）
- 减资决策评估（是否处置现有资产）

## 核心公式

### 经济增加值计算
```
经济增加值 = 调整后税后净营业利润 - 调整后平均资本占用 × 加权平均资本成本
```

### 数值解读
| EVA结果 | 含义 |
|---------|------|
| EVA > 0 | 经营者在为企业创造价值 |
| EVA < 0 | 经营者在损毁企业价值 |
| EVA = 0 | 刚好覆盖资本成本，无超额价值 |

## 加权平均资本成本率（WACC）计算

### 核心公式
```
WACC = 债权资本成本率 × 债务权重 × (1-25%) 
     + 股权资本成本率 × 权益权重
```

其中：
- 债务权重 = 平均带息负债 / (平均带息负债 + 平均所有者权益)
- 权益权重 = 平均所有者权益 / (平均带息负债 + 平均所有者权益)
- 债务成本考虑25%税盾效应

### 资产负债率调整（如适用）
若本年资产负债率高于上年且超过阈值：
- 第一档（超阈值）：WACC + 0.2个百分点
- 第二档（显著超标）：WACC + 0.5个百分点

## 投资决策应用

### 决策规则
选择使**经济增加值增加**的项目，而非仅看投资报酬率是否高于资本成本。

### 一致性优势
EVA指标引导部门经理做出与公司总目标一致的决策，解决部门利益与公司整体利益可能冲突的问题。

## 关键政策依据
- 国务院国资委第40号令《中央企业负责人经营业绩考核办法》（2019年）
- 财政部《管理会计应用指引第602号——经济增加值法》（2017年）
- 二十届三中全会：建立国有企业履行战略使命评价制度，开展国有经济增加值核算（2024年）

## 输出结果
- 经济增加值绝对值（正值/负值）
- 投资决策建议：接受/拒绝（基于EVA变化方向）
- 减资决策建议：执行/放弃（基于EVA变化方向）
