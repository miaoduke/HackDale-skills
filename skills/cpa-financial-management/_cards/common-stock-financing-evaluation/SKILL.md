# 普通股筹资评估

## 使用场景
当企业评估普通股筹资方案，或比较普通股、债券、优先股等不同筹资方式时，使用此技能进行综合评估。

## 普通股筹资特征

### 基本定义
- 普通股是最基本的股票形式，具有表决权和剩余索取权
- 每一份股权包含对公司财产享有的平等权利

### 筹资分类
- **内部股权筹资**：留存收益的增加
- **外部股权筹资**：股本或实收资本的增加（通常伴随资本公积增加）

## 普通股筹资五大优势

1. **无固定利息负担**：
   - 有盈余且适合分配时才分给股东
   - 盈余少、资金短缺或有更好投资机会时，可少分或不分

2. **无固定到期日**：
   - 筹集的是永久性资金
   - 除非公司清算才需偿还
   - 对保证公司最低资金需求有重要意义

3. **增加公司信誉**：
   - 股本与留存收益是债务风险的缓冲地带
   - 较多自有资金为债权人提供保障
   - 提高信用价值并支持更多债务资金使用

4. **筹资限制较少**：
   - 相比优先股或债券筹资，普通股筹资限制较少
   - 不影响公司经营灵活性

5. **抗通胀与吸引力**：
   - 预期收益较高，可抵消通货膨胀影响
   - 通胀期间不动产升值时普通股随之升值
   - 更容易吸收资金

## 普通股筹资三大缺点

### 缺点一：普通股资本成本较高
**三重原因**：
1. **投资者角度**：投资于普通股风险较高（剩余索取权、收益不确定性），要求较高的投资报酬率
2. **筹资公司角度**：普通股股利来自净利润，不像债券利息那样作为费用从税前支付，不具有抵税作用
3. **发行费用角度**：普通股的发行费用一般也高于其他证券

### 缺点二：控制权分散风险
- 以普通股筹资会增加新股东
- 后果链条：增加新股东 → 可能分散公司的控制权 → 削弱原有股东对公司的控制 → 甚至增加被收购的可能

### 缺点三：信息披露成本与商业秘密保护难度（仅适用于上市公司）
- 前提条件：公司股票上市
- 要求：需要履行严格的信息披露制度，接受公众的监督
- 后果：会带来较大的信息披露成本，也增加了公司保护商业秘密的难度

## 普通股资本成本定义

### 基本定义
- 普通股资本成本是指筹集普通股所需的成本
- 是面向未来的成本，而不是过去的成本（历史成本 irrelevant）

### 筹资方式分类
1. **增发新的普通股**（外部股权融资）：涉及发行费用
2. **留存收益转增普通股**（内部融资）：将留存收益用于再投资而非分配股利

### 关键原则
- **面向未来**：关注的是新增资本的边际成本，而非已投入资本的历史成本
- **机会成本**：留存收益转增涉及的机会成本是股东本可获得的股利回报

## 决策评估流程

1. **评估资本成本承受能力**：
   - 企业能否接受高于债务融资的资本成本？
   - 税盾效应缺失的影响是否可接受？

2. **评估控制权影响**：
   - 原有股东是否愿意接受控制权稀释？
   - 是否存在被收购风险？

3. **评估信息披露负担**（如适用）：
   - 企业能否承担信息披露成本？
   - 商业秘密保护难度是否可接受？

4. **权衡优势与成本**：
   - 无固定负担、永久性资金、提升信誉的优势是否超过高成本、控制权稀释的劣势？

## 关键变量
- 资本成本：普通股投资者要求的投资报酬率
- 股利支付方式：税后净利润支付，无抵税作用
- 发行费用：普通股发行费用，通常高于债券等证券
- 新股东持股比例：增发普通股后新股东持有的股权比例
- 信息披露成本：上市公司履行信息披露制度的年度成本
- 筹资方式：增发新股或留存收益转增
