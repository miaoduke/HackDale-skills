# 现金预算编制

## 何时使用此技能

当企业进入财务预算编制阶段，需要基于营业预算和资本预算数据，预测未来各期现金流入流出，识别资金缺口或盈余，并制定相应的融资或投资计划时使用。

## 前置要求

确保以下专项预算已完成编制：
- 销售预算（提供销货现金收入数据）
- 直接材料预算、直接人工预算、制造费用预算（提供生产支出数据）
- 销售及管理费用预算（提供期间费用支出数据）
- 资本支出预算（提供设备购置等投资支出数据）
- 股利分配政策（提供股利支出数据）
- 期初现金余额数据

## 核心工作流程

### 第一步：计算可供使用现金

汇总预算期初的现金持有量和当期预计现金收入：

**计算公式：**
```
可供使用现金 = 期初现金余额 + 本期销货现金收入
```

**数据来源：**
- 期初现金余额：上一预算期期末余额
- 销货现金收入：直接取自销售预算的现金回款计划

### 第二步：汇总现金支出

整合预算期内所有预计现金支付项目：

| 支出类别 | 数据来源 | 说明 |
|---------|---------|------|
| 直接材料 | 直接材料预算 | 当期材料采购现金支出 |
| 直接人工 | 直接人工预算 | 当期人工成本现金支出 |
| 制造费用 | 制造费用预算 | 当期制造费用现金支出 |
| 销售及管理费用 | 销售及管理费用预算 | 当期期间费用现金支出 |
| 所得税费用 | 税务预算/历史数据 | 按季度或年度预计 |
| 资本性支出 | 资本支出预算 | 设备购置等长期投资支出 |
| 股利分配 | 股利政策预算 | 根据分配政策确定 |

**计算合计：** 将上述各项支出按预算期加总，得到现金支出合计。

### 第三步：确定现金多余或不足

计算可供使用现金与总支出的差额：

**计算公式：**
```
现金多余或不足 = 可供使用现金 - 现金支出合计
```

**结果解读：**
- **正值（多余）**：现金余额超出需求，可用于偿还债务或投资
- **负值（不足）**：出现资金缺口，需要筹措资金
- **零**：现金收支恰好平衡（较少见）

### 第四步：制定现金筹措与运用方案

根据第三步结果进行资金平衡操作：

**如果现金不足：**
1. 确定最低现金余额要求
2. 计算需要筹措的资金总额（缺口 + 最低余额）
3. 选择融资方式（银行借款、发行债券等）
4. 安排借款时间和期限

**如果现金多余：**
1. 优先偿还短期借款（如有）
2. 支付借款利息
3. 进行短期有价证券投资
4. 保留必要现金储备

**目标：** 确保期末现金余额满足企业最低现金持有量要求。

## 数据来源速查表

编制现金预算时，按以下对应关系从专项预算中提取数据：

- **销货现金收入** → 销售预算
- **直接材料支出** → 直接材料预算  
- **直接人工支出** → 直接人工预算
- **制造费用支出** → 制造费用预算
- **销售及管理费用支出** → 销售及管理费用预算
- **设备购置支出** → 资本支出预算
- **股利支出** → 股利分配政策/预算

## 输出成果

完成编制后，应形成包含以下要素的现金预算表：
- 各期期初现金余额
- 当期现金收入明细
- 当期现金支出明细（分类列示）
- 现金净流量（多余或不足）
- 融资活动明细（借入/偿还）
- 投资活动明细（购入/出售证券）
- 各期期末现金余额
