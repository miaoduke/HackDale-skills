# 现金预算编制详细示例

## 季度现金预算编制案例

以下示例展示如何按季度编制现金预算（单位：元）：

### 第一季度示例

**基础数据：**
- 期初现金余额：8,000
- 销货现金收入：18,200（来自销售预算）

**计算过程：**
```
可供使用现金 = 8,000 + 18,200 = 26,200
```

**现金支出明细：**
- 直接材料：5,000（来自直接材料预算表18-8）
- 直接人工：2,100（来自直接人工预算表18-9）
- 制造费用：1,900（来自制造费用预算表18-10）
- 销售及管理费用：5,000（来自销售及管理费用预算表18-12）
- 所得税费用：4,000

**支出合计：** 18,000

**现金多余或不足：**
```
26,200 - 18,000 = 8,200（多余）
```

### 第二季度示例（现金不足情况）

**基础数据：**
- 期初现金余额：8,200（上季度期末）
- 销货现金收入：26,000

**可供使用现金：** 34,200

**现金支出明细：**
- 直接材料：6,740
- 直接人工：3,100
- 制造费用：2,900
- 销售及管理费用：5,000
- 所得税费用：4,000
- 资本性支出（设备购置）：10,000（来自资本支出预算）
- 股利分配：8,000（来自股利政策）

**支出合计：** 39,140

**现金多余或不足：**
```
34,200 - 39,140 = -4,940（不足，短缺4,940元）
```

**资金筹措：**
由于出现4,940元缺口，需向银行借款（假设最低现金余额要求为6,000元，则实际需借款10,940元，通常取整为11,000元）。

### 第三季度示例（现金多余情况）

**基础数据：**
- 期初现金余额：6,000（假设借款后保持最低余额）
- 销货现金收入：36,060

**可供使用现金：** 42,060

**现金支出明细：**
- 直接材料：8,920
- 直接人工：3,960
- 制造费用：3,560
- 销售及管理费用：5,000
- 所得税费用：4,000
- 其他支出：780

**支出合计：** 24,220

**现金多余或不足：**
```
42,060 - 24,220 = 17,840（多余）
```

**资金运用：**
多余17,840元可用于：
1. 偿还第二季度银行借款11,000元
2. 支付借款利息（假设年利率10%，借款期2季度，利息约550元）
3. 剩余资金进行短期投资或保留现金

## 关键公式总结

### 基础公式
```
可供使用现金 = 期初现金余额 + 销货现金收入
现金净流量 = 可供使用现金 - 现金支出合计
期末现金余额 = 期初现金余额 + 现金净流量 + 融资流入 - 融资流出
```

### 融资决策规则
**借款金额计算：**
```
需借款金额 = 现金不足金额 + 目标最低现金余额 - 可用信贷额度（如有）
```

**还款优先级：**
1. 即将到期的短期借款
2. 高利率借款
3. 其他长期债务

### 注意事项
- 销货现金收入需考虑赊销政策（当期收现比例 vs 下期收现比例）
- 资本支出通常金额较大，需提前规划融资
- 股利分配时间通常固定在特定季度（如第二、四季度）
- 所得税费用通常按季预缴，需参考税务预算
