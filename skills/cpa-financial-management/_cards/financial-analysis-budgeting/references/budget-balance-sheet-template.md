## 财务比率分析

### 流动比率
```
流动比率 = 流动资产 / 流动负债
```
- 标准：一般大于2为佳
- 用途：衡量短期偿债能力

### 资产负债率
```
资产负债率 = 负债总额 / 资产总额 × 100%
```
- 标准：一般低于50%为佳
- 用途：衡量长期偿债能力

### 权益乘数
```
权益乘数 = 资产总额 / 股东权益
```
- 用途：衡量财务杠杆
