# ROI分解分析示例

## 基础数据
- 部门税前经营利润：100万元
- 部门销售收入：500万元
- 部门平均净经营资产：400万元

## 第一层分解
```
投资报酬率 = (100 / 400) × 100% = 25%
部门经营利润率 = 100 / 500 = 20%
投资周转率 = 500 / 400 = 1.25次

验证：20% × 1.25 = 25% ✓
```

## 第二层分解示例

### 资产端分解
```
净经营资产 400万元
├── 应收账款 100万元
├── 存货 150万元
└── 固定资产 150万元

应收账款周转率 = 500 / 100 = 5次
存货周转率 = 500 / 150 = 3.33次
固定资产周转率 = 500 / 150 = 3.33次
```

### 收支端分解
```
税前经营利润 100万元
├── 销售收入 500万元
├── 直接材料 -200万元
├── 直接人工 -100万元
├── 制造费用 -50万元
└── 销售管理费用 -50万元

毛利率 = (500 - 300) / 500 = 40%
营业利润率 = 100 / 500 = 20%
```

## 诊断结论
- 如果利润率低：检查成本控制、产品定价
- 如果周转率低：检查资产占用、存货管理、应收账款回收
