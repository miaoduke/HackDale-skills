# 资本成本在企业管理中的综合应用

## 适用场景
需要进行营运资本管理、评估企业价值、评价业绩、制定公司战略时，应用资本成本作为决策依据。

## 应用领域

### 1. 营运资本管理应用
- 利用资本成本评估营运资本投资政策和营运资本筹资政策
- **动态调整逻辑**：
  - IF (用于流动资产的资本成本提高) THEN：
    - 适当减少营运资本投资额
    - 采用相对激进的筹资政策
- **具体决策依据**：
  - 决定存货的采购批量和储存量
  - 制定销售信用政策
  - 决定是否赊购

### 2. 企业价值评估应用
- **核心方法**：主要采用现金流量折现法
- **关键参数**：必须使用公司资本成本作为公司现金流量的折现率
- **应用场景**：企业并购、重组、制定公司战略（评估战略选择对企业价值的影响）

### 3. 业绩评价应用
- **核心指标**：经济增加值 (EVA)
- **计算要求**：计算经济增加值需要使用公司资本成本
- **比较逻辑**：将资本成本（投资者要求的报酬率）与公司实际的投资报酬率进行比较以评价业绩
- **市场关联**：由于资本成本与资本市场相关，经济增加值能把业绩评价和资本市场联系在一起

### 4. 投资与筹资的纽带作用

#### 正向联系
投资决策决定了公司所需资金的数额和时间，成为筹资决策的依据。

#### 反向联系
筹资决策决定了一个公司的加权平均资本成本，加权平均资本成本又成为投资决策的依据。

#### 目标导向
为了实现股东财富最大化的目标：
- 筹资活动中寻求资本成本最小化
- 投资于报酬高于资本成本的项目并力求净现值最大化

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| capital_cost | Rate | 投资者要求的报酬率或加权平均资本成本 |
| working_capital_investment | Amount | 营运资本投资额 |
| cash_flow | Value | 公司现金流量 |
| investment_return | Rate | 公司实际投资报酬率 |
| eva | Value | 经济增加值 |

## 决策输出
根据资本成本调整营运资本策略、计算企业现值或得出经济增加值评价业绩。
