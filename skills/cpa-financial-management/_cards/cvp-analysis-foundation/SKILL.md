# 本量利分析基础

## 使用场景
- 需要进行盈亏平衡分析时
- 制定目标利润计划时
- 分析价格、成本、销量变化对利润的影响时
- 进行短期经营决策时
- 需要可视化成本-业务量-利润关系时

## 线性假设体系

本量利分析基于以下核心假设，共同构成总成本模型 y = a + bx

### 1. 固定成本不变假设
- **内容：** 在企业经营能力相关范围内，固定成本总额保持不变
- **数学表达：** 模型中的常数项 a
- **几何解释：** 与横轴平行的水平直线
- **关键限定：** 仅在相关范围内成立

### 2. 变动成本与业务量成完全线性关系假设
- **内容：** 变动成本总额与业务量成正比例关系
- **数学表达：** 模型中的 bx 项
  - b = 单位变动成本（常数）
  - x = 业务量
- **几何解释：** 过原点的直线，斜率 = b

### 3. 销售收入与销售数量成完全线性关系假设
- **内容：** 销售单价为常数，销售收入与销售数量成正比例
- **数学模型：** s = px
  - s = 销售收入
  - p = 销售单价（常数）
  - x = 销售数量
- **几何解释：** 过原点的直线，斜率 = p

### 4. 产销平衡假设
- **内容：** 假设产量等于销量，无存货变动影响
- **必要性：** 确保分析基于单一业务量变量进行
- **说明：** 本量利分析中的"量"特指销售数量

## 综合数学模型

```
总成本函数：TC = a + bx
总收入函数：TR = px
利润函数：π = TR - TC = px - (a + bx) = (p - b)x - a
         = 单位边际贡献 × 销量 - 固定成本
```

## 绘制基本本量利关系图

### 绘制步骤（以销售数量为横轴）

1. **选定坐标系：** 横轴表示销售数量，纵轴表示成本和销售收入金额

2. **绘制固定成本线F：**
   - 在纵轴上找出固定成本数值
   - 以点（0，固定成本值）为起点
   - 绘制与横轴平行的水平线

3. **绘制总成本线V：**
   - 以点（0，固定成本值）为起点
   - 以单位变动成本为斜率
   - 向右上方延伸绘制直线

4. **绘制销售收入线S：**
   - 以坐标原点（0，0）为起点
   - 以单价为斜率
   - 向右上方延伸绘制直线

### 图形解读

**盈亏临界点P：** 销售收入线与总成本线的交点
- 横轴对应销售量：盈亏临界销售量
- 含义：总收入 = 总成本，利润为零

**利润区：** 销售量 > 盈亏临界点，S和V的距离为利润值

**亏损区：** 销售量 < 盈亏临界点，总成本超过销售收入

### 正方形本量利关系图（金额表示法）

**适用场景：** 销售量使用金额而非实物量表示

**绘制特点：**
- 图形呈正方形
- 销售收入线S为从原点出发的对角线，斜率为1
- 总成本线V从点（0，固定成本值）出发，斜率为变动成本率

**多产品应用：** 使用加权平均变动成本率作为总成本线斜率

## 关键参数

- **a：** 固定成本总额
- **b：** 单位变动成本
- **p：** 销售单价
- **x：** 业务量/销售数量
- **变动成本率：** b/p，用于金额表示法
