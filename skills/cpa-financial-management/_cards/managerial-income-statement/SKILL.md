# 管理用利润表结构及净利润构成

## 适用场景
- 编制管理用利润表
- 分析净利润构成
- 区分经营损益与金融损益
- 评估企业经营与财务活动的贡献

## 核心概念

### 金融损益
金融损益是指负的税后利息费用。

### 利息费用
利息费用是指金融负债利息与金融资产收益的差额，即扣除利息收入、金融资产公允价值变动收益等以后的利息费用。

### 经营损益
经营损益是指除金融损益以外的当期损益，即税后经营净利润。

## 净利润计算公式

净利润由经营损益和金融损益构成，遵循以下关系表达式：
```
净利润 = 经营损益 + 金融损益
净利润 = 税后经营净利润 - 税后利息费用
净利润 = 税前经营利润 × (1 - 所得税税率) - 利息费用 × (1 - 所得税税率)
```

## 报表编制结构

### 经营损益部分
列示以下项目，计算得出"税前经营利润"，扣除"经营利润所得税"后，得出"税后经营净利润"：
- 营业收入
- 营业成本
- 毛利
- 税金及附加
- 销售费用
- 管理费用
- 经营资产减值损失
- 其他收益
- 经营资产处置收益
- 营业外收入
- 营业外支出

### 金融损益部分
列示"利息费用"，扣除"利息费用抵税"后，得出"税后利息费用"。

### 最终结果
```
净利润 = 税后经营净利润 - 税后利息费用
```

## 变量说明

- **税后经营净利润**：除金融损益以外的当期损益
- **税后利息费用**：金融负债利息与金融资产收益的差额扣除所得税后的金额
- **所得税税率**：企业适用的所得税税率

## 注意事项

不适用于未区分经营与金融活动的传统利润表。
