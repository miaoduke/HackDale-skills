# 边际贡献率与变动成本率计算

## 何时使用
- 需要进行产品盈利能力分析
- 比较不同产品的盈利能力
- 进行本量利分析
- 评估产品对固定成本的抵减能力
- 制定产品定价策略

## 核心概念

### 边际贡献率
- **定义**：边际贡献在销售收入中所占的百分率
- **含义**：每1元销售收入中边际贡献所占的比重，反映产品给企业作出贡献的能力

### 变动成本率
- **定义**：变动成本在销售收入中所占的百分率
- **含义**：每1元销售收入中变动成本所占的比重

## 计算公式

### 边际贡献率计算（以下公式等价）
```
边际贡献率 = (边际贡献 / 销售收入) × 100%
边际贡献率 = (单位边际贡献 × 销量) / (单价 × 销量) × 100%
边际贡献率 = 单位边际贡献 / 单价
```

### 变动成本率计算（以下公式等价）
```
变动成本率 = (变动成本 / 销售收入) × 100%
变动成本率 = (单位变动成本 × 销量) / (单价 × 销量) × 100%
变动成本率 = 单位变动成本 / 单价
```

## 两者关系

### 基本关系
```
变动成本率 + 边际贡献率 = 1
```

### 推导过程
```
(单位变动成本 / 单价) + (单位边际贡献 / 单价)
= [单位变动成本 + (单价 - 单位变动成本)] / 单价
= 1
```

### 经济含义
- 销售收入被分为两部分：变动成本（产品自身的耗费）和边际贡献（给企业作的贡献）
- 两者之和等于1，互为补数

## 应用步骤

1. **收集基础数据**：获取单价、销量、单位变动成本
2. **计算单位边际贡献**：单位边际贡献 = 单价 - 单位变动成本
3. **计算边际贡献率**：使用上述任一公式
4. **计算变动成本率**：使用上述任一公式
5. **验证关系**：检查两者之和是否等于1
6. **分析结果**：边际贡献率越高，产品盈利能力越强

## 决策参考

- 边际贡献率 > 0：产品能够抵减部分固定成本
- 边际贡献率越高：产品盈利能力越强，对企业贡献越大
- 变动成本率越高：产品自身耗费占比越大，盈利空间越小
- 多品种分析：使用加权平均边际贡献率进行综合分析
