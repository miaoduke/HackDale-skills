# 标准成本应用指南

## 标准成本的制定流程

1. **确定制定目的：**
   - 用于成本控制：选择正常可实现的标准
   - 用于潜力分析：选择理想标准成本
   - 用于趋势分析：选择基本标准成本

2. **收集基础数据：**
   - 历史成本数据
   - 技术测定数据
   - 市场价格信息
   - 生产能力数据

3. **技术测定：**
   - 材料消耗标准
   - 人工工时标准
   - 机器工时标准

4. **价格确定：**
   - 材料标准价格
   - 人工标准工资率
   - 制造费用标准分配率

5. **综合计算：**
   - 直接材料标准成本 = 标准用量 × 标准价格
   - 直接人工标准成本 = 标准工时 × 标准工资率
   - 制造费用标准成本 = 标准工时 × 标准分配率

## 标准成本的修订

**修订触发条件：**
- 生产的基本条件发生重大变化

**修订流程：**
1. 评估变化对成本的影响程度
2. 重新进行技术测定
3. 更新价格标准
4. 计算新的标准成本
5. 记录修订原因和日期

**不修订的情况：**
- 市场供求变化导致的售价波动
- 生产经营能力利用程度的正常波动
- 工作方法改进导致的效率提升
