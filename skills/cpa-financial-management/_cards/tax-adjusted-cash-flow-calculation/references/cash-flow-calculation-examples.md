# 现金流量计算示例

## 折旧抵税效应对比分析（示例5-9）

**共同基础：** 两公司全年营业收入均为20000元，付现营业费用均为10000元，所得税税率25%

**甲公司（有折旧）：**
- 折旧：3000元
- 合计费用：13000元
- 税前经营利润：7000元
- 所得税费用：1750元（7000×25%）
- 税后经营净利润：5250元
- 营业现金毛流量：5250 + 3000 = 8250元

**乙公司（无折旧）：**
- 折旧：0元
- 合计费用：10000元
- 税前经营利润：10000元
- 所得税费用：2500元（10000×25%）
- 税后经营净利润：7500元
- 营业现金毛流量：7500 + 0 = 7500元

**关键发现：** 甲公司税后经营净利润比乙公司少2250元，但现金净流入却多出750元。

**增量分析：** 由于增加了一笔3000元折旧，使应纳税所得额减少3000元，从而少纳税750元（3000×25%），企业因此获得750元的现金流入。

## 税后费用计算示例（示例5-8）

**不做广告方案：**
- 营业收入：15000元
- 成本和费用：5000元
- 税前经营利润：10000元
- 所得税费用：2500元
- 税后经营净利润：7500元

**做广告方案：**
- 营业收入：15000元
- 成本和费用：5000元
- 新增广告费：2000元
- 税前经营利润：8000元
- 所得税费用：2000元
- 税后经营净利润：6000元

**增量分析：** 两方案净利润差额为1500元（7500-6000），即该项广告的税后费用为1500元。

**公式验证：** 2000 × (1 - 25%) = 2000 × 0.75 = 1500元

## 营业现金毛流量三种方法推导

**方法二推导过程：**
```
营业现金毛流量 = 营业收入 - 付现营业费用 - 所得税
= 营业收入 - (营业费用 - 折旧) - 所得税
= 营业收入 - 营业费用 + 折旧 - 所得税
= 税前经营利润 + 折旧 - 所得税
= (税前经营利润 - 所得税) + 折旧
= 税后经营净利润 + 折旧
```

**方法三推导过程：**
```
营业现金毛流量 = 税后经营净利润 + 折旧
= (营业收入 - 营业费用)×(1-税率) + 折旧
= (营业收入 - 付现营业费用 - 折旧)×(1-税率) + 折旧
= 营业收入×(1-税率) - 付现营业费用×(1-税率) - 折旧×(1-税率) + 折旧
= 营业收入×(1-税率) - 付现营业费用×(1-税率) + 折旧×税率
```
