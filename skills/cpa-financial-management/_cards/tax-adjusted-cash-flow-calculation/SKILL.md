# 税后现金流量计算

## 适用场景
- 进行投资决策分析，需要计算项目营业期现金流量
- 评估不同折旧政策对现金流的影响
- 比较不同投资方案的现金流差异
- 资本预算中的现金流量测算
- 涉及可抵税费用的经营决策

## 核心概念

**税后费用：** 扣除所得税节约后的真实费用成本
**税后收入：** 扣除所得税后的实际现金流入
**折旧抵税：** 因计提折旧而减少的所得税金额，构成增量现金流入
**营业现金毛流量：** 营业活动产生的现金流入净额

## 计算方法

### 1. 税后费用计算

**公式：**
```
税后费用 = 费用金额 × (1 - 税率)
```

**示例：** 公司每月支付2000元广告费，企业所得税税率25%
```
税后费用 = 2000 × (1 - 25%) = 2000 × 0.75 = 1500元
```

### 2. 税后收入计算

**公式：**
```
税后收入 = 收入金额 × (1 - 税率)
```

**注意：** "收入金额"特指根据税法规定需要纳税的营业收入，不包括项目结束时收回垫支营运资本等现金流入。

### 3. 折旧抵税计算

**公式：**
```
折旧抵税 = 折旧 × 税率
```

**核心机制：** 折旧通过计入费用减少应纳税所得额，起到减少税负的作用。折旧本身不是现金流出，但通过减少所得税支付，间接产生现金流入（税盾效应）。

**示例：** 折旧3000元，税率25%
```
折旧抵税 = 3000 × 25% = 750元
```

### 4. 营业现金毛流量三种计算方法

#### 方法一：直接法（根据现金流量定义）
```
营业现金毛流量 = 营业收入 - 付现营业费用 - 所得税
```

#### 方法二：间接法（基于税后经营净利润调整）
```
营业现金毛流量 = 税后经营净利润 + 折旧
```

#### 方法三：根据所得税对收入、费用和折旧的影响计算
```
营业现金毛流量 = 税后营业收入 - 税后付现营业费用 + 折旧抵税
展开式：= 营业收入×(1-税率) - 付现营业费用×(1-税率) + 折旧×税率
```

**方法选择建议：**
- 方法三：适用于税率已知但所得税金额未知的情况
- 方法二：适用于已知会计利润的情况
- 方法一：适用于直接现金流数据完整的情况

## 执行流程

### 场景一：评估某项费用的真实成本
1. 确定费用金额
2. 确定适用的企业所得税税率
3. 计算税后费用 = 费用金额 × (1 - 税率)
4. 使用税后费用进行决策分析

### 场景二：计算项目营业现金毛流量
1. 收集基础数据：营业收入、付现营业费用、折旧、税率
2. 根据数据可得性选择合适的计算方法
3. 代入公式计算营业现金毛流量
4. 验证三种方法计算结果的一致性

### 场景三：比较不同折旧政策的现金流影响
1. 确定不同折旧政策下的折旧金额
2. 计算各自的折旧抵税 = 折旧 × 税率
3. 计算各自的营业现金毛流量
4. 比较现金流差异，选择最优方案

## 关键变量
- **费用金额：** 实际支付的可抵税费用总额
- **收入金额：** 根据税法规定需要纳税的营业收入
- **税率：** 适用的企业所得税税率
- **折旧：** 当期计提的折旧费用
- **营业收入：** 项目产生的营业收入总额
- **付现营业费用：** 需要实际支付现金的营业费用（不含折旧）
- **所得税：** 当期应缴纳的所得税费用
- **税后经营净利润：** 扣除所得税后的净利润

## 输出结果
- 税后费用金额
- 税后收入金额
- 折旧抵税金额
- 营业现金毛流量金额

## 约束条件
- 仅适用于税法允许计提折旧且折旧可抵税的情况
- 不适用于已提足折旧资产或免税期间
- 不适用于免税收入或不可抵税费用项目
- 仅适用于营业阶段现金流量计算，不适用于项目初始投资或终结点现金流量
- 假设数据为年度数据且税率稳定
