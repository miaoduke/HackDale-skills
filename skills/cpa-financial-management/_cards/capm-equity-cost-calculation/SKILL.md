# CAPM权益资本成本计算

## 何时使用

- 需要计算股东权益资本成本（必要报酬率）
- 已获得项目特定β_权益，需估算折现率
- 确定股权现金流量（FCFE）的折现率
- 计算WACC中的权益成本组成部分

## 核心公式（资本资产定价模型CAPM）

```
股东权益资本成本 = 无风险利率 + β_权益 × 市场风险溢价

Re = Rf + β × (Rm - Rf)
```

其中：**市场风险溢价 = 市场组合预期收益率(Rm) - 无风险利率(Rf)**

## 参数确定方法

| 参数 | 定义 | 确定方法 |
|-----|------|---------|
| **Rf（无风险利率）** | 资金的时间价值和通货膨胀补偿 | 采用与项目期限匹配的**长期国债到期收益率** |
| **β_权益** | 包含项目财务杠杆的权益贝塔系数 | 经项目目标资本结构调整后的贝塔（包含经营风险+财务风险） |
| **市场风险溢价(Rm-Rf)** | 系统风险的补偿 | 市场组合相对于无风险资产的超额收益 |

## 计算步骤

### 步骤1：确认β_权益已加载财务杠杆

- β_权益必须来自前一步加载财务杠杆的结果
- 该值同时包含项目的**经营风险**和**财务风险**

### 步骤2：确定无风险利率

- 选择与项目期限匹配的长期国债收益率
- 反映资金的时间价值

### 步骤3：确定市场风险溢价

- 采用市场组合预期收益率减去无风险利率
- 或采用行业通用的市场风险溢价估计值

### 步骤4：代入公式计算

```
Re = Rf + β × (Rm - Rf)
```

### 步骤5：解释结果经济含义

- 代表股东投资于该项目所要求的**最低必要报酬率**
- 反映股东承担项目系统风险所要求的补偿
- 是股权资本的**机会成本**

## 应用场景匹配

| 现金流量类型 | 折现率选择 |
|-----------|-----------|
| **股权现金流量（FCFE）** | **权益资本成本Re**（本技能计算结果） |
| 实体现金流量（FCFF） | 加权平均资本成本WACC |

## 完整示例

**已知条件**：
- 无风险利率(Rf) = 5%
- 市场风险溢价 = 8%
- 调整后β_权益 = 1.1813

**计算**：
```
股东权益资本成本 = 5% + 1.1813 × 8%
                  = 5% + 9.4504%
                  = 14.45%
```

**结论**：该项目的股东权益资本成本为14.45%，若项目预期股权回报率低于此值，则不应投资。

## 注意事项

- 仅适用于估算**权益资本成本**，不适用于债务资本成本
- β_权益必须已包含项目特定财务风险
- 必须与现金流量类型匹配：股权现金流量配权益成本，实体现金流量配WACC
- 假设资本市场有效、CAPM模型适用
