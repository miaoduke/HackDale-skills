# 短期决策成本分类

## 使用场景
- 企业进行短期经营决策分析
- 需要识别决策相关成本与无关成本
- 评估成本的可避免性和可延缓性
- 判断约束性固定成本的决策相关性

## 不可避免成本识别

### 判定条件
当同时满足以下条件时，判定为不可避免成本：
- 成本属于约束性固定成本或现有固定资产折旧
- 处于短期经营决策场景
- 生产经营能力已确定
- 生产组织机构已建立

### 识别步骤
1. **检查成本类型**：确认是否为约束性固定成本（committed fixed costs）
2. **验证前提条件**：
   - 企业的生产经营能力已经确定
   - 生产组织机构已经确定
3. **评估决策影响**：
   - 短期决策层面：该成本数额不是短期经营决策所能改变
   - 长期决策层面：长期战略决策可能改变生产经营能力
4. **区分沉没成本**：
   - 不可避免成本：可能是未来要发生的，但数额固定
   - 沉没成本：过去已经发生的

### 典型类别
- 约束性固定成本（与产能决策相关）
- 企业现有厂房、建筑物等固定资产的年折旧费
- 已确定产能相关的固定费用

### 输出结果
```
警告：该成本为不可避免成本，在短期决策中无法通过管理行动削减或改变数额，必须纳入固定成本基数考虑
```

## 不可延缓成本判定

### 判定条件
当同时满足以下条件时，判定为不可延缓成本：
- 企业面临财力有限的情况
- 存在已选定方案的组成部分
- 该成本必须在计划期间内发生
- 延迟发生将影响企业大局

### 判定流程
1. **确认方案归属**：检查该成本是否属于已选定方案的组成部分
2. **评估财务约束**：即使财力有限是否仍必须发生
3. **评估时间约束**：是否必须在当前计划期间发生（不能推迟到下期）
4. **评估影响程度**：若延迟发生是否会影响企业大局
5. **得出结论**：若步骤2-4均为"是"，则判定为不可延缓成本

### 典型实例
- 场景：企业旧厂房因暴雨冲击产生较大裂痕
- 判定：必须在计划期内进行大修，即使财力紧张也必须支出，否则会造成严重后果
- 结论：该大修费用属于不可延缓成本

### 与可延缓成本对比
- **可延缓成本**：财力紧张时可推迟到下期，不影响大局
- **不可延缓成本**：财力紧张时仍必须在当期发生，否则影响大局

### 输出结果
```
判定结果：该成本属于/不属于不可延缓成本；决策建议：必须在当期安排资金，不可推迟
```

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| cost_type | 分类 | 成本类型：约束性固定成本/酌量性固定成本 |
| capacity_status | 分类 | 生产经营能力状态：已确定/可调整 |
| decision_horizon | 分类 | 决策时间范围：短期/长期 |
| asset_ownership | 布尔 | 是否拥有现有固定资产 |
| financial_constraint | 布尔 | 企业是否面临财力有限的情况 |
| time_constraint | 字符串 | 成本发生的计划期间限制 |
| impact_level | 枚举 | 延迟发生对企业大局的影响等级 |

## 约束条件
- 仅适用于短期经营决策
- 长期战略决策可能改变生产经营能力
- 不适用于酌量性固定成本
- 假设现有产能和组织结构保持不变
