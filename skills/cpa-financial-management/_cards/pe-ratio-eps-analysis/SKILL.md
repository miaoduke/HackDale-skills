# 市盈率与每股收益分析

## 何时使用

- 评估上市公司股票估值水平
- 判断投资者对公司未来前景的预期
- 比较同行业公司估值差异
- 分析股票投资价值

## 核心公式

### 每股收益（EPS）

```
每股收益 = 归属于普通股股东净利润 ÷ 发行在外普通股加权平均股数
```

**优先股调整**：
```
每股收益 = (净利润 - 优先股股息) ÷ 发行在外普通股加权平均股数
```
注意：分子必须是归属于普通股股东的净利润，需扣除当年宣告或累积的优先股股息。

### 市盈率

```
市盈率 = 每股市价 ÷ 每股收益
```

## 市盈率类型

| 类型 | 公式 | 应用场景 |
|------|------|---------|
| 静态市盈率（本期市盈率） | 每股市价 ÷ 当期每股收益 | 使用已知的上年度每股收益 |
| 动态市盈率（内在/预期市盈率） | 每股市价 ÷ 预期每股收益 | 使用预测的下一期每股收益 |

## 指标解读

| 市盈率水平 | 市场预期 |
|-----------|---------|
| 高市盈率（20倍以上） | 投资者预期收益将从当前水平大幅增长 |
| 低市盈率（10倍以下） | 投资者预期收益将由当前水平大幅下降 |

市盈率反映投资者对公司未来前景的预期，相当于每股收益的资本化。

## 快速计算示例

**例1（无优先股）**：
- 净利润 = 136万元，股数 = 100万股，每股市价 = 36元
- 每股收益 = 136 ÷ 100 = 1.36元/股
- 市盈率 = 36 ÷ 1.36 = 26.47倍

**例2（静动态对比）**：
- 每股市价 = 20元，当期EPS = 0.4元，预期EPS = 0.5元
- 静态市盈率 = 20 ÷ 0.4 = 50倍
- 动态市盈率 = 20 ÷ 0.5 = 40倍
