# 风险管理与衍生品

## 适用场景
- 期货投机获利与风险计算
- 识别非系统风险
- 理解多样化投资的分散化效应
- 评估投资组合风险

## 期货投机获利与风险计算

### 何时使用
基于对市场价格走势的预期，为了盈利在期货市场上进行买卖行为时。

### 执行步骤
1. **设定参数**：确定现价、预期价格、卖出价格、交易数量
2. **确定操作方向**：根据预期选择买入或卖出期货合约
3. **计算盈亏**：应用盈亏计算公式
4. **情景分析**：分析不同到期市场价格下的盈亏情况

### 核心公式
```
盈利/亏损 = (卖出价格 - 到期市场价格) × 交易数量
```

### 风险特征
- 由于远期市场价格的波动性，与套期保值相反，期货的投机会增加风险
- 结果为正值表示盈利，负值表示亏损
- 绝对值大小反映风险敞口

### 计算示例（原油期货卖出）

设定参数：
- 现价：75美元/桶
- 预期价格：半年后跌至50美元/桶
- 操作：卖出100万桶半年后交割的原油期货
- 卖出价格：80美元/桶

情景分析：
- **情景A（符合预期）**：到期价50美元 → 盈利 = (80 - 50) × 1,000,000 = 3,000万美元
- **情景B（反向波动）**：到期价100美元 → 亏损 = (80 - 100) × 1,000,000 = -2,000万美元
- **情景C（极端反向）**：到期价200美元 → 亏损 = (80 - 200) × 1,000,000 = -1.2亿美元

## 非系统风险识别

### 何时使用
发生特定公司特有事件，该事件只影响一个或少数公司，且事件是非预期的、随机发生时。

### 执行步骤
1. **识别特有事件**：判断是否为个别公司特有事件
2. **评估影响范围**：确认事件只影响一个或少数公司
3. **判断可分散性**：确认事件是非预期的、随机发生的
4. **应用多样化原理**：理解通过多样化投资分散风险的机制

### 定义
非系统风险（又称特殊风险、特有风险、可分散风险）是发生于个别公司的特有事件造成的风险。

### 具体示例

**负面事件**：
- 一家公司的工人罢工
- 新产品开发失败
- 失去重要的销售合同
- 诉讼失败

**正面事件**：
- 宣告发现新矿藏
- 取得一个重要合同

### 可分散性机制
- 可以通过多样化投资来分散
- 发生于一家公司的不利事件可以被其他公司的有利事件所抵消
- 一个充分的投资组合几乎没有非系统风险

### 市场定价原则
- 假设投资者都是理智的，都会选择充分投资组合
- 非系统风险将与资本市场无关
- 市场不会对它给予任何价格补偿
- 通过分散化消除的非系统风险，几乎没有任何值得市场承认的成本

### 术语体系
- **特殊风险**：个别公司或个别资产所特有
- **特有风险**：个别公司或个别资产所特有
- **可分散风险**：可以通过投资多样化分散掉
