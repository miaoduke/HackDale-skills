# 销售百分比法财务预测

## 何时使用

- 销售增长驱动型的融资需求预测
- 编制预计财务报表（以销售收入为起点）
- 计算外部融资需求额
- 评估销售增长对资金需求的影响

## 预测步骤

### 第一步：确定预测基期

基期通常是预测工作的上一个年度。

**基期数据确定方法：**
- 若上年财务数据具有可持续性 → 以上年实际数据作为基期数据
- 若上年数据不具有可持续性 → 适当调整后作为基期数据

### 第二步：执行销售预测

销售预测是财务预测的起点。

**外部报表使用人方法（增长率法）：**
```
预测期销售收入 = 基期销售收入 × (1 + 预计销售增长率)
```

增长率预测基础：以历史增长率为起点，根据宏观经济、行业状况、企业经营战略进行修正。

### 第三步：估计经营资产与经营负债

**计算公式：**
```
各项经营资产(或负债) = 预计营业收入 × 各项目销售百分比
```

**关键假设：** 经营资产、经营负债与销售收入保持稳定的百分比关系。

### 第四步：计算融资需求

**基础公式：**
```
融资需求 = (预计经营资产合计 - 基期经营资产合计) 
         - (预计经营负债合计 - 基期经营负债合计)

简化公式：
融资需求 = 预计净经营资产总计 - 基期净经营资产总计
```

### 第五步：确定外部融资额

**融资优先顺序：**
1. 动用现存的金融资产
2. 增加留存收益
3. 增加金融负债
4. 增发股票

**调整后融资需求：**
```
外部融资需求 = 融资需求 - 可动用金融资产 - 预计留存收益增加
```

## 核心公式汇总

| 计算项目 | 公式 |
|---------|------|
| 融资需求 | 预计净经营资产 - 基期净经营资产 |
| 预计留存收益增加 | 预计营业收入 × 销售净利率 × 利润留存率 |
| 外部融资额 | 融资需求 - 可动用金融资产 - 预计留存收益增加 |

## 关键提示

- 销售预测准确性直接影响整个财务预测质量
- 假设销售百分比关系保持稳定
- 适用于经营性资产负债，不包含金融项目
