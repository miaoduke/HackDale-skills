# 外部融资销售增长比

## 计算公式

```
外部融资销售增长比 = 敏感资产销售百分比 - 敏感负债销售百分比 
                   - [(1 + 销售增长率) / 销售增长率] × 销售净利率 × (1 - 股利支付率)
```

## 应用示例

**已知条件：**
- 敏感资产销售百分比 = 66.67%
- 敏感负债销售百分比 = 6.17%
- 销售净利率 = 4.5%
- 股利支付率 = 30%

**情形1：销售增长33.33%**
```
外部融资销售增长比 = 0.6667 - 0.0617 - [(1.3333/0.3333) × 4.5% × 70%]
                   = 0.605 - (4 × 0.045 × 0.7)
                   = 0.605 - 0.126 = 47.9%

外部融资额 = 47.9% × 销售增长额 = 479万元（需外部融资）
```

**情形2：销售增长5%**
```
外部融资销售增长比 = 0.605 - [(1.05/0.05) × 4.5% × 70%]
                   = 0.605 - (21 × 0.0315)
                   = 0.605 - 0.6615 = -5.65%

外部融资额 = -5.65% × 销售增长额 = -8.475万元（资金剩余）
```

## 通货膨胀调整

当存在通货膨胀时，使用名义增长率：
```
名义增长率 = (1 + 通货膨胀率) × (1 + 销量增长率) - 1
```

示例：通胀率10%，销量增长5%
```
名义增长率 = 1.10 × 1.05 - 1 = 15.5%
```

即使销量增长为0%，仅因通胀带来的名义销售增长也需要补充资金。
