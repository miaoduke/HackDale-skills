# 特殊订单决策示例（例17-3）

## 基础数据

- 单位变动成本 = 3 + 2 + 1 = 6元
- 正常销售价格 = 10元

## 情况(1)：利用剩余产能，无专属成本

**条件：** 特殊订单单价7元，订货数量1000件

**计算：**
- 单位边际贡献 = 7 - 6 = 1元
- 订单总边际贡献 = 1 × 1000 = 1000元
- 相关成本 = 0
- 增量收益 = 1000 - 0 = 1000元

**决策：** 接受（单价7元 > 变动成本6元）

## 情况(2)：需追加专属成本

**条件：** 订货数量2000件，单价7元，专属成本1000元

**计算：**
- 订单总边际贡献 = (7 - 6) × 2000 = 2000元
- 相关成本 = 1000元
- 增量收益 = 2000 - 1000 = 1000元

**决策：** 接受（边际贡献2000 > 专属成本1000）

## 情况(3)：影响正常销售

**条件：** 订货数量500件，单价10元，需减少正常销售500件

**计算：**
- 订单边际贡献 = (10 - 6) × 500 = 2000元
- 机会成本 = 500 × (10 - 6) = 2000元
- 增量收益 = 2000 - 2000 = 0元

**决策：** 接受（边际贡献 = 机会成本）

## 情况(4)：综合场景

**条件：** 订货数量500件，单价10元，专属成本1000元，减少正常销售500件，放弃租金收入3000元

**计算：**
- 订单边际贡献 = (10 - 6) × 500 = 2000元
- 总相关成本 = 1000 + 2000 + 3000 = 6000元
- 增量收益 = 2000 - 6000 = -4000元

**决策：** 拒绝（边际贡献2500 < 总成本6000）
