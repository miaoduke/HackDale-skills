# 特殊订单接受决策

## 使用场景
- 收到特殊订单请求且订单价格低于市场价格或平均单位成本时
- 需要评估是否接受低于正常价格的订单时
- 存在剩余生产能力需要利用时
- 特殊订单可能影响正常销售时
- 需要追加专属成本才能完成订单时

## 基本决策原则

比较该订单所提供的边际贡献是否能够大于该订单所增加的相关成本。

## 执行步骤

### 1. 计算基础数据

```
单位变动成本 = 直接材料 + 直接人工 + 变动制造费用
单位边际贡献 = 特殊订单单价 - 单位变动成本
订单总边际贡献 = 单位边际贡献 × 订货数量
```

### 2. 识别并计算相关成本

根据具体场景选择适用逻辑：

**场景一：利用剩余生产能力，无需专属成本，产能不可转移**
- 相关成本 = 0
- 判定规则：只要特殊订单单价 > 单位变动成本，就可以接受

**场景二：需追加专属成本（其余条件同场景一）**
- 相关成本 = 追加的专属成本
- 判定规则：订单边际贡献 > 追加的专属成本

**场景三：剩余生产能力可以转移（其余条件同场景一）**
- 相关成本 = 转移剩余生产能力的可能收益（机会成本）
- 判定规则：特殊订单边际贡献 > 机会成本

**场景四：影响正常销售（剩余产能不足）**
- 相关成本 = 减少的正常销售量所带来的边际贡献（机会成本）
- 判定规则：特殊订单边际贡献 > 机会成本

**综合场景（多种因素叠加）：**
```
总相关成本 = 专属成本 + 减少正常销售的机会成本 + 放弃租金收入的机会成本等
```

### 3. 计算增量收益并决策

```
增量收益 = 订单总边际贡献 - 总相关成本
```

**决策标准：**
- 增量收益 > 0：接受订单
- 增量收益 ≤ 0：拒绝订单

## 关键变量

- **Unit_Variable_Cost：** 单位变动成本（直接材料+直接人工+变动制造费用）
- **Special_Order_Price：** 特殊订单单价
- **Order_Quantity：** 特殊订单订货数量
- **Specific_Cost：** 为完成特殊订单需追加的专属成本
- **Opportunity_Cost_Transfer：** 剩余生产能力转移可获得的收益
- **Opportunity_Cost_Lost_Sales：** 因接受特殊订单而减少正常销售所损失的边际贡献

## 约束条件
- 不适用于长期定价策略
- 假设固定成本在短期内保持不变

## 输出结果
- 决策建议（接受/拒绝）
- 增量利润金额
- 各项相关成本明细
