# 租赁分析示例

## 折现率确定示例

### 场景：大型设备租赁

**租赁方案：**
- 租赁期限：5年
- 年租赁费：100万元
- 设备公允价值：400万元
- 预计期末余值：50万元

**折现率确定：**
1. 租赁费折现率：有担保债券税后利率 5%
2. 折旧抵税额折现率：6%（略高于5%）
3. 期末资产余值折现率：WACC 10%

**现金流量折现：**
```
租赁费现值 = 100 × (P/A, 5%, 5) = 100 × 4.3295 = 432.95万元
折旧抵税额现值 = (计税基础/5 × 25%) × (P/A, 6%, 5)
期末余值现值 = 50 × (P/F, 10%, 5) = 50 × 0.6209 = 31.05万元
```

### 场景：小型设备租赁（简化方法）

**租赁方案：**
- 租赁期限：3年
- 年租赁费：10万元

**折现率确定：**
统一使用有担保债券税后利率 5%

**现金流量折现：**
```
租赁费现值 = 10 × (P/A, 5%, 3) = 10 × 2.7232 = 27.23万元
```

## 计税基础计算示例

### 情况一：合同约定付款总额

**租赁合同：**
- 约定付款总额：500万元
- 签订合同相关费用：5万元

**计税基础：**
```
计税基础 = 500 + 5 = 505万元
年折旧额 = 505 ÷ 5 = 101万元
年折旧抵税额 = 101 × 25% = 25.25万元
```

### 情况二：合同未约定付款总额

**租赁合同：**
- 未约定付款总额
- 资产公允价值：480万元
- 签订合同相关费用：5万元

**计税基础：**
```
计税基础 = 480 + 5 = 485万元
年折旧额 = 485 ÷ 5 = 97万元
年折旧抵税额 = 97 × 25% = 24.25万元
```

## 租赁vs购买决策分析

### 购买方案现金流量
- 初始投资：-400万元
- 年折旧抵税：+25万元
- 期末余值：+50万元

### 租赁方案现金流量
- 年租赁费：-100万元
- 租赁费抵税：+25万元
- 机会成本（放弃余值）：-50万元

### 净现值比较
```
购买方案NPV = -400 + 25×(P/A,10%,5) + 50×(P/F,10%,5)
租赁方案NPV = -75×(P/A,5%,5) - 50×(P/F,10%,5)
```

选择NPV较大的方案。

## 风险调整说明

### 保守估计调整

**折旧抵税额保守估计：**
- 假设应税所得不足，折现率提高1-2%
- 或按可实现抵税额的80%计算

**期末余值保守估计：**
- 按预计余值的70-80%计算
- 或使用更高的折现率（如12%代替10%）
