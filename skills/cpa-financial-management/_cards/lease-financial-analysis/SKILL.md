# 租赁财务分析

## 使用场景
当需要计算租赁净现值、比较租赁与购买方案、确定租赁资产税务处理时使用此技能。

## 租赁现金流量折现率确定

### 三类现金流量及折现率

| 现金流量类型 | 风险特征 | 折现率 |
|-------------|---------|--------|
| 租赁费 | 类似债券还本付息，不确定性很低 | 有担保债券税后利率 |
| 折旧抵税额 | 风险比租赁费大（应税所得不足、税率变化） | 略高于有担保债券税后利率 |
| 期末资产余值 | 经营风险大于借款风险 | 加权平均资本成本（WACC） |

### 风险排序
```
租赁费风险 < 折旧抵税额风险 < 期末资产余值风险
```

### 折现率选择决策

**精确方法（租赁金额巨大时）：**
- 租赁费：有担保债券税后利率
- 折旧抵税额：略高于有担保债券税后利率
- 期末资产余值：WACC

**简化方法（实务常用）：**
- 统一使用有担保债券税后利率
- 对高风险现金流量进行保守估计调整

### 理论依据

**租赁费：**
- 租赁资产是租赁筹资的担保物
- 租赁费现金流量和有担保借款在经济上等价

**折旧抵税额：**
- 假设全部折旧抵税额均有足够应税所得
- 假设适用税率将来不会变化
- 实际存在不确定性

**期末资产余值：**
- 受市场条件、技术变革、资产物理损耗影响
- 持有资产的经营风险大于借款风险

## 租赁税务处理

### 基本原则
- 税法不考虑货币时间价值，按实际支付款项计税
- 会计处理与税收法规不一致时，遵循税收法规

### 融资租赁费用扣除规则
以融资租赁方式租入固定资产发生的租赁费支出，按照规定构成融资租入固定资产价值的部分应当提取折旧费用，分期扣除。

### 融资租入固定资产计税基础

**情况一（合同约定付款总额）：**
```
计税基础 = 租赁合同约定的付款总额 + 签订合同过程中发生的相关费用
```

**情况二（合同未约定付款总额）：**
```
计税基础 = 该资产的公允价值 + 签订合同过程中发生的相关费用
```

### 利息支出扣除
企业在生产经营活动中发生的利息支出（包括非金融企业向金融企业借款的利息支出），准予扣除。

## 分析流程

### 第一步：识别现金流量类型
- 租赁费（定期支付）
- 折旧抵税额（基于计税基础）
- 期末资产余值（残值）

### 第二步：确定折现率
- 判断租赁金额是否巨大
- 选择精确方法或简化方法
- 确定各类现金流量的折现率

### 第三步：计算计税基础
- 检查合同是否约定付款总额
- 应用相应公式计算计税基础
- 确定折旧抵税额

### 第四步：计算净现值
- 折现各类现金流量
- 汇总计算租赁方案净现值
- 与购买方案比较

## 关键要点

1. **风险匹配：** 不同现金流量风险不同，应使用不同折现率
2. **实务简化：** 除非金额巨大，通常统一使用有担保债券税后利率
3. **税务优先：** 会计与税法不一致时，遵循税法规定
4. **计税基础：** 根据合同约定情况选择计算方法
