# 亏损产品停产决策（边际贡献分析法）

## 何时使用
- 某产品或部门出现账面亏损（息税前利润为负）
- 决策场景为短期经营决策
- 需要评估是否停产亏损产品
- 多产品企业的产品线优化

## 核心决策原则

### 关键判断指标
```
边际贡献 = 销售收入 - 变动成本
```

### 决策规则
在短期内，如果亏损产品能够提供正的边际贡献，就不应该立即停产。

## 决策分析步骤

### 步骤1：计算各产品的边际贡献
```
边际贡献 = 销售收入 - 变动成本
```

**判断标准**：
- 边际贡献 > 0：该产品对固定成本有抵减作用
- 边际贡献 ≤ 0：该产品不仅亏损，还会加剧整体亏损

### 步骤2：分析固定成本的可避免性（短期假设）
- 短期内，即使停产某产品，固定成本也不会相应降低
- 固定成本总额保持不变，将在剩余产品之间重新分摊或全部由剩余产品承担

### 步骤3：比较停产前后的企业整体息税前利润

**停产前整体息税前利润**：
```
= 所有产品边际贡献之和 - 固定成本总额
```

**停产后整体息税前利润**：
```
= 剩余产品边际贡献之和 - 固定成本总额（不变）
```

### 步骤4：做出决策

- 若亏损产品边际贡献 > 0：继续生产（因其能抵减部分固定成本，停产会使整体利润更差）
- 若亏损产品边际贡献 ≤ 0：考虑停产（因其无法抵减任何固定成本，每生产一件都在扩大亏损）

## 关键原理解释

"为什么会出现这种现象呢？原因在于乙产品虽然亏损，但是提供的边际贡献仍然为正。乙产品如果继续生产，其边际贡献能够抵减固定成本，但是如果停产，则连这部分固定成本也无法抵减，因此会造成息税前利润的下降。"

## 常见误区警示

### 误区
以"息税前利润为负"作为停产依据

### 正解
应以"边际贡献是否为正"作为短期决策依据

### 账面亏损的原因
可能是固定成本分摊过高，而非产品本身无盈利能力

## 关键变量

- **销售收入**：产品的营业收入
- **变动成本**：随产量变动的成本，属于相关成本
- **边际贡献**：销售收入减去变动成本，衡量产品弥补固定成本的能力
- **固定成本**：短期内不随产量变动的成本，停产决策中视为不可避免成本
- **息税前利润**：边际贡献减去固定成本，账面利润指标

## 注意事项

- 仅适用于短期决策（固定成本在短期内不可消除）
- 假设停产某产品后，其专属固定成本不会自动消失
- 不考虑长期战略因素（如市场份额、客户关联购买等）
- 长期决策需考虑固定成本的可避免性
