# 股利留存与筹资决策

## 使用场景
当企业满足以下条件时使用此技能：
- 企业实现净利润，有可供分配的利润
- 需要确定股利分配方案或利润留存比例
- 需要评估内部筹资能力与外部融资需求的平衡
- 需要协调股利政策与资本结构决策

## 核心概念
股利分配决策具有双重属性：
1. **分配属性**：决定当期净利润中多少分配给股东作为现金股利
2. **筹资属性**：决定当期净利润中多少留存作为内部权益资本

留存收益筹资与发行新股在经济效果上等价，都是增加公司权益资本，但前者无需发行费用，不稀释股权。

## 决策流程

### 步骤1：评估投资需求
- 识别未来期间NPV>0的投资项目
- 计算投资项目的资金需求总额
- 评估内部现金流（含折旧等非现金支出）的再投资能力

### 步骤2：确定资金缺口
```
资金缺口 = 投资需求 - 内部可用现金流
```

### 步骤3：计算最小留存额
- 为满足资金缺口，需要留存的最小利润额
- 考虑目标资本结构中权益资本的比例要求

### 步骤4：确定股利支付方案
- 考虑股东对现金收入vs资本增值的偏好
- 评估税收差异（股利税vs资本利得税）
- 考虑信号传递效应
- 确定股利支付率（0%-100%）或具体金额

### 步骤5：执行决策
- 董事会提议
- 股东大会批准
- 宣告并发放股利（或决定留存）

## 关键变量

| 变量 | 类型 | 说明 |
|------|------|------|
| 净利润 | 财务指标 | 当期可供分配的税后利润 |
| 留存比例 | 决策变量 | 不分配给股东而留存的利润比例（0-100%） |
| 股利支付率 | 决策变量 | 分配给股东的利润占净利润的比例（0-100%） |
| 内部筹资额 | 资本金额 | 通过利润留存实现的权益资本增加额 |

## 计算公式
```
内部筹资额 = 净利润 × 留存比例
股利支付额 = 净利润 × 股利支付率
留存比例 + 股利支付率 = 1
```

## 决策考量因素
- **筹资需求侧**：投资机会越多，应提高留存比例
- **股东需求侧**：考虑股东对当期收入和资本增值的偏好
- **法律约束**：必须按公司法规定提取法定公积金后才能分配
- **契约约束**：债务契约可能规定最低留存收益或最高股利支付率
- **信号效应**：股利变化传递公司前景信号

## 输出结果
1. 确定的利润留存比例和股利支付方案
2. 计算的内部筹资额
3. 对资本结构、未来投资能力和股东价值的影响评估
4. 会计处理建议

## 约束条件
- 亏损企业无利润可留存时不适用
- 必须遵守公司法关于利润分配顺序和公积金提取的强制性规定
- 受债务契约中对股利支付的限制条款约束
