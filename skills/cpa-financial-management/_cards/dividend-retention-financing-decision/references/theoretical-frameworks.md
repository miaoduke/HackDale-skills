# 股利政策理论框架

## 信号传递理论
- 股利增加 → 传递管理层对未来盈利有信心的信号
- 股利减少 → 可能传递财务困难信号
- 留存比例变化 → 市场会解读为公司投资机会变化

## 代理成本理论
- 高股利支付率 → 减少自由现金流，降低管理层过度投资风险
- 低股利支付率 → 增加内部资金，降低外部融资的代理成本

## 税收偏好理论
- 股利税 vs 资本利得税差异影响股东偏好
- 高税率股东偏好资本增值（低股利）
- 低税率股东偏好当期收入（高股利）

## 客户效应理论
- 不同类型的投资者偏好不同的股利政策
- 公司应维持稳定的股利政策以吸引目标投资者群体

## 剩余股利政策
```
步骤：
1. 确定最优资本结构
2. 计算投资所需的权益资本
3. 尽可能使用留存收益满足权益资本需求
4. 剩余利润作为股利分配
```
