# 利润留存筹资的会计处理

## 基本会计分录

### 利润分配时
```
借：利润分配——未分配利润
    贷：应付股利（分配部分）
    贷：盈余公积（提取部分）
```

### 留存收益确认时
```
借：利润分配——未分配利润
    贷：留存收益（权益资本增加）
```

## 利润分配顺序（公司法规定）
1. 弥补以前年度亏损
2. 提取法定公积金（净利润的10%）
3. 提取任意公积金（股东会决议）
4. 支付普通股股利

## 与外部筹资的对比

| 特征 | 留存收益筹资 | 发行新股筹资 |
|------|-------------|-------------|
| 发行费用 | 无 | 有 |
| 股权稀释 | 无 | 有 |
| 筹资速度 | 快 | 慢 |
| 资本成本 | 隐性（股东机会成本） | 显性（发行费用+股利） |
| 市场信号 | 中性或正面 | 可能传递负面信号 |
