# 管理用资产负债表项目分类

将传统财务报表转换为管理用财务报表，区分经营活动与金融活动的资产负债占用。

## 适用场景

- 编制管理用资产负债表
- 计算净经营资产(NOA)和净金融负债(NFD)
- 分析企业经营性资本占用与金融性资本结构
- 进行改进的杜邦分析(管理用财务分析体系)

## 前置检查

确认已完成：
- [ ] 企业经营活动与金融活动的界定
- [ ] 明确货币资金的处理方式(全部经营/按比例划分/最低运营现金为经营)

## 分类执行流程

### 步骤1：资产分类判定

**判定标准**：
- **经营资产**：销售商品或提供劳务所涉及的资产
- **金融资产**：利用经营活动多余资金进行投资所涉及的资产

**执行动作**：
遍历资产负债表资产项目，按以下规则归类：

| 类别 | 典型项目 | 判定要点 |
|------|---------|---------|
| 经营性流动资产 | 货币资金、应收票据、应收账款、预付款项、存货 | 与主营业务循环直接相关 |
| 经营性长期资产 | 长期股权投资、固定资产、在建工程、无形资产、商誉 | 支撑主营业务运营 |
| 金融资产 | 交易性金融资产、其他债权投资、其他权益工具投资 | 闲置资金的投资运用 |

**特殊处理**：
- 其他应收款：需拆分，应收利息/应收股利为金融，其余为经营
- 货币资金：根据企业实际，通常假设为经营所需(除非明确为投资闲置资金)

### 步骤2：负债分类判定

**判定标准**：
- **经营负债**：销售商品或提供劳务所涉及的负债(自发负债)
- **金融负债**：筹资活动所涉及的负债(有息负债)

**执行动作**：
遍历资产负债表负债项目，按以下规则归类：

| 类别 | 典型项目 | 判定要点 |
|------|---------|---------|
| 经营性流动负债 | 应付票据、应付账款、预收款项、应付职工薪酬、应交税费 | 经营过程中自发形成 |
| 经营性长期负债 | 长期应付款(经营性质)、预计负债、递延所得税负债 | 与经营相关的长期义务 |
| 金融负债 | 短期借款、长期借款、应付债券、交易性金融负债 | 主动筹资形成，通常有利息 |

**特殊处理**：
- 其他应付款：需拆分，应付利息/应付股利为金融，其余为经营
- 一年内到期的非流动负债：通常为金融负债(源于长期借款或债券)

### 步骤3：计算净经营资产与净负债

**计算公式**：
```
净经营资产 = 经营资产 - 经营负债
           = (经营性流动资产 - 经营性流动负债) + (经营性长期资产 - 经营性长期负债)
           = 经营营运资本 + 净经营性长期资产

净金融负债 = 金融负债 - 金融资产
```

## 输出格式

生成管理用资产负债表结构：

**左侧：净经营资产**
- 经营营运资本(经营性流动资产 - 经营性流动负债)
- 净经营性长期资产(经营性长期资产 - 经营性长期负债)

**右侧：净金融负债与股东权益**
- 净金融负债(金融负债 - 金融资产)
- 股东权益

## 常见难点处理

1. **货币资金**：若企业无明确投资性现金，通常全部归为经营资产；若有大量闲置资金用于理财，应按比例拆分
2. **长期股权投资**：对子公司/联营企业投资通常归为经营资产(视为经营延伸)，对非关联企业财务投资归为金融资产
3. **应收股利/利息**：属于金融资产投资的回报，归为金融资产
4. **递延所得税**：通常与经营相关，归为经营资产/负债

## 验证检查

分类完成后验证：
- [ ] 资产总计 = 经营资产 + 金融资产
- [ ] 负债总计 = 经营负债 + 金融负债
- [ ] 净经营资产 = 净金融负债 + 股东权益 (恒等式必须成立)
