# 管理用资产负债表分类详细案例

## ABC公司案例详解

### 原始资产负债表数据(节选)

**资产端：**
- 货币资金：100万
- 应收票据：50万
- 应收账款：200万
- 预付款项：30万
- 其他应收款：40万(其中应收利息5万，应收股利3万)
- 存货：300万
- 一年内到期的非流动资产：20万
- 其他流动资产：10万
- 长期应收款：50万
- 长期股权投资：150万
- 固定资产：500万
- 在建工程：80万
- 无形资产：100万
- 开发支出：20万
- 商誉：30万
- 长期待摊费用：15万
- 递延所得税资产：25万
- 其他非流动资产：10万
- 交易性金融资产：60万
- 其他债权投资：40万
- 其他权益工具投资：30万
- 投资性房地产：80万

**负债端：**
- 短期借款：120万
- 交易性金融负债：10万
- 应付票据：80万
- 应付账款：250万
- 预收款项：60万
- 应付职工薪酬：40万
- 应交税费：30万
- 其他应付款：50万(其中应付利息8万，应付股利12万)
- 其他流动负债：20万
- 长期应付款：30万(经营租赁形成)
- 预计负债：25万
- 递延所得税负债：15万
- 其他非流动负债：10万
- 一年内到期的非流动负债：40万(长期借款到期)
- 长期借款：200万
- 应付债券：100万

### 分类结果

**经营资产：**
- 经营性流动资产：100+50+200+30+(40-5-3)+300+20+10 = 742万
  - 注：其他应收款扣除应收利息5万、应收股利3万
- 经营性长期资产：50+150+500+80+100+20+30+15+25+10 = 980万
- **经营资产合计：1,722万**

**金融资产：**
- 60+40+30+80 = 210万
- 注：包含投资性房地产(赚取租金或资本增值)
- **金融资产合计：210万**

**经营负债：**
- 经营性流动负债：80+250+60+40+30+(50-8-12)+20 = 510万
  - 注：其他应付款扣除应付利息8万、应付股利12万
- 经营性长期负债：30+25+15+10 = 80万
- **经营负债合计：590万**

**金融负债：**
- 120+10+8+12+40+200+100 = 490万
- **金融负债合计：490万**

### 管理用资产负债表编制

**净经营资产：**
- 经营营运资本 = 742 - 510 = 232万
- 净经营性长期资产 = 980 - 80 = 900万
- **净经营资产总计：1,132万**

**净金融负债与权益：**
- 净金融负债 = 490 - 210 = 280万
- 股东权益(原表)：852万
- **总计：1,132万** (验证平衡)

## 边缘案例处理

### 案例1：财务公司模式
若企业为集团财务公司，资金集中管理：
- **货币资金**：需区分运营必需现金(经营)与资金池归集用于放贷的资金(金融)
- **发放贷款及垫款**：金融资产的典型代表

### 案例2：房地产企业
- **投资性房地产**：若为主营业务(出租+出售)，归为经营资产；若为闲置资金投资，归为金融资产
- **开发成本/开发产品**：经营资产

### 案例3：金融机构特殊处理
银行、保险公司不适用此分类体系，需使用金融行业专用报表格式。

## 常见错误警示

1. **混淆其他应收/应付款**：必须拆分其中的利息、股利部分
2. **长期股权投资误判**：对合并范围内子公司投资通常为经营资产，但财务性投资为金融资产
3. **递延所得税处理**：通常与经营相关，除非明确源于金融资产负债的暂时性差异
4. **应付债券**： always 金融负债，不可因用于"经营性项目"而误判
