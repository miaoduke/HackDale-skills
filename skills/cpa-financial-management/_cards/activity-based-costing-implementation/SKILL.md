# 作业成本法实施

## 使用场景
当企业需要：
- 提高产品成本准确性，解决传统成本法的成本扭曲问题
- 基于因果关系而非单一产量动因分配间接费用
- 分析和控制作业层面的成本
- 为复杂产品或小批量产品提供精确成本信息

## 核心原则

### 因果关系原则
资源成本动因和作业成本动因必须与成本之间存在因果关系，不能随意选择。无因果关系的动因会导致成本信息失真。

### 成本分配优先级
按以下优先顺序执行成本分配：
1. **追溯**（最准确）：通过实地观察直接追溯到具体产品
2. **动因分配**（次优）：使用资源动因或作业动因进行分配
3. **分摊**（最后手段）：使用产量等标准强制分摊

## 实施步骤

### 步骤1：识别作业
确认企业生产经营过程中的各项具体活动。

### 步骤2：建立作业成本库
按作业成本动因将作业归入四级成本库：
- **单位级作业成本库**：随产量变动
- **批次级作业成本库**：随批次数量变动，与批内产量无关
- **品种级（产品级）作业成本库**：随产品品种变动
- **设施级（生产维持级）作业成本库**：维持生产能力

### 步骤3：选择成本动因
根据常用动因对照表选择具有因果关系的动因：

| 作业 | 资源成本动因 |
|------|-------------|
| 机器运行作业 | 机器小时 |
| 安装作业 | 安装小时 |
| 清洁作业 | 平方米 |
| 材料移动作业 | 搬运次数、搬运距离、吨千米 |
| 人事管理作业 | 雇员人数、工作时间 |
| 能源消耗 | 电表、流量表、装机功率和运行时间 |
| 制作订单作业 | 订单数量 |
| 顾客服务作业 | 服务电话次数、服务产品品种数、服务时间 |

### 步骤4：确定作业成本构成
判断资源成本能否直接追溯到特定作业：
- **直接计入成本**：能直接追溯，准确性高
- **间接计入成本**：需分配计入，需选择合适的分配标准

### 步骤5：选择分配率类型

**选项A：实际分配率**
- 公式：实际分配率 = 实际作业成本 / 实际作业动因量
- 优点：反映真实成本
- 缺点：需等待期末数据，时效性差

**选项B：预算（计划）分配率**
- 公式：预算分配率 = 预算作业成本 / 预算作业动因量
- 优点：支持日常及时核算
- 缺点：需处理成本差异

### 步骤6：处理成本差异（如使用预算分配率）

**方法A：直接结转法**
- 将成本差异总额直接结转计入本期营业成本
- 适用于差异较小或要求简化处理

**方法B：差异分配法**
- 计算差异率并分配给有关产品
- 适用于差异较大且需要准确产品成本

### 步骤7：特殊场景处理

**强度动因应用**（特殊订单、新产品试制）：
1. 为特定对象建立独立的产品订单或工作单
2. 详细记录实际耗用的全部资源
3. 单独归集作业成本
4. 直接计入特定产品，不进行二次分配

**批次级作业分配**：
1. 单独归集批次级作业成本
2. 计算单位批次成本 = 批次级作业总成本 / 总批次数量
3. 分配给具体批次
4. 在批内产品间分摊：单位产品批次成本 = 该批次总成本 / 该批次产品数量

## 关键控制点

- 优先选择与资源消耗有强因果关系的动因
- 当强因果关系动因数据不可获取时，选择代理动因
- 避免选择与资源消耗无因果关系的动因
- 尽可能扩大追溯到个别产品的成本比例
- 批次级作业必须严格区分批次与单位，避免错误分配
