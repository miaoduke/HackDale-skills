# 预算差异分析示例

## 基础数据

假设：
- 预算业务量：1,000单位
- 实际业务量：1,100单位
- 预算单价：180元/单位
- 实际收入：194,200元

## 作业量差异计算

### 收入作业量差异

弹性预算收入 = 180 × 1,100 = 198,000元
固定预算收入 = 180 × 1,000 = 180,000元
收入作业量差异 = 198,000 - 180,000 = 18,000元（F）

### 费用作业量差异（以工资为例）

工资成本公式：65,000 + 37q
弹性预算工资 = 65,000 + 37 × 1,100 = 105,700元
固定预算工资 = 65,000 + 37 × 1,000 = 102,000元
工资作业量差异 = 105,700 - 102,000 = 3,700元（U）

### 经营净利润作业量差异

弹性预算经营净利润 = 30,510元
固定预算经营净利润 = 16,800元
经营净利润作业量差异 = 30,510 - 16,800 = 13,710元（F）

## 收入差异计算

弹性预算收入 = 180 × 1,100 = 198,000元
实际收入 = 194,200元
收入差异 = 194,200 - 198,000 = -3,800元（U）

验证：实际平均售价 = 194,200 ÷ 1,100 = 176.55元/单位
低于预算单价180元，产生不利差异

## 支出差异计算

### 工资费用（混合成本：65,000 + 37q）

实际成本 = 106,900元
弹性预算 = 65,000 + 37 × 1,100 = 105,700元
支出差异 = 106,900 - 105,700 = 1,200元（U）

### 材料费用（变动成本：5.6q）

实际成本 = 8,490元
弹性预算 = 5.6 × 1,100 = 6,160元
支出差异 = 8,490 - 6,160 = 2,330元（U）

### 水电费（混合成本：1,500 + 0.1q）

实际成本 = 1,550元
弹性预算 = 1,500 + 0.1 × 1,100 = 1,610元
支出差异 = 1,550 - 1,610 = -60元 = 60元（F）

### 租金（固定成本）

实际成本 = 28,500元
弹性预算 = 28,500元
支出差异 = 0元

### 保险费（固定成本）

实际成本 = 25,400元
弹性预算 = 24,100元
支出差异 = 25,400 - 24,100 = 1,300元（U）

### 总支出差异

实际费用合计 = 172,970元
弹性预算费用合计 = 167,490元
总支出差异 = 172,970 - 167,490 = 5,480元（U）

## 差异汇总验证

收入差异（3,800元U）+ 总支出差异（5,480元U）= 9,280元（U）

即实际经营净利润（21,230元）比弹性预算经营净利润（30,510元）少9,280元。
