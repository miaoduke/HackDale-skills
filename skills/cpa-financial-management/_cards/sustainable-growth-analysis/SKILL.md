# 可持续增长率分析

## 何时使用

- 评估企业增长策略是否可持续
- 判断实际增长与可持续增长的差异原因
- 制定平衡增长的财务政策
- 分析财务比率变化对增长能力的影响
- 预警超常增长后的增长下降风险

## 核心概念

**可持续增长率**：在不增发新股或回购股票的情况下，企业当前经营效率和财务政策决定的未来内在增长能力。

**核心公式：**
```
可持续增长率 = 权益净利率 × 利润留存率
             = 销售净利率 × 总资产周转率 × 权益乘数 × 利润留存率
```

## 增长状态判定规则

### 规则1：均衡增长状态

**触发条件：** 四个财务比率均保持不变，且不增发新股

**数学关系：**
```
本年实际增长率 = 上年可持续增长率 = 本年可持续增长率
```

**财务机制：**
- 股东权益按可持续增长率增长
- 负债按相同比例增加（资本结构不变）
- 总资产增加支持销售额同比例增长

**可持续性：** 可永远持续发展（前提是产品能为市场接受）

### 规则2：超常增长状态

**触发条件：** 四个财务比率有一个或多个提高，且不增发新股

**数学关系：**
```
本年实际增长率 > 上年可持续增长率
本年可持续增长率 > 上年可持续增长率
```

**关键限制：** 超常增长是"改变"财务比率的结果，不可能每年持续提高财务比率，因此超常增长**不可持续**。

### 规则3：增长下降状态

**触发条件：** 四个财务比率有一个或多个下降，且不增发新股

**数学关系：**
```
本年实际增长率 < 上年可持续增长率
本年可持续增长率 < 上年可持续增长率
```

**本质特征：** 超常增长后的必然结果，需事先有所准备。若勉强冲刺，现金周转危机很快来临。

### 规则4：极限突破状态

**触发条件：** 四个财务比率已达企业极限

**解决方案：** 只有通过增发新股增加资金，才能满足更高销售增长率对资金的需求。

## 平衡增长模式

**定义：** 保持目前的资本结构，按照股东权益内源融资的增长率增加借款，以此支持销售增长。

**操作机制：**
1. 计算股东权益内源融资增长率
2. 按相同比例增加借款（维持负债/权益比率不变）
3. 总资本增量决定可持续的销售增长率上限

**双重优势：**
- 不增加财务风险（资本结构不变）
- 一般不消耗公司财务资源（资金需求与来源同步内生增长）

## 分析应用

通过比较实际增长率和可持续增长率，检查四个财务比率中哪些发生变化，识别增长状态的驱动因素和风险。
