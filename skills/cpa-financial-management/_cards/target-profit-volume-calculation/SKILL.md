# 保利量计算

## 何时使用
- 需要确定为实现既定目标利润必须达到的销售量
- 制定销售目标和经营计划
- 编制利润预算
- 进行利润规划和业绩目标设定
- 评估目标利润的可行性

## 基本原理

在单价和成本水平一定的情况下，计算为确保预先制定的目标利润可以实现而必须达到的销售量。

## 计算公式

### 场景一：无企业所得税

**目标利润定义**：目标税前经营利润，或以目标息税前利润代替

**基础关系公式**：
```
目标利润 = 单价 × 销量 - 单位变动成本 × 销量 - 固定成本
```

**保利量计算公式**：
```
保利量 = (固定成本 + 目标利润) / (单价 - 单位变动成本)
```

**替代公式（使用单位边际贡献）**：
```
保利量 = (固定成本 + 目标利润) / 单位边际贡献
```

### 场景二：存在企业所得税

**目标利润定义**：目标税后利润（目标税后经营净利润，或以目标息前税后利润代替）

**基础关系公式**：
```
税后目标利润 = (单价 × 销量 - 单位变动成本 × 销量 - 固定成本) × (1 - 企业所得税税率)
```

**保利量计算公式**：
```
保利量 = [固定成本 + (税后目标利润 / (1 - 企业所得税税率))] / (单价 - 单位变动成本)
```

**替代公式（使用单位边际贡献）**：
```
保利量 = [固定成本 + (税后目标利润 / (1 - 企业所得税税率))] / 单位边际贡献
```

## 计算步骤

1. **确定目标利润类型**：明确是税前目标利润还是税后目标利润
2. **收集基础数据**：单价、单位变动成本、固定成本
3. **如涉及税后利润**：获取企业所得税税率，将税后目标利润转换为税前目标利润
4. **计算单位边际贡献**：单位边际贡献 = 单价 - 单位变动成本
5. **应用相应公式**：根据场景选择公式计算保利量
6. **验证结果**：检查计算结果是否合理

## 应用场景

- **销售目标制定**：根据目标利润倒推必须完成的销售量
- **利润规划**：评估不同销售量下的利润水平
- **预算编制**：为销售预算提供量化依据
- **业绩考核**：设定销售部门的业绩目标
- **可行性分析**：评估目标利润是否可实现

## 注意事项

- 假设单价和成本水平保持一定
- 不适用于多品种混合销售（除非转换为统一标准）
- 区分税前和税后两种计算模式
- 实际应用中需考虑市场容量和竞争环境
