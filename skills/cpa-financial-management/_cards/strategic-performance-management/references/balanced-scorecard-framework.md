# 平衡计分卡四个方面

## 典型四维度框架

1. **财务维度**
   - 滞后指标：收入增长、利润率、ROI
   - 驱动因素：客户满意度、运营效率

2. **客户维度**
   - 滞后指标：客户满意度、市场份额、客户保留率
   - 驱动因素：产品质量、服务响应时间

3. **内部流程维度**
   - 滞后指标：流程周期时间、质量合格率
   - 驱动因素：员工技能、流程优化

4. **学习与成长维度**
   - 滞后指标：员工满意度、员工保留率
   - 驱动因素：培训投入、信息系统支持

## 因果关系链示例

```
员工培训投入增加 → 员工技能提升 → 流程效率改善 → 客户满意度提高 → 客户忠诚度提升 → 收入增长 → 股东价值增加
```

## 业绩评价层级关系

```
企业业绩
  ↑ 制约
部门业绩
  ↑ 制约
个人业绩
```

**相互影响**：
- 个人业绩决定部门业绩
- 部门业绩决定企业业绩
- 企业目标制约部门目标
- 部门目标制约个人目标
