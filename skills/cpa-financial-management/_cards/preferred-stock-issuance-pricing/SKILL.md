# 优先股发行定价与税收分析

## 何时使用

- 上市公司计划发行优先股
- 确定发行价格底线和票面股息率
- 分析优先股筹资的税收影响
- 评估优先股股息率的市场均衡定价

## 第一部分：发行价格与股息率确定

### 基本规则

| 项目 | 规则 |
|-----|------|
| 票面金额 | **固定为100元** |
| 发行价格底线 | **不得低于票面金额**（即≥100元） |
| 一般原则 | 发行价格和票面股息率应当公允、合理 |

### 定价方式

**情形A：公开发行**
- 价格或票面股息率以**市场询价**或证监会认可的其他公开方式确定

**情形B：非公开发行**
- 票面股息率**不得高于**最近两个会计年度的**年均加权平均净资产收益率**

### 计算步骤

1. 确定发行方式（公开/非公开）
2. 若为非公开：计算最近两年年均加权平均净资产收益率
3. 确定票面股息率上限
4. 设定具体发行价格和股息率

## 第二部分：税收不对称性与市场均衡

### 税收劣势（发行公司端）

分类为**权益工具**的优先股：
- 股利支付**不可在企业所得税前扣除**
- 与债券利息对比：债券利息可税前扣除，具有税盾效应

```
发行优先股的税后成本 = 优先股股息率（无税盾）
债券税后成本 = 债券利率 × (1 - 企业所得税率)
```

### 税收优势（投资者端）

- 投资者购买优先股所获股利通常**享受免税待遇**
- 与债券利息对比：债券利息收入通常需缴纳个人所得税
- 投资者可接受较低的税前回报率（因税后实际收益更高）

### 市场均衡机制

**条件**：发行端的税收劣势与投资者端的税收优势完全抵销

**结果**：优先股股息率 ≈ 债券利率（名义利率趋于一致）

**机制解释**：
- 公司因无税盾愿意支付更高股息（抬高股息率）
- 投资者因免税愿意接受较低税前回报（压低要求回报率）
- 两者力量平衡时，市场股息率等于债券利率

**不完全抵销情形**：
若抵销不完全，优先股股息率将偏离债券利率，偏离方向取决于税收制度对发行方和投资方的相对影响强度。

## 适用范围说明

| 情形 | 税收分析适用性 |
|-----|-----------|
| 权益工具分类的优先股 | 适用（发行端不可扣除，投资端免税） |
| 债务工具分类的优先股 | 不适用（利息可税前扣除） |
| 机构投资者为主 | 需调整（机构投资者税收政策不同） |

## 关键约束

- 不得损害股东或其他利益相关方的合法利益
- 在建工程必须符合主业规定方可扣除
- 假设投资者为个人投资者（享受股利免税）
