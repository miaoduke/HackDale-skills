# 典型案例分析

## 案例1：某制造企业生产线剥离

**背景**：A公司拟出售一条专用生产线

**分析过程**：
1. **部分类型识别**：可单独存在（物理上可拆除搬迁）
2. **整体内价值**：该生产线年产100万件，贡献毛利3000万，与其他产线共享质检、物流系统
3. **单独价值评估**：
   - 设备重置成本：8000万
   - 二手市场交易价：5000万（专用性强，买方有限）
4. **双向价值损失**：
   - 剩余企业：需重建产能或外包，年增成本800万
   - 被剥离部分：脱离原供应链体系，投产调试成本增加

**结论**：账面价值8000万的生产线，实际剥离净收益远低于5000万售价

## 案例2：事业部独立核算改造

**背景**：B集团将销售部门改为独立子公司，按市场价结算

**问题**：改造后销售子公司"利润"大增，但集团整体利润下降

**根因分析**：
| 改造前 | 改造后 |
|--------|--------|
| 销售部门作为成本中心，专注市场开拓 | 销售子公司追求自身利润最大化 |
| 无条件配合新品推广 | 要求新品支付更高推广费 |
| 与生产部门信息共享 | 信息壁垒增加，协同效率下降 |

**依赖性原理应用**：销售职能在原整体中承担"战略配合"功能，独立后功能异化为"利润最大化"

## 案例3：并购中的商誉估值争议

**背景**：C公司收购D公司，D公司账面净资产2亿，收购价8亿，产生商誉6亿

**争议焦点**：商誉是否可单独辨认？能否分拆出售？

**分析**：
- 商誉6亿 = 客户资源（2亿）+ 技术团队（2亿）+ 品牌溢价（1.5亿）+ 预期协同（0.5亿）
- 客户资源：脱离D公司后，客户关系难以维系
- 技术团队：核心人员可能流失
- 品牌溢价：需持续投入维持
- 预期协同：依赖C公司整合能力

**结论**：6亿商誉完全不可单独存在，任何"分拆出售商誉"的方案均违背依赖性原理

## 案例4：房地产企业项目公司剥离

**背景**：E集团拟出售某城市项目公司（含土地储备+在建项目+当地团队）

**特殊考量**：
- 土地：可单独交易，但规划指标与集团整体战略相关
- 在建项目：工程承包关系、预售合同具有企业专属性
- 当地团队：与集团品牌、管理体系深度绑定

**估值陷阱**：简单加总"土地市场价+在建工程成本+团队重置成本"，忽视：
1. 脱离集团品牌后，预售价格需折价
2. 团队脱离管理体系后效率下降
3. 集团失去该区域战略布局节点

## 案例5：连锁企业单店出售

**背景**：F餐饮集团出售某盈利门店

**表面分析**：该店年净利润100万，按10倍PE估值1000万

**依赖性原理深入分析**：
- 供应链：原由集团中央厨房统一配送，单独运营需自建供应链
- 品牌：可使用品牌3年，后续需支付特许费或更名
- 管理系统：原集团IT、培训、督导体系支撑
- 人员：核心员工与集团存在劳动关系

**调整后估值**：
```
名义价值：1000万
减：供应链重建成本（一次性）  200万
减：品牌过渡期后价值折现      300万
减：管理系统替代年成本现值      150万
减：人员重新签约风险折价        100万

调整后合理估值：250万
```
