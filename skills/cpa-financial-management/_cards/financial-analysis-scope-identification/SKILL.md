# 财务报表分析与财务预测范围界定

## 适用场景
- 启动财务分析项目时确定工作范围与方法论
- 区分历史绩效评估与未来规划预测的任务边界
- 规划财务管理章节的学习或咨询路径
- 明确财务分析项目的交付物类型（诊断报告 vs 预测模型）

## 执行步骤

### 1. 识别两大核心模块
界定本章/本项目包含的两个组成部分及其关系：

**模块A：财务报表分析（Financial Statement Analysis）**
- **分析对象**：历史财务数据（已发生的经营成果和财务状况）
- **核心方法**：比率分析、趋势分析、结构分析、杜邦分析等
- **主要目的**：评估过往经营绩效、识别财务健康状况、诊断经营问题
- **数据基础**：资产负债表、利润表、现金流量表等历史报表

**模块B：财务预测（Financial Forecasting）**
- **分析对象**：未来财务状况和经营成果（尚未发生的预期）
- **核心方法**：销售百分比法、回归分析、情景模拟、现金预算编制等
- **主要目的**：预测未来现金流、评估资金需求、支持投资决策和预算编制
- **数据特征**：基于假设和模型的预估数据

### 2. 确定分析重心与资源分配
根据业务需求选择侧重点：
- **诊断需求**（了解过去表现、评估历史业绩）→ 侧重财务报表分析
- **规划需求**（未来融资、投资决策、资源配置）→ 侧重财务预测
- **全面评估**（并购、重组、全面财务顾问）→ 两者结合，先分析后预测

### 3. 明确逻辑顺序与承接关系
- **基础先行**：财务报表分析为财务预测提供历史基准、参数依据和假设验证
- **逻辑递进**：通过分析历史趋势（增长率、周转率、利润率）建立预测假设
- **循环验证**：预测结果应与历史分析揭示的能力边界相一致

### 4. 界定项目交付物
根据选定范围明确具体工作内容：
- **仅财务分析**：财务比率计算、趋势图表、同业对比分析、财务健康诊断报告
- **仅财务预测**：销售预测、预计财务报表、资金缺口分析、敏感性分析
- **综合分析**：历史诊断 + 未来预测 + 改善建议 + 实施路径

## 约束说明
- 本界定仅包含章节框架和范围划分，不包含具体的财务分析方法或预测模型细节
- 实际执行时需结合具体行业特点和企业生命周期阶段选择适当技术

## 输出结果
- 工作范围界定（历史分析/未来预测/两者结合）
- 方法论选择建议（分析技术 vs 预测模型）
- 数据需求清单（历史报表数据 vs 未来假设参数）
- 后续工作步骤规划及交付物定义
