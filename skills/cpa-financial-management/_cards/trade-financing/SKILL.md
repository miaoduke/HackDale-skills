# 贸易融资

## 适用场景
- 外国进口商资金不足需要进口产品
- 出口商希望扩大出口并降低风险
- 安排租赁费的具体支付时间、金额和频率
- 现金流管理

## 出口信贷买方信贷

### 何时使用
外国进口商资金不足，需要进口产品（特别是大型设备），且出口商所在国银行愿意提供融资时。

### 执行步骤
1. **确认信贷对象**：确定贷款给外国进口商或进口商所在地的银行
2. **选择资金路径**：
   - 路径A：出口商所在国银行 → 外国进口商（直接贷款）
   - 路径B：出口商所在国银行 → 进口商所在地银行 → 外国进口商（转贷模式）
3. **安排资金流转**：确保进口商获得资金支付能力
4. **完成交易**：进口商支付货款，出口商实现出口

### 核心优势
- 有利于进口商迅速筹集资金，解决资金不足问题
- 进口商能够及时支付货款给出口商
- 出口商能够及时收汇，降低应收账款风险
- 出口商扩大出口

### 运作效果
通过向进口方提供直接融资支持，消除了进口商资金瓶颈对出口交易的阻碍，实现双赢。

### 适用特点
特别适合资金不足但有进口需求的进口商，以及希望快速收汇、降低风险的出口商。

## 租赁费支付安排

### 何时使用
需要安排或解读租赁费的具体支付时间、金额和频率时。

### 执行步骤
1. **确定支付时间点**：选择期初（预付年金）或期末（普通年金）
2. **确定支付频率**：选择年、半年、季度、月等
3. **确定支付金额**：选择等额支付或不等额支付
4. **安排利息支付**：确定各期等额支付或随本金递减
5. **安排手续费支付**：选择开始日一次支付或分期等额支付
6. **协商确认**：双方协商一致，签订合约

### 五个维度安排

#### 维度一：支付时间点
1. **预付年金（期初支付）**
   - 定义：分期的期初等额系列付款
   - 特点：第一笔在签约时就要支付
   - 常见频率：每月或每半年支付一笔等额租赁费

2. **普通年金（期末支付）**
   - 定义：每期期末支付租赁费
   - 适用场景：承租人希望延后现金流出

#### 维度二：支付金额
1. **标准形式**：各期支付额相等（等额支付）
2. **调整形式**：各期支付额不等
   - 调整原因：根据承租人要求，匹配实际经营需要
   - 典型例子：设备使用第一年需要调试，第一年安排较低租赁费，甚至约定免租期

#### 维度三：利息支付方式
1. 各期等额支付利息
2. 根据各期期初负债余额计算并支付（随本金减少而递减）

#### 维度四：手续费支付方式
1. 租赁开始日一次支付（最常见）
2. 分期等额支付（减轻初期负担）

#### 维度五：支付频率
- 可选：年、半年、季度、月、日等
- 实务惯例：通常每月或每半年支付

### 协商原则
所有支付安排均为"双方可以灵活安排，是协商一致的产物，没有统一的标准"。

### 典型方案
期初预付 + 月付/半年付 + 等额为主 + 首年可调整
