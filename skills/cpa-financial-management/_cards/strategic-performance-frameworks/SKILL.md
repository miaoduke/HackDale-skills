# 战略绩效评价框架

## 适用场景
- 企业需要构建三维绩效评价体系
- 企业旨在处理与利益相关者的关系以实现可持续发展
- 企业需要构建或完善业绩评价体系
- 需要平衡财务与非财务指标

## 绩效柱模型

### 何时使用
企业需要构建三维绩效评价体系，或旨在处理与利益相关者的关系以实现可持续发展时。

### 执行步骤
1. **识别利益相关者**：清楚知道企业重要的利益相关者是谁
2. **了解利益相关者需求**：明确他们想得到什么
3. **制定企业战略**：据此制定战略，通过实施战略将价值传递给利益相关者
4. **设计业务流程**：确定能够有效发出命令和执行命令的业务流程
5. **评估组织能力**：确定企业具有能够保证流程顺畅运行的能力
6. **获取利益相关者贡献**：获取利益相关者对企业的贡献

### 五个关键构面

#### 利益相关者满意构面
- **目标**：解决"谁是企业的主要利益相关者，他们的愿望和要求是什么"的问题
- **定位**：模型的出发点

#### 企业战略构面
- **目标**：解决"企业应该采用什么战略来满足利益相关者需求，同时也满足企业自己要求"的问题
- **定位**：满足利益相关者需求的手段

#### 业务流程构面
- **目标**：解决"企业需要哪些关键业务流程才能执行战略"的问题
- **定位**：执行战略的关键路径

#### 组织能力构面
- **目标**：解决"企业需要哪些能力才能开展和改善企业业务流程"的问题
- **定位**：保证流程顺畅运行的基础

#### 利益相关者贡献构面
- **目标**：解决"为了培育和发展组织能力，企业需要利益相关者为企业作出哪些贡献"的问题
- **定位**：模型的落脚点

### 核心逻辑链条（可持续发展路径）
1. 知道企业重要的利益相关者是谁，以及他们想得到什么
2. 据此制定战略，将价值传递给利益相关者
3. 必须具有能够有效发出命令和执行命令的业务流程
4. 必须有能力保证流程的顺畅运行
5. 必须获取利益相关者对企业的贡献

## 平衡计分卡

### 何时使用
企业需要构建或完善业绩评价体系，或需要平衡财务与非财务指标时。

### 执行步骤
1. **定义内部业务流程维度**：
   - 明确企业自身的核心竞争力
   - 遴选出对顾客满意度有最大影响的业务流程
   - 将这些流程转化为具体的测评指标
2. **定义学习与成长维度**：
   - 根据经营环境和利润增长点的差异，确定不同的指标
   - 关注创新类、员工类、资本准备度类指标
3. **理解集成逻辑**：建立企业目标与业绩指标之间的"因果关系链"
4. **应用平衡定义**：确保四个维度的平衡

### 四个维度

#### 内部业务流程维度
- **目标**：解决"我们的优势是什么"的问题
- **前提**：企业必须以合理流畅的内部业务流程为前提
- **常用指标**：交货及时率、生产负荷率、产品合格率等

#### 学习与成长维度
- **目标**：解决"我们是否能继续提高并创造价值"的问题
- **价值创造逻辑**：持续开发新产品 → 为客户创造更多价值 → 打入新市场 → 赢得顾客满意 → 增加股东价值
- **常用指标**：
  - 创新类：新产品开发周期
  - 员工类：员工满意度、员工保持率、员工生产率、培训计划完成率
  - 资本准备度类：人力资本准备度、信息资本准备度、组织资本准备度

### 平衡计分卡的"平衡"
1. **外部与内部评价的平衡**：外部（股东、客户评价）与内部（内部经营过程、新技术学习）
2. **成果与驱动因素的平衡**：成果（利润、市场占有率）与驱动因素（新产品投资开发）
3. **财务与非财务评价的平衡**：财务（利润）与非财务（员工忠诚度、客户满意程度）
4. **短期与长期评价的平衡**：短期（利润指标）与长期（员工培训成本、研发费用）

### 集成逻辑
- 与传统系统的区别：平衡计分卡各组成部分以集成方式设计
- 因果关系：企业现在的努力与未来的前景之间存在"因果"关系
- 管理价值：管理者能看到影响整体目标的关键因素，确保实际业绩与长期战略一致
