# 短缺成本分析

## 使用场景
当企业评估流动资产投资水平，需要了解降低投资可能带来的成本时，使用此技能进行短缺成本分析。

## 触发条件
IF (流动资产投资不足) THEN (发生短缺成本)

## 短缺成本定义
短缺成本是指随着流动资产投资水平降低而增加的成本。

## 现金短缺的具体表现与成本

### 1. 出售有价证券
- 需要承担交易成本

### 2. 紧急借款
- 若出售有价证券不足以解决问题
- 需紧急借款并承担较高的利息

### 3. 违约
- 若借不到足够的款项
- 需承担违约成本

### 4. 紧急抛售存货
- 被迫紧急抛售存货
- 承担低价出售损失

## 存货短缺的具体表现与成本

### 1. 生产中断
- 打乱原有生产进程
- 导致停工待料

### 2. 生产调整
- 需要重新调整生产
- 承担生产准备成本

### 3. 紧急订货
- 需要紧急订货
- 承担较高的交易成本

### 4. 销售损失
- 若不能及时补充存货
- 会失去销售机会，甚至失去客户

## 输出结果
评估因资产不足导致的各类经济损失（交易成本、利息、违约成本、生产损失等）
