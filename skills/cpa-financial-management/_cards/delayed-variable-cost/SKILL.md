# 延期变动成本

## 适用场景
- 分析成本习性
- 存在固定基数且超量按比例增长
- 人工成本分析（如加班费）
- 混合成本分析

## 基本定义
延期变动成本是指成本总额在一定业务量范围内保持稳定，超过特定业务量后随业务量增加而同比例增长的成本。

## 识别与分析流程

### 步骤1：定义识别
识别成本总额在一定业务量范围内保持稳定。

### 步骤2：阈值判定
确定"特定业务量"作为临界点（即正常业务量水平）。

### 步骤3：分段行为分析

**低于阈值（业务量 ≤ 特定业务量）**
- 成本总额保持不变
- 表现为**固定成本**
- 例如：正常业务量情况下给员工支付固定月工资

**高于阈值（业务量 > 特定业务量）**
- 超出部分成本随业务量增加而同比例增长
- 表现为**变动成本**
- 例如：业务量超过正常水平后需支付的加班费

### 步骤4：综合定性
该成本在临界点以下表现为固定成本，超过这一业务量则成为半变动成本。

## 计算公式
```
总成本 = 固定基数 + (超出业务量 × 单位变动成本)
```

## 典型示例
员工固定工资 + 加班费
- 正常工作时间内：固定工资
- 超过正常工作时间：加班费（按小时计算）

## 变量说明
- 业务量：企业实际发生的经营业务量
- 特定业务量：成本总额保持稳定的临界点（正常业务量）
- 成本总额：在特定业务量下固定，超量后增长的总成本

## 决策输出
计算出的总成本 = 固定基数 + (超出业务量 × 单位变动成本)
