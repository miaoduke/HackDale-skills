# WACC计算详细示例

## 目标资本结构权重法计算示例（ABC公司）

### 步骤1：确定目标权重
- 债务权重 w_d = 40%
- 优先股权重 w_p = 10%
- 普通股权重 w_e = 50%

### 步骤2：确定各要素资本成本
- 新债务税后资本成本 r_d_after_tax = 3.9%
- 新优先股资本成本 r_p = 8.2%
- 新普通股资本成本 r_e = 11.8%

### 步骤3：计算WACC
```
WACC = (40% × 3.9%) + (10% × 8.2%) + (50% × 11.8%)
     = 1.56% + 0.82% + 5.9%
     = 8.28%
```

**经济含义**：每筹集1元新资金，综合资本成本为0.0828元

## 实际市场价值权重法计算示例（甲公司）

### 步骤1：计算长期债券税前资本成本

假设长期债券每半年的资本成本为i：
```
935.33 = 1000 × (8% ÷ 2) × (P/A, i, 8) + 1000 × (P/F, i, 8)
```

求解得：i = 5%

### 步骤2：转换为年税前资本成本
```
债券年税前资本成本 = (1 + 5%)² - 1 = 10.25%
```

### 步骤3：计算普通股资本成本（CAPM模型）
```
普通股资本成本 = 无风险利率 + β × (股票市场平均收益率 - 无风险利率)
                = 6% + 1.4 × (11% - 6%)
                = 13%
```

### 步骤4：计算实际市场价值权重
```
债券总市值 = 935.33 × 1 = 935.33万元
普通股总市值 = 600 × 10 = 6000万元

债券占比 = 935.33 / (935.33 + 6000) = 13.49%
普通股占比 = 6000 / (935.33 + 6000) = 86.51%
```

### 步骤5：计算WACC（假设企业所得税税率25%）
```
WACC = 10.25% × (1 - 25%) × 13.49% + 13% × 86.51%
     = 7.6875% × 13.49% + 13% × 86.51%
     = 1.037% + 11.246%
     = 12.29%
```

## 无税MM理论WACC推导

### 基本公式
```
r_WACC^0 = [D/(D+E)] × r_d^0 + [E/(D+E)] × r_sL^0
```

### 命题I推论
```
r_WACC^0 = r_sU^0
```

### 命题II推导过程

步骤1：从WACC公式出发
```
[D/(D+E)] × r_d^0 + [E/(D+E)] × r_sL^0 = r_sU^0
```

步骤2：两边同乘(D+E)
```
D × r_d^0 + E × r_sL^0 = (D+E) × r_sU^0
```

步骤3：展开右边
```
D × r_d^0 + E × r_sL^0 = D × r_sU^0 + E × r_sU^0
```

步骤4：移项整理
```
E × r_sL^0 = E × r_sU^0 + D × (r_sU^0 - r_d^0)
```

步骤5：两边同除以E
```
r_sL^0 = r_sU^0 + (r_sU^0 - r_d^0) × (D/E)
```

此即MM命题II，验证了理论的自洽性。

## 权衡理论 vs 优序融资理论对比

| 维度 | 权衡理论 | 优序融资理论 |
|------|---------|-------------|
| 最优资本结构 | 存在 | 不存在 |
| 理论假设 | 信息对称或半强式有效市场 | 信息不对称框架 |
| 融资行为 | 根据目标结构调整 | 遵循固定顺序 |
| 盈利企业 | 应有更多债务 | 应有更少债务 |
| 负债率变化 | 主动优化结果 | 融资需求被动反映 |
