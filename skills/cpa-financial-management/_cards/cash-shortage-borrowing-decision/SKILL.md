# 现金短缺时的银行借款决策与金额计算

## 适用场景
- 现金预算显示现金不足
- 预计期末现金余额低于企业设定的最低现金余额标准
- 短期融资决策和资金规划

## 触发条件判定
```
IF 预计期末现金余额（未融资前） < 最低现金余额要求 THEN 必须借款
```

## 借款金额计算

### 理论借款额
```
理论借款额 = 最低现金余额 + |现金不足额|
```

**目的**：既要弥补资金缺口用于支付支出，又要确保期末保留最低余额。

### 整数倍约束调整
- **约束条件**：银行要求借款金额必须是1,000元的整数倍
- **调整规则**：将理论计算结果**向上取整**至最接近的1,000元倍数（进位取整，非四舍五入）

### 计算示例
| 项目 | 数值 |
|------|------|
| 现金不足额 | 4,940元 |
| 最低现金余额要求 | 6,000元 |
| 理论借款额 | 6,000 + 4,940 = 10,940元 |
| **实际借款额（向上取整）** | **11,000元** |

**验证**：-4,940 + 11,000 = 6,060元 > 6,000元 ✓

## 借款管理约定

### 借款时点
**季度初（期初）借入**，以满足该季度整个期间的资金需求

### 期限与归还
- 原则："期初借入，期末归还，利随本清"
- 通常跨季度（如第二季度初借入，第三季度末归还，期限6个月）

### 利率
短期借款年利率（示例：10%）

## 输出结果
- 具体借款金额（已向上取整至1,000元倍数）
- 确保既能弥补资金短缺，又能满足最低现金余额要求
