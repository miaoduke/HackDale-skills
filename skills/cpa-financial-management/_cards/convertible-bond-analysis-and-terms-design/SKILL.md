# 可转换债券分析与条款设计

## 何时使用

- 分析可转换债券性质和转换参数
- 计算转换价格、转换比率
- 评估可转债筹资方案资本成本
- 优化条款设计以满足投资者回报要求

## 第一部分：转换机制与参数计算

### 可转换债券性质

- **定义**：可转换为特定公司普通股的债券
- **资产负债表影响**：转换仅为负债转换为普通股，**并不增加额外资本**（区别于认股权证）
- **权利属性**：债券持有人拥有选择权，可选择转换或继续持有债券

### 转换价格

**定义**：发行时明确规定的价格，即转换发生时投资者为取得普通股每股所支付的实际价格。

**定价标准**：转换价格通常比发行时的股价**高出20%~30%**。

### 转换比率

**公式**：
```
转换比率 = 债券面值 ÷ 转换价格
```

**示例**：债券面值1,000元，转换比率6.41
- 转换价格 = 1,000 ÷ 6.41 = 156.01元
- 含义：为取得1股股票，需放弃156.01元的债券面值

## 第二部分：筹资方案优化设计

### 确定目标资本成本区间

1. 计算税前股权资本成本上限：
   ```
   上限 = 股权资本成本 ÷ (1 - 企业所得税率)
   ```

2. 确定下限：普通债券利率

3. **目标区间**：普通债券利率 < 筹资资本成本 < 税前股权资本成本上限

### 三种修改途径

| 途径 | 调整内容 | 对投资者的影响 | 对发行人的影响 |
|-----|---------|-----------|-----------|
| 提高票面利率 | 增加年利息支付 | 提高固定收益 | 增加固定负担 |
| 提高转换比率 | 增加每张债券可转换股数 | 提高股权增值潜力 | 稀释更多股权 |
| 延长赎回保护期 | 推迟发行人有权赎回时间 | 增加选择权价值 | 增加不确定性 |

### 优化执行步骤

1. **计算当前内含报酬率**
   - 建立方程：发行价 = Σ(利息/(1+i)^t) + 转换价值/(1+i)^n
   - 求解使等式成立的内含报酬率i

2. **判断是否需要调整**
   - 若当前i < 下限（普通债券利率）→ 必须调整
   - 若当前i > 上限（税前股权成本）→ 条款过于优厚，可收紧

3. **选择调整方式**
   - 单一参数调整：优先选择对发行人成本影响最小的方式
   - 组合调整：若单一调整无法达到目标，组合使用多种方式

4. **验证调整效果**
   - 重新计算内含报酬率
   - 确认处于目标区间内

### 决策建议

- 优先选择对发行人成本影响最小的修改方式
- 权衡：提高利息增加固定负担 vs 提高转换比率稀释更多股权 vs 延长保护期增加不确定性

## 关键公式总结

| 指标 | 公式 |
|-----|------|
| 转换比率 | 债券面值 ÷ 转换价格 |
| 转换价值 | 股价 × (1+增长率)^n × 转换比率 |
| 内含报酬率 | 使未来现金流现值等于发行价的折现率 |
| 税前股权成本上限 | 股权资本成本 ÷ (1 - 税率) |
