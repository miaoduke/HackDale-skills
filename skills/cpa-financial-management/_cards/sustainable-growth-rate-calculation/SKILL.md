# 可持续增长率计算

## 适用场景
- 评估企业不增发新股情况下的最大增长能力
- 进行财务规划和增长预测
- 确定股利增长率
- 分析企业增长与财务政策的关系
- 评估企业后续期现金流量增长率

## 核心概念

### 可持续增长率定义
可持续增长率是指企业在不增发新股（或股票回购），并保持当前经营效率和财务政策不变的情况下，销售所能增长的最大比率。

### 稳定状态条件
在稳定状态下，以下等式成立：
```
实体现金流量增长率 = 股权现金流量增长率 = 营业收入增长率
```

稳定状态必须同时满足：
- 经营效率不变：净经营资产净利率保持不变
- 财务政策不变：资本结构保持不变
- 股利分配政策不变
- 不增发新股或回购股票

## 计算方法

### 方法一：基于期初股东权益计算

**公式**
```
可持续增长率 = 营业净利率 × 净经营资产周转次数 × 期初权益乘数 × 本期利润留存率
```

### 方法二：基于期末股东权益计算

**简化公式**
```
可持续增长率 = (期末权益净利率 × 本期利润留存率) ÷ (1 - 期末权益净利率 × 本期利润留存率)
```

**四因素分解公式（杜邦分析扩展）**
```
可持续增长率 = (营业净利率 × 期末总资产周转次数 × 期末总资产权益乘数 × 本期利润留存率) ÷ (1 - 营业净利率 × 期末总资产周转次数 × 期末总资产权益乘数 × 本期利润留存率)
```

其中：
- 营业净利率 = 本期净利润 ÷ 本期营业收入
- 期末总资产周转次数 = 本期营业收入 ÷ 期末总资产
- 期末总资产权益乘数 = 期末总资产 ÷ 期末股东权益
- 本期利润留存率 = 利润留存 ÷ 本期净利润

### 方法三：基于管理用财务报表计算

**根据期初股东权益计算**
```
可持续增长率 = 营业净利率 × 净经营资产周转次数 × 期初权益乘数 × 本期利润留存率
```

**根据期末股东权益计算**
```
分子部分 = 营业净利率 × 期末净经营资产周转次数 × 期末净经营资产权益乘数 × 本期利润留存率
分母部分 = 1 - 分子部分
可持续增长率 = 分子部分 ÷ 分母部分
```

## 股利增长率确定

### 可持续增长率法
当公司未来不增发新股（或股票回购），并且保持当前的经营效率和财务政策不变时：
```
股利增长率 = 期初权益预期净利率 × 预计利润留存率
```

其中：
- 预计利润留存率 = 1 - 预计股利支付率

### 隐含假设
- 利润留存率不变
- 预期新投资的权益净利率等于当前期望报酬率
- 公司不发行新股（或股票回购）

## 计算注意事项

### 假设前提
计算可持续增长率必须基于以下五个假设条件：
1. 企业营业净利率将维持基期水平
2. 企业净经营资产周转率将维持基期水平
3. 企业基期的资本结构是目标资本结构，并且打算继续维持下去
4. 企业基期的利润留存率是目标利润留存率，并且打算继续维持下去
5. 企业不愿意或者不打算增发新股（包括股票回购）

### 结果一致性验证
在相同财务数据下，期末法与期初法计算的可持续增长率结果应当一致，但计算路径和使用的权益基准不同。

### 适用性判断
如果假设与未来的状况有较大区别，则可持续增长率法不宜单独使用，需要与其他方法结合使用。
