# 金融市场与财务目标

## 适用场景
- 分析金融市场类型和金融工具属性
- 理解价格发现和资源配置机制
- 确定企业财务管理的最终目标
- 评估股东财富、股价和公司价值的关系

## 核心内容

### 1. 金融市场按期限分类

**分类标准：** 金融工具的期限

**分类规则：**

| 期限 | 市场类型 | 主要特征 | 典型工具 |
|:---|:---|:---|:---|
| ≤ 1年 | 货币市场 | 利率较低，保持流动性，满足短期资金需求 | 短期国债、大额存单、商业票据 |
| > 1年 | 资本市场 | 风险较大，利率较高，进行长期资本融通 | 股票、长期债券、长期贷款 |

**判断逻辑：**
```
IF (金融工具期限 ≤ 1年) THEN 归类为货币市场
ELSE IF (金融工具期限 > 1年) THEN 归类为资本市场
```

### 2. 价格发现与资源配置机制

**核心机制：**
1. **价格决定：** 买卖双方相互作用决定证券价格（等于要求的报酬率）
2. **筹资能力：** 公司能否筹集到资金取决于能否达到要求的报酬率
3. **资源配置：** 竞争形成的价格引导资金流向效率高的部门和企业

**信息反映功能（晴雨表）：**
- 活跃程度：反映经济繁荣和衰退
- 证券价格：反映发行公司经营状况和发展前景
- 交易信息：反映政府货币政策和财政政策效应
- 宏观信息：生成并传播经济和金融信息

### 3. 股东财富最大化目标

**核心定义：** 增加股东财富是财务管理的基本目标

**衡量标准：**
```
股东财富 = 股东权益的市场价值
股东财富增加 = 股东权益的市场价值 - 股东投资资本
```

**与股价最大化的关系：**
- **前提条件：** 资本市场有效，且股东投资资本不变
- **等价关系：** 股价上升反映财富增加，股价下跌反映财富减损
- **例外情况：** 公司与股东之间的交易（如分派股利除权）影响股价但不影响股东财富

**与公司价值最大化的关系：**
```
公司价值 = 股东权益价值 + 债务价值
```
- 若债务价值不变，公司价值增加等同于股东权益价值增加
- 若股东投资资本和债务价值均不变，公司价值最大化等同于股东财富最大化

## 决策要点
- 金融市场分类基于金融工具期限，1年为临界点
- 价格发现机制引导资源向高效率部门流动
- 股东财富最大化是教材采纳的财务管理目标
- 需区分公司与股东交易对股价和财富的不同影响
