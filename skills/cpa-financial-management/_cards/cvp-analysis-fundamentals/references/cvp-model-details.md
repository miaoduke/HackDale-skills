# 本量利分析详细说明

## 核心三要素定义

### 成本 (Cost)

按性态划分为：
- 固定成本总额（a）：在相关范围内保持不变
- 单位变动成本（b）：在相关范围内保持不变
- 总成本模型：TC = a + bx

### 业务量 (Volume)

通常指销售量（x），是驱动收入和成本变化的独立变量。

### 利润 (Profit)

指营业利润或息税前利润（P），计算公式为销售收入扣除总成本。

## 关键衍生概念

### 盈亏临界点 (Break-even Point)

当 P = 0 时的业务量，即 x = a / (p - b)

### 安全边际 (Margin of Safety)

实际销售量超过盈亏临界点销售量的差额。

### 边际贡献 (Contribution Margin)

销售收入减去变动成本后的余额，用于补偿固定成本并创造利润。

## 主要应用领域

- 盈亏平衡点测算与风险评估
- 目标利润下的销售规模预测
- 敏感性分析（分析价格、成本、销量变动对利润的影响程度）
- 经营杠杆系数计算与风险衡量
- 特殊订单定价决策、产品组合优化决策
- 预算编制与业绩评价标准制定

## 约束条件

- 仅适用于短期分析（相关范围内）
- 假设成本与收入呈线性关系
- 假设产销平衡（存货水平不变）
- 多品种情况下需假设品种结构稳定
