# 本量利分析基础框架

## 理解本量利分析

本量利分析（Cost-Volume-Profit Analysis, CVP Analysis）是研究成本、业务量（销售量）和利润之间内在依存关系的定量分析技术。

## 管理会计中的利润定义

在管理会计预算体系和本量利分析中：

- **不单独考虑财务费用预算**（利息支出、汇兑损益等融资相关费用不纳入经营预算）
- 本量利分析中的"利润"概念特指**税前经营利润**（Pre-tax Operating Profit）
- 可以使用**息税前利润（EBIT）**作为等效替代指标

这种处理保持了管理会计内部逻辑的一致性，避免融资结构差异干扰经营绩效评估。

## 基本数学模型

### 损益方程式

利润 = 销售收入 - 总成本
P = (p × x) - (a + b × x)
整理得：P = (p - b)x - a

其中：
- P = 目标利润（息税前利润）
- p = 销售单价
- x = 销售量（业务量）
- a = 固定成本总额
- b = 单位变动成本
- (p - b) = 单位边际贡献

## 模型构建步骤

### 步骤一：确立成本性态分类

研究成本和业务量之间的关系，确立成本按性态的分类：
- 固定成本：在相关范围内不随业务量变化
- 变动成本：随业务量正比例变化

### 步骤二：建立数学关系

把成本分解成固定成本和变动成本两部分后，再把收入和利润加进来，统一于一个数学模型。

### 步骤三：模型特性设定

模型中除了业务量和利润之外，其他参数（单价、单位变动成本、固定成本）应当都是常数。

## 基本假设前提

1. **相关范围假设**：分析仅限于业务量特定范围内
2. **线性关系假设**：总收入和总成本与业务量呈严格线性关系
3. **产销平衡假设**：当期生产量等于销售量
4. **成本可分解性假设**：全部运营成本可明确划分为固定成本和变动成本
5. **品种结构稳定假设**（多品种情况）：各种产品的销售比重保持不变

## 模型应用场景

- 正向应用：在业务量变动时估计其对利润的影响（What-if分析）
- 逆向应用：在目标利润变动时计算出完成目标所需要的业务量水平（目标利润规划）

## 前提条件

- 成本性态分类知识（固定成本与变动成本）
- 变动成本法基础
- 基本财务数学运算能力

## 输出结果

建立成本-业务量-利润关系的数学模型，提供盈亏平衡分析框架，支持短期经营决策的量化分析基础。
