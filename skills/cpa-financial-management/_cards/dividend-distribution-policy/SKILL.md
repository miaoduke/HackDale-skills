# 利润分配与股利政策

## 适用场景
- 制定年度利润分配及资本公积转增股本方案
- 选择并执行股利政策（剩余股利政策或固定股利支付率政策）
- 计算法定公积金提取金额及可分配利润
- 验证净利润条件及亏损弥补状态
- 编制资产负债表预算中的未分配利润项目

## 核心流程

### 1. 净利润检查与亏损弥补

**触发条件：** 公司计划发放股利前必须执行

**执行步骤：**
1. 计算累计净利润 = 当年净利润 + 以前年度未分配利润（或亏损）
2. 检查是否存在以前年度未弥补亏损
3. 若存在亏损，用当年净利润优先足额弥补（先亏先补）
4. **判定条件：** 累计净利润必须为正数且所有以前年度亏损已足额弥补
5. 若不满足条件，禁止分配；若满足条件，进入下一步骤

### 2. 法定公积金提取

**触发条件：** 公司有税后利润且计划分配股利或提取公积金

**执行步骤：**
1. 比较累计法定公积金余额与注册资本的50%
2. 若累计法定公积金 ≥ 注册资本×50%，可不再提取
3. 若累计法定公积金 < 注册资本×50%，必须按当年税后利润的10%提取
4. 提取任意公积金（可选，需股东会决议）
5. 计算可分配利润 = 税后利润 - 法定公积金 - 任意公积金

### 3. 股利政策选择与执行

#### 剩余股利政策
**适用场景：** 有着良好投资机会、追求加权平均资本成本最低的公司

**执行步骤：**
1. 设定目标资本结构（权益资本与债务资本的最佳比率）
2. 计算投资所需权益资本 = 投资所需资金 × 目标权益资本比例
3. 最大限度使用保留盈余满足投资需求
4. 计算股利分配 = 本年净利润 - 利润留存

**关键限制：**
- 财务限制：新增长期资本结构符合目标，不涉及无息负债和短期借款
- 经济限制：优先使用利润留存（成本低于增发股份）
- 法律限制：必须提取10%法定公积金

#### 固定股利支付率政策
**适用场景：** 需要体现"多盈多分、少盈少分、无盈不分"原则的公司

**执行步骤：**
1. 确定固定的股利占净利润比率
2. 计算股利额 = 净利润 × 固定股利支付率
3. 各年股利额随经营盈余波动

**风险提示：** 股利变动较大可能造成公司不稳定的感觉

### 4. 利润分配方案执行

**执行步骤：**
1. 确定计算基数：以公司现有总股数为基数
2. 执行现金红利派发：向全体股东按每10股派发X元现金
3. 执行差异化扣税逻辑（根据投资者类型适用不同税率）
4. 执行资本公积转增股本：向全体股东按每10股转增Y股
5. 确定关键时间节点：股权登记日、除权除息日、起始交易日

### 5. 未分配利润期末余额计算

**触发条件：** 编制资产负债表预算时

**计算公式：**
```
期末未分配利润 = 期初未分配利润 + 本期利润 - 本期股利
```

**执行步骤：**
1. 从期初资产负债表获取期初未分配利润余额
2. 从预计利润表获取本期预计净利润
3. 从股利分配政策或现金预算获取本期预计分配股利
4. 代入公式计算期末余额

## 关键变量
- **目标资本结构：** 权益资本与债务资本的最佳比率
- **固定股利支付率：** 长期不变的股利占净利润比例
- **累计法定公积金：** 历年已提取的法定盈余公积余额
- **注册资本：** 公司登记注册资本总额
- **期初未分配利润：** 预算期初未分配利润余额
- **本期利润：** 预算期预计实现的净利润
- **本期股利：** 预算期预计向股东分配的股利

## 输出结果
- 可分配利润金额
- 股利分配金额
- 法定公积金提取金额
- 期末未分配利润余额
- 利润分配方案执行结果（含差异化扣税）

## 注意事项
- 法定公积金累计额达到注册资本50%后可停止提取
- 提取法定公积金前不得向股东分配利润
- 当年税后利润不足以弥补以前年度亏损时，应先补亏
- 不同投资者类型适用不同的个人所得税扣缴政策
