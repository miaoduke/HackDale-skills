# 投资组合理论详解

## 协方差与相关系数

### 协方差
```
Cov(i,j) = E[(Ri - E(Ri)) × (Rj - E(Rj))]
```
- 正协方差：证券报酬率同向变动
- 负协方差：证券报酬率反向变动
- 零协方差：证券报酬率无关

### 相关系数
```
ρ(i,j) = Cov(i,j) ÷ (σi × σj)
```
- ρ = 1：完全正相关（无法分散风险）
- ρ = -1：完全负相关（可完全分散风险）
- ρ = 0：不相关

## 组合风险计算

### 两种证券组合
```
σp² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂Cov(1,2)
```
或
```
σp² = w₁²σ₁² + w₂²σ₂² + 2w₁w₂ρ(1,2)σ₁σ₂
```

### 多种证券组合
```
σp² = ΣΣwiwjCov(i,j)
```

## 分散化效应示例

### 证券A和证券B

| 证券 | 期望报酬率 | 标准差 |
|------|-----------|--------|
| A | 10% | 20% |
| B | 15% | 25% |

### 不同相关系数下的组合风险

假设等权重投资（wA = wB = 50%）

| 相关系数 | 组合标准差 | 分散化效果 |
|---------|-----------|-----------|
| ρ = 1.0 | 22.5% | 无效果 |
| ρ = 0.5 | 19.1% | 中等效果 |
| ρ = 0.0 | 16.0% | 较好效果 |
| ρ = -0.5 | 11.2% | 很好效果 |
| ρ = -1.0 | 2.5% | 完全分散 |

### 结论
相关系数越低，风险分散效果越好。

## 有效边界构建示例

### 三种证券组合

| 证券 | 期望报酬率 | 标准差 |
|------|-----------|--------|
| A | 8% | 15% |
| B | 12% | 20% |
| C | 15% | 25% |

### 机会集曲线
通过改变投资比例，计算不同组合的期望报酬率和标准差，绘制机会集曲线。

### 有效边界
从最小方差组合点到最高期望报酬率（证券C）的曲线段。

## 资本市场线（CML）

### 公式
```
E(Rp) = Rf + [E(Rm) - Rf] ÷ σm × σp
```

- E(Rp)：投资组合期望报酬率
- Rf：无风险报酬率
- E(Rm)：市场组合期望报酬率
- σm：市场组合标准差
- σp：投资组合标准差

### 斜率（风险价格）
```
斜率 = [E(Rm) - Rf] ÷ σm
```
表示单位总风险的市场风险溢价。

### 分离定理
1. 所有投资者都持有市场组合
2. 投资者根据风险偏好选择无风险资产和市场组合的比例

## 实务应用

### 投资组合构建步骤

1. **确定投资目标：** 明确风险承受能力和收益要求
2. **选择资产：** 选择相关性较低的资产
3. **确定权重：** 优化投资比例
4. **监控调整：** 定期评估和调整

### 风险分散策略

1. **跨资产类别分散：** 股票、债券、商品、房地产
2. **跨行业分散：** 不同行业、不同周期
3. **跨地域分散：** 国内、国际市场
4. **跨时间分散：** 定期投资（定投）
