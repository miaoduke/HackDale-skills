# 应收账款管理详解

## 商业竞争型应收账款管理

### 信用政策制定

**信用标准：**
- 客户信用等级评估
- 信用额度确定
- 信用期限设定

**信用条件：**
- 信用期限：30天、60天、90天
- 现金折扣：2/10，1/20，n/30

### 收账政策

**收账程序：**
1. 提醒：到期前提醒
2. 催收：到期后催收
3. 法律：必要时采取法律手段

**收账费用权衡：**
- 收账费用增加 → 坏账损失减少
- 最优点：收账费用边际收益 = 收账费用边际成本

### 应收账款监控

**账龄分析：**
| 账龄 | 金额 | 比例 |
|------|------|------|
| 0-30天 | 100万 | 50% |
| 31-60天 | 60万 | 30% |
| 61-90天 | 30万 | 15% |
| 90天以上 | 10万 | 5% |

**平均收账期：**
```
平均收账期 = 应收账款余额 ÷ 日赊销额
```

## 时间差距型应收账款

### 结算方式影响

| 结算方式 | 结算时间 | 应收账款影响 |
|---------|---------|-------------|
| 现金 | 即时 | 无 |
| 支票 | 1-3天 | 较小 |
| 银行汇票 | 3-7天 | 中等 |
| 商业汇票 | 1-6个月 | 较大 |

### 缩短时间差距的方法

1. **改进结算方式：** 使用电子支付、网银等
2. **加强催收：** 及时跟进收款进度
3. **优化流程：** 简化结算流程

## 应收账款成本

### 机会成本
```
机会成本 = 应收账款余额 × 变动成本率 × 资本成本率
```

### 管理成本
- 调查客户信用费用
- 收账费用
- 账簿记录费用

### 坏账成本
```
坏账成本 = 赊销额 × 预计坏账率
```

## 信用评估方法

### 5C评估法

1. **Character（品质）：** 客户的信誉
2. **Capacity（能力）：** 客户的偿债能力
3. **Capital（资本）：** 客户的财务实力
4. **Collateral（抵押）：** 客户提供的担保
5. **Conditions（条件）：** 外部经济环境

### 信用评分模型

```
信用评分 = Σ(权重 × 评分)
```

根据评分确定信用等级和信用额度。
