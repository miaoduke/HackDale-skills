# 杜邦分析体系应用

## 适用场景
需要评估企业综合盈利能力、进行跨公司比较、或分析企业财务结构时，应用杜邦分析体系的核心比率。

## 核心比率

### 权益净利率（Return on Equity, ROE）
- **基本特性**：
  - 具有很强的可比性：可用于不同公司之间的比较
  - 具有很强的综合性：能够综合反映企业经营成果和财务状况

## 三因素分解公式

```
权益净利率 = (净利润 / 营业收入) × (营业收入 / 总资产) × (总资产 / 股东权益)

或表示为：
权益净利率 = 营业净利率 × 总资产周转次数 × 权益乘数
```

## 三个分解指标详解

### 1. 营业净利率 = 净利润 / 营业收入
- **性质**：利润表的一种概括表示
- **作用**："净利润"与"营业收入"两者相除可以概括企业经营成果
- **提升方向**：提高净利润率或控制成本费用
- **代表维度**：盈利能力

### 2. 总资产周转次数 = 营业收入 / 总资产
- **性质**：连接利润表和资产负债表的桥梁指标
- **作用**：反映资产运营效率，衡量每单位资产创造收入的能力
- **特殊意义**：把利润表和资产负债表联系起来
- **代表维度**：运营效率

### 3. 权益乘数 = 总资产 / 股东权益
- **性质**：资产负债表的一种概括表示
- **作用**：表明资产、负债和股东权益的比例关系，可以反映企业最基本的财务状况
- **经济含义**：反映财务杠杆程度，数值越大说明负债程度越高
- **代表维度**：财务杠杆

## 核心逻辑关系
- 无论提高其中的哪个比率（营业净利率、总资产周转次数、权益乘数），权益净利率都会提高
- 三个指标分别代表：盈利能力（营业净利率）、运营效率（总资产周转次数）、财务杠杆（权益乘数）

## 综合分析功能
通过三个分解指标，权益净利率可以综合分析评价整个企业经营成果和财务状况：
- 营业净利率反映经营成果（利润表维度）
- 权益乘数反映财务状况（资产负债表维度）
- 总资产周转次数实现两个报表的联动分析

## 结果解读
权益净利率以百分比表示，数值越高说明股东权益的投资回报越高；通过三个分解指标的乘积关系，可以定位驱动ROE变化的具体因素（盈利驱动、效率驱动或杠杆驱动）。

## 市场机制
由于资本具有逐利性，总是流向投资报酬率高的行业和公司，因此各公司的权益净利率会比较接近：
- 权益净利率经常高于其他公司的企业会引来竞争者，迫使ROE回到平均水平
- 权益净利率经常低于其他公司的企业难以增获资本，会被市场驱逐，从而使留存公司的权益净利率平均水平回归正常
