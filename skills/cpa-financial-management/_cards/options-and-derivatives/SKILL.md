# 期权与衍生品

## 适用场景
- 计算标准正态分布累积概率（期权定价、假设检验）
- 评估多头看涨期权策略的损益
- 分析执行价格、到期期限对期权价值的影响
- 对比认股权证与股票看涨期权的差异

## 核心内容

### 1. 标准正态分布累积概率查表法

**适用条件：**
- 已知标准差数量d（Z值）
- d值范围在0.00至5.0之间
- 需要查找累积概率N(d)

**查表步骤：**
1. 将d值分解为整数部分和小数部分（如d=0.22，整数部分0.2，小数部分0.02）
2. 在表格第一列找到与整数部分+十分位对应的行
3. 在表格第一行找到与百分位对应的列
4. 行列交叉处的数值即为N(d)

**对称性处理：**
- 对于负d值，使用N(-d) = 1 - N(d)转换

**插值处理：**
- 若d值有千分位，可在相邻两列间线性插值

### 2. 多头看涨期权策略

**执行决策逻辑：**
```
IF (股票市价 > 执行价格) THEN 执行期权
ELSE IF (股票市价 <= 执行价格) THEN 不执行期权
```

**核心公式：**
```
多头看涨期权到期日价值 = max(股票市价 - 执行价格, 0)
多头看涨期权净损益 = 到期日价值 - 期权价格
```

**损益情形分析：**
- **亏损：** 股票市价 ≤ 执行价格，净损益 = -期权价格
- **盈亏平衡：** 股票市价 = 执行价格 + 期权价格，净损益 = 0
- **盈利：** 股票市价 > 执行价格 + 期权价格，净损益 > 0

**策略特征：**
- 净损失有限（最大值为期权价格）
- 净收益潜力巨大
- 具有巨大杠杆效应

### 3. 执行价格对期权价值的影响

**看涨期权：**
- 执行价格越高，价值越小
- 原因：执行价格越高，未来行权时需要支付更多资金，差额收入越小
- 关系：负相关

**看跌期权：**
- 执行价格越高，价值越大
- 原因：执行价格越高，未来行权时可以以更高价格卖出股票，差额收入越大
- 关系：正相关

### 4. 到期期限对美式期权价值的影响

**核心结论：** 较长的到期时间能增加美式看涨期权的价值

**作用机制：**
1. **扩大股价变动范围：** 到期日越远，股价变动范围越大，获利可能性增加
2. **执行价格现值降低：** 随着时间延长，执行价格现值减少，实际支付成本下降
3. **灵活性优势：** 美式期权可在到期前任何时间执行，更长期限提供更多执行机会

### 5. 认股权证与股票看涨期权的异同

**共同点：**
- 标的资产均为股票
- 均具有选择权
- 均有固定执行价格

**区别：**

| 特征 | 股票看涨期权 | 认股权证 |
|:---|:---|:---|
| 股票来源 | 二级市场 | 新发股票 |
| 稀释效应 | 不存在 | 存在，稀释每股收益和股价 |
| 期限长短 | 通常几个月 | 可长达10年或更长 |
| 定价模型 | 布莱克-斯科尔斯模型适用 | 不能假设不分红，不适用B-S模型 |

## 决策要点
- 标准正态分布查表仅适用于非负d值，负值需用对称性转换
- 多头看涨期权盈亏平衡点 = 执行价格 + 期权价格
- 执行价格对看涨和看跌期权的影响方向相反
- 美式期权价值随期限延长而增加，欧式期权不一定
- 认股权证具有稀释效应，不能直接用B-S模型定价
