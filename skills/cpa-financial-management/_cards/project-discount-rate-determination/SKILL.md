# 项目折现率确定

## 适用场景
进行投资项目评估、资本预算决策、折现率确定时，根据项目风险水平确定合适的折现率。

## 等风险项目折现率应用规则

### 适用条件
仅适用于项目风险与公司现有资产平均风险相同的情况。

### 执行步骤
1. **风险评估**：首先评估投资项目的风险水平，确定其风险特征
2. **基准比较**：将项目风险与公司现有资产的平均风险进行比较
3. **等价判定**：如果判定两者风险相同，则进入下一步；如果不同，则适用其他规则
4. **折现率确定**：当确认项目风险与公司现有资产平均风险相同时，直接将公司资本成本作为该项目现金流量的折现率
5. **重要警告**：在确定一个项目风险恰好等于现有资产平均风险时，需要特别慎重，因为这种等价关系的判断对结果影响重大

## 异风险项目资本成本风险调整方法

### 适用条件
投资项目风险与公司现有资产平均风险不同时。

### 执行步骤
1. **风险识别**：识别投资项目风险与公司现有资产平均风险的差异
2. **禁止直接使用**：明确公司资本成本不能作为该项目现金流量的折现率
3. **确定调整基础**：将公司资本成本作为重要的调整基准点（adjustment basis）
4. **风险比较分析**：
   - 如果项目风险 > 公司平均风险：需要调增资本成本（增加风险溢价）
   - 如果项目风险 < 公司平均风险：需要调减资本成本（降低风险溢价）
5. **估计项目资本成本**：根据项目风险与公司风险的差别程度，适当调增或调减，估计出适合该项目的特定资本成本
6. **应用调整后的成本**：使用调整后的项目资本成本作为折现率进行项目评估

## 决策流程

```
开始
  │
  ▼
评估项目风险
  │
  ├──► 项目风险 == 公司平均风险？
  │    │
  │    ├──► 是 → 使用公司资本成本作为折现率
  │    │
  │    └──► 否 → 继续判断
  │              │
  │              ▼
  │         项目风险 > 公司平均风险？
  │              │
  │              ├──► 是 → 调增资本成本（增加风险溢价）
  │              │
  │              └──► 否 → 调减资本成本（降低风险溢价）
```

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| 项目风险 | 风险度量 | 投资项目的风险水平 |
| 公司现有资产平均风险 | 风险度量 | 公司当前资产组合的平均风险水平 |
| 公司资本成本 | 百分比/利率 | 作为调整基准的公司整体资本成本 |
| 风险差异程度 | 定性/定量 | 项目风险与公司风险的具体差别大小 |

## 决策输出
确定项目评估使用的折现率数值，直接采用公司资本成本或经风险调整后的项目特定资本成本进行NPV等计算。
