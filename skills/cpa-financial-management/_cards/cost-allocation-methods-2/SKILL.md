# 成本分配方法

## 适用场景
- 同一生产过程中产生主产品和副产品，需要分配加工成本
- 企业发生外购动力费用（电力、蒸汽等），需要按用途归集和分配

## 副产品成本分配（扣除分配法）

### 何时使用
在同一生产过程中，使用同种原料，生产主要产品的同时附带生产非主要产品，且副产品价值相对较低。

### 执行步骤
1. **识别副产品**：确认产品为副产品（产量随主产品变动）
2. **选择简化方法**：采用固定单价等简化方法确定副产品成本
3. **计算副产品成本**：副产品成本 = 固定单价 × 副产品产量
4. **计算主产品成本**：主产品成本 = 总成本 - 副产品成本
5. **遵循分配顺序**：先确定副产品成本，再确定主产品成本

### 关键公式
```
主产品成本 = 总成本 - 副产品成本
```

## 外购动力费用分配

### 何时使用
企业发生外购动力费用（电力、蒸汽等），需要按用途进行归集和分配。

### 执行步骤
1. **确定分配依据**：根据仪表记录、生产工时、定额消耗量比例进行分配
2. **编制分配表**：编制"动力费用分配表"作为核算依据
3. **执行会计分录**：
   - 直接用于产品生产 → 记入"生产成本"科目及"燃料和动力费用"成本项目
   - 照明、取暖等用途 → 按使用部门记入"制造费用"、"管理费用"等科目
4. **特殊情况处理**：设有辅助生产车间时，外购电费先记入"生产成本——辅助生产成本"科目

### 会计科目映射
| 用途 | 科目 | 成本项目 |
|------|------|----------|
| 直接生产 | 生产成本 | 燃料和动力费用/直接材料成本 |
| 照明取暖 | 制造费用/管理费用 | - |
| 辅助生产 | 生产成本-辅助生产成本 | - |
