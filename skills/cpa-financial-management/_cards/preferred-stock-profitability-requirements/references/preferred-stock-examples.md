# 优先股盈利要求判定示例

## 示例一：满足连续盈利要求

**假设某上市公司最近3年数据如下（单位：万元）：**
- 第1年：扣非净利润800，净利润1000（含非经常性收益200）
- 第2年：扣非净利润1200，净利润900（含非经常性损失300）
- 第3年：扣非净利润500，净利润1500（含非经常性收益1000）

**判定过程：**
```
第1年有效净利润 = min(800, 1000) = 800万元
第2年有效净利润 = min(1200, 900) = 900万元
第3年有效净利润 = min(500, 1500) = 500万元
```

**判定结果：** 三年有效净利润分别为800、900、500，均为正数，满足连续盈利要求。

**分析：** 若仅以净利润判断，第2年净利润为900万元，但实际经常性净利润为1200万元；第3年净利润高达1500万元，但经常性净利润仅500万元。采用孰低原则能够真实反映盈利质量。

## 示例二：不满足连续盈利要求

**假设某上市公司最近3年数据如下（单位：万元）：**
- 第1年：扣非净利润800，净利润1000
- 第2年：扣非净利润-100，净利润500（含非经常性收益600）
- 第3年：扣非净利润600，净利润700

**判定过程：**
```
第1年有效净利润 = min(800, 1000) = 800万元
第2年有效净利润 = min(-100, 500) = -100万元
第3年有效净利润 = min(600, 700) = 600万元
```

**判定结果：** 第2年有效净利润为-100万元，不满足连续盈利要求。

**分析：** 虽然第2年报表净利润为500万元，但这是通过600万元非经常性收益实现的，扣非后实际亏损100万元。采用孰低原则能够防止公司通过非经常性损益粉饰业绩。

## 孰低原则的重要性

**防止利润操纵：**
- 非经常性损益包括：资产处置收益、政府补助、债务重组收益、投资收益等
- 这些收益具有一次性、不可持续的特点
- 若仅以净利润判断，公司可能通过处置资产等方式"创造"利润

**确保盈利质量：**
- 孰低原则确保公司必须具备真实的、可持续的盈利能力
- 保护投资者利益，降低投资风险

## 非经常性损益常见项目

1. 资产处置损益
2. 政府补助
3. 债务重组收益
4. 非流动资产毁损报废损失
5. 与公司正常经营业务无关的或有事项产生的损益
6. 除同公司正常经营业务相关的有效套期保值业务外，持有交易性金融资产、交易性金融负债产生的公允价值变动损益
7. 单独进行减值测试的应收款项减值准备转回
8. 对外委托贷款取得的损益
9. 采用公允价值模式进行后续计量的投资性房地产公允价值变动产生的损益
