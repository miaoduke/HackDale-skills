# 优先股公开发行盈利要求判定

## 适用场景
- 上市公司申请公开发行优先股前的合规性检查
- 评估上市公司盈利质量和连续性
- 验证是否满足监管要求的盈利条件
- 防止上市公司通过非经常性损益粉饰业绩

## 核心标准

**盈利连续性判定标准：**
- 时间范围：最近3个会计年度（即申请发行时向前追溯3个完整会计年度）
- 连续性要求：3个会计年度均须盈利，不得有任何一年亏损
- 计算口径：采用"孰低原则"，即取扣除非经常性损益后的净利润与扣除前的净利润中的较低者

## 判定流程

### 步骤1：提取财务数据
提取最近3个会计年度的财务报表，获取以下数据：
- 各年度扣除非经常性损益后的净利润
- 各年度扣除前的净利润（即报表净利润）

### 步骤2：计算有效净利润
对每个年度，分别计算两个指标并取较低者：
```
年度有效净利润 = min(扣非后净利润, 扣除前净利润)
```

### 步骤3：验证连续盈利
检查3个年度的有效净利润是否均为正值。

### 步骤4：输出判定结果
- 若全部为正：满足"连续盈利"要求
- 任一年度为负或为零：不满足要求

## 计算规则

### 孰低原则
```
年度有效净利润 = min(指标A, 指标B)
```

其中：
- 指标A：扣除非经常性损益后的净利润（经常性净利润）
- 指标B：扣除前的净利润（即报表净利润，包含非经常性损益）

**目的：** 防止上市公司通过非经常性损益（如资产处置收益、政府补助等一次性收益）粉饰业绩，确保盈利的持续性和稳定性。

## 执行流程

### 场景一：判定是否满足发行条件
1. 收集最近3个会计年度的财务报表
2. 提取各年度扣非后净利润和扣除前净利润
3. 对每个年度计算有效净利润 = min(扣非后净利润, 扣除前净利润)
4. 检查3个年度的有效净利润是否均为正值
5. 输出判定结果：满足/不满足

### 场景二：评估盈利质量
1. 对比扣非后净利润与扣除前净利润的差异
2. 分析非经常性损益对净利润的影响程度
3. 评估盈利的持续性和稳定性
4. 输出盈利质量分析报告

## 关键变量
- **年度1扣非净利润：** 第1个会计年度扣除非经常性损益后的净利润
- **年度1净利润：** 第1个会计年度扣除前的净利润
- **年度2扣非净利润：** 第2个会计年度扣除非经常性损益后的净利润
- **年度2净利润：** 第2个会计年度扣除前的净利润
- **年度3扣非净利润：** 第3个会计年度扣除非经常性损益后的净利润
- **年度3净利润：** 第3个会计年度扣除前的净利润
- **年度1有效净利润：** min(年度1扣非净利润, 年度1净利润)
- **年度2有效净利润：** min(年度2扣非净利润, 年度2净利润)
- **年度3有效净利润：** min(年度3扣非净利润, 年度3净利润)

## 输出结果
- 满足/不满足连续盈利要求
- 如满足，列明三年有效净利润数值
- 如不满足，指出具体哪个年度未达标

## 约束条件
- 非公开发行优先股可能适用不同标准
- 非上市公司不适用
- 必须为最近3个完整会计年度
