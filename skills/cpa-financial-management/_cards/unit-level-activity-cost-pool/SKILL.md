# 单位级作业成本库设计

## 使用场景
- 实施作业成本法（ABC）
- 识别和分类作业成本
- 处理与产品数量直接相关的成本
- 建立成本计算单

## 作业识别与定义

### 单位级作业特征
- 每一单位产品至少要执行一次的作业
- 具有普遍性和重复性
- 对每个产品都必须执行

### 典型示例
- 机器加工作业
- 组装作业
- 直接材料消耗
- 直接人工消耗

## 成本构成识别

### 直接成本要素
单位级作业的成本包括以下直接成本要素：
- 直接材料成本（Direct Materials）
- 直接人工成本（Direct Labor）
- 机器成本（Machine Costs）
- 直接能源消耗（Direct Energy Consumption）

## 成本性质判定

### 直接成本特征
- 属于直接成本
- 可以追溯到每个单位产品上
- 直接计入成本对象的成本计算单

### 成本性态
- 成本与产品数量呈严格线性关系
- 每多生产一个单位就增加一份成本
- 不存在规模经济或批次效应

## 分配执行方法

### 直接追溯流程
无需复杂的间接分配计算，直接将成本追溯到每个单位产品：

#### 步骤1：计量资源消耗
计量单位产品耗用的：
- 直接材料
- 直接人工
- 机器工时
- 直接能源消耗

#### 步骤2：计算单位成本
```
单位成本 = 直接材料 + 直接人工 + 机器成本 + 直接能源消耗
```

#### 步骤3：计入成本计算单
将单位成本直接计入该产品的成本计算单

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 单位产品 | 成本对象 | 成本计算的基本单位，每个产品都必须执行该作业 |
| 直接材料成本 | 成本要素 | 可直接追溯到单位产品的材料消耗 |
| 直接人工成本 | 成本要素 | 可直接追溯到单位产品的人工消耗 |
| 机器成本 | 成本要素 | 机器加工产生的单位级成本 |
| 成本计算单 | 文档 | 记录单位产品成本明细的表单 |

## 约束条件
- 仅适用于与产品数量成比例变动的作业
- 不适用于批次相关或产品品种相关的作业
- 必须能够计量单位产品资源消耗

## 输出结果
```
得到单位产品的直接成本数值（直接材料+直接人工+机器成本+能源消耗），直接计入该产品成本计算单，作为产品成本的基础组成部分
```

## 触发条件
```
IF (作业性质为每一单位产品至少要执行一次 AND 成本与产量线性相关) 
THEN 适用单位级作业成本库规则
```
