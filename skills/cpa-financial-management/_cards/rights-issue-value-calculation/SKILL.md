# 配股权价值计算

计算原股东持有的每股股票所附带的配股权价值。

## 适用场景

- 上市公司实施配股融资，需向股东说明配股权益价值
- 评估配股权作为实值期权的内在价值
- 股东决策是否参与配股或转让配股权
- 财务分析中调整股东权益估值

## 前提条件

- 已完成配股除权参考价计算
- 已知配股价格（每股认购价）
- 已知配股比例（如每10股配2股）

## 计算公式

```
每股配股权价值 = (配股除权参考价 - 配股价格) ÷ 购买1股新配股所需原股数
```

## 执行步骤

1. **确认配股权为实值期权**
   - 验证：配股价格 < 配股前股票市价
   - 若条件不满足，配股权无内在价值

2. **确定配股比例换算**
   - 计算：购买1股新配股所需原股数 = 配股比例的分母 ÷ 分子
   - 例：每10股配2股 → 10÷2 = 5股原股票购1股新股

3. **代入公式计算**
   - 获取配股除权参考价（元/股）
   - 获取配股价格（元/股）
   - 计算价差并除以所需原股数

4. **结果解读**
   - 结果表示每股原股票附带的配股权价值
   - 该价值为股东因优先认购权获得的额外收益

## 快速参考

| 配股比例 | 购1股新股所需原股数 |
|---------|------------------|
| 10配2 | 5 |
| 10配3 | 3.33 |
| 10配1.5 | 6.67 |

## 输出示例

> 每股配股权价值：0.167元/股
> 
> 含义：原股东持有的每股股票因配股权获得0.167元的额外价值。

## 注意事项

- 本计算基于配股除权参考价，为理论估计值
- 实际市场交易中配股权价格可能受流动性、期限等因素影响
- 若配股价格高于或等于市价，配股权为虚值或平值期权，无内在价值
