# 预算与成本管理

## 使用场景
当需要进行管理决策、编制作业预算、实施成本控制时使用此技能。

## 成本管理会计相关性原则

### 核心原则
仅保留与决策相关的增量成本信息，剔除无关成本。

### 应用流程

**第一步：确定决策目标与类型**
- 明确判断方案优劣的具体场景（如定价决策）
- 根据决策类型确定信息范围
  - 定价决策：产品全价值链成本信息
  - 对外财务报告：产品制造成本信息

**第二步：识别并分类成本**

**相关成本：**
- 定义：因接受决策而发生的未来成本变化
- 判定：分析"接受该决策所带来的增量成本"

**无关成本：**
- 定义：无论接受或拒绝决策都不会改变的成本
- 判定：不随决策变化的成本，应从决策分析中剔除

**第三步：输出决策相关信息**
- 仅保留相关成本（增量成本）
- 用于方案优劣对比

### 关键要点
- 不随决策变化的成本不应纳入决策考量
- 不同决策类型对信息范围要求不同
- 相关成本必须是未来成本且因决策而变化

## 作业预算管理

### 编制流程

**第一步：确定资源需求量**
```
资源需求量 = Σ 各类作业需求量 × 资源消耗率
```
- 依据：作业消耗资源的因果关系
- 资源消耗率：单位作业消耗的资源数量

**第二步：平衡资源需求量与供给量**
- 资源供给量：企业目前拥有并能投入作业的资源数量
- 检查：需求量与供给量是否平衡
- 调整措施：
  - 增加或减少资源费用供给量
  - 降低资源消耗率
- 目标：使差额处于可接受区间内

**第三步：编制预算**
```
资源费用预算 = Σ 各类资源需求量 × 该资源费用预算价格
```
- 编制对象：以作业中心为对象
- 编制依据：按照作业类别编制
- 价格来源：企业建立的资源价格库（历史成本、行业标杆、预期市价）

**第四步：审核最终预算**
- 评审小组：预算管理部门、运营与生产管理部门、作业及流程管理部门、技术定额管理部门
- 评审维度：业绩要求、作业效率要求、资源效益要求
- 审批流程：评审通过后上报企业预算管理决策机构

**第五步：预算控制与分析**
- 控制方式：按照作业中心和作业进度控制
- 控制精细化：精细化到作业管理层次
- 控制重点：作业活动驱动的资源

### 分析内容

**资源动因分析：**
- 揭示作业消耗资源的必要性和合理性
- 发现减少资源浪费、降低资源消耗成本的机会
- 提高资源利用效率

**作业动因分析：**
- 揭示作业的有效性和增值性
- 减少无效作业和不增值作业
- 进行作业改进和流程优化
- 提高作业产出效果

## 应用要点

1. **相关性原则：** 决策分析必须剔除无关成本，聚焦增量成本
2. **资源平衡：** 需求量与供给量必须达到基本平衡
3. **价格库建设：** 收集历史成本、行业标杆、预期市价数据
4. **多部门评审：** 确保预算的合理性和可行性
5. **动因分析：** 从资源和作业两个维度分析效率
