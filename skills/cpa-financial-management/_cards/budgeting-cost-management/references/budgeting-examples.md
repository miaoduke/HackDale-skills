# 预算与成本管理示例

## 相关性原则应用示例

### 决策场景：是否接受特殊订单

**订单信息：**
- 订单价格：80元/件
- 订单数量：1000件

**成本信息：**
- 单位产品制造成本：100元/件
  - 直接材料：40元
  - 直接人工：30元
  - 变动制造费用：10元
  - 固定制造费用：20元
- 专属设备租金：5000元

**相关成本分析：**
| 成本项目 | 是否相关 | 金额 |
|---------|---------|------|
| 直接材料 | 是（增量） | 40元 |
| 直接人工 | 是（增量） | 30元 |
| 变动制造费用 | 是（增量） | 10元 |
| 固定制造费用 | 否（沉没成本） | 0元 |
| 专属设备租金 | 是（专属成本） | 5元（5000÷1000） |
| **单位相关成本** | | **85元** |

**决策结论：**
- 订单价格80元 < 单位相关成本85元
- **拒绝订单**

## 作业预算编制示例

### 作业中心：装配车间

**作业需求量：**
- 作业A（零件装配）：1000次
- 作业B（质量检验）：500次

**资源消耗率：**
- 作业A消耗人工：0.5小时/次
- 作业B消耗人工：0.2小时/次

**资源需求量计算：**
```
人工需求量 = 1000×0.5 + 500×0.2 = 500 + 100 = 600小时
```

**资源供给量：**
- 车间可用人工：650小时

**平衡检查：**
```
差额 = 650 - 600 = 50小时（可接受）
```

**资源费用预算：**
- 人工预算价格：30元/小时
```
人工费用预算 = 600 × 30 = 18000元
```

## 动因分析示例

### 资源动因分析

**发现：**
- 作业A实际消耗人工0.6小时/次，标准0.5小时/次
- 作业B实际消耗人工0.25小时/次，标准0.2小时/次

**原因分析：**
- 工人技能不足
- 设备老化，效率下降

**改进措施：**
- 加强工人培训
- 更新设备

### 作业动因分析

**发现：**
- 作业C（返工）发生200次
- 作业C为不增值作业

**原因分析：**
- 质量控制不严格
- 原材料质量不稳定

**改进措施：**
- 加强原材料检验
- 优化质量控制流程
- 目标：消除作业C
