# 敏感程度分析法

## 何时使用

- 需要评估目标变量受各因素变化的影响程度
- 识别投资项目或财务预测中的关键风险点
- 已完成确定性分析，需要进行不确定性分析
- 比较不同方案的敏感度，选择风险较小的方案

## 执行步骤

### 基础准备
1. 预测每个影响因素的预期值
2. 根据影响因素的预期值计算目标变量的预期值

### 敏感性测试（单因素循环）

对每个影响因素执行：

1. **选定因素变动**：选取一个影响因素，假定其发生一定幅度变化
2. **固定其他因素**：保持其他因素不变
3. **重新计算目标变量**：计算变动后的目标变量值
4. **计算敏感系数**：
   ```
   敏感系数 = 目标变量变动百分比 ÷ 选定影响因素变动百分比
   ```
   含义：选定影响因素变动1%导致目标变量变动的百分数

### 敏感因素判定

- **敏感因素**：|敏感系数| > 1
- **非敏感因素**：|敏感系数| ≤ 1

### 结果应用

1. **排序分析**：按敏感系数绝对值排序，找出对目标变量影响较大的敏感因素
2. **深入分析**：对敏感因素进行进一步分析、预测或估算其影响程度
3. **风险控制**：找出产生不确定性的根源，采取相应有效措施
4. **方案对比**：选择敏感度小（风险小）的方案作为投资方案
5. **决策支持**：预测最有利与最不利的经济效益变动范围，为决策者提供风险程度预测

## 关键参数（投资项目场景）

| 参数类别 | 具体参数 |
|---------|---------|
| 收入类 | 销售收入 |
| 成本类 | 经营成本 |
| 运营类 | 生产能力、寿命期、建设期、达产期 |
| 投资类 | 初始投资 |

## 经济效益指标

- 净现值（NPV）
- 内含报酬率（IRR）

## 方法局限性

| 局限性 | 说明 |
|--------|------|
| 单因素假设 | 只允许一个因素发生变动，假设其他因素保持不变 |
| 概率缺失 | 没有给出每一个因素发生该变化的可能性（概率） |

## 注意事项

- 现实中因素通常相互关联，分析结果需谨慎解读
- 适用于初步风险识别，重大决策需结合其他分析方法
