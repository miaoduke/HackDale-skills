# 现金流量折现估值法

## 适用场景
- 评估企业整体价值
- 评估股权价值
- 进行企业价值评估
- 倾向于使用受资本结构影响较小的WACC作为折现率
- 需要预测企业未来的实体现金流量和股权现金流量

## 模型选择依据

### 实体现金流量模型 vs 股权现金流量模型
- **股权资本成本**：受资本结构影响较大，估计复杂
- **加权平均资本成本(WACC)**：受资本结构影响较小，估计容易

债务增加使债务成本下降，但风险增加导致股权成本上升，两者大部分抵销。

## 实体现金流量模型

### 模型类型

**1. 永续增长模型**
适用于现金流稳定增长的企业。
```
实体价值 = 下期实体现金流量 ÷ (加权平均资本成本 - 永续增长率)
```

**2. 两阶段增长模型**
适用于先详细预测后稳定增长的企业。
```
实体价值 = 详细预测期实体现金流量现值 + 后续期实体现金流量现值
```

数学表达式：
```
实体价值 = Σ[t=1 to m] [实体现金流量_t ÷ (1+加权平均资本成本)^t] + [实体现金流量_{m+1} ÷ (加权平均资本成本 - 永续增长率)] ÷ (1+加权平均资本成本)^m
```

## 现金流量预测流程

### 预测步骤

**1. 计算营业收入**
```
营业收入 = 基期营业收入 × (1 + 增长率)
```

**2. 计算营业成本**
```
营业成本 = 营业收入 × (销售成本/营业收入)
```

**3. 计算销售和管理费用**
```
销售和管理费用 = 营业收入 × (销售和管理费用/营业收入)
```

**4. 计算税前经营利润**
```
税前经营利润 = 营业收入 - 营业成本 - 销售和管理费用
```

**5. 计算经营利润所得税**
```
经营利润所得税 = 税前经营利润 × 所得税税率
```

**6. 计算税后经营净利润**
```
税后经营净利润 = 税前经营利润 - 经营利润所得税
```

**7. 计算净经营资产增加**
```
净经营资产增加 = 基期营业收入 × 增长率 × (净经营资产/营业收入)
```

**8. 计算实体现金流量**
```
实体现金流量 = 税后经营净利润 - 净经营资产增加
```

**9. 计算税后利息费用**
```
税后利息费用 = 营业收入 × (净负债/营业收入) × 债务利息率 × (1 - 所得税税率)
```

**10. 计算净负债增加**
```
净负债增加 = 基期营业收入 × 增长率 × (净负债/营业收入)
```

**11. 计算股权现金流量**
```
股权现金流量 = 实体现金流量 - 税后利息费用 + 净负债增加
```

## 执行计算步骤（以两阶段模型为例）

### 步骤 1：确定参数
确定详细预测期年限 m、各期实体现金流量、永续增长率 g。

### 步骤 2：确定折现率
确定各期加权平均资本成本(WACC)。注意：不同时期 WACC 可能不同。

### 步骤 3：计算详细预测期现值
- 计算折现系数 = 1 ÷ (1 + WACC)^t
- 计算各年现值 = 实体现金流量 × 折现系数
- 汇总详细预测期价值 = Σ(各年现值)

### 步骤 4：计算后续期价值（终值）
- 计算后续期在第 m 年末的价值 = 实体现金流量_{m+1} ÷ (后续期 WACC - 永续增长率)
- 计算后续期在当前（0点）的现值 = 第 m 年末价值 × 第 m 年折现系数

### 步骤 5：计算实体总价值
```
实体价值 = 详细预测期价值 + 后续期现值
```

### 步骤 6：计算股权价值
```
股权价值 = 实体价值 - 净负债价值
```

### 步骤 7：计算每股股权价值
```
每股价值 = 股权价值 ÷ 流通在外的普通股股数
```

### 步骤 8：估值判断
- 若 市场价格 > 计算出的每股价值，则股票被市场高估
- 若 市场价格 < 计算出的每股价值，则股票被市场低估
