# 现金流量预测示例

## 预测参数
- 基期营业收入 = 1000万元
- 增长率 = 12%
- 销售成本率 = 70%
- 销售和管理费用率 = 5%
- 净经营资产/营业收入 = 80%
- 净负债/营业收入 = 40%
- 债务利息率 = 6%
- 所得税税率 = 25%

## 计算过程

1. 营业收入 = 1000 × (1 + 12%) = 1120万元

2. 营业成本 = 1120 × 70% = 784万元

3. 销售和管理费用 = 1120 × 5% = 56万元

4. 税前经营利润 = 1120 - 784 - 56 = 280万元

5. 经营利润所得税 = 280 × 25% = 70万元

6. 税后经营净利润 = 280 - 70 = 210万元

7. 净经营资产增加 = 1000 × 12% × 80% = 96万元

8. 实体现金流量 = 210 - 96 = 114万元

9. 税后利息费用 = 1120 × 40% × 6% × (1 - 25%) = 20.16万元

10. 净负债增加 = 1000 × 12% × 40% = 48万元

11. 股权现金流量 = 114 - 20.16 + 48 = 141.84万元
