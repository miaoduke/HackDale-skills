# 融资需求计算详细参考

## 一、资产增加额计算公式

### 基础公式（销售百分比法）
```
资产增加额(ΔA) = (A/S) × ΔS
```
其中：
- A/S = 资产销售百分比（历史资产周转率的倒数）
- ΔS = 销售增加额 = S₁ × g
- S₁ = 基期销售额
- g = 销售增长率

### 分项计算法（更精确）
```
ΔA = Δ流动资产 + Δ固定资产
     = (AR% + Inv% + Cash%) × ΔS + ΔFA
```

**流动资产分项：**
| 项目 | 计算方法 | 备注 |
|-----|---------|------|
| 应收账款增加 | (DSO/365) × ΔS | DSO=应收账款周转天数 |
| 存货增加 | (DIO/365) × COGS增加 | DIO=存货周转天数 |
| 现金增加 | 销售增长×现金销售占比×目标现金比率 | 或按固定比例 |

**固定资产增加判断：**
```
若：S₁ × (1+g) / 现有产能 > 产能利用率阈值（通常85-90%）
则：ΔFA = 新增产能投资
否则：ΔFA = 0（仅维护性资本支出）
```

## 二、留存收益可提供资金计算

### 基本公式
```
留存收益可提供资金(RE) = S₁ × (1+g) × PM × b
```
其中：
- PM = 销售净利率（预测期）
- b = 留存比率 = 1 - 股利支付率

### 调整因素
| 调整项 | 说明 | 调整方法 |
|-------|------|---------|
| 规模效应 | 高增长可能降低利润率 | PM使用保守估计 |
| 折旧影响 | 折旧非现金支出但影响利润 | RE计算已含折旧，但需单独考虑折旧再投资 |
| 非经常性损益 | 一次性收益不可持续 | 剔除后计算可持续利润 |

## 三、外部融资需求量（EFN）完整公式

```
EFN = (A/S) × ΔS - (L/S) × ΔS - S₁ × (1+g) × PM × b
```

增加自发负债项（L/S）：
- 应付账款销售百分比
- 应计费用销售百分比

**修正后：**
```
EFN = [ (A/S) - (L/S) ] × ΔS - RE
```

## 四、融资提前期参考标准

### 按融资方式分类

| 融资方式 | 最短周期 | 常规周期 | 最长周期 | 关键影响因素 |
|---------|---------|---------|---------|-----------|
| 银行短期贷款 | 2周 | 1个月 | 2个月 | 银企关系、担保落实 |
| 银行中长期贷款 | 1个月 | 2-3个月 | 6个月 | 项目评估、抵押登记 |
| 信用贷款 | 1个月 | 2个月 | 4个月 | 信用评级、授信额度 |
| 股权私募 | 2个月 | 4-6个月 | 12个月 | 尽职调查、估值谈判 |
| IPO/增发 | 6个月 | 12-18个月 | 24个月+ | 监管审批、市场窗口 |
| 债券发行 | 3个月 | 4-6个月 | 9个月 | 注册/核准、路演定价 |
| 融资租赁 | 1个月 | 2-3个月 | 4个月 | 租赁物评估、厂商协调 |
| 供应链金融 | 1周 | 2-3周 | 1个月 | 核心企业确权、系统对接 |

### 按企业规模分类

| 企业类型 | 银行融资周期 | 股权融资周期 | 建议提前期 |
|---------|-----------|-----------|-----------|
| 大型企业 | 1-2个月 | 3-6个月 | 资金需求前4-6个月 |
| 中型企业 | 2-3个月 | 4-8个月 | 资金需求前5-8个月 |
| 小型企业 | 2-4个月 | 6-12个月 | 资金需求前6-10个月 |
| 初创企业 | 3-6个月 | 6-12个月 | 资金需求前8-12个月 |

## 五、行业差异化参数

### 资产密集型行业
| 行业 | 资产销售比(A/S) | 典型产能阈值 | 融资特点 |
|-----|---------------|-----------|---------|
| 制造业（重工业） | 80-120% | 75-80% | 固定资产融资占比高，周期长 |
| 公用事业 | 150-300% | 85% | 项目融资为主，提前期12-18个月 |
| 房地产开发 | 200-400% | 项目制 | 预售回款与开发贷结合 |
| 基础设施 | 300%+ | 项目制 | PPP/专项债，提前期18-36个月 |

### 轻资产行业
| 行业 | 资产销售比(A/S) | 主要资产增量 | 融资特点 |
|-----|---------------|-----------|---------|
| 软件/互联网 | 20-40% | 人员、营销费用 | 股权融资为主，关注烧钱率 |
| 专业服务 | 30-50% | 应收账款 | 营运资金贷款，周期短 |
| 零售（轻资产模式） | 40-60% | 存货、应收 | 供应链金融适用 |

## 六、敏感性分析模板

### 关键变量波动影响

**场景：基础假设下EFN = 1000万元**

| 变量变动 | 变动幅度 | EFN影响 | 风险等级 |
|---------|---------|---------|---------|
| 销售增长率↑ | +5% | +25-40% | 高 |
| 销售净利率↓ | -2% | +15-25% | 中 |
| 留存比率↓ | -10% | +10% | 中 |
| 资产周转率↓ | -10% | +10-15% | 中 |
| 融资利率↑ | +2% | 后续财务费用+20% | 中 |

### 情景分析框架

```
乐观情景：销售增长达成120%，利润率提升
→ 资产需求超预期，但内部资金改善，EFN变动不确定

基准情景：销售增长达成100%，利润率持平
→ EFN按预测执行

悲观情景：销售增长仅达成80%，利润率下滑
→ 资产需求下降，但内部资金更紧张，需重新评估
```

## 八、风险预警信号

| 预警信号 | 触发条件 | 应对措施 |
|---------|---------|---------|
| 融资进度滞后 | 实际进度<计划进度80% | 启动备选方案，压缩后续环节时间 |
| 融资成本超预期 | 实际利率>预算利率150bps | 重新评估融资结构，考虑混合融资 |
| 资金到位延迟 | 延迟>2周 | 启用应急信贷额度，协商供应商账期 |
| 销售增长不及预期 | 实际增长<预测70% | 暂停非必要资本支出，调整融资规模 |
| 内部资金恶化 | 实际利润<预测80% | 增加外部融资储备，控制运营支出 |
