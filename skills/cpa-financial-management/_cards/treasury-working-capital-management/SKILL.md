# 司库与营运资本管理

## 适用场景
- 企业集团需要管理资金等金融资源
- 需要提高资金运营效率、降低资金成本、防控资金风险
- 企业进行现金管理
- 存在赊销业务和应收账款
- 企业已实施营运资本管理，需要向司库管理升级

## 现金流量同步管理

### 操作目标
尽量使企业的现金流入与现金流出的发生时间趋于一致。

### 核心原理
通过时间匹配，减少资金在账户中的闲置时间。

### 预期效果
使企业所持有的交易性现金余额降到最低水平。

### 实施要点
- 编制详细的现金流量预测
- 协调收入和支出的时间安排
- 建立现金流量监控系统
- 无法完全同步时需保留安全储备

## 加速收款策略

### 核心目标
缩短应收账款的时间。

### 利弊分析
- **利**：扩大销售规模，增加销售收入
- **弊**：增加企业资金占用

### 平衡策略
在利用应收账款吸引顾客和缩短收款时间之间找到适当的平衡点。

### 执行措施
1. 实施妥善的收账策略
2. 优化信用政策
3. 建立客户信用评估体系
4. 加强应收账款跟踪管理

## 司库管理定义与演进

### 概念起源
司库(treasury)原指用于安全储藏财物或贵重物品的地方。对企业而言，资金就是企业最贵重的资源。

### 历史演进阶段

| 阶段 | 时间 | 特征 |
|------|------|------|
| 起源 | 1970s欧美 | 现金管理 |
| 集中化 | 发展阶段 | 收支集中管理、银行账户管理、流动性管理 |
| 扩展 | 发展阶段 | 资金战略规划、营运资金管理、投融资管理、风险管理 |
| 当前 | 信息技术推动 | 集中的、专业化的司库管理 |

### 本质定义
对企业以资金为主要元素的金融资源从筹集到内部配置再到运营管理各个环节进行的动态及全面管理。

### 简化定义
用金融模式解决业务问题。

### 国资委2022年官方规范

**发布时间**：2022年1月

**文件**：《关于推动中央企业加快司库体系建设进一步加强资金管理的意见》

**司库体系定义**：
企业集团依托财务公司、资金中心等管理平台，运用现代网络信息技术，以资金集中和信息集中为重点，以提高资金运营效率、降低资金成本、防控资金风险为目标，以服务战略、支撑业务、创造价值为导向，对企业资金等金融资源进行实时监控和统筹调度的现代企业治理机制。

**战略定位**：
将司库体系建设作为促进财务管理数字化转型升级的切入点和突破口，重构内部资金等金融资源管理体系。

## 司库管理与营运资本管理的区分

### 基础概念界定

| 概念 | 定义 |
|------|------|
| 营运资本管理 | 对流动资金来源和运用的管理 |
| 司库管理 | 对企业资金等金融资源进行实时监控和统筹调度的现代企业治理机制 |

### 三维特征对比

**维度1：管理体系定位**
- 司库管理：服务于企业集团的财务管理（强调集团层面）
- 营运资本管理：可服务于单一企业或集团的短期财务管理

**维度2：数字化转型角色**
- 司库管理：财务管理数字化转型升级的切入口和突破口
- 营运资本管理：传统财务管理工具，不强调作为数字化转型的突破口

**维度3：目标体系**
- 司库管理：提高资金运营效率、降低资金成本、防控资金风险（三维）
- 营运资本管理：流动性与盈利性的平衡（二维）

### 升级关系
司库管理是现代经济环境下营运资本管理的升级与扩展：
- 从静态的流动资金管理扩展到动态的金融资源全生命周期管理
- 从单纯的财务管理工具扩展到服务战略、支撑业务、创造价值的现代企业治理机制

### 适用边界决策树
```
单体小企业 → 营运资本管理
大型企业集团且需资金集中 → 司库管理（营运资本管理的升级形态）
中央企业 → 必须按照国资委2022要求建设司库体系
```

## 司库体系建设要点

### 管理平台
- 财务公司
- 资金中心

### 技术基础
- 现代网络信息技术
- 资金集中和信息集中

### 核心目标
1. 提高资金运营效率
2. 降低资金成本
3. 防控资金风险

### 导向原则
- 服务战略
- 支撑业务
- 创造价值
