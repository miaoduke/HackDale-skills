# 市场有效性分析

## 适用场景
- 评估资本市场效率程度
- 验证公开信息是否反映于股价
- 判断基本面分析或技术分析的有效性
- 评估投资基金业绩

## 有效市场核心定义

### 基本定义
有效资本市场是指价格能够"同步地"、"完全地"反映"全部"可用信息的市场。

### 检验标准
价格是否能够反映证券的四大特征：
1. **平均收益**
2. **风险**
3. **税收待遇**
4. **流动性**

### 判定结果
- 若价格完全反映上述特征 → 市场有效
- 有效市场特征："价格是公平的"
- 投资者影响："无法取得超额收益"

## 市场运作机制

### 竞标市场机制
1. 卖者"开价"，买者"竞价"
2. 投资者看好并争购 → 价格上升
3. 投资者不满并抛售 → 价格下跌

### 资本配置功能
- 高效市场将资本调配到最有效使用资本的公司
- 经营业绩优良 → 吸引资本 → 价值提高
- 经营业绩较差 → 难以吸收资本 → 价值下跌

### 价格反应特征
- 新信息传播 → 投资者立即反应 → 价格迅速调整
- 调整完成后，过时信息无价值（"鸡肋效应"）

## 半强式有效市场判定

### 判定标准
检查市场价格是否同时反映：
- 历史信息
- 所有公开信息

### 投资策略推论
- 现有市价充分反映所有公开可得信息
- 投资者无法通过对公开信息的分析获得超额收益
- **基本面分析无效**

## 检验方法

### 方法一：事件研究法

**基本思想：** 比较事件发生前后的投资收益率，看特定事件信息能否被价格迅速吸收。

**变量计算：**
```
超额收益率 (AR) = 当天实际收益率 (R) - 当天市场收益率 (Rm)
市场收益率 (Rm) = 宽基股票市场指数
```

**时间窗口分析：**
- AR_{t-1}：事件公布前一天
- AR_t：事件公布当天
- AR_{t+1}：事件公布后一天

**有效性判定逻辑：**
- 若市场半强式有效，股票在t时间披露的事件只与AR_t有关
- 事件与此前的AR_{t-1}以及此后的AR_{t+1}无关
- 若超额收益率只与当天披露的事件相关，则判定为半强式有效

**异常事件类型：**
- 事件异常：盈利公告、兼并公告、股利分配等
- 时间异常：年初异常、周末异常、假日异常等
- 公司异常：小公司、被忽略公司等
- 会计异常：市盈率较低、实际盈余大于预期等

### 方法二：投资基金表现研究法

**逻辑前提：**
- 若市场半强式有效，技术分析、基本面分析和各种估值模型均无效
- 投资基金不可能取得超额收益

**判定标准：**
- 投资基金经理根据公开信息选股
- 其平均业绩应与市场整体收益率大体一致

**实证结论：**
- 投资基金没有"跑赢大盘"
- 平均业绩略低于市场业绩
- 短期超过市场业绩归因于运气（不可持续）

## 分析流程

1. **确定检验目标**
   - 评估整体市场有效性
   - 验证特定事件的信息反映速度

2. **选择检验方法**
   - 事件研究法：适用于特定事件分析
   - 基金表现研究法：适用于整体市场效率评估

3. **执行检验**
   - 计算超额收益率
   - 分析时间窗口
   - 统计检验

4. **得出结论**
   - 判定市场有效性程度
   - 评估投资策略有效性
