# 市场有效性分析公式

## 超额收益率计算
```
AR_t = R_t - Rm_t
```

其中：
- AR_t：第t天的超额收益率
- R_t：第t天的实际收益率
- Rm_t：第t天的市场收益率

## 累计超额收益率
```
CAR = Σ AR_t
```

## 市场模型
```
R_t = α + β × Rm_t + ε_t
```

其中：
- α：截距项
- β：系统性风险系数
- ε_t：残差项

## 局限性说明
- 不可能对每一种公开信息类型及其组合都做检验
- 即使大多数检验显示有效，仍不能排除市场对某些"尚未检验的信息"无效的可能性
- 绝大多数金融市场属于半强式有效（少数例外除外）
