# 最大最小法敏感性分析

## 适用场景
需要确定各影响因素的可接受临界值以评估项目风险时，应用最大最小法。

## 执行步骤

### 步骤1：预测每个影响因素的预期值
收集并确定所有相关影响因素的基础预测数据，例如：
- 单价
- 单位变动成本
- 销售量
- 固定成本

### 步骤2：计算目标变量的预期值
建立目标变量（通常是利润或经济效益指标）的计算公式，代入预期值计算基准情景下的目标变量值。

**利润公式示例**：
利润 = (单价 - 单位变动成本) × 销售量 - 固定成本

### 步骤3：逐个测算每个影响因素的临界值
1. 选取一个影响因素，假设其他所有因素保持不变
2. 令目标变量等于临界值（通常为0，即盈亏平衡点）
3. 反推计算该影响因素的最大（或最小）可接受值
4. 重复此过程，测算每个影响因素的临界值

## 计算示例

**已知条件**：
- 单价：30元/件
- 预测销售量：10万件
- 固定成本：20万元
- 目标利润临界值：0

**计算单位变动成本临界值**：
```
0 = (30 - 单位变动成本) × 100,000 - 200,000
200,000 = (30 - 单位变动成本) × 100,000
2 = 30 - 单位变动成本
单位变动成本 = 28元/件
```

**结果解读**：
- 28元/件是单位变动成本的最大可接受值
- 若实际单位变动成本 ≥ 28元/件，项目将亏损
- 决策者应分析单位变动成本达到或超过28元的可能性，以此评估投资风险

## 关键假设
- 假设其他因素不变（单因素分析）
- 不考虑所得税（如示例所述）
- 目标变量临界值通常设为0或盈亏平衡点
