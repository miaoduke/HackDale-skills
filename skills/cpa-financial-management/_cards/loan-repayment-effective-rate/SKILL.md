# 贷款偿还与有效利率计算

## 适用场景
- 制定贷款偿还条款
- 比较不同还款方式的实际成本
- 计算补偿性余额下的有效年利率
- 评估加息法贷款的真实利率
- 银行与企业贷款谈判

## 贷款偿还方式对比

### 方式一：到期一次偿还

**企业视角：**
- 优点：降低有效年利率
- 偏好：企业通常希望采用此方式

**银行视角：**
- 缺点：增加企业拒付风险，降低实际贷款利率
- 偏好：银行不希望采用此方式

### 方式二：定期等额偿还

**企业视角：**
- 缺点：提高有效年利率（资金实际占用时间变短）
- 偏好：企业不希望采用此方式

**银行视角：**
- 优点：降低拒付风险，提高实际贷款利率
- 偏好：银行希望采用此方式

## 收款法付息

### 执行流程
1. 确认贷款协议采用收款法
2. 等待贷款到期
3. 在到期日一次性支付全部利息
4. 同时偿还本金

### 利率特性
- 有效年利率 = 报价利率
- 适用场景：银行向工商企业发放的贷款大都采用此方法

## 加息法付息

### 适用场景
- 分期等额偿还贷款
- 长期借款

### 计算步骤
1. 计算利息：利息 = 本金 × 报价利率
2. 计算本息和：本息和 = 本金 + 利息
3. 分期偿还本息之和

### 有效年利率公式
```
有效年利率 = (本金 × 报价利率) / (本金 ÷ 2) × 100%
```

**原理：** 由于贷款分期均衡偿还，借款企业实际上只平均使用了贷款本金的半数，却支付全额利息。

**结果：** 有效年利率约为报价利率的2倍

## 补偿性余额下的有效利率

### 计算步骤
1. 确定名义借款金额和名义年利率
2. 确定补偿性余额比例（通常为10%~20%）
3. 计算补偿性余额金额
4. 计算实际可动用金额
5. 计算有效年利率

### 有效年利率公式
```
有效年利率 = (名义借款金额 × 名义年利率) / 实际可用额
```

其中：\- 补偿性余额 = 名义借款金额 × 补偿性余额比例
- 实际可用额 = 名义借款金额 - 补偿性余额

### 影响分析
- **银行角度**：降低风险
- **企业角度**：提高实际资金成本

## 决策建议

### 企业角度
1. 优先选择到期一次偿还方式（有效年利率最低）
2. 避免加息法分期等额偿还（有效年利率约为报价利率2倍）
3. 谈判时争取降低补偿性余额比例

### 银行角度
1. 优先选择定期等额偿还方式（降低风险，提高收益）
2. 要求补偿性余额以降低风险
3. 收款法适用于信用较好的企业
