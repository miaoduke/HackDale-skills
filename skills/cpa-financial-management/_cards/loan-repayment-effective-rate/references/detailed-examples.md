# 详细计算示例

## 示例1：加息法有效利率计算

**数据：**
- 借款金额：20,000元
- 名义年利率：12%
- 还款方式：分12个月等额偿还

**计算：**
- 利息 = 20,000 × 12% = 2,400元
- 本息和 = 20,000 + 2,400 = 22,400元
- 平均占用本金 = 20,000 ÷ 2 = 10,000元
- 有效年利率 = 2,400 / 10,000 × 100% = 24%

**结论：** 有效年利率（24%）是名义利率（12%）的2倍

## 示例2：补偿性余额下的有效利率

**数据：**
- 名义借款金额：100,000元
- 名义年利率：8%
- 补偿性余额比例：15%

**计算：**
- 补偿性余额 = 100,000 × 15% = 15,000元
- 实际可用额 = 100,000 - 15,000 = 85,000元
- 年利息 = 100,000 × 8% = 8,000元
- 有效年利率 = 8,000 / 85,000 = 9.41%

**结论：** 实际有效利率（9.41%）高于名义利率（8%）

## 示例3：不同还款方式对比

**假设：** 借款100,000元，名义利率10%，期限1年

| 还款方式 | 有效年利率 | 企业偏好 | 银行偏好 |
|---------|-----------|---------|---------|
| 到期一次偿还 | 10% | 高 | 低 |
| 收款法（到期付息） | 10% | 高 | 低 |
| 加息法（分期等额） | 约20% | 低 | 高 |
| 补偿性余额15% | 约11.76% | 中 | 中 |

**计算补偿性余额情况：**
- 实际可用额 = 100,000 × (1-15%) = 85,000元
- 利息 = 100,000 × 10% = 10,000元
- 有效年利率 = 10,000 / 85,000 = 11.76%
