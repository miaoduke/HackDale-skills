## 核心公式完整推导

### 第一步：基础分解
```
权益净利率 = 税后经营净利润/股东权益 - 税后利息费用/股东权益
```
说明：将权益净利率分解为经营活动贡献和金融活动贡献两部分，体现"经营-金融"分离思想

### 第二步：引入净经营资产作为中介
```
权益净利率 = (税后经营净利润/净经营资产) × (净经营资产/股东权益) - (税后利息费用/净负债) × (净负债/股东权益)
```
说明：通过净经营资产建立经营效率与资本结构的联系

### 第三步：资本结构关系转换
由于 净经营资产 = 净负债 + 股东权益，因此：
```
净经营资产/股东权益 = 1 + 净负债/股东权益 = 1 + 净财务杠杆
```

代入得：
```
权益净利率 = (税后经营净利润/净经营资产) × (1 + 净负债/股东权益) - 税后利息费用/净负债 × 净负债/股东权益
```

### 第四步：最终标准形式
```
权益净利率 = 净经营资产净利率 + (净经营资产净利率 - 税后利息率) × 净财务杠杆
```

## 应用示例：ABC公司数据分析

**数据对比（去年→上年）**：

| 指标 | 去年 | 上年 | 变动 |
|------|------|------|------|
| 净经营资产净利率 | 12.005% | 15.586% | +3.581% |
| 税后利息率 | 9.281% | 11.549% | +2.268% |
| 净财务杠杆 | 0.7938 | 0.6432 | -0.1506 |
| 经营差异率 | 2.724% | 4.037% | +1.313% |
| 杠杆贡献率 | 2.162% | 2.597% | +0.435% |
| **权益净利率** | **14.167%** | **18.182%** | **+4.015%** |

**关键洞察**：尽管净财务杠杆下降（财务风险降低），但由于经营效率提升幅度（+3.581%）大于融资成本上升幅度（+2.268%），经营差异率扩大，最终推动权益净利率显著提升。
