# 改进的财务分析体系（管理用财务报表分析）

## 何时使用

- 已编制管理用财务报表，能区分经营损益与金融损益
- 需要分析权益净利率的驱动因素
- 需要区分经营效率与财务政策对股东回报的贡献
- 评估企业综合盈利能力并指导管理决策

## 核心公式

### 最终标准形式

```
权益净利率 = 净经营资产净利率 + (净经营资产净利率 - 税后利息率) × 净财务杠杆
```

### 三驱动因素框架

| 驱动因素 | 公式 | 含义 |
|---------|------|------|
| 净经营资产净利率 | 税后经营净利润 / 净经营资产 | 反映经营效率 |
| 税后利息率 | 税后利息费用 / 净负债 | 反映债务融资成本 |
| 净财务杠杆 | 净负债 / 股东权益 | 反映资本结构政策 |

### 经营效率的进一步分解

```
净经营资产净利率 = 税后经营净利率 × 净经营资产周转次数

其中：
- 税后经营净利率 = 税后经营净利润 / 营业收入
- 净经营资产周转次数 = 营业收入 / 净经营资产
```

### 杠杆贡献的构成

```
经营差异率 = 净经营资产净利率 - 税后利息率
杠杆贡献率 = 经营差异率 × 净财务杠杆
```

## 执行步骤

1. **编制管理用财务报表**：区分经营资产/负债与金融资产/负债，计算税后经营净利润、税后利息费用
2. **计算核心指标**：净经营资产净利率、税后利息率、净财务杠杆
3. **计算权益净利率**：代入标准公式
4. **驱动因素分解**：分析各因素变动对权益净利率的影响
5. **对比分析**：与行业标杆或历史数据对比，识别改进方向

## 关键指标定义

| 指标 | 计算公式 | 管理含义 |
|------|---------|---------|
| 净经营资产 | 经营资产 - 经营负债 | 经营活动占用的净资本 |
| 净负债 | 金融负债 - 金融资产 | 有息债务净额 |
| 税后经营净利润 | 净利润 + 税后利息费用 | 经营活动产生的税后利润 |
| 经营差异率 | 净经营资产净利率 - 税后利息率 | 举债经营的收益率空间 |

## 分析要点

- **经营差异率 > 0**：财务杠杆产生正向贡献，可适当提高杠杆
- **经营差异率 < 0**：财务杠杆产生负向贡献，应降低杠杆或改善经营效率
- 权益净利率提升可来自：经营效率改善、融资成本下降、或适度的杠杆增加
