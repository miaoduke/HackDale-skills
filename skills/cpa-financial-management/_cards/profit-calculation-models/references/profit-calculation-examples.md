# 利润计算示例

## 基础数据

假设：
- 单价 = 2元
- 单位变动成本 = 1.2元
- 销售收入 = 5,000元
- 销售量 = 2,500件
- 固定成本 = 1,600元
- 盈亏临界点销售额 = 4,000元

## 方法一：常规计算

息税前利润 = 销售收入 - 变动成本 - 固定成本
           = 5,000 - (2,500 × 1.2) - 1,600
           = 5,000 - 3,000 - 1,600
           = 400元

## 方法二：基于安全边际

### 计算边际贡献率

边际贡献率 = (单价 - 单位变动成本) / 单价
           = (2 - 1.2) / 2
           = 0.4 = 40%

### 计算安全边际额

安全边际额 = 销售收入 - 盈亏临界点销售额
           = 5,000 - 4,000
           = 1,000元

### 计算息税前利润

息税前利润 = 安全边际额 × 边际贡献率
           = 1,000 × 40%
           = 400元

### 验证（单一产品法）

安全边际量 = 2,500 - 2,000 = 500件
单位边际贡献 = 2 - 1.2 = 0.8元
息税前利润 = 500 × 0.8 = 400元

## 销售息税前利润率计算

### 方法一：常规计算

销售息税前利润率 = 息税前利润 / 销售收入 × 100%
                 = 400 / 5,000 × 100%
                 = 8%

### 方法二：安全边际率 × 边际贡献率

安全边际率 = 安全边际额 / 销售收入
           = 1,000 / 5,000
           = 20%

销售息税前利润率 = 安全边际率 × 边际贡献率
                 = 20% × 40%
                 = 8%

## 利润提升策略分析

| 策略 | 影响 |
|------|------|
| 提高安全边际率 | 降低盈亏临界点作业率，增加安全边际 |
| 提高边际贡献率 | 降低变动成本率，提高单位产品盈利能力 |
| 同时提高两者 | 利润率提升效果叠加 |
