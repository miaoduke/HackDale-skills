# 生产成本分配方法选择

## 使用场景
当企业需要：
- 将生产成本在完工产品与在产品之间进行分配
- 选择合理的成本分配方法
- 平衡成本核算的准确性与简便性

## 决策依据

选择分配方法的决策依据包含四个关键维度：

### 1. 在产品数量的多少
- **数量很少** → 可考虑简化方法（不计算在产品成本或按年初数固定计算）
- **数量较多** → 需采用更精确的方法

### 2. 各月在产品数量变化的大小
- **变化很小、各月稳定** → 可采用固定计算方法
- **变化较大** → 需采用能反映实际变动的方法

### 3. 各项费用比重的大小
- **原材料费用占比很大** → 可采用"在产品成本按所耗原材料费用计算"方法
- **各项费用比重均衡** → 需采用更全面的分配方法

### 4. 定额管理基础的好坏
- **定额管理基础好** → 可采用定额比例法等精确方法
- **定额管理基础差** → 采用简化方法

## 核心原则

在满足"合理"（准确反映成本）的前提下，追求"简便"（降低核算成本）。

## 六种常用分配方法

### 方法1：不计算在产品成本法
- **适用条件**：各月末在产品数量很少
- **特点**：不计算在产品成本，全部成本由完工产品承担

### 方法2：在产品成本按年初数固定计算法
- **适用条件**：各月末在产品数量较小，或在产品数量虽大但各月之间变化不大
- **特点**：各月在产品成本固定按年初数计算

### 方法3：在产品成本按所耗原材料费用计算法
- **适用条件**：原材料费用在产品成本中所占比重很大
- **特点**：在产品只计算原材料费用，其他费用由完工产品承担

### 方法4：约当产量法
- **适用条件**：在产品数量较大，各月变化较大，各项费用比重均衡
- **特点**：将在产品按完工程度折算为约当产量，与完工产品一起分配成本

### 方法5：在产品成本按定额成本计算法
- **适用条件**：定额管理基础好，各项消耗定额比较准确、稳定
- **特点**：在产品按定额成本计算，差异由完工产品承担

### 方法6：定额比例法
- **适用条件**：定额管理基础好，各项消耗定额比较准确、稳定
- **特点**：按完工产品和在产品的定额消耗量或定额费用比例分配实际成本

## 方法选择决策树

```
开始
  ↓
在产品数量是否很少？
  ├─ 是 → 不计算在产品成本法
  └─ 否 ↓
各月在产品数量变化是否很小？
  ├─ 是 → 在产品成本按年初数固定计算法
  └─ 否 ↓
原材料费用占比是否很大？
  ├─ 是 → 在产品成本按所耗原材料费用计算法
  └─ 否 ↓
定额管理基础是否好？
  ├─ 是 → 定额比例法
  └─ 否 → 约当产量法
```

## 注意事项

- 不适用于无在产品的简单生产场景
- 方法选择应定期评估，根据企业实际情况调整
- 在满足准确性的前提下，优先选择操作简便的方法
