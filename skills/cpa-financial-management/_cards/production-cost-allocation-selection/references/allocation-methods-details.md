# 生产成本分配方法详细说明

## 六种方法详细对比

| 方法 | 适用条件 | 优点 | 缺点 | 准确性 |
|------|---------|------|------|--------|
| 不计算在产品成本法 | 在产品数量很少 | 简单 | 不准确 | 低 |
| 按年初数固定计算 | 在产品数量小或变化小 | 简单 | 不够准确 | 较低 |
| 按所耗原材料计算 | 原材料占比大 | 较简单 | 忽略其他费用 | 中等 |
| 约当产量法 | 数量大、变化大、费用均衡 | 较准确 | 计算复杂 | 较高 |
| 按定额成本计算 | 定额基础好 | 简单 | 差异由完工产品承担 | 中等 |
| 定额比例法 | 定额基础好 | 准确 | 计算复杂 | 高 |

## 约当产量法详细步骤

### 步骤1：确定在产品完工程度
- 原材料：按投料程度计算
- 加工费用：按工时完工程度计算

### 步骤2：计算约当产量
```
在产品约当产量 = 在产品数量 × 完工程度
```

### 步骤3：计算分配率
```
分配率 = (月初在产品成本 + 本月发生费用) ÷ (完工产品产量 + 在产品约当产量)
```

### 步骤4：分配成本
```
完工产品成本 = 完工产品产量 × 分配率
在产品成本 = 在产品约当产量 × 分配率
```

## 定额比例法详细步骤

### 步骤1：确定定额消耗量
- 完工产品定额消耗量 = 完工产品产量 × 单位消耗定额
- 在产品定额消耗量 = 在产品数量 × 单位消耗定额 × 完工程度

### 步骤2：计算定额比例
```
定额比例 = 完工产品定额消耗量 ÷ (完工产品定额消耗量 + 在产品定额消耗量)
```

### 步骤3：分配实际成本
```
完工产品成本 = 实际总成本 × 定额比例
在产品成本 = 实际总成本 × (1 - 定额比例)
```

## 方法选择示例

### 场景1：简单生产企业
- 在产品数量：很少（约占总产量5%）
- 各月变化：很小
- 原材料占比：中等
- 定额基础：一般

**推荐方法**：不计算在产品成本法

### 场景2：原材料密集型企业
- 在产品数量：较多
- 各月变化：较大
- 原材料占比：80%
- 定额基础：一般

**推荐方法**：在产品成本按所耗原材料费用计算法

### 场景3：现代化生产企业
- 在产品数量：很多
- 各月变化：很大
- 各项费用比重：均衡
- 定额基础：很好

**推荐方法**：定额比例法
