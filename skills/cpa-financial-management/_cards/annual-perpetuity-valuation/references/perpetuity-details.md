# 永续年金估值详解

## 公式推导

永续年金现值公式来源于等比数列求和：

```
P = A/(1+i) + A/(1+i)² + A/(1+i)³ + ...
```

当 n→∞ 时，该无穷等比数列收敛于：

```
P = A ÷ i
```

## 完整计算示例

**例3-9第一部分**：年度支付优先股估值

| 参数 | 数值 |
|------|------|
| 年度股息 A | 8 元/年 |
| 市场利率 i | 6% = 0.06 |

**计算过程**：

```
P = 8 ÷ 0.06
P = 133.333...
P ≈ 133.33 元（保留两位小数）
```

**验证**：
```
133.33 × 6% = 8.00 元 ✓
```

## 经济含义深度解读

投资者支付 **133.33元** 购买该优先股：

- 每年获得股息 **8元**
- 按 **6%** 市场利率，133.33元的年利息 = 8元
- 本金 **133.33元** 永远保留
- 实现 **永久年金** 效果

**决策边界**：
- 若市场价格 < 133.33元 → 投资回报率 > 6%，值得买入
- 若市场价格 = 133.33元 → 投资回报率 = 6%，与市场持平
- 若市场价格 > 133.33元 → 投资回报率 < 6%，不如其他投资

## 频率不匹配的调整

当支付频率与利率周期不一致时，需先调整利率：

| 支付频率 | 调整公式 |
|---------|---------|
| 季度支付 | 使用季度利率 i_quarterly = (1+i_annual)^(1/4) - 1 |
| 月度支付 | 使用月度利率 i_monthly = (1+i_annual)^(1/12) - 1 |

或直接调整公式为：

```
P = A_period × (1+i_period) ÷ i_period   [期初支付]
P = A_period ÷ i_period                  [期末支付]
```

## 常见错误

1. **利率单位混淆**：6% 应输入为 0.06，而非 6
2. **频率错配**：季度支付股息不能直接用年度利率计算
3. **忽略约束条件**：实际中股息可能变动，需用增长型永续年金模型

## 增长型永续年金（扩展）

若现金流以固定增长率 g 增长：

```
P = A₁ ÷ (i - g)    [其中 i > g]
```

A₁ 为第一期支付金额。
