# 标准成本系统建立

## 使用场景
- 企业实施标准成本控制制度
- 产品生产前需要编制标准成本文件
- 确定固定制造费用标准成本及控制方式
- 制定各成本项目的用量和价格标准

## 第一步：确定固定制造费用标准成本的适用条件

### 判断成本计算方法
检查企业采用的成本计算方法，决定固定制造费用的处理方式：

#### 变动成本计算法
- 固定制造费用不计入产品成本，作为期间费用处理
- 单位产品的标准成本中不包括固定制造费用的标准成本
- 不需要制定固定制造费用的用量标准和价格标准
- 固定制造费用的控制通过预算管理来进行

#### 完全成本计算法
- 固定制造费用要计入产品成本
- 必须确定其标准成本，包括制定用量标准和价格标准
- 需要计算单位产品固定制造费用标准成本并纳入产品标准成本卡

### 决策逻辑
```
检查企业成本计算制度 → 识别成本计算方法 → 决定是否制定固定制造费用标准成本
```

## 第二步：制定固定制造费用用量标准

### 标准类型选择
固定制造费用的用量标准与变动制造费用的用量标准相同，可选类型包括：
- 直接人工工时
- 机器工时
- 其他用量标准（如产量单位、作业次数等）

### 一致性要求（关键约束）
- 固定制造费用与变动制造费用的用量标准必须保持一致
- 采用完全相同的计量基础和数值
- 目的：便于进行差异分析（将固定制造费用成本差异与变动制造费用成本差异进行对比分析）

### 制定时点与依据
- 该标准的数量在制定直接人工用量标准时已经确定
- 直接沿用直接人工用量标准的数值，无需单独重新测定
- 示例：若单位产品直接人工用量标准为2小时，则固定制造费用用量标准也为2小时

### 车间级应用
各车间分别确定自己的用量标准：
- 第一车间：2人工工时/单位产品
- 第二车间：1人工工时/单位产品

## 第三步：编制标准成本卡

### 编制时点
- 在每种产品生产之前完成编制
- 作为生产准备工作的必要环节

### 编制内容

#### 1. 直接材料
- 分材料种类列示（如甲材料、乙材料）
- 包括：用量标准、价格标准、标准成本小计
- 示例：3.3千克 × 1.07元/千克 = 3.53元

#### 2. 直接人工
- 分车间列示（如第一车间、第二车间）
- 包括：工时标准、工资率标准、标准成本小计

#### 3. 制造费用
**变动费用**：
- 按车间细分
- 包括：用量标准、分配率、标准成本

**固定费用**：
- 按车间细分
- 包括：用量标准、标准分配率、标准成本
- 示例：第一车间2小时 × 0.5元/时 = 1元

#### 4. 单位产品标准成本总计
各成本项目合计数的总和

### 分发对象
- 各生产车间负责人（用于生产控制和成本管理）
- 会计部门（用于成本核算和差异分析）
- 仓库保管员（用于材料发放控制）
- 其他相关职工（生产计划人员、采购人员等）

### 使用目的
- 作为领料的依据：仓库根据标准成本卡规定的材料用量标准发放材料
- 作为派工的依据：生产调度根据标准工时标准安排生产任务和人工分配
- 作为支出其他费用的依据：各项费用支出需对照标准成本进行控制
- 作为成本控制的基准：实际成本与标准成本对比，计算差异并进行分析

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| costing_method | 字符串 | 成本计算方法：变动成本计算/完全成本计算 |
| quantity_standard_type | 字符串 | 用量标准类型：直接人工工时/机器工时 |
| quantity_standard_value | 数值 | 用量标准数值，如2小时/单位产品 |
| workshop_id | 字符串 | 车间标识 |
| product_id | 字符串 | 产品标识或型号 |
| standard_cost_components | 对象 | 各成本项目标准成本明细 |
| total_standard_cost | 货币 | 单位产品标准成本总计 |

## 约束条件
- 必须与变动制造费用用量标准保持一致
- 必须在直接人工用量标准制定时同步确定
- 必须在产品生产前完成编制和分发
- 需要覆盖所有成本项目

## 输出结果
```
确定是否需要制定固定制造费用标准成本：若采用完全成本计算，输出'需制定标准成本'；若采用变动成本计算，输出'通过预算管理控制'
```

```
生成标准成本卡文档并分发至相关部门，作为生产作业和成本控制的授权依据
```
