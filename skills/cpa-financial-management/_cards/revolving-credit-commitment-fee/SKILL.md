# 周转信贷协定承诺费计算

## 适用场景
- 企业签订周转信贷协定
- 存在未使用的贷款额度
- 需要计算企业应向银行支付的承诺费

## 计算步骤

### 步骤1：确定周转信贷协定的最高限额
确定周转信贷额（周转信贷协定的最高限额）。

### 步骤2：确定实际借款总额
确定企业在有效期内的实际借款总额。

### 步骤3：计算未使用的贷款限额
```
未使用额度 = 最高限额 - 实际借款总额
```

### 步骤4：确定承诺费率
确定承诺费率（由银行规定，例如0.5%）。

### 步骤5：计算承诺费金额
```
承诺费 = 未使用额度 × 承诺费率
```

## 注意事项

1. 承诺费是银行提供此项贷款的附加条件
2. 协定有效期通常超过1年，兼具短期和长期借款双重特点
3. 借款总额未超过最高限额时银行必须满足借款要求

## 变量说明

- **credit_limit**：周转信贷协定的最高限额
- **used_amount**：企业实际使用的借款金额
- **commitment_fee_rate**：银行规定的承诺费率
