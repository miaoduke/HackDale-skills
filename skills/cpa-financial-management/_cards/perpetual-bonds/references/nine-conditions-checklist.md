# 永续债债券利息政策9项条件清单

## 判定标准
满足以下9项条件中的5条及以上，可选择债券利息政策

| 序号 | 条件内容 | 是否满足 |
|------|---------|---------|
| 1 | 被投资企业对该项投资具有还本义务 | □ 是 □ 否 |
| 2 | 有明确约定的利率和付息频率 | □ 是 □ 否 |
| 3 | 有一定的投资期限 | □ 是 □ 否 |
| 4 | 投资方对被投资企业净资产不拥有所有权 | □ 是 □ 否 |
| 5 | 投资方不参与被投资企业日常生产经营活动 | □ 是 □ 否 |
| 6 | 被投资企业可以赎回，或满足特定条件后可以赎回 | □ 是 □ 否 |
| 7 | 被投资企业将该项投资计入负债 | □ 是 □ 否 |
| 8 | 该项投资不承担被投资企业股东同等的经营风险 | □ 是 □ 否 |
| 9 | 该项投资的清偿顺序位于被投资企业股东持有的股份之前 | □ 是 □ 否 |

## 判定结果
