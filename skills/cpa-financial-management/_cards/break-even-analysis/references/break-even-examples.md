# 盈亏平衡分析示例

## 基本损益方程式计算示例（例16-5）

**已知条件：**
- 每月固定成本 = 1000元
- 仅生产一种产品
- 销售单价 = 10元
- 单位变动成本 = 6元
- 本月计划销量 = 500件

**计算步骤：**
```
息税前利润 = 10 × 500 - 6 × 500 - 1000
= 5000 - 3000 - 1000
= 1000（元）
```

## 单一产品保本量计算示例（例16-6）

**已知条件：**
- 销售单价 = 2元
- 单位变动成本 = 1.2元
- 固定成本 = 1600元/月

**计算过程：**
```
单位边际贡献 = 2 - 1.2 = 0.8元
保本量 = 1600 / 0.8 = 2000（件）
```

**验证：**
```
保本量 = 1600 / (2 - 1.2) = 1600 / 0.8 = 2000（件）
```

## 多品种企业保本额计算示例

**已知条件：**
- 销售单价 = 2元
- 单位变动成本 = 1.2元
- 固定成本 = 1600元

**计算步骤：**
```
步骤① 计算单位边际贡献 = 2 - 1.2 = 0.8元
步骤② 计算边际贡献率 = 0.8 / 2 = 40%
步骤③ 计算保本额 = 1600 / 40% = 1600 / 0.4 = 4000（元）
```

**结果验证：**
```
保本额4000元 ÷ 单价2元 = 2000件，与单一产品保本量分析结果一致
```

## 方程式的扩展性

- 可以根据所需计算的问题变换成其他形式
- 可以根据企业具体情况增加一些变量，成为更复杂、更接近实际的方程式
- 损益方程式实际上是损益表的模型化表达
- 不同的损益表可以构造出不同的模型
