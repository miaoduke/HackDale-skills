# 盈亏平衡分析

## 适用场景
- 计算预期利润或确定实现目标利润所需销量
- 计算单一产品企业的盈亏平衡点销售量
- 计算多品种企业的综合盈亏平衡点销售额
- 企业利润规划和经营决策
- 本量利分析

## 核心概念

**息税前利润：** 税前经营利润，计算目标
**保本量：** 企业达到盈亏平衡时需要的销售量
**保本额：** 企业达到盈亏平衡时需要的销售额
**单位边际贡献：** 单价减去单位变动成本
**边际贡献率：** 边际贡献占销售额的百分比

## 计算方法

### 1. 基本损益方程式

**公式：**
```
息税前利润 = 单价 × 销量 - 单位变动成本 × 销量 - 固定成本
```

**推导过程：**
```
息税前利润 = 销售收入 - 总成本
= 单价 × 销量 - (变动成本 + 固定成本)
= 单价 × 销量 - 单位变动成本 × 产量 - 固定成本
= 单价 × 销量 - 单位变动成本 × 销量 - 固定成本  （假设产量=销量）
```

**方程式特性：** 含有5个相互联系的变量（单价、销量、单位变动成本、固定成本、息税前利润），给定其中4个，便可求出第5个变量的值。

**应用方式：**
- 正向计算：给定销量时，利用方程式直接计算出预期利润
- 反向计算：给定目标利润时，直接计算出应达到的销量

### 2. 单一产品保本量计算

**公式：**
```
保本量 = 固定成本 / (单价 - 单位变动成本)
保本量 = 固定成本 / 单位边际贡献
```

**推导过程：**
```
令息税前利润 = 0
0 = 单价 × 保本量 - 单位变动成本 × 保本量 - 固定成本
保本量 = 固定成本 / (单价 - 单位变动成本)
```

### 3. 多品种企业保本额计算

**公式：**
```
保本额 = 固定成本 / 边际贡献率
```

**边际贡献率计算：**
```
边际贡献率 = (单价 - 单位变动成本) / 单价 = 单位边际贡献 / 单价
```

**推导过程：**
```
息税前利润 = 销售额 × 边际贡献率 - 固定成本
令息税前利润 = 0
0 = 保本额 × 边际贡献率 - 固定成本
保本额 = 固定成本 / 边际贡献率
```

**适用性说明：** 不同品种产品的销售量直接加总没有意义，因此需要采用销售额作为统一的盈亏平衡分析指标。

## 执行流程

### 场景一：计算预期利润
1. 确定单价、单位变动成本、固定成本
2. 确定计划销量
3. 代入基本损益方程式计算息税前利润

### 场景二：计算实现目标利润所需销量
1. 确定单价、单位变动成本、固定成本
2. 设定目标利润
3. 将目标利润代入方程式，求解销量

### 场景三：计算单一产品保本量
1. 确定销售单价
2. 确定单位变动成本
3. 确定固定成本
4. 计算单位边际贡献 = 单价 - 单位变动成本
5. 计算保本量 = 固定成本 / 单位边际贡献

### 场景四：计算多品种企业保本额
1. 确定固定成本总额
2. 确定综合边际贡献率（或各产品边际贡献率及销售结构）
3. 计算保本额 = 固定成本 / 边际贡献率
4. 可根据销售结构将保本额分解到各产品

## 关键变量
- **单价：** 产品单位销售价格
- **销量：** 产品销售数量
- **单位变动成本：** 每单位产品的变动成本
- **固定成本：** 不随产量变化的固定成本总额
- **单位边际贡献：** 每销售一单位产品可用于弥补固定成本和创造利润的金额
- **边际贡献率：** 每一元销售额可用于弥补固定成本和创造利润的比例

## 输出结果
- 息税前利润金额（正值表示盈利，负值表示亏损）
- 保本量（具体数量，如2000件）
- 保本额（具体金额，如4000元）
- 实现目标利润所需的销量

## 约束条件
- 利润应为税前经营利润或息税前利润
- 假设产量和销量相等
- 单价、单位变动成本、固定成本视为稳定常量时才能用于规划利润
- 仅适用于单一产品企业（保本量计算）
- 假设产销平衡
- 假设成本性态可明确划分为固定成本和变动成本
- 假设销售结构（品种构成比例）保持稳定（多品种企业）
