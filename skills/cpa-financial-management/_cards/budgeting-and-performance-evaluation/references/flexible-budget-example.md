# 弹性预算业绩报告示例

## 基础数据
- 预算业务量：1,000
- 实际业务量：1,100
- 预算公式：
  - 收入：180q
  - 工资：65,000 + 37q
  - 材料：5.6q
  - 水电费：1,500 + 0.1q
  - 租金：28,500（固定）
  - 保险费：24,100（固定）
  - 其他费用：1,200 + 0.2q

## 弹性预算金额计算
- 收入：180 × 1,100 = 198,000
- 工资：65,000 + 37 × 1,100 = 105,700
- 材料：5.6 × 1,100 = 6,160
- 水电费：1,500 + 0.1 × 1,100 = 1,610
- 租金：28,500
- 保险费：24,100
- 其他费用：1,200 + 0.2 × 1,100 = 1,420

## 分析结论
- 总差异：实际vs固定预算差异为4,430(F)
- 作业量差异：13,710(F)，表明业务量增长带来的收益
- 收入支出差异：9,280(U)，表明经营效率下降
- 业务量增长收益被经营效率损失部分抵消
