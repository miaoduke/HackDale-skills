# 预算与业绩评价

## 适用场景
- 编制企业全面预算
- 分析实际业绩与预算差异
- 区分业务量变动影响与价格/效率影响
- 计算经济增加值中的债权资本成本率
- 评价管理者业绩

## 核心流程

### 1. 全面预算编制标准程序

**七步程序：**
1. **目标下达：** 企业决策机构依据长期规划，提出总目标并向下级下达规划指标
2. **基层草编：** 最基层成本控制人员自行草编预算
3. **部门汇总与协调：** 各部门汇总部门预算，编制销售、生产、财务等具体预算
4. **审查与平衡：** 预算委员会审查、平衡各预算，汇总出公司总预算
5. **总经理批准与审议：** 预算经过总经理批准，由审议机构通过或驳回修改
6. **董事会/上级审批：** 主要预算指标报告给董事会或上级主管单位
7. **下达执行：** 批准后的预算正式下达给各部门执行

**核心原则：** 只有执行人参与预算编制，才能使预算成为他们自愿努力完成的目标

### 2. 弹性预算业绩报告编制

**报告结构：** 五栏式
- (1) 实际结果
- (2) 收入和支出差异
- (3) 弹性预算
- (4) 作业量差异
- (5) 固定预算

**弹性预算金额计算：**
- 变动成本：单位变动成本 × 实际业务量
- 固定成本：保持固定预算金额不变
- 混合成本：固定部分 + 单位变动成本 × 实际业务量

**差异分析：**

1. **作业量差异（弹性预算 vs 固定预算）：**
```
作业量差异 = 弹性预算金额 - 固定预算金额
```
- 反映仅因业务量变动而产生的差异
- 与价格控制和经营效率无关

2. **收入和支出差异（实际结果 vs 弹性预算）：**
```
收入支出差异 = 实际结果金额 - 弹性预算金额
```
- 反映价格控制效果和经营管理效率
- 剔除业务量变动影响后的纯经营绩效

**标记规则：**
- (F)表示有利差异（收入增加或费用减少）
- (U)表示不利差异（收入减少或费用增加）

### 3. 财务业绩评价优点

**三大核心优点：**
1. **反映综合经营成果：** 以货币为统一计量单位，整合企业各方面经营活动结果
2. **数据获取便捷：** 直接从会计系统获取，无需额外建立数据收集体系
3. **操作与理解门槛低：** 利用现有会计流程和报表，管理者普遍具备财务知识基础

**常见财务评价指标：**
- 净利润（Net Profit）
- 资产报酬率（Return on Assets, ROA）
- 经济增加值（Economic Value Added, EVA）

### 4. 债权资本成本率计算

**核心公式：**
```
债权资本成本率 = 利息支出总额 ÷ 平均带息负债
```

**分子确定——利息支出总额：**
```
利息支出总额 = 费用化利息 + 资本化利息
```
- 费用化利息：计入当期损益的利息支出
- 资本化利息：计入资产成本的利息支出

**分母确定——平均带息负债：**
```
平均带息负债 = (年初带息负债 + 年末带息负债) ÷ 2
```

## 决策要点
- 预算编制需要执行人参与，否则可能成为外界强加的枷锁
- 弹性预算能够区分业务量变动影响与价格/效率影响
- 作业量差异反映市场需求或产能利用变化
- 收入支出差异反映定价策略和成本控制能力
- 债权资本成本率计算必须包含费用化利息和资本化利息两部分
- 财务业绩评价广泛应用于各类责任中心
