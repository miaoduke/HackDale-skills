# 经营战略类型判断与增长资本需求

## 何时使用

- 营业净利率与总资产周转次数呈反方向变化时
- 需要判断企业经营战略类型（高盈利低周转 vs 低盈利高周转）
- 比较不同企业经营战略差异
- 评估销售增长计划下的资本需求

## 核心原则

**禁止单独判断**：仅从营业净利率的高低并不能看出业绩好坏

**必须联动分析**：应把营业净利率与总资产周转次数联系起来考察企业经营战略

**战略无优劣**：采取"高盈利、低周转"还是"低盈利、高周转"的方针，是企业根据外部环境和自身资源作出的战略选择

## 两种典型战略模式

### 模式一：高盈利、低周转（高附加值战略）

| 维度 | 特征 |
|------|------|
| 指标特征 | 营业净利率较高，总资产周转次数较低 |
| 实现路径 | 增加产品附加值，往往需要增加投资 |
| 代价 | 引起周转次数的下降 |
| 典型行业 | 制造业（通常营业净利率较高，周转次数较低） |

### 模式二：低盈利、高周转（薄利多销战略）

| 维度 | 特征 |
|------|------|
| 指标特征 | 总资产周转次数较高，营业净利率较低 |
| 实现路径 | 降低价格以加快周转 |
| 代价 | 引起营业净利率下降 |
| 典型行业 | 零售业（通常周转次数很高，营业净利率很低） |

## 最终评价指标

**总资产净利率** = 营业净利率 × 总资产周转次数

反映管理者运用企业资产赚取盈利的业绩，是最重要的盈利能力指标。

## 销售增长与资本需求的因果关系

### 传导机制

```
销售增长 → 业务规模扩大 → 存货备货增加
        → 赊销规模扩大 → 应收账款增加
        → 营运资产占用资金增加 → 需要更多资本
```

### 核心结论

销售增长与资本需求呈正相关关系：**销售增长得越多，需要的资本越多**

### 关键原理

- 由商业运营的"营运资金占用"特性决定
- 即使盈利的销售增长，在现金流时间错配的情况下也会产生资金缺口
- 公司必须提前规划资本来源，否则增长将受资金约束
