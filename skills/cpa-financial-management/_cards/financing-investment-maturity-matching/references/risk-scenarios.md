# 期限错配风险情景详解

## 情景一：房地产企业的短债长投危机

**背景**：某房地产企业使用短期信托资金（1年期）购置土地并开发住宅项目（开发周期3年）。

**风险演化**：
1. **T+1年**：短期债务到期，项目尚未预售，无现金流入
2. **应对措施**：被迫借入新的短期高利贷（利率上涨200bps）
3. **T+2年**：信贷紧缩，无法获得新融资
4. **最终结果**：被迫折价30%出售在建项目，破产清算

**教训**：长期资产（土地+在建工程）使用短期债务支持，遭遇再融资风险。

## 情景二：制造业企业的利率波动损失

**背景**：某制造企业为购置设备（使用寿命10年）使用短期银行贷款（6个月期），计划滚动续借。

**财务影响计算**：
- 初始利率：4%
- 第2次续借利率：6%（+200bps）
- 第3次续借利率：5.5%
- 长期贷款利率（对比基准）：5%固定

**3年利息成本对比**：
- 短期滚动方案：平均利率5.17%，且面临不确定性
- 长期贷款方案：固定利率5%，成本确定

**隐性成本**：财务团队每6个月需花费2周时间协调续借，机会成本未计入。

## 情景三：合理的成本优先例外

**背景**：某企业在信贷紧缩期无法获得长期贷款，但有一个回报率25%的固定资产投资项目。

**风险缓释方案**：
1. 使用短期贷款（利率7%）启动项目
2. 同时申请备用信贷额度（额度为贷款额的120%）
3. 设立偿债基金，每月提取现金流入的30%作为流动性储备
4. 6个月后信贷环境改善，立即置换为长期贷款

**结果**：成功锁定高收益项目，通过严格的风险控制避免了期限错配危机。

## 决策检查清单

在批准短期债务支持长期资产前，确认以下问题：

- [ ] 是否已穷尽长期融资渠道？
- [ ] 是否建立了至少覆盖2个债务周期的流动性储备？
- [ ] 是否获得了备用授信额度？
- [ ] 资产变现是否可行（是否存在活跃二级市场）？
- [ ] 项目收益率是否足够覆盖潜在的利率上涨（建议>15%）？
- [ ] 是否制定了明确的长期融资置换时间表？

若以上任一答案为"否"，则禁止该期限错配方案。
