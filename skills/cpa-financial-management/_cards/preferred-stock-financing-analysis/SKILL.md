# 优先股融资分析

## 适用场景
- 确定优先股必要报酬率（介于债券和普通股之间）
- 比较优先股与债券的破产风险差异
- 比较优先股与普通股的控制权稀释差异
- 评估优先股在资本结构中的定位

## 风险层级与资本成本

### 清偿与支付优先级
破产/财务困难时的顺序：
1. **债权人**（债务利息、本金清偿）
2. **优先股股东**（股利、剩余财产）
3. **普通股股东**（最后分配）

### 必要报酬率关系（同一公司）
```
r_债券 < r_优先股 < r_普通股
```

**含义**：
- 优先股风险 > 债券（清偿次级）
- 优先股风险 < 普通股（支付优先）
- 因此：优先股筹资成本 > 债务成本，但 < 普通股成本

## 运营优势对比

### 相比债券的优势
1. **无破产风险**：不支付优先股股利不会导致公司破产（不同于债券违约）
2. **无本金偿还义务**：无到期期限，形成永久性资本

### 相比普通股的优势
1. **控制权保护**：通常无表决权，不稀释现有股东控制权
2. **避免股权分散**：增发普通股会分散投票权，优先股不会

## 三维决策矩阵

| 维度 | 优先股 | 债券 | 普通股 |
|------|--------|------|--------|
| 资本成本 | 中等 | 最低 | 最高 |
| 破产风险 | 无 | 有（违约风险） | 无 |
| 控制权稀释 | 无 | 无 | 有 |

**最优选择场景**：
- 希望避免破产风险（不选债券）
- 不愿稀释控制权（不选普通股）
- 可接受中等资本成本
