# 流动资产资金来源配置

## 使用场景
当企业实施适中型筹资策略，需要配置流动资产资金来源时，使用此技能进行二元分类与配置。

## 触发条件
IF (实施适中型筹资策略) AND (需要配置流动资产资金来源) THEN 应用二元分类与配置规则

## 流动资产二元分类标准

按投资需求的时间长短划分：

### 稳定性流动资产（Stable Current Assets）
- 即使在企业经营淡季也仍然需要保留的流动资产
- 用于满足企业长期稳定运行
- 属于长期需求，甚至是永久需求

### 波动性流动资产（Fluctuating Current Assets）
- 受季节性、周期性影响的流动资产
- 如季节性存货、销售旺季的应收账款等
- 属于真正的短期需求

## 资金来源配置规则

### 波动性流动资产
→ 使用**临时性负债**（短期金融负债）筹集资金
→ 利用短期银行借款等短期金融负债工具

### 稳定性流动资产 + 长期资产
→ 使用**权益资本、长期债务和经营性流动负债**筹集

## 数学表达式

**公式①**：
长期资产 + 稳定性流动资产 = 股东权益 + 长期债务 + 经营性流动负债

**公式②**：
波动性流动资产 = 短期金融负债

## 实施要求

1. 企业的短期金融负债筹资计划必须严密
2. 实现现金流动与预期安排相一致
3. 根据波动性流动资产需求时间和数量选择与之配合的短期金融负债
4. 关键认知：稳定性流动资产虽在会计上列为流动资产，但实质是长期占用资金，应由长期资金来源支持；只有季节性变化引起的资金需求才是真正的短期需求

## 输出结果
确定长期资金需求总额（长期资产+稳定性流动资产）和短期资金需求总额（波动性流动资产），分别配置对应期限的资金来源。
