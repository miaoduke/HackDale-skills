# 权衡理论企业价值评估与资本结构决策

## 适用场景
- 企业考虑债务融资以获取抵税收益，同时存在陷入财务困境的潜在风险
- 需要评估不同负债水平下的企业价值
- 确定使企业价值最大化的最优资本结构（债务与权益比率）
- 计算有负债企业的总价值(V_L)和股权价值(S)

## 核心估值模型

### 1. 权衡理论估值公式
基于修正的 MM 理论命题：
```
V_L = V_U + PV(利息抵税) - PV(财务困境成本)
```

其中：
- V_L：有负债企业的价值
- V_U：无负债企业的价值
- PV(利息抵税)：债务利息抵税收益的现值（税盾效应）
- PV(财务困境成本)：财务困境成本的现值

### 2. 企业价值构成公式
```
V = S + B + P
```

其中：
- V：企业总价值
- S：普通股价值（股权价值）
- B：长期债务价值（简化假设：等于账面价值）
- P：优先股价值（简化假设：等于账面价值）

### 3. 股权价值永续折现模型
```
S = [(EBIT - I)(1 - T) - PD] / r_s
```

其中：
- EBIT：息税前利润（假设永续不变）
- I：年利息额（= 债务价值 B × 债务税前资本成本 r_d）
- T：企业所得税税率
- PD：优先股股息（若存在优先股）
- r_s：权益资本成本（股东要求的报酬率，假设不变）

**计算逻辑**：归属于普通股股东的净收益（税后净利润减去优先股股息）按永续年金折现。

## 最优资本结构决策

### 判定条件（边际分析）
最佳资本结构出现在：
```
债务抵税收益的边际价值 = 增加的财务困境成本的现值
```

此时：
- 债务利息抵税收益的现值与财务困境成本的现值之间的差额最大
- 企业价值达到最大值 V_L*

### 企业价值与负债比率关系

**A 点前阶段**：财务困境成本不明显，债务抵税收益起主导作用，负债增加持续提升企业价值。

**A 点至 B 点阶段**：随着债务比率增加，财务困境成本作用逐渐加强，但抵税收益仍占主导，企业价值继续上升但增速减缓。

**B 点（最优点）**：债务利息抵税收益的增量与财务困境成本的增量相平衡，企业价值达到最大 V_L*，此时的债务与权益比率即为**最佳资本结构**。

**B 点之后阶段**：财务困境的不利影响超过抵税收益，企业价值开始加速下降。

## 执行步骤

1. **确定无负债价值(V_U)**：计算企业无债务时的基础价值
2. **估算税盾现值**：计算不同债务水平下利息抵税收益的现值
3. **估算财务困境成本现值**：评估不同负债比率下陷入财务困境的概率和成本
4. **计算有负债企业价值(V_L)**：应用权衡理论公式 V_L = V_U + PV(税盾) - PV(困境成本)
5. **计算股权价值(S)**：使用永续折现模型 S = [(EBIT-I)(1-T)-PD]/r_s，或 S = V_L - B - P
6. **确定最优资本结构**：找到使 V_L 最大化的债务比率（B 点），即边际抵税收益等于边际财务困境成本的点
7. **资本结构调整决策**：
   - 实际负债比率 < B 点：可增加债务以提升价值
   - 实际负债比率 = B 点：维持现状
   - 实际负债比率 > B 点：应降低债务以避免价值损失

## 关键假设与约束

- 假设 EBIT 永续不变（适用于永续经营企业）
- 假设股东要求的报酬率(权益资本成本)不变
- 长期债务和优先股价值等于其账面价值（简化处理）
- 假设市场不完全完美（考虑税收和财务困境）
- 暂不考虑代理成本等其他因素
