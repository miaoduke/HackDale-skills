# 资本结构优化决策

## 适用场景
进行筹资决策、资本结构优化、财务规划时，应用最优资本结构决策规则。

## 基于WACC最小的最优资本结构决策规则

### 核心问题
筹资决策的核心问题是决定资本结构（capital structure）。

### 最优标准
理论上最优资本结构是使股东财富最大化的资本结构。

### 关键假设
由于估计资本结构对股东财富的影响非常困难，通常假设资本结构不改变公司的现金流量。

### 决策规则
在满足上述假设条件下，加权平均资本成本（WACC）最小的资本结构就是使公司价值最大化的资本结构。

### 股东财富影响推导
在股东投资资本和债务价值不变的情况下，该资本结构（即使WACC最小的结构）也是使股东财富最大化的资本结构。

### 实践依据
预测资本结构变化对平均资本成本的影响，比预测其对股东财富的影响要容易，因此加权平均资本成本可以指导资本结构决策。

### 实施步骤
1. 计算不同资本结构方案下的WACC
2. 比较各方案的WACC数值
3. 选择WACC最小的资本结构作为最优方案

## 扩展的资本结构权衡理论模型

### 模型公式
```
VL = VU + PV(利息抵税) − PV(财务困境成本) − PV(债务的代理成本) + PV(债务的代理收益)
```

### 各组成部分含义

| 组成部分 | 含义 |
|---------|------|
| VL（Levered Firm Value） | 有杠杆企业的价值 |
| VU（Unlevered Firm Value） | 无杠杆企业的价值 |
| PV(利息抵税) | 债务利息抵税带来的税盾效应现值，这是债务融资的主要收益来源 |
| PV(财务困境成本) | 企业因负债过高可能陷入财务困境所产生的成本现值，包括直接成本（法律费用、破产清算费用）和间接成本（客户流失、供应商收紧信用、人才流失等） |
| PV(债务的代理成本) | 由于股东与债权人之间的利益冲突产生的成本现值，包括：资产替代问题、投资不足问题、债权稀释问题、资金转移问题 |
| PV(债务的代理收益) | 债务融资带来的治理改善收益现值，包括：减少管理层自由现金流抑制过度投资、增加管理层破产压力提高经营效率、债务契约的约束作用 |

### 模型核心逻辑
企业最优资本结构是在债务的税盾收益、财务困境成本、代理成本与代理收益之间进行权衡的结果。当增加负债带来的边际收益等于边际成本时，企业价值达到最大化。

### 重要说明
代理理论为资本结构如何影响企业价值的主要因素以及内在逻辑关系提供了一个基本分析框架，但这些结论并非与企业的实际做法完全一致。资本结构决策通常是由经理人员在符合自身基本动机的基础上综合考虑其他多种因素作出的。

## 关键变量

| 变量 | 类型 | 描述 |
|------|------|------|
| 加权平均资本成本(WACC) | 百分比 | 不同资本结构下的综合资本成本 |
| 资本结构 | 结构比例 | 债务与权益的比例组合 |
| 股东投资资本 | 金额 | 股东投入的资本金额，假设不变 |
| 债务价值 | 金额 | 公司债务的市场价值，假设不变 |
| 公司价值 | 金额 | 企业整体价值 |
| 股东财富 | 金额 | 股东权益价值 |

## 决策输出
确定最优资本结构方案（债务/权益比例），该方案同时实现公司价值最大化和股东财富最大化。
