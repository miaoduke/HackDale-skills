# 投资项目评估框架

## 适用场景
- 进行长期资本性资产投资决策
- 评估投资项目可行性
- 计算投资方案的增量现金流量
- 区分项目成本类型
- 界定资本使用期限

## 投资项目基本特征

### 投资根本目标
为实现公司增长，进而达成**股东财富最大化**目标。

### 典型投资活动
- 开发新产品
- 建造生产线
- 其他需要投入资本并开展项目建设的活动

### 四大基本特征

**1. 目标性**
- 投资项目具有明确的目标导向
- 旨在实现特定的战略或财务目标

**2. 长期性**
- 投资回收期长
- 对企业未来多年的经营活动产生持续影响
- 区别于日常经营性支出

**3. 独特性**
- 每个项目具有独特的技术、市场或管理特点
- 是一次性的非重复性活动

**4. 不可逆性**
- 一旦投入资本开展项目建设，难以完全撤回或改变
- 沉没成本高
- 决策具有承诺价值（Commitment Value）

### 决策意义
由于具备长期性和不可逆性，投资项目决策必须谨慎，需进行系统的资本预算评价。

## 长期资本构成与分类

### 长期资本定义
资本必须满足"可长期使用"特征，即企业可在较长期间内持续占用该资本用于生产经营。

### 第一类别：权益资本

**特征：**
- 一般不需要归还本金
- 企业可永久使用（无到期日）

**资本属性：**
- 属于长期资本的核心组成部分

### 第二类别：长期债务资本

**期限门槛：**
- 债务合同期限必须在**1年以上**（含1年）

**形式包括：**
- 长期借款（银行长期贷款）
- 长期债券（公司债等）

**使用特征：**
- 虽然最终需要归还本金
- 但可在约定期限内持续使用

### 排除项
期限在1年以内的债务资本（如短期借款、应付票据）不属于长期资本，应归类为短期资金来源。

### 组合确认
```
长期资本 = 权益资本 + 长期债务资本（满足期限>1年条件的债务）
```

## 相关成本与非相关成本区分

### 相关成本识别

**定义：**
与特定决策有关的、在分析评价时必须加以考虑的有差别的未来成本。

**特征：**
- 随着决策的改变而改变

**常见类型：**
- 变动成本
- 边际成本
- 机会成本
- 重置成本
- 付现成本
- 可避免成本
- 可延缓成本
- 专属成本
- 差量成本

### 非相关成本识别

**定义：**
与特定决策无关的、在分析评价时不必加以考虑的成本。

**常见类型：**
- 沉没成本
- 不可避免成本
- 不可延缓成本
- 无差别成本
- 共同成本

### 判断逻辑（以沉没成本为例）

**检查步骤：**
1. 检查成本是否已经发生
2. 检查成本是否无法收回

**示例：**
某公司新建车间支付的5万元咨询费，不管公司是否采纳新建方案，该笔支出都已发生且无法收回，与公司未来的总现金流量无关，因此属于非相关成本。

### 决策后果分析

**警示：**
- 如果将非相关成本纳入投资方案的总成本
- 会导致一个有利的方案变为不利的方案
- 或者一个较好的方案变为较差的方案
- 从而造成决策错误

## 评估流程

### 步骤1：识别投资项目
- 确认是否属于长期资本性投资
- 识别四大基本特征

### 步骤2：界定资本来源
- 区分权益资本和债务资本
- 确认资本使用期限（>1年为长期）

### 步骤3：区分成本类型
- 识别相关成本
- 排除非相关成本（特别是沉没成本）

### 步骤4：计算增量现金流量
- 仅考虑相关成本
- 计算项目全生命周期现金流

### 步骤5：进行决策分析
- 应用净现值（NPV）等方法
- 比较投资报酬率与资本成本
