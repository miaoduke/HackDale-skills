# 成本分类详细示例

## 相关成本示例

### 机会成本
- 公司拥有一块土地，可用于建厂或出租
- 若建厂，则放弃的租金收入即为机会成本
- 属于相关成本，必须纳入决策

### 重置成本
- 设备更新决策中，新设备的购置成本
- 属于相关成本

### 可避免成本
- 某项广告支出，若不投放则可节省
- 属于相关成本

## 非相关成本示例

### 沉没成本
- 已支付的市场调研费用
- 已发生的设备购置成本
- 无论决策如何都无法收回

### 不可避免成本
- 固定资产折旧（若设备已购置）
- 管理人员基本工资

### 共同成本
- 多个产品共享的厂房租金
- 需按合理方式分摊，但总额与单个产品决策无关

## 决策错误案例

### 错误做法
```
项目A：
- 未来收益：100万元
- 未来成本：80万元
- 沉没成本：30万元（已发生）

错误计算：净收益 = 100 - 80 - 30 = -10万元 → 拒绝项目
```

### 正确做法
```
项目A：
- 未来收益：100万元
- 未来成本：80万元
- 沉没成本：30万元（非相关，不纳入）

正确计算：净收益 = 100 - 80 = 20万元 → 接受项目
```

**结论：** 错误地将沉没成本纳入决策，导致拒绝了一个有利的项目。
