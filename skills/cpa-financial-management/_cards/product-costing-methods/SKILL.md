# 产品成本计算方法

## 方法选择指南

### 品种法
**适用条件**：
- 大量大批的单步骤生产企业
- 生产按流水线组织、管理上不要求按生产步骤计算成本的企业

**特点**：
- 以产品品种为成本对象
- 最基础的成本计算方法
- 成本计算程序是成本计算的一般程序

### 逐步综合结转分步法
**适用条件**：
- 大量大批连续式复杂生产的企业
- 半成品经常作为商品对外销售（如钢铁厂、汽车制造厂、纺织厂）

**特点**：
- 需要计算各步骤半成品成本
- 半成品通过半成品库收发
- 可采用实际成本或计划成本结转

### 约当产量法（先进先出）
**适用条件**：
- 存在月初在产品
- 需要区分期初在产品成本和本期生产成本

**特点**：
- 假设先开始生产的产品先完工
- 仅使用本月发生生产费用计算分配率

## 品种法成本计算程序

### 步骤1：设置成本计算单
包含以下栏目：
- 成本项目（直接材料费、直接人工费、燃料和动力费、制造费用）
- 月初在产品成本
- 本月生产费用
- 生产费用合计
- 产品成本（总成本、单位成本）
- 月末在产品成本

### 步骤2：归集月初在产品成本
从上月成本计算单结转

### 步骤3：归集本月生产费用
根据原始凭证和费用分配表归集各项费用

### 步骤4：计算生产费用合计
```
生产费用合计 = 月初在产品成本 + 本月生产费用
```

### 步骤5：在完工产品和在产品之间分配
将生产费用合计在完工产品总成本和月末在产品成本之间进行分配

### 步骤6：计算单位成本
```
单位成本 = 完工产品总成本 ÷ 完工产品数量
```

### 步骤7：编制完工产品入库分录
```
借：库存商品——XX产品
  贷：生产成本——基本生产成本——XX产品
```

## 逐步综合结转分步法计算流程

### 第一车间（半成品）成本计算
1. 依据费用分配表、产量月报及在产品定额成本资料登记成本计算单
2. 计算完工半成品成本：
```
完工半成品成本 = 月初在产品定额成本 + 本月生产费用 - 月末在产品定额成本
```
3. 编制会计分录：
```
借：自制半成品
  贷：生产成本——基本生产成本——第一车间
```

### 半成品库收发核算
1. 根据入库单和领用单登记半成品明细账
2. 采用先进先出或加权平均法计算单位成本
3. 编制领用分录：
```
借：生产成本——基本生产成本——第二车间
  贷：自制半成品
```

### 第二车间（产成品）成本计算
1. 依据费用分配表、领用单、产量月报及在产品定额成本资料登记成本计算单
2. 计算产成品转出成本：
```
产成品转出成本 = 月初在产品定额成本 + 本月费用（含半成品） - 月末在产品定额成本
```
3. 编制会计分录：
```
借：产成品
  贷：生产成本——基本生产成本——第二车间
```

## 约当产量法（先进先出）计算流程

### 步骤1：确定约当产量组成部分

**直接材料约当产量**：
```
月初在产品本月加工约当产量 = 月初在产品数量 × (1 - 已投料比例)
本月投入本月完工产品数量 = 本月全部完工产品数量 - 月初在产品数量
月末在产品约当产量 = 月末在产品数量 × 本月投料比例
```

**转换成本约当产量**：
```
月初在产品本月加工约当产量 = 月初在产品数量 × (1 - 月初在产品完工程度)
本月投入本月完工产品数量 = 本月全部完工产品数量 - 月初在产品数量
月末在产品约当产量 = 月末在产品数量 × 月末在产品完工程度
```

### 步骤2：计算单位成本（分配率）
```
分配率 = 本月发生生产费用 / (月初在产品本月加工约当产量 + 本月投入本月完工产品数量 + 月末在产品约当产量)
```

**注意**：仅使用本月发生生产费用作为分子

### 步骤3：计算完工产品成本
```
完工产品成本 = 月初在产品成本 + (月初在产品本月加工约当产量 × 分配率) + (本月投入本月完工产品数量 × 分配率)
```

### 步骤4：计算月末在产品成本
```
月末在产品成本 = 月末在产品约当产量 × 分配率
```

### 特殊情况
若原材料在开始生产时一次投入：
- 月初在产品本月加工约当产量(直接材料) = 0
- 月末在产品约当产量(直接材料) = 月末在产品数量
