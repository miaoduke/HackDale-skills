# 预算编制示例

## 固定预算法示例

**企业情况：**
- 经营业务稳定
- 预计年销售量：10,000件
- 预计单位变动成本：50元
- 预计固定成本：200,000元

**预算编制：**
```
销售收入 = 10,000 × 100 = 1,000,000元
变动成本 = 10,000 × 50 = 500,000元
固定成本 = 200,000元
利润 = 1,000,000 - 500,000 - 200,000 = 300,000元
```

## 公式法示例（例18-1）

**单一成本项目：** 修理费用

**参数确定：**
- 固定修理费用 a = 3,000元
- 单位工时变动修理费用 b = 2元/工时
- 预计修理工时 x = 3,500小时

**计算：**
```
预算修理费用 = 3,000 + 2 × 3,500 = 10,000元
```

## 公式法示例（例18-2）

**多项目成本预算：**

| 费用项目 | 固定费用(元/月) | 变动费用(元/工时) |
|----------|------------------|-------------------|
| 运输费用 | 0 | 0.2 |
| 电力费用 | 0 | 1.0 |
| 材料费用 | 0 | 0.1 |
| 修理费用 | 85 | 0.85 |
| 油料费用 | 108 | 0.2 |
| 折旧费用 | 300 | 0 |
| 人工费用 | 100 | 0 |
| **合计** | **593** | **2.35** |

**业务量适用范围：** 420-660人工工时

**业务量阈值处理：**
- 若 x ≤ 600工时：a = 593元
- 若 x > 600工时：a = 693元（修理费用固定部分从85元增至185元）

**计算示例：**
```
当 x = 500工时时：
预算成本 = 593 + 2.35 × 500 = 593 + 1,175 = 1,768元

当 x = 650工时时：
预算成本 = 693 + 2.35 × 650 = 693 + 1,527.5 = 2,220.5元
```

**备注：** 需明确说明600工时为修理费用固定成本调整点
