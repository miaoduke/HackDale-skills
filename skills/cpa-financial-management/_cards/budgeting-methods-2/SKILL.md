# 预算编制方法

## 使用场景
- 编制营业预算时
- 编制固定费用预算时
- 需要测算特定业务量水平下的成本预算时
- 处理混合成本项目预算时
- 业务量在一定范围内波动需要灵活测算时

## 方法一：固定预算法（静态预算法）

### 定义
以预算期内正常、可实现的某一固定的业务量水平为唯一基础编制预算的方法

### 执行步骤

1. **确定预算基础：**
   - 选择预算期内正常、可实现的某一固定业务量水平
   - 业务量可以是生产量、销售量等

2. **编制预算：**
   - 基于该确定的单一固定业务量水平进行预算编制

### 适用条件
- 经营业务稳定的企业
- 产品产销量稳定的企业
- 能准确预测产品需求及产品成本的企业
- 编制固定费用预算

### 缺点
- **适应性差：** 无法适应业务量变动
- **可比性差：** 当实际业务量与预算差异大时，可比性差

## 方法二：公式法

### 定义
利用成本性态模型 y = a + bx 编制成本费用预算的方法

### 适用条件
- 需要测算特定业务量水平下的成本预算总额
- 该成本可分解为固定成本和变动成本
- 成本性态可用线性模型近似表示

### 执行步骤

1. **建立总成本性态模型：**
   ```
   y = a + bx
   ```
   - y：某项成本预算总额（元）
   - a：该项成本中的固定成本预算总额（元）
   - b：该项成本中的单位变动成本预算额（元/业务量单位）
   - x：预计业务量（业务量单位）

2. **确定参数：**
   - 通过成本性态分析确定a和b
   - 对于多项目，分别确定各项目的a和b后加总

3. **计算预算：**
   ```
   预算成本 = a + b × x
   ```

4. **处理业务量阈值：**
   - 若存在阶梯成本，需分段处理
   - 明确说明不同业务量范围对应的固定成本参数

### 处理非线性成本

**阶梯成本：**
- 必须先用数学方法修正为直线（线性化近似）
- 或分段处理不同业务量范围

**曲线成本：**
- 必须先用数学方法修正为直线
- 才能应用公式法

### 核心优势
只要在预算中列示a（固定成本）和b（单位变动成本），便可随时利用公式计算任一业务量（x）的预算成本（y），无需为每个业务量水平单独编制预算

## 关键变量

- **固定业务量：** 预算期内确定的正常、可实现的单一业务量水平
- **y：** 某项成本预算总额
- **a：** 固定成本预算总额
- **b：** 单位变动成本预算额
- **x：** 预计业务量

## 约束条件
- 阶梯成本必须数学修正为直线后才能应用公式法
- 曲线成本必须数学修正为直线后才能应用公式法
- 不同业务量范围可能对应不同的固定成本参数

## 输出结果
- 基于固定业务量的预算方案（固定预算法）
- 成本性态模型参数（公式法）
- 特定业务量下的预算成本（公式法）
