# 无偏预期理论

## 适用场景
- 计算长期债券即期利率
- 解释收益率曲线形状（上斜/下斜/水平/峰型）
- 分析市场对未来短期利率的预期
- 理解利率期限结构

## 核心定义
利率期限结构完全取决于市场对未来利率的预期。长期债券即期利率是短期债券预期利率的函数，即长期即期利率是短期预期利率的无偏估计。

## 计算公式

### 以2年期为例
设1年期即期利率为 r1，1年后预期的1年期利率为 f1。
```
2年期即期利率 r2 = √[(1+r1) × (1+f1)] - 1
```

### 计算示例
若 r1=6%，f1=7%，则：
```
r2 = √[(1+6%)×(1+7%)] - 1 = 6.5%
```

## 市场均衡调节机制

### 若实际2年期即期利率低于理论计算值
例如：实际6.2% < 理论6.5%

**含义**：2年期利率便宜，1年期利率昂贵

**借款者行为**：
- 转向2年期借款（需求增加）
- 放弃1年期借款（需求减少）

**贷款者行为**：
- 放弃2年期贷款（供给减少）
- 转向1年期贷款（供给增加）

**结果**：2年期利率上升，1年期利率下降，直至市场利率重回均衡。

## 收益率曲线形状解释

### 上斜收益率曲线
市场预期未来短期利率会上升。

### 下斜收益率曲线
市场预期未来短期利率会下降。

### 水平收益率曲线
市场预期未来短期利率保持稳定。

### 峰型收益率曲线
市场预期较近一段时期短期利率会上升，而在较远的将来，市场预期短期利率会下降。

## 理论局限性

1. 假定人们对未来短期利率具有确定的预期（过于理想化）
2. 假定资金在长期资金市场和短期资金市场之间的流动完全自由（与金融市场实际差距太远）
