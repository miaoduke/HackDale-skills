# 外汇折算风险详细示例

## 示例1：外币资产折算

### 基本情况

某中国公司于2023年1月1日从美国进口设备，合同金额100万美元。

- 交易发生日汇率（2023/1/1）：1 USD = 6.90 CNY
- 资产负债表日汇率（2023/12/31）：1 USD = 7.10 CNY

### 折算计算

**初始入账（2023/1/1）**：
```
固定资产（美元） = 100万美元
固定资产（人民币） = 100 × 6.90 = 690万元
```

**期末折算（2023/12/31）**：
```
固定资产（美元） = 100万美元（不变）
固定资产（人民币） = 100 × 7.10 = 710万元
```

**折算损益**：
```
折算收益 = 710 - 690 = 20万元
```

### 影响分析

- **会计影响**：固定资产账面价值增加20万元
- **现金流影响**：无实际现金流变化
- **财务分析影响**：资产总额增加，可能影响资产周转率等指标

## 示例2：外币负债折算

### 基本情况

某中国公司于2023年6月1日向美国银行借款50万美元。

- 借款日汇率（2023/6/1）：1 USD = 7.00 CNY
- 资产负债表日汇率（2023/12/31）：1 USD = 7.10 CNY

### 折算计算

**初始入账（2023/6/1）**：
```
短期借款（美元） = 50万美元
短期借款（人民币） = 50 × 7.00 = 350万元
```

**期末折算（2023/12/31）**：
```
短期借款（美元） = 50万美元（不变）
短期借款（人民币） = 50 × 7.10 = 355万元
```

**折算损益**：
```
折算损失 = 355 - 350 = 5万元
```

### 影响分析

- **会计影响**：短期借款账面价值增加5万元，产生汇兑损失
- **现金流影响**：无实际现金流变化
- **财务分析影响**：负债总额增加，资产负债率上升

## 示例3：综合影响

### 基本情况

某跨国公司同时持有外币资产和外币负债：

| 项目 | 金额（万美元） | 初始汇率 | 期末汇率 |
|------|--------------|---------|---------|
| 应收账款 | 200 | 6.90 | 7.10 |
| 应付账款 | 150 | 6.90 | 7.10 |

### 折算计算

**应收账款**：
```
初始金额 = 200 × 6.90 = 1380万元
期末金额 = 200 × 7.10 = 1420万元
折算收益 = 1420 - 1380 = 40万元
```

**应付账款**：
```
初始金额 = 150 × 6.90 = 1035万元
期末金额 = 150 × 7.10 = 1065万元
折算损失 = 1065 - 1035 = 30万元
```

**净折算收益**：
```
净折算收益 = 40 - 30 = 10万元
```

### 自然对冲效果

由于外币资产和外币负债同时存在，部分折算风险相互抵消。

## 折算方法比较

### 现行汇率法
- **适用**：国外子公司独立经营
- **方法**：所有资产负债项目按期末汇率折算
- **特点**：简单，但可能扭曲财务比率

### 时态法
- **适用**：国外子公司是母公司延伸
- **方法**：货币性项目按期末汇率，非货币性项目按历史汇率
- **特点**：更符合经济实质，但计算复杂

## 风险管理策略详解

### 1. 自然对冲

**原理**：使外币资产和外币负债规模匹配，减少净外币头寸。

**实施**：
- 外币资产增加时，相应增加外币负债
- 外币负债增加时，相应增加外币资产

**示例**：
```
外币应收账款100万美元 → 借入外币100万美元
净外币头寸 = 100 - 100 = 0
折算风险 = 0
```

### 2. 货币选择

**原则**：
- 优先使用稳定货币（如美元、欧元）
- 避免使用波动剧烈的货币（如新兴市场货币）
- 收入和支出使用相同货币

### 3. 会计政策选择

**考虑因素**：
- 子公司经营独立性
- 母公司管理要求
- 会计准则规定
- 信息使用者需求

### 4. 披露与沟通

**披露内容**：
- 外币项目明细
- 折算方法
- 折算损益金额
- 汇率变动影响

**沟通要点**：
- 折算损益不影响现金流
- 折算损益是暂时的
- 关注经营业绩而非会计损益
