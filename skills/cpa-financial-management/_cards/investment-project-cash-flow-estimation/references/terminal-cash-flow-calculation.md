# 终结期现金流量详细计算

## 设备变现税后净现金流入

### 情形1：变现收益（变现价值 > 账面价值）

```
变现收益 = 变现价值 - 账面价值
应纳所得税 = 变现收益 × 所得税税率
税后变现流入 = 变现价值 - 应纳所得税
             = 变现价值 - (变现价值 - 账面价值) × 税率
```

### 情形2：变现损失（变现价值 < 账面价值）

```
变现损失 = 账面价值 - 变现价值
抵减所得税 = 变现损失 × 所得税税率
税后变现流入 = 变现价值 + 抵减所得税
             = 变现价值 + (账面价值 - 变现价值) × 税率
```

### 情形3：无盈亏（变现价值 = 账面价值）

```
税后变现流入 = 变现价值（无税务影响）
```

## 终结期净现金流量汇总

```
终结期现金流量 = 设备变现税后净现金流入 
               + 收回营运资本现金流入 
               - 弃置义务税后现金流出
```

## 注意事项

1. 设备变现必须考虑税后净额，不能仅使用变现价值
2. 营运资本回收通常假设全额回收，除非有特定损失
3. 弃置义务可能发生在项目结束后一段时间，需考虑折现
