# 投资项目现金流量估计

## 何时使用

- 估计投资方案的净经营性长期资产总投资
- 计算每年经营现金净流量
- 编制投资项目现金流量表，用于NPV、IRR等资本预算分析

## 核心原则

**只有增量现金流量才是与项目相关的现金流量。**

增量现金流量：接受或拒绝某个投资方案后，企业总现金流量因此发生的变动。

## 建设期现金流量

**构成要素：**

| 项目 | 性质 | 说明 |
|-----|------|------|
| 设备购置支出 | 现金流出 | 固定资产购买价款 |
| 安装支出 | 现金流出 | 使设备达到可使用状态的安装调试费用 |
| 垫支营运资本 | 现金流出 | 为项目运行投入的流动资金（存货、应收账款等） |
| 机会成本 | 现金流出 | 占用现有资源（厂房、设备、土地）的税后机会成本 |

**计算公式：**
```
建设期净现金流量 = -(设备购置 + 安装支出 + 垫支营运资本 + 机会成本)
```

## 运营期现金流量

**多部门协作预测：**
- **销售部门**：预测售价和销量
- **产品开发/技术部门**：估计长期资产投资
- **生产/成本部门**：估计制造成本
- **财务部门**：建立共同假设条件，协调各部门防止高估或低估

**增量原则应用：**
- 现金流出：只有因采纳项目引起的现金支出增加额
- 现金流入：只有因采纳项目引起的现金流入增加额

## 营运资本变动处理

**计算公式：**
```
营运资本需求量 = 增加的经营性流动资产 - 增加的经营性流动负债
```

**期初投入：** 项目开始时垫支营运资本（现金流出）

**期末回收：** 项目结束时收回营运资本（现金流入），通常假设**全额回收**

## 终结期现金流量

**构成要素：**

| 项目 | 计算要点 |
|-----|---------|
| 设备变现税后净现金流入 | 需考虑变现损益的税务影响 |
| 收回营运资本 | 通常等于建设期垫支金额 |
| 弃置义务现金流出 | 环境恢复、场地清理等税后成本 |

**设备变现税务处理：**
```
若变现价值 > 账面价值（收益）：
  税后变现流入 = 变现价值 - (变现价值 - 账面价值) × 税率

若变现价值 < 账面价值（损失）：
  税后变现流入 = 变现价值 + (账面价值 - 变现价值) × 税率
```

## 现金流量时间轴

```
建设期          运营期                    终结期
  │              │                         │
  ▼              ▼                         ▼
┌─────┐    ┌─────────┐              ┌─────────┐
│初始 │    │ 经营现金 │    ...       │设备变现 │
│投资 │ →  │ 净流量  │      →       │营运资本 │
│     │    │         │              │  回收   │
└─────┘    └─────────┘              └─────────┘
  -            +/-                       +
```
