# 成本性态分析

## 适用场景
- 分析包含固定基数和变动部分的混合成本
- 预测不同业务量水平下的总成本
- 分解历史成本数据以确定成本参数

## 半变动成本模型

### 何时使用
当成本包含不随业务量变化的初始基数，且超出基数部分与业务量成正比时。

### 典型应用
- 电费：基本电费（固定）+ 用电量×电价（变动）
- 电话费：月租费（固定）+ 通话时长×费率（变动）
- 设备维护费：基础维护合同费（固定）+ 实际维修工时×工时费率（变动）
- 燃料费：设备预热燃料（固定）+ 生产运行燃料（变动）

### 执行步骤
1. **识别成本结构**：将成本分解为固定部分和变动部分
2. **建立数学模型**：使用线性方程 y = a + bx
3. **确定参数值**：
   - a：固定成本部分（初始基数）
   - b：单位变动成本
4. **应用模型预测**：代入业务量x计算总成本y

### 核心公式
```
y = a + bx
```

其中：
- y：半变动成本总额
- a：固定成本部分（初始基数）
- b：单位变动成本
- x：业务量（产量、机器工时等）

### 成本性态特征
- 当业务量为0时，总成本 = a（固定基数）
- 当业务量增加Δx时，总成本增加 = b × Δx
- 单位成本随业务量增加而递减（固定部分被分摊）
