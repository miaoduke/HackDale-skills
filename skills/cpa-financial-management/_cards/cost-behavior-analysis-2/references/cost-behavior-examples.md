## 半变动成本计算示例

### 电费计算
假设：
- 基本电费（固定部分）：a = 1000元/月
- 电价（单位变动成本）：b = 0.8元/度
- 用电量（业务量）：x = 5000度

计算：
```
y = 1000 + 0.8 × 5000 = 1000 + 4000 = 5000元
```

### 电话费计算
假设：
- 月租费（固定部分）：a = 20元/月
- 通话费率（单位变动成本）：b = 0.1元/分钟
- 通话时长（业务量）：x = 300分钟

计算：
```
y = 20 + 0.1 × 300 = 20 + 30 = 50元
```

### 参数确定方法
1. **高低点法**：使用历史数据中最高和最低业务量点
2. **回归分析法**：使用统计方法拟合最佳直线
3. **工程分析法**：基于技术标准确定
