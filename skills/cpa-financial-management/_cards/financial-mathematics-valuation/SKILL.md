# 财务数学与估值工具

## 适用场景
- 永续年金现值计算（优先股、永久债券）
- 标准正态分布累积概率查询（如Black-Scholes期权定价）
- 复利现值系数查询与应用
- 货币时间价值计算

## 永续年金现值公式

### 基本公式
```
P = A / i
```

其中：
- P = 永续年金的现值
- A = 每期定额收付金额
- i = 每期折现率（必须大于0）

### 公式推导
1. 从普通年金现值公式出发：
   ```
   P = A × [1 - (1+i)^(-n)] / i
   ```

2. 当 n → ∞ 时：
   - 由于 i > 0，所以 (1+i) > 1
   - (1+i)^(-n) = 1/(1+i)^n → 0

3. 代入简化：
   ```
   P = A × [1 - 0] / i = A / i
   ```

### 直观理解
如果将金额P以利率i投资，每年产生的利息P×i正好等于每年支付的A，因此本金P永远不需要动用。

### 适用条件
- 折现率 i 必须大于 0
- 每期支付金额 A 恒定不变
- 折现率 i 在整个期限内保持恒定

## 标准正态分布累积分布函数查表法

### 查表步骤

**步骤1：分解d值**
- 将标准化值d分解为"行值"（整数部分+第一位小数）和"列值"（第二位小数）
- 例如：d=0.22，行值为0.2，列值为0.02

**步骤2：定位表格**
- 在表格最左侧第一列找到对应的行值
- 在表格最上方第一行找到对应的列值（0.00, 0.01, 0.02, ..., 0.09）

**步骤3：读取N(d)值**
- 行值所在行与列值所在列的交叉单元格即为N(d)
- 例如d=0.22：N(0.22)=0.5871

### 结果解释
- N(d)表示标准正态分布变量取值小于d的概率
- 即 P(Z < d) = N(d)，其中 Z ~ N(0,1)
- 例如N(0.22)=0.5871表示：有58.71%的概率，随机变量取值小于均值+0.22个标准差

### 关键数值
- d=0.0: N(d)=0.5000（中位数）
- d=1.0: N(d)=0.8413
- d=1.645: N(d)≈0.95（95%置信区间单侧临界值）
- d=1.96: N(d)≈0.975（95%置信区间双侧临界值）
- d=3.0: N(d)=0.9987（"3σ原则"）

## 复利现值系数表查询

### 查表步骤

**步骤1：确定参数**
- 明确折现率（i）和期数（n）

**步骤2：选择表格**
- 折现率 1%-10%：使用第一张表
- 折现率 12%-36%：使用第二张表

**步骤3：定位行列**
- 列：找到对应的折现率
- 行：在"期数"列中找到对应的n值（1-55期）

**步骤4：获取系数**
- 行与列交叉点的数值即为复利现值系数（PVIF）
- PVIF = 1/(1+i)^n

**步骤5：计算现值**
```
现值(PV) = 未来值(FV) × 复利现值系数(PVIF)
```

### 特殊标记
- 表格中标记为 `*` 的数值表示该值小于 0.0001
- 此类极小数值通常可忽略不计或视为零
