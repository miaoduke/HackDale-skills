# 详细计算示例

## 示例1：永续年金现值计算

**优先股估值：**
- 每年股息：5元
- 必要报酬率：10%

**计算：**
- P = A / i = 5 / 0.1 = 50元

**解释：** 为获得每年5元的永久股息，当前需要投入50元

## 示例2：永久债券定价

**数据：**
- 面值：1000元
- 票面利率：6%
- 市场利率：8%

**计算：**
- 每年利息 = 1000 × 6% = 60元
- P = 60 / 0.08 = 750元

**结论：** 该永久债券的理论价值为750元

## 示例3：标准正态分布查表

**场景：** 计算d=1.65的累积概率

**步骤：**
1. 分解：行值=1.6，列值=0.05
2. 查表：找到行"1.6"与列"0.05"交叉处
3. 结果：N(1.65)=0.9505

**解释：** 有95.05%的概率，随机变量取值小于均值+1.65个标准差

## 示例4：复利现值计算

**数据：**
- 未来值：10,000元
- 折现率：8%
- 期数：5年

**查表：**
1. 选择第一张表（8%在1%-10%范围内）
2. 找到列"8%"和行"5"
3. PVIF = 0.6806

**计算：**
- PV = 10,000 × 0.6806 = 6,806元

**验证：**
- PV = 10,000 / (1.08)^5 = 10,000 / 1.4693 = 6,806元

## 示例5：Black-Scholes期权定价中的N(d)计算

**场景：** 计算看涨期权价值

**数据：**
- d1 = 0.22
- d2 = -0.08

**查表：**
- N(d1) = N(0.22) = 0.5871
- N(d2) = N(-0.08) = 1 - N(0.08) = 1 - 0.5319 = 0.4681

**应用：**
这些N(d)值将用于Black-Scholes公式计算期权价格
