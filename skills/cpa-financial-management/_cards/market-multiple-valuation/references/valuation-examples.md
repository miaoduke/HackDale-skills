# 市场乘数估值示例

## 市盈率模型示例
甲企业：
- 股利支付率 = 70%
- 增长率 = 6%
- 股权资本成本 = 11.125%

本期市盈率 = [70% × (1 + 6%)] ÷ (11.125% - 6%) = 14.48

## 市销率模型示例
可比公司：
- 每股收益 = 3.82
- 每股营业收入 = 83.06
- 营业净利率 = 3.82 ÷ 83.06 = 4.6%
- 股利支付率 = 74%
- 增长率 = 6%
- 股权资本成本 = 7% + 0.75 × (12.5% - 7%) = 11.125%

市销率 = (4.6% × 74% × (1 + 6%)) ÷ (11.125% - 6%) = 0.704

目标公司每股营业收入 = 50
目标公司股票价值 = 50 × 0.704 = 35.2（元）

## 修正市盈率示例
可比公司A：市盈率 = 20，预期增长率 = 10%
可比公司B：市盈率 = 15，预期增长率 = 5%

修正市盈率A = 20 ÷ (10% × 100) = 2
修正市盈率B = 15 ÷ (5% × 100) = 3

平均修正市盈率 = (2 + 3) ÷ 2 = 2.5

目标公司预期增长率 = 8%，每股收益 = 2
目标公司每股价值 = 2.5 × 8% × 100 × 2 = 40（元）
