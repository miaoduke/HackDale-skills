# 市场乘数估值法

## 适用场景
- 评估上市公司股权价值
- 进行相对估值分析
- 判断股票定价是否合理
- 亏损企业或资不抵债企业的估值（市销率）
- 销售成本率较低的服务类企业估值
- 找不到完全可比企业时的修正估值

## 三大估值模型

### 1. 市盈率模型（P/E）

**基本公式**
- 市盈率 = 每股市价 ÷ 每股收益
- 目标企业每股价值 = 可比企业市盈率 × 目标企业每股收益

**驱动因素**
- 增长潜力（关键因素）
- 股利支付率
- 风险（股权资本成本）

**本期市盈率**
```
本期市盈率 = [股利支付率 × (1 + 增长率)] ÷ (股权资本成本 - 增长率)
```

**内在市盈率（预期市盈率）**
```
内在市盈率 = 股利支付率 ÷ (股权资本成本 - 增长率)
```

**适用性**
- 适用于连续盈利的企业
- 收益为0或负值时模型失去意义

### 2. 市净率模型（P/B）

**基本公式**
- 市净率 = 每股市价 ÷ 每股净资产
- 目标企业每股价值 = 可比企业市净率 × 目标企业每股净资产

**驱动因素**
- 权益净利率（关键因素）
- 股利支付率
- 增长潜力
- 风险（股权资本成本）

**内在市净率**
```
内在市净率 = (股利支付率 × 权益净利率) ÷ (股权资本成本 - 增长率)
```

### 3. 市销率模型（P/S）

**基本公式**
- 市销率 = 每股市价 ÷ 每股营业收入
- 目标企业每股价值 = 可比企业市销率 × 目标企业每股营业收入

**驱动因素**
- 营业净利率（关键因素）
- 股利支付率
- 增长潜力
- 风险（股权资本成本）

**本期市销率**
```
本期市销率 = [股利支付率 × 营业净利率 × (1 + 增长率)] ÷ (股权资本成本 - 增长率)
```

**内在市销率（预期市销率）**
```
内在市销率 = (股利支付率 × 营业净利率) ÷ (股权资本成本 - 增长率)
```

**适用性**
- 适用于亏损企业或资不抵债的企业
- 适用于销售成本率较低的服务类企业
- 适用于销售成本率趋同的传统行业企业

## 估值匹配原则

### 严格匹配规则
- **规则A**：使用本期数据估值时，目标企业本期每股收益必须乘以可比企业本期市盈率
- **规则B**：使用预期数据估值时，目标企业预期每股收益必须乘以可比企业预期市盈率
- **严禁交叉匹配**：本期收益不能乘以预期市盈率，预期收益不能乘以本期市盈率

### 适用范围
此原则不仅适用于市盈率，也适用于市净率和市销率；不仅适用于未修正的价格乘数，也适用于修正的价格乘数。

## 修正的市价比率法

### 适用场景
- 找不到符合条件的可比企业
- 可比条件严格
- 同行业上市公司很少

### 计算步骤

**步骤1：确定关键驱动因素**
- 修正市盈率：关键变量是增长率
- 修正市净率：关键因素是权益净利率
- 修正市销率：关键因素是销售净利率

**步骤2：计算修正的市价比率**
```
修正市盈率 = 可比企业市盈率 ÷ (可比企业预期增长率 × 100)
修正市净率 = 可比公司市净率 ÷ (可比公司预期权益净利率 × 100)
修正市销率 = 可比公司市销率 ÷ (可比公司预期销售净利率 × 100)
```

**步骤3：评估目标公司价值**

方法一：修正平均市价比率法
1. 计算可比公司平均市价比率和平均预期增长率
2. 计算修正平均市价比率
3. 计算目标公司每股价值

方法二：股价平均法
1. 分别计算各可比公司的修正市盈率
2. 分别计算目标公司每股价值
3. 将得出的股票估值进行算术平均
