# 回归分析法财务预测

## 何时使用

- 拥有充足的历史财务报表数据
- 需要比销售百分比法更精确的预测结果
- 资产负债表项目与销售收入存在线性关系
- 希望识别非比例性关系（固定+变动部分）

## 核心原理

利用历史资料求得各资产负债表项目和销售收入的函数关系，通常假设线性关系：

```
Y = a + b × X

Y：资产负债表项目金额（如存货、应收账款）
X：营业收入
a：截距（固定基础水平）
b：斜率（变动敏感系数）
```

## 操作流程

### 第一步：建立函数关系

对每个重要的经营资产和经营负债项目，建立与营业收入的线性回归模型。

### 第二步：参数估计（最小二乘法）

根据历史数据，使用最小二乘法求出系数 a 和 b：
- **a**：与营业收入无关的固定部分
- **b**：营业收入每增加1单位，该项目的增加量

### 第三步：预测应用

根据预计营业收入和已求出的直线方程，预测各项目的金额：
```
预计存货 = a存货 + b存货 × 预计营业收入
```

### 第四步：计算融资需求

完成资产、负债项目预测后，计算外部融资需求：
```
净经营资产增加 = 预计经营资产合计 - 预计经营负债合计
外部融资需求 = 净经营资产增加 - 可动用金融资产 - 预计留存收益增加
```

## 与销售百分比法对比

| 维度 | 回归分析法 | 销售百分比法 |
|-----|-----------|------------|
| 假设 | 不强制稳定百分比 | 假设稳定百分比 |
| 灵活性 | 可识别固定+变动部分 | 仅比例关系 |
| 数据要求 | 需要较多历史数据点 | 基期数据即可 |
| 精确度 | 更高 | 一般 |
| 复杂度 | 较高 | 较低 |

## 关键提示

- 需要足够的历史数据点以保证回归可靠性
- 假设的线性关系在实际中可能不完全成立
- 预测结果应结合业务判断进行适当调整
