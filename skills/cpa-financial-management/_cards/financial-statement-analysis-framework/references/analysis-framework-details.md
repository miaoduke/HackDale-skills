# 管理用现金流量表详细示例

## 基本概念区分

### 经营现金流量
指企业因销售商品或提供劳务等营业活动以及与此有关的生产性资产投资活动产生的现金流量。

### 金融现金流量
指企业因筹资活动和金融市场投资活动而产生的现金流量。

## 实体现金流量计算示例

假设某公司数据如下：
- 税后经营净利润 = 500万元
- 折旧与摊销 = 100万元
- 经营营运资本增加 = 50万元
- 净经营长期资产增加 = 80万元

### 计算过程

**步骤1：营业现金毛流量**
```
营业现金毛流量 = 500 + 100 = 600万元
```

**步骤2：营业现金净流量**
```
营业现金净流量 = 600 - 50 = 550万元
```

**步骤3：资本支出**
```
资本支出 = 80 + 100 = 180万元
```

**步骤4：实体现金流量**
```
实体现金流量 = 550 - 180 = 370万元
```

## 融资现金流量示例

假设该公司：
- 支付利息 = 30万元
- 偿还债务本金 = 100万元
- 新借债务 = 50万元
- 支付股利 = 80万元
- 发行新股 = 0万元

### 计算过程

**债务现金流量**
```
债务现金流量 = -30（支付利息） - 100（偿还本金） + 50（新借债务）
             = -80万元
```

**股权现金流量**
```
股权现金流量 = -80（支付股利） + 0（发行新股）
             = -80万元
```

**融资现金流量合计**
```
融资现金流量 = -80 + (-80) = -160万元
```

## 平衡验证

理论上：实体现金流量 = 融资现金流量

本例中：370万元 ≠ -160万元

**差异原因**：可能存在金融资产变动或其他未列示项目，需要进一步核对。

## 会计价值与经济价值对比示例

### 珠海格力电器2021年数据

| 项目 | 会计价值 | 市场价值 |
|------|---------|---------|
| 股东权益每股 | 18.14元 | 48.19元（平均）/ 37.03元（收盘） |

**差异悬殊**：市场价值约为会计价值的2-2.7倍

### 差异原因分析

1. **表外资产**：
   - 品牌价值
   - 技术专利
   - 渠道优势
   - 管理能力

2. **表外负债**：
   - 潜在诉讼
   - 产品质量风险
   - 行业竞争加剧

3. **未来预期**：
   - 市场对公司未来盈利能力的预期
   - 行业增长前景
   - 宏观经济环境

### 价值评估启示

- 历史成本无法反映企业真实价值
- 价值评估必须关注未来现金流
- 需要识别和量化表外资产与负债
- 市场价格包含投资者对未来预期的判断
