# 财务报表分析框架

## 使用场景
当需要进行系统性财务报表分析、企业价值评估或投资决策时，使用此技能建立分析框架并执行分析流程。

## 四维分析框架

### 1. 战略分析（定性评估）
- **目的**：确定主要利润动因及经营风险
- **内容**：
  - 宏观分析：宏观经济环境影响
  - 行业分析：行业特征与发展趋势
  - 竞争策略分析：竞争优势与市场定位

### 2. 会计分析（质量评估）
- **目的**：评价会计信息质量
- **内容**：
  - 评估会计反映经济业务的程度
  - 评价会计政策的灵活性和恰当性
  - 必要时修正会计数据至可比较基础

### 3. 财务分析（业绩评价）
- **目的**：量化评价当前及历史业绩
- **内容**：
  - 比率分析：计算和解读财务指标
  - 现金流量分析：分析现金流结构与质量

### 4. 前景分析（未来预测）
- **目的**：预测未来财务状况和经营成果
- **内容**：
  - 财务报表预测：编制预计财务报表
  - 公司估值：评估企业内在价值

## 比较分析法

### 按比较对象分类

#### 1. 趋势分析（与本企业历史比较）
- **定义**：将当前数据与不同时期（3-10年）的历史指标相比
- **目的**：揭示变化趋势，判断发展轨迹和增长潜力
- **数据要求**：连续多期同质财务数据

#### 2. 横向分析（与同类企业比较）
- **定义**：与行业平均数或对标企业比较
- **目的**：揭示相对地位，发现差距或优势
- **选择标准**：同行业、规模相近、业务模式相似

#### 3. 预算差异分析（实际与计划比较）
- **定义**：将实际执行结果与计划预算指标比较
- **目的**：揭示预算执行情况，发现偏差及原因
- **应用**：内部控制、管理考核、绩效评价

### 通用原则
无论选择哪种比较对象，必须确保**可比性**：
- 计算口径一致
- 会计政策一致
- 计量基础一致

## 管理用财务报表体系

### 核心分类原则
将公司所有活动划分为两大类别：

#### 经营活动
- 销售商品或提供劳务等营业活动
- 与此有关的生产性资产投资活动

#### 金融活动
- 筹资活动
- 多余资本的利用

### 管理用现金流量表

#### 经营现金流量（来源端/实体现金流量）

**步骤1：营业现金毛流量**
```
营业现金毛流量 = 税后经营净利润 + 折旧与摊销
```

**步骤2：营业现金净流量**
```
营业现金净流量 = 营业现金毛流量 - 经营营运资本增加
```

**步骤3：实体现金流量**
```
实体现金流量 = 营业现金净流量 - 资本支出
资本支出 = 净经营长期资产增加 + 折旧与摊销
```

#### 融资现金流量（去向端/金融现金流量）

- **债务现金流量**：与债权人之间的交易形成的现金流量
- **股权现金流量**：与股东之间的交易形成的现金流量

#### 基本平衡等式
```
营业现金毛流量 - 经营营运资本增加 - 资本支出 = 债务现金流量 + 股权现金流量
```

**恒等关系**：经营现金流量 = 实体现金流量 = 融资现金流量 = 金融现金流量

## 会计价值 vs 经济价值

### 核心概念

| 概念 | 定义 | 特点 |
|------|------|------|
| 会计价值 | 资产、负债和所有者权益的账面价值 | 基于历史成本，面向过去 |
| 现时市场价值 | 按现行市场价格计量的资产价值 | 可能公平，也可能不公平 |
| 经济价值 | 资产的公平市场价值 | 经济学家所持的价值观念 |

### 历史成本计量的逻辑

**会计师选择历史成本的理由**：
1. **客观性**：可重复验证，支持职业地位
2. **可操作性**：市场不活跃或资产非同质性时，难以找到现时市场价值

### 历史成本计量的局限性

1. **缺乏决策相关性**：信息面向过去，决策需要现实和未来信息
2. **不能反映真实财务状况**：不代表可支配的资产或可抵偿债务的资产
3. **缺乏方法一致性**：受会计政策和估计影响大，人为调整空间大
4. **缺乏时间一致性**：混合不同会计期间的购置价格

### 价值评估原则

- 财务报表数据的真正缺点：没有关注未来，排除表外项目
- **表外资产**：良好管理、商誉、忠诚顾客、先进技术等
- **表外负债**：未决诉讼、过时生产线、低劣管理等
- **结论**：价值评估通常不使用历史价格，只有在其他方法无法获得恰当数据时，才将其作为质量不高的替代品

## 分析流程

1. **明确分析目的**：确定分析的根本目标
2. **执行战略分析**：评估宏观、行业、竞争环境
3. **执行会计分析**：评价会计信息质量，必要时调整数据
4. **执行财务分析**：计算比率，分析现金流
5. **执行前景分析**：预测未来，评估价值
6. **综合判断**：形成决策支持信息

## 关键原则

- 财务报表分析的目的是将数据转换成有用的信息，以改善决策
- 管理用财务报表需根据企业业务活动性质具体分析，教材示例不代表必然划分方式
- 没有比较就没有鉴别，必须确保比较数据的可比性
