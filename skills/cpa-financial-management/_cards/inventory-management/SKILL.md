# 存货管理与经济订货量

## 使用场景
- 需要决定进货时间和进货批量时
- 需要优化存货总成本时
- 存货陆续入库且陆续耗用时
- 产成品入库、在产品转移场景
- 边送边用的生产场景

## 存货总成本构成

```
TC = TCa + TCc + TCs
```

其中：
- **TCa（取得成本）：** F1 + (D/Q)K + DU
  - F1：固定订货成本
  - (D/Q)K：变动订货成本
  - DU：购置成本

- **TCc（储存成本）：** F2 + Kc(Q/2)
  - F2：固定储存成本
  - Kc(Q/2)：变动储存成本

- **TCs（缺货成本）

## 基本经济订货量模型

### 适用条件
- 存货一次全部入库
- 需求率恒定
- 不允许缺货

### 决策内容
财务部门负责：
- 决定进货时间（T）
- 决定进货批量（Q）

### 经济订货量定义
使存货总成本最低的合理进货批量

## 陆续供应和使用模型

### 适用条件
- 存货陆续入库且陆续耗用
- 送货期间同时发生消耗
- 送货速率P大于耗用速率d（P > d）

### 执行步骤

1. **计算送货期：**
   ```
   送货期 = Q/P
   ```

2. **计算送货期内的全部耗用量：**
   ```
   送货期内耗用量 = (Q/P) × d
   ```

3. **计算最高库存量：**
   ```
   最高库存量 = Q - (Q/P)×d = Q(1 - d/P)
   ```

4. **计算平均存量：**
   ```
   平均存量 = ½ × Q × (1 - d/P)
   ```

5. **建立总成本函数：**
   ```
   TC(Q) = (D/Q)×K + (Q/2)×(1 - d/P)×Kc
   ```

6. **计算经济订货量Q*：**
   ```
   Q* = √[(2KD/Kc) × (P/(P-d))]
   ```

7. **计算最小总成本TC(Q*)：**
   ```
   TC(Q*) = √[2KDKc × (1 - d/P)]
   ```

## 关键变量

- **D：** 年需求量（件/年）
- **Q：** 每批订货数或生产批量（件）
- **Q*：** 经济订货量（件）
- **K：** 一次订货成本或生产准备成本（元/次）
- **Kc：** 单位储存变动成本（元/件·年）
- **P：** 每日送货量（件/日），供应速率
- **d：** 每日耗用量（件/日），需求速率

## 模型对比

| 项目 | 基本模型 | 陆续供应模型 |
|------|----------|--------------|
| 入库方式 | 一次全部入库 | 陆续入库 |
| 经济批量公式 | √(2KD/Kc) | √[(2KD/Kc) × (P/(P-d))] |
| 修正系数 | 1 | √[P/(P-d)] > 1 |
| 最小总成本 | √(2KDKc) | √[2KDKc × (1 - d/P)] |

## 输出结果
- 经济订货量Q*（最优批量）
- 最小总成本TC(Q*)
- 最适宜进货时间T
