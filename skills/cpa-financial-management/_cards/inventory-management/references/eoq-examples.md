# 经济订货量计算示例

## 基本模型示例

**已知数据：**
- 年需求量 D = 3,600件
- 每次订货成本 K = 24元
- 单位储存变动成本 Kc = 2元

**计算：**
```
Q* = √(2 × 24 × 3,600 / 2) = √86,400 = 293.94 ≈ 294件
TC(Q*) = √(2 × 24 × 3,600 × 2) = √345,600 = 587.88元
```

## 陆续供应模型示例（例11-7）

**已知数据：**
- 年需求量 D = 3,600件
- 每日送货量 P = 30件/日
- 每日耗用量 d = 10件/日
- 每次订货成本 K = 24元
- 单位储存变动成本 Kc = 2元

**计算过程：**

1. **修正系数：**
   P/(P-d) = 30/(30-10) = 30/20 = 1.5

2. **经济订货量：**
   Q* = √[(2 × 24 × 3,600 / 2) × 1.5]
       = √[86,400 × 1.5]
       = √129,600
       = 360件

3. **最小总成本：**
   TC(Q*) = √[2 × 24 × 3,600 × 2 × (1 - 10/30)]
           = √[345,600 × (2/3)]
           = √230,400
           = 480元

**对比分析：**
- 基本模型：Q* = 294件，TC = 588元
- 陆续供应模型：Q* = 360件，TC = 480元

**结论：** 陆续供应模型的经济批量更大，但总成本更低（因为边送边用，平均库存量降低）
