# 资本结构与融资工具评估

## 使用场景
当需要执行以下任一任务时使用本技能：
- 评估优先股、永续债、可转换债券等混合筹资工具
- 计算加权平均资本成本（WACC）
- 分析投资政策变化对资本成本的影响
- 判断融资工具的风险属性和成本定位
- 确定可转换债券的转股期限和锁定期

## 核心评估流程

### 1. 投资政策对资本成本的影响分析

**基本原则**：公司的资本成本反映现有资产的平均风险

**影响机制**：
1. 确定基准：现有资产的平均风险水平
2. 分析变化：新项目风险与现有资产风险的比较
3. 推导结果：
   - 新项目风险 > 现有资产风险 → 资本成本上升
   - 新项目风险 < 现有资产风险 → 资本成本下降

**典型应用**：传统行业企业进入高风险新兴产业时，不能使用当前资本成本作为新项目折现率

### 2. 优先股的财务风险属性评估

**关键判断**：优先股股利应视为固定成本

**判断依据**：
- 法律层面：无强制支付义务（不同于债务利息）
- 经济层面：市场约束形成刚性支付义务
  - 停发股利传递财务困境信号
  - 影响股价和未来融资能力

**财务风险传导**：
```
优先股股利增加 → 固定财务费用增加 → 财务杠杆系数提高 → 每股收益波动性增大 → 财务风险上升
```

**对普通股成本的影响**：财务风险增加 → 普通股股东要求更高风险溢价 → 普通股资本成本上升

### 3. 永续债筹资成本与风险定位

**工具属性**：具有一定权益属性的债务工具（混合筹资工具）

**风险层级**：
```
普通债券 < 永续债 < 普通股
```

**利率水平判定**：
- vs 普通债券：利率更高（补偿额外信用风险、流动性风险、久期风险）
- vs 普通股：利率更低（普通股承担剩余风险，要求更高回报）

**WACC应用**：永续债成本率应设定在税后债务成本和权益成本之间

### 4. 可转换债券转股规则

**转股起始时间**：
- 等待期：发行结束之日起6个月后
- 6个月内不得转股（强制性规定）

**转股期限**：
- 起点：发行结束满6个月
- 终点：到期日前几个交易日
- 具体起止日期由公司确定

**持有人权利**：
- 选择权：可转可不转
- 股东身份：转股次日（T+1）成为股东

**特定对象发行的锁定期**：
- 锁定期：18个月（从发行结束日起算）
- 限制内容：转股后股票不得转让
- 关键区别：锁定期从发行结束日起算，而非转股日起算

## 决策要点

- 优先股虽为权益工具，但经济上具有类债务的固定成本属性
- 永续债风险介于债务和股权之间，成本定位需综合考虑
- 投资政策变化会改变企业整体风险，从而影响资本成本
- 可转换债券的锁定期计算起点是发行结束日，需特别注意特定对象发行的18个月限制
- 在计算WACC时，应将优先股股利视为固定财务费用

## 输出结果
- 投资政策变化对资本成本的影响方向
- 优先股的固定成本属性认定及财务风险评估
- 永续债的风险等级和合理利率区间
- 可转换债券的转股时间表和锁定期安排
- 融资工具在资本结构中的定位建议
