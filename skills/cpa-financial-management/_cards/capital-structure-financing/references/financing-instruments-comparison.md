# 融资工具对比分析

## 风险与成本排序

| 工具类型 | 风险等级 | 成本水平 | 清偿顺序 | 固定支付义务 |
|---------|---------|---------|---------|------------|
| 普通债券 | 低 | 低 | 最优先 | 有（法律强制） |
| 永续债 | 中 | 中 | 次于普通债券 | 有（通常可递延） |
| 优先股 | 中-高 | 中-高 | 次于债务 | 有（经济约束） |
| 普通股 | 高 | 高 | 最后 | 无 |

## 可转换债券时间线示例

**特定对象发行**：
```
T日：可转债发行结束
T+6个月：首次可转股日
T+12个月：某投资者转股
T+18个月：锁定期结束，可转让股票
```

**注意**：即使T+17个月转股，也需等到T+18个月才能转让

## 财务杠杆系数计算

```
DFL = EBIT / (EBIT - I - Dp/(1-T))
```

其中：
- EBIT：息税前利润
- I：利息费用
- Dp：优先股股利
- T：所得税税率

**结论**：优先股股利（Dp）增加，分母减小，DFL增大，财务风险上升
