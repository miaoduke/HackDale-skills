# 信用期间决策分析

## 适用场景
- 企业考虑调整信用期间
- 评估信用政策变化对利润的影响
- 应收账款管理决策
- 营运资金管理

## 核心决策原则

**收益增加 > 成本增加**：可以延长信用期

**收益增加 < 成本增加**：不宜延长信用期

缩短信用期则情况相反。

## 定量分析步骤

### 步骤1：计算收益的增加
```
收益增加 = 销售量增加 × 单位边际贡献
```

其中：
- 单位边际贡献 = 单价 - 单位变动成本

### 步骤2：计算应收账款占用资金的应计利息增加

**核心公式链：**
```
应收账款应计利息 = 应收账款占用资金 × 资本成本
应收账款占用资金 = 应收账款平均余额 × 变动成本率
应收账款平均余额 = 日销售额 × 平均收现期
```

**综合公式：**
```
应计利息 = (年销售额/360) × 平均收现期 × 变动成本率 × 资本成本
```

### 步骤3：计算收账费用和坏账损失增加
```
收账费用增加 = 新信用期收账费用 - 原信用期收账费用
坏账损失增加 = 新信用期坏账损失 - 原信用期坏账损失
```

### 步骤4：计算改变信用期的税前损益增加
```
税前损益增加 = 收益增加 - (应计利息增加 + 收账费用增加 + 坏账损失增加)
```

### 步骤5：决策
- 若税前损益增加 > 0：采用新信用期
- 若税前损益增加 < 0：维持原信用期

## 扩展分析（考虑存货因素）

当销售量增加导致存货水平变化时：
```
存货增加占用资金利息 = 存货增加量 × 单位存货成本 × 资本成本
```

**调整后税前损益增加：**
```
调整后损益增加 = 原税前损益增加 - 存货增加占用资金利息
```

## 关键计算细节

### 应收账款占用资金计算
应收账款占用资金应当按应收账款平均余额乘以变动成本率计算确定。

**原因：** 需要增加的营运资金数额仅仅是变动成本，既不是全部销售额，也不是全部制造成本。

### 变动成本率
```
变动成本率 = 单位变动成本 / 单价
```

## 更细致的分析要点

1. **考虑存货增加引起的应付账款增加**：负债增加会节约营运资金，减少应计利息

2. **信用期变动的双重影响**：
   - 对利润表的影响（收入、成本和费用）
   - 对资产负债表的影响（应收账款、存货、应付账款）

3. **统一得失比较**：将资金占用的影响用资本成本转化为应计利息

## 信用期长短的影响

### 信用期过短
- 不足以吸引顾客
- 在竞争中会使销售额下降

### 信用期过长
- 对销售额增加有利
- 但所得收益可能被增长的费用抵消
- 甚至造成利润减少
