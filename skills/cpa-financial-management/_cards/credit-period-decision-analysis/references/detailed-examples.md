# 详细计算示例

## 基础示例：信用期从30天延长至60天

### 基础数据
| 项目 | 30天信用期 | 60天信用期 |
|------|-----------|-----------|
| 销售量 | 100,000件 | 120,000件 |
| 单价 | 5元 | 5元 |
| 单位变动成本 | 4元 | 4元 |
| 固定成本 | - | - |
| 资本成本率 | 15% | 15% |
| 平均收现期 | 30天 | 60天 |
| 收账费用 | 3,000元 | 4,000元 |
| 坏账损失 | 5,000元 | 9,000元 |

### 步骤1：计算收益增加
```
销售量增加 = 120,000 - 100,000 = 20,000件
单位边际贡献 = 5 - 4 = 1元
收益增加 = 20,000 × 1 = 20,000元
```

### 步骤2：计算应计利息增加

**30天信用期：**
```
年销售额 = 100,000 × 5 = 500,000元
变动成本总额 = 100,000 × 4 = 400,000元
变动成本率 = 400,000 / 500,000 = 80%

应计利息 = (500,000/360) × 30 × 80% × 15%
         = 1,389 × 30 × 0.8 × 0.15
         = 5,000元
```

**60天信用期：**
```
年销售额 = 120,000 × 5 = 600,000元
变动成本总额 = 120,000 × 4 = 480,000元
变动成本率 = 480,000 / 600,000 = 80%

应计利息 = (600,000/360) × 60 × 80% × 15%
         = 1,667 × 60 × 0.8 × 0.15
         = 12,000元
```

**应计利息增加：**
```
12,000 - 5,000 = 7,000元
```

### 步骤3：计算收账费用和坏账损失增加
```
收账费用增加 = 4,000 - 3,000 = 1,000元
坏账损失增加 = 9,000 - 5,000 = 4,000元
```

### 步骤4：计算税前损益增加
```
成本费用增加 = 7,000 + 1,000 + 4,000 = 12,000元
税前损益增加 = 20,000 - 12,000 = 8,000元
```

### 步骤5：决策
```
税前损益增加 = 8,000元 > 0
决策：采用60天信用期
```

## 扩展示例：考虑存货因素

### 额外数据
| 项目 | 30天信用期 | 60天信用期 |
|------|-----------|-----------|
| 平均存货水平 | 9,000件 | 20,000件 |
| 单位存货成本 | 3元 | 3元 |

### 计算存货增加占用资金利息
```
存货增加量 = 20,000 - 9,000 = 11,000件
存货增加占用资金 = 11,000 × 3 = 33,000元
存货增加占用资金利息 = 33,000 × 15% = 4,950元
```

### 调整后税前损益增加
```
调整后损益增加 = 8,000 - 4,950 = 3,050元
```

### 最终决策
```
调整后税前损益增加 = 3,050元 > 0
决策：仍采用60天信用期
```

## 决策总结

| 分析层次 | 税前损益增加 | 决策 |
|---------|-------------|------|
| 基础分析（不考虑存货） | 8,000元 | 采用60天信用期 |
| 扩展分析（考虑存货） | 3,050元 | 仍采用60天信用期 |

**关键洞察：** 即使考虑存货增加的资金占用成本，延长信用期仍然有利可图，但收益大幅减少。
