# 自制或外购决策完整示例

## 示例背景
某自行车制造企业需要决定外胎是自制还是外购。

### 基础数据
- 年需求量：10,000条
- 外购单价：58元/条
- 自制单位成本：
  - 直接材料：32元
  - 直接人工：12元
  - 变动制造费用：7元
  - 固定制造费用：10元（无关成本）
- 自制单位变动成本：32 + 12 + 7 = 51元/条

## 场景一：有足够剩余生产能力且无法转移

### 计算
```
自制相关成本 = 51 × 10,000 = 510,000元
外购相关成本 = 58 × 10,000 = 580,000元
差额成本 = 510,000 - 580,000 = -70,000元
```

### 决策
选择自制方案，每年可节约成本70,000元

## 场景二：有足够剩余生产能力但可以转移

### 附加条件
闲置产能用于加工自行车内胎，每年可节省内胎外购成本20,000元

### 计算
```
自制相关成本 = 510,000 + 20,000 = 530,000元
外购相关成本 = 580,000元
差额成本 = 530,000 - 580,000 = -50,000元
```

### 决策
选择自制方案，每年可节约成本50,000元

## 场景三：生产能力不足，需追加专属投资

### 附加条件
需租入设备，月租金4,000元

### 计算
```
专属成本 = 4,000 × 12 = 48,000元
自制相关成本 = 510,000 + 48,000 = 558,000元
外购相关成本 = 580,000元
差额成本 = 558,000 - 580,000 = -22,000元
```

### 决策
选择自制方案，每年可节约成本22,000元

## 场景四：部分生产能力，混合决策

### 附加条件
- 现有产能：5,000条
- 需租入设备满足剩余需求，月租金4,000元

### 计算

**步骤1：利用现有产能**
- 自制单位变动成本51元 < 外购价58元
- 先自制5,000条

**步骤2：计算剩余需求增量成本**
```
增量成本 = 51 + (48,000 / 5,000) = 51 + 9.6 = 60.6元/条
```

**步骤3：比较**
- 增量成本60.6元 > 外购价58元
- 超过部分应该选择外购

### 决策
- 自制5,000条
- 外购5,000条

## 决策总结表

| 场景 | 自制成本 | 外购成本 | 差额 | 决策 |
|------|----------|----------|------|------|
| 产能充足无法转移 | 510,000 | 580,000 | -70,000 | 自制 |
| 产能可转移 | 530,000 | 580,000 | -50,000 | 自制 |
| 产能不足需投资 | 558,000 | 580,000 | -22,000 | 自制 |
| 部分产能 | 混合 | 混合 | - | 自制5,000+外购5,000 |

## 关键概念说明

### 无关成本
- 固定制造费用：无论自制或外购都会发生
- 已发生的沉没成本

### 相关成本
- 变动成本：随产量变化的成本
- 机会成本：放弃其他用途的损失
- 专属成本：为特定方案追加的成本

### 决策原则
- 比较各方案的相关成本
- 选择相关成本最小的方案
- 考虑非成本因素进行最终决策
