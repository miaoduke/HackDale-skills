# 零部件自制或外购差量成本决策

## 使用场景
- 制造企业面临零部件自制或外购选择
- 汽车制造、自行车制造、机械设备制造等企业
- 需要评估剩余生产能力的利用
- 短期经营决策分析

## 前提条件
- 零部件年需求量数据
- 外购单价
- 自制单位变动成本（直接材料、直接人工、变动制造费用）
- 企业剩余生产能力评估
- 机会成本数据（如产能可转移）
- 专属成本数据（如需追加投资）

## 决策分析步骤

### 第一步：计算自制单位变动成本
```
自制单位变动成本 = 直接材料 + 直接人工 + 变动制造费用
```

**注意**：固定制造费用属于无关成本，因无论自制或外购，该成本均会发生。

### 第二步：确定外购相关成本
```
外购相关成本 = 外购单价 × 年需求量
```

### 第三步：根据产能状况选择计算路径

#### 路径A：有足够剩余生产能力且无法转移

**计算公式**：
```
自制相关成本 = 单位变动成本 × 数量
差额成本 = 自制相关成本 - 外购相关成本
```

**决策规则**：
- 若差额成本 < 0，选择自制方案
- 若差额成本 > 0，选择外购方案

#### 路径B：有足够剩余生产能力但可以转移

**计算公式**：
```
自制相关成本 = 变动成本总额 + 机会成本
差额成本 = 自制相关成本 - 外购相关成本
```

**机会成本**：若闲置产能用于其他用途可带来的收益

#### 路径C：生产能力不足，需追加专属投资

**计算公式**：
```
自制相关成本 = 变动成本总额 + 专属成本
差额成本 = 自制相关成本 - 外购相关成本
```

**专属成本**：为增加产能必须追加的固定成本

#### 路径D：部分生产能力，可混合决策

**决策步骤**：
1. 利用现有产能自制单位变动成本低于外购价的部分
2. 对剩余需求量计算自制增量成本：
   ```
   增量成本 = 单位变动成本 + (专属成本 / 超量部分数量)
   ```
3. 比较增量成本与外购价
4. 确定最终方案：自制数量 + 外购数量

### 第四步：非成本因素补充评估
在定量分析基础上，还需定性评估：
- 外购产品的质量
- 送货的及时性
- 长期供货能力
- 供货商的新产品研发能力
- 本企业有关职工的抱怨程度

## 关键变量

| 变量名 | 类型 | 描述 |
|--------|------|------|
| 年需求量 | 数值 | 零部件年需要量 |
| 外购单价 | 数值 | 向供应商采购的单价 |
| 单位直接材料 | 数值 | 自制单位直接材料成本 |
| 单位直接人工 | 数值 | 自制单位直接人工成本 |
| 单位变动制造费用 | 数值 | 自制单位变动制造费用成本 |
| 单位变动成本 | 数值 | 自制单位变动成本合计 |
| 剩余生产能力 | 数值 | 企业现有闲置产能可生产数量 |
| 机会成本 | 数值 | 剩余产能转移可带来的年收益 |
| 专属固定成本 | 数值 | 追加设备投资的年固定成本 |
| 设备月租金 | 数值 | 租入设备的月租金 |

## 约束条件
- 短期经营决策视角
- 固定制造费用在产能充足且不追加投资时为无关成本
- 假设外购质量与自制等效（仅成本比较阶段）

## 输出结果
```
决策结果：选择[自制/外购/混合方案]，预计年成本节约[金额]元。若选择混合方案，需明确自制数量和外购数量的分界点。
```
