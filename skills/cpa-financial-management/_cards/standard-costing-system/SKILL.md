# 标准成本系统

## 使用场景
当需要制定成本控制标准、分析成本差异、评价生产部门业绩时使用此技能。

## 正常标准成本制定

### 核心定义
在效率良好的条件下，根据下期一般应该发生的生产要素消耗量、预计价格和预计生产经营能力利用程度制定出来的标准成本。

### 制定条件
- 基础条件：效率良好的生产条件
- 包含因素：生产经营活动中一般难以避免的损耗和低效率
- 目标：切合下期实际情况，成为切实可行的控制标准

### 可达性特征
- **难度定位：** 要达到不是没有困难，但是可能达到的
- **数量关系：** 理想标准成本 < 正常标准成本 < 历史平均水平
- **执行预期：** 实际成本更大的可能是逆差（实际>标准）
- **激励效果：** 经过努力才能达到，可调动职工积极性

### 四大特点
1. **客观性和科学性：** 用科学方法根据客观实验和过去实践经验制定
2. **现实性：** 排除偶然性和意外情况，保留目前条件下难以避免的损失
3. **激励性：** 作为评价业绩的尺度和督促职工努力的目标
4. **稳定性：** 工艺技术水平和管理有效性水平变化不大时不需要经常修订

## 固定制造费用标准成本计算

### 基本公式
```
单位产品固定制造费用标准成本 = 单位产品直接人工标准工时 × 固定制造费用标准分配率
```

### 多车间环境计算流程

**1. 分车间计算：**
```
车间单位产品固定制造费用标准成本 = 车间用量标准 × 车间价格标准
```

**2. 汇总计算：**
```
单位产品固定制造费用标准成本总计 = Σ(各车间单位产品固定制造费用标准成本)
```

**3. 完整产品标准成本：**
将直接材料、直接人工、变动制造费用、固定制造费用标准成本汇总。

## 变动制造费用差异分析

### 差异分解框架

```
变动制造费用成本差异
├── 耗费差异（价差）
└── 效率差异（量差）
```

### 计算步骤

**第一步：计算总差异**
```
变动制造费用成本差异 = 实际变动制造费用 - 标准变动制造费用
标准变动制造费用 = 实际产量 × 单位产品标准变动制造费用成本
```

**第二步：分解耗费差异**
```
变动制造费用耗费差异 = 实际工时 × (实际分配率 - 标准分配率)
= 实际变动制造费用 - (实际工时 × 标准分配率)
```
- 含义：反映耗费水平的高低
- 正值(U)：不利差异（超支）
- 负值(F)：有利差异（节约）

**第三步：分解效率差异**
```
变动制造费用效率差异 = (实际工时 - 标准工时) × 标准分配率
标准工时 = 实际产量 × 单位产品标准工时
```
- 含义：反映工作效率变化引起的费用节约或超支
- 正值(U)：不利差异（效率低）
- 负值(F)：有利差异（效率高）

**第四步：验算**
```
总差异 = 耗费差异 + 效率差异
```

## 应用要点

1. **标准制定：** 正常标准成本应具有可达性和激励性
2. **差异分析：** 必须通过验算确认耗费差异与效率差异之和等于总差异
3. **多车间汇总：** 各车间标准成本需汇总形成产品完整标准成本
4. **持续改进：** 实际成本多为逆差，需努力改进
