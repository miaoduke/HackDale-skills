# 标准成本计算示例

## 固定制造费用标准成本计算

### 多车间示例

**第一车间：**
- 用量标准：2小时/单位产品
- 价格标准：0.5元/工时
- 车间标准成本：2 × 0.5 = 1元/单位产品

**第二车间：**
- 用量标准：1小时/单位产品
- 价格标准：0.6元/工时
- 车间标准成本：1 × 0.6 = 0.6元/单位产品

**汇总：**
单位产品固定制造费用标准成本总计 = 1 + 0.6 = 1.6元/单位产品

**完整产品标准成本（A产品）：**
- 直接材料标准成本：10元
- 直接人工标准成本：5元
- 变动制造费用标准成本：3.95元
- 固定制造费用标准成本：1.6元
- **单位产品标准成本总计：20.55元**

## 变动制造费用差异分析示例

### 已知条件（例14-3）
- 本月实际产量：400件
- 实际使用工时：890小时
- 实际发生变动制造费用：1,958元
- 变动制造费用标准成本：4元/件
- 每件产品标准工时：2小时
- 标准变动制造费用分配率：2元/小时

### 计算过程

**a) 计算耗费差异：**
```
实际分配率 = 1,958 ÷ 890 = 2.2元/小时
耗费差异 = 890 × (2.2 - 2) = 890 × 0.2 = 178元（U）
或：1,958 - (890 × 2) = 1,958 - 1,780 = 178元（U）
```

**b) 计算效率差异：**
```
标准工时 = 400 × 2 = 800小时
效率差异 = (890 - 800) × 2 = 90 × 2 = 180元（U）
```

**c) 计算总差异：**
```
标准变动制造费用 = 400 × 4 = 1,600元
总差异 = 1,958 - 1,600 = 358元（U）
```

**d) 验算：**
```
178元（U）+ 180元（U）= 358元（U）✓
```

### 差异分析结论
- 耗费差异178元（U）：实际分配率高于标准，费用控制不佳
- 效率差异180元（U）：实际工时超过标准工时，工作效率低
- 总差异358元（U）：变动制造费用超支358元

## 标准成本类型比较

| 标准类型 | 定义 | 难度 | 适用场景 |
|---------|------|------|---------|
| 理想标准成本 | 最优条件下，无浪费、无低效率 | 很难达到 | 理论分析 |
| 正常标准成本 | 效率良好条件下，包含一般损耗 | 经过努力可达到 | **广泛使用** |
| 基本标准成本 | 历史平均水平 | 容易达到 | 基础对比 |

## 差异分析责任归属

| 差异类型 | 责任部门 | 可能原因 |
|---------|---------|---------|
| 耗费差异 | 生产部门、采购部门 | 价格波动、用量浪费、管理不善 |
| 效率差异 | 生产部门 | 工人技能、设备状况、生产组织 |
