# 辅助生产费用直接分配法示例

## 已知数据

### 供电车间
- 费用总额：89,000元
- 总供电量：362,000度
- 提供给锅炉车间：6,000度

### 锅炉车间
- 费用总额：21,000元
- 总蒸汽量：5,370吨
- 提供给供电车间：120吨

### 受益单位耗用量

| 受益单位 | 供电（度） | 锅炉（吨） |
|---------|-----------|----------|
| 甲产品 | 220,000 | 3,000 |
| 乙产品 | 130,000 | 2,200 |
| 基本生产车间 | 4,200 | 30 |
| 管理部门 | 1,800 | 20 |

## 计算过程

### 步骤1：确定对外分配基数

**供电车间**：
```
对外分配基数 = 362,000 - 6,000 = 356,000度
```

**锅炉车间**：
```
对外分配基数 = 5,370 - 120 = 5,250吨
```

### 步骤2：计算单位成本（分配率）

**供电车间**：
```
单位成本 = 89,000 ÷ 356,000 = 0.25元/度
```

**锅炉车间**：
```
单位成本 = 21,000 ÷ 5,250 = 4元/吨
```

### 步骤3：计算各受益单位应分配的费用

**甲产品**：
```
供电费用 = 220,000 × 0.25 = 55,000元
锅炉费用 = 3,000 × 4 = 12,000元
合计 = 67,000元
```

**乙产品**：
```
供电费用 = 130,000 × 0.25 = 32,500元
锅炉费用 = 2,200 × 4 = 8,800元
合计 = 41,300元
```

**基本生产车间制造费用**：
```
供电费用 = 4,200 × 0.25 = 1,050元
锅炉费用 = 30 × 4 = 120元
合计 = 1,170元
```

**管理费用**：
```
供电费用 = 1,800 × 0.25 = 450元
锅炉费用 = 20 × 4 = 80元
合计 = 530元
```

### 步骤4：验证分配总额

**供电车间**：
```
55,000 + 32,500 + 1,050 + 450 = 89,000元 ✓
```

**锅炉车间**：
```
12,000 + 8,800 + 120 + 80 = 21,000元 ✓
```

### 步骤5：编制会计分录

```
借：生产成本——基本生产成本——甲产品 67,000
    生产成本——基本生产成本——乙产品 41,300
    制造费用——基本生产车间 1,170
    管理费用 530
贷：生产成本——辅助生产成本——供电车间 89,000
    生产成本——辅助生产成本——锅炉车间 21,000
```
