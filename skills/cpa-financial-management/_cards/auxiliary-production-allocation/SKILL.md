# 辅助生产费用直接分配法

## 核心特征

"对外分配，忽略内部"——计算分配率时，必须从劳务总量中扣除提供给其他辅助生产车间的部分。

## 适用条件

- 辅助生产内部相互提供产品或劳务不多
- 不进行费用的交互分配对辅助生产成本和产品制造成本影响不大

**不适用情况**：
- 辅助生产内部相互提供产品或劳务量差异较大时
- 不进行费用的交互分配对辅助生产成本和产品制造成本影响较大时

## 计算步骤

### 步骤1：确定计算基础（扣除内部交互）
```
对外分配基数 = 辅助生产的产品或劳务总量 - 对其他辅助部门提供的劳务量
```

### 步骤2：计算辅助生产的单位成本（分配率）
```
辅助生产的单位成本 = 辅助生产费用总额 / 对外分配基数
```

### 步骤3：计算各受益单位应分配的费用
```
各受益单位应分配的费用 = 辅助生产的单位成本 × 该受益单位的耗用量
```

### 步骤4：验证分配总额
```
各受益单位分配费用之和 = 辅助生产费用总额
```

### 步骤5：编制会计分录
```
借：生产成本——基本生产成本——某产品
    制造费用——基本生产车间
    管理费用
贷：生产成本——辅助生产成本——某辅助车间
```

## 关键要点

1. **扣除内部交互**：计算分配率时必须从劳务总量中扣除提供给其他辅助生产车间的部分
2. **仅对外分配**：不进行辅助生产内部的交互分配
3. **计算简便**：方法简单，但分配结果可能不够准确
4. **适用性限制**：仅适用于辅助生产内部相互提供劳务量较少的情况

## 会计处理

分配后应借记"生产成本——基本生产成本"、"制造费用"、"管理费用"等科目，贷记"生产成本——辅助生产成本"科目，将辅助生产成本结转至受益对象。
