# EVA与RI计算示例

## 基础数据

| 项目 | 部门A |
|------|-------|
| 部门税前经营利润 | 100万元 |
| 所得税税率 | 25% |
| 部门投资 | 500万元 |
| 要求的税前投资报酬率 | 12% |
| 税后加权平均资本成本 | 9% |

## 剩余收益计算

```
剩余收益 = 部门税前经营利润 - 部门投资 × 要求的税前投资报酬率
剩余收益 = 100 - 500 × 12%
剩余收益 = 100 - 60 = 40万元
```

## 经济增加值计算

### 第一步：计算税后净营业利润
```
税后净营业利润 = 部门税前经营利润 × (1 - 所得税税率)
税后净营业利润 = 100 × (1 - 25%) = 75万元
```

### 第二步：计算资本成本
```
资本成本 = 部门投资 × 税后加权平均资本成本
资本成本 = 500 × 9% = 45万元
```

### 第三步：计算经济增加值
```
经济增加值 = 税后净营业利润 - 资本成本
经济增加值 = 75 - 45 = 30万元
```

## 结果对比

| 指标 | 数值 |
|------|------|
| 剩余收益 | 40万元 |
| 经济增加值 | 30万元 |

### 差异分析
- 剩余收益 > 经济增加值
- 原因：税前报酬率12% > 税后WACC 9%
- 税金影响：税金是重要因素，EVA更能反映真实价值创造

## 不同税金重要性下的选择

### 情景一：税金是重要因素

**条件：**
- 部门盈利能力受税金影响显著
- 税率可能变化

**选择：** 经济增加值（EVA）
**原因：** 考虑税后收益，更准确反映部门盈利能力

### 情景二：税金与部门业绩无关

**条件：**
- 部门主要考核税前业绩
- 税率稳定

**选择：** 剩余收益（RI）或经济增加值（EVA）均可
**考虑：**
- RI计算简单，易于理解
- EVA更符合股东价值理念

## WACC调整示例

### 资本市场变化

| 项目 | 变化前 | 变化后 |
|------|-------|-------|
| 无风险利率 | 4% | 5% |
| 权益资本成本 | 10% | 11% |
| 债务资本成本 | 6% | 7% |
| WACC | 9% | 10% |

### EVA调整

**变化前：**
```
EVA = 75 - 500 × 9% = 30万元
```

**变化后：**
```
EVA = 75 - 500 × 10% = 25万元
```

**结论：** EVA随市场变化调整，反映真实资本成本。

## 部门业绩评价应用

### 评价标准

| 指标 | 评价标准 |
|------|---------|
| 剩余收益 | > 0 表示部门创造了超过最低要求的收益 |
| 经济增加值 | > 0 表示部门创造了股东价值 |

### 部门对比

| 部门 | 投资 | 税前利润 | RI | EVA |
|------|------|---------|-----|-----|
| A | 500 | 100 | 40 | 30 |
| B | 800 | 150 | 54 | 37.5 |
| C | 300 | 50 | 14 | 7.5 |

**分析：**
- RI排序：B > A > C
- EVA排序：B > A > C
- 结论：部门B业绩最优
