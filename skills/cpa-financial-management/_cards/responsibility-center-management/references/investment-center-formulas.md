# 投资中心指标详细计算

## 基础公式

### 投资报酬率（ROI）
```
部门投资报酬率 = (部门税前经营利润 / 部门平均净经营资产) × 100%
```

### 剩余收益
```
要求的税前投资收益 = 部门平均净经营资产 × 要求的税前投资报酬率
部门剩余收益 = 部门税前经营利润 - 要求的税前投资收益
```

## 补充指标

### 现金回收率
```
现金回收率 = 部门营业现金净流量 / 部门平均净经营资产
```

### 剩余现金流量
```
剩余现金流量 = 部门营业现金净流量 - (部门平均净经营资产 × 资本成本)
```
