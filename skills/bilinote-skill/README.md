# bilinote-skill 说明（速览）

把视频 / 文章 / 文档整理成结构化 Markdown 笔记，**零外部 API Key**（全程走 WorkBuddy 原生 LLM）。
当前版本：**v2.1.0**（2026-07-12）。

> 本文件是「速览 + v2.1 改进要点」，权威细节（交互流程、失败恢复、脚本命令）以同目录 **SKILL.md** 为准。

---

## 它解决什么

- **输入自动识别**：B站 / YouTube / 抖音 / 快手 / 本地视频·音频、文章 URL、粘贴文本、`.txt` `.md` `.pdf` `.docx`
- **视频管线**：字幕优先 → 无字幕走 `bcut` / `kuaishou` 转写 → 当前 LLM 生成笔记（原生模式，无外部 LLM API）
- **扩展能力 E1–E8**：浏览器抓取 / 研究写作 / 手绘配图 / 信息图 / 网页PPT / 去AI味 / 公众号排版 + 导出 PDF·Word / 思维导图 / 系列合集

## 核心交互流

`CP1 智能默认采集` → `等待期被动预览` → `concise 草稿` → **`CP5-A 风格预览`** → **`CP5-B 渐进增强`** → **`📋 质检摘要`** → 交付 + `S7 后续建议`

---

## 快速上手示例

**场景 A — 第一次用（无 Profile，标准路径）**

你发：`把这条 B站链接整理成笔记 https://www.bilibili.com/video/BVxxxx`

Bilinote 流程：
1. CP1 自动按"视频"套最优采集（字幕 + 弹幕 + 截图），告知可取消
2. 等待期：被动提示"已采到 X 分钟字幕，稍候出草稿"
3. concise 草稿出炉
4. CP5-A：并行生成 4 版真实样例（🔥小红书 / 📊商业 / ⚡精简 / 🎭费曼）
5. 你挑「🔥小红书」
6. CP5-B：按风格过滤增强项，你勾「配图 + 信息图 + 去AI味」
7. 📋 质检摘要：硬门禁通过 / 冷读外审（因选了去AI味）/ 无 series → 跳过索引
8. 交付 + S7：「要不要做成系列合集？」

**场景 B — 设好 Profile（常用户，1 弹窗加速）**

```yaml
# ~/.bilinote/profile.yaml
default_style: xiaohongshu
enhance: [E6, E8]
```

你发：`整理这条视频`

Bilinote 流程：
1. 检测到 Profile
2. CP5-A 轻量确认（仅 1 弹窗）：*你的偏好是「小红书 + 去AI味 + 公众号排版」，这篇也这样出？* → [就按这个来] [换风格看看]
3. 你选「就按这个来」
4. 直接按默认风格 + 增强链出成品 → 质检摘要 → 交付（全程不弹四预览、不弹 CP5-B）

更多脚本命令、失败恢复、风格提示词见 SKILL.md。

## v2.1.0 改进速览（本版重点）

融合 `sansheng-distill` 与 `sansheng-write` 的四项借鉴，落地「**方案三：Profile 双路径 + 质检摘要门禁**」。

### 1. 风格偏好 Profile（常用户 1 弹窗加速）

文件 `~/.bilinote/profile.yaml`（不存在则走标准 CP5，无惩罚、无提示噪声）：

```yaml
default_style: xiaohongshu   # 默认产出风格
enhance: [E6, E8]            # 默认增强链（去AI味 + 公众号排版）
avoid: [academic]            # 永不主动推荐的风格（可选）
```

- **有 Profile** → CP5-A 走「轻量确认路径」：**仅 1 次弹窗**（就按这个来 / 换风格看看），确认即按默认风格 + 增强链出成品，**跳过四预览与 CP5-B**。
- **无 Profile** → 标准四风格预览（同 v2.0.1）。
- **说"换风格"** → 立即退回标准路径。Profile 是加速键，不是绑架。

### 2. 铁律总纲（硬约束集中处）

把分散全文的硬约束收敛一处，各阶段执行前引用：破折号统一 `--`、不编造、版权线 ≤150 字、强制 checkpoint、等待期不弹窗、确定性优先、质量门禁。

### 3. 📋 质检摘要门禁（交付前必过 · 无弹窗）

三层被动卡片，**不过不交付**：

1. **硬门禁**：逐条机检「铁律总纲」（破折号 / 版权线 / 不编造 / 确定性 / 等待期不弹窗）。
2. **冷读外审**（仅应用 E6 去AI味时）：另起一个**不同模型族** subagent 仅喂成品冷读，判定"像不像 AI 写"（是/否 + 置信度）+ 最多 3 条改点——即「去AI味（含换模型审稿）」承诺的审稿环节。
3. **跨笔记索引**（仅 series 合集时）：更新 `~/.bilinote/knowledge-index.json`，供系列自动聚合与统一导出。

### 4. CP5-B 微调

- 「去AI味」选项补「（含换模型审稿）」标注，描述写明冷读审稿环节。
- CP5-B 顶部注明：Profile「就按这个来」用户不进入本步。
