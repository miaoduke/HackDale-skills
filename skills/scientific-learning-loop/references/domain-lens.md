## 通用扫描层（所有高风险领域共享）

> 实战沉淀（GF-DMA 选股框架帖 + 香港券商渠道帖 + QQQ 策略帖）。跑任何高风险领域主题时第 4 步**先**逐条过一遍，再追加命中领域的专属视角。

### 🧰 通用排雷模板

**A. 三层优先级排序（先安全，后证据/收益，最后体验）**
1. **安全层（生死线，最易被原文省略）**：本金 / 健康 / 法律后果会不会没？持牌/资质、资金/身体/责任隔离、赔偿/救济兜底、监管归属。
   - 跨领域锚点：
     - 投资：本金安全 = SFC 持牌 + 资金隔离（CMR）+ 赔偿基金（ICF，每户最高 HK$50 万，保违责不保亏损）
     - 医疗：身体安全 = 禁忌 / 不良反应 / 相互作用
     - 法律：责任安全 = 时效 / 举证门槛 / 程序要件
     - 工程：功能安全 = 失效后果 / 单点故障
2. **证据/收益层（存疑区）**：宣称的效果 / 超额收益有无实证？选择性单例还是样本外？负面样本（破发 / 不良反应 / 败诉）是否被省略？
   - 投资：超额收益有无样本外 / walk-forward、有无成本模型、有无 regime 风险
   - 医疗：循证等级（牛津 CEBM：1a 系统综述 › 5 专家意见）
   - 法律：法条效力 / 判例 vs 个例类比
   - 工程：可靠性数据 / FMEA
3. **体验层（加分项，权重最低）**：易用度 / 口感 / 界面 / 流程繁琐度——主观，别当第一标准。

**C. 利益透明度扫描（内容帖专属）**：作者是否披露返佣 / 合作 / 持仓 / 资助？「客观排名」「独立评测」「个人记录」是否可能是转化漏斗？零披露 = 透明度硬伤，结论按「存疑」降级。

**E. 一句话收敛句式**：「内核____（可信/存疑）、外壳____（伪精度?）、实证____（有无）、利益____（透明?）」。

## 视角一 · 投资 / 金融 / 量化 → 合规红线

**已交叉核验，来源可信度 ≈ 95–98%**

- **核心立场**：判定一个框架是否踩投顾红线，**不看它叫什么，看它做了什么、向谁做、收没收费**。
- **B. 三要素红线扫描（投资专属）**：涉及**具体品种** ✅? 给出**方向/时机暗示** ✅? 收取**费用/返佣/引流** ✅? —— 三者同中即实质落入证券投资顾问业务，须机构持牌 + 个人注册投顾，否则非法。
- **权威依据**：
  - 《证券投资顾问业务暂行规定》（证监会 2020 年修订，公告〔2020〕66 号）第六条、第三十一条；
  - 《证券法》第 160 条（证券投资咨询机构须经国务院证券监督管理机构核准）；
  - 执法案例：和讯信息（责令改正 + 暂停新增客户 6 个月）、海南港澳资讯（暂停新增客户 3 个月）、王某非法荐股（**非法经营罪，判刑 2 年 6 个月、罚金 1500 万**）、金某「抢帽子」（没收 + 罚款 4000 余万 + 3 年市场禁入）。
- **费曼叠加点**：免责声明**不豁免业务实质**；「健康度 0–100 分 / 六档状态」类外壳伪精度，比裸喊「买它」更易诱导投资者卸下防备——这是 cargo cult 的危害放大版。
- **D. 伪优惠/伪精度话术库（投资专属锚点，费曼货物崇拜检测用）**：
  - 「一世免佣特权」→ 免佣不免平台费，营销词。
  - 「健康度 0–100 分 / 六档状态」→ 连续判断压整数刻度，伪精度。
  - 「黄金坑 / 过热 / 精准定位 / 重仓机会」→ 方向性暗示 + 伪确定性。
  - 「打新不错 / 稳赚」→ 选择性呈现，破发样本被省略。

## 视角二 · 医疗 / 健康 / 营养 → 循证等级

- **核心立场**：任何健康主张先问「证据级别」，再看「谁受益」。个案与网红帖不可当结论。
- **检查点**：
  - **证据分级（牛津 CEBM）**：1a 系统综述 RCT › 1b 单 RCT › 2a 队列研究 › 3a 病例对照 › 4 病例系列 › 5 专家意见。个案 / 网红帖 ≈ 5 级。
  - 是否把「相关性」说成「因果」；是否披露利益冲突 / 资助方；营养补剂主张是否过拟合个例；
  - 是否**替代执业医师诊断**（尤其急症 / 处方药 / 慢病管理）。
- **权威依据**：Cochrane 系统综述、GRADE 评级系统、NEJM / Lancet / JAMA 等同侪评审期刊、WHO 及各国疾控指南。
- **费曼叠加点**：「天然 / 古法 / 细胞级 / 量子」等修饰词常是 cargo cult 包装——翻成六年级版若只剩「听起来高级」，即伪科学信号。

## 视角三 · 法律 / 合规 / 政策 → 法域与资质

- **核心立场**：法律结论高度依赖**法域、时效、事实细节**；「通用法律建议」往往不成立。
- **检查点**：
  - 是否指明适用**法域**（中国大陆 / 中国香港 / 其他）与**生效时点**；
  - 是否提示**举证门槛 / 诉讼时效 / 程序要件**；
  - 是否越界给出「必胜 / 无风险」承诺；是否**替代执业律师**。
- **权威依据**：对应法域成文法 / 司法解释 / 指导性案例；未同行评审的自媒体法律解读标「存疑」。
- **费曼叠加点**：「百分百赢 / 包过 / 绝对没问题」等绝对化表述是反自欺审查重点。

## 视角四 · 工程 / 安全 / 医疗设备 → 失效模式

- **核心立场**：任何「能跑通」≠「安全 / 可靠」；须做 FMEA 式失效假设。
- **检查点**：边界条件、单点故障、回滚 / 熔断机制、人在回路；是否只展示成功案例、回避失效场景。
- **权威依据**：FMEA（IEC 60812）、失效安全（fail-safe）与冗余设计原则。
- **费曼叠加点**：「演示成功」≠「生产可靠」；把「它在 demo 里跑通了」翻译成六年级版——「它在最理想的一次里没出错」，即暴露样本偏差。

## 更新约定

- 新增领域时，复制「视角 N」模板，保留领域专属四要素：**核心立场 + 检查点/红线(B/D类) + 权威依据（带可信度） + 费曼叠加点**。
- **跨领域通用件（A/C/E：三层优先级、利益透明度、收敛句式）统一放「通用扫描层」，不重复进各视角**。
- 权威依据须可查；社媒经验 / 未同侪评审内容标「中低 / 存疑」，不当权威使用。
