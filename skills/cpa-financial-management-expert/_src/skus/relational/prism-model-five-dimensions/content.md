# 绩效棱柱模型五构面设计

绩效棱柱模型从企业利益相关者角度出发，以利益相关者满意为出发点，以利益相关者贡献为落脚点，以企业战略、业务流程、组织能力为手段，用棱柱五个构面构建三维绩效评价体系。五个构面：1.利益相关者满意构面：解决“谁是企业的主要利益相关者，他们的愿望和要求是什么”问题；2.企业战略构面：解决“企业应该采用什么战略来满足利益相关者需求”问题；3.业务流程构面：解决“企业需要哪些关键业务流程才能执行战略”问题；4.组织能力构面：解决“企业需要哪些能力才能开展和改善企业业务流程”问题；5.利益相关者贡献构面：解决“为了培育和发展组织能力，企业需要利益相关者为企业作出哪些贡献”问题。企业根据不同利益相关者（投资者、员工、客户、供应商、监管机构）设置五构面的评价指标体系。设定绩效目标值以利益相关者满意指标目标值为出发点，逐步分解得到其他构面指标目标值。
