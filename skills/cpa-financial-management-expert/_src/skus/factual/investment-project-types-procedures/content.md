# 投资项目类型和评价程序

投资项目类型按不同标准分类：1.按项目间关系：独立项目（采纳或放弃互不影响）、互斥项目（只能选一个）、关联项目（接受一个影响另一个）。2.按风险特征：常规项目（现金流符号只变一次，有唯一IRR）和非常规项目（现金流符号变多次，可能有多个IRR）。评价程序：1.提出各种投资方案；2.估计方案的相关现金流量；3.计算投资方案的价值指标（如NPV、IRR）；4.比较价值指标与可接受标准；5.对已接受方案进行再评价。项目投资具有目标性、长期性、独特性和不可逆性等基本特征。
