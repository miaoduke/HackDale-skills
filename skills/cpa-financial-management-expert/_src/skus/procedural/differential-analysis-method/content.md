# 差量分析法

差量分析法通过分析备选方案之间的差额收入和差额成本，根据差额利润进行选择。计算公式：差额利润=差额收入-差额成本；差额收入=方案A相关收入-方案B相关收入；差额成本=方案A相关成本-方案B相关成本。决策规则：若差额利润>0，则方案A优于方案B；若差额利润<0，则方案B优于方案A。可通过编制差量分析表计算差额利润高低。分析过程中只考虑相关收入和相关成本，对不相关因素不予考虑。对于两个以上备选方案，需两两进行比较，逐次筛选。相关成本包括可避免成本、可延缓成本、专属成本、机会成本等；不相关成本包括不可避免成本、不可延缓成本、无差别成本、共同成本等。
