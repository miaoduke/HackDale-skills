# EBIT-EPS无差别点分析

EBIT-EPS分析的完整步骤：
1.无差别点公式：(EBIT-I1)(1-T)/N1=(EBIT-I2)(1-T)/N2（债务与普通股比较）；(EBIT-I)(1-T)-PD/N=(EBIT)(1-T)/N（优先股与普通股比较）
2.计算各方案EPS：EPS=[(EBIT-I)(1-T)-PD]/N
3.图示分析起点：①债务线起点=年利息额（EBIT轴截距）；②优先股线起点=PD/(1-T)；③普通股线起点=0
4.决策规则：预期EBIT高于无差别点时选债务筹资（EPS更高）；预期EBIT低于无差别点时选普通股筹资
5.债务筹资与优先股筹资线永不相交（平行），债务始终优于优先股
6.综合决策：在预期EBIT水平下，选择能提供最大EPS的单一方案
