# 实物期权价值评估

实物期权的三种主要类型及估值方法：
1.扩张期权（看涨期权）：标的资产=未来扩张项目现金流量现值，执行价格=扩张投资额现值，可使用BS模型。考虑期权的项目净现值=不含期权净现值+扩张期权价值
2.延迟期权（看涨期权）：标的资产=项目价值=永续现金流量/折现率，使用二叉树模型。步骤：①构造现金流量和项目价值二叉树；②构造净现值二叉树；③用风险中性原理计算上行概率；④计算含期权的项目净现值。若不含期权净现值<0但含期权净现值>0，应延迟投资
3.放弃期权（看跌期权）：标的资产=项目继续经营价值，执行价格=清算价值。当继续经营价值<清算价值时执行放弃。使用二叉树模型，从后向前逐期比较继续经营价值与清算价值
