# 经济订货量模型

经济订货量基本模型假设：能及时补货、集中到货、不允许缺货、需求稳定、单价不变、现金充足、市场供应充足。公式：Q* = √(2KD/Kc)，其中K为一次订货变动成本，D为存货年需求量，Kc为单位储存变动成本。相关衍生公式：(1)每年最佳订货次数N* = D/Q* = √(DKc/2K)；(2)最佳订货周期t* = 1/N*；(3)经济订货量占用资金I* = Q*/2 × U；(4)与经济批量有关的存货总成本TC(Q*) = √(2KDKc)。总成本TC = F1 + (D/Q)K + DU + F2 + (KcQ)/2。
