# 企业价值评估-现金流量折现模型

现金流量折现模型的基本框架：
1.基本公式：企业价值=Σ未来各期自由现金流量/(1+加权平均资本成本)^n
2.股权现金流量模型：股权价值=Σ股权现金流量/(1+权益资本成本)^n；股权现金流量=净利润-净投资×(1-负债率)
3.实体现金流量模型：实体价值=Σ实体现金流量/(1+加权平均资本成本)^n；实体现金流量=税后经营净利润-净经营资产增加
4.两阶段模型：企业价值=详细预测期价值+后续期价值；后续期价值=后续期第一年现金流量/(资本成本-永续增长率)/(1+资本成本)^n
5.企业价值V=股权价值S+债务价值B+优先股价值P
