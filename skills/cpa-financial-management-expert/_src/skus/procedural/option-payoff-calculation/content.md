# 期权到期日价值与损益计算

期权到期日价值与净损益的计算方法：
1.买入看涨期权（多头看涨）：到期日价值=max(股票市价-执行价格,0)；净损益=到期日价值-期权价格
2.卖出看涨期权（空头看涨）：到期日价值=-max(股票市价-执行价格,0)；净损益=到期日价值+期权价格
3.买入看跌期权（多头看跌）：到期日价值=max(执行价格-股票市价,0)；净损益=到期日价值-期权价格
4.卖出看跌期权（空头看跌）：到期日价值=-max(执行价格-股票市价,0)；净损益=到期日价值+期权价格
判断原则：看涨期权当股票市价>执行价格时执行，看跌期权当股票市价<执行价格时执行。期权买方最大损失为期权价格，卖方最大收益为期权价格。
