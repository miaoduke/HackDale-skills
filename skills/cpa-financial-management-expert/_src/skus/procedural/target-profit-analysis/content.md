# 保利分析

保利分析是基于本量利基本关系原理进行的确保达到既定目标利润的分析。保利点计算：1.实现税前目标利润的销售量=(固定成本+目标利润)/(单价-单位变动成本)=(固定成本+目标利润)/单位边际贡献；2.实现税前目标利润的销售额=(固定成本+目标利润)/边际贡献率；3.实现税后目标利润的销售量=[固定成本+目标利润/(1-T)]/单位边际贡献（T为所得税税率）。敏感分析：分析单价、单位变动成本、销售量、固定成本等因素变动对利润的影响。敏感系数=目标变量变动百分比/选定因素变动百分比。利润对单价的敏感系数通常最大，对固定成本的敏感系数通常最小。管理上应重点关注敏感因素。
