# 会计账户设置与记录

## 使用场景
当需要进行会计核算时，依据会计科目设置账户并按相反方向登记；当需要计算账户期末余额或结转下期余额时，应用余额核算公式。

## 会计账户的定义
会计账户是对会计要素的内容进一步进行具体分类，对所有发生的经济业务在对应的账户中分别进行记录，系统地反映企业各项经济业务的发生情况。

## 会计账户与会计科目的关系

### 联系
- **名称关系**：会计科目是会计账户的名称
- **分类性质**：都是会计对象的性质和具体内容的分类
- **依据关系**：会计科目是会计账户设置的依据
- **应用关系**：会计账户是对会计科目内容的具体反映和应用

### 区别
- **会计科目**：只是会计账户的"名称"，不存在结构
- **会计账户**：是记录和反映经济业务的"载体"，须有一定的"内容"和"形式结构"

## 会计账户的设置

### 设置依据
会计账户必须根据会计科目进行设置，且必须具备一定的格式和结构。

### 账户分类（按反映详细程度）

#### 总账
- **设置依据**：根据"总分类科目"设置
- **核算性质**：对会计要素的具体内容进行"总括分类核算"

#### 明细账
- **设置依据**：根据"明细分类科目"设置
- **核算性质**：对会计要素具体内容进行"明细分类核算"

### 账户分类（按经济业务性质）
- 资产类账户
- 负债类账户
- 所有者权益类账户
- 成本类账户
- 损益类账户

## 登记规则

### 平衡原则
企业的资产与权益始终保持相等的平衡关系：**资产 = 权益**

### 登记方向规则
在上述两方面的会计科目中，必须分别从两个相反的方向来登记会计要素的增减变动。

## 会计账户余额核算

### 核心计算公式
```
期末余额 = 期初余额 + 本期增加发生额 - 本期减少发生额
```

### 术语定义
- **期初余额**：会计期间开始时账户的金额（即上期期末余额）
- **期末余额**：会计期间结束时账户的金额
- **本期增加发生额**：会计账户中左方和右方记录的本期增加的金额
- **本期减少发生额**：会计账户中登记本期减少的金额

### 余额结转规则
- 上期期末余额 = 本期期初余额
- 本期期末余额 = 下期期初余额

### 计算步骤
1. 获取账户的期初余额
2. 汇总计算期内所有增加的金额（本期增加发生额）
3. 汇总计算期内所有减少的金额（本期减少发生额）
4. 应用公式计算期末余额

## 约束条件
- 必须遵循资产与权益平衡关系
- 需明确区分左方和右方的登记方向（借方或贷方）

## 预期结果
生成具有特定格式的账户记录，反映会计要素在两个相反方向上的增减变动，计算得出账户在特定时间点的结存金额。
