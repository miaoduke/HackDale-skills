# 主要财务报表类型

## 资产负债表
- **反映内容**：特定日期的财务状况
- **结构**：资产 = 负债 + 所有者权益
- **时点**：某一时点（如年末、月末）

## 利润表
- **反映内容**：一定期间的经营成果
- **结构**：收入 - 费用 = 利润
- **时期**：某一期间（如年度、月度）

## 现金流量表
- **反映内容**：一定期间的现金流量
- **分类**：经营活动、投资活动、筹资活动
- **时期**：某一期间

## 所有者权益变动表
- **反映内容**：一定期间所有者权益变动情况
- **内容**：实收资本、资本公积、留存收益等变动

## 附注
- **作用**：对报表项目的补充说明
- **内容**：会计政策、会计估计、或有事项等
