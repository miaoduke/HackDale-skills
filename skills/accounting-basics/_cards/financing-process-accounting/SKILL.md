# 筹资过程核算账户设置与记账规则

## 使用场景
当企业接受投资者投资、发生筹资相关经济业务，需要进行账户设置和记账时使用。

## 基本账户设置
筹资过程核算所需的基本账户包括：
- 银行存款
- 实收资本
- 固定资产
- 无形资产
- 短期借款
- 长期借款

## 投资业务的双重影响
企业接受投资者投资时：
- 一方面：资产增加
- 另一方面：所有者权益增加

## 资产类账户记账规则
适用于：银行存款、固定资产、无形资产

- **账户性质**：资产类账户
- **借方登记**：增加数
  - 银行存款增加数
  - 固定资产增加数
  - 无形资产增加数
- **贷方登记**：减少数
  - 银行存款减少数
  - 固定资产减少数
  - 无形资产减少数
- **期末余额**：一般在借方，表示实有数额或结余价值

## 所有者权益类账户记账规则
适用于：实收资本

- **账户性质**：所有者权益类账户
- **登记方向**：与资产类账户刚好相反
- **借方登记**：减少额（所有者投资的减少数）
- **贷方登记**：增加额（所有者投资的增加数）
- **期末余额**：在贷方，表示期末实收资本的实有数额

## 实收资本账户的特殊约束

### 变动限制
- 企业的实收资本不能随意变动

### 允许变动的例外情况
- 经批准将企业资本公积转增资本
- 经批准将盈余公积转增资本

### 明细核算要求
- 实收资本账户应按投资者设置明细分类账户

## 记账规则总结
```
资产类账户：借增贷减，余额在借方
权益类账户：借减贷增，余额在贷方
```
