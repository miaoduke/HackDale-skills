# 盘存单填写

## 适用场景
需要进行实物资产盘点或清查时，使用盘存单记录盘点结果。

## 填写表头信息

### 必填字段
- **单位名称**：盘点单位的法定全称
- **存放地点**：资产实际存放的具体位置
- **编号**：该盘存单的唯一编号
- **财产类别**：盘点的资产类别（如：固定资产、原材料等）
- **盘点时间**：盘点操作的具体日期和时间

## 填写明细项目

按行填写以下信息：

| 字段 | 说明 | 示例 |
|-----|------|------|
| 序号 | 按顺序填写的流水号 | 1, 2, 3... |
| 名称 | 资产或存货的名称 | 办公电脑 |
| 规格 | 资产的型号或规格参数 | 联想ThinkPad X1 |
| 计量单位 | 资产的计量单位 | 台、件、千克 |
| 数量 | 实际盘点的实物数量 | 5 |
| 单价 | 该资产的单位成本或单价 | 8000.00 |
| 金额 | 数量 × 单价 | 40000.00 |
| 备注 | 其他说明信息（残损、积压等） | 正常 |

## 金额计算公式
```
金额 = 数量 × 单价
```

## 填写注意事项
1. 确保盘点范围完整，无遗漏
2. 数量必须为实际盘点数，不能仅凭账面记录
3. 单价应使用资产的实际成本或账面价值
4. 备注栏应如实记录资产状态（如：完好、残损、积压等）
5. 盘点完成后应由盘点人和监盘人签字确认
