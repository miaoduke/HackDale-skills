# 资产周转率分析

## 使用场景
当需要评估企业资产使用效率、运营能力或应收账款回收速度时，使用此技能。

## 执行步骤

### 1. 总资产周转率分析

**收集数据**：
- 营业收入
- 期初总资产
- 期末总资产

**计算公式**：
```
平均总资产 = (期初总资产 + 期末总资产) / 2
总资产周转率 = 营业收入 / 平均总资产
```

**高低比较分析**：
- **纵向比较**：与历史数据对比，比率上升说明资产利用效率提高
- **横向比较**：与同行业对比，高于行业平均说明具有竞争优势

**结果解读**：
- 较高：资产使用效率高，周转速度快，销售能力强
- 较低：资产使用效率低，可能存在资产闲置或销售能力不足

### 2. 应收账款周转率分析

**收集数据**：
- 销售收入净额
- 年初应收账款余额
- 年末应收账款余额

**计算公式**：
```
应收账款平均余额 = (年初应收账款 + 年末应收账款) / 2
应收账款周转率 = 销售收入净额 / 应收账款平均余额
```

**结果解读**：
- 数值越高：应收账款回收速度越快，资金使用效率越高
- 数值越低：应收账款回收速度慢，资金占用时间长

## 注意事项
- 不同行业间不可直接对比
- 资本密集型行业周转率通常较低
- 劳动密集型或流通行业周转率通常较高
- 需结合企业具体经营周期分析
