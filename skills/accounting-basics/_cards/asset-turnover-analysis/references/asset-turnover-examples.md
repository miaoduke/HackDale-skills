# 总资产周转率示例

## 计算示例
- 营业收入：1000万元
- 期初总资产：800万元
- 期末总资产：1200万元

## 计算过程
1. 平均总资产 = (800 + 1200) / 2 = 1000万元
2. 总资产周转率 = 1000 / 1000 = 1.0次

# 应收账款周转率示例

## 计算示例
- 销售收入净额：200万元
- 年初应收账款：48万元
- 年末应收账款：42万元

## 计算过程
1. 应收账款平均余额 = (48 + 42) / 2 = 45万元
2. 应收账款周转率 = 200 / 45 ≈ 4.4次

## 结果说明
应收账款周转率为4.4，说明企业应收账款回收速度较快。
