# 盈利能力分析

## 使用场景
当需要以下操作时使用此技能：
- 评估企业经营业绩
- 进行投资决策
- 经营者发现内部问题
- 评估企业盈利能力
- 判断企业是否值得投资

## 核心定义
企业的盈利能力可以直接反映出企业经营业绩。

## 盈利能力强弱判定
- **利润高**：盈利能力强
- **利润低**：盈利能力差

## 分析目的

### 对于投资者
了解一个企业的盈利能力，可以判断其是否值得投资。

### 对于企业老板
分析盈利能力有助于了解自身存在的问题，帮助经营者做出有效决策。

## 核心指标

### 1. 资本收益率
```
资本收益率 = 净利润 ÷ 总资本
```

### 2. 营业利润率
```
营业利润率 = 营业利润 ÷ 营业收入 × 100%
```

### 3. 营业毛利率
```
营业毛利率 = (营业收入 - 营业成本) ÷ 营业收入 × 100%
```

### 4. 净利率
```
净利率 = 净利润 ÷ 营业收入 × 100%
```

## 资本收益率影响评估

### 高资本收益率的影响
- **正面信号**：资本利用效率高，盈利能力强
- **管理层能力**：反映管理层在资源配置和资产运营方面表现优异
- **市场表现**：通常能吸引更多投资，提升股价，降低融资成本

### 低资本收益率的影响
- **负面信号**：资本利用效率低下，投入资本未能产生足够回报
- **潜在问题**：可能暗示存在过度投资、资产闲置、运营成本过高或战略方向错误
- **价值破坏风险**：若收益率长期低于资本成本，意味着企业在毁灭股东价值

### 价值创造判断
```
IF (资本收益率 > 加权平均资本成本 WACC)：企业在创造价值
IF (资本收益率 < 加权平均资本成本 WACC)：企业在破坏价值
```

## 综合对比与判断

### 横向对比
将当前收益率与行业平均水平对比，判断企业在行业中的竞争地位。

### 纵向对比
将当前收益率与企业历史数据对比，观察经营趋势是改善还是恶化。

## 注意事项
- 不适用于非营利性组织
- 需剔除非经常性损益以获得准确评估
- 不同行业的资本收益率基准差异较大，不可直接跨行业比较
- 需要结合加权平均资本成本(WACC)进行价值创造判断

## 输出结果
- 各项盈利能力指标数值
- 盈利能力强弱评估
- 价值创造/破坏判断
- 投资价值评估结论
