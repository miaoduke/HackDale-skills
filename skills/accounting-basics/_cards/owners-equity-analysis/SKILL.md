# 所有者权益分析

## 适用场景
- 需要编制或分析所有者权益变动表
- 需要分析企业一定时期内的资本保值增值水平
- 需要评价企业资本运营效益
- 需要评价企业资本安全性

## 前置条件
- 企业所有者权益期末数
- 企业所有者权益期初数
- 公司财务数据
- 会计期间界定

## 所有者权益变动表性质
- **报表类型**：动态报表
- **时间范围**：一般是年度
- **核心功能**：反映一定期间内公司股东权益的变动情况

## 所有者权益变动逻辑

### 所有者权益增加的情况
当发生以下情况时，判定所有者权益增加：
1. 公司获得盈余（盈利）
2. 公司股本增加

### 所有者权益减少的情况
当发生以下情况时，判定所有者权益减少：
1. 公司发生亏损
2. 公司分配现金股利等情况

## 资本保值增值率计算

### 计算公式
```
资本保值增值率 = 企业所有者权益期末数 / 企业所有者权益期初数
```

### 指标定义
该指标是企业所有者权益的期末数与期初数之间的比率

### 核心目的
用以反映企业一定时期内的资本保值增值水平

### 评价依据
该指标是评价企业资本运营效益和资本安全性的依据

## 分析输出
- 确定报表性质
- 判定权益变动方向（增加或减少）
- 计算资本保值增值率
- 评价资本运营效益和安全性
