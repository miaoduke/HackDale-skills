# 所有者权益变动示例

## 权益增加示例

### 情况1：公司盈利
- 期初所有者权益：1,000,000元
- 本期净利润：200,000元
- 期末所有者权益：1,200,000元
- 资本保值增值率 = 1,200,000 / 1,000,000 = 1.2（120%）

### 情况2：公司股本增加
- 期初所有者权益：1,000,000元
- 新增股本：500,000元
- 期末所有者权益：1,500,000元
- 资本保值增值率 = 1,500,000 / 1,000,000 = 1.5（150%）

## 权益减少示例

### 情况1：公司亏损
- 期初所有者权益：1,000,000元
- 本期净亏损：100,000元
- 期末所有者权益：900,000元
- 资本保值增值率 = 900,000 / 1,000,000 = 0.9（90%）

### 情况2：分配现金股利
- 期初所有者权益：1,000,000元
- 分配现金股利：50,000元
- 期末所有者权益：950,000元
- 资本保值增值率 = 950,000 / 1,000,000 = 0.95（95%）
