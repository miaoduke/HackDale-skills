# 所有者权益详细说明

## 核心公式
```
所有者权益 = 实收资本 + 资本公积 + 盈余公积 + 未分配利润
```

## 资本公积具体项目
- 资本（或股本）溢价
- 接受捐赠资产
- 外币资本折算差额
- 其他原因

## 盈余公积定义
- 资金来源：企业"实现的利润"
- 形成方式：通过"提取"或"形成"产生
- 留存性质：留存于企业内部的积累，未分配给股东

## 未分配利润定义
- 主体：企业
- 性质：利润范畴
- 状态：未分配状态，包含两种情形：
  1. 企业主动保留，计划用于"以后年度分配"
  2. 目前处于"待分配"状态

## 计算示例

### 年初余额
- 实收资本(或股本)：1,196.47
- 资本公积：2,933.72
- 盈余公积：1,197.96
- 未分配利润：390.37
- 所有者权益合计：5,718.52

### 本年变动
- 净利润：239.13
- 提取盈余公积：125.18
- 对所有者分配：358.94

### 年末余额计算
- 实收资本(或股本)：1,196.47（无变动）
- 资本公积：2,933.72（无变动）
- 盈余公积：1,197.96 + 125.18 = 1,323.14
- 未分配利润：390.37 + 239.13 - 125.18 - 358.94 = 145.37
- 所有者权益合计：5,718.52 + 239.13 - 358.94 = 5,598.70
