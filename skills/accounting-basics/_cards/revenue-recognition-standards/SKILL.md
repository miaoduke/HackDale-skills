# 收入确认标准

## 使用场景
当发生经济利益流入，需要判断其是否应确认为收入时使用。

## 确认流程

### 第一步：基本定义核对
收入是指企业在日常经营活动中，销售商品、提供劳务或让渡资产等形成的、会导致所有者权益增加的、且与所有者投入资本无关的经济利益流入。

### 第二步：排除项检查
- **代收款项**：为第三方或客户代收的款项（如增值税进项税额）不属于收入

### 第三步：特征检查

#### 特征一：日常活动判定
- 检查经营活动是否属于日常活动
- 日常活动示例：
  - 工业企业生产加工
  - 商业企业销售产品
  - 信息咨询公司提供咨询服务
- **区分**：非日常经营活动形成的收益应计入"利得"，而非收入

#### 特征二：与资本无关判定
- 确认流入是否与所有者投入资本无关
- 若是所有者投入资本增加导致的流入，应确认为"所有者权益增加"，而非收入
- 正常收入应导致企业资产增加（如现金收入或应收账款）

#### 特征三：所有者权益增加判定
- 确认流入是否会导致所有者权益增加
- **反例**：企业向银行借入款项，虽导致经济利益流入，但所有者权益未增加（而是承担债务），应确认为"负债"

### 第四步：分类归属
若符合上述所有条件，确认为收入：
- 主营业务收入
- 其他业务收入

## 判定逻辑
```
IF (日常活动 AND 与资本无关 AND 导致所有者权益增加 AND 非代收款项)
THEN 确认为收入
ELSE IF (非日常活动) THEN 计入利得
ELSE IF (与资本有关) THEN 确认为所有者权益
ELSE IF (导致负债增加) THEN 确认为负债
```
