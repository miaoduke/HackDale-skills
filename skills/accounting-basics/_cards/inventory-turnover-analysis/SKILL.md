# 存货周转率分析

## 使用场景
当需要评估企业存货变现能力、资金使用效率或运营管理能力时，使用此技能。

## 执行步骤

### 1. 计算存货周转率

**收集数据**：
- 期初存货余额
- 期末存货余额
- 营业成本

**计算公式**：
```
平均存货余额 = (期初存货 + 期末存货) / 2
存货周转率 = 营业成本 / 平均存货余额
```

### 2. 多维度对比分析

**纵向历史对比**：
- 将当前存货周转率与企业历史数据对比
- 分析变化趋势（改善或恶化）
- 评估内部管理效率变动

**横向同业对比**：
- 与同行业、同规模企业比较
- 确定企业在行业竞争中的相对位置
- 注意不同行业基准值的天然差异

### 3. 结果解读

**高存货周转率**：
- 产品销售良好，市场需求旺盛
- 资金回流快，资金使用效率高
- 存货变现能力强

**低存货周转率**：
- 产品可能滞销，库存积压
- 资金回流慢，占用大量资金
- 可能影响短期偿债能力

**数值含义**：
- 存货周转率 3.8 表示：每 1 元存货会产生 3.8 倍的销售成本
- 数值越高，存货转化为销售成本的效率越高

## 注意事项
- 所有数据必须来自同一会计期间
- 存货数据需以货币单位计价
- 不可跨行业直接对比绝对数值
- 需同时进行纵向和横向对比才能得出准确结论
