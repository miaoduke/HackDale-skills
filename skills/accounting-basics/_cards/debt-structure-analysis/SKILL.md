# 债务结构分析

## 使用场景
当需要评估企业财务结构稳健性、债务风险或资本利用效率时，使用此技能。

## 执行步骤

### 1. 计算资产负债率

**计算公式**：
```
资产负债率 = (负债总额 ÷ 资产总额) × 100%
```

**结果解读**：
- 60%左右：财务结构较为合理
- 高于同行业平均：财务结构稳健，偿债保障度高
- 低于同行业平均：负债过高，债务风险高

### 2. 计算股东权益比率

**计算公式**：
```
股东权益比率 = 股东权益 ÷ 资产总额
```

**结果解读**：
- **比率偏低**：净资产占比低，负债比例高，债务风险高
- **比率偏高**：资产主要由股东投入，负债风险低，财务结构稳健
- **比率过高**：不善于利用资本扩大规模，无法获取更大利益
- **适宜标准**：一般不低于30%

### 3. 高负债率影响分析

**识别高负债率**：
- 当资产负债率达到80%时，判定为负债率过高

**计算自有资金比例**：
```
自有资金比例 = 100% - 资产负债率
```

**评估财务后果**：
- 检查净资产是否为负数
- 评估现金支付能力是否存在危机

**制定缓解措施**：
- 若存在资金危机，需进行短期融资
- 及时发现企业问题，支持管理决策

## 指标关联性
- 股东权益比率与资产负债比率从两方面反映长期财务状况
- 股东权益比率越大，资产负债比率越小
- 两者之和等于100%

## 注意事项
- 不同行业适宜标准可能存在差异
- 需基于标准会计准则编制的数据
- 高负债率需结合具体经营情况综合判断
