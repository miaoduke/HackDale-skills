# 速动比率分析

## 使用场景
当需要评估企业短期偿债能力、验证流动资产质量或识别短期偿债风险时，使用此技能。

## 执行步骤

### 1. 计算速动比率

**确定速动资产**：
速动资产 = 流动资产 - 存货 - 预付账款 - 一年内到期的非流动资产 - 其他流动资产

速动资产包含：
- 银行存款
- 应收账款
- 短期投资
- 应收票据
- 其他应收款项

**计算公式**：
```
速动比率 = (速动资产 ÷ 流动负债) × 100%
```

### 2. 结果解读

**基准阈值**：100%

**比率高于100%**：
- 企业最快可变为现金的资产充足
- 偿还短期债务有保障
- 短期偿债风险较低

**比率低于100%**：
- 企业用于日常经营所需的流转现金较少
- 偿还短期债务保障度低
- 可能面临无法按时偿还短期债务的风险

### 3. 关键影响因素

主要影响因素是**应收账款的变现能力**：
- 应收账款回收及时程度直接影响速动比率的有效性
- 需结合应收账款账龄和质量综合判断

## 与流动比率的区别
- 速动比率是流动比率的补充和完善
- 速动资产可以随时变现，用以支付流动负债
- 弥补了流动比率中包含变现能力慢资产的不足

## 注意事项
- 需结合应收账款变现能力综合判断
- 不适用于非营利组织
- 速动比率过高也可能意味着资金利用效率低
