# 经营效率指标计算示例

## 存货周转率计算

### 基础数据
- 销货成本：600,000元
- 期初存货：150,000元
- 期末存货：250,000元

### 计算过程
```
平均存货 = (150,000 + 250,000) ÷ 2 = 200,000元
存货周转率 = 600,000 / 200,000 = 3
```

### 结果解读
- 存货周转率为3，达到参考标准
- 结论：企业存货管理状况良好，产品竞争力较强

## 资本收益率计算

### 基础数据
- 净利润：200,000元
- 实收资本年初数：1,000,000元
- 实收资本年末数：1,200,000元
- 资本公积年初数：200,000元
- 资本公积年末数：300,000元

### 计算过程
```
平均资本 = [(1,000,000 + 200,000) + (1,200,000 + 300,000)] ÷ 2
平均资本 = (1,200,000 + 1,500,000) ÷ 2 = 1,350,000元
资本收益率 = (200,000 / 1,350,000) × 100 = 14.81%
```

### 结果解读
- 资本收益率为14.81%
- 结论：企业资本收益能力良好
