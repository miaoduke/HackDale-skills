# 原始凭证识别与分类

## 使用场景
- 接收到经济业务书面证明，需要判断是否为原始凭证
- 需要区分原始凭证的来源类型
- 需要验证凭证的法律效力
- 遇到复印件、影印件等非原始形式凭证

## 识别流程

### 步骤1：定义验证
确认该文件是否满足以下条件：
- 在经济业务发生时填制
- 是书面形式的证明文件
- 是最初的证明文件

### 步骤2：法律属性确认
- 原始凭证在法律上具有证明效力
- 只有原始凭证具有法律效力

### 步骤3：形式识别
检查文件是否属于常见形式：
- 发票
- 单据

### 步骤4：来源分类
根据来源不同，将原始凭证划分为：

| 分类 | 判定标准 | 示例 |
|------|----------|------|
| 自制原始凭证 | 由本企业内部自行填制 | 产品入库单、收货单 |
| 外来原始凭证 | 从外部单位取得 | 发票、货物运单 |

### 步骤5：二次凭证识别
若凭证形式为以下类型，则判定为二次凭证：
- 复印件
- 影印件
- 其他非原始形式

**重要提示**：二次凭证不具有法律效力，不能作为有效证据使用。

## 判定结果模板
```
识别为原始凭证，类型为[自制原始凭证/外来原始凭证]，作为填制记账凭证的依据
```
或
```
凭证类型：二次凭证；法律效力：无
```
