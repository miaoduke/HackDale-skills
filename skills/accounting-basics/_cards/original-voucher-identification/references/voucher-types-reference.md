# 原始凭证类型参考

## 自制原始凭证类型

### 一次凭证
- 定义：只记录一项经济业务，或记录同类型经济业务的一次填制完成的凭证
- 示例：验收入库单、领料单、报销单

### 累计凭证
- 定义：多次累计记载连续发生的同类型经济业务，到会计期末才填制完成
- 优势：手续简化，易于管理控制
- 示例：限额领料单、费用登记表

### 汇总原始凭证
- 定义：将一个时期的同类经济业务记录凭证，汇总编制成一张凭证
- 目的：集中反映总体发生情况，简化记账凭证编制
- 示例：现金收入汇总表、发料凭证汇总表

### 记账编制凭证
- 定义：根据账簿记录整理、归类后重新编制的凭证
- 示例：制造费用分配表

## 外来原始凭证特征
- 性质：都是一次凭证
- 来源：一般由税务统一印刷
- 类型：发票、货物运单、银行收账通知单、报销单等
- 强制要求：必须加盖出具凭证单位公章
