# 原始凭证审核

## 使用场景
- 接收到原始凭证，需要进行会计处理或入账
- 需要验证原始凭证是否可作为记账依据
- 需要履行会计机构、会计人员的法定审核职责

## 法定职责
会计机构、会计人员**必须**审核原始凭证，这是法定职责。

## 审核标准
按照国家统一的会计制度的规定进行审核。

## 五维审核流程

### 1. 审核真实性
**检查内容**：
- 经济业务是否真实
- 是否符合国家有关规定要求
- 有无弄虚作假、违反相关法规制度等情况

**具体违规情形**：
- 不实记录
- 多计或者少计收入和费用

**处理**：不可以作为合法真实的原始凭证，按规定处理

### 2. 审核合法性
**检查内容**：
- 经济业务内容是否符合国家政策、法律法规、财务制度和计划的规定
- 成本费用列支的范围、标准是否按规定执行

**具体违规行为**：
- 违反财产纪律
- 贪污盗窃
- 虚报冒领
- 伪造凭证等违法乱纪行为

### 3. 审核合理性
**检查内容**：
- 经济业务是否符合节约资源、反对浪费等有利于提高经济效益的原则

**处理**：违背该原则的，不能作为合理的原始凭证

### 4. 审核完整性
**检查内容**：
- 原始凭证的填写是否完整
- 所需填列的项目是否填写齐全
- 填写的字迹是否清晰可辨

**具体缺失情形**：
- 未填写项目
- 没有经办人员签章
- 无填写接收凭证单位名称
- 业务内容与附件不符

**处理**：不能作为内容完整的原始凭证

### 5. 审核正确性
**检查内容**：
- 凭证填写和计算的数量金额是否存在失误

**具体错误情形**：
- 摘要与数量、金额不相符
- 数量、单价计算有误

**处理**：不能作为正确的原始凭证

## 审核结果处理

### 不真实、不合法凭证
- **判定条件**：原始凭证被认定为"不真实"或"不合法"
- **执行行动**：
  - 有权不予受理
  - 向单位负责人报告
  - 请求查明原因
  - 追究有关当事人的责任

### 记载不准确、不完整凭证
- **判定条件**：原始凭证被认定为"记载不准确"或"不完整"
- **执行行动**：
  - 予以退回
  - 要求经办人员按照国家统一的会计制度的规定进行更正
  - 要求经办人员按照国家统一的会计制度的规定进行补充

### 审核合格凭证
- 经过审核无误的原始凭证
- 才能作为编制记账凭证的依据

## 审核结果模板

**通过**：
```
审核无误 → 编制记账凭证
```

**不通过**：
```
审核有误 → 按规定处理（不予受理/报告追责/退回更正补充）
```
