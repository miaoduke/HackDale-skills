# 成本分配方法参考

## 常用分配标准

### 制造费用分配
1. **生产工时比例法**：按各产品实际生产工时分配
2. **机器工时比例法**：按各产品机器工时分配
3. **生产工人工资比例法**：按各产品生产工人工资分配
4. **直接材料成本比例法**：按各产品直接材料成本分配

### 分配公式
```
分配率 = 待分配费用总额 ÷ 分配标准总额
某产品应分配费用 = 该产品分配标准 × 分配率
```

## 边界情况

### 共同耗用材料
当多种产品共同耗用同一种材料时：
- 如能准确计量，按实际消耗量分配
- 如无法准确计量，按定额消耗量或产品重量分配

### 辅助生产费用
辅助生产车间发生的费用：
- 先归集到"辅助生产成本"
- 再按受益对象分配到"生产成本"、"制造费用"等科目
