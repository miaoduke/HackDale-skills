# 生产成本核算详细示例

## 完整生产周期核算示例

某企业生产A产品，本月发生以下业务：

### 1. 原材料领用
- A产品直接耗用：70,000元
- 车间一般消耗：10,000元

会计分录：
```
借：生产成本——A产品 70,000
借：制造费用 10,000
    贷：原材料——原材料 80,000
```

### 2. 车间日常费用
- 支付车间水电费：5,000元

会计分录：
```
借：制造费用 5,000
    贷：银行存款 5,000
```

### 3. 月末工资分配
- 生产工人工资：80,000元
- 车间管理人员工资：60,000元
- 行政部门人员工资：60,000元
- 工资总额：200,000元

会计分录：
```
借：生产成本 80,000
借：制造费用 60,000
借：管理费用 60,000
    贷：应付工资 200,000
```

### 4. 提取现金备发工资
会计分录：
```
借：现金 200,000
    贷：银行存款 200,000
```

### 5. 实际发放工资
会计分录：
```
借：应付工资 200,000
    贷：现金 200,000
```

### 6. 制造费用分配
假设本月制造费用总额为75,000元（10,000 + 5,000 + 60,000），全部由A产品承担。

会计分录：
```
借：生产成本——A产品 75,000
    贷：制造费用 75,000
```

### 7. 完工产品成本结转
本月A产品全部完工1,000件，总成本为225,000元（70,000 + 80,000 + 75,000）。

会计分录：
```
借：库存产品——A产品 225,000
    贷：生产成本——A产品 225,000
```

## 成本计算说明

A产品单位成本 = 总成本 ÷ 产量 = 225,000 ÷ 1,000 = 225元/件
