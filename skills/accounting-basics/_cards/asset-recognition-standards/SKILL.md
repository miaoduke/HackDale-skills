# 资产确认标准

## 使用场景
当存在潜在资源，需要判断其是否应确认为资产时使用。

## 确认流程

### 第一步：定义检查
确认该对象是否满足以下条件：
- 由"过去的交易或者事项"形成
- 由企业"拥有或者控制"

### 第二步：特征检查

#### 拥有或控制
- 企业拥有所有权，或者
- 虽不拥有所有权但实际控制了该资源（如融资租入固定资产）

#### 预期经济利益
- 该资源必须具有直接或间接导致现金和现金等价物流入企业的潜力

### 第三步：确认条件检查
必须同时满足以下两个条件：

#### 经济利益流入可能性
- 与该资源有关的经济利益很可能（通常指概率大于50%）流入企业

#### 成本或价值计量
- 该资源的成本或者价值能够可靠地计量

### 第四步：判定结论
```
IF (满足定义 AND 满足特征 AND 满足确认条件)
THEN 在资产负债表中确认为资产
ELSE 不确认为资产，或在附注中披露
```

## 排除情况
- 无法可靠计量成本
- 经济利益流入不确定
- 未来交易或事项形成的资源

## 常见资产类型
- 货币资金
- 应收账款
- 存货
- 固定资产
- 无形资产
- 长期股权投资
