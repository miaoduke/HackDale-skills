# 盈利现金比率分析

## 使用场景
当需要评估企业以下方面时使用此技能：
- 盈利质量优劣
- 现金回收能力
- 应收账款回收状况
- 现金周转是否正常

## 执行步骤

### 1. 获取基础数据
从现金流量表和利润表中提取：
- **现金流入总量**：经营活动现金流入总额
- **现金流出总量**：经营活动现金流出总额
- **净利润**：企业一定时期的净利润

**约束条件**：净利润为0时无法计算

### 2. 计算经营现金净流量
```
经营现金净流量 = 现金流入总量 - 现金流出总量
```

### 3. 计算盈利现金比率
```
盈利现金比率 = (经营现金净流量 ÷ 净利润) × 100%
```

### 4. 评估盈利质量

| 比率水平 | 含义 |
|---------|------|
| 比率越大 | 盈利质量越好 |
| 比率越小 | 现金收入较小或没有回收的应收账款过多，现金流入量较少，可能出现现金周转不灵 |

### 5. 判断标准
一般情况下，该比率 **大于100%** 为宜。

## 输出结果
返回盈利现金比率百分比数值，用于判断盈利质量优劣。
