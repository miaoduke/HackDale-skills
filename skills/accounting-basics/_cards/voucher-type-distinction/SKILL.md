# 原始凭证与记账凭证的区别

## 使用场景
- 需要识别凭证类型
- 需要理解会计凭证体系
- 需要区分不同凭证的填制责任
- 需要明确凭证的用途和依据关系

## 四维度区分法

### 1. 填制人员区别

| 凭证类型 | 填制人员 |
|----------|----------|
| 原始凭证 | 经济业务发生时的经办人员 |
| 记账凭证 | 会计人员 |

### 2. 填制时间与依据区别

| 凭证类型 | 填制时间 | 依据 |
|----------|----------|------|
| 原始凭证 | 经济业务发生或完成时 | 经济业务实际发生 |
| 记账凭证 | 原始凭证审核无误后 | 审核无误的原始凭证 |

### 3. 内容与性质区别

| 凭证类型 | 内容特点 |
|----------|----------|
| 原始凭证 | 对经济业务的发生或完成加以记录 |
| 记账凭证 | 根据会计科目分类，对经济业务进行整理和归类 |

### 4. 用途（作为依据的对象）区别

| 凭证类型 | 用途 |
|----------|------|
| 原始凭证 | 作为填制记账凭证的依据 |
| 记账凭证 | 作为登记会计账簿的依据 |

## 流程关系
```
经济业务发生 → 原始凭证 → 记账凭证 → 会计账簿
```

## 判定模板
根据填制人、时间、内容及用途四个维度准确区分原始凭证与记账凭证。
