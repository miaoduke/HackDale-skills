# 现金流量表编制

## 适用场景
- 需要编制特定会计期间的现金流量表
- 需要计算各分类的现金流量净额
- 需要汇总经营、投资、筹资活动的现金流入流出

## 前置条件
- 会计期间内的经营活动数据
- 会计期间内的投资活动数据
- 会计期间内的筹资活动数据

## 编制步骤

### 第一步：经营活动产生的现金流量计算

**现金流入小计计算**：
```
现金流入小计 = 销售商品、提供劳务收到的现金 + 收到的税费返还 + 收到其他与经营活动有关的现金
```

**现金流出小计计算**：
```
现金流出小计 = 购买商品、接受劳务支付的现金 + 支付给职工以及为职工支付的现金 + 支付的各项税费 + 支付其他与经营活动有关的现金
```

**经营活动现金流量净额计算**：
```
经营活动现金流量净额 = 经营活动现金流入小计 - 经营活动现金流出小计
```

### 第二步：投资活动产生的现金流量计算

**现金流入小计计算**：
```
现金流入小计 = 收回投资收到的现金 + 取得投资收益收到的现金 + 处置固定资产等收回的现金净额 + 处置子公司等收到的现金净额 + 收到其他与投资活动有关的现金
```

**现金流出小计计算**：
```
现金流出小计 = 购建固定资产等支付的现金 + 投资支付的现金 + 取得子公司等支付的现金净额 + 支付其他与投资活动有关的现金
```

**投资活动现金流量净额计算**：
```
投资活动现金流量净额 = 投资活动现金流入小计 - 投资活动现金流出小计
```

### 第三步：筹资活动产生的现金流量计算

**现金流入小计计算**：
```
现金流入小计 = 吸收投资收到的现金 + 取得借款收到的现金 + 收到其他与筹资活动有关的现金
```

**现金流出小计计算**：
```
现金流出小计 = 偿还债务支付的现金 + 分配股利、利润或偿付利息支付的现金 + 支付其他与筹资活动有关的现金
```

**筹资活动现金流量净额计算**：
```
筹资活动现金流量净额 = 筹资活动现金流入小计 - 筹资活动现金流出小计
```

## 输出结果
输出各分类（经营、投资、筹资）的：
- 现金流入小计
- 现金流出小计
- 现金流量净额
