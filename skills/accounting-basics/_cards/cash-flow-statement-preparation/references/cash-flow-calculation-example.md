# 现金流量表编制示例

## 示例数据（北京芳芳水果超市 2011年1月）

### 经营活动
- 销售商品、提供劳务收到的现金：120,000元
- 收到的税费返还：5,000元
- 收到其他与经营活动有关的现金：200元
- 购买商品、接受劳务支付的现金：60,200元
- 支付给职工以及为职工支付的现金：11,000元
- 支付的各项税费：20,200元
- 支付其他与经营活动有关的现金：2,000元

**计算结果**：
- 现金流入小计 = 120,000 + 5,000 + 200 = 125,200元
- 现金流出小计 = 60,200 + 11,000 + 20,200 + 2,000 = 95,200元
- 经营活动现金流量净额 = 125,200 - 95,200 = 30,000元

### 投资活动
- 收回投资收到的现金：10,000元
- 取得投资收益收到的现金：2,000元
- 购建固定资产等支付的现金：20,000元
- 投资支付的现金：10,000元

**计算结果**：
- 现金流入小计 = 10,000 + 2,000 = 12,000元
- 现金流出小计 = 20,000 + 10,000 = 30,000元
- 投资活动现金流量净额 = 12,000 - 30,000 = -18,000元

### 筹资活动
- 吸收投资收到的现金：10,000元
- 偿还债务支付的现金：20,000元
- 分配股利、利润或偿付利息支付的现金：3,200元

**计算结果**：
- 现金流入小计 = 10,000元
- 现金流出小计 = 20,000 + 3,200 = 23,200元
- 筹资活动现金流量净额 = 10,000 - 23,200 = -13,200元
