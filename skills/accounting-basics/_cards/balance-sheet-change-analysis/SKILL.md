# 资产负债表变动分析

## 使用场景
当需要执行以下分析任务时使用本技能：
- 评估企业财务状况的变化趋势
- 分析资产负债表项目的增减变动
- 计算项目的绝对变化量和相对变化幅度
- 识别异常波动并分析原因

## 核心计算流程

### 1. 确定分析对象

从资产负债表中选取需要分析的财务项目：
- **非流动资产**：发放贷款及垫款、固定资产、在建工程等
- **非流动负债**：长期借款、应付债券等
- **所有者权益**：未分配利润、少数股东权益等
- **流动负债**：短期借款、应付账款等

### 2. 获取基础数据

提取以下数据：
- **期初余额**：报告年度开始时的账户金额（如年初金额）
- **期末余额**：报告年度结束时的账户金额（如年末金额）

**约束条件**：
- 期初余额不能为零（否则无法计算增减幅度）
- 需保持货币单位一致

### 3. 计算增减金额

**标准公式**：
```
增减金额 = 期末余额 - 期初余额
```

**结果说明**：
- 正数：表示增加
- 负数：表示减少

### 4. 计算增减幅度

**标准公式**：
```
增减幅度 = (增减金额 / 期初余额) × 100%
```

**结果说明**：
- 正百分比：表示增长幅度
- 负百分比：表示下降幅度
- 该指标用于量化变化的相对比例

### 5. 数据校验与分析

**校验步骤**：
1. 检查计算结果是否符合会计恒等式逻辑
2. 关注异常波动（如变动幅度超过30%的项目）
3. 结合财务报表附注分析变动原因

## 分析要点

### 资产项目分析
- 关注非流动资产的大额变动，反映企业投资策略变化
- 在建工程大幅增加可能预示未来产能扩张

### 负债项目分析
- 长期借款减少可能反映企业去杠杆策略
- 应付债券变动反映融资结构调整

### 权益项目分析
- 未分配利润变动反映盈利积累情况
- 少数股东权益变动反映子公司权益变化

## 输出格式

```
项目[名称]本期增减金额为[金额]元，增减幅度为[百分比]%
```

## 注意事项
- 计算时保持货币单位一致（通常为元）
- 期初余额为零的项目无法计算变动幅度
- 异常波动需结合附注深入分析原因
- 变动幅度应与增减金额结合分析，避免片面判断
