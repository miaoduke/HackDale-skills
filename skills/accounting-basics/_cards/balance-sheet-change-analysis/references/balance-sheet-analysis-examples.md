# 资产负债表变动分析示例

## 示例数据
| 项目 | 期初余额（万元） | 期末余额（万元） |
|------|------------------|------------------|
| 发放贷款及垫款 | 169,231.87 | 144,840.79 |
| 长期借款 | 12,119.75 | 10,009.69 |
| 在建工程 | 5,678.32 | 7,806.45 |
| 未分配利润 | 23,456.78 | 28,901.23 |

## 计算过程

### 1. 发放贷款及垫款
```
增减金额 = 144,840.79 - 169,231.87 = -24,391.08万元
增减幅度 = (-24,391.08 / 169,231.87) × 100% = -14.41%
```
**分析**：发放贷款及垫款减少14.41%，可能反映资产结构调整或风险控制策略。

### 2. 长期借款
```
增减金额 = 10,009.69 - 12,119.75 = -2,110.06万元
增减幅度 = (-2,110.06 / 12,119.75) × 100% = -17.41%
```
**分析**：长期借款下降17.41%，企业可能正在降低杠杆水平。

### 3. 在建工程
```
增减金额 = 7,806.45 - 5,678.32 = 2,128.13万元
增减幅度 = (2,128.13 / 5,678.32) × 100% = 37.49%
```
**分析**：在建工程大幅增长37.49%，需关注附注了解具体投资项目。

### 4. 未分配利润
```
增减金额 = 28,901.23 - 23,456.78 = 5,444.45万元
增减幅度 = (5,444.45 / 23,456.78) × 100% = 23.21%
```
**分析**：未分配利润增长23.21%，反映企业盈利能力良好。
