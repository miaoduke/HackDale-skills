## 银行存款余额调节表编制示例

### 案例：2010年8月31日

**已知条件：**
- 企业银行存款日记账余额：20,800元
- 银行对账单余额：24,400元

**经查发现未达账项：**
1. 银行已收企业未收款项：银行代收货款6,000元，企业未收到通知
2. 银行已付企业未付款项：银行代付电费1,200元，企业未收到通知
3. 企业已收银行未收款项：企业送存转账支票3,000元，银行尚未收妥
4. 企业已付银行未付款项：企业开出转账支票2,000元，持票人尚未到银行办理

**编制调节表：**

| 项目 | 金额 |
|------|------|
| 企业银行存款日记账余额 | 20,800 |
| 加：银行已收企业未收 | +6,000 |
| 减：银行已付企业未付 | -1,200 |
| **调节后余额** | **25,600** |
| | |
| 银行对账单余额 | 24,400 |
| 加：企业已收银行未收 | +3,000 |
| 减：企业已付银行未付 | -2,000 |
| **调节后余额** | **25,600** |

**结论：** 调节后双方余额相等，说明记账一般没有错误。
