# 总分类账登记

## 适用场景
- 需要在总分类账中登记经济业务
- 需要记录借方或贷方发生额
- 需要计算并记录账户余额

## 核心流程

### 1. 设置账页基础信息
1. 确认需要登记的会计科目
2. 在账页顶部的"科目名称：___"横线处填写具体的会计科目名称
3. 确保科目名称与会计制度规定的名称一致

### 2. 记录业务发生日期
在表格左侧的日期列填写：
- "年"栏目：填写业务发生的年份
- "月"栏目：填写业务发生的月份
- "日"栏目：填写业务发生的日期

### 3. 登记凭证编号
1. 定位到日期列右侧的"凭证编号"栏目
2. 查阅该笔业务对应的记账凭证
3. 将凭证上的编号填入该栏目

### 4. 填写借方金额
1. 定位到"摘要"右侧的"借方"区域
2. 识别7个金额子栏目：万、千、百、十、元、角、分
3. 将借方发生额的数字按位填入对应的栏目中
4. 无该位金额时，该栏留空或填零

### 5. 填写贷方金额
1. 定位到"借方"右侧的"贷方"区域
2. 识别7个金额子栏目：万、千、百、十、元、角、分
3. 将贷方发生额的数字按位填入对应的栏目中
4. 确保数字对齐，分位不差

### 6. 记录余额方向与金额
1. 定位到"贷方"右侧的"借或贷"栏目
2. 根据账户性质和计算结果，填写"借"字或"贷"字，标明余额方向
3. 定位到最右侧的"余额"区域
4. 将计算出的余额数字按位填入对应的栏目中
5. 确保余额金额与方向栏的指示一致
