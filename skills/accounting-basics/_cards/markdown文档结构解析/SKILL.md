# Markdown文档结构解析

## 使用场景
- 文档包含以 `#` 开头的标题行
- 需要识别章节层级和标题内容
- 处理仅包含标题而无正文内容的章节
- 需要提取文档元数据（ID、路径等）

## 执行步骤

### 1. 识别标题层级
- 检测文本行开头的井号（`#`）数量
- `#` = 一级标题（H1）
- `##` = 二级标题（H2）
- `###` = 三级标题（H3），以此类推
- 确认井号后必须跟随一个空格

### 2. 提取标题内容
- 移除标题前缀（如 `## `）
- 提取剩余文本作为标题名称
- 示例：`## More` → 标题层级：2，标题内容：`More`

### 3. 解析章节元数据
- 提取文本块的唯一标识符（chunk_id）
- 识别父级路径（parent_path）
- 确定章节在文档树中的位置

### 4. 评估内容状态
- 检查文本块是否包含正文内容
- 标识空章节（仅包含标题和元数据）
- 区分结构定义与技术内容

## 输出格式
```json
{
  "heading_level": 2,
  "title": "More",
  "has_body": false,
  "metadata": {
    "chunk_id": "chunk_0248",
    "parent_path": "Root"
  }
}
```

## 注意事项
- 仅适用于Markdown格式的标题
- 不适用于HTML或其他标记语言
- 空章节不包含具体技术规则或程序内容
