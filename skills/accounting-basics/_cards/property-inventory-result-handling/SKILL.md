# 财产清查结果处理

## 使用场景
当企业完成财产清查，发现以下情况时使用本技能：
- 库存现金溢余或短缺
- 实物资产（存货、固定资产等）盘盈或盘亏
- 往来款项账实不符
- 财产物资积压

## 核心流程

### 1. 差异确认阶段

**触发条件**：财产清查发现账实不符

**执行步骤**：
1. 分析产生差异的原因和性质
2. 取得清查原始凭证
3. 编制初始确认分录，将差异转入"待处理财产损溢"
4. 及时调整账簿记录，保证账实相符

### 2. 现金溢余处理

**初始确认**：
```
借：库存现金
    贷：待处理财产损溢——待处理流动资产损溢
```

**查明原因后处理**：
- **应支付给有关人员或单位**：
  - 借：待处理财产损溢——待处理流动资产损溢
  - 贷：其他应付款——应付现金溢余（××）
- **无法查明原因**（需经批准）：
  - 借：待处理财产损溢——待处理流动资产损溢
  - 贷：营业外收入

### 3. 现金短缺处理

**初始确认**：
```
借：待处理财产损溢——待处理流动资产损溢
    贷：库存现金
```

**查明原因后处理**：
- **个人原因造成**：由个人赔偿
  - 借：其他应收款——××人
  - 贷：待处理财产损溢——待处理流动资产损溢
- **管理不善造成**：计入管理费用
  - 借：管理费用
  - 贷：待处理财产损溢——待处理流动资产损溢
- **自然灾害造成**：计入营业外支出
  - 借：营业外支出
  - 贷：待处理财产损溢——待处理流动资产损溢

### 4. 实物资产差异处理

**损失处理分类**：
- 个人造成的损失：由个人进行赔偿
- 管理不善原因造成的损失：作为企业"管理费用"入账
- 自然灾害造成的非常损失：列入企业的"营业外支出"

**执行步骤**：
1. 根据差异原因执行相应的财务处理规则
2. 根据清查中取得的原始凭证编制记账凭证
3. 登记有关账簿，确保账存数与实存数一致

### 5. 后续管理优化

**执行步骤**：
1. 积极处理多余积压的财产物资
2. 清理往来款项
3. 总结经验教训，建立健全各项管理制度

## 关键科目
- **待处理财产损溢**：用于核算财产清查中发现的盘盈盘亏
- **管理费用**：管理不善造成的损失
- **营业外支出**：自然灾害造成的非常损失
- **其他应收款**：个人赔偿款
- **其他应付款**：应支付给有关人员的款项
- **营业外收入**：无法查明原因的现金溢余

## 注意事项
- 必须明确区分损失的具体原因（个人/管理/自然灾害）
- 所有处理必须基于取得的清查原始凭证
- 待处理财产损溢科目应及时清理，不得长期挂账
- 现金溢余无法查明原因时，必须经批准后才能计入营业外收入
