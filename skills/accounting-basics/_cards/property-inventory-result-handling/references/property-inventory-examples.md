# 财产清查处理示例

## 示例1：现金溢余
库存现金清查发现溢余500元。

**初始确认**：
```
借：库存现金 500
    贷：待处理财产损溢——待处理流动资产损溢 500
```

**查明原因**：属于少支付给某职工的差旅费
```
借：待处理财产损溢——待处理流动资产损溢 500
    贷：其他应付款——应付现金溢余（张三） 500
```

**若无法查明原因**：
```
借：待处理财产损溢——待处理流动资产损溢 500
    贷：营业外收入 500
```

## 示例2：现金短缺
库存现金清查发现短缺300元。

**初始确认**：
```
借：待处理财产损溢——待处理流动资产损溢 300
    贷：库存现金 300
```

**查明原因**：出纳员责任
```
借：其他应收款——出纳员 300
    贷：待处理财产损溢——待处理流动资产损溢 300
```

## 示例3：存货盘亏
原材料盘亏2000元，查明原因：管理不善造成。

**初始确认**：
```
借：待处理财产损溢——待处理流动资产损溢 2000
    贷：原材料 2000
```

**批准后处理**：
```
借：管理费用 2000
    贷：待处理财产损溢——待处理流动资产损溢 2000
```
