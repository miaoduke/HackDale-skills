# 企业偿债能力分析

## 使用场景
当以下情况时应用此技能：
- 评估企业财务健康状况
- 分析企业债务风险
- 进行信贷决策
- 投资者评估投资风险
- 企业内部财务诊断

## 偿债能力分类

### 短期偿债能力
- **定义**：企业以流动资产偿还流动负债的能力
- **核心要素**：关注"流动资产"与"流动负债"的匹配关系

### 长期偿债能力
- **定义**：企业偿还长期负债的本金和利息的能力
- **核心要素**：关注"长期负债"的"本金"及"利息"的偿付保障

## 流动比率分析

### 计算公式
```
流动比率 = 流动资产 / 流动负债
```

### 判断标准

#### 高于200%
- **判定结果**：偿还能力较好
- **财务状况**：财务状况良好

#### 低于200%
- **判定结果**：资金周转不畅
- **财务状况**：偿还债务能力弱

#### 特殊警示（过高风险）
- **注意事项**：流动比率也并非越高越好
- **风险分析**：
  - 可能意味着企业的短期资金利用率不高
  - 表明资金闲置或未能有效投入运营

## 执行步骤

1. **获取财务数据**：收集资产负债表中的流动资产和流动负债数据
2. **计算流动比率**：流动资产 / 流动负债
3. **基准比较**：将计算结果与200%阈值进行比较
4. **评估偿债能力**：
   - 判断短期偿债能力（流动比率）
   - 判断长期偿债能力（需结合其他指标）
5. **综合分析**：
   - 结合行业背景综合判断
   - 注意单一指标不能完全代表企业状况
6. **识别风险**：
   - 过低：偿债风险
   - 过高：资金利用率低

## 注意事项
- 单一指标不能完全代表企业状况
- 需结合行业背景综合判断
- 流动比率过高可能意味着资金利用率低
- 需同时评估短期和长期偿债能力
- 持续经营假设是分析前提
