# 日记账登记方法

## 银行存款日记账登记

### 账簿设置
- 按企业在银行开立的账户和币种分别设置
- 每个银行账户设置一本日记账

### 登记依据
- 银行存款收款凭证
- 银行存款付款凭证
- 部分现金付款凭证（将现金存入银行）

### 登记方法
- 按经济业务发生的时间先后顺序，逐日逐笔进行登记
- 格式和登记方法与现金日记账相同

## 现金日记账登记

### 执行人员
出纳人员

### 登记依据
根据同现金收付有关的记账凭证

### 登记顺序
按时间顺序逐日逐笔进行登记

### 余额结算公式
```
本日余额 = 上日余额 + 本日收入 - 本日支出
```

### 核对要求
- 逐日结出现金余额
- 结算出当日余额并与库存现金的实存数核对
- 检查每日现金的支出和收入有无误差

## 多栏式现金日记账登记

### 收入登记
根据有关现金收入业务的记账凭证登记现金收入日记账

### 支出登记
根据有关现金支出业务的记账凭证登记现金支出日记账

### 每日结转
1. 每日营业终了，根据现金支出日记账统计的支出合计数
2. 一笔转入现金收入日记账的"支出合计"栏中
3. 结出当日余额

## 普通日记账登记

### 格式特征
一般只设借方和贷方两个金额栏，称为两栏式日记账

### 操作步骤
将每天发生的经济业务逐笔登记在借方和贷方，用以反映经济业务情况

### 注意事项
- 不便于分工记账
- 不便于对经济业务加以分类归集
- 记账的工作量大
