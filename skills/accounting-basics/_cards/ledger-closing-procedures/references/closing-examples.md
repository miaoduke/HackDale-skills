# 结账操作详细示例

## 月结示例

某企业银行存款日记账本月发生额如下：
- 借方发生额合计：500,000元
- 贷方发生额合计：300,000元
- 月末余额：200,000元

操作步骤：
1. 在本月最后一笔记录下面划一条通栏单红线
2. 在红线下方摘要栏注明"本月合计"
3. 在借方栏填写500,000，贷方栏填写300,000，余额栏填写200,000
4. 在借贷栏注明"借"方向
5. 在这一行下面再划一条通栏红线

## 年结示例

某企业应收账款账户年末情况：
- 年初余额：100,000元（借方）
- 本年借方发生额合计：800,000元
- 本年贷方发生额合计：600,000元
- 年末余额：300,000元（借方）

操作步骤：
1. 12月份月结：划单红线，注明"本月合计"
2. 第四季度季结：在月结下一行，注明"本季合计"，划单红线
3. 年度合计：在季结下一行，填写本年发生额和年末余额，注明"本年合计"
4. 结转下年：在下一行填写"年初余额"100,000元，再下一行填写"结转下年"300,000元
5. 封账：划通栏双红线
