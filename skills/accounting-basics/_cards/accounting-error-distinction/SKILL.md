# 会计误差与错账的区别

## 使用场景
当识别到账目记录存在问题，需要判断问题性质及决定后续处理方式时使用。

## 概念区分

### 错账
- **特性1**：是可以被发现的
- **特性2**：是可以被更正的
- **处理方式**：执行发现并更正的程序

### 会计误差
- **特性1**：即使被发现
- **特性2**：也是无法更正的
- **处理方式**：即使发现也不执行更正程序

## 判定流程

1. **识别问题类型**：确定账目问题是"错账"还是"会计误差"

2. **应用处理原则**：
```
IF (问题类型 = 错账)
THEN 执行发现并更正的程序
ELSE IF (问题类型 = 会计误差)
THEN 即使发现也不执行更正程序
```

## 核心结论
- 会计误差和错账是两回事，必须严格区分
- 区分的关键在于"可更正性"
- 正确分类决定了后续的处理方式

## 注意事项
- 不要将两者混淆，否则会导致错误的处理方式
- 会计误差通常涉及无法追溯调整的历史记录
- 错账通常是由于记录过程中的疏忽或计算错误
