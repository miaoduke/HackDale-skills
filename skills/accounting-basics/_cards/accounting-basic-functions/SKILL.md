# 会计基本职能

## 使用场景
- 开展会计工作，需要理解会计的核心职能
- 对企业经济业务活动进行记录、核算和编制报告
- 对企业经济活动过程进行合法监督
- 依据我国会计法执行会计相关业务

## 执行步骤

### 1. 确认基本职能构成
依据我国会计法，会计的基本职能包含两个核心部分：
- **会计核算**：会计工作的基本内容
- **会计监督**：贯穿于核算过程中的控制职能

### 2. 执行会计核算
对企业发生的经济业务活动进行以下操作：
- 记录经济业务
- 进行会计核算
- 编制会计报告

### 3. 执行会计监督
监督过程必须以国家的财经法规、政策以及会计信息为依据，具体内容包括：
- 审查会计核算资料的真实合法性
- 检查是否违反国家相关法律法规
- 评价企业经营成果
- 协助调整企业计划
- 协调企业与税务机关之间的关系

### 4. 达成管理目标
最终目的是提高企业的经营管理水平和经营效益。

## 关键要点
- 会计核算的过程其实也是会计监督的过程
- 监督必须依据国家财经法规和政策
- 监督对象是企业经济活动的过程

## 输出结果
- 合法性评价
- 经营成果评估
- 计划调整建议
- 税务关系协调
