# 资金周转效率指标

## 周转率指标

### 存货周转率
```
存货周转率 = 营业成本 ÷ 平均存货余额
存货周转天数 = 365 ÷ 存货周转率
```

### 应收账款周转率
```
应收账款周转率 = 营业收入 ÷ 平均应收账款余额
应收账款周转天数 = 365 ÷ 应收账款周转率
```

### 总资产周转率
```
总资产周转率 = 营业收入 ÷ 平均资产总额
```

## 现金周转期
```
现金周转期 = 存货周转天数 + 应收账款周转天数 - 应付账款周转天数
```

## 效率提升策略

### 缩短生产周期
- 优化生产流程
- 提高生产效率
- 减少在产品库存

### 加速应收账款回收
- 优化信用政策
- 加强应收账款管理
- 提供早付款折扣

### 延长应付账款付款期
- 与供应商协商付款条件
- 合理利用商业信用
