# 投入资本核算示例

## 示例1：非股份公司

### 场景
甲公司为非股份公司，注册资本1000万元。投资者A投入资金300万元，占注册资本的20%。

### 计算
- 注册资本份额 = 1000万 × 20% = 200万
- 资本溢价 = 300万 - 200万 = 100万

### 会计分录
```
借：银行存款 3,000,000
    贷：实收资本——投资者A 2,000,000
        资本公积——资本溢价 1,000,000
```

## 示例2：股份公司

### 场景
乙股份有限公司发行股票，每股面值1元，发行价格5元，共发行100万股。

### 计算
- 股本（注册资本份额） = 1元 × 100万股 = 100万
- 股本溢价 = (5元 - 1元) × 100万股 = 400万

### 会计分录
```
借：银行存款 5,000,000
    贷：股本 1,000,000
        资本公积——股本溢价 4,000,000
```

## 注意事项

1. 实收资本/股本反映投资者在企业注册资本中所占的份额
2. 资本公积反映投资者投入资金中超过注册资本份额的部分
3. 资本公积可以用于转增资本，但不能用于弥补亏损
4. 不同投资者的投入应分别核算
