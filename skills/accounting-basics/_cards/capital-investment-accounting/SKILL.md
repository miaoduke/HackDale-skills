# 投入资本与资本溢价核算规则

## 使用场景
当企业收到投资者投入的资金时，根据企业类型及金额与注册资本份额的关系进行分类核算。

## 前置条件

- 企业收到投资者投入的资金

## 约束条件

- 不适用于减资或股份回购场景

## 核算流程

### 1. 确定主要核算科目

根据企业类型选择科目：
- **非股份公司**：投入的资本通过"实收资本"科目核算
- **股份公司**：投入的资本通过"股本"科目核算

### 2. 处理超出注册资本份额的资金

计算投资者投入资金中超过其在注册资本所占份额的部分：
- 超出部分**不记入**"实收资本"或"股本"科目
- 超出部分作为"资本溢价"（非股份公司）或"股本溢价"（股份公司）
- 必须在"资本公积"科目中核算该部分金额

## 会计分录示例

### 非股份公司
```
借：银行存款
    贷：实收资本（注册资本份额）
        资本公积——资本溢价（超出部分）
```

### 股份公司
```
借：银行存款
    贷：股本（注册资本份额）
        资本公积——股本溢价（超出部分）
```

## 输出结果

将注册资本份额记入'实收资本'或'股本'，将超额部分记入'资本公积'。
