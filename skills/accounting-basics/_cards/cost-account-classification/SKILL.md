# 成本类科目分类标准

## 使用场景
当需要确认会计科目类别或查询成本类科目清单时，应用此分类标准。

## 成本类科目定义

成本类科目主要用于核算企业生产产品、提供劳务、研发及工程施工过程中发生的各项成本。

## 标准成本类科目清单

| 科目编号 | 科目名称 |
|---------|---------|
| 5001 | 生产成本 |
| 5101 | 制造费用 |
| 5201 | 劳务成本 |
| 5301 | 研发支出 |
| 5401 | 工程施工 |
| 5402 | 工程结算 |
| 5403 | 机械作业 |

## 识别流程

1. **定义识别**：确认科目性质，判断是否用于核算生产、劳务、研发或工程施工成本
2. **科目清单匹配**：依据科目编号与名称核对上述标准清单
3. **分类执行**：将匹配的科目统一归入"成本类"进行管理

## 约束条件

- 不包含损益类科目
- 不包含资产类科目（除非特定转结情况）

## 输出结果

该科目属于成本类科目，具体为：[科目名称] (编号: [科目编号])
