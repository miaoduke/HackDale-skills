# 科目汇总表示例模板

## 表格结构

| 科目编码 | 会计科目 | 借方金额 | 贷方金额 |
|---------|---------|---------|---------|
| 1001    | 库存现金 | 5,000.00 | 3,000.00 |
| 1002    | 银行存款 | 50,000.00 | 25,000.00 |
| ...     | ...     | ...     | ...     |
| **合计** | **总计** | **77,000.00** | **77,000.00** |

## 表头信息示例

- 汇总期间：2009年5月1日至10日
- 记账凭证：第××号至第××号
- 单位：元
- 制表：张三

## 编制要点
1. 科目排列顺序应与总分类账一致
2. 借方合计必须等于贷方合计
3. 无发生额的科目用"—"表示
4. 制表人需在表格底部签名
