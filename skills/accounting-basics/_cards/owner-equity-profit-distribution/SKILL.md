# 所有者权益与利润分配核算

## 适用场景
当企业需要处理以下业务时使用此技能：
- 从净利润中提取盈余公积（法定盈余公积、法定公益金）
- 使用盈余公积转增资本金或弥补亏损
- 进行利润分配核算
- 确认历年未分配利润或未弥补亏损余额

## 盈余公积账户核算

### 账户性质
盈余公积属于"所有者权益账户"，用于核算和监督企业从净利润中提取的盈余公积的增减变动情况。

### 借贷方登记规则
- **借方（减少）**：登记盈余公积的减少数
  - 转增资本金
  - 弥补亏损
  
- **贷方（增加）**：登记盈余公积的提取数
  - 从净利润中提取的法定盈余公积
  - 从净利润中提取的法定公益金

### 期末余额
- 余额方向：贷方
- 余额含义：反映企业提取的盈余公积的余额

## 利润分配账户核算

### 账户性质
利润分配账户属于"所有者权益账户"，用于核算和监督企业利润的分配（或亏损的弥补）和历年分配（或弥补）后的余额。

### 借方登记逻辑
登记企业分配给投资者的利润、亏损或弥补亏损等情况：
- "年初余额"：记录年初未弥补亏损
- "本期减少额"：记录本年度已分配利润
  - 已提取法定盈余公积
  - 已提取法定公益金
  - 已向股东分派股利

### 贷方登记逻辑
登记企业当期实现的净利润：
- "年初余额"：记录年初未分配利润
- "本期增加额"：记录年末转入的本年实现的净利润

### 期末余额判定
- **借方余额**：表示企业"累计的未弥补亏损"
- **贷方余额**：表示企业"累计的未分配利润"

## 执行步骤

1. 确认账户性质（所有者权益类）
2. 根据业务类型选择账户：
   - 提取/使用盈余公积 → 盈余公积账户
   - 利润分配/亏损弥补 → 利润分配账户
3. 按借贷方规则登记相应金额
4. 确定期末余额方向和含义
