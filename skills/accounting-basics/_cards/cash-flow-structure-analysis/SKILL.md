# 现金流量结构分析

## 适用场景
- 需要判断企业经营状况和赚钱能力
- 需要规划预测未来发展能力
- 需要评估企业现金流量结构的健康程度
- 需要评估投入产出效率

## 前置条件
- 经营活动现金流入及流出数据
- 投资活动现金流入及流出数据
- 筹资活动现金流入及流出数据

## 分析步骤

### 第一步：计算现金流入结构
计算各类活动现金流入占总现金流入的比重：
```
经营活动流入占比 = 经营活动现金流入 / 现金总流入 × 100%
投资活动流入占比 = 投资活动现金流入 / 现金总流入 × 100%
筹资活动流入占比 = 筹资活动现金流入 / 现金总流入 × 100%
```

### 第二步：计算现金流出结构
计算各类活动现金流出占总现金流出的比重：
```
经营活动流出占比 = 经营活动现金流出 / 现金总流出 × 100%
投资活动流出占比 = 投资活动现金流出 / 现金总流出 × 100%
筹资活动流出占比 = 筹资活动现金流出 / 现金总流出 × 100%
```

### 第三步：评估现金流量健康度

**经营活动结构分析**：
- 计算经营活动现金流出占现金流出总量的比例
- 判断标准：若该比例占主导地位（如达到64%以上），说明企业现金收入大部分来自经营活动所得，现金支出大部分用于经营费用
- 结论：表明企业现金流量结构比较良好

**投资与筹资活动效率分析**：
- 对比投资活动和筹资活动的现金流出与现金流入金额
- 警示阈值：如果投资活动和筹资活动的现金流出是现金流入的2倍以上
- 结论：表示企业本期的投资和筹资活动的投入产出率比较低下

### 第四步：综合评估
结合经营活动占比和投资筹资活动效率：
- 若经营活动占比高且投资筹资活动未出现严重倒挂（流出远超流入），则整体结构健康
- 若投资筹资流出过高，需关注其效率问题

## 分析目的
通过分析现金收支构成，判断和评价：
- 企业经营状况
- 企业赚钱能力
- 企业未来发展能力

## 经营性现金流量解读规则
- **比率越大**：说明企业从日常经营活动中获取现金的能力越强
- **比率越小**：表示企业资金的来源主要是通过对外投资和筹资而来
