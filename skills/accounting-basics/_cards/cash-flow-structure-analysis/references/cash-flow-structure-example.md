# 现金流量结构分析示例

## 示例数据（2010年10月）

### 现金流入结构
- 经营活动流入：125,200元（占比85.05%）
- 投资活动流入：12,000元（占比8.15%）
- 筹资活动流入：10,000元（占比6.8%）
- 合计流入：147,200元

### 现金流出结构
- 经营活动流出：95,200元（占比64.15%）
- 投资活动流出：30,000元（占比20.22%）
- 筹资活动流出：23,200元（占比15.63%）
- 合计流出：148,400元

## 结构特征分析

### 现金流入分析
- 经营活动占据主导地位（85.05%）
- 说明企业现金收入主要来自主营业务

### 现金流出分析
- 经营活动同样占据最大份额（64.15%）
- 说明企业现金支出主要用于经营费用

### 健康度评估
- 经营活动现金流出占比64.15%，占主导地位
- 结论：企业现金流量结构比较良好

### 投资筹资效率分析
- 投资活动：流出30,000元，流入12,000元，流出是流入的2.5倍
- 筹资活动：流出23,200元，流入10,000元，流出是流入的2.32倍
- 结论：投资和筹资活动的投入产出率比较低下
