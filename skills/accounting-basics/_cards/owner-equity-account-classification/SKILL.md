# 所有者权益类科目分类

## 适用场景
当遇到以下情况时使用此技能：
- 需要确认某个会计科目是否属于所有者权益类
- 需要查询所有者权益类科目的完整列表
- 需要根据科目编号或名称进行科目归类
- 处理财务报表中所有者权益相关项目

## 执行步骤

### 1. 确认科目类别
检查目标科目是否属于所有者权益类科目。所有者权益类科目包括：
- 实收资本
- 资本公积
- 盈余公积
- 一般风险准备（金融共用）
- 本年利润
- 利润分配
- 库存股

### 2. 编号匹配验证
根据科目编号进行精确匹配：

| 科目编号 | 科目名称 |
|---------|---------|
| 4001 | 实收资本 |
| 4002 | 资本公积 |
| 4101 | 盈余公积 |
| 4102 | 一般风险准备（金融共用） |
| 4103 | 本年利润 |
| 4104 | 利润分配 |
| 4201 | 库存股 |

### 3. 判定规则
- 如果科目编号为 4001、4002、4101、4102、4103、4104 或 4201，则归类为所有者权益类科目
- 如果科目名称匹配上述任一名称，则归类为所有者权益类科目
- 如果编号和名称均不匹配，则不属于所有者权益类科目

## 输出结果
将目标科目归类为"所有者权益类"或"非所有者权益类"。
