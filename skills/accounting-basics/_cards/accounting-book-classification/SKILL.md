# 会计账簿分类与选择

## 使用场景
当需要设置、识别或使用会计账簿时，根据账户类型和业务需求选择对应的账页格式和外形特征。

## 按账页格式分类

### 两栏式账簿
- **结构特征**：只有借方和贷方两个基本金额栏
- **适用场景**：收入、费用类账户

### 三栏式账簿
- **结构特征**：设有借方、贷方和余额三栏
- **适用场景**：日记账、总分类账、资本明细账

### 多栏式账簿
- **结构特征**：借方和贷方按需要划分成多个专栏
- **适用场景**：收入、费用明细账

### 数量金额式账簿
- **结构特征**：设有借方、贷方和金额栏，并分设数量、单价和金额三个小栏
- **适用场景**：原材料、库存商品等明细账

### 横线登记式账簿
- **结构特征**：在同一张账页的同一行里，登记某项经济业务从发生到结束的完整内容
- **适用场景**：材料采购业务、报销业务、收回业务

## 按外形特征分类

### 订本式账簿（订本账）
- **定义**：启用前将编有顺序页码的一定数量账页装订成册
- **适用范围**：总分类账、现金日记账、银行存款日记账
- **优点**：避免账页散失，防止账页被抽换，比较安全
- **缺点**：不便于分工协作记账，不便于计算机打印

### 活页式账簿（活页账）
- **定义**：将一定数量的账页置于活页夹内，可根据需要增减账页
- **适用范围**：明细分类账
- **优点**：使用灵活，便于分工记账
- **缺点**：账页容易散失和被抽换

### 卡片式账簿（卡片账）
- **定义**：将卡片式账页存放于专设的卡片箱中
- **适用范围**：固定资产明细账
- **特殊规定**：我国一般只对固定资产明细账采用卡片账形式

## 选择决策流程

1. 确定账户类型（收入、费用、原材料、固定资产等）
2. 确定核算需求（仅金额核算、金额+数量核算、业务全过程追踪）
3. 根据账户类型选择账页格式
4. 根据账簿重要性选择外形特征
