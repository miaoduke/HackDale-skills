# 负债按偿还期限分类

## 使用场景
当已知负债的偿还期限，需要将其归类为流动负债或非流动负债时使用。

## 分类标准
以"一年"为时间界限进行划分：

### 流动负债（短期负债）
- **判定标准**：偿还期限在一年以内（含一年）
- **关键点**："含一年"意味着期限正好等于12个月时也符合条件
- **包含项目**：
  - 短期借款
  - 应付账款
  - 应付利息
  - 应付职工薪酬
  - 应缴税费
  - 其他应付款

### 非流动负债（长期负债）
- **判定标准**：偿还期限在一年以上
- **包含项目**：
  - 长期借款
  - 应付债券
  - 长期应付款

## 判定流程

1. **获取偿还期限信息**：确定负债从确认之日起至到期日止的时间长度

2. **应用判定标准**：将偿还期限与"一年"阈值进行比对

3. **执行分类**：
```
IF (偿还期限 <= 1年)
THEN 归类为"流动负债"
ELSE IF (偿还期限 > 1年)
THEN 归类为"非流动负债"
```

## 示例
- 6个月期的银行贷款 → 流动负债
- 12个月期的应付票据 → 流动负债
- 3年期的公司债券 → 非流动负债
- 5年期的长期借款 → 非流动负债

## 注意事项
- 该分类标准基于负债的时间特征
- 是会计核算中区分短期与长期偿债责任的基础
- 分类影响财务报表的列报位置
