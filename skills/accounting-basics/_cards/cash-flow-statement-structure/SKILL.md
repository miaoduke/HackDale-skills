# 现金流量表结构与分类

## 适用场景
- 需要编制或审核现金流量表
- 需要理解现金流量表的组成要素
- 需要将现金流量项目进行正确分类
- 需要解读现金流量表的功能和作用

## 现金流量表结构

### 表头
必须包含以下信息：
- 公司名称
- 报表名称
- 日期

### 内容
核心数据部分，包含三类现金流量项目：
- 经营活动产生的现金流量
- 投资活动产生的现金流量
- 筹资活动产生的现金流量

### 表尾
责任落实部分，必须包含以下人员签章：
- 会计人员
- 单位负责人
- 主管会计

## 现金流量分类标准

### 经营活动产生的现金流量
**定义**：企业主营业务的交易所产生的现金流量

**包含事项**：
- 销售商品、提供劳务
- 购买材料、生产产品
- 推销产品等交易事项

**重要性**：经营活动是企业的主业，经营活动的现金流是企业现金的主要来源

### 投资活动产生的现金流量
**定义**：企业各种长、短期投资活动产生的现金流量

**包含事项**：
- 长期投资
- 购建固定资产
- 处置长期资产
- 不包括在现金等价物范围内的长短期投资及其处置活动

### 筹资活动产生的现金流量
**定义**：各种筹资活动产生的现金流量

**包含事项**：
- 发行股票
- 购买债券
- 借入和偿还资金
- 分配利润

**特殊规则**：利润分配属于筹资活动。当企业减少对投资者的本期利润分配或不分配，等于是向投资者筹集资金。

## 现金流量表的主要作用
1. 评价和分析企业的现金获取能力
2. 帮助预测企业未来的现金流量和评估企业的盈利能力
3. 分析企业现金周转是否良好
4. 评价企业支付和偿还债务的能力

## 分类决策流程
当需要将现金流量项目分类时：
1. 识别交易性质：是否为主营业务？
2. 若是主营业务 → 经营活动
3. 若为长期资产或投资 → 投资活动
4. 若涉及资本及债务规模变化 → 筹资活动
