# 会计核算基本前提

## 使用场景
- 进行会计核算工作，需要确认核算的基本假设
- 编制财务报表，需要明确核算的空间和时间范围
- 确定企业的记账本位币
- 划分会计期间，进行分期结算
- 界定会计核算和监督的特定对象

## 执行步骤

### 1. 确认会计主体
- **定义**：会计核算的特定单位或组织
- **判定标准**：只要是独立核算的企业，都是会计主体
- **作用**：界定会计工作的空间范围，明确会计核算服务的是哪个特定的单位
- **工作内容**：对企业经济业务的收支情况进行核算

### 2. 确认持续经营
- **定义**：预期企业可以持续经营下去
- **核心含义**：假设企业在可预见的未来不会面临破产清算，而是会按当前的规模和状态继续经营
- **约束**：不适用于破产清算环境

### 3. 确认会计期间
- **定义**：将一个持续经营的企业分成几个连续、相等的期间
- **分类**：分为年度、季度和月份
- **日期标准**：年度、季度和月份的起讫日期采用公历日期
- **目的**：进行会计结算，编制财务报告，及时反映企业经营变动信息

### 4. 确认货币计量
- **定义**：会计核算以货币为计量单位
- **核心含义**：企业在会计核算中采用货币作为统一的主要计量单位
- **记账本位币确定**：
  - 一般原则：会计核算应以人民币作为记账本位币
  - 例外情况：如果企业的业务收支以外币为主，也可以确立某种外币为记账本位币
- **报表编制要求**：无论记账本位币选定为人民币还是某种外币，在编制会计报表时，必须将相关金额折算为人民币

## 关键要点
- 四个基本前提共同构成了会计核算的基础框架
- 会计主体界定了空间范围
- 持续经营提供了时间基础
- 会计期间实现了时间划分
- 货币计量确立了计量尺度

## 输出结果
- 确立会计核算的空间范围（会计主体）
- 确立会计核算的时间基础（持续经营）
- 确立会计核算的时间划分（会计期间）
- 确立会计核算的计量尺度（货币计量）
