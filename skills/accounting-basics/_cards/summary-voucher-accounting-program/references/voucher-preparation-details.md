# 汇总凭证编制详细规范

## 汇总收款凭证编制步骤
1. 依据现金和银行存款的收款凭证进行编制
2. 按借方科目（现金或银行存款）分别设置汇总凭证
3. 按对应的贷方科目进行归类和汇总
4. 每隔5天或10天定期填列一次
5. 每月编制一张汇总收款凭证
6. 月末计算出汇总收款凭证的合计数
7. 将合计数登记在现金或银行存款总账的借方，以及对应账户的贷方

## 汇总付款凭证编制步骤
1. 依据现金或银行存款的付款凭证进行编制
2. 按贷方科目（现金或银行存款）分别设置汇总凭证
3. 按对应的借方科目进行归类和汇总
4. 每隔5天或10天定期填列一次
5. 每月编制一张汇总付款凭证
6. 月末计算出汇总付款凭证的合计数
7. 将合计数登记在现金或银行存款总账的贷方，以及对应账户的借方

## 汇总转账凭证编制步骤
1. 依据转账凭证进行编制
2. 按每一科目的贷方分别设置汇总凭证
3. 按对应的借方科目进行归类汇总
4. 每隔5天或10天填列一次
5. 每月编制一张汇总转账凭证
6. 月末计算出汇总转账凭证的合计数
7. 将合计数分别登记在各有关总账的借方或贷方

## 转账凭证填制规则
- 必须遵循"一贷多借"原则
- 严禁使用"一借多贷"格式
- 贷方科目凭证数量较少时，可不编制汇总转账凭证，直接登账
