## 流动性比率计算公式

### 流动比率
```
流动比率 = 流动资产 ÷ 流动负债
```
一般认为流动比率应维持在2:1左右。

### 速动比率
```
速动比率 = (流动资产 - 存货) ÷ 流动负债
```
一般认为速动比率应维持在1:1左右。

### 现金比率
```
现金比率 = (现金 + 现金等价物) ÷ 流动负债
```
反映企业即时偿债能力。

## 现金流量表分析要点

1. 经营活动现金流量净额：反映企业造血能力
2. 投资活动现金流量净额：反映企业扩张能力
3. 筹资活动现金流量净额：反映企业融资能力

**警示：** 若企业连续多年经营活动现金流量为负，即使账面盈利，也存在重大流动性风险。
