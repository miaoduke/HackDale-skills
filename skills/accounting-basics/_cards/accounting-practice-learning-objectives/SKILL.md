# 会计实务核心学习目标

## 使用场景
当开始学习本章内容或需要掌握本章涵盖的会计技能时，参考以下学习目标以确保掌握核心实务能力。

## 核心学习目标

### 1. 账务处理程序选择
- **关键问题**：如何选择适合本企业的账务处理程序？
- **学习重点**：
  - 理解不同账务处理程序的特点
  - 评估企业规模和业务量
  - 选择最适合的程序类型

### 2. 会计凭证填制
- **关键问题**：如何填制会计凭证？
- **学习重点**：
  - 掌握凭证的基本要素
  - 学习规范的填制方法
  - 理解凭证的审核要求

### 3. 会计凭证分类
- **关键问题**：如何分类会计凭证？
- **学习重点**：
  - 识别原始凭证和记账凭证
  - 掌握凭证的分类标准
  - 建立有序的凭证管理体系

### 4. 汇总与登记总账
- **关键问题**：如何进行凭证汇总，如何根据汇总表登记总账？
- **学习重点**：
  - 掌握凭证汇总方法
  - 学习总账登记流程
  - 理解账簿核对要求

## 执行步骤

1. **目标确认**：明确需要掌握的会计实务技能
2. **逐项学习**：按照四个学习目标逐项掌握相关技能
3. **实践应用**：在实际工作中应用所学技能
4. **能力评估**：检验是否达到各项目标要求

## 学习成果
完成本章学习后，应具备选择账务程序、填制与分类凭证、汇总凭证及登记总账的能力。
