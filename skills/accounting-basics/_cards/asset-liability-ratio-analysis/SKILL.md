# 资产负债率分析

## 使用场景
当需要以下情况时使用此技能：
- 评估企业财务杠杆水平
- 判断企业长期偿债能力
- 分析企业资产结构稳定性
- 评估债权人资金保障程度
- 判断企业是否有效利用财务杠杆

## 计算公式

### 基本公式
```
资产负债率 = (负债总额 / 资产总额) × 100%
```

### 变量说明
- **负债总额**：企业承担的各项负债的总和
- **资产总额**：企业拥有的各项资产的总和
- **资产负债率**：反映总资产中有多大比例是通过借债来筹集的

## 分析解读

### 高资产负债率
**特征**：
- 资产结构越不稳固
- 大部分资产是通过外借或筹资回来的
- 需要定期偿还本金和利息

**风险**：
- 债务负担较重
- 偿债压力较大

### 低资产负债率
**特征**：
- 企业债务风险越小
- 大部分资产是企业自有资产
- 不会形成企业债务负担

**优势**：
- 债权人回收本金和利息的保障度越高

## 评估基准

### 合理基准
- 一般情况下，资产负债率维持在**60%左右**较为合理

### 权衡考虑
资产负债率并非越低越好：
- 比率过低：说明企业不善于利用负债来经营（未能有效利用财务杠杆效应）
- 比率过高：资产结构不稳固，债务风险较大

### 行业差异
不同行业可能需要调整基准值，需结合行业特点进行分析。

## 分析步骤
1. 收集负债总额和资产总额数据
2. 计算资产负债率
3. 与60%基准值对比
4. 结合行业特点评估合理性
5. 分析资产结构稳定性和债务风险
6. 评估财务杠杆利用效果
