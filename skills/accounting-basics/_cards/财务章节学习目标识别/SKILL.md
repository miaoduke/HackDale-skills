# 财务章节学习目标识别

## 使用场景
- 开始阅读新的财务章节
- 需要快速了解章节的学习目标
- 确认章节涵盖的知识模块
- 规划学习路径和重点

## 执行步骤

### 1. 识别章节类型
- 判断章节属于财务报表分析、财务管理还是其他财务领域
- 确认章节是否为学习目标/大纲类型

### 2. 提取核心学习模块
- 列举章节涵盖的主要知识点
- 识别每个模块的具体学习目标
- 理解模块之间的逻辑关系

### 3. 常见财务学习模块

#### 财务报表分析类
- 会计报表类型识别
- 财务报表信息解读
- 资产负债表分析方法
- 利润表经营能力评估
- 现金流量表作用理解

#### 财务管理与舞弊防范类
- 财务清查方法
- 财务清查结果处理
- 财务报表舞弊手段识别
- 假报表识别技巧

### 4. 确认学习范围
- 明确章节将指导完成的学习过程
- 识别从基础到高级的知识递进关系
- 理解实践技能与理论知识的结合点

## 输出格式
```
章节学习目标：
1. [模块名称] - [具体学习目标]
2. [模块名称] - [具体学习目标]
...

本章将指导读者完成：[整体学习路径描述]
```

## 注意事项
- 学习目标章节通常不包含具体操作细节
- 需要结合后续章节获取详细内容
- 适用于财务学习者、企业管理者和投资者
