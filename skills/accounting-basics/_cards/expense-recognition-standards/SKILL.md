# 费用确认标准

## 使用场景
当发生经济利益流出，需要判断其是否应确认为费用时使用。

## 确认流程

### 第一步：活动性质检查
- 检查经济利益流出是否发生在企业的"日常经营活动"中
- 日常活动示例：销售成本、应交税费、应付职工薪酬、折旧费等

### 第二步：权益影响检查
- 确认该流出会导致"所有者权益减少"

### 第三步：排除特定情况
- 必须确认该流出与"向所有者分配利润"无关
- 这是区分费用与利润分配的关键界限

### 第四步：识别表现形式
费用相关的经济利益流出通常通过以下形式引起所有者权益减少：
- 资产流出企业（如现金支付）
- 资产损耗（如固定资产折旧、存货消耗）
- 负债增加（如应付账款增加）

### 第五步：判定结论
```
IF (日常活动 AND 导致所有者权益减少 AND 非向所有者分配利润)
THEN 确认为费用，计入当期损益
ELSE IF (非日常活动) THEN 计入损失
ELSE IF (向所有者分配利润) THEN 作为所有者权益抵减项目
```

## 排除情况
- 非日常活动形成的经济利益流出 → 计入损失
- 向所有者分配利润 → 所有者权益抵减项目
- 所有者抽回投资 → 所有者权益减少，不属于费用

## 费用分类
- 营业成本（主营业务成本、其他业务成本）
- 期间费用（销售费用、管理费用、财务费用）
- 税金及附加
