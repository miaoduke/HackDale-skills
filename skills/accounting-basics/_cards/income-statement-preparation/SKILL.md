# 利润表编制（多步式）

## 使用场景
当需要以下操作时使用此技能：
- 编制企业月度、季度或年度利润表
- 分析企业一定会计期间的经营成果
- 计算企业净利润或净亏损
- 预测企业未来利润获取能力

## 利润表定义

利润表是反映企业在一定会计期间经营成果的报表，通过对企业一定期间的营业收入与营业费用进行计算，得出企业当期的净利润或净亏损。

## 编制格式

我国企业统一采用**多步式**格式

## 三步计算流程

### 第一步：计算营业利润

**计算公式：**
```
营业利润 = 营业收入 - 营业成本 - 营业税金及附加 - 销售费用 - 管理费用 - 财务费用 - 资产减值损失 + 公允价值变动收益（或 - 损失） + 投资收益（或 - 损失）
```

**项目说明：**
- **营业收入**：企业在日常经营活动中销售商品或提供劳务所取得的收入
- **期间费用**：营业成本、营业税金及附加、销售费用、管理费用、财务费用、资产减值损失等
- **变动项目**：公允价值变动收益/损失、投资收益/损失

### 第二步：计算利润总额

**计算公式：**
```
利润总额 = 营业利润 + 营业外收入 - 营业外支出
```

**项目说明：**
- **营业外收入**：与生产经营无直接关系的各项收入
- **营业外支出**：与生产经营无直接关系的各项支出

### 第三步：计算净利润

**计算公式：**
```
净利润 = 利润总额 - 所得税费用
```

**项目说明：**
- **所得税费用**：企业确认的应从当期利润总额中扣除的所得税费用
- **结果判定**：结果为正为净利润，结果为负为净亏损

## 执行步骤

1. **数据准备**
   - 营业收入数据
   - 各项成本费用数据（营业成本、期间费用等）
   - 营业外收支数据
   - 所得税费用数据
   - 变动项目数据（公允价值变动、投资收益等）

2. **计算营业利润**
   - 以营业收入为起始数值
   - 依次减去各项期间费用
   - 加减变动项目
   - 得出营业利润

3. **计算利润总额**
   - 以营业利润为基础
   - 加上营业外收入
   - 减去营业外支出
   - 得出利润总额

4. **计算净利润**
   - 以利润总额为基础
   - 减去所得税费用
   - 得出净利润或净亏损

## 输出结果

- 营业利润金额
- 利润总额金额
- 净利润或净亏损金额

## 报表用途

- 体现企业经营业绩
- 是企业进行利润分配的主要依据
- 通过分析不同时期的报表可预测企业未来的利润获取能力和发展能力
