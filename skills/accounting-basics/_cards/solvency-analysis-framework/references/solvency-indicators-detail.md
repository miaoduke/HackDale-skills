# 偿债能力指标详细说明

## 变量定义

### 流动资产
企业可以在一年或者超过一年的一个营业周期内变现或者运用的资产。

### 流动负债
企业在一年内或者超过一年的一个营业周期内需要偿还的债务总额。

### 速动资产
可以迅速转换为现金的资产，通常等于流动资产减去存货。

### 现金及现金等价物
企业库存现金、银行存款及短期投资等流动性极强的资产。

### 负债总额
企业承担的各项负债总和。

### 资产总额
企业拥有的各项资产总和。

### 利润总额
企业在一定时期内实现的利润总和。

### 利息费用
企业发生的借款利息等费用。

## 指标关系
- 流动比率、速动比率、现金比率依次递进，反映不同流动性资产的偿债能力
- 资产负债率反映企业整体财务结构
- 利息保障倍数反映企业支付利息的能力
