# 偿债能力分析框架

## 使用场景
当需要评估企业财务状况、偿债能力或风险水平时，使用此技能。

## 核心概念

### 偿债能力定义
偿债能力是指债务到期时企业能否及时偿还债务本金和利息的能力，以及偿债的保证程度。它是评价企业财务状况、经营能力好坏的重要标志。

### 偿债能力分类

**短期债务偿还能力**：
- 以流动资产偿还流动负债的能力
- 反映企业变现能力和财务能力

**长期债务偿还能力**：
- 偿还长期负债本金和利息的能力
- 反映偿债的保证度

## 核心指标计算

### 短期偿债能力指标

**流动比率**：
```
流动比率 = (流动资产 ÷ 流动负债) × 100%
```

**速动比率**：
```
速动比率 = (速动资产 ÷ 流动负债) × 100%
```

**现金比率**：
```
现金比率 = (现金 + 现金等价物) ÷ 流动负债
```

### 长期偿债能力指标

**资产负债率**：
```
资产负债率 = (负债总额 ÷ 资产总额) × 100%
```

**利息保障倍数**：
```
利息保障倍数 = (利润总额 + 利息费用) ÷ 利息费用
```

## 分析要点
- 经营效率高、盈利能力强的企业，偿债能力通常较强
- 偿债能力分析可透视企业持续经营和应对风险的能力
- 需结合行业特性和企业具体经营情况综合判断
