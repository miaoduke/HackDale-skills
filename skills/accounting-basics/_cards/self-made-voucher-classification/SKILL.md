# 自制原始凭证分类与编制

## 使用场景
- 需要识别自制原始凭证的具体类型
- 需要编制汇总原始凭证
- 需要理解不同类型自制凭证的填制方法
- 需要简化记账凭证编制工作

## 自制原始凭证定义
在经济业务发生或完成时，由本企业经手人填制的凭证。

## 四类自制凭证识别

### 1. 一次凭证
**判定标准**：只反映一项经济业务，或同时反映若干项同类性质经济业务，填制手续一次完成

**典型实例**：
- 验收入库单
- 领料单
- 报销单

### 2. 累计凭证
**判定标准**：在一定时期内多次记录发生的同类经济业务，填制手续随经济业务发生分次进行

**典型实例**：
- 限额领料单
- 费用登记表

**优势**：手续简化，易于管理控制

### 3. 汇总原始凭证
**判定标准**：根据一定时期内反映相同经济业务的多张原始凭证，汇总编制而成

**典型实例**：
- 现金收入汇总表
- 发料凭证汇总表
- 收料凭证汇总表

**目的**：集中反映某项经济业务总体发生情况，简化记账凭证编制

### 4. 记账编制凭证
**判定标准**：根据账簿记录和经济业务需要，对账簿内容进行整理而编制

**典型实例**：
- 制造费用分配表

## 汇总原始凭证编制流程

### 前提条件
- 存在一定时期内发生的同类经济业务
- 拥有若干份相关的原始凭证
- 有简化记账凭证编制工作的需求

### 编制步骤
1. **确定编制对象**：选取"一定时期内"发生的"若干份"记录"同类经济业务"的"原始凭证"
2. **执行汇总编制**：按照"一定的管理要求"，将上述原始凭证汇总编制成"一张汇总凭证"
3. **明确凭证性质**：该凭证属于"会计凭证"，也称为"原始凭证汇总表"
4. **遵循编制规范**：由"有关责任者"根据"经济管理的需要""定期"进行编制

### 编制要求
- 必须是同类经济业务
- 必须按照一定的管理要求进行汇总
- 必须由有关责任者编制
