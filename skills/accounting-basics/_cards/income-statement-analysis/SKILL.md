# 利润表分析

## 使用场景
当需要以下分析时使用此技能：
- 评估企业某一期间的经营成果（盈利或亏损）
- 分析企业盈利能力和利润质量
- 编制符合规范的利润表
- 了解收入支出结构和偿债能力
- 预测企业未来发展能力

## 执行步骤

### 1. 确定利润表类型
- **单步式利润表**：将所有收入之和减去所有费用支出之和，一步得出利润或亏损
- **多步式利润表**：将收入和费用项目归类，经过多个层次计算损益

**法规要求**：国境内企业统一采用多步式利润表格式

### 2. 获取基础数据
收集企业某一会计期间的：
- 所有收入数据
- 所有费用支出数据
- 会计科目记录

### 3. 执行多步式计算逻辑

#### 步骤1：计算主营业务利润
```
主营业务利润 = 主营业务收入 - 主营业务成本 - 主营业务税金及附加
```
亏损以"-"号填列

#### 步骤2：计算营业利润
```
营业利润 = 主营业务利润 - 销售费用 - 管理费用 - 财务费用
```
亏损以"-"号填列

#### 步骤3：计算利润总额
```
利润总额 = 营业利润 + 投资收益 + 营业外收入 - 营业外支出
```
投资收益损失以"-"填列，亏损以"-"号填列

#### 步骤4：计算净利润
```
净利润 = 利润总额 - 所得税
```
净亏损以"-"号填列

### 4. 利润表结构

**表头**：报表名称、公司名称、日期

**内容**：
- 本期发生额：本期所有的交易进出总额量
- 本年累计数：从年初起至本月末止的实际累计发生数

**表尾**：公司负责人、经理、主管会计签章

### 5. 结果分析

#### 经营成果判断
- **高利润**：经营效益高，赚的钱越多
- **低利润或亏损**：经营不善，效益低下
- **长期无利润**：面临破产或倒闭风险

#### 利润质量评估
- 利润的收支结构：总收入与总支出的差额比例结构
- **判定标准**：收入占利润的比值越高，利润质量越高
- **推论**：利润质量越高，偿还能力和应对突发财务状况的能力越强

## 输出结果
返回包含表头、数据列及计算得出的主营业务利润、营业利润、利润总额和净利润的完整报表，以及对盈利能力、利润质量、偿债能力的综合评价。
