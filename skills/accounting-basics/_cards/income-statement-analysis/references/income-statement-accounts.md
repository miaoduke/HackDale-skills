# 利润表核心会计科目定义

## 收入类
- **营业收入**：企业经营业务收入的总额
- **投资收益**：企业对外投资所获取的收益
- **营业外收入**：企业副业经营中所获得的各项收入

## 成本费用类
- **营业成本**：企业为经营业务所支出的实际成本
- **营业税金及附加**：企业需交纳的营业税、消费税、城市维护建设税以及教育费附加等税款
- **销售费用**：商品销售和流通过程中所产生的费用支出
- **管理费用**：企业管理部门所发生的各项费用支出
- **财务费用**：企业发生的利息费用等
- **营业外支出**：企业副业经营中所发生的各项支出
- **所得税**：企业在一定时期内应缴纳的所得税额

## 利润计算公式
```
利润 = 总收入 - 总支出
```

## 利润表优势（多步式）
- 更能直接反映企业利润表的数据
- 有助于比较同行的利润水平
- 分析企业经营状况
- 预测企业未来的发展能力

## 法规依据
《企业会计准则第30号——财务报表列报》
