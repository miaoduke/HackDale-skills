# 编制和报送财务报告流程

## 使用场景
当以下情况时应用此技能：
- 月末、季末、年末终了时
- 需要编制财务报表
- 需要向老板或管理层报送财务报告
- 上市公司需要公开披露财务报表

## 报告时间节点
- 月末
- 季末
- 年末

## 核心财务报表

### 1. 资产负债表
- **性质**：静态报表
- **功能**：反映企业在一定时间点上的财务状况
- **公式**：资产 = 负债 + 所有者权益

### 2. 利润表
- **性质**：动态报表
- **功能**：反映企业在某段时间内关于经营成果的动态信息
- **公式**：收入 - 费用 = 利润

### 3. 现金流量表
- **性质**：动态报表
- **功能**：反映企业一定时期的现金流出与流入情况

## 执行步骤

1. **确定报告时间节点**
   - 在月末、季末或年末终了时启动流程

2. **数据收集与核对**
   - 根据企业本期发生的经济业务和变动情况
   - 依据账簿记录进行整理

3. **编制核心财务报表**
   - 编制资产负债表（反映财务状况）
   - 编制利润表（反映经营成果）
   - 编制现金流量表（反映现金流量）

4. **整合报告信息**
   - 将企业的经营成果、权益变动以及现金流量等信息
   - 通过财务报表全面反映出来

5. **内部报送与使用**
   - 将编制好的财务报表提供给老板或其他报表使用者
   - 便于其阅读和了解企业的经营状况

6. **上市公司特殊合规处理**
   - 必须按照规定定期向有关部门报送、公开财务报表
   - 严禁未按期报送财务报表
   - 严禁财务报表中包含重大错报

## 注意事项
- 必须按期报送
- 报表不得包含重大错报
- 需要完整的账簿记录作为基础
- 上市公司有公开披露义务
