# 会计错账更正

## 基本原则

### 严格禁止行为
若是发现账簿登记错误，绝对不能随意涂改、挖补或用其他方法消除字迹。

### 强制执行要求
必须按规定的方法进行错账更正。

### 方法选择依据
由于错账的种类、形成的原因或发现的时间不同，进行更正的方法也有所不同。

## 错账的主要形式

### 四大主要类别
- 文字上的笔误
- 数字的错误
- 计算的差错
- 会计记录的错误

### 五种具体账簿记录差错形式
1. **重复登记分录**：将一笔会计分录重复登记，或一笔分录的其中一方登记重复
2. **漏记分录**：将一笔会计分录漏记，或只登记了一笔分录的其中一方
3. **借贷方向记错**：将一笔分录本应记在借方的金额误记成贷方，或将贷方错记成借方
4. **数字记错**：将会计分录金额的数字写错或错位登记等
5. **计算错误**：金额计算时的误差，具体表现为合计数算错，或计算中漏计、重复计算某一项金额等

## 三种主要更正方法

### 1. 划线更正法
适用于账簿记录错误但记账凭证正确的情况。

### 2. 红字更正法
适用于记账凭证已入账且发现记账凭证错误的情况。

### 3. 补充登记法
适用于记账凭证金额小于实际金额的情况。

## 红字更正法详细流程

### 情况一：记账凭证上的应记科目和金额发生错误（全额冲销）

1. **填制红字凭证**：用红字填写一张与原错误凭证记录内容（科目、方向、金额）完全相同的凭证
2. **填写摘要**：在摘要栏注明"更正第××号错误凭证"
3. **冲销原记录**：据以用红字登记入账，以冲销原来的错误记录
4. **填制蓝字凭证**：再用蓝字填制一张正确的记账凭证
5. **登记正确记录**：将蓝字凭证登记入账

### 情况二：会计分录的借、贷账户没有错，只是把金额写成了大于实际金额（部分冲销）

1. **计算差额**：计算大于实际金额的部分（多记金额 = 原记金额 - 实际金额）
2. **填制红字凭证**：将多记金额填制一张红字金额记账凭证（科目与原凭证相同）
3. **填写摘要**：在凭证的摘要栏注明"冲转第×号凭证多计数"
4. **冲销多记金额**：据以入账，以冲销原来多计的金额

## 方法选择决策流程

1. 确认错误类型（科目错误、金额错误、方向错误等）
2. 确认错误发现时间（记账前、记账后）
3. 根据错误类型选择更正方法
4. 执行相应的更正流程
