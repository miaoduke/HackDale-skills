# 账簿结构与记录

## 适用场景
- 建立新的会计账簿
- 登记经济业务到账簿
- 查阅账簿结构和记录规范

## 总分类账结构

### 账页表头
- **科目名称**：填写具体的会计科目名称

### 表格主体列结构（从左至右）
1. **日期与凭证列**：
   - 年、月、日：记录经济业务发生时间
   - 凭证编号：记录凭证索引

2. **摘要列**：简要描述经济业务内容

3. **借方金额列**：记录借方发生额
   - 包含7个子列：万、千、百、十、元、角、分

4. **贷方金额列**：记录贷方发生额
   - 包含7个子列：万、千、百、十、元、角、分

5. **方向列**：标记"借"或"贷"，指示余额方向

6. **余额列**：记录当前账户结余金额
   - 包含7个子列：万、千、百、十、元、角、分

## 银行存款日记账结构

### 标准栏目
1. **日期栏**：记录经济业务发生的具体时间
2. **记账凭证栏**：登记入账的凭证种类及编号
3. **对方科目栏**：填写与银行存款对应的会计科目
4. **摘要栏**：简要说明经济业务内容
5. **结算方式栏**：记录银行结算方式（支票号、汇票号等）
6. **借方栏**：登记银行存款增加金额
7. **贷方栏**：登记银行存款减少金额
8. **余额栏**：计算并登记每次变动后的结余金额

## 业务摘要记录规范

### 填写位置
定位到"凭证编号"右侧的"摘要"栏目

### 填写要求
1. 概括描述经济业务的主要内容
2. 文字说明应简明扼要
3. 清晰反映经济业务的性质
4. 确保摘要能够清晰反映业务来源

### 摘要填写流程
1. 定位到"凭证编号"右侧的"摘要"栏目
2. 概括描述经济业务的主要内容
3. 填写文字说明，应简明扼要地反映经济业务的性质
4. 确保摘要能够清晰反映业务来源
