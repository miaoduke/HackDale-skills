# 所有者权益分析

## 使用场景
当需要以下操作时使用此技能：
- 编制或分析企业资产负债表
- 确认和计量所有者权益
- 评估企业资本保值增值能力
- 分析投资者权益结构和权利
- 评估企业经营效益和发展状况

## 分析步骤

### 1. 确认所有者权益定义
所有者权益是指企业资产扣除负债后，由所有者享有的剩余权益。

### 2. 识别所有者权益构成要素
所有者权益由以下四个主要部分构成：
- **实收资本（或股本）**：投资者实际投入企业的资本
- **资本公积**：股本溢价及直接计入权益的利得/损失
- **盈余公积**：从净利润中提取的积累资金
- **未分配利润**：历年结存留待分配的利润

### 3. 计算所有者权益总额
```
所有者权益总额 = 实收资本 + 资本公积 + 盈余公积 + 未分配利润
```

### 4. 计算资本保值增值率
```
资本保值增值率 = (期末所有者权益 ÷ 期初所有者权益) × 100%
```

### 5. 解读分析结果

#### 资本保值增值率解读
- **比率 ≥ 100%**：资本保值或增值，企业发展良好
- **比率 < 100%**：资本受损，经营效益低下
- 比率越大，表示所有者权益增值率越大，企业发展越好

#### 所有者权益特征分析
- 投资者享有企业利润分配权
- 投资者承担经营风险
- 投资者拥有企业管理权或委托管理权

## 注意事项
- 期初和期末数据必须属于同一会计年度或可比期间
- 不适用于所有者权益为负或为零的特殊破产清算场景
- 所有者权益仅指所有者享有的剩余权益，不包含负债部分

## 输出结果
- 所有者权益总额及明细构成
- 资本保值增值率数值
- 资本增值能力评估结论
