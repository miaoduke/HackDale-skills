# 期末会计处理全流程

## 使用场景
当到达会计期末且本期所有经济业务已全部记录入账时，执行期末结算、对账及报表报送流程。

## 前置条件
- 本期所有经济业务已全部记录入账
- 必须在会计期末进行
- 必须确保所有业务结算清楚

## 期末结算流程

### 1. 计算本期损益
- 执行"计算本期收入与成本核算"
- 确定当期的财务成果

### 2. 结账处理
将各项经济业务结算清楚，包含以下步骤：
- 计算并结出各账户的"本期发生额"
- 计算并结出各账户的"期末余额"
- 将"期末余额结转下期"，作为下一期的期初余额

### 3. 编制试算平衡表
- 编制"总分类账"和"明细分类账试算平衡表"
- **检查重点**：检查账簿记录中"有无错漏误记"
- **质量目标**：确保"账簿记录的准确性、真实性"

### 4. 执行对账
在完成记录经济业务后必须进行对账，包含三个维度：
- **账账相符**：核对总账与明细账的一致性
- **账证相符**：核对账簿记录与会计凭证的一致性
- **账实相符**：核对账簿记录与实物资产的一致性

## 财务报表报送

### 报表类型与报送时限

| 报表类型 | 报送时限 |
|---------|---------|
| 月报表 | 会计期间结束后6天内 |
| 季度报表 | 会计期间结束后15天内 |
| 半年度会计报表 | 会计期间结束后60天内 |
| 年度报表 | 会计期间结束后4个月内 |

### 合规性前置检查
在报送前必须满足以下条件：
- 确保财务报表**没有错误**
- 确保财务报告已经由**会计事务所**进行确认/审计

### 违规后果
- 如果报表存在错误或未通过事务所确认，将受到相应的法律法规惩处

## 输出结果

- 生成试算平衡表
- 生成对账报告
- 确认账账、账证、账实三者相符
- 完成期末结账
- 在规定时限内报送财务报表
