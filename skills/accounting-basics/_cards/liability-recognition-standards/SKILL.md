# 负债确认标准

## 使用场景
当需要判断企业的一项义务是否属于负债时，应用此技能进行确认判断。

## 确认流程

### 第一步：区分债权与债务
- **债权**：企业借给别人，即"人欠我"，属于企业的资产
- **债务（负债）**：企业欠别人，即"我欠人"，属于企业的负债

### 第二步：检查负债的三个核心特征
必须同时满足以下三个特征才能确认为负债：

#### 特征一：现时义务
- 负债必须是企业承担的"现时义务"
- "现时义务"指企业在"现行条件下"已承担的义务
- **排除项**：未来发生的交易或事项形成的义务不属于现时义务，不能确认为负债

#### 特征二：预期会导致经济利益流出企业
- 履行义务时必须导致经济利益流出企业
- 流出形式包括：
  - 用现金偿还
  - 以实物资产偿还
  - 提供劳务偿还
  - 将负债转为资本
- **排除项**：如果履行义务不会导致经济利益流出，则不能确认为负债

#### 特征三：由企业过去的交易或事项形成
- 只有过去的交易或事项才能形成负债
- **排除项**：未来发生的交易或事项（如未执行的合同）不形成现时负债

### 第三步：判定结论
```
IF (属于"我欠人" AND 满足现时义务 AND 导致经济利益流出 AND 过去交易形成)
THEN 确认为负债
ELSE 不确认为负债
```

## 常见实例
- 企业购买机械设备形成的"应付账款"
- 企业向银行或其他金融机构的"贷款"
- 企业需"定期支付"的款项
- 职工薪酬等法定义务

## 注意事项
- 三个特征必须同时满足，缺一不可
- 代收款项（如增值税进项税额）不属于负债
- 未来计划产生的义务不属于现时义务
