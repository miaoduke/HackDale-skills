# 流动比率分析

## 使用场景
当需要评估企业以下方面时使用此技能：
- 企业短期偿债能力
- 财务状况健康程度
- 资金利用效率
- 破产风险预警

## 执行步骤

### 1. 获取基础数据
从资产负债表中提取：
- 流动资产总额：企业可以在一年或超过一年的一个营业周期内变现或运用的资产
- 流动负债总额：企业在一年内或超过一年的一个营业周期内需要偿还的债务总额

**约束条件**：流动负债不能为零

### 2. 计算流动比率
```
流动比率 = (流动资产 ÷ 流动负债) × 100%
```

### 3. 结果解读
根据计算结果进行评估：

| 比率水平 | 含义 | 风险评估 |
|---------|------|---------|
| 比率较高 | 偿还短期债务的能力较有保障 | 资金利用率可能不高 |
| 比率过高 | 短期资金利用率不高，未充分发挥资金效益 | 资金闲置 |
| 比率较低 | 财务状况不佳，偿还债务能力较弱 | 偿债风险 |
| 比率过低 | 可能面临破产危机 | 高风险 |

### 4. 标准基准
- 一般维持在 **200%** 为宜
- 不同行业可能有差异，需结合行业背景分析

## 输出结果
返回流动比率数值，并基于200%基准对偿债保障度、资金利用率和破产风险进行评估。
