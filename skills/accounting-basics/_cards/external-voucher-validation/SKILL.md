# 外来原始凭证验证

## 使用场景
- 接收到来自外部单位的原始凭证
- 需要审核外来凭证的完整性
- 需要验证外来凭证的合规性
- 需要确认凭证是否可作为记账依据

## 外来原始凭证定义
在经济业务发生或完成时，从外单位取得的凭证。

**典型场景**：企业购买设备或材料时从供货单位取得的发货票

## 凭证特征
- 性质：外来原始凭证都是一次凭证
- 来源：一般统一由税务印刷

## 七项必备要素检查清单

### 1. 凭证的名称
- **要求**：必须有明确名称
- **目的**：方便凭证的管理和业务处理

### 2. 填制凭证的日期
- **要求**：明确经济业务发生或完成的日期
- **目的**：便于对经济业务的真实有效性进行审查

### 3. 凭证出具单位的名称
- **要求**：填列凭证出具单位
- **目的**：证实经济业务的发生是可证明的，了解业务来龙去脉

### 4. 凭证接收单位的名称
- **要求**：必须是单位名全称
- **目的**：证明确是本单位发生的经济业务，便于记账和查账

### 5. 经办人员的签名或者盖章
- **要求**：凭证上需要经办人的签名或盖章
- **目的**：明确经济责任

### 6. 经济业务的内容
- **要求**：记录经济业务的内容
- **目的**：了解经济业务的具体情况，查核真实、合法性

### 7. 金额、数量和单价
- **要求**：填写经济业务发生的详细证明
- **目的**：保证会计资料真实性的基础

## 强制合规要求

### 公章要求
- 外来凭证填制时**必须加盖**出具凭证单位的公章
- 若未加盖公章，则凭证**不符合规范**，视为无效

## 验证流程

1. **核对凭证名称**：确认凭证上明确标有凭证的名称
2. **核实单位信息**：检查是否同时包含出具单位和接收单位名称
3. **确认时间要素**：检查是否注明了凭证日期
4. **验证责任签章**：确认有经办人员的签章
5. **审核业务内容**：检查是否详细描述了经济业务内容
6. **核对量化数据**：确认准确记录了金额、数量、单价
7. **检查公章**：确认加盖了出具凭证单位公章

## 验证结果模板

**有效凭证**：
```
若凭证包含上述所有要素且符合具体要求，则凭证完整有效
```

**无效凭证**：
```
若缺失任何一项要素或未加盖公章，则凭证不完整或无效，需退回或补正
```
