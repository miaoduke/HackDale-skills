# 企业利润分配核算流程

## 使用场景
当需要以下操作时使用此技能：
- 企业进行年终财务结算
- 制定年度利润分配方案
- 计算可供分配利润和可供投资者分配利润
- 提取法定和任意盈余公积
- 确定未分配利润
- 设置利润分配核算账户

## 法律依据
严格遵循《中华人民共和国公司法》等相关法规规定

## 核心计算公式

### 可供分配利润
```
可供分配的利润 = 本年净利润（或亏损） + 年初未分配利润（或亏损）
```

### 可供投资者分配利润
```
可供投资者分配的利润 = 可供分配的利润 - 提取法定盈余公积 - 提取法定公益金
```

### 未分配利润
```
未分配利润 = 净利润 - 弥补以前年度亏损 - 提取法定盈余公积 - 提取任意盈余公积 - 向投资者分配利润
```

## 利润分配程序（必须按顺序执行）

### 第一步：计算可供分配的利润
1. 获取本年净利润（或亏损）数据
2. 获取年初未分配利润（或亏损）数据
3. 执行加法运算得出可供分配的利润

**分配资格判定：**
- 如果可供分配的利润为负数（亏损）→ 不能进行后续分配
- 如果可供分配的利润为正数（盈利）→ 才能进行后续分配

### 第二步：提取法定盈余公积
- **提取比例**：按净利润的10%提取
- **提取前提**：企业实现盈利（净利润大于0）
- **提取豁免**：累计法定盈余公积已达注册资本的50%时停止提取

**转增资本限制：**
转增资本后，留存的法定盈余公积不得低于注册资本的25%

### 第三步：提取任意盈余公积
- **提取比例**：企业根据自身经营需要和发展战略自主决定
- **灵活性**：不同于法定盈余公积的强制性固定比例
- **审批要求**：若用于分配利润，必须经股东大会同意

### 第四步：向投资者分配利润（股利）
完成上述提取后，向投资者进行利润（股利）分配

## 账户设置

### 利润分配核算账户
设置专门的会计账户，确保利润分配过程中的各项经济业务能够被准确记录和反映。

## 执行步骤

1. **数据准备**
   - 利润总额
   - 所得税费用
   - 年初未分配利润或亏损数据
   - 注册资本金额
   - 累计法定盈余公积金额

2. **计算净利润**
   ```
   净利润 = 利润总额 - 所得税
   ```

3. **计算可供分配的利润**
   ```
   可供分配的利润 = 当年实现的净利润 + 年初未分配利润（或 - 年初未弥补亏损）
   ```

4. **判定分配资格**
   - 可供分配利润 < 0：停止分配流程
   - 可供分配利润 > 0：继续下一步

5. **提取法定盈余公积**
   - 检查累计法定盈余公积是否已达注册资本50%
   - 如未达，按净利润10%提取
   - 如已达，可停止提取

6. **提取任意盈余公积**
   - 管理层拟定提取比例
   - 如涉及使用该公积分配，提交股东大会审议批准

7. **计算可供投资者分配利润**
   ```
   可供投资者分配的利润 = 可供分配的利润 - 提取法定盈余公积 - 提取法定公益金
   ```

8. **向投资者分配利润**
   - 根据股东大会决议分配股利或利润

9. **确定未分配利润**
   - 经过上述所有分配步骤后的剩余金额
   - 代表企业历年结存的、可供未来分配的利润

## 输出结果
- 净利润金额
- 可供分配的利润金额
- 提取的法定盈余公积金额
- 提取的任意盈余公积金额
- 可供投资者分配的利润金额
- 向投资者分配的利润金额
- 未分配利润金额
- 完成利润分配后的财务报表状态及股东权益变动
