# 利润分配会计分录示例

## 示例1：净利润结转
某公司2023年实现净利润500万元。

```
借：本年利润 5,000,000
    贷：利润分配——未分配利润 5,000,000
```

## 示例2：提取盈余公积
接上例，按10%提取法定盈余公积，按5%提取任意盈余公积。

```
借：利润分配——提取法定盈余公积 500,000
    利润分配——提取任意盈余公积 250,000
    贷：盈余公积——法定盈余公积 500,000
        盈余公积——任意盈余公积 250,000
```

## 示例3：宣告现金股利
接上例，宣告每股派发现金股利0.2元，发行在外普通股1000万股。

```
借：利润分配——应付现金股利 2,000,000
    贷：应付股利 2,000,000
```

## 示例4：利润转增资本
股东大会批准将1000万元未分配利润转增股本。

```
借：利润分配——转作股本的股利 10,000,000
    贷：股本 10,000,000
```
