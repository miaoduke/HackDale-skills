# 三栏式总账登记与结账

## 前提条件
- 有效的记账凭单（包含日期、编号、摘要、金额）
- 账户期初余额
- 采用借贷记账法

## 账页结构初始化

确认账页包含以下标准栏目：
- 记账凭单（月、日、顺序号）
- 摘要
- 借方
- 贷方
- 借或贷
- 余额

填写账头信息：
- 科目名称（如"现金"）
- 编号
- 年度（如"2013年度"）
- 页码

## 登记期初余额

1. 在会计期间首日（如9月1日）的"摘要"栏填写"期初余额"
2. 在"余额"栏录入期初金额（如700）
3. 在"借或贷"栏注明余额方向（资产类通常为"借"）

## 逐笔登记经济业务

### 日期与凭证
根据记账凭单填写"月"、"日"及"顺序号"（如15日，记21/2）

### 摘要录入
简明扼要地填写经济业务内容（如"提现备发工资"、"发放工资"）

### 金额登记
- 借方发生额记入"借方"栏（如20,000）
- 贷方发生额记入"贷方"栏（如20,000）

## 计算并登记余额

每笔业务后即时进行计算。

### 计算逻辑
```
当前余额 = 上期余额 + 借方发生额 - 贷方发生额
```

### 示例计算
- 第一笔后：700（期初） + 20,000（借） = 20,700（余额），方向为"借"
- 第二笔后：20,700（上期） - 20,000（贷） = 700（余额），方向为"借"

将计算结果填入"余额"栏，并更新"借或贷"方向。

## 月末结账

在月末最后一行（如30日）执行以下操作：

1. 在"摘要"栏填写"本月发生额及余额"
2. **合计借方**：汇总本月所有借方发生额（如20,000），填入"借方"栏
3. **合计贷方**：汇总本月所有贷方发生额（如20,000），填入"贷方"栏
4. **确认期末余额**：确保"余额"栏数值与最后一笔业务后的余额一致（如700），方向一致（如"借"）
