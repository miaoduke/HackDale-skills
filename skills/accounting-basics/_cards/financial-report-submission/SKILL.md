# 财务会计报表报送时限

## 使用场景
当需要确定各类财务会计报表的对外报送截止日期、确保按时合规报送时使用此技能。

## 适用条件
- 会计期间（月度/季度/半年度/年度）终了
- 报表必须对外提供

## 报送时限标准

### 月度会计报表
- 报送时限：月度终了后6天内

### 季度会计报表
- 报送时限：季度终了后15天内

### 半年度会计报表
- 报送时限：半年度结束后60天内

### 年度会计报表
- 报送时限：年度终了后4个月内

## 确定流程

1. 确定当前需要报送的会计报表类型
2. 根据报表类型匹配对应的对外提供时限
3. 计算具体截止日期：期间终了日 + 规定天数

## 合规要求
- 必须在规定时限内对外提供
- 违反时限可能导致监管处罚

## 输出结果
报表应在[期间终了日] + [规定天数]内对外提供。
