# 记账凭证账务处理程序工作流程图

```
原始凭证
    ↓
编制记账凭证（收款/付款/转账凭证）
    ↓
    ├─→ 登记特种日记账（现金日记账、银行存款日记账）
    ├─→ 登记明细分类账（三栏式/数量金额式/多栏式）
    └─→ 逐笔登记总分类账（三栏式）
            ↓
        对账（总账与日记账、总账与明细账）
            ↓
        编制财务报表
```

## 凭证编制示例

### 收款凭证示例
```
收款凭证
借方科目：银行存款    2024年1月5日    收字第001号

摘要                贷方科目        金额      记账
收到客户货款        应收账款—甲公司  50,000    √
                    合计            50,000
```

### 付款凭证示例
```
付款凭证
贷方科目：库存现金  2024年1月8日    付字第005号

摘要                借方科目        金额      记账
支付办公用品费      管理费用        800       √
                    合计            800
```

### 转账凭证示例
```
转账凭证
2024年1月31日    转字第028号

摘要                借方科目        贷方科目        金额      记账
计提本月折旧        管理费用        累计折旧        2,000     √
                    合计            合计            2,000
```
