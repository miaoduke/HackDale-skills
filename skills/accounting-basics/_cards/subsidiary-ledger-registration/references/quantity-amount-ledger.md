# 数量金额式明细账登记详解

## 账簿结构初始化

### 表头字段
- 材料名称（如"甲种材料"）
- 规格（如"10 mm×10 mm"）
- 计量单位（如"千克"）
- 实际单价

### 表格栏目
- 日期（年/月/日）
- 凭证字号
- 摘要
- 收入(借方)[数量/单价/金额]
- 发出(贷方)[数量/单价/金额]
- 结存(余额)[数量/单价/金额]

## 期初余额录入

在首行"摘要"栏填入"期初余额"，在"结存(余额)"栏填入期初数量、单价及金额。

**示例**：数量 15,000，单价 20，金额 300,000

## 发出(贷方)业务登记

依据凭证字号（如"记1"）和业务内容（如"生产甲产品领用"、"生产乙产品领用"、"生产车间耗用"、"管理部门领用"）进行登记。

在"发出(贷方)"栏填入数量和单价。

**计算发出金额**：金额 = 数量 × 单价

**示例**：领用 1,260 千克，单价 20 元，金额 = 25,200 元

## 结存(余额)实时更新

每笔业务发生后，立即计算并填入新的结存数据。

### 计算公式
```
结存数量 = 上行结存数量 - 本次发出数量
结存金额 = 上行结存金额 - 本次发出金额
```

### 逻辑校验
结存金额应等于 结存数量 × 单价

### 示例步骤
- 第一步：15,000 - 1,260 = 13,740 (数量)；300,000 - 25,200 = 274,800 (金额)
- 第二步：13,740 - 1,420 = 12,320 (数量)；274,800 - 28,400 = 246,400 (金额)

## 本月合计计算

月末汇总"发出(贷方)"栏的数量和金额。

**示例**：数量合计 2,900，金额合计 58,000

确认期末结存：数量 12,100，单价 20，金额 242,000
