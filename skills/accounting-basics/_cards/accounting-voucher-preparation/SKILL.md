# 记账凭证填制流程

## 使用场景
- 持有审核无误的原始凭证
- 需要将经济业务记录传递至会计账簿
- 需要方便记账和减少差错

## 前提条件
- 必须基于"审核无误的原始凭证"开展工作

## 填制流程

### 步骤1：确认依据
- 检查原始凭证是否已经审核无误
- 确认原始凭证的合法性和有效性

### 步骤2：整理归类
- 由于原始凭证"来源不同，类型规格也各式各样"
- 为了"方便统一核算"，按"经济业务的类型"对原始凭证进行分类和整理

### 步骤3：确定分录
- 根据整理归类后的业务类型
- 确定"会计分录"（应借应贷账户及其金额）

### 步骤4：填制凭证
- 填制"记账凭证"（也称为"记账凭单"）
- 按照规定的格式和要求填写

### 步骤5：附件处理
- 将原始凭证附在记账凭证后面
- 确保原始凭证与记账凭证的对应关系

## 流程目的
- 此过程是"将原始凭证记录的经济业务向会计账簿传递的重要环节"
- 有助于"方便记账和减少差错"

## 流程关系
```
原始凭证（审核无误）→ 整理归类 → 确定会计分录 → 填制记账凭证 → 登记会计账簿
```

## 填制结果模板
```
生成一张填制完成的记账凭证，且后附原始凭证，作为登记账簿的直接依据
```
