# 债务违约风险机制

## 使用场景
当企业存在债务关系，到达偿还期限，需要评估延期未偿还的风险及后果时使用。

## 风险识别流程

### 第一步：检查偿还状态
确认企业是否延期且没有偿还债务（含本金）

### 第二步：评估后果
若发生延期未偿还，将产生以下后果：

#### 后果A：信誉受损
- 影响企业的商业信誉
- 可能影响未来的融资能力
- 降低供应商和合作伙伴的信任度

#### 后果B：经济赔偿
- 需要支付一定的赔偿金
- 可能产生违约金或罚息
- 增加财务成本

### 第三步：风险定义
上述信誉受损及赔偿金支付即为债务所承担的风险。

## 判定逻辑
```
IF (延期未偿还债务)
THEN 触发风险后果：
  - 信誉受损
  - 需支付赔偿金
```

## 风险管理建议
- 建立债务到期提醒机制
- 合理规划现金流，确保按时偿还
- 与债权人保持良好沟通
- 必要时提前安排债务重组或展期

## 注意事项
- 此风险机制不包含已按时偿还债务的情况
- 风险程度与延期时长、债务金额相关
- 信誉损失可能比经济赔偿影响更深远
