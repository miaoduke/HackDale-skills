# 文档章节结构识别

## 使用场景
当需要识别文档中特定章节的结构信息时使用此技能，包括：
- 解析文档节点时确认章节标题
- 验证章节的父路径和ID
- 检查章节是否包含正文内容或规则

## 执行步骤

1. **识别章节标题**
   - 确认章节的标题文本
   - 例如：'More'

2. **确认父路径**
   - 验证章节在文档树中的父节点路径
   - 例如：'Root'

3. **验证章节ID**
   - 确认章节的唯一标识符
   - 例如：'chunk_0464'

4. **检查章节内容**
   - 确认章节是否包含正文内容
   - 确认章节是否包含具体规则
   - 如果章节为空，记录该状态

## 输出结果
返回章节结构信息，包括：
- 章节标题
- 父路径
- 章节ID
- 内容状态（是否为空）

## 注意事项
- 此技能仅用于识别章节结构，不涉及内容分析
- 空章节仍需记录其结构信息
- 确保所有标识符准确无误
