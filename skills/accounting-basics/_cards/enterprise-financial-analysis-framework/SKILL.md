# 企业整体财务分析框架

## 使用场景
当启动企业整体财务分析流程时，必须应用此四大维度分类体系，确保分析的全面性和系统性。

## 分析维度

### 1. 企业经营效率分析
- **分析内容**：评估企业运营效率和资源利用效果
- **参考位置**：第164页

### 2. 企业偿债能力分析
- **分析内容**：评估企业偿还债务的能力和财务风险
- **参考位置**：第170页

### 3. 企业获利能力分析
- **分析内容**：评估企业创造利润的能力和盈利水平
- **参考位置**：第176页

### 4. 企业财务结构分析
- **分析内容**：评估企业资本结构和财务稳定性
- **参考位置**：第181页

## 执行步骤

1. **启动分析**：确认需要进行全面的企业财务状况评估
2. **应用框架**：按照四大维度构建完整的分析体系
3. **逐项分析**：对每个维度进行专项分析
4. **综合评估**：整合四个维度的分析结果，形成整体财务评估报告

## 输出结果
输出包含四个维度的完整财务分析框架列表，确保涵盖企业经营效率、偿债能力、获利能力和财务结构。
