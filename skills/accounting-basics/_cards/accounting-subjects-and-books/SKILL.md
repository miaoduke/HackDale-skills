# 会计科目与账簿设置

## 使用场景
- 企业建立会计核算体系
- 设置或调整会计科目
- 查询资产类会计科目
- 建立会计账簿体系

## 统一会计科目的设置原则

### 设置目的
- 对企业的经济业务进行规范和管理
- 便于统一管理
- 代表经济业务的性质和类型

### 设置依据
- 遵循国家会计法规的规定
- 使用国家专门设置的"统一的会计科目"

### 应用流程
1. **识别业务背景**：确认企业经济业务内容具有多样性
2. **依据法规标准**：遵循国家会计法规规定
3. **应用统一工具**：使用统一的会计科目
4. **执行分类映射**：利用会计科目代表业务性质和类型
5. **达成管理目标**：实现经济业务的规范和统一管理

## 会计账簿设置规范

### 设置依据
- 按照有关规定执行
- 根据企业性质和规模需要

### 核心要素
设置账簿主要确定：
- 账簿的种类
- 账簿的数量
- 账簿的内容
- 账簿的格式

### 标准账簿类型
企业一般需要设置以下账簿：
1. **总分类账**
2. **明细分类账**
3. **日记账**
4. **其他辅助账**

### 设置原则
在设置账簿时需满足以下平衡要求：
- 保证账簿的严密、完整
- 保证账簿的合理性和可操作性
- 避免过于复杂烦琐
- 避免过于简化
- **最终目标**：设置合理，便于查看

### 影响因素
- **企业性质**：企业的行业属性或组织形式（如工业企业、商业企业等）
- **企业规模**：企业的经营规模大小

## 资产类会计科目

资产类科目涵盖以下类别：
- 流动资产（如库存现金、应收账款）
- 长期投资（如长期股权投资）
- 固定资产（如固定资产、累计折旧）
- 无形资产及其他资产

**注意**：详细的资产类科目编号及名称对照表请参考 `references/asset-accounting-subjects.md`

## 执行步骤

### 设置会计科目体系
1. 确认企业性质和规模
2. 依据国家会计法规选择统一会计科目
3. 根据业务需求确定科目范围
4. 建立科目分类体系

### 建立会计账簿
1. 评估企业性质和规模
2. 确定账簿种类和数量
3. 设计账簿内容和格式
4. 确保设置合理且便于查看

## 输出结果

- **会计科目体系**：将具体经济业务归类至对应的统一会计科目中，实现标准化管理
- **账簿体系**：生成一套包含总分类账、明细分类账、日记账及其他辅助账的会计账簿体系，该体系严密完整且便于操作查看
