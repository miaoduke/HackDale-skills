# 记账方法分类与应用

## 使用场景
当发生经济业务且需要确定记账方式时，应用分类规则；当查看会计报表或编制会计记录时，应用复式记账平衡原则。

## 记账法分类规则

### 单式记账法
- **记录规则**：每项经济业务的内容和金额只记录在一个账户上
- **判定特征**：账户数量为1

### 复式记账法
- **记录规则**：每项经济业务的内容和金额同时记录在两个或两个以上的账户上
- **判定特征**：账户数量大于或等于2

### 判定逻辑
```
IF 记录账户数量 = 1 THEN 单式记账法
IF 记录账户数量 ≥ 2 THEN 复式记账法
```

## 增减记账法

### 记账符号
使用"增"和"减"作为记账符号。

### 记录方式
直接反映经济业务的发生所引起的会计要素变动。

### 理论基础
记账基础理论是"资金占用 = 资金来源"。

## 复式记账的平衡管理

### 核心概念
所有的会计报表都是一个整体的系统，通过会计科目相互联系构成"复式记账关系"。

### 复式记账特性
- **优势**：让会计账更加复杂，但"不容易出现漏洞"（即完备）
- **目的**：确保会计记录的完备性

### 会计科目与复式记账的对比

| 特性 | 会计科目 | 复式记账 |
|------|----------|----------|
| 作用 | 让会计记录简单而清楚 | 让会计账复杂而完备 |
| 目标 | 简单性 | 完备性 |

### 平衡管理原则
管理者需要在会计科目（简单性）和复式记账（完备性）之间寻找平衡，最终目标是获得一份"清楚而完备"的会计记录。

## 约束条件
- 不适用于非经济业务的记录
- 不适用于纯资产类、负债类、所有者权益类、成本类或损益类科目的共同类科目处理

## 预期结果
根据账户数量判定为'单式记账法'或'复式记账法'，获得一份既清楚又完备的会计记录，实现简单性与完备性的平衡。
